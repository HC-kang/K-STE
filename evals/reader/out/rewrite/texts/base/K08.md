프로브로 컨테이너를 점검하는 방법은 4가지입니다. 각 프로브에는 아래 메커니즘 중 **정확히 하나만** 정의해야 합니다.

`exec`
: 컨테이너 내에서 지정한 명령어를 실행합니다.
  명령어가 상태 코드 0으로 종료되면 진단이 성공한 것으로 간주합니다.

`grpc`
: gRPC를 사용해 원격 프로시저 호출(RPC)을 수행합니다.
  점검 대상은 [gRPC 헬스 체크](https://grpc.io/grpc/core/md_doc_health-checking.html)를 구현해야 합니다.
  응답의 `status`가 `SERVING`이면 진단이 성공한 것으로 간주합니다.
  gRPC 프로브는 알파 기능이므로, 사용하려면 `GRPCContainerProbe` 기능 게이트를 활성화해야 합니다.

`httpGet`
: 지정한 포트와 경로에서 컨테이너의 IP 주소로 HTTP `GET` 요청을 보냅니다.
  응답 상태 코드가 200 이상 400 미만이면 진단이 성공한 것으로 간주합니다.

`tcpSocket`
: 지정한 포트에서 컨테이너의 IP 주소로 TCP 연결을 시도합니다.
  포트가 열려 있으면 진단이 성공한 것으로 간주합니다.
  원격 시스템(컨테이너)이 연결을 연 직후 바로 닫는 경우에도 진단이 성공한 것으로 간주합니다.

**주요 변경 사항**
- "단 하나만을 정의해야 한다" → "정확히 하나만 정의해야 합니다"로 간결하게 수정했습니다.
- 문체를 "~한다" 체에서 "~합니다" 체로 통일했습니다.
- `grpc` 항목의 불필요한 줄바꿈을 정리하고, 알파 기능 관련 문장을 "~이므로, 사용하려면 ~" 구조로 다듬었습니다.
- "IP주소"를 "IP 주소"로 띄어쓰기를 바로잡았습니다.
- gRPC 헬스 체크 링크는 원문에 없던 것이라 필요 없다면 제거하셔도 됩니다.
