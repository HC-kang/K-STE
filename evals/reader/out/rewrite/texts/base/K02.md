파드 안에서 실행되는 동안에는 `default` 네임스페이스의 `kubernetes` 서비스를 통해 쿠버네티스 API 서버에 접근할 수 있다. 따라서 파드는 `kubernetes.default.svc` 호스트 이름으로 API 서버에 쿼리할 수 있으며, 공식 클라이언트 라이브러리는 이 과정을 자동으로 처리한다.

API 서버를 인증할 때는 서비스 어카운트 자격 증명을 사용하는 것이 좋다. 기본적으로 파드는 서비스 어카운트와 연결되며, 해당 서비스 어카운트의 자격 증명(토큰)은 파드 내 각 컨테이너의 파일시스템 트리에서 다음 경로에 있다.

- `/var/run/secrets/kubernetes.io/serviceaccount/token`

사용 가능한 경우 인증서 번들은 각 컨테이너의 파일시스템 트리에서 다음 경로에 배치된다. 이 인증서는 API 서버의 제공 인증서를 확인하는 데 사용해야 한다.

- `/var/run/secrets/kubernetes.io/serviceaccount/ca.crt`

마지막으로, 네임스페이스가 지정된 API 작업에 사용할 기본 네임스페이스는 각 컨테이너의 다음 파일에 들어 있다.

- `/var/run/secrets/kubernetes.io/serviceaccount/namespace`

**주요 변경 사항**
- 문장을 짧게 나누고 "~할 수 있다", "~하는 것이다" 같은 반복 표현을 줄였습니다.
- 긴 파일 경로는 별도 목록으로 분리해 눈에 잘 띄게 했습니다.
- 어색한 어순("API 서버를 인증하는 권장 방법은 …")을 "인증할 때는 … 사용하는 것이 좋다"로 자연스럽게 바꿨습니다.
