다듬은 글은 다음과 같습니다.

---

이 문서는 쿠버네티스 클러스터에서 서비스 IP 주소 범위를 관리하는 방법을 설명합니다. 이 범위는 클러스터가 서비스에 지원하는 IP 패밀리에도 영향을 줍니다.

서비스 ClusterIP에 사용할 수 있는 IP 패밀리는 kube-apiserver의 `--service-cluster-ip-range` 플래그로 결정됩니다. 서비스 IP 주소 할당 방식을 더 자세히 알아보려면 가상 IP 및 서비스 프록시 문서를 참고하세요.

쿠버네티스 1.33부터는 클러스터에 설정된 서비스 IP 패밀리가 `kubernetes`라는 이름의 `ServiceCIDR` 오브젝트에 반영됩니다. 이 오브젝트는 가장 먼저 실행된 kube-apiserver 인스턴스가 자신의 `--service-cluster-ip-range` 플래그 값을 기반으로 생성합니다. 클러스터가 일관되게 동작하려면 모든 kube-apiserver 인스턴스에 동일한 `--service-cluster-ip-range` 값을 설정해야 하며, 이 값은 기본 `kubernetes` `ServiceCIDR` 오브젝트와도 일치해야 합니다.
