프로브로 컨테이너를 점검하는 방법은 4가지가 있습니다. 각 프로브에는 아래 메커니즘 중 **하나만** 정의해야 합니다.

`exec`
: 컨테이너 안에서 지정한 명령어를 실행합니다.
  명령어가 상태 코드 0으로 종료되면 진단에 성공한 것으로 간주합니다.

`grpc`
: gRPC를 사용해 원격 프로시저 호출(RPC)을 수행합니다.
  점검 대상이 [gRPC 헬스 체크](https://grpc.io/docs/guides/health-checking/)를 구현해야 합니다.
  응답의 `status`가 `SERVING`이면 진단에 성공한 것으로 간주합니다.
  gRPC 프로브는 알파 기능이므로, 사용하려면 `GRPCContainerProbe` 기능 게이트를 활성화해야 합니다.

`httpGet`
: 지정한 포트와 경로에서 컨테이너의 IP 주소로 HTTP `GET` 요청을 보냅니다.
  응답 상태 코드가 200 이상 400 미만이면 진단에 성공한 것으로 간주합니다.

`tcpSocket`
: 지정한 포트에서 컨테이너의 IP 주소로 TCP 연결을 시도합니다.
  포트가 열려 있으면 진단에 성공한 것으로 간주합니다.
  원격 시스템(컨테이너)이 연결을 연 직후 바로 닫는 경우에도 성공으로 간주합니다.

**수정한 부분**
- "체크하는 방법에는 4가지가 있다 / 4가지 메커니즘"의 중복을 정리하고, 문체를 "~합니다"로 통일했습니다. 원문 스타일("~한다")을 유지하려면 말씀해 주세요.
- `grpc` 항목의 불필요한 줄바꿈을 없애고, 문장 단위로 나눴습니다.
- "TCP 검사를 수행한다"는 실제 동작에 맞게 "TCP 연결을 시도합니다"로 풀어 썼습니다.
- "포트가 활성화되어 있다면"은 "포트가 열려 있으면"으로 바꿨습니다.
- 원문에 없던 gRPC 헬스 체크 링크를 추가했습니다. 필요 없으면 지우셔도 됩니다.
