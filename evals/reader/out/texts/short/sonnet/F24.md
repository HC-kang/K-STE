# 임시 좌석 점유 자동 해제 작업 추가 (PR #853)

이 PR은 해솔예약 묶음 5-4에 속하며, 임시 좌석 점유를 자동으로 해제하는 작업을 추가한다. 배포 실행 담당 당직자 문라온은 아래 절차로 배포한다.

## 배경

결제 없이 닫힌 예약 화면의 좌석 점유가 남아 있었다. 그래서 판매 가능 좌석 수가 줄었다.

## 변경 내용

- 자동 해제 작업을 추가한다.
- 자동 해제 작업은 5분 간격으로 실행된다.
- 이번 PR은 해외 공연 영역에 적용하지 않는다.

## 해제 대상

생성 후 15분 이상 지난 미결제 임시 점유를 해제한다. 결제 완료 좌석과 상담원이 수동으로 잠근 좌석은 해제 대상에서 제외한다.

## 담당자

| 역할 | 담당자 |
| --- | --- |
| 개발 | 오시안 |
| 배포 실행(당직자) | 문라온 |
| 배포 승인(서비스 책임자) | 한지율 |

## 위치

- 검토 위치는 haesol/booking의 PR #853이다.
- 배포 위치는 운영 콘솔 seat-ops의 국내 공연 영역이다.

## 일정

| 항목 | 마감 또는 시작 |
| --- | --- |
| 한지율 승인 마감 | 12/02(수) 18:00 |
| 문라온 배포 시작 | 12/03(목) 09:00 |
| 관찰 결과 기록 마감 | 12/03(목) 10:00 |

## 배포 절차

1. 문라온은 배포 전에 현재 설정값을 내보내야 한다.
2. 문라온은 한지율의 승인을 확인한 뒤, 12/03(목) 09:00에 운영 콘솔 seat-ops의 국내 공연 영역에서 배포를 시작한다.
3. 문라온은 배포 후 첫 30분 동안 관찰해야 한다.
4. 문라온은 관찰 결과를 PR #853 댓글에 12/03(목) 10:00까지 기록해야 한다.

추가 30분 관찰은 해도 된다. 해외 공연 영역은 수동 점검을 하지 않아도 된다.

## 중지 조건

**관찰 중 결제 완료 좌석의 해제 건수가 1건 이상이면, 문라온은 즉시 작업을 중지하고 한지율에게 연락해야 한다.**
