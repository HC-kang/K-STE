# 정산 CSV 생성기 중복 행 제거 (모람결제 묶음 5-1, PR #526)

이 PR은 정산 CSV 생성기가 같은 거래 행을 중복해서 쓰는 문제를 고친다.

## 변경 내용

- 원인은 재시도 요청마다 같은 거래 행이 CSV에 추가되는 것이다.
- 이 PR은 거래 ID와 정산일의 조합이 같으면 중복 행으로 판정하도록 바꾼다.

## 적용 범위

- 이 변경은 국내 원화 정산 CSV에만 적용한다.
- 해외 통화 CSV는 변경 대상이 아니다.
- 화면 조회 API는 변경 대상이 아니다.

## 검토 방법

고유찬은 아래 순서로 검토해야 한다.

1. 중복 거래를 포함한 2,000행 샘플을 실행한다.
2. 생성 결과가 1,960행인지 확인한다.
3. 실행 로그를 PR에 첨부한다.

성능 기준은 샘플 생성 시간 8초 이하다. 생성 시간이 8초를 초과하면 승인 보류와 서다빈의 수정 요청이 필수다.

확인 필요: 8초를 초과할 때 승인을 보류하고 수정을 요청하는 주체가 고유찬인지 확인이 필요하다.

선택 사항은 다음과 같다.

- 전체 거래 재생 테스트는 선택이다.
- 해외 통화 샘플 실행은 하지 않아도 된다.
