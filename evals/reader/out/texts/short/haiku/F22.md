이 PR(병합 요청)은 출고 라벨을 재인쇄할 때 이전 라벨을 자동으로 무효화하는 기능을 추가한다. 대상은 누비창고 묶음 5-2이고, 저장소는 nubi/dispatch의 PR #631이다.

### 배경

재인쇄 후에도 이전 라벨이 스캔된다. 그래서 한 상자가 두 번 출고 처리된다.

### 자동 무효화 적용 조건

- 동일 주문의 동일 상자 라벨을 재인쇄하면 이전 라벨을 자동으로 무효화한다.
- 주문이 같더라도 상자가 다르면 기존 라벨을 유지한다.

### 역할

| 담당 | 이름 | 내용 |
|---|---|---|
| 개발 담당 | 백도윤 | PR #631을 병합할 예정이다. stage-pack 접속 문제를 문의받는다. |
| 필수 검증 담당(QA) | 윤해솔 | 검증을 수행하고 결과를 등록한다. 판정 기준을 문의받는다. |
| 현장 담당 | 임채원 | 검증 결과를 열람한다. 검증은 하지 않아도 된다. |

### 일정

- 검증은 11/16(월) 13:00에 시작한다.
- 윤해솔은 11/18(수) 15:00까지 결과를 등록한다.
- 백도윤은 11/19(목) 10:00에 PR #631을 병합할 예정이다.

### 검증 환경

- 검증 대상은 nubi/dispatch의 PR #631이다.
- 검증은 검증 서버 stage-pack에서 한다.
- 실제 출고 서버에서 테스트하면 안 된다.

### 필수 검증

- 재인쇄 사례 12건과 다른 상자 사례 8건, 총 20건의 결과를 PR 체크리스트에 기록해야 한다.
- 이전 라벨 무효화는 3초 이내에 끝나야 한다.
- **한 건이라도 3초를 초과하면 병합 차단 표시를 해야 한다.**
- 고정형 스캐너 검증은 해야 한다.
- 휴대형 스캐너 검증은 하지 않아도 된다.
- 프린터 외관 사진은 첨부하지 않아도 된다.

### 문의처

- 판정 기준은 윤해솔에게 문의한다.
- stage-pack 접속 문제는 백도윤에게 문의한다.
- 사내 메신저 #label-qa 채널을 이용한다.
