PR #853은 결제 없이 닫힌 예약 화면에 남은 임시 좌석 점유를 자동으로 해제하는 작업을 추가한다.

## 배경

결제 없이 닫힌 예약 화면에서 좌석 점유가 남는다. 남은 좌석 점유 때문에 판매 가능 좌석 수가 줄어든다.

## 변경 내용

자동 해제 작업은 생성 후 15분 이상 지난 미결제 임시 점유 좌석을 해제한다. 결제 완료 좌석과 상담원 수동 잠금 좌석은 해제하지 않는다. 자동 해제 작업은 5분 간격으로 실행된다. 이번 PR은 해외 공연 영역에 자동 해제 작업을 적용하지 않는다.

검토 위치는 haesol/booking의 PR #853이다. 배포 위치는 운영 콘솔 seat-ops의 국내 공연 영역이다.

## 담당자와 일정

개발 담당은 오시안이다. 배포 실행 담당은 당직자 문라온이다. 배포 승인 담당은 서비스 책임자 한지율이다.

| 항목 | 일시 |
|---|---|
| 배포 승인 마감 | 12/02(수) 18:00 |
| 배포 시작 | 12/03(목) 09:00 |
| 관찰 결과 기록 마감 | 12/03(목) 10:00 |

## 배포 절차

배포 전에 문라온은 현재 설정값을 내보내야 한다.
문라온은 배포 후 첫 30분 동안 관찰해야 한다.
문라온은 관찰 결과를 PR 댓글에 기록해야 한다.

**관찰 중 결제 완료 좌석 해제 건수가 1건 이상이면 즉시 작업을 중지하고 한지율에게 연락해야 한다.**

추가 30분 관찰은 선택 사항이다. 해외 공연 수동 점검은 하지 않아도 된다.
