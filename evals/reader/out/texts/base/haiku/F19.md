# 누리담렌탈 중복 교환 주문 처리 런북

**대상:** 고객센터 교환 접수 상담사
**시스템:** 주문 시스템 '담주문'
**묶음:** 4
**적용 기간:** 2026년 12월 3일(목) 09:00 ~ 12월 4일(금) 18:00

---

## 1. 배경

고객 앱의 재시도 오류로 동일 제품의 교환 주문이 중복 생성되는 문제가 발생하고 있습니다. 이 런북은 중복 주문을 식별하고, 출고 상태에 따라 취소하거나 물류 담당에게 이관하는 절차를 설명합니다.

---

## 2. 중복 검토 대상 판단 기준

### 2-1. 동일 주문 묶음 조건 (세 가지 모두 일치)

| 항목 | 기준 |
|---|---|
| 계약번호 | 동일 |
| 제품번호 | 동일 |
| 회수 주소 | 동일 |

세 가지 중 **하나라도 다르면 중복이 아니므로 일반 접수를 유지**합니다.

### 2-2. 시간 조건

- 동일 묶음 주문이 **30분 이내에 2건 이상** 생성되면 중복 검토 대상입니다.
- 기준 시점은 **가장 먼저 생성된 주문(최초 주문)의 생성 시각**입니다.
- **30분을 초과해 생성된 주문은 이번 중복 취소 절차를 적용하지 않습니다.** 임의로 취소하지 말고 일반 접수를 유지합니다.

---

## 3. 처리 절차

### 1단계: 검토 대상 확인
1. '담주문'에서 계약번호, 제품번호, 회수 주소가 같은 교환 주문을 조회합니다.
2. 생성 시각을 확인하고, 최초 주문 기준 30분 이내 주문을 검토 대상으로 묶습니다.
3. 검토 대상이 1건뿐이면 중복이 아니므로 일반 접수를 유지합니다.

> **시간 제한:** 검토 대상을 발견한 시점부터 **20분 이내**에 상담사 처리 또는 물류 이관을 완료해야 합니다.

### 2단계: 출고 상태 확인
검토 대상 주문 전체의 출고 상태를 확인합니다.

### 3단계: 분기 처리

**[경우 A] 검토 대상 전부 '출고 전'**
1. 최초 주문 1건은 유지합니다.
2. 나머지 주문은 **반드시 취소**합니다.
3. 취소 사유 코드는 **D14**를 사용합니다.
4. 주문 메모에 **유지 주문번호**를 기록합니다.
5. 처리 후 고객에게 안내 문자를 발송합니다 (4단계 참고).

**[경우 B] 검토 대상 중 '출고 완료' 주문이 1건이라도 있음**
1. **상담사 취소는 하지 않습니다.**
2. **물류 담당 고도윤에게 반드시 이관**합니다.
3. 주문 메모에 **물류 이관번호**를 기록합니다.
4. 이관 후 고객에게 안내 문자를 발송합니다 (4단계 참고).

---

## 4. 고객 안내

- 취소 전 고객에게 전화할 필요는 없습니다.
- **처리(취소 또는 물류 이관) 후 안내 문자를 반드시 발송**합니다.
- 고객이 요청한 경우 **취소 내역 이메일을 추가로 발송**할 수 있습니다.
- 이메일 발송 여부와 관계없이 **안내 문자는 필수**입니다.

---

## 5. 금지 사항

| 금지 항목 | 내용 |
|---|---|
| 출고 완료 주문 취소 | 검토 대상에 출고 완료 주문이 있으면 상담사가 취소할 수 없습니다. 고도윤에게 이관합니다. |
| 사유 코드 D41 사용 | 고객 변심 취소 코드 D41은 중복 취소에 사용할 수 없습니다. 중복 취소는 D14만 사용합니다. |
| 30분 초과 주문 임의 취소 | 시간 조건을 벗어난 주문은 일반 접수를 유지합니다. |
| 기준 불일치 주문 취소 | 계약번호, 제품번호, 회수 주소 중 하나라도 다르면 취소하지 않습니다. |

## 9. 운영 전 확인이 필요한 사항

1. **'최초 주문'의 기준 시각:** 생성 시각이 같은 주문이 여러 건일 때의 기준을 정해 두면 좋습니다.
2. **안내 문자 양식:** 표준 문구가 있다면 런북에 첨부해 주세요.
3. **이관 방법:** 고도윤에게 이관하는 구체적인 경로(시스템 기능, 내선 연락 등)를 명시해 주세요.
4. **적용 연도:** 적용 기간이 2026년 12월로 되어 있어 현재 날짜(2026년 10월 18일) 기준으로는 아직 시작 전입니다. 연도가 맞는지 확인해 주세요.
