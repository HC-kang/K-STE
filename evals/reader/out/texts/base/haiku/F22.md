# [PR #631] 출고 라벨 재인쇄 시 이전 라벨 자동 무효화

**저장소:** nubi/dispatch
**고객사:** 누비창고
**작업 묶음:** 5-2
**개발 담당:** 백도윤
**필수 검증 담당(QA):** 윤해솔
**결과 열람 담당:** 임채원(현장 담당, 검증 의무 없음)

---

## 1. 변경 요약

출고 라벨을 재인쇄하면 이전 라벨이 자동으로 무효화되도록 합니다.

## 2. 문제 원인

재인쇄 후에도 이전 라벨이 스캔 가능한 상태로 남아 있습니다. 그 결과 한 상자가 두 번 출고 처리되는 문제가 발생합니다.

## 3. 자동 무효화 적용 조건

| 상황 | 동작 |
|---|---|
| 동일 주문의 **동일 상자** 라벨 재인쇄 | 이전 라벨 자동 무효화 |
| 동일 주문이지만 **다른 상자** | 기존 라벨 유지 |

> 주문 번호가 같아도 상자가 다르면 기존 라벨을 무효화하지 않습니다. 이 구분이 맞게 동작하는지 반드시 확인해 주세요.

## 4. 검증 환경 및 금지 사항

- **검증 위치:** nubi/dispatch의 PR #631, 검증 서버 `stage-pack`
- **금지:** 실제 출고 서버에서 테스트하지 않습니다.
