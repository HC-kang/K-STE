# 포장재 시험 운영 회의록

| 항목 | 내용 |
|---|---|
| **회의명** | 포장재 시험 운영안 확정 회의 |
| **일시** | 2026년 11월 3일(화) 10:00~10:30 |
| **장소** | 본사 2층 회의실 |
| **관련 부서** | 모래별패키징 생산기술팀, 포장 2라인 |
| **참석자** | 윤세람(생산기술 담당), 도하준(포장 2라인 조장) |
| **작성자** | |

---

## 1. 안건

기존 완충재 사용 제품의 모서리 파손 신고가 증가함에 따라, 새 완충재 적용 시험 운영안을 확정한다.

## 2. 시험 배경

- 기존 완충재를 사용한 제품에서 모서리 파손 신고가 증가하였다.

## 3. 시험 개요

| 항목 | 내용 |
|---|---|
| **시험 일시** | 2026년 11월 5일(목) 09:00~12:00 |
| **시험 장소** | 제1공장 포장 2라인 |
| **시험 대상** | 새 완충재 적용 제품 240상자 |
| **제외 범위** | 포장 1라인은 이번 시험에서 제외한다. 새 완충재 수령 및 시험 결과 등록이 모두 불필요하다. |

## 4. 역할 및 담당 업무

| 담당자 | 역할 | 기한 및 세부 사항 |
|---|---|---|
| **윤세람** (생산기술 담당) | 새 완충재 300개 자재 배치 | 2026년 11월 4일(수) 16:00까지 포장 2라인 자재대에 배치 (필수) |
| **도하준** (포장 2라인 조장) | 시험 상자 모서리 상태 확인 | 시험 상자 240개 전량 확인 (필수) |
| **도하준** (포장 2라인 조장) | 시험 결과 등록 | 2026년 11월 5일(목) 15:00까지 '포장결' 시스템 등록 (필수) |
| **생산기술팀** | 시험 참관 | 2026년 11월 5일(목) 09:00~10:00, 선택 사항 |

## 5. 시험 중단 및 계속 기준

모서리 파손 상자 수에 따라 다음과 같이 처리한다.

| 파손 상자 수 | 조치 |
|---|---|
| **5상자 이상** | 시험을 즉시 중단한다. 도하준이 윤세람에게 전화로 보고한다. (필수) |
| **4상자 이하** | 예정된 240상자 시험을 계속한다. 추가 시험은 윤세람의 승인을 받은 경우에만 진행할 수 있다. |

## 6. 후속 일정

| 2026년 11월 6일(금) 11:00 | 시험 결과 검토 회의 | 본사 2층 회의실 | 윤세람, 도하준 (필수) |
