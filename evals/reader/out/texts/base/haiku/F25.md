# PR #964: 센서 연결 끊김 알림 재발송 간격 변경

**회사:** 다온센서 | **묶음:** 5-5 | **저장소:** daon/alerts
**개발:** 류한결 | **고객지원 필수 검토:** 배소율 | **문서(안내 문구):** 진유하

## 배경

짧은 통신 끊김이 반복되면 같은 설비에서 연결 끊김 알림이 계속 쌓입니다. 이로 인해 고객지원 문의가 늘고 있습니다. 이번 PR은 같은 센서의 연결 끊김 알림 재발송 간격을 조정해 중복 알림을 줄이는 것을 목표로 합니다.

## 변경 내용

**적용 대상**
- 표준 요금제의 **이메일** 연결 끊김 알림

**제외 대상 (동작 변경 없음)**
- 기업 요금제 알림
- 문자(SMS) 알림

**새 발송 동작**
- 같은 센서의 연결 끊김이 계속되면, 최초 이메일은 즉시 발송합니다.
- 이후 재발송은 **20분 간격**으로 합니다.
- 연결 복구 이메일은 대기 없이 **즉시** 발송합니다.

## 검토 환경

- 검토 위치: `daon/alerts`의 PR #964
- 테스트 계정: **demo-factory**(데모 계정)만 사용합니다.
- **고객의 실제 계정은 사용하지 마세요.**
