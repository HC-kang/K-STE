# [묶음 5-4] 임시 좌석 점유 자동 해제 작업 추가 (PR #853)

**회사:** 해솔예약
**저장소:** haesol/booking, PR #853
**배포 위치:** 운영 콘솔 seat-ops > 국내 공연 영역
**개발 담당:** 오시안
**배포 실행 담당(당직자):** 문라온
**배포 승인 담당(서비스 책임자):** 한지율

## 1. 변경 배경

결제 없이 닫힌 예약 화면에서 좌석 임시 점유가 해제되지 않고 남아, 판매 가능 좌석 수가 실제보다 적게 표시되는 문제가 있습니다. 이를 해결하기 위해 미결제 임시 점유를 주기적으로 자동 해제하는 작업을 추가합니다.

## 2. 변경 내용

- **해제 대상:** 생성 후 15분 이상 지난 미결제 임시 점유
- **해제 제외:**
  - 결제 완료 좌석
  - 상담원이 수동으로 잠근 좌석
- **실행 간격:** 5분
- **적용 범위:** 국내 공연 영역만 적용. 해외 공연 영역에는 이번 PR을 적용하지 않습니다.

## 5. 배포 절차

1. seat-ops 운영 콘솔에서 국내 공연 영역을 선택합니다.
2. PR #853의 자동 해제 작업을 배포합니다. 실행 간격은 5분입니다.
3. 배포 직후 **첫 30분 동안 관찰**합니다 (필수).
4. 추가 30분 관찰은 선택 사항입니다.
5. 해외 공연 수동 점검은 불필요합니다.
