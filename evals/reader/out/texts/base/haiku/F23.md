# PR #742: 웹 강의 플레이어 키보드 자막 설정 기능

## 배경
- **회사/프로젝트:** 새온학습, 묶음 5-3
- **저장소:** saeon/player
- **문제:** 기존 자막 설정 창은 마우스로만 열 수 있어 키보드 사용자가 자막 설정을 변경할 수 없었습니다.

## 변경 내용
- 키보드로 자막 설정 창을 열 수 있도록 기능을 추가했습니다.
- **단축키 C:** 플레이어에 초점이 있을 때만 자막 설정 창을 엽니다. 검색 입력란에 초점이 있으면 문자 `c`를 그대로 입력합니다.

## 적용 범위
- **포함:** 녹화 강의 웹 플레이어
- **제외:** 실시간 강의, 모바일 앱 플레이어
