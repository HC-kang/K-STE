# 냉장 원료 입고 보류 런북 (서리온푸드 · 동부 물류센터)

**근거:** 묶음 4, 서리온푸드 차량 온도계 교정 누락 발견에 따른 지정 차량 원료 추가 검수
**적용 기간:** 2026년 11월 16일(월) ~ 11월 18일(수)

---

## 1. 적용 대상

- **장소:** 동부 물류센터 2번 도크에 도착하는 차량
- **차량:** 차량 번호 끝자리가 **62번** 또는 **84번**인 차량
- **대상 외 차량:** 기존 검수 절차를 그대로 따릅니다. 추가 3상자 측정과 추가 보류 등록은 하지 않습니다.

## 2. 역할 및 연락처

| 역할 | 담당자 | 주요 업무 | 연락처 |
|---|---|---|---|
| 입고 검수자 | 한지오 | 온도 측정, 봉인 확인, 보류 등록 | - |
| 품질 당직 | 정다빈 | 보류 원료 사용 가능 여부 결정(승인/반송), 검수 기준 문의 | 내선 5221 |
| 창고 반장 | 유태건 | 보류 원료 보관 위치 배정, Q구역 자리 부족 문의 | 내선 5227 |

## 3. 절차

### 단계 1. 차량 도착 확인
- 2번 도크 도착 차량의 번호 끝자리가 62 또는 84인지 확인합니다.
- 해당하지 않으면 기존 검수 절차를 따르고 이 런북을 적용하지 않습니다.

### 단계 2. 원료 중심 온도 측정 (도착 후 15분 이내, 필수)
- 원료 상자 **3개**를 무작위로 골라 각 상자의 **중심 온도**를 측정합니다.
- 측정한 **3개 값을 모두 기록**합니다.

### 단계 3. 온도 판정
- **3개 값이 모두 0.0℃ 이상 5.0℃ 이하**이면 온도 기준은 통과입니다.
- **1개라도 범위를 벗어나면** 해당 차량의 원료 **전량 보류**입니다.

### 단계 4. 봉인 상태 확인
- 온도 기준이 통과여도 상자 **봉인이 훼손**된 것을 발견하면 해당 차량의 원료 **전량 보류**입니다.
- 재측정으로는 보류를 해제할 수 없습니다.

### 단계 5. 판정 결과에 따른 처리

**정상 입고 (온도 통과 + 봉인 이상 없음)**
- 기존 입고 절차에 따라 입고합니다.

**보류 (온도 이탈 또는 봉인 훼손)**
1. **보류 등록:** 차량 도착 후 **30분 이내**에 재고 시스템 **‘찬고’**에서 등록을 완료합니다. 현장 사진 첨부는 선택 사항입니다.
2. **보관 위치 배정:** 유태건 창고 반장이 위치를 배정합니다.
3. **이동 및 표시:** 보류 원료를 **냉장고 Q구역**으로 옮기고 **노란 보류표**를 반드시 부착합니다.
4. **출고 금지:** 정다빈 품질 당직의 승인 전에는 **생산 출고를 할 수 없습니다.**

### 단계 6. 품질 당직 판단 (보류 등록 후 60분 이내)
- 정다빈 품질 당직이 보류 원료의 사용 가능 여부를 결정합니다.
- 결정 결과(**승인** 또는 **반송**)를 찬고에 **보류 등록 후 60분 이내**에 기록합니다.

## 4. 빠른 판정표

| 조건 | 처리 |
|---|---|
| 3개 중심 온도 모두 0.0~5.0℃ 이고 봉인 이상 없음 | 정상 입고 |
| 3개 중 1개 이상 0.0℃ 미만 또는 5.0℃ 초과 | 차량 원료 전량 보류 |
| 온도 통과, 상자 봉인 훼손 발견 | 차량 원료 전량 보류 (재측정으로 해제 불가) |
| 대상 외 차량 (끝자리 62·84 아님) | 기존 검수 유지 |

## 5. 시간 기준 요약

| 항목 | 기한 |
|---|---|
| 온도 측정 (상자 3개) | 차량 도착 후 15분 이내 |
| 보류 등록 (찬고) | 차량 도착 후 30분 이내 |
| 승인 또는 반송 기록 (찬고) | 보류 등록 후 60분 이내 |

## 6. 문의

- **검수 기준 문의:** 정다빈 품질 당직, 내선 5221
- **Q구역 자리 부족 문의:** 유태건 창고 반장, 내선 5227

---

**확인이 필요한 사항 (메모에 명시되지 않음):**
- 중심 온도 측정에 사용할 온도계 및 측정 방법(예: 탐침 삽입 깊이)
- 봉인 훼손 판정 기준(어떤 상태를 훼손으로 볼지)
- 온도계 교정 완료 여부 확인 방법
- 측정 기록 양식(찬고 입력 방식 또는 별도 기록지 여부)

이 항목들은 현장 운영 기준이 정해져 있다면 런북에 추가하는 것이 좋습니다.
