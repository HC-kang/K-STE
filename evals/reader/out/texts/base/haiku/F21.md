## PR #526: 정산 CSV 생성기 중복 행 제거

**회사/묶음:** 모람결제 / 묶음 5-1
**저장소:** moram/settlement
**작성자:** 서다빈
**필수 승인자:** 고유찬 (정산 플랫폼 리뷰어)
**참조:** 나세림 (보안 담당, 승인 불필요)

---

### 변경 배경

재시도 요청이 들어올 때마다 같은 거래 행이 정산 CSV에 다시 추가되어 중복 행이 생성되고 있습니다. 이 PR은 중복 판정 기준을 **거래 ID와 정산일의 조합**으로 변경해, 같은 거래가 같은 정산일에 두 번 기록되지 않도록 합니다.

### 변경 내용

- 정산 CSV 생성기에서 행을 추가하기 전에 (거래 ID, 정산일) 조합으로 중복 여부를 확인하고, 중복이면 추가하지 않도록 수정했습니다.

### 적용 범위

- **포함:** 국내 원화 정산 CSV
- **제외:** 해외 통화 CSV, 화면 조회 API (변경 없음)

### 리뷰어 필수 확인 사항

1. **샘플 실행 (필수):** 중복 거래를 포함한 **2,000행 샘플**로 CSV 생성기를 실행합니다.
   - 생성 결과가 **1,960행**인지 확인합니다.
   - 실행 로그를 PR에 첨부합니다.
2. **성능 기준 (필수):** 샘플 생성 시간이 **8초 이하**여야 합니다.
   - 8초를 초과하면 승인을 보류하고, 서다빈이 수정해야 합니다.

### 선택 사항

- 전체 거래 재생 테스트는 선택 사항입니다.
- 해외 통화 CSV 샘플 실행은 필요하지 않습니다.
