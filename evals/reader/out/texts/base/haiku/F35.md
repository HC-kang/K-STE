# [공지] 온라인 실시간 강좌 강의 자료 제출 규정 변경 안내

**대상:** 온라인 실시간 강좌 강사 및 운영 매니저
**시행일:** 2026년 12월 14일(월) 개강 강좌부터
**문의:** 교육지원 서이담 / 메신저 '자료운영문의'

---

## 1. 변경 배경

최근 강의 자료가 늦게 수정되면서 수강생에게 이전 버전 파일이 배포되는 사례가 발생했습니다. 이를 방지하기 위해 자료 제출 시점을 앞당기고, 제출 이후의 자료 변경 절차를 정비합니다.

## 2. 적용 범위

- **적용:** 온라인 실시간 강좌의 강사 및 운영 매니저
- **제외:** 사전 녹화 강좌는 기존 자료 등록 규정을 그대로 따릅니다.

## 3. 주요 변경 사항

### 가. 자료 제출 마감 변경

자료 제출 시점이 **개강 1일 전에서 3일 전으로** 앞당겨집니다.

### 나. 강사 업무

- 개강 3일 전 **18:00까지** '배움결' 시스템의 강좌별 **'배포 자료'** 메뉴에 최종 PDF를 업로드해야 합니다.
- 자료는 **강좌당 PDF 1개, 파일 크기 20MB 이하**로 제출합니다.
- 여러 문서가 있는 경우 강사가 **PDF 1개로 합쳐서** 업로드합니다.

### 다. 운영 매니저 업무

- 개강 2일 전 **12:00까지** 파일 열림 여부와 강좌명을 확인한 후, 시스템에서 **검수 완료** 처리해야 합니다.

### 라. 제출 마감 이후 자료 변경

- 제출 마감 이후에는 **강사가 직접 파일을 교체할 수 없습니다.**
- 내용 오류를 수정해야 할 경우 '배움결'의 **'수정 요청'** 메뉴로 접수합니다.
- 운영 매니저 승인 후 매니저가 파일을 교체합니다.

### 마. 수업 중 발견된 오류

- 수업 중 발견된 내용 오류는 강사가 먼저 **구두로 바로잡을 수 있습니다.**
- 다만 수업 종료 후 **2시간 이내에 '수정 요청'을 접수하는 것은 필수**입니다.

### 바. 동일 강좌 재개설 시

- 자료 변경이 없는 동일 강좌를 재개설하는 경우 기존 파일을 재사용할 수 있습니다.
- 강사는 제출 마감까지 **'기존 자료 사용' 버튼을 클릭**해야 하며, 파일을 다시 업로드할 필요는 없습니다.

## 4. 주요 일정 요약 (12/14 개강 강좌 기준)

| 구분 | 기한 | 담당 | 내용 |
|---|---|---|---|
| 규정 확인 | 12/10(목) 17:00 | 강사·운영 매니저 | '배움결' 공지의 규정 확인 버튼 클릭 |
| 자료 제출 | 12/11(금) 18:00 | 강사 | 최종 PDF 업로드 (또는 '기존 자료 사용' 클릭) |
| 검수 완료 | 12/12(토) 12:00 | 운영 매니저 | 파일 열림 및 강좌명 확인 후 검수 완료 처리 |
| 수정 요청 | 수업 종료 후 2시간 이내 | 강사 | 내용 오류 발견 시 '수정 요청' 접수 (필수) |

## 5. 확인 요청

강사와 운영 매니저는 **12/10(목) 17:00까지** '배움결' 공지에서 **규정 확인 버튼**을 반드시 클릭해 주시기 바랍니다.

궁금한 사항은 교육지원 서이담 또는 메신저 '자료운영문의'로 문의해 주세요.
