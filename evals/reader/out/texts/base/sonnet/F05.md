**제목: [전사 공지] 11월 공용 장비 자산 실사 안내 (11/24 17:00까지 '별장부' 확인 필수)**

별고리연구원 연구직·행정직 전 직원 여러분께,

장비 관리대장과 실제 보관 위치가 일치하지 않는 문제를 해소하기 위해 11월에 공용 장비 자산 실사를 진행합니다. 모든 직원은 아래 내용을 확인하시고 기한 내에 참여해 주시기 바랍니다.

## 1. 실사 대상
- **대상:** 회사 자산번호가 붙은 노트북, 태블릿, 측정기
- **제외:** 개인 소유 장비, 자산번호가 없는 소모품

## 2. 전 직원 필수 사항 (기한: 11/24(화) 17:00)
가상 자산 시스템 **'별장부'**에서 본인에게 배정된 장비 목록을 확인하고 **'확인 완료'** 처리를 해 주세요.
- **배정된 장비가 없는 경우에도** 같은 기한까지 **'배정 없음'** 처리를 해야 합니다. 별도 이메일 보고는 필요하지 않습니다.

## 3. 장비 보유자 입력 사항
배정된 각 장비마다 아래 항목을 별장부에 입력해 주세요.
- 자산번호
- 현재 위치
- 자산번호가 보이는 사진 1장 첨부

## 4. 장비 상태별 처리 방법

| 상태 | 처리 방법 |
|---|---|
| **정상 작동** | 별장부 온라인 확인만 하면 됩니다. 실사실로 직접 가져올 필요는 없습니다. |
| **고장** | 온라인 확인과 별도로 **11/25(수) 10:00~16:00**에 **연구동 1층 실사실**로 반납해야 합니다. |
| **외부 수리업체에 맡긴 장비** | 직접 반납은 면제됩니다. **11/24(화) 17:00까지** 별장부에 **수리 접수증**을 첨부해 주세요. 자산번호 사진은 접수증으로 대체할 수 있습니다. |

## 5. 팀장 추가 확인
한 직원에게 배정된 장비가 **3대 이상**이면 팀장의 추가 확인이 필요합니다. 해당 팀원이 있는 팀장은 **11/26(목) 12:00까지** 별장부에서 승인해 주세요.

## 6. 미등록 장비 발견 시
실사 중 관리대장에 없는 장비를 새로 발견하면 **자산번호 유무와 관계없이 반드시 자산팀에 신고**해 주세요. 직원이 임의로 폐기하거나 다른 사람에게 이전해서는 안 됩니다.

## 7. 온라인 입력 설명회 (선택 참여)
- **일시:** 11/20(금) 15:00~15:30
- **장소:** 사내 화상회의방 '별교실'
- 참여는 선택이며, **불참하더라도 실사 의무는 동일하게 유지**됩니다.
