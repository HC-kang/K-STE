# 전자책 재검수 회의록

**물결서가 콘텐츠운영팀**

| 항목 | 내용 |
|---|---|
| 일시 | 2026년 11월 9일(월) 14:00~14:40 |
| 장소 | 본사 편집회의실 |
| 안건 | 전자책 재검수 분담 확정 |

## 1. 재검수 배경
변환 도구 변경 후 일부 전자책에서 각주 연결 누락이 발생하여 재검수를 진행합니다.

## 2. 재검수 대상
- **대상:** 11/02(월) 변환한 전자책 18종
- **목록 확인:** '책마루' 시스템의 재검수 게시판에 게시
- **제외:** 11/02(월) 변환분 중 종이책용 PDF 4종은 이번 재검수에서 제외하며, 결과 등록도 필요하지 않습니다.

## 3. 담당자별 검수 업무 (필수)

| 담당자 | 검수 내용 | 결과 등록 기한 |
|---|---|---|
| 백여울 | 대상 18종 전체의 각주 연결 전수 확인 | 11/11(수) 17:00까지 책마루에 등록 |
| 진도겸 | 대상 중 표 포함 도서 6종의 표 잘림 확인 | 11/12(목) 12:00까지 책마루에 등록 |

## 4. 검수 결과에 따른 처리 기준
- **각주 연결 누락이 1건 이상인 도서:** 검수자가 즉시 배포 보류로 표시합니다. 수정본의 재검수가 완료되기 전에는 배포할 수 없습니다.
- **각주·표 검수를 모두 통과한 도서:** 서이든 편집책임자의 승인 후 조기 배포가 가능합니다. 조기 배포는 선택 사항입니다.

## 5. 공동 검수 시간
- **일시:** 11/10(화) 10:00~11:00
- **장소:** 본사 디지털작업실
- **참석:** 검수자 선택 참석

## 6. 최종 확인
- **서이든 편집책임자:** 11/13(금) 15:00까지 배포 보류 목록을 최종 확인해야 합니다. (필수)

## 7. 문의처
책마루 접속 및 검수 기준 문의: 노해솔 콘텐츠지원 담당(내선 582)
