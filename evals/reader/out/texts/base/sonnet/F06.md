누비온물류 동부센터 출고 담당자, 현장 반장 여러분께 공유드립니다.

**■ 장애 현황**
- 발생 시각: 11/12(목) 09:10부터
- 대상: 동부센터 2층 포장구역 송장 출력 시스템 '택핀'
- 원인: 송장 서버 인증서 갱신 누락
- 운송사 배송조회 기능은 정상입니다.
- 복구 담당: IT운영팀 서도윤
- 복구 목표: 11/12(목) 11:30 (실제 복구 여부는 #동부센터-장애 채널에 별도 공지)

**■ 출고 담당자 유의사항**
1. 장애 발생 이후 택핀 **재출력 버튼 사용 금지**
2. 복구 공지 전까지 **동일 주문 재접수 금지**
3. **긴급 주문** (오늘 12:00 출발 차량 적재분)만 수기 송장 사용 가능
4. **일반 주문**은 포장 완료 후 2층 **보류 선반**에 보관
5. 장애 전 출력 완료되어 바코드가 정상 인식되는 송장은 그대로 사용 가능하며, 해당 주문은 공유문서에 입력하지 않아도 됩니다.

**■ 수기 송장 사용 방법**
- 수령: 현장 반장 강하린에게 받기
- 지급 수량: 출고 담당자 1명당 최초 15장 (추가분은 강하린 승인 필요)
- 기록: 공유문서 '11월 수기출고'에 주문번호·송장번호·사용 장수를 **11/12(목) 10:50까지 반드시 입력**
- 부착: 긴급 주문 수기 송장 부착은 **11/12(목) 11:10까지 완료**
- 차량 출발 시각 **12:00은 변경 없습니다.**

**■ 현장 반장 요청사항**
- 보류 선반 주문 건수를 **11/12(목) 11:00까지** #동부센터-장애 채널에 보고
