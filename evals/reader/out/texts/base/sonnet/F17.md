# 냉장 원료 입고 보류 런북 (묶음 4)

**서리온푸드 동부 물류센터 | 차량 온도계 교정 누락에 따른 지정 차량 추가 검수**

## 1. 목적
일부 차량의 온도계 교정 누락이 발견되어, 지정 차량에 대해 냉장 원료의 중심 온도를 추가로 측정하고 기준 이탈 시 보류 처리하기 위한 절차입니다.

## 2. 적용 범위
| 항목 | 내용 |
|---|---|
| 기간 | 11/16(월) ~ 11/18(수) |
| 장소 | 동부 물류센터 2번 도크 |
| 대상 차량 | 차량 번호 끝자리 **62번, 84번** |
| 대상 외 차량 | 기존 검수 유지. 추가 3상자 측정과 추가 보류 등록은 불필요 |

## 3. 역할
| 담당 | 이름 | 책임 |
|---|---|---|
| 입고 검수자 | 한지오 | 온도 측정, 기록, 보류 판정 및 등록 |
| 품질 당직 | 정다빈 | 보류 원료의 사용 가능 여부 결정 (승인/반송) |
| 창고 반장 | 유태건 | Q구역 보관 위치 배정 |

## 4. 시간 기준 (차량 도착 시각 기준)
| 시점 | 필수 조치 |
|---|---|
| 도착 후 15분 이내 | 원료 상자 3개 중심 온도 측정 완료 |
| 도착 후 30분 이내 | 보류 대상이면 찬고에 보류 등록 완료 |
| 보류 등록 후 60분 이내 | 정다빈이 찬고에 승인 또는 반송 결정 기록 |

## 5. 절차

### 5.1 대상 확인
1. 2번 도크 도착 차량의 번호 끝자리가 62 또는 84인지 확인합니다.
2. 해당하지 않으면 기존 검수만 진행하고 이 런북은 종료합니다.
3. 해당하면 도착 시각을 기록하고 5.2로 진행합니다.

### 5.2 온도 측정 (한지오)
1. 도착 후 **15분 이내**에 원료 상자 **3개**의 중심 온도를 측정합니다.
2. **세 측정값을 모두** 기록합니다.

### 5.3 판정
| 조건 | 판정 |
|---|---|
| 세 값 모두 0.0℃ 이상 5.0℃ 이하이고 상자 봉인 이상 없음 | **정상 입고** |
| 한 값이라도 0.0℃ 미만 또는 5.0℃ 초과 | 해당 차량 원료 **전량 보류** |
| 온도는 범위 안이지만 상자 봉인 훼손 발견 | 해당 차량 원료 **전량 보류** |

- 봉인 훼손으로 인한 보류는 **재측정만으로 해제할 수 없습니다.**

### 5.4 보류 처리 (보류 판정 시)
1. 보류 원료를 **냉장고 Q구역**으로 이동합니다. 보관 위치는 유태건이 배정합니다.
2. 보류 원료에 **노란 보류표**를 부착합니다. (필수)
3. 도착 후 **30분 이내**에 재고 시스템 **‘찬고’**에 보류를 등록합니다. 현장 사진 첨부는 선택입니다.
4. 정다빈의 승인 전에는 **생산 출고를 금지**합니다.

### 5.5 사용 가능 여부 결정 (정다빈)
1. 보류 등록 후 **60분 이내**에 찬고에 **승인 또는 반송** 결정을 기록합니다.
2. 승인 기록 전까지 보류 원료는 Q구역에서 유지합니다.

## 6. 체크리스트 (대상 차량 1대당)
- [ ] 차량 번호 끝자리 62/84 확인, 도착 시각 기록
- [ ] 15분 이내 상자 3개 중심 온도 측정, 세 값 모두 기록
- [ ] 세 값 모두 0.0~5.0℃ 여부 확인
- [ ] 상자 봉인 훼손 여부 확인
- [ ] (보류 시) Q구역 이동 및 노란 보류표 부착
- [ ] (보류 시) 30분 이내 찬고 등록
- [ ] (보류 시) 정다빈의 승인/반송 기록 확인 (등록 후 60분 이내)
- [ ] 승인 전 생산 출고 없음 확인
