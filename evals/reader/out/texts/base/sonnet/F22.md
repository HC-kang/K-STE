# PR #631: 출고 라벨 재인쇄 시 이전 라벨 자동 무효화

## 배경 및 원인
출고 라벨을 재인쇄한 뒤에도 이전 라벨이 계속 스캔되어, 한 상자가 두 번 출고 처리되는 문제가 있었습니다. 이 PR은 재인쇄 시 이전 라벨을 자동으로 무효화해 중복 출고를 막습니다.

## 변경 내용
- **적용 조건:** 동일 주문의 **동일 상자** 라벨을 재인쇄하는 경우 이전 라벨을 자동 무효화합니다.
- **적용 제외:** 주문이 같아도 **상자가 다르면** 기존 라벨을 유지합니다.
