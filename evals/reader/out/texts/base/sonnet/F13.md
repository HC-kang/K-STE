# 반납 장비 입고 절차 확정 회의록

**다온빛렌탈 서부물류센터**

| 항목 | 내용 |
|---|---|
| 일시 | 2026년 11월 16일(월) 08:30~09:00 |
| 장소 | 서부물류센터 교육실 |
| 안건 | 반납 장비 입고 절차 확정 |
| 대상 | 회수기사, 입고담당자 |

## 1. 변경 배경
반납 장비와 출고 장비의 동선이 겹쳐 상차가 지연되었습니다. 이를 해소하기 위해 반납 장비 입고 절차를 아래와 같이 변경합니다.

## 2. 적용 범위
- **적용 시작일:** 11월 18일(수)
- **대상:** 서부물류센터로 반납하는 이동형 냉풍기
- **제외:** 동부물류센터 반납분

## 3. 확정 절차

### 3-1. 사전 등록 (회수기사)
- 방문 전날 16:00까지 '돌아온' 시스템에 **차량번호와 반납 수량**을 등록해야 합니다.

### 3-2. 예약 반납 기준
| 구분 | 기준 |
|---|---|
| 반납 시간 | 10:00~12:00 |
| 차량당 수량 | 냉풍기 최대 8대 |
| 기본 하역 장소 | 서부물류센터 3번 도크 |

- 반납 수량이 8대를 초과하면 회수기사가 차량을 나누어 **각각 예약**해야 합니다.
- 한 차량에 초과분을 적재해 반납할 수 없습니다.

### 3-3. 누수 흔적이 있는 장비
- 회수기사는 하역 전에 입고담당 **서나겸**에게 연락해야 합니다.
- 해당 장비는 3번 도크가 아닌 **격리구역 Q**에서 하역해야 합니다.

### 3-4. 당일 긴급 반납
- 배차책임자 **고시온**의 사전 승인을 받은 경우에만 사전 시스템 등록 없이 반납할 수 있습니다.
- 차량당 수량 제한(최대 8대)은 동일하게 적용됩니다.

### 3-5. 입고 후 사진 등록 (입고담당)
- 입고담당 **서나겸**은 장비별 외관 사진 2장을 촬영해 시스템에 첨부해야 합니다.
- **반납 당일 17:00까지** 완료해야 합니다.

## 4. 절차 시연
| 항목 | 내용 |
|---|---|
| 일시 | 11월 17일(화) 15:00~15:30 |
| 장소 | 3번 도크 |
| 회수기사 | 참석 선택 |
| 입고담당 | 참석 필수 |

## 5. 문의처
- 예약 변경 및 시스템 오류: 배차지원 **류채운**, 내선 **267**

## 6. 핵심 요약
1. 11/18(수)부터 서부물류센터 반납 이동형 냉풍기에 적용됩니다.
2. 전날 16:00까지 '돌아온'에 차량번호와 수량을 등록합니다.
3. 반납은 10:00~12:00, 차량당 최대 8대, 3번 도크에서 합니다.
4. 누수 장비는 서나겸에게 사전 연락 후 격리구역 Q에서 하역합니다.
5. 긴급 반납은 고시온의 사전 승인이 필요합니다.
6. 장비별 사진 2장을 반납 당일 17:00까지 등록합니다.
