# 다온결제넷 정산 파일 재전송 런북

## 1. 개요

| 항목 | 내용 |
|---|---|
| 배경 | 묶음 4 / 다온결제넷 전송 게이트웨이 교체로 정산 파일 수신 확인 지연 예상 |
| 적용 작업일 | 11/12(목) |
| 대상 파일 | 11/11(수) 매출 정산 파일 |
| 작업 위치 | 사내 운영 콘솔 ‘결빛’ > 정산 > 전송 이력 |
| 실행자 | 야간 정산 운영자 민서준 |
| 완료 확인자 | 당직 책임자 배유림 |

## 2. 문의처

| 문의 유형 | 담당 | 내선 |
|---|---|---|
| 수신 상태 조회 오류 | 플랫폼 당직 오하린 | 4312 |
| 정산 대상 판단 | 당직 책임자 배유림 | 4318 |

## 3. 일정 요약

| 시각 | 작업 | 담당 |
|---|---|---|
| 01:10 | 수신 상태 조회 (필수) | 민서준 |
| 01:20 | 10분 연속 ‘미수신’ 파일 재전송 시작 | 민서준 |
| 재전송 후 5분 | 여전히 미수신이면 2차 재전송 | 민서준 |
| 01:50까지 | 결과 및 실패 파일 목록 작업일지 기록 | 민서준 |
| 02:00까지 | 작업일지 확인 및 완료 표시 | 배유림 |

## 4. 절차

### 4.1 수신 상태 조회 (01:10, 필수)
1. ‘결빛’ > 정산 > 전송 이력에서 11/11(수) 매출 정산 파일 목록을 조회한다.
2. 파일별 수신 상태를 확인하고 기록한다.
3. 조회 중 오류가 발생하면 플랫폼 당직 오하린(내선 4312)에게 문의한다.

### 4.2 상태별 처리 기준

| 수신 상태 | 처리 |
|---|---|
| 수신 완료 | 재전송 불필요. 단순 조회만 허용 |
| 처리 중 | 재전송하지 않고 배유림에게 확인 요청 |
| 미수신 | 4.3 절차에 따라 재전송 대상 여부 판단 |

### 4.3 재전송 대상 판단
- ‘미수신’ 상태가 **10분 연속** 유지된 파일만 대상이다.
- 재전송은 **01:20부터** 가능하다.
- 10분 미만이거나 중간에 상태가 바뀐 파일은 대상이 아니다. 대상 여부가 불분명하면 배유림(내선 4318)에게 문의한다.

### 4.4 해시 확인 (재전송 전 필수)
1. 원본 파일 해시와 보관본 해시를 비교한다.
2. **일치**: 재전송 진행.
3. **불일치**: 재전송 금지, 즉시 배유림에게 보고한다.

### 4.5 재전송 (파일당 최대 2회)
1. **1차 재전송**: 해시가 일치한 대상 파일을 재전송한다.
2. 1차 재전송 후 5분이 지나 수신 상태를 확인한다.
   - 수신 완료: 종료
   - 처리 중: 재전송하지 않고 배유림에게 확인 요청
   - 미수신: 2차 재전송 진행
3. **2차 재전송**: 1차 재전송 후 5분 뒤 실행한다.
4. 2차 재전송 후에도 실패하면 **추가 전송을 금지**하고 실패 파일로 기록한다.

## 5. 작업일지 기록 (01:50까지)
‘결빛’ 작업일지에 다음을 기록한다.
- 파일별 재전송 결과 (재전송 횟수, 최종 상태)
- 실패 파일 목록
- 실패 파일이 없어도 반드시 **‘실패 0건’** 으로 기록한다.
- 해시 불일치로 보고한 파일, ‘처리 중’으로 확인 요청한 파일이 있으면 함께 기록한다.

## 6. 완료 확인 (02:00까지, 배유림)
- 작업일지를 확인한 뒤 다음 중 하나로 표시한다.
  - 미해결 파일 없음: **완료**
  - 미해결 파일 있음: **후속 조치 필요** (완료 표시 금지)

## 7. 체크리스트

- [ ] 01:10 수신 상태 조회 완료
- [ ] ‘수신 완료’ 파일은 재전송 제외
- [ ] ‘처리 중’ 파일은 배유림에게 확인 요청
- [ ] ‘미수신’ 10분 연속 유지 확인
- [ ] 01:20 이후 재전송 시작
- [ ] 재전송 전 원본/보관본 해시 일치 확인
- [ ] 해시 불일치 시 재전송 금지 및 배유림 보고
- [ ] 파일당 재전송 2회 초과 없음
- [ ] 01:50까지 작업일지 기록 (실패 0건 포함)
- [ ] 02:00까지 배유림 완료 또는 ‘후속 조치 필요’ 표시

## 8. 금지 사항 요약
- 해시 불일치 파일 재전송
- ‘수신 완료’ 파일 재전송
- ‘처리 중’ 파일 재전송
- 파일당 3회 이상 전송
- 10분 연속 미수신이 확인되지 않은 파일의 01:20 이전 재전송
