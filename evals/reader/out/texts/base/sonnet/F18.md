# 모래별스튜디오 온라인 공연 예비 회선 전환 런북

**묶음 4 / 현장용**

## 1. 개요
- **사유:** 주 회선 장비 점검으로 공연 중 송출 끊김 가능성이 있어 예비 회선을 준비한다.
- **적용 공연:** 11/27(금) 19:30~21:00
- **작업 장소:** 본사 3층 송출실, 콘솔 **'별송'**

## 2. 역할
| 역할 | 담당 | 임무 |
|---|---|---|
| 송출 기사 (주 담당) | 윤태림 | 예비 회선 연결 시험, 회선 전환 실행, 대기 화면 송출, 기록 제출 |
| 음향 기사 | 서가온 | 전환 후 음성 확인 및 기록 |
| 현장 책임자 | 문해솔 | 공연 송출 중단 여부 결정 |

**문의:** 회선 – 문해솔 내선 **6134** / 음성 – 서가온 내선 **6139**

## 3. 타임라인
| 시각 | 내용 |
|---|---|
| ~19:00 | 윤태림: 예비 회선 연결 시험 완료 |
| 19:30~21:00 | 공연, 주 회선 손실률 감시 |
| 21:20까지 | 윤태림: 전환 시각·손실률 기록 제출 |

## 4. 공연 전 준비 (19:00까지)
1. 윤태림이 예비 회선 연결 시험을 완료한다.
2. 시험 영상은 **내부 미리보기로만** 확인한다. **시청자 채널 송출 금지.**
3. **주 회선 자동 복귀 기능을 비활성화**한다. 공연 내내 유지해야 한다.

## 5. 공연 중 전환 기준 (주 회선)
| 상태 | 조치 |
|---|---|
| 손실률 **3% 이상이 20초 연속** 유지 | **예비 회선 전환 필수.** 문해솔의 별도 승인 불필요 |
| 손실률 3% 미만 | 전환 불필요 (내부 미리보기 확인은 허용) |
| 3% 이상이지만 지속 20초 미만 | 전환 불필요 (내부 미리보기 확인은 허용) |

## 6. 전환 후 절차
1. **윤태림**이 예비 회선으로 전환하고 전환 시각과 손실률을 기록한다.
2. **서가온**이 전환 후 **40초 이내**에 음성을 확인하고 결과를 **별송 작업창에 기록**한다.
3. 음성 이상 시 서가온은 **문해솔에게 즉시 보고**한다.

## 7. 예비 회선도 불량할 때
- 예비 회선에서 손실률 **3% 이상이 20초 연속** 유지되면 윤태림은 **대기 화면을 송출**한다.
- **공연 송출 중단 여부는 문해솔만 결정**한다. 윤태림과 서가온은 임의로 중단하지 않는다.

## 8. 금지 사항
- 주 회선이 정상으로 보여도 **공연 종료 전 수동 복귀 금지**
- 자동 복귀 기능 활성화 금지
- 시험 영상의 시청자 채널 송출 금지

## 9. 공연 후 제출
- 윤태림은 **21:20까지** 전환 시각과 손실률 기록을 제출한다.
- 전환이 없었더라도 **'전환 없음'**으로 제출한다.

## 10. 현장 체크리스트
- [ ] 19:00 전 예비 회선 연결 시험 완료
- [ ] 시험 영상 내부 미리보기로만 확인
- [ ] 자동 복귀 비활성화 확인
- [ ] 전환 발생 시 시각·손실률 기록
- [ ] 서가온 음성 확인 40초 이내 기록
- [ ] 21:20까지 기록 또는 '전환 없음' 제출
