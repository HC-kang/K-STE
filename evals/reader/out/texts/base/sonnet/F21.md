# PR #526: 정산 CSV 생성기 중복 행 제거

**회사/묶음:** 모람결제 / 묶음 5-1
**저장소:** 사내 코드 저장소 `moram/settlement` PR #526
**작성자:** 서다빈

## 개요
정산 CSV 생성기에서 같은 거래가 중복 행으로 출력되는 문제를 수정합니다.

## 원인
재시도 요청이 들어올 때마다 동일한 거래 행이 CSV에 추가되고 있었습니다.

## 변경 내용
- 거래 ID와 정산일 조합을 기준으로 중복 여부를 판정하도록 변경했습니다.
- 동일한 조합의 행은 한 번만 출력됩니다.

## 적용 범위
| 구분 | 적용 여부 |
|---|---|
| 국내 원화 정산 CSV | 적용 |
| 해외 통화 CSV | 변경 제외 |
| 화면 조회 API | 변경 제외 |

## 리뷰어 및 승인
| 역할 | 담당 | 비고 |
|---|---|---|
| 작성자 | 서다빈 | 병합 담당 |
| 필수 승인자 (정산 플랫폼 리뷰어) | 고유찬 | 승인 필수 |
| 보안 담당 | 나세림 | 참조만, 승인 불필요 |

## 일정
- **검토 시작:** 11/09(월) 10:00
- **고유찬 승인 마감:** 11/11(수) 16:00
- **병합 예정:** 11/12(목) 09:00 (서다빈)

## 검토 요청 사항 (고유찬)
**필수**
1. 중복 거래를 포함한 **2,000행 샘플**을 실행합니다.
2. 생성 결과가 **1,960행**인지 확인합니다.
3. **실행 로그를 이 PR에 첨부**합니다.

**성능 기준**
- 샘플 생성 시간 **8초 이하**여야 합니다.
- 8초를 초과하면 **승인을 보류**하고 **서다빈에게 수정을 요청**해야 합니다.

**선택 / 불필요**
- 전체 거래 재생 테스트: 선택 사항입니다.
- 해외 통화 샘플 실행: 하지 않아도 됩니다.
