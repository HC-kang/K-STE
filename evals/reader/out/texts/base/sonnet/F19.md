# 중복 교환 주문 처리 런북 (누리담렌탈 고객센터)

**대상:** 교환 접수 상담사
**시스템:** 주문 시스템 ‘담주문’
**적용 기간:** 12/03(목) 09:00 ~ 12/04(금) 18:00

## 1. 배경
고객 앱 재시도 오류로 동일 제품의 교환 주문이 중복 생성되고 있습니다. 아래 절차에 따라 중복 주문을 확인하고 처리합니다.

## 2. 중복 검토 대상 판단

다음 **세 가지가 모두 동일**하고, **30분 이내**에 교환 주문이 **2건 이상** 생성되었으면 중복 검토 대상입니다.

| 확인 항목 | 기준 |
|---|---|
| 계약번호 | 동일 |
| 제품번호 | 동일 |
| 회수 주소 | 동일 |
| 생성 시간 | 30분 이내 |

- 세 정보 중 **하나라도 다르면** 중복 검토 대상이 아니며 **일반 접수를 유지**합니다.
- 30분을 **초과**해 생성된 주문은 이번 절차 적용 불가입니다. 임의로 취소하지 말고 **일반 접수를 유지**합니다.

## 3. 처리 절차

**기한: 검토 대상 발견 후 20분 이내 처리 또는 이관 완료**

1. **출고 상태 확인:** 검토 대상 주문 전체의 출고 상태를 먼저 확인합니다.
2. 확인 결과에 따라 분기합니다.

### A. 전부 ‘출고 전’인 경우 (상담사 직접 처리)
1. **최초 생성 주문 1건을 유지**합니다.
2. 나머지 주문은 **모두 취소**합니다. (취소 필수)
3. 취소 사유 코드는 **D14(중복 취소)** 를 사용합니다.
4. 주문 메모에 **유지 주문번호**를 기록합니다.
5. 처리 후 고객에게 **안내 문자를 발송**합니다.

### B. ‘출고 완료’ 주문이 1건이라도 있는 경우 (물류 이관)
1. **상담사는 취소하지 않습니다.** (취소 금지)
2. **물류 담당 고도윤**에게 이관합니다. (이관 필수)
3. 주문 메모에 **물류 이관번호**를 기록합니다.
4. 이관 후 고객에게 **안내 문자를 발송**합니다.

## 4. 고객 안내
- 취소 전에 고객에게 전화할 필요는 **없습니다**.
- 처리 후 **안내 문자 발송은 필수**입니다.
- 고객이 요청하면 **취소 내역 이메일을 추가로 발송**할 수 있습니다.
- 이메일 발송 여부와 관계없이 **안내 문자는 반드시 발송**합니다.

## 5. 입력 규칙

| 항목 | 규칙 |
|---|---|
| 중복 취소 사유 코드 | **D14** |
| 고객 변심 취소 코드 | **D41 사용 금지** |
| 주문 메모 | 유지 주문번호 또는 물류 이관번호 기록 |
