# PR #853: 임시 좌석 점유 자동 해제 작업 추가

## 개요
- **회사/묶음**: 해솔예약 / 묶음 5-4
- **내용**: 결제 없이 닫힌 예약 화면에 남은 임시 좌석 점유를 자동으로 해제하는 작업을 추가합니다.
- **원인**: 결제 없이 닫힌 예약 화면의 좌석 점유가 남아 판매 가능 좌석 수가 줄어듭니다.

## 변경 동작
- **해제 대상**: 생성 후 15분 이상 지난 미결제 임시 점유
- **제외 대상**: 결제 완료 좌석, 상담원 수동 잠금 좌석
- **실행 간격**: 5분
- **적용 범위**: 국내 공연 영역만 해당합니다. 이번 PR은 해외 공연 영역에 적용하지 않습니다.
