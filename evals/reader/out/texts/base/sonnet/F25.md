# PR #964: 센서 연결 끊김 이메일 알림 재발송 간격 변경

**회사:** 다온센서 | **묶음:** 5-5 | **저장소:** daon/alerts

## 변경 배경
짧은 통신 끊김이 반복되면 같은 설비에 대한 알림이 쌓여 고객지원 문의가 늘고 있습니다. 이를 줄이기 위해 재발송 간격을 변경합니다.

## 변경 내용
같은 센서의 연결 끊김이 계속되는 경우:
- 최초 이메일은 즉시 발송합니다.
- 이후에는 20분 간격으로 재발송합니다.
- 연결 복구 이메일은 대기 없이 즉시 발송합니다.

## 적용 대상 및 제외
| 구분 | 적용 여부 |
|---|---|
| 표준 요금제 이메일 연결 끊김 알림 | **적용** |
| 기업 요금제 | 제외 (기존 동작 유지) |
| 문자 알림 | 제외 (기존 동작 유지) |
