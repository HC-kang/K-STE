# [공지] 11월 공용 장비 자산 실사 안내

**대상:** 별고리연구원 연구직·행정직 전 직원
**발신:** [부서명]
**발신일:** [발신일]

## 1. 실사 목적

장비 관리대장과 실제 보관 위치가 일치하지 않는 문제를 해결하기 위해 11월 공용 장비 자산 실사를 진행합니다. 전 직원은 아래 기한과 절차에 따라 빠짐없이 참여해 주시기 바랍니다.

## 2. 실사 대상

- **포함:** 회사 자산번호가 부착된 노트북, 태블릿, 측정기
- **제외:** 개인 소유 장비, 자산번호가 없는 소모품

## 3. 주요 일정

| 일시 | 내용 |
|---|---|
| 11/20(금) 15:00~15:30 | 온라인 입력 설명회 (참여 선택) |
| 11/24(화) 17:00까지 | 배정 장비 확인 및 '확인 완료' 처리 (전 직원 필수) |
| 11/24(화) 17:00까지 | 외부 수리 장비 수리 접수증 첨부 (해당자) |
| 11/25(수) 10:00~16:00 | 고장 장비 반납 (해당자) |
| 11/26(목) 12:00까지 | 팀장 승인 (배정 장비 3대 이상인 직원) |

## 4. 직원별 해야 할 일

### 가. 전 직원 (배정 장비 유무 무관)

- 가상 자산 시스템 **'별장부'**에서 본인에게 배정된 장비 목록을 확인하고 **11/24(화) 17:00까지 '확인 완료'**를 처리해 주십시오.
- **배정된 장비가 없는 경우에도** 같은 기한까지 **'배정 없음'**으로 처리해 주십시오.
- 별도의 이메일 보고는 필요하지 않습니다.

### 나. 장비 보유자

1. **정상 작동 장비**
   - 별장부에서 온라인 확인만 하면 됩니다.
   - 실사실로 직접 가져오실 필요가 없습니다.
   - 각 장비의 **자산번호와 현재 위치**를 입력하고, **자산번호가 보이는 사진 1장**을 첨부해 주십시오.

2. **고장 장비**
   - 별장부에서 온라인 확인을 완료하셔야 합니다.
   - 그와 별도로 **11/25(수) 10:00~16:00에 연구동 1층 실사실로 반납**해 주십시오.
   - 반납 시간 조정이 필요하면 시설팀에 문의해 주십시오.

3. **외부 수리업체에 맡긴 장비**
   - 직접 반납은 면제됩니다.
   - **11/24(화) 17:00까지 별장부에 수리 접수증을 첨부**해 주십시오.
   - 자산번호 사진은 수리 접수증으로 대체할 수 있습니다.

### 다. 팀장

- 한 직원에게 배정된 장비가 **3대 이상**인 경우 해당 직원의 장비 목록을 추가로 확인해야 합니다.
- **11/26(목) 12:00까지 별장부에서 승인**을 완료해 주십시오.

## 5. 실사 중 미등록 장비 발견 시

- 자산번호 유무와 관계없이 **자산팀에 신고**해 주십시오.
- 임의로 폐기하거나 다른 사람에게 이전하지 마십시오.

## 6. 온라인 입력 설명회

- **일시:** 11/20(금) 15:00~15:30
- **장소:** 사내 화상회의방 **'별교실'**
- 참여는 선택 사항입니다. 다만 불참하시더라도 실사 의무는 그대로 유지됩니다.

- **고장 장비 반납 시간 조정 관련:** 시설팀 차유건 (내선 297)
