# PR #742: 웹 강의 플레이어 키보드 자막 설정 기능 추가

**묶음:** 5-3 | **회사:** 새온학습 | **저장소:** saeon/player

## 1. 배경과 원인

기존 자막 설정 창은 마우스로만 열 수 있었습니다. 키보드만 사용하는 학습자는 자막 설정을 바꿀 수 없었습니다. 이 PR은 키보드로 자막 설정 창을 열고 조작할 수 있게 합니다.

## 2. 변경 내용

- 키보드로 자막 설정 창을 여는 기능을 추가했습니다.
- **단축키 C**: 플레이어에 초점이 있을 때만 자막 설정 창을 엽니다.
- **검색 입력란에 초점이 있을 때**: 단축키가 동작하지 않고, 문자 `c`가 그대로 입력됩니다.

## 3. 적용 범위

- **포함:** 녹화 강의 웹 플레이어
- **제외:** 실시간 강의, 모바일 앱 플레이어

## 4. 검토 요청 사항

검토 위치는 saeon/player의 PR #742에 연결된 `preview-caption`입니다.

### 필수 검증

- **키보드 이동 검증:** 한국어 강의 4개와 영어 강의 2개, 총 6개 강의에서 수행합니다. 결과는 PR 댓글에 기록합니다.
- **화면낭독기 검증:** 설정 창의 읽기 동작을 확인합니다.
- **설정 창 배율 200%:** 검증 시 이 배율을 사용합니다.
- **초점 표시:** 초점 표시가 한 번이라도 사라지면 **승인을 보류**합니다.

### 선택 항목 및 불필요 항목

- **마우스 이동 경로 녹화:** 선택 사항입니다.
- **모바일 앱 화면 캡처:** 불필요합니다. 모바일 앱은 이번 적용 범위에서 제외되었습니다.
