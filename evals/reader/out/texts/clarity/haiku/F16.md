# 정산 파일 재전송 런북: 다온결제넷 야간 정산

| 항목 | 내용 |
|---|---|
| 대상 | 다온결제넷 11/11(수) 매출 정산 파일 |
| 배경 | 묶음 4, 전송 게이트웨이 교체로 정산 파일 수신 확인 지연 예상 |
| 적용 작업일 | 2026-11-12(목) 야간 |
| 실행자 | 야간 정산 운영자 민서준 |
| 완료 확인자 | 당직 책임자 배유림 |
| 작업 위치 | 사내 운영 콘솔 '결빛' > 정산 > 전송 이력 |

---

## 1. 작업 원칙

- 재전송은 **'미수신' 상태가 10분 연속 유지된 파일만** 대상으로 한다.
- 파일당 재전송은 **최대 2회**다. 두 번째 실패 후에는 추가 전송하지 않는다.
- '수신 완료' 파일은 재전송하지 않는다. 단순 조회만 허용한다.
- '처리 중' 파일은 재전송하지 않고 배유림에게 확인을 요청한다.
- 해시가 일치하지 않으면 재전송하지 않고 배유림에게 보고한다.

---

## 2. 시간표

| 시각 | 작업 | 담당 |
|---|---|---|
| 01:10 | 전체 파일 수신 상태 조회 (필수) | 민서준 |
| 01:10~01:20 | 미수신 10분 연속 여부 확인, 해시 대조 | 민서준 |
| 01:20 | 1차 재전송 대상 파일 재전송 | 민서준 |
| 1차 재전송 후 5분 | 수신 상태 재확인, 미수신이면 2차 재전송 | 민서준 |
| 01:50 | 재전송 결과와 실패 파일 목록을 작업일지에 기록 | 민서준 |
| 02:00 | 작업일지 확인 후 완료 또는 '후속 조치 필요' 표시 | 배유림 |

---

## 3. 절차

### 3.1 수신 상태 조회 (01:10)

1. 결빛 > 정산 > 전송 이력에서 11/11(수) 매출 정산 파일 목록을 연다.
2. 각 파일의 수신 상태를 확인하고 아래 표에 따라 분류한다.

| 상태 | 처리 |
|---|---|
| 수신 완료 | 재전송 불필요. 조회만 하고 기록한다. |
| 처리 중 | 재전송하지 않는다. 배유림에게 확인을 요청한다. |
| 미수신 (10분 연속 유지) | 재전송 대상이다. 3.2 해시 확인을 거친다. |
| 미수신 (10분 미만) | 재전송하지 않는다. 다음 조회 시점에 다시 확인한다. |

### 3.2 해시 확인 (재전송 전 필수)

1. 재전송 대상 파일마다 **원본 파일 해시**와 **보관본 해시**를 확인한다.
2. 두 값이 **일치하면** 재전송을 진행한다.
3. 두 값이 **불일치하면** 해당 파일은 재전송하지 않는다. 배유림에게 즉시 보고하고 실패 목록에 '해시 불일치'로 기록한다.

### 3.3 재전송 (01:20 이후)

1. 해시가 일치한 미수신 파일만 1차 재전송한다. (01:20 이후)
2. 재전송 후 5분 뒤 수신 상태를 다시 조회한다.
3. 여전히 미수신이면 **2차 재전송**한다.
4. 2차 재전송 후에도 미수신이면 **실패**로 기록한다. 이후 추가 전송은 하지 않는다.
5. 1차 재전송 후 수신 완료가 되면 재전송을 종료한다.

### 3.4 작업일지 기록 (01:50까지)

결빛 작업일지에 다음을 기록한다.

- 조회 시각, 파일별 수신 상태
- 파일별 재전송 횟수 (0회, 1회, 2회)
- 해시 확인 결과 (일치 / 불일치)
- 실패 파일 목록 (파일명, 실패 사유)
- **실패 파일이 없으면 '실패 0건'을 반드시 기록한다.**

### 3.5 완료 확인 (02:00까지, 배유림)

- 미해결 파일이 없으면 **완료** 표시를 한다.
- 미해결 파일이 있으면 완료 대신 **'후속 조치 필요'** 표시를 한다.

---

## 4. 중단 및 보고 조건

| 상황 | 조치 | 보고 대상 |
|---|---|---|
| 해시 불일치 | 재전송 금지, 해당 파일 제외 | 배유림 |
| '처리 중' 파일 | 재전송 금지 | 배유림 |
| 2회 재전송 후에도 미수신 | 추가 전송 금지, 실패 기록 | 배유림 (작업일지 실패 목록) |
| 수신 상태 조회 오류 | 조회 오류 내용 기록 | 오하린 (플랫폼 당직, 내선 4312) |
| 정산 대상 판단이 필요한 파일 | 판단하지 않고 보류 | 배유림 (내선 4318) |

## 6. 확인이 필요한 사항

메모에 없어서 작업 전에 배유림과 정해 두어야 하는 항목이다.

1. **'10분 연속 유지' 판정 방법**: 01:10 조회 한 번으로 판정하는지, 01:00 등 이전 시점 기록과 비교하는지 정해야 한다.
2. **2차 재전송 시점**: 1차 재전송 후 "5분 뒤"의 기준 시각(재전송 직후인지, 상태 재조회 시점인지)을 명확히 한다.
3. **재전송 마감 시각**: 2차 재전송이 01:50 기록 마감 전에 끝나는지, 그 이후에 걸리는 경우의 처리를 정한다.
4. **해시 값의 기록 방식**: 해시 값 전체를 작업일지에 남길지, 일치 여부만 남길지 정한다.
