# 모래별스튜디오 온라인 공연 예비 회선 전환 런북

| 항목 | 내용 |
|---|---|
| 묶음 | 4 |
| 대상 | 모래별스튜디오 온라인 공연 송출 |
| 작업 사유 | 주 회선 장비 점검으로 공연 중 송출 끊김 가능성이 있어 예비 회선 준비 |
| 적용 공연 | 2026-11-27(금) 19:30~21:00 |
| 작업 위치 | 본사 3층 송출실, 콘솔 '별송' |

## 1. 역할

| 역할 | 담당자 | 주요 책임 |
|---|---|---|
| 주 담당 송출 기사 | 윤태림 | 회선 전환 실행, 예비 회선 연결 시험, 대기 화면 송출, 기록 제출 |
| 음향 기사 | 서가온 | 전환 후 음성 확인, 확인 결과 기록, 음성 이상 보고 |
| 현장 책임자 | 문해솔 | 공연 중단 여부 결정, 회선 전환 승인(3% 기준 미만 또는 20초 미만 상황 제외), 예비 회선 손실 시 판단 |

## 2. 사전 준비 (19:00까지)

1. 윤태림이 19:00까지 예비 회선 연결 시험을 완료한다.
2. 시험 영상은 **내부 미리보기로만** 확인한다.
3. 시험 영상을 **시청자 채널에 송출하지 않는다.**
4. 주 회선 자동 복귀 기능을 **공연 시작 전에 비활성화**한다. 공연 내내 비활성 상태를 유지한다.

## 3. 공연 중 판단 기준 (주 회선)

주 회선 손실률을 기준으로 다음과 같이 판단한다.

| 조건 | 조치 |
|---|---|
| 손실률 3% 이상이 **20초 연속** 유지 | **예비 회선 전환 필수.** 문해솔의 별도 승인은 필요 없다. |
| 손실률 3% 미만 | 전환 불필요. 내부 미리보기 확인만 허용한다. |
| 손실률 3% 이상이지만 지속 시간이 20초 미만 | 전환 불필요. 내부 미리보기 확인만 허용한다. |

## 4. 전환 절차

1. 윤태림이 별송 콘솔에서 예비 회선 전환을 실행하고, **전환 시각을 기록**한다.
2. 전환 실행 후 **40초 이내**에 서가온이 음성을 확인한다.
3. 서가온이 확인 결과를 **별송 작업창에 기록**한다.
4. 음성에 이상이 있으면 서가온은 **즉시 문해솔에게 보고**한다.

## 5. 예비 회선 사용 중 이상 발생 시

예비 회선에서도 손실률 3% 이상이 20초 연속 유지되면 다음과 같이 조치한다.

1. 윤태림은 **대기 화면을 송출**한다.
2. 공연 송출 중단 여부는 **문해솔만 결정**한다. 윤태림과 서가온은 중단을 독자적으로 결정하지 않는다.

## 6. 자동 복귀 금지

- 주 회선 자동 복귀 기능은 **공연 내내 비활성화**한다.
- 주 회선이 정상으로 보여도 **공연 종료 전 수동 복귀를 하지 않는다.**

## 7. 종료 후 기록 제출

- 윤태림은 **21:20까지** 다음 내용을 제출한다.
  - 전환 시각과 전환 시점의 손실률 기록
  - 전환이 없었던 경우에도 **'전환 없음'**으로 제출
- 서가온의 음성 확인 기록은 별송 작업창에 남아 있어야 한다.

## 8. 연락처

| 문의 유형 | 담당자 | 내선 |
|---|---|---|
| 회선 문의 | 문해솔 | 6134 |
| 음성 문의 | 서가온 | 6139 |

## 확인 필요 사항 (메모에 없음)

현장 혼선을 막기 위해 아래 항목은 작업 전에 담당자와 확정하는 것을 권장한다.

- **손실률 측정 방법과 측정 위치**: 별송 콘솔의 어느 지표를 보는지 명시되어 있지 않다.
- **20초 판단 시작 시점**: 손실률이 3%를 넘은 순간부터 세는지, 확인 후부터 세는지 정해져 있지 않다.
- **19:00 시험 실패 시 대응**: 시험을 완료하지 못했을 때 공연 진행 여부와 담당자 보고 절차가 없다.
- **대기 화면의 준비 주체와 시점**: 대기 화면을 사전에 준비하고 확인하는 절차가 없다.
- **'전환 없음' 제출 대상**: 기록을 누가 최종 확인하고 누구에게 전달하는지 명시되어 있지 않다.
