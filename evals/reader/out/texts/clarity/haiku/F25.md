# [묶음 5-5] 센서 연결 끊김 알림 재발송 간격 변경 (PR #964)

## 요약

짧은 통신 끊김이 반복되면 같은 설비에 대한 연결 끊김 알림이 계속 쌓여 고객지원 문의가 늘고 있습니다. 이 PR은 **표준 요금제의 이메일 연결 끊김 알림**에 한해 재발송 간격을 조정합니다. 기업 요금제와 문자 알림은 이번 변경에서 제외됩니다.

## 변경 내용

같은 센서의 연결 끊김이 계속되는 경우 다음과 같이 동작합니다.

| 상황 | 변경 후 동작 |
|---|---|
| 연결 끊김 최초 발생 | 이메일 즉시 발송 |
| 연결 끊김 지속 | 20분 간격으로 재발송 |
| 연결 복구 | 복구 이메일을 대기 없이 즉시 발송 |

## 적용 대상과 제외 대상

- **적용:** 표준 요금제의 이메일 연결 끊김 알림
- **제외:** 기업 요금제 알림, 문자(SMS) 알림

## 검토자 요청 사항

**1. 대상·제외 동작 검증 (필수)**
배소율 검토자는 아래 데모 센서 5대로 대상과 제외 동작을 모두 확인해 주세요.
- 표준 요금제 센서 3대: 이메일 재발송 간격(20분)과 복구 이메일 즉시 발송 확인
- 기업 요금제 센서 2대: 기존 동작이 바뀌지 않았는지 확인

**2. 이메일 제목 확인 (필수)**
알림 이메일의 제목이 안내 문구와 일치하는지 확인해 주세요.

**3. 본문 화면 캡처 (선택)**
필요하면 이메일 본문 화면 캡처를 첨부해 주세요.

**4. 문자 알림 발송 테스트**
이번 변경 범위가 아니므로 테스트하지 않아도 됩니다.
