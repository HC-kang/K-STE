## 변경 배경

정산 CSV 생성 과정에서 재시도 요청이 들어올 때마다 같은 거래 행이 추가되어, 생성된 CSV에 중복 행이 포함되는 문제가 있습니다.

## 변경 내용

- 중복 판정 기준을 **거래 ID + 정산일 조합**으로 변경하여, 같은 조합의 행은 한 번만 CSV에 기록되도록 했습니다.
- 재시도 요청으로 같은 거래 행이 다시 추가되더라도 최종 CSV에서는 중복되지 않습니다.

## 적용 범위

- **적용:** 국내 원화 정산 CSV
- **변경 제외:** 해외 통화 정산 CSV, 화면 조회 API

위 범위 밖의 기능은 이 PR로 동작이 바뀌지 않습니다.

## 리뷰어 필수 확인 사항

고유찬 리뷰어는 아래 항목을 반드시 수행하고, 결과를 PR에 남겨 주세요.

1. **샘플 실행:** 중복 거래를 포함한 2,000행 샘플을 실행합니다.
2. **결과 행 수 확인:** 생성된 CSV가 **1,960행**인지 확인합니다.
3. **실행 로그 첨부:** 실행 로그를 PR에 첨부합니다.

## 성능 기준

- 샘플 생성 시간은 **8초 이하**여야 합니다.
- **8초를 초과하면** 승인을 보류하고, 작성자(서다빈)에게 수정을 요청해 주세요.
