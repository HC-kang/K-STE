# 누리담렌탈 중복 교환 주문 처리 런북

| 항목 | 내용 |
|---|---|
| 대상 | 고객센터 교환 접수 상담사 |
| 적용 기간 | 2026-12-03(목) 09:00 ~ 12-04(금) 18:00 |
| 사용 시스템 | 주문 시스템 '담주문' |
| 배경 | 고객 앱 재시도 오류로 동일 제품 교환 주문이 중복 생성됨 |
| 점검자 | 상담 리더 조세린 (매일 18:30까지 처리 목록 점검) |

---

## 1. 목적

고객 앱 재시도 오류로 생성된 중복 교환 주문을 정확히 식별하고, 출고 상태에 따라 취소하거나 물류 담당자에게 이관한다. 고객 변심에 따른 정상 교환 주문은 취소하지 않는다.

---

## 2. 중복 검토 대상 판단

### 2-1. 판단 기준

아래 세 정보가 **모두 같은** 교환 주문이 **30분 이내에 2건 이상** 생성되면 중복 검토 대상이다.

- 계약번호
- 제품번호
- 회수 주소

> 세 정보 중 하나라도 다르면 중복 검토 대상이 아니며, 일반 접수로 유지한다.

### 2-2. 판단 예시

| 상황 | 판단 |
|---|---|
| 같은 계약, 같은 제품, 같은 회수 주소, 생성 시각 차이 10분 | 중복 검토 대상 |
| 같은 계약, 같은 제품, 회수 주소만 다름, 10분 차이 | 일반 접수 유지 |
| 같은 계약, 같은 제품, 같은 회수 주소, 생성 시각 차이 40분 | 30분 초과, 일반 접수 유지 |
| 같은 계약, 다른 제품, 같은 회수 주소, 5분 차이 | 일반 접수 유지 |

### 2-3. 30분 이내 판단 방법

- 기준 시각은 **가장 먼저 생성된 주문의 생성 시각**으로 한다.
- 최초 주문과 나머지 주문의 생성 시각 차이가 30분 이내인 것만 묶는다.
- 30분을 초과해 생성된 주문은 이번 절차 대상이 아니다.

---

## 3. 처리 절차

### 3-1. 1단계: 검토 대상 확인 (발견 시점부터 20분 이내 완료 목표)

1. '담주문'에서 세 정보로 교환 주문을 조회한다.
2. 30분 이내 2건 이상이면 검토 대상으로 표시한다.
3. 검토 대상 주문 전체의 **출고 상태**를 확인한다.

### 3-2. 2단계: 출고 상태에 따른 분기

| 검토 대상 출고 상태 | 처리 |
|---|---|
| **전부 '출고 전'** | 최초 주문 1건 유지, 나머지 주문 **취소 (사유 코드 D14)** |
| **'출고 완료' 1건 이상 포함** | 상담사 취소 **금지**, 물류 담당 **고도윤**에게 **이관** |

**주의사항**

- '출고 전' 주문만 취소하고, '출고 완료' 주문은 절대 취소하지 않는다.
- 출고 상태 판단이 애매하면 임의로 처리하지 말고 고도윤(내선 7246)에게 문의한다.

### 3-3. 3단계: 취소 또는 이관 실행

**A. 출고 전 전부인 경우 (상담사 처리)**

1. 최초 주문을 유지 주문으로 정한다.
2. 나머지 주문을 취소한다.
   - 취소 사유 코드: **D14**
   - 고객 변심 취소 코드 **D41은 사용하지 않는다.**
3. 주문 메모에 **유지 주문번호**를 기록한다.

**B. 출고 완료 주문이 1건 이상인 경우 (물류 이관)**

1. 상담사는 취소하지 않는다.
2. 고도윤에게 검토 대상 주문을 이관한다.
3. 주문 메모에 **물류 이관번호**를 기록한다.

### 3-4. 4단계: 고객 안내 문자 발송 (필수)

- 처리 완료 후 **고객에게 안내 문자를 반드시 발송**한다.
- 취소 전 고객에게 전화할 필요는 없다.
- 이메일 발송은 고객이 요청한 경우에만 추가로 한다. 이메일 발송 여부와 관계없이 안내 문자는 필수다.

## 6. 적용 제외 및 금지 사항

- **30분을 초과해 생성된 주문**: 이번 중복 취소 절차를 적용하지 않는다. 상담사가 임의로 취소하지 않고 **일반 접수로 유지**한다.
- **D41 코드 사용 금지**: 중복 취소에는 D14만 사용한다.
- **출고 완료 주문 취소 금지**: 상담사는 출고 완료 주문을 취소하지 않는다.
- **세 정보 중 하나라도 다른 주문 취소 금지**: 일반 접수로 유지한다.

## 8. 일일 점검 (상담 리더)

- 매일 **18:30까지** 당일 처리 목록을 점검한다.
- 점검 항목은 다음과 같다.
  - 검토 대상 주문의 처리 완료 여부
  - 20분 이내 처리 여부
  - D14 사용 여부 및 D41 미사용 여부
  - 유지 주문번호 또는 물류 이관번호 기록 여부
  - 안내 문자 발송 여부

---

## 9. 확인 필요 사항

메모에 명시되지 않아 운영 시작 전에 확정이 필요한 항목이다.

1. **물류 이관 방법**: '담주문' 내 이관 기능을 쓰는지, 별도 채널(메신저, 전화 등)을 쓰는지
2. **이관번호 발급 방식**: 누가, 어떤 형식으로 발급하는지
3. **안내 문자 문구**: 표준 템플릿이 있는지, 있다면 공유 위치
4. **이메일 발송 방법**: 고객 요청 시 누가 어느 시스템에서 발송하는지
5. **여러 묶음이 동시에 발견된 경우**: 우선순위 기준이 있는지
6. **교육 방법**: 적용 기간 전 상담사 교육 여부와 일정
