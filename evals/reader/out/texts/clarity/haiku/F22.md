# [PR #631] 출고 라벨 재인쇄 시 이전 라벨 자동 무효화

## 1. 개요

- **회사/프로젝트**: 누비창고
- **작업 묶음**: 5-2
- **PR**: #631 (nubi/dispatch)
- **기능**: 출고 라벨을 재인쇄하면 이전 라벨을 자동으로 무효화한다.

## 2. 배경 및 원인

라벨을 재인쇄한 뒤에도 이전 라벨이 스캔되어, 한 상자가 두 번 출고 처리되는 문제가 있었다.

## 3. 자동 무효화 적용 조건

| 상황 | 동작 |
|---|---|
| 동일 주문의 동일 상자 라벨을 재인쇄 | 이전 라벨을 자동 무효화한다. |
| 주문은 같지만 상자가 다른 경우 | 기존 라벨을 유지한다. |

## 4. 역할

| 역할 | 담당자 | 책임 |
|---|---|---|
| 개발 담당 | 백도윤 | 기능 개발, 병합 |
| 필수 검증 담당 (QA) | 윤해솔 | 검증 수행, 결과 등록 |
| 현장 담당 | 임채원 | 결과 열람 (검증 의무 없음) |

## 5. 검증 환경 및 금지 사항

- **검증 위치**
  - 코드: nubi/dispatch의 PR #631
  - 서버: 검증 서버 stage-pack
- **금지**: 실제 출고 서버에서 테스트하지 않는다.
