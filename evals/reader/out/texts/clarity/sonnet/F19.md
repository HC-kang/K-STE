# 중복 교환 주문 처리 런북 (묶음 4 / 누리담렌탈)

## 1. 개요
- **대상**: 누리담렌탈 고객센터 교환 접수 상담사
- **시스템**: 주문 시스템 ‘담주문’
- **적용 기간**: 12/03(목) 09:00 ~ 12/04(금) 18:00
- **배경**: 고객 앱 재시도 오류로 동일 제품 교환 주문이 중복 생성되는 문제가 발생했습니다. 이 런북은 해당 중복 주문을 처리하는 절차입니다.

## 2. 중복 검토 대상 판단
아래 **세 가지 정보가 모두 같은** 교환 주문이 **30분 이내에 2건 이상** 생성되었으면 중복 검토 대상입니다.

1. 계약번호
2. 제품번호
3. 회수 주소

| 상황 | 처리 |
|---|---|
| 세 정보가 모두 같고 30분 이내 2건 이상 생성 | 중복 검토 대상 → 3장 절차 진행 |
| 세 정보 중 하나라도 다름 | 일반 접수 유지 |
| 30분을 초과해 생성된 주문 | 이번 중복 취소 절차 적용 불가. 임의 취소하지 않고 일반 접수 유지 |

## 3. 처리 절차
**검토 대상을 발견한 시점부터 20분 이내에** 상담사 처리 또는 물류 이관을 완료합니다.

### 1단계: 출고 상태 확인
검토 대상 주문 전체의 출고 상태를 먼저 확인합니다.

### 2단계: 상태에 따른 분기

**A. 전부 ‘출고 전’인 경우 (상담사 처리)**
1. 최초 생성된 주문 1건을 유지합니다.
2. 나머지 주문은 모두 취소합니다. (필수)
3. 취소 사유 코드는 **D14(중복)** 를 사용합니다.
4. 주문 메모에 **유지 주문번호**를 기록합니다.

**B. ‘출고 완료’ 주문이 1건이라도 있는 경우 (물류 이관)**
1. 상담사는 **어떤 주문도 취소하지 않습니다.** (취소 금지)
2. 물류 담당 **고도윤**에게 이관합니다. (필수)
3. 주문 메모에 **물류 이관번호**를 기록합니다.

### 3단계: 고객 안내
- 취소 전에 고객에게 전화할 필요는 없습니다.
- 처리 후 **안내 문자를 반드시 발송**합니다.
- 고객이 요청하면 취소 내역을 이메일로 추가 발송할 수 있습니다. 이메일 발송 여부와 관계없이 안내 문자는 반드시 발송합니다.

## 4. 코드·기록 기준
| 항목 | 기준 |
|---|---|
| 중복 취소 사유 코드 | **D14** |
| 사용 금지 코드 | **D41**(고객 변심 취소) |
| 주문 메모 | 유지 주문번호(A) 또는 물류 이관번호(B) |

## 5. 점검 및 문의
- **처리 목록 점검**: 상담 리더 조세린이 매일 18:30까지 점검합니다.
- **기준 문의**: 조세린 (내선 7240)
- **출고 상태 오류 문의**: 고도윤 (내선 7246)

## 6. 처리 전 체크리스트
- [ ] 계약번호·제품번호·회수 주소가 모두 같은가
- [ ] 30분 이내에 생성된 주문인가
- [ ] 검토 대상 주문 전체의 출고 상태를 확인했는가
- [ ] 전부 ‘출고 전’이면 최초 주문 1건만 남기고 나머지를 D14로 취소했는가
- [ ] ‘출고 완료’가 1건이라도 있으면 취소하지 않고 고도윤에게 이관했는가
- [ ] 발견 후 20분 이내에 처리를 완료했는가
- [ ] 주문 메모에 유지 주문번호 또는 물류 이관번호를 기록했는가
- [ ] 처리 후 안내 문자를 발송했는가
