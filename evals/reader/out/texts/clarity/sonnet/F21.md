# [묶음 5-1] 정산 CSV 생성기 중복 행 제거 (PR #526)

## 요약
정산 CSV 생성기에서 같은 거래 행이 중복 출력되는 문제를 수정합니다. 중복 판정 기준을 **거래 ID + 정산일 조합**으로 변경했습니다.

## 원인
재시도 요청이 들어올 때마다 같은 거래 행이 CSV에 다시 추가되고 있었습니다.

## 변경 내용
- 거래 ID와 정산일이 모두 같은 행은 중복으로 보고 한 건만 남깁니다.

## 적용 범위
| 구분 | 적용 여부 |
|---|---|
| 국내 원화 정산 CSV | 적용 |
| 해외 통화 정산 CSV | 변경 제외 |
| 화면 조회 API | 변경 제외 |

| 보안 담당 | 나세림 | 참조만, 승인 불필요 |

## 리뷰어 확인 사항 (고유찬)

### 필수
1. 중복 거래를 포함한 **2,000행 샘플**로 CSV 생성기를 실행합니다.
2. 생성 결과가 **1,960행**인지 확인합니다.
3. **실행 로그를 이 PR에 첨부**합니다.

### 성능 기준
- 샘플 생성 시간은 **8초 이하**여야 합니다.
- **8초를 초과하면 승인을 보류**하고 **서다빈에게 수정을 요청**해야 합니다.

### 선택 / 생략 가능
- 전체 거래 재생 테스트: 선택 사항입니다.
- 해외 통화 샘플 실행: 하지 않아도 됩니다.
