# 실습 교육 운영안 확정 회의록

## 1. 회의 개요

| 항목 | 내용 |
|---|---|
| 일시 | 2026년 12월 1일(화) 11:00~11:40 |
| 장소 | 본사 기획회의실 |
| 안건 | 실습 교육 운영안 확정 |
| 대상 독자 | 새록온교육 기업교육 강사, 현장 운영담당자 |

## 2. 운영 방식 변경 배경

지난 교육에서 교육생 개인 노트북의 설정 차이로 실습 시작이 지연되었습니다. 이를 막기 위해 이번 교육부터 대여 노트북을 기본으로 사용하고, 실습 파일을 사전에 설치·점검하기로 했습니다.

## 3. 본 교육 개요

| 항목 | 내용 |
|---|---|
| 일시 | 2026년 12월 8일(화) 13:00~16:00 |
| 장소 | 새록온교육 남부교육장 4실 |
| 인원·장비 | 교육생 24명, 대여 노트북 24대 사용 |
| 교재 | 인쇄 교재 없음, 배움칸 전자교재 사용 |

## 4. 결정 사항

### 4.1 실습 파일 준비 (강사)
- 하라윤 강사는 실습 파일을 **12월 4일(금) 12:00까지** '배움칸' 시스템의 강사자료함에 업로드해야 합니다.

### 4.2 대여 노트북 준비 (운영담당)
- 문태겸 운영담당은 대여 노트북 24대 전부에 실습 파일을 복사하고 실행되는지 확인해야 합니다. 완료 기한은 **12월 7일(월) 17:00**입니다.

### 4.3 개인 노트북 사용 기준
- 개인 노트북 사용은 원칙적으로 불가합니다.
- 예외로, 접근성 보조 프로그램이 필요한 교육생은 운영책임자 차여진의 **사전 승인**을 받은 경우에만 사용할 수 있습니다.
- 승인받은 개인 노트북도 실습 파일이 실행되는지 확인해야 합니다. 문태겸 운영담당이 **12월 8일(화) 12:30까지** 확인을 완료합니다.

### 4.4 보충 실습과 종료 시각
- 외부망 접속 없이 실행되는 보충 실습은 강사 판단으로 추가할 수 있습니다.
- 보충 실습을 포함하더라도 교육 종료 시각은 **16:00**으로 유지합니다.

### 4.5 교재
- 인쇄 교재는 배부하지 않습니다. 강사와 운영담당 모두 교재를 인쇄할 필요가 없습니다.
- 교육생은 배움칸 전자교재를 사용합니다.
