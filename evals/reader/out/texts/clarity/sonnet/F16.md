# 다온결제넷 정산 파일 재전송 런북 (묶음 4)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 배경 | 다온결제넷 전송 게이트웨이 교체로 정산 파일 수신 확인이 지연될 것으로 예상됨 |
| 적용 작업일 | 11/12(목) |
| 대상 파일 | 11/11(수) 매출 정산 파일 |
| 작업 위치 | 사내 운영 콘솔 '결빛' > 정산 > 전송 이력 |
| 실행 | 야간 정산 운영자 민서준 |
| 완료 확인 | 당직 책임자 배유림 |

## 2. 시간표

| 시각 | 작업 | 담당 |
|---|---|---|
| 01:10 | 수신 상태 조회 (필수) | 민서준 |
| 01:10~01:20 | '미수신' 상태가 10분 연속 유지되는지 확인 | 민서준 |
| 01:20 | 조건을 충족한 파일부터 재전송 시작 | 민서준 |
| 01:50까지 | 재전송 결과와 실패 파일 목록을 작업일지에 기록 | 민서준 |
| 02:00까지 | 작업일지 확인 후 완료 또는 '후속 조치 필요' 표시 | 배유림 |

## 3. 상태별 처리 기준

| 수신 상태 | 처리 |
|---|---|
| 수신 완료 | 재전송 불필요. 단순 조회만 허용 |
| 처리 중 | 재전송하지 않음. 배유림에게 확인 요청 |
| 미수신 | 10분 연속 유지된 경우에만 재전송 대상 (4장 절차 진행) |

## 4. 실행 절차

### 4-1. 수신 상태 조회 (01:10)
1. 결빛 > 정산 > 전송 이력에서 11/11(수) 매출 정산 파일 목록을 조회한다.
2. 파일별 수신 상태를 확인하고 3장 기준으로 분류한다.
3. 조회 오류가 나면 8장 연락처의 오하린에게 문의한다.

### 4-2. 재전송 대상 확정 (01:20)
1. 01:10부터 01:20까지 '미수신'이 계속 유지된 파일만 재전송 대상으로 확정한다.
2. 중간에 상태가 바뀐 파일은 대상에서 제외하고 3장 기준대로 처리한다.

### 4-3. 해시 확인 (재전송 전, 파일마다 필수)
1. 원본 파일 해시와 보관본 해시를 비교한다.
2. **일치**: 재전송을 진행한다.
3. **불일치**: 재전송을 금지하고 즉시 배유림에게 보고한다.

### 4-4. 재전송 (파일당 최대 2회)
1. 해시가 일치한 파일을 1차 재전송한다.
2. 1차 후에도 '미수신'이면 5분 뒤 2차 재전송한다.
3. 2차까지 실패하면 추가 전송을 하지 않고 실패 파일로 기록한다.

## 5. 작업일지 기록 (01:50까지)

결빛 작업일지에 아래 내용을 기록한다.
- 파일별 재전송 결과 (재전송 횟수 포함)
- 실패 파일 목록
- 해시 불일치 또는 '처리 중'으로 재전송하지 않은 파일과 사유
- 실패 파일이 없더라도 **'실패 0건'을 반드시 기록**한다.

## 6. 완료 확인 (02:00까지, 배유림)

- 작업일지를 확인한다.
- 미해결 파일이 없으면 **완료**로 표시한다.
- 미해결 파일이 있으면 완료 대신 **'후속 조치 필요'**로 표시한다.

## 7. 금지 사항 요약

- '미수신' 10분 연속 유지 확인 전 재전송 금지
- 해시 불일치 파일 재전송 금지
- '수신 완료' 파일 재전송 금지
- '처리 중' 파일 재전송 금지
- 파일당 3회 이상 전송 금지
