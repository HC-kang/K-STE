# PR #964: 센서 연결 끊김 알림 재발송 간격 변경

- 회사/묶음: 다온센서 / 묶음 5-5
- 저장소: daon/alerts
- 개발 담당: 류한결
- 고객지원 필수 검토: 배소율
- 안내 문구 담당: 진유하

## 변경 배경
짧은 통신 끊김이 반복되면 같은 설비의 연결 끊김 알림이 쌓이고, 이로 인해 고객지원 문의가 늘고 있습니다. 이를 줄이기 위해 재발송 간격을 변경합니다.

## 변경 내용
같은 센서의 연결 끊김이 계속될 때 다음과 같이 동작합니다.

- 최초 연결 끊김 이메일은 즉시 발송합니다.
- 끊김이 계속되면 20분 간격으로 재발송합니다.
- 연결 복구 이메일은 대기 없이 즉시 발송합니다.

## 적용 대상과 제외 대상

| 구분 | 변경 적용 여부 |
|---|---|
| 표준 요금제의 이메일 연결 끊김 알림 | 적용 |
| 기업 요금제 | 제외 (기존 동작 유지) |
| 문자 알림 | 제외 (기존 동작 유지) |

## 검토 방법
