# PR #853: 임시 좌석 점유 자동 해제 작업 추가

**회사**: 해솔예약 · **묶음**: 5-4 · **검토 위치**: haesol/booking PR #853

## 배경
결제 없이 닫힌 예약 화면의 임시 좌석 점유가 해제되지 않고 남습니다. 이 때문에 판매 가능 좌석 수가 줄어듭니다. 이 PR은 미결제 임시 점유를 자동으로 해제하는 작업을 추가합니다.

## 변경 내용
- 자동 해제 작업은 **5분 간격**으로 실행됩니다.
- **해제 대상**: 생성 후 15분 이상 지난 미결제 임시 점유
- **해제 제외**: 결제 완료 좌석, 상담원 수동 잠금 좌석
- **적용 범위**: 국내 공연 영역만 해당합니다. **해외 공연 영역에는 적용하지 않습니다.**

## 배포 실행 절차 (문라온)
배포 위치는 운영 콘솔 **seat-ops의 국내 공연 영역**입니다.

**1. 배포 전**
- [ ] 한지율의 승인이 12/02(수) 18:00까지 완료되었는지 확인합니다.
- [ ] **현재 설정값을 내보내 둡니다. (필수)**

**2. 배포**
- [ ] 12/03(목) 09:00에 seat-ops의 국내 공연 영역에 배포를 시작합니다.

**3. 배포 후 관찰**
- [ ] **첫 30분간 관찰합니다. (필수)**
- [ ] 추가 30분 관찰은 선택 사항입니다.
- [ ] 해외 공연 영역은 이번 PR의 적용 대상이 아니므로 수동 점검이 필요 없습니다.
- [ ] **관찰 결과를 이 PR의 댓글에 기록합니다. (필수, 12/03 10:00까지)**

## 중지 기준
관찰 중 **결제 완료 좌석이 해제된 건수가 1건 이상**이면 다음을 바로 실행합니다.
1. 자동 해제 작업을 **즉시 중지**합니다.
2. **한지율에게 연락**합니다.
