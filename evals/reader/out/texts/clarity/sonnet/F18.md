# 모래별스튜디오 온라인 공연 예비 회선 전환 런북

**묶음 4 | 현장 송출 기사용**

## 1. 개요

- **배경**: 주 회선 장비 점검으로 공연 중 송출이 끊길 가능성이 있어 예비 회선을 준비한다.
- **적용 공연**: 11/27(금) 19:30~21:00
- **작업 장소**: 본사 3층 송출실, 콘솔 '별송'

## 2. 역할

| 역할 | 담당 | 업무 |
|---|---|---|
| 송출 기사 | 윤태림 | 예비 회선 연결 시험, 회선 전환 실행, 대기 화면 송출, 기록 제출 |
| 음향 기사 | 서가온 | 전환 후 음성 확인 및 기록 |
| 현장 책임자 | 문해솔 | 공연 송출 중단 여부 결정 |

## 3. 공연 전 준비 (19:00까지)

1. 윤태림은 19:00까지 예비 회선 연결 시험을 완료한다.
2. 시험 영상은 **내부 미리보기로만** 확인한다. **시청자 채널로는 송출하지 않는다.**
3. 주 회선 자동 복귀 기능을 **비활성화**하고, 공연 내내 비활성 상태를 유지한다.

## 4. 공연 중 전환 기준

기준은 주 회선 손실률과 지속 시간이다.

| 상황 | 조치 |
|---|---|
| 손실률 3% 이상이 **20초 연속** 유지 | **예비 회선으로 전환 필수.** 문해솔의 별도 승인은 필요 없다. |
| 손실률이 3% 미만 | 전환하지 않는다. 내부 미리보기 확인은 가능하다. |
| 손실률 3% 이상이지만 지속 시간이 20초 미만 | 전환하지 않는다. 내부 미리보기 확인은 가능하다. |

## 5. 전환 후 절차

1. 윤태림이 예비 회선으로 전환한다.
2. 서가온은 전환 실행 후 **40초 이내**에 음성 확인 결과를 별송 작업창에 기록한다.
3. 음성에 이상이 있으면 서가온이 문해솔에게 **즉시** 보고한다.

## 6. 예비 회선도 불안정한 경우

1. 예비 회선에서도 손실률 3% 이상이 20초 연속 유지되면 윤태림은 **대기 화면을 송출**한다.
2. 공연 송출을 중단할지는 **문해솔만** 결정한다. 윤태림과 서가온은 중단 여부를 판단하지 않는다.

## 7. 주 회선 복귀 금지

- 주 회선이 정상으로 보여도 **공연 종료 전에는 수동으로 복귀하지 않는다.**
- 자동 복귀 기능은 공연 내내 비활성 상태여야 한다.

## 8. 공연 후 제출 (21:20까지)

- 윤태림은 21:20까지 **전환 시각과 손실률 기록**을 제출한다.
- 전환이 없었더라도 **'전환 없음'**으로 제출한다.

## 9. 문의처

| 구분 | 담당 | 내선 |
|---|---|---|
| 회선 문의 | 문해솔 | 6134 |
| 음성 문의 | 서가온 | 6139 |

## 10. 요약 체크리스트

- [ ] 19:00 전: 예비 회선 연결 시험 완료 (내부 미리보기만 사용)
- [ ] 19:00 전: 자동 복귀 비활성화 확인
- [ ] 공연 중: 손실률 3% 이상이 20초 연속이면 즉시 전환
- [ ] 전환 후 40초 이내: 음성 확인 결과 기록
- [ ] 음성 이상 시: 문해솔에게 즉시 보고
- [ ] 예비 회선도 3% 이상 20초 연속 시: 대기 화면 송출, 중단 여부는 문해솔 결정
- [ ] 공연 종료 전: 수동 복귀 금지
- [ ] 21:20 전: 기록 제출 (전환이 없었으면 '전환 없음')

---

**확인 필요**: 메모에는 "대기 화면 송출"과 "공연 송출 중단"이 별도 조치로 적혀 있어 그대로 옮겼습니다. 대기 화면 송출 중에도 공연 송출은 중단되지 않은 상태로 보는 것이 맞는지, 문해솔 책임자와 한 번 확인해 두시면 현장 혼선을 줄일 수 있습니다.
