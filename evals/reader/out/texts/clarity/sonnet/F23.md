# PR #742: 웹 강의 플레이어 키보드 자막 설정 기능

**서비스/묶음**: 새온학습 / 묶음 5-3
**저장소**: saeon/player

## 배경
기존 자막 설정 창은 마우스로만 열 수 있습니다. 그래서 키보드 사용자는 자막 설정을 변경할 수 없습니다. 이 PR은 키보드만으로 자막 설정 창을 열고 조작할 수 있게 합니다.

## 변경 내용
- 플레이어에 초점이 있을 때 단축키 **C**를 누르면 자막 설정 창이 열립니다.
- 검색 입력란에 초점이 있을 때는 단축키가 동작하지 않고, 문자 `c`가 그대로 입력됩니다.

## 적용 범위
- **포함**: 녹화 강의 웹 플레이어
- **제외**: 실시간 강의, 모바일 앱 플레이어
