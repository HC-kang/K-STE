**제목: [필독] 11월 공용 장비 자산 실사 안내 (11/24(화) 17:00까지 ‘별장부’ 확인 필수)**

별고리연구원 연구직·행정직 전 직원 여러분께,

장비 관리대장과 실제 보관 위치가 일치하지 않는 문제를 해소하기 위해 11월에 공용 장비 자산 실사를 진행합니다. 전 직원이 참여해야 하므로 아래 내용을 확인하시고 기한 내 처리해 주시기 바랍니다.

**1. 실사 대상**
- 대상: 회사 자산번호가 붙은 노트북, 태블릿, 측정기
- 제외: 개인 소유 장비, 자산번호가 없는 소모품

**2. 전 직원 공통 (필수)**
- 가상 자산 시스템 ‘별장부’에서 본인에게 배정된 장비 목록을 확인하고 **11/24(화) 17:00까지 ‘확인 완료’ 처리**해 주세요.
- 배정된 장비가 없는 경우에도 같은 기한까지 **‘배정 없음’ 처리**를 해야 합니다. 별도로 이메일 보고를 하실 필요는 없습니다.

**3. 장비 보유자가 할 일 (필수)**
- 별장부에서 각 장비의 **자산번호와 현재 위치**를 입력합니다.
- **자산번호가 보이는 사진 1장**을 첨부합니다.

**4. 장비 상태별 처리 방법**

| 장비 상태 | 처리 방법 |
|---|---|
| 정상 작동 | 별장부 온라인 확인만 하면 됩니다. 실사실로 가져오실 필요 없습니다. |
| 고장 | 온라인 확인과 별도로 **11/25(수) 10:00~16:00 연구동 1층 실사실에 반납**해야 합니다. |
| 외부 수리업체에 맡김 | 직접 반납은 면제됩니다. **11/24(화) 17:00까지 별장부에 수리 접수증을 첨부**해 주세요. 자산번호 사진은 접수증으로 대체할 수 있습니다. |

**5. 팀장 추가 확인**
- 한 직원에게 배정된 장비가 **3대 이상**이면 팀장의 추가 확인이 필요합니다.
- 해당 팀의 팀장은 **11/26(목) 12:00까지 별장부에서 승인**해 주세요.

**6. 미등록 장비를 발견한 경우**
- 실사 중 새로 발견한 미등록 장비는 자산번호 유무와 관계없이 **반드시 자산팀에 신고**해 주세요.
- 임의로 폐기하거나 다른 사람에게 이전해서는 안 됩니다.

**7. 온라인 입력 설명회 (선택)**
- 일시: 11/20(금) 15:00~15:30
- 장소: 사내 화상회의방 ‘별교실’
- 참여는 선택이며, 불참하셔도 실사 의무는 동일하게 적용됩니다.

**8. 주요 일정 요약**

| 일시 | 내용 |
|---|---|
| 11/20(금) 15:00~15:30 | 온라인 입력 설명회 (선택) |
| 11/24(화) 17:00 | 전 직원 ‘확인 완료’ 또는 ‘배정 없음’ 처리, 장비 정보 입력, 수리 접수증 첨부 마감 |
| 11/25(수) 10:00~16:00 | 고장 장비 실사실(연구동 1층) 반납 |
| 11/26(목) 12:00 | 팀장 승인 마감 (배정 장비 3대 이상 직원 해당) |

**9. 문의처**
- 배정 목록, 수리 접수증: 자산팀 도서린 (내선 643)
- 고장 장비 반납 시간 조정: 시설팀 차유건 (내선 297)
