# PR #742: 웹 강의 플레이어 키보드 자막 설정

새온학습 묶음 5-3의 PR #742는 웹 강의 플레이어에 키보드 자막 설정 기능을 추가한다. 기존 자막 설정 창은 마우스로만 열 수 있어서 키보드 사용자가 자막 설정을 바꿀 수 없었다. 구현 담당은 민여울이고, 접근성 필수 승인 담당은 정이든이다. 번역 담당은 조하린이며 번역 문의만 맡는다.

## 변경 내용

- 단축키 C는 플레이어에 초점이 있을 때만 자막 설정 창을 연다.
- 검색 입력란에 초점이 있으면 문자 c 입력을 그대로 유지한다.

## 적용 범위

이 기능은 녹화 강의 웹 플레이어에 적용한다. 실시간 강의와 모바일 앱 플레이어는 제외한다.

## 검토 위치와 일정

검토 위치는 saeon/player의 PR #742에 연결된 preview-caption이다.

- 검토 시작: 11/23(월) 09:00에 시작한다.
- 승인 마감: 정이든이 11/25(수) 17:00까지 승인해야 한다.
- 병합 예정: 민여울이 11/26(목) 11:00에 병합할 예정이다.

## 검증 요구사항

- 정이든은 한국어 강의 4개와 영어 강의 2개, 총 6개에서 키보드 이동을 검증해야 한다.
- 키보드 이동 검증 결과는 PR 댓글에 기록해야 한다.
- 화면낭독기 검증도 해야 한다.
- 검증할 때 설정 창 배율은 200%를 사용해야 한다.
- 검증 중 초점 표시가 한 번이라도 사라지면 승인을 보류해야 한다.
- 마우스 이동 경로 녹화는 해도 된다.
- 모바일 앱 화면 캡처는 하지 않아도 된다.

## 문의처

문의는 사내 메신저 #caption-review로 한다.

- 초점 이동 오류: 민여울
- 자막 언어 표기: 조하린
