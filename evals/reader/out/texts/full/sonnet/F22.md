# PR #631 출고 라벨 재인쇄 시 이전 라벨 자동 무효화

누비창고 묶음 5-2의 PR #631은 출고 라벨을 재인쇄할 때 이전 라벨을 자동으로 무효화한다. 지금까지는 재인쇄 후에도 이전 라벨이 스캔되어 한 상자가 두 번 출고 처리되었다. 이 PR은 출고 시스템 QA 담당자가 검증한다.

## 자동 무효화 적용 조건

- 동일 주문의 동일 상자 라벨을 재인쇄하면 이전 라벨이 자동으로 무효화된다.
- 주문이 같아도 상자가 다르면 기존 라벨은 유지된다.

## 담당자

- 개발: 백도윤
- 필수 검증: QA 윤해솔
- 현장 담당 임채원은 결과를 열람만 하며, 검증하지 않아도 된다.

## 검증 위치

- nubi/dispatch의 PR #631과 검증 서버 stage-pack에서 검증해야 한다.
- 실제 출고 서버에서 테스트하면 안 된다.

## 필수 검증

재인쇄 사례 12건과 다른 상자 사례 8건, 총 20건의 결과를 PR 체크리스트에 기록해야 한다.

### 합격 기준

이전 라벨이 3초 이내에 무효화되어야 한다. 한 건이라도 3초를 초과하면 병합 차단 표시를 해야 한다.
