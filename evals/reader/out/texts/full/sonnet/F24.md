# 임시 좌석 점유 자동 해제 작업 추가 (PR #853)

회사 해솔예약 묶음 5-4의 PR #853은 임시 좌석 점유를 자동으로 해제하는 작업을 추가한다. 결제 없이 닫힌 예약 화면의 좌석 점유가 남아 판매 가능 좌석 수가 줄었기 때문이다. 이 PR은 해외 공연 영역에 적용하지 않는다.

## 변경 내용

- 해제 대상: 생성 후 15분 이상 지난 미결제 임시 점유
- 해제 제외: 결제 완료 좌석, 상담원 수동 잠금 좌석
- 자동 해제 작업 실행 간격: 5분
- 검토 위치: haesol/booking의 PR #853
- 배포 위치: 운영 콘솔 seat-ops의 국내 공연 영역

## 실행 절차

아래 1-5단계는 모두 해야 한다.

1. 12/03(목) 09:00 배포를 시작하기 전에 현재 설정값을 내보낸다.
2. 한지율의 승인을 받은 뒤 12/03(목) 09:00에 운영 콘솔 seat-ops의 국내 공연 영역에서 배포를 시작한다.
3. 배포 후 첫 30분 동안 관찰한다.
4. 관찰 중 결제 완료 좌석 해제 건수가 1건 이상이면 즉시 작업을 중지하고 한지율에게 연락한다.
5. 12/03(목) 10:00까지 관찰 결과를 PR 댓글에 기록한다.

## 선택 사항

- 배포 후 추가 30분 동안 관찰해도 된다.
- 해외 공연 수동 점검은 하지 않아도 된다.
