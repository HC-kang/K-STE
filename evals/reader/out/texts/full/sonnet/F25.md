# PR #964: 센서 연결 끊김 알림 재발송 간격 변경 (묶음 5-5)

다온센서의 공장 모니터링 제품에서 센서 연결 끊김 이메일 알림의 재발송 간격을 바꾼다. 이 PR은 daon/alerts에 있고, 고객지원 릴리스 검토자가 12/09(수) 16:00까지 검증 결과를 PR 댓글에 등록해야 한다.

## 배경

짧은 통신 끊김이 반복되면 같은 설비의 알림이 쌓여 고객지원 문의가 늘었다.

## 변경 내용

같은 센서의 연결 끊김이 계속되면 최초 이메일을 즉시 발송하고, 이후 20분 간격으로 재발송한다. 연결 복구 이메일은 대기 없이 즉시 발송한다.

## 적용 대상

- 적용: 표준 요금제의 이메일 연결 끊김 알림
- 제외: 기업 요금제, 문자 알림

## 담당자

- 개발: 류한결
- 고객지원 필수 검토: 배소율
- 안내 문구 문의: 진유하(문서 담당)

## 일정

- 검토 시작: 12/07(월) 10:00
- 결과 등록 기한: 12/09(수) 16:00까지
- 병합 예정: 12/10(목) 09:00

## 검토 방법

검토 위치는 daon/alerts의 PR #964와 데모 계정 demo-factory이다. 고객 실제 계정을 사용하면 안 된다.

배소율은 다음 항목을 검토해야 한다.

1. 표준 요금제 센서 3대와 기업 요금제 센서 2대, 총 5대로 적용 대상과 제외 대상의 동작을 검증해야 한다.
2. 이메일 제목을 확인해야 한다.
3. 검증 결과와 고객 안내 문구의 승인 여부를 PR 댓글에 기록해야 한다.

이메일 본문 화면 캡처는 첨부해도 된다. 문자 알림 발송 테스트는 하지 않아도 된다.

고객 안내 문구가 승인되지 않으면 병합을 보류해야 한다.
