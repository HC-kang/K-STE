# 정산 CSV 생성기 중복 행 제거 (PR #526)

재시도 요청마다 같은 거래 행이 추가되던 문제를 수정한다. 거래 ID와 정산일의 조합으로 중복 행을 판정하고, 중복으로 판정된 행은 제거한다. 적용 범위는 국내 원화 정산 CSV이며, 해외 통화 CSV와 화면 조회 API는 변경하지 않는다.

## 기본 정보

- 회사: 모람결제
- 묶음: 5-1
- 저장소: moram/settlement
- PR: #526
- 작성자: 서다빈
- 필수 승인자: 고유찬 (정산 플랫폼 리뷰어)
- 참조: 나세림 (보안 담당). 승인은 필요하지 않다.

## 원인

재시도 요청이 들어올 때마다 같은 거래 행이 추가되었다.

## 변경 내용

정산 CSV 생성기는 거래 ID와 정산일의 조합으로 중복을 판정하도록 변경된다.

## 적용 범위

- 변경 대상: 국내 원화 정산 CSV
- 변경 제외: 해외 통화 CSV, 화면 조회 API

## 검토 일정

- 검토 시작: 11/09(월) 10:00
- 승인 기한: 11/11(수) 16:00 (고유찬)
- 병합 예정 시각: 11/12(목) 09:00 (서다빈)

## 검토 요구사항

고유찬은 중복 거래를 포함한 2,000행 샘플을 실행해야 한다. 생성 결과가 1,960행인지 확인한 뒤, 실행 로그를 PR에 첨부해야 한다.

## 성능 기준

샘플 생성 시간은 8초 이하여야 한다. 8초를 초과하면 승인을 보류하고 서다빈에게 수정을 요청해야 한다.

## 선택 항목

- 전체 거래 재생 테스트는 선택 사항이다.
- 해외 통화 샘플 실행은 하지 않아도 된다.
