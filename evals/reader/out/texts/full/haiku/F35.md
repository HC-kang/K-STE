**제목:** [규정 변경 안내] 온라인 실시간 강좌 강의 자료 제출 기한 변경 (12/14 개강 강좌부터)

12/14(월) 개강하는 강좌부터 온라인 실시간 강좌의 강의 자료 제출 시점이 개강 1일 전에서 3일 전으로 앞당겨집니다. 강의 자료가 늦게 바뀌어 수강생에게 이전 파일이 배포된 사례가 있었기 때문입니다.

적용 대상은 온라인 실시간 강좌의 강사와 운영 매니저입니다. 사전 녹화 강좌는 기존 자료 등록 규정을 그대로 따릅니다.

- 강사는 개강 3일 전(12/11 금) 18:00까지 '배움결' 시스템의 강좌별 '배포 자료'에 최종 PDF를 업로드해야 합니다.
- 자료는 강좌당 PDF 1개, 파일 크기 20MB 이하로 제출해야 합니다. 여러 문서가 있으면 강사가 PDF 1개로 합쳐 업로드해야 합니다.
- 운영 매니저는 개강 2일 전(12/12 토) 12:00까지 파일이 열리는지와 강좌명을 확인한 뒤, 시스템에서 검수를 완료 상태로 바꿔야 합니다.
- 제출 마감 이후에는 강사가 파일을 직접 교체하면 안 됩니다. 내용 오류는 '수정 요청' 메뉴로 접수해야 하며, 운영 매니저의 승인을 받은 뒤 매니저가 파일을 교체합니다.
- 수업 중 발견한 내용 오류는 강사가 먼저 구두로 바로잡아도 됩니다. 다만 수업 종료 후 2시간 이내에 '수정 요청'으로 접수해야 합니다.
- 자료 변경이 없는 동일 강좌를 다시 개설하는 경우 기존 파일을 재사용해도 됩니다. 이때 강사는 제출 마감까지 '기존 자료 사용' 버튼을 클릭해야 하며, 파일을 다시 업로드하지 않아도 됩니다.

강사와 운영 매니저는 12/10(목) 17:00까지 '배움결' 공지의 규정 확인 버튼을 클릭해야 합니다.

문의는 교육지원 서이담(메신저 '자료운영문의')으로 주시기 바랍니다.
