# [묶음 5-5] 센서 연결 끊김 알림 재발송 간격 변경 (PR #964)

다온센서 묶음 5-5의 PR #964는 센서 연결 끊김 알림의 재발송 간격을 바꾼다. 짧은 통신 끊김이 반복되면 같은 설비의 알림이 쌓여 고객지원 문의가 늘어난다. 이번 변경은 표준 요금제의 이메일 연결 끊김 알림만 대상으로 하며, 기업 요금제와 문자 알림은 변경에서 제외한다.

## 변경 내용

같은 센서의 연결 끊김이 계속되면 최초 이메일을 즉시 발송한 뒤 20분 간격으로 재발송한다. 연결이 복구되면 복구 이메일을 대기 없이 즉시 발송한다.

## 변경 범위

- 변경 대상: 표준 요금제의 이메일 연결 끊김 알림
- 변경 제외: 기업 요금제, 문자 알림

## 검토 요구 사항

검토는 daon/alerts 저장소의 PR #964와 데모 계정 demo-factory에서 한다.

- 배소율은 표준 요금제 센서 3대와 기업 요금제 센서 2대, 총 5대에서 대상과 제외 동작을 검증해야 한다.
- 배소율은 검증 결과와 고객 안내 문구 승인 여부를 PR 댓글에 기록해야 한다.
- 고객 안내 문구가 승인되지 않으면 병합을 보류해야 한다.
- 이메일 제목을 확인해야 한다.
- 본문 화면 캡처는 첨부해도 된다.
- 문자 알림 발송 테스트는 하지 않아도 된다.
- 고객 실제 계정은 사용하면 안 된다.
