# PR #631: 출고 라벨 재인쇄 시 이전 라벨 자동 무효화

누비창고 묶음 5-2의 PR #631은 출고 라벨을 재인쇄할 때 이전 라벨을 자동으로 무효화하는 기능을 추가한다. 재인쇄 후 이전 라벨도 스캔되어 한 상자가 두 번 출고 처리되는 문제를 해결하기 위한 변경이다. QA 담당자는 아래 필수 검증을 수행하고 결과를 PR 체크리스트에 기록해야 한다.

## 원인

재인쇄 후 이전 라벨도 스캔되어 한 상자가 두 번 출고 처리되었다.

## 변경 내용

자동 무효화는 동일 주문의 동일 상자 라벨을 재인쇄한 경우에 적용한다. 주문이 같더라도 상자가 다르면 기존 라벨을 유지한다.
