# 웹 강의 플레이어에 키보드로 여는 자막 설정 기능 추가 (PR #742)

새온학습 묶음 5-3의 PR #742는 웹 녹화 강의 플레이어에서 키보드로 자막 설정 창을 여는 기능을 추가한다. 기존 자막 설정 창은 마우스로만 열 수 있어 키보드 사용자가 자막 설정을 바꿀 수 없었다.

## 적용 범위

녹화 강의 웹 플레이어에 적용한다. 실시간 강의와 모바일 앱 플레이어는 이 PR의 범위에서 제외한다.

## 키보드 동작

플레이어에 초점이 있을 때 C 키는 자막 설정 창을 연다. 검색 입력란에 초점이 있을 때 C 키는 문자 c를 입력한다.

## 검증 방법

접근성 검토자인 정이든은 아래 항목을 검증해야 한다.

1. 한국어 강의 4개와 영어 강의 2개, 총 6개에서 키보드 이동을 검증해야 한다.
2. 화면낭독기 검증을 해야 한다.
3. 설정 창은 배율 200%에서 검증해야 한다.
4. 마우스 이동 경로는 녹화해도 되고 하지 않아도 된다.
5. 모바일 앱 화면 캡처는 하지 않아도 된다.
6. 검증 결과는 PR 댓글에 기록해야 한다.

**초점 표시가 한 번이라도 사라지면 승인을 보류해야 한다.**

## 문의처

초점 이동 오류는 민여울에게, 자막 언어 표기는 조하린에게 문의한다. 문의는 사내 메신저 #caption-review를 이용한다.
