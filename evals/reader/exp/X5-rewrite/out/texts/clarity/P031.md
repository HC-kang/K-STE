포그라운드 캐스케이딩 삭제에서는 삭제하려는 소유자 오브젝트가 먼저 *삭제 중* 상태가 됩니다. 이때 소유자 오브젝트에는 다음과 같은 변화가 생깁니다.

* 쿠버네티스 API 서버가 오브젝트의 `metadata.deletionTimestamp` 필드에 삭제 표시된 시간을 설정합니다.
* 쿠버네티스 API 서버가 `metadata.finalizers` 필드를 `foregroundDeletion`으로 설정합니다.
* 삭제가 완료되기 전까지는 쿠버네티스 API로 해당 오브젝트를 조회할 수 있습니다.

소유자 오브젝트가 삭제 중 상태가 되면 컨트롤러가 종속 오브젝트를 삭제합니다. 모든 종속 오브젝트가 삭제되면 컨트롤러가 소유자 오브젝트를 삭제하며, 이 시점부터는 쿠버네티스 API로 해당 오브젝트를 조회할 수 없습니다.

포그라운드 캐스케이딩 삭제 중에 소유자 오브젝트의 삭제를 막을 수 있는 종속 오브젝트는 `ownerReference.blockOwnerDeletion=true` 필드를 가진 오브젝트입니다. 자세한 내용은 [포그라운드 캐스케이딩 삭제 사용](https://kubernetes.io/docs/tasks/administer-cluster/use-cascading-deletion/#use-foreground-cascading-deletion)을 참고하세요.

**수정한 부분**
- 문체를 "~한다"에서 "~합니다"로 바꿨습니다. 원문 문체를 유지해야 한다면 말씀해 주세요. 어미만 되돌리면 됩니다.
- "소유자 오브젝트에게 다음과 같은 일이 일어난다"를 "소유자 오브젝트에는 다음과 같은 변화가 생깁니다"로 바꿔 자연스럽게 했습니다.
- "`foregroundDeletion`로"를 "`foregroundDeletion`으로"로 고쳤습니다.
- 코드 표기 앞뒤의 빠진 띄어쓰기를 바로잡고 "삭제되고나면"을 "삭제되면"으로 정리했습니다.
- 마지막 문장은 "막는 종속 오브젝트"를 "막을 수 있는 종속 오브젝트"로 바꿔, 해당 필드가 삭제를 막을 수 있게 하는 설정임을 분명히 했습니다.
- 영어로 남아 있던 "Use foreground cascading deletion"은 한국어 제목으로 옮기고 링크를 붙였습니다. 링크 주소와 한국어 제목은 공식 문서 기준으로 한 번 확인해 주세요.
