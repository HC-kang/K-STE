### 레거시 API 레퍼런스의 볼륨 항목

* [`Volume`](#): 컨테이너가 접근할 파드 내의 일반 볼륨을 정의한다.
* [`DownwardAPIVolumeSource`](#): 다운워드 API 정보를 포함하는 볼륨을 정의한다.
* [`DownwardAPIVolumeFile`](#): 다운워드 API 볼륨 내 파일을 채우기 위한 오브젝트 또는 리소스 필드의 레퍼런스를 포함한다.
* [`ResourceFieldSelector`](#): 컨테이너 리소스와 그 출력 형식을 지정한다.
