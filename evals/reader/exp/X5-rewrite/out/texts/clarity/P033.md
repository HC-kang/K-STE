유효성 검사 어드미션 정책(ValidatingAdmissionPolicy)을 사용하면 공통 표현식 언어(Common Expression Language, CEL)로 작성한 유효성 검사 규칙을 API 서버에서 실행할 수 있습니다. 예를 들어 `latest` 이미지 태그의 사용을 금지하는 정책을 만들 수 있습니다.

`ValidatingAdmissionPolicy`는 API 요청을 대상으로 동작합니다. 이를 이용하면 규정을 준수하지 않는 구성을 차단하거나 감사(audit)할 수 있고, 해당 구성에 대해 사용자에게 경고할 수도 있습니다.

`ValidatingAdmissionPolicy` API의 자세한 내용과 예시는 별도 섹션에서 확인할 수 있습니다.

**주요 변경 사항**

- **문체**: 원문의 "~한다" 체를 "~합니다" 체로 바꿨습니다. 안내문이라면 이쪽이 자연스럽지만, 원문이 쿠버네티스 공식 문서 번역처럼 "~한다" 체를 유지해야 한다면 말씀해 주세요. 그 문체로 다시 맞추겠습니다.
- **첫 문장**: "구성 가능한 유효성 검사"는 의미가 모호해서 "CEL로 작성한 유효성 검사 규칙"으로 풀어 썼습니다.
- **둘째 문장**: "~하고, ~하는 데 사용할 수 있다"로 이어지던 문장을 "~할 수 있고, ~할 수도 있습니다"로 정리해 세 가지 기능(차단, 감사, 경고)이 읽기 쉽게 드러나도록 했습니다.
- **마지막 문장**: "문서화되어 있다"를 "확인할 수 있습니다"로 바꿔 독자 입장에서 자연스럽게 했습니다.
- **링크**: 마지막 목록의 `(#)`는 자리표시자이므로 실제 문서 주소로 교체해 주세요.
