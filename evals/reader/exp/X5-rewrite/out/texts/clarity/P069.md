네임스페이스에 리소스 쿼터(ResourceQuota)가 설정되어 있다면, CPU 상한(limit)의 기본값도 함께 설정하는 것이 좋습니다. CPU 리소스 쿼터는 네임스페이스에 다음 두 가지 제한을 적용하기 때문입니다.

* 네임스페이스에서 실행되는 모든 파드의 모든 컨테이너에는 CPU 상한이 지정되어 있어야 합니다.
* CPU 상한은 파드가 스케줄링될 노드에 리소스를 예약합니다. 네임스페이스 내 모든 파드에 예약된 CPU 총량은 쿼터에 지정된 상한을 초과할 수 없습니다.

## 리밋레인지(LimitRange)를 추가할 때

네임스페이스에 리밋레인지로 CPU 상한 기본값을 설정해 두면, 파드의 컨테이너에 CPU 상한이 지정되어 있지 않을 때 컨트롤 플레인이 해당 컨테이너에 기본값을 자동으로 적용합니다. 따라서 이 파드는 CPU 리소스 쿼터가 적용된 네임스페이스에서도 실행될 수 있습니다.
