다듬은 글은 다음과 같습니다.

---

클러스터에서 동적 프로비저닝을 활성화하면, 스토리지클래스를 지정하지 않은 모든 클레임이 동적으로 프로비저닝됩니다. 클러스터 관리자는 다음 두 가지 작업으로 이를 활성화할 수 있습니다.

- 스토리지클래스 오브젝트 하나를 *기본(default)* 으로 표시한다.
- API 서버에서 `DefaultStorageClass` 어드미션 컨트롤러를 활성화한다.

관리자는 스토리지클래스에 `storageclass.kubernetes.io/is-default-class` 어노테이션을 추가하여 해당 스토리지클래스를 기본으로 표시할 수 있습니다. 클러스터에 기본 스토리지클래스가 있는 상태에서 사용자가 `storageClassName`을 지정하지 않고 퍼시스턴트볼륨클레임(PVC)을 생성하면, `DefaultStorageClass` 어드미션 컨트롤러가 기본 스토리지클래스를 가리키는 `storageClassName` 필드를 자동으로 추가합니다.

**참고:** 클러스터에서 두 개 이상의 스토리지클래스에 `storageclass.kubernetes.io/is-default-class: "true"` 어노테이션이 설정되어 있을 때 `storageClassName` 없이 PVC를 생성하면, 쿠버네티스는 가장 최근에 생성된 기본 스토리지클래스를 사용합니다.

**주요 변경 사항**
- 첫 문장의 "활성화할 수 있다 … 활성화할 수 있다" 반복을 정리하고, 두 가지 작업이 나온다는 점을 먼저 밝혔습니다.
- 어노테이션 값이 `true`임을 `"true"`로 표기해 실제 매니페스트에 쓰는 형태와 맞췄습니다.
- 마지막 문단은 주의 사항임이 드러나도록 "참고"로 시작하고, 조건과 결과를 순서대로 배치했습니다.
- 문체를 원문의 평서형(~한다)에서 존댓말(~합니다)로 바꿨습니다. 기술 문서 스타일(~한다)을 유지하려면 말씀해 주세요.
