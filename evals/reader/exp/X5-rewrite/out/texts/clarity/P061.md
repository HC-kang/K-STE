쿠버네티스 클러스터는 설정된 IP 패밀리에 따라 다음과 같이 분류할 수 있습니다.

- **IPv4 전용**: 네트워크 플러그인, kube-apiserver, kubelet/cloud-controller-manager가 모두 IPv4 주소만 할당하도록 설정된 클러스터
- **IPv6 전용**: 네트워크 플러그인, kube-apiserver, kubelet/cloud-controller-manager가 모두 IPv6 주소만 할당하도록 설정된 클러스터
- **이중 스택(IPv4/IPv6 또는 IPv6/IPv4)**: 다음 조건을 모두 만족하는 클러스터
  - 네트워크 플러그인이 IPv4와 IPv6 주소를 모두 할당하도록 설정되어 있다.
  - kube-apiserver가 IPv4와 IPv6 주소를 모두 할당하도록 설정되어 있다.
  - kubelet 또는 cloud-controller-manager가 IPv4와 IPv6 주소를 모두 할당하도록 설정되어 있다.
  - 모든 컴포넌트가 동일한 기본 IP 패밀리를 사용하도록 설정되어 있어야 한다.

클러스터 유형을 판단할 때 쿠버네티스는 파드, 서비스, 노드 오브젝트에 기록된 IP 패밀리만 고려하며, 해당 오브젝트가 실제로 가진 다른 IP는 고려하지 않습니다. 예를 들어 노드나 파드의 인터페이스에 여러 IP 주소가 할당되어 있더라도, 쿠버네티스 네트워크 모델을 구현하고 클러스터 유형을 정의할 때는 `node.status.addresses` 또는 `pod.status.ips`에 있는 IP 주소만 고려합니다.

**수정 내용**
- 각 항목을 "~로 설정된 클러스터" 형태로 통일해 분류 기준이 한눈에 보이게 했습니다.
- 이중 스택 항목의 "다음 조건을 모두 만족"을 명시해, 마지막 항목(동일한 기본 IP 패밀리)도 필수 조건임을 분명히 했습니다.
- 원문의 "서버나 파드"는 문맥상 "노드나 파드"가 맞아 보여 바꿨습니다. 의도와 다르면 원문대로 되돌려 주세요.
- "기존 IP와는 무관하다"는 모호해서 "실제로 가진 다른 IP는 고려하지 않는다"로 풀어 썼습니다.
- 문체는 본문은 "~합니다"로, 목록은 "~다"로 두었습니다. 한 가지로 통일하길 원하시면 알려 주세요.
