다듬은 글은 다음과 같습니다.

---

잡(Job)과 달리, 일부 컨트롤러는 클러스터 외부의 리소스를 변경해야 합니다.

예를 들어 컨트롤 루프로 클러스터에 충분한 수의 노드가 있도록 유지하려면, 필요할 때 새 노드를 설정할 수 있도록 클러스터 외부의 무언가가 필요합니다.

외부 상태와 상호 작용하는 컨트롤러는 API 서버에서 의도한 상태를 가져온 다음, 외부 시스템과 직접 통신하여 현재 상태를 의도한 상태에 가깝게 만듭니다. (실제로 클러스터의 노드를 수평으로 확장하는 컨트롤러가 있습니다.)

여기서 중요한 점은 컨트롤러가 의도한 상태를 실현하기 위해 변경을 가한 뒤, 현재 상태를 클러스터의 API 서버에 다시 보고한다는 것입니다. 다른 컨트롤 루프는 이렇게 보고된 데이터를 관찰하고 필요한 조치를 취할 수 있습니다.

온도 조절기 예에서 방이 매우 추우면, 다른 컨트롤러가 서리 방지 히터를 켤 수도 있습니다. 쿠버네티스 클러스터에서는 쿠버네티스 확장을 통해 IP 주소 관리 도구, 스토리지 서비스, 클라우드 제공자의 API 같은 외부 서비스와 간접적으로 연동하여 이러한 제어를 구현합니다.

---

주요 수정 사항은 다음과 같습니다.

- **"잡과는 대조적으로" → "잡(Job)과 달리"**: 더 자연스러운 표현으로 바꾸고, 쿠버네티스 리소스임을 알 수 있도록 원어를 병기했습니다.
- **"클러스터 외부의 것" → "클러스터 외부의 리소스"**: 모호한 "것"을 구체화했습니다.
- **"~할 필요가 있다"와 "~하는 경우, 해당 컨트롤러는" 구조 정리**: 원문은 주어가 어긋나 있어서 문장을 간결하게 다시 썼습니다.
- **"현재 상태를 보다 가깝게 만든다" → "현재 상태를 의도한 상태에 가깝게 만듭니다"**: 무엇에 가깝게 만드는지 빠져 있던 부분을 보완했습니다.
- **"약간의 변화" → "변경"**: 원문의 "약간"은 불필요하게 범위를 한정하므로 뺐습니다.
- **문체 통일**: "~다"체와 "~한다"체가 섞여 있어서 "~합니다"체로 통일했습니다. 문서 전체가 "~다"체라면 그에 맞춰 바꾸셔도 됩니다.
- **마지막 문장**: "이를 구현한다"의 "이"가 가리키는 대상이 불분명해서 "이러한 제어를 구현합니다"로 고쳤습니다. 다만 원문 의도가 "외부 시스템과의 연동"이라면 "이러한 연동을 구현합니다"가 더 정확할 수 있으니 확인해 보세요.
