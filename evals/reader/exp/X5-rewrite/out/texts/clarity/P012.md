노드 컨트롤러는 클라우드 인프라에 새 서버가 생성될 때 해당 서버에 대응하는 노드 오브젝트를 업데이트합니다. 이를 위해 클라우드 공급자의 사용자 테넌시 내에서 실행되는 호스트의 정보를 가져옵니다. 주요 기능은 다음과 같습니다.

1. 클라우드 공급자 API로 확인한 서버의 고유 ID를 노드 오브젝트에 업데이트합니다.
2. 클라우드 관련 정보를 사용해 노드 오브젝트에 어노테이션과 레이블을 추가합니다. 클라우드 관련 정보에는 노드가 배포된 지역, 사용 가능한 리소스(CPU, 메모리 등)가 포함됩니다.
3. 노드의 호스트 이름과 네트워크 주소를 가져옵니다.
4. 노드의 상태를 확인합니다. 노드가 응답하지 않으면 클라우드 공급자 API로 해당 서버가 비활성화, 삭제, 종료되었는지 확인합니다. 노드가 클라우드에서 삭제되었다면 쿠버네티스 클러스터에서도 해당 노드 오브젝트를 삭제합니다.

일부 클라우드 공급자 구현에서는 이 기능을 노드 컨트롤러와 별도의 노드 라이프사이클 컨트롤러로 분리하기도 합니다.

**주요 수정 사항**
- 문체를 "~한다"에서 "~합니다"로 바꾸었습니다. 원문의 문체를 유지해야 한다면 알려 주세요.
- 반복되는 "노드 컨트롤러는"을 줄이고, 도입부를 두 문장으로 정리했습니다.
- 2번 항목의 괄호 안 긴 설명을 풀어 써서 어떤 정보가 어노테이션과 레이블에 쓰이는지 분명하게 했습니다.
- 4번 항목의 "비활성화됨 / 삭제됨 / 종료됨"을 "비활성화, 삭제, 종료되었는지"로 자연스럽게 고쳤습니다.
- 마지막 문장의 "이를"이 가리키는 대상이 모호해서 "이 기능"으로 명시했습니다.
