# 노드 컨트롤러

노드 컨트롤러는 노드의 여러 측면을 관리하는 쿠버네티스 컨트롤 플레인 컴포넌트이다.

노드 컨트롤러는 노드가 생성되어 유지되는 동안 다음과 같은 역할을 한다.

## 1. CIDR 블록 할당

노드가 등록될 때, CIDR 할당이 활성화되어 있으면 해당 노드에 CIDR 블록을 할당한다.

## 2. 내부 노드 목록 최신화

노드 컨트롤러는 클라우드 제공자가 제공하는 사용 가능한 머신 목록을 기준으로 내부 노드 목록을 최신 상태로 유지한다.

클라우드 환경에서 실행 중일 때 노드의 상태가 불량하면, 노드 컨트롤러는 해당 노드의 VM이 여전히 사용 가능한지 클라우드 제공자에게 확인한다. VM을 더 이상 사용할 수 없으면 노드 컨트롤러는 해당 노드를 노드 목록에서 삭제한다.

## 3. 노드 동작 상태 모니터링

노드 컨트롤러는 다음 작업을 담당한다.

- 노드에 접근할 수 없게 되면(unreachable) 노드의 `.status` 필드에 있는 `Ready` 컨디션을 `Unknown`으로 업데이트한다.
- 노드에 계속 접근할 수 없으면 해당 노드의 모든 파드에 대해 API를 이용한 축출(eviction)을 시작한다. 기본적으로 노드를 `Unknown`으로 표시한 뒤 5분을 기다렸다가 첫 번째 축출 요청을 보낸다.

노드 컨트롤러는 기본적으로 5초마다 각 노드의 상태를 확인한다. 이 확인 주기는 `kube-controller-manager`의 `--node-monitor-period` 플래그로 설정할 수 있다.

**주요 변경 사항**
- 항목별로 소제목을 달아 "첫째/두 번째/세 번째"의 흐름을 구분하기 쉽게 했습니다.
- "블럭", "사용토록", "최신상태" 등 표기를 바로잡았습니다(블록, 활성화, 최신 상태).
- "클라우드 제공사업자"는 "클라우드 제공자"로 간결하게 줄였습니다. 용어집 등 기존 번역과 맞춰야 한다면 원래 표현으로 되돌리세요.
- "트리거한다", "마킹한" 같은 외래어식 표현은 "시작한다", "표시한"으로 바꿨습니다.
- 원문의 "접근 불가능 상태가 되는 경우, ... 이 경우에는"처럼 겹치는 문장을 하나로 합쳤습니다.
