기본적으로 kubelet은 이미지를 **직렬**로 풀(pull)합니다. 즉, 한 번에 하나의 이미지 풀 요청만 이미지 서비스에 전송하며, 나머지 요청은 처리 중인 요청이 끝날 때까지 대기합니다.

다만 이 직렬 처리는 노드 단위로만 적용됩니다. 각 노드는 이미지 풀을 독립적으로 결정하므로, 직렬 이미지 풀을 사용하더라도 서로 다른 두 노드가 같은 이미지를 동시에 풀할 수 있습니다.

## 병렬 이미지 풀 활성화

병렬 이미지 풀을 사용하려면 kubelet 설정에서 `serializeImagePulls` 필드를 `false`로 지정합니다. 이 경우 이미지 풀 요청이 즉시 이미지 서비스로 전송되어 여러 이미지가 동시에 풀됩니다.

> **참고:** 병렬 이미지 풀을 활성화하기 전에, 컨테이너 런타임의 이미지 서비스가 병렬 풀을 처리할 수 있는지 확인하세요.

## 파드 단위의 동작

kubelet은 **하나의 파드를 위한 이미지들**은 병렬로 풀하지 않습니다. 예를 들어 초기화 컨테이너와 애플리케이션 컨테이너가 있는 파드에서는 두 컨테이너의 이미지가 병렬로 풀되지 않습니다.

반면 서로 다른 이미지를 사용하는 두 개의 파드가 있고 병렬 이미지 풀이 활성화되어 있다면, kubelet은 두 파드의 이미지를 병렬로 풀합니다.

**주요 변경 사항**
- 문장을 짧게 나누고 "~한다" 체를 "~합니다" 체로 통일했습니다.
- 직렬 풀의 노드 간 독립성을 "다만"으로 연결해 흐름을 명확히 했습니다.
- 설정 방법, 주의사항, 파드 단위 동작을 소제목과 인용 블록으로 구분했습니다.
