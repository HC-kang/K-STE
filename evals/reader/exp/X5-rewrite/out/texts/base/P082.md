## cgroup v2를 사용하는 리눅스 배포판

cgroup v2를 사용하는 전체 배포판 목록은 cgroup v2 문서를 참조한다.

**cgroup v2를 기본으로 사용하는 주요 배포판**

* Container Optimized OS (M97 이상)
* Ubuntu (21.10 이상, 22.04 이상 권장)
* Debian GNU/Linux (Debian 11 bullseye 이상)
* Fedora (31 이상)
* Arch Linux (2021년 4월 이후)
* RHEL 및 RHEL 기반 배포판 (9 이상)

**사용 중인 배포판 확인 방법**

사용 중인 배포판이 cgroup v2를 사용하는지 확인하려면 해당 배포판의 문서를 참조하거나, 「리눅스 노드에서 cgroup 버전 확인하기」의 지침을 따른다.

**cgroup v2 수동 활성화**

커널 cmdline 부트 인자를 수정하면 cgroup v2를 수동으로 활성화할 수 있다. 배포판이 GRUB을 사용한다면 다음 순서로 진행한다.

1. `/etc/default/grub` 파일의 `GRUB_CMDLINE_LINUX`에 `systemd.unified_cgroup_hierarchy=1`을 추가한다.
2. 다음 명령을 실행한다.

   ```shell
   sudo update-grub
   ```

> **참고:** 수동으로 활성화하기보다는, cgroup v2를 기본으로 활성화하는 배포판을 사용하는 방법을 권장한다.
