## 노드 컨트롤러

노드 컨트롤러는 클라우드 인프라스트럭처에 새 서버가 생성될 때 노드 오브젝트를 업데이트한다. 이를 위해 클라우드 공급자의 사용자 테넌시 내에서 실행되는 호스트의 정보를 가져온다.

### 주요 기능

1. **고유 ID 업데이트**: 클라우드 공급자 API로 획득한 서버의 고유 ID를 노드 오브젝트에 업데이트한다.
2. **어노테이션 및 레이블 작성**: 클라우드 관련 정보를 사용해 노드 오브젝트에 어노테이션과 레이블을 작성한다. 여기에는 노드가 배포된 지역, 사용 가능한 리소스(CPU, 메모리 등)가 포함된다.
3. **호스트 이름 및 네트워크 주소 조회**: 노드의 호스트 이름과 네트워크 주소를 가져온다.
4. **노드 상태 확인**:
   - 노드가 응답하지 않으면 클라우드 공급자 API로 서버가 비활성화됨, 삭제됨, 종료됨 중 어떤 상태인지 확인한다.
   - 노드가 클라우드에서 삭제되었다면 쿠버네티스 클러스터에서도 해당 노드 오브젝트를 삭제한다.

> **참고**: 일부 클라우드 공급자의 구현에서는 이 기능을 노드 컨트롤러와 별도의 노드 라이프사이클 컨트롤러로 분리하기도 한다.
