쿠버네티스 클러스터는 설정된 IP 패밀리에 따라 다음과 같이 분류할 수 있다.

- **IPv4 전용**: 네트워크 플러그인, kube-apiserver, kubelet/cloud-controller-manager가 모두 IPv4 주소만 할당하도록 설정된다.
- **IPv6 전용**: 네트워크 플러그인, kube-apiserver, kubelet/cloud-controller-manager가 모두 IPv6 주소만 할당하도록 설정된다.
- **IPv4/IPv6 또는 IPv6/IPv4 이중 스택**:
  - 네트워크 플러그인, kube-apiserver, kubelet 또는 cloud-controller-manager가 모두 IPv4와 IPv6 주소를 함께 할당하도록 설정된다.
  - 모든 컴포넌트는 동일한 기본 IP 패밀리를 사용하도록 설정해야 한다.

쿠버네티스 클러스터는 파드, 서비스, 노드 오브젝트의 상태에 기록된 IP 패밀리만 고려하며, 해당 오브젝트가 가진 다른 IP와는 무관하다. 예를 들어 서버나 파드의 네트워크 인터페이스에 여러 IP 주소가 할당되어 있더라도, 쿠버네티스 네트워크 모델을 구현하고 클러스터 유형을 정의할 때는 `node.status.addresses` 또는 `pod.status.ips`에 있는 IP 주소만 고려한다.

**주요 변경 사항**
- 이중 스택 항목에서 반복되던 "IPv4 및 IPv6 주소를 할당하도록 설정되어 있다"를 한 문장으로 합쳤다.
- "설정되어 있다"를 "설정된다"로 간결하게 바꾸고, 분류명을 굵게 표시해 구분하기 쉽게 했다.
- "기존 IP"처럼 모호한 표현을 "다른 IP"로 바꾸고, 마지막 문장의 서술을 "고려한다"로 끝맺어 문장 구조를 명확히 했다.
