다듬은 글입니다.

- **cluster-proportional-autoscaler** 애플리케이션은 DNS 서비스와 별도로 배포됩니다.

- 오토스케일러 파드는 클러스터의 노드 및 코어 수를 확인하기 위해 쿠버네티스 API 서버를 폴링(poll)하는 클라이언트를 실행합니다.

- 의도한 레플리카 수는 주어진 스케일링 파라미터로 계산하며, 예약 가능한 노드와 코어를 기반으로 DNS 백엔드에 적용합니다.

- 스케일링 파라미터와 데이터 포인트는 컨피그맵(ConfigMap)을 통해 오토스케일러에 제공됩니다. 오토스케일러는 폴링 간격마다 파라미터 표를 갱신하여, 항상 최신 스케일링 파라미터가 적용되도록 합니다.

- 스케일링 파라미터는 오토스케일러 파드를 다시 빌드하거나 재시작하지 않고도 변경할 수 있습니다.

- 오토스케일러는 *linear*와 *ladder* 두 가지 제어 패턴을 지원하는 컨트롤러 인터페이스를 제공합니다.

**수정한 내용**
- 오타 수정: "스케일링 파마리터" → "스케일링 파라미터"
- 어색한 표현 정리: "자동 오토스케일러에게 제공된다.그리고," → 문장을 나누고 "오토스케일러에 제공됩니다"로 수정
- 문체 통일: "~된다"를 "~합니다/됩니다" 체로 통일
