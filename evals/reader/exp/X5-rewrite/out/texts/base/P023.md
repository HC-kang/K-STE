## 기본 스토리지클래스와 동적 프로비저닝

클러스터에서 동적 프로비저닝을 활성화하면, 스토리지클래스를 지정하지 않은 모든 클레임이 동적으로 프로비저닝된다. 클러스터 관리자는 다음 두 가지를 설정하여 이를 활성화할 수 있다.

1. 스토리지클래스 오브젝트 하나를 *기본(default)* 으로 표시한다.
2. API 서버에서 `DefaultStorageClass` 어드미션 컨트롤러를 활성화한다.

### 기본 스토리지클래스 지정

관리자는 스토리지클래스에 `storageclass.kubernetes.io/is-default-class` 어노테이션을 추가하여 해당 클래스를 기본으로 지정할 수 있다.

기본 스토리지클래스가 존재하는 클러스터에서 사용자가 `storageClassName` 없이 퍼시스턴트볼륨클레임(PVC)을 생성하면, `DefaultStorageClass` 어드미션 컨트롤러가 기본 스토리지클래스를 가리키는 `storageClassName` 필드를 자동으로 추가한다.

### 참고

두 개 이상의 스토리지클래스에 `storageclass.kubernetes.io/is-default-class: "true"` 어노테이션이 설정되어 있고, `storageClassName`이 없는 PVC를 생성하면, 쿠버네티스는 **가장 최근에 생성된** 기본 스토리지클래스를 사용한다.
