**쿠버네티스 오브젝트**는 쿠버네티스 시스템에서 영속성을 가지는 엔티티입니다. 쿠버네티스는 이 엔티티를 사용해 클러스터의 상태를 나타냅니다. 오브젝트로 구체적으로 표현할 수 있는 내용은 다음과 같습니다.

* 어떤 컨테이너화된 애플리케이션이 어느 노드에서 실행 중인지
* 애플리케이션이 사용할 수 있는 리소스
* 재시작 정책, 업그레이드, 내결함성 등 애플리케이션의 동작 방식에 관한 정책

쿠버네티스 오브젝트는 **"의도의 기록"**입니다. 오브젝트를 생성하면 쿠버네티스는 그 오브젝트가 계속 존재하도록 지속적으로 동작합니다. 즉, 오브젝트를 생성하는 것은 클러스터의 워크로드가 어떤 모습이어야 하는지를 쿠버네티스에 알려 주는 일이며, 이것이 바로 클러스터의 **의도한 상태(desired state)**입니다.

오브젝트를 생성, 수정, 삭제하려면 쿠버네티스 API를 사용해야 합니다. 예를 들어 `kubectl` 명령줄 인터페이스(CLI)를 사용하면 CLI가 필요한 쿠버네티스 API 호출을 대신 수행합니다. 클라이언트 라이브러리를 이용해 직접 작성한 프로그램에서 쿠버네티스 API를 호출할 수도 있습니다.

**주요 변경 사항**
- 문장 종결을 "~이다"에서 "~합니다"로 바꿔 부드럽게 했습니다. (문서 톤에 따라 "~이다"체로 유지하셔도 됩니다.)
- "구체적으로, 다음을 설명할 수 있다"를 "표현할 수 있는 내용은 다음과 같습니다"로 바꿔 의미를 분명히 했습니다.
- 첫 번째 목록의 항목을 간결하게 정리하고 세 항목의 문장 구조를 맞췄습니다.
- API 설명 문단에서 어색했던 "예를 들어"의 위치를 바로잡고, 문장을 짧게 나눠 흐름을 매끄럽게 했습니다.
- 강조 표기를 `*...*`에서 `**...**`로 통일했습니다.
