## 더 알아보기

### 파드 및 downward API
* 파드 API 정의인 `spec`을 읽어보자. 여기에는 파드의 일부인 컨테이너의 정의가 포함되어 있다.
* downward API를 사용하여 노출할 수 있는 필드의 목록을 읽어보자.

### 레거시 API 레퍼런스: 볼륨
볼륨과 관련된 다음 API 정의를 확인해 보자.

* `Volume`: 컨테이너가 접근할 수 있는 파드 내 일반 볼륨을 정의한다.
* `DownwardAPIVolumeSource`: downward API 정보를 포함하는 볼륨을 정의한다.
* `DownwardAPIVolumeFile`: downward API 볼륨 내 파일을 채우기 위해, 오브젝트 또는 리소스 필드에 대한 레퍼런스를 포함한다.
* `ResourceFieldSelector`: 컨테이너 리소스와 그 출력 형식을 지정한다.
