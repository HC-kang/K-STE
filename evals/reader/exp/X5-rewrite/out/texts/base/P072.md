다듬은 버전입니다.

- **안정된 최신 API 버전을 명시합니다.** 구성을 정의할 때 사용할 API 버전을 명확히 지정합니다.

- **구성 파일은 클러스터에 적용하기 전에 버전 컨트롤에 저장합니다.** 필요할 때 변경 사항을 빠르게 되돌릴 수 있고, 클러스터를 다시 만들거나 복원하는 데에도 도움이 됩니다.

- **구성 파일은 JSON보다 YAML로 작성합니다.** 두 포맷 모두 대부분의 상황에서 사용할 수 있지만, YAML이 더 사용자 친화적입니다.

- **관련 오브젝트는 의미상 적절하다면 하나의 파일로 묶습니다.** 여러 파일보다 하나의 파일이 관리하기 더 쉬운 경우가 많습니다. 예시는 `guestbook-all-in-one.yaml` 파일을 참고합니다.

- **`kubectl` 명령은 디렉터리 단위로도 실행할 수 있습니다.** 예를 들어 구성 파일이 들어 있는 디렉터리에 `kubectl apply`를 실행할 수 있습니다.

- **불필요하게 기본값을 명시하지 않습니다.** 설정을 간단하고 최소한으로 유지하면 오류가 줄어듭니다.

- **오브젝트 설명은 어노테이션에 넣습니다.** 이렇게 하면 인트로스펙션(introspection)이 쉬워집니다.

주요 변경점:
- 각 항목의 핵심 문장을 굵게 표시해 훑어보기 쉽게 했습니다.
- "이는 ~ 이는 또한 ~"처럼 반복되던 표현을 한 문장으로 합쳤습니다.
- "대부분의 모든", "통용되어 사용될 수 있지만" 같은 중복·번역투 표현을 정리했습니다.
- 원문의 "이 문법의 예시로서"는 의미가 어색해 "예시는 ~를 참고합니다"로 바꿨습니다.

원하시면 굵게 표시 없이 문장만 담백하게 정리한 버전이나, 공식 문서 스타일의 "~한다" 체로도 바꿔 드릴 수 있습니다.
