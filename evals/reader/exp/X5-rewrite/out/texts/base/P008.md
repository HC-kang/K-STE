일반 서비스 또는 헤드리스 서비스에서 이름이 지정된 포트에는 SRV 레코드가 생성됩니다.

- **레코드 형식**: 이름이 지정된 각 포트의 SRV 레코드는 다음 형식입니다.
  `_port-name._port-protocol.my-svc.my-namespace.svc.cluster-domain.example`

- **일반 서비스**: SRV 레코드는 포트 번호와 다음 도메인 이름으로 해석됩니다.
  `my-svc.my-namespace.svc.cluster-domain.example`

- **헤드리스 서비스**: SRV 레코드는 서비스를 지원하는 파드마다 하나씩, 여러 개의 응답으로 해석됩니다. 각 응답에는 포트 번호와 다음 형식의 파드 도메인 이름이 포함됩니다.
  `hostname.my-svc.my-namespace.svc.cluster-domain.example`

**주요 변경 사항**
- "생성된다" → "생성됩니다"로 문체를 통일했습니다(경어체). 기존 문체를 유지하려면 "~된다"로 되돌리세요.
- 긴 문장을 나누고, 도메인 이름은 별도 줄로 분리해 코드 형식이 눈에 잘 띄게 했습니다.
- 각 항목의 핵심 용어(일반 서비스, 헤드리스 서비스)를 굵게 표시했습니다.
