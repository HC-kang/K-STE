다듬은 버전입니다.

---

기본적으로 쿠버네티스 API 서버는 로컬호스트가 아닌 첫 번째 네트워크 인터페이스의 6443 포트에서 요청을 수신하며, 이 통신은 TLS로 보호됩니다. 일반적인 프로덕션 클러스터에서는 API가 443 포트로 제공됩니다. 포트는 `--secure-port` 플래그로, 수신 대기 IP 주소는 `--bind-address` 플래그로 변경할 수 있습니다.

API 서버는 자신의 인증서를 클라이언트에 제시합니다. 이 인증서는 사설 인증 기관(CA)으로 서명하거나, 공인 CA와 연결된 공개키 인프라(PKI)를 기반으로 발급할 수 있습니다. 인증서와 해당 개인키는 `--tls-cert-file`과 `--tls-private-key-file` 플래그로 지정합니다.

클러스터가 사설 CA를 사용한다면, 해당 CA 인증서의 사본을 클라이언트의 `~/.kube/config`에 설정해야 합니다. 그래야 서버 연결을 신뢰할 수 있고, 중간에서 연결을 가로채는 공격이 없었음을 확신할 수 있습니다.

이 단계에서 클라이언트도 TLS 클라이언트 인증서를 제시할 수 있습니다.
