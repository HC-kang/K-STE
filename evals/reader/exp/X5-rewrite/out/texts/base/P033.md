유효성 검사 어드미션 정책(ValidatingAdmissionPolicy)은 공통 표현식 언어(Common Expression Language, CEL)를 사용해 API 서버에서 구성 가능한 유효성 검사를 실행하는 기능이다. 예를 들어 `latest` 이미지 태그의 사용을 금지하도록 설정할 수 있다.

이 정책은 API 요청을 대상으로 동작한다. 규정을 준수하지 않는 구성을 차단하거나 감사(audit)할 수 있으며, 해당 구성에 대해 사용자에게 경고를 보낼 수도 있다.
