# 노드 컨트롤러

노드 컨트롤러는 노드의 다양한 측면을 관리하는 쿠버네티스 컨트롤 플레인 컴포넌트이다.

## 주요 역할

노드 컨트롤러는 노드가 생성되어 유지되는 동안 다음과 같은 역할을 한다.

### 1. CIDR 블록 할당
CIDR 할당이 활성화되어 있으면, 노드가 등록될 때 해당 노드에 CIDR 블록을 할당한다.

### 2. 내부 노드 목록 최신화
노드 컨트롤러는 클라우드 제공사업자가 제공하는 사용 가능한 머신 목록을 근거로 내부 노드 목록을 최신 상태로 유지한다.

클라우드 환경에서 동작 중일 때 노드 상태가 불량하면, 노드 컨트롤러는 해당 노드의 VM이 여전히 사용 가능한지 클라우드 제공사업자에게 묻는다. VM을 더 이상 사용할 수 없으면 노드 컨트롤러는 노드 목록에서 해당 노드를 삭제한다.

### 3. 노드 동작 상태 모니터링
노드 컨트롤러는 다음 작업을 담당한다.

- **접근 불가능(unreachable) 상태 처리**: 노드에 접근할 수 없게 되면 노드의 `.status` 필드에 있는 `Ready` 컨디션을 `Unknown`으로 업데이트한다.
- **파드 축출**: 노드가 계속 접근 불가능한 상태로 남아 있으면 해당 노드의 모든 파드에 대해 API를 이용한 축출을 트리거한다. 기본적으로 노드를 `Unknown`으로 표시한 뒤 5분을 기다렸다가 최초의 축출 요청을 시작한다.

## 상태 확인 주기

기본적으로 노드 컨트롤러는 5초마다 각 노드의 상태를 확인한다. 이 주기는 `kube-controller-manager`의 `--node-monitor-period` 플래그로 설정할 수 있다.
