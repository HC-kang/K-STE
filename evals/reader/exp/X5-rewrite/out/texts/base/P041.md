1. **Kubelet의 기능 보고**
   - 시작 시 각 노드의 kubelet은 현재 활성화된 관리형 쿠버네티스 기능을 감지합니다.
   - 감지한 기능은 노드의 `.status.declaredFeatures` 필드에 보고합니다.
   - 이 필드에는 현재 활발히 개발 중인 기능만 포함됩니다.

2. **스케줄러 필터링**
   - 기본 kube-scheduler는 `NodeDeclaredFeatures` 플러그인을 사용합니다. 이 플러그인은 다음과 같이 동작합니다.
     - **`PreFilter` 단계:** `PodSpec`을 확인하여 파드에 필요한 노드 기능 집합을 추론합니다.
     - **`Filter` 단계:** 노드의 `.status.declaredFeatures`에 나열된 기능이 파드에서 추론한 요구사항을 충족하는지 확인합니다. 필요한 기능이 없는 노드에는 파드가 스케줄링되지 않습니다.
   - 사용자 정의 스케줄러도 `.status.declaredFeatures` 필드를 활용해 유사한 제약 조건을 적용할 수 있습니다.

3. **승인 제어**
   - `nodedeclaredfeaturevalidator` 승인 컨트롤러는 바인딩된 노드가 선언하지 않은 기능을 요구하는 파드를 거부할 수 있습니다.
   - 이를 통해 파드 업데이트 중 발생할 수 있는 문제를 방지합니다.

**수정한 부분**
- 평서문(`~한다`)을 존댓말(`~합니다`)로 통일했습니다. 원문 문체를 유지하고 싶으시면 알려 주세요.
- 긴 문장을 나누고 하위 항목을 계층화해 단계별 역할이 한눈에 보이도록 했습니다.
