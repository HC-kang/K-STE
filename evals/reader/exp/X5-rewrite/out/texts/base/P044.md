다듬은 글은 다음과 같습니다.

---

잡(Job)과 달리, 일부 컨트롤러는 클러스터 외부의 대상을 변경해야 합니다.

예를 들어 컨트롤 루프로 클러스터에 충분한 수의 노드를 유지하려는 경우, 컨트롤러는 필요할 때 새 노드를 설정하기 위해 클러스터 외부의 무언가를 필요로 합니다.

외부 상태와 상호 작용하는 컨트롤러는 API 서버에서 의도한 상태를 가져온 뒤, 외부 시스템과 직접 통신하여 현재 상태를 의도한 상태에 가깝게 만듭니다.
(실제로 클러스터의 노드를 수평 확장하는 컨트롤러도 있습니다.)

여기서 중요한 점은 컨트롤러가 의도한 상태를 실현하기 위해 변경을 가한 뒤, 현재 상태를 클러스터의 API 서버에 다시 보고한다는 것입니다. 다른 컨트롤 루프는 이렇게 보고된 데이터를 관찰하고 자체 조치를 취할 수 있습니다.

온도 조절기 예시에서 방이 매우 춥다면, 다른 컨트롤러가 서리 방지 히터를 켤 수도 있습니다. 쿠버네티스 클러스터에서는 쿠버네티스 확장을 통해 IP 주소 관리 도구, 스토리지 서비스, 클라우드 제공자의 API 등 다양한 서비스와 간접적으로 연동하여 이를 구현합니다.

---

**주요 수정 사항**
- "잡과는 대조적으로" → "잡(Job)과 달리"로 간결하게 바꾸고, 쿠버네티스 리소스명임을 드러냈습니다.
- "~해야 할 필요가 있다", "~하는 경우" 등 번역투 표현을 자연스럽게 정리했습니다.
- "현재 상태를 보다 가깝게 만든다"는 무엇에 가깝게 만드는지 불분명해서 "의도한 상태에 가깝게"로 명확히 했습니다.
- 문체를 "~다"체에서 "~합니다"체로 통일했습니다. 원문 톤(평서문)을 유지하길 원하시면 다시 바꿔 드리겠습니다.
- 긴 문장을 끊고 불필요한 줄바꿈을 정리해 읽는 흐름을 매끄럽게 했습니다.
