유효성 검사 어드미션 정책(validating admission policy)을 사용하면 API 서버에서 구성 가능한 유효성 검사를 실행할 수 있다. 이때 공통 표현식 언어(Common Expression Language, CEL)를 이용한다. 예를 들어 `ValidatingAdmissionPolicy`를 사용해 `latest` 이미지 태그의 사용을 금지할 수 있다.

`ValidatingAdmissionPolicy`는 API 요청을 대상으로 동작한다. 규정을 준수하지 않는 구성을 차단하거나 감사(audit)하는 데 사용할 수 있다. 해당 구성에 대해 사용자에게 경고하는 데에도 사용할 수 있다.

`ValidatingAdmissionPolicy` API에 대한 세부 정보와 예시는 별도 섹션에서 다룬다.
