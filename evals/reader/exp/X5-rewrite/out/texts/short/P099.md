- 아래 지침은 업그레이드 과정에서 각 노드를 언제 드레인해야 하는지를 제시한다.
  kubelet을 **마이너** 버전으로 업그레이드하는 경우, 먼저 업그레이드할 노드를 드레인**해야 한다**.
  컨트롤 플레인 노드는 CoreDNS 파드 또는 다른 중요한 워크로드를 실행 중일 수 있다.
  더 많은 정보는 노드 드레인하기를 참조한다.
- 컨테이너 사양 해시 값이 변경된다. 그래서 업그레이드 후 모든 컨테이너가 다시 시작된다.
- kubelet을 업그레이드한 뒤 kubelet 서비스가 성공적으로 다시 시작됐는지 확인하려면, `systemctl status kubelet` 명령을 실행하거나 `journalctl -xeu kubelet` 명령으로 서비스 로그를 확인할 수 있다.
- 클러스터를 재구성하기 위해 `kubeadm upgrade`를 할 때 kubeadm 구성 API 종류를 명시하여 `--config` 플래그를 사용하는 것은 추천하지 않는다. 이 사용 방식은 예상치 못한 결과를 초래할 수 있다.
  대신 kubeadm 클러스터 재구성하기를 참조한다.

확인 필요: "`kubeadm upgrade` 시에 kubeadm 구성 API 종류를 명시하여 `--config` 플래그를 사용하는 것"에서 "클러스터를 재구성하기 위해"가 `kubeadm upgrade` 전체에 걸리는지, `--config` 사용에만 걸리는지 알려 주세요.
