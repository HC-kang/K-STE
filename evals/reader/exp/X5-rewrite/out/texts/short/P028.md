* `spec`을 읽어보자.
  `spec`은 파드에 대한 API 정의다. `spec`은 컨테이너(파드의 일부)의 정의를 포함한다.
* downward API로 노출할 수 있는 필드 목록을 읽어보자.

레거시 API 레퍼런스에서 볼륨에 대해 읽어본다.
* `Volume` API 정의를 확인한다. `Volume`은 컨테이너가 접근할 파드 내의 일반 볼륨을 정의한다.
* `DownwardAPIVolumeSource` API 정의를 확인한다. `DownwardAPIVolumeSource`는 downward API 정보를 포함하는 볼륨을 정의한다.
* `DownwardAPIVolumeFile` API 정의를 확인한다. `DownwardAPIVolumeFile`은 downward API 볼륨 내 파일을 채우기 위한 오브젝트 또는 리소스 필드로의 레퍼런스를 포함한다.
* `ResourceFieldSelector` API 정의를 확인한다. `ResourceFieldSelector`는 컨테이너 리소스와 이들의 출력 형식을 지정한다.
