- 관리자가 네임스페이스에 `LimitRange`를 생성한다.
- 사용자가 해당 네임스페이스에서 파드나 퍼시스턴트볼륨클레임 같은 오브젝트를 생성한다(또는 생성하려고 시도한다).
- 첫째, `LimitRange` 어드미션 컨트롤러는 컴퓨팅 리소스 요구사항을 설정하지 않은 모든 파드(및 해당 컨테이너)에 기본 요청 및 제한 값을 적용한다.
- 둘째, `LimitRange`는 사용량을 추적해서, 네임스페이스에 존재하는 `LimitRange`에 정의된 리소스 최소, 최대 및 비율을 초과하지 않는지 확인한다.
- `LimitRange` 제약 조건을 위반하는 리소스(파드, 컨테이너, 퍼시스턴트볼륨클레임)를 생성하거나 업데이트하려고 하면, API 서버에 대한 요청이 실패한다. 이때 HTTP 상태 코드 `403 FORBIDDEN`과 위반한 제약 조건을 설명하는 메시지가 함께 나온다.
- 네임스페이스에 `cpu`, `memory` 같은 컴퓨팅 리소스에 대한 `LimitRange`를 추가한 경우, 사용자는 해당 값에 대한 요청 또는 제한을 지정해야 한다. 지정하지 않으면 시스템이 파드 생성을 거부할 수 있다.
- `LimitRange` 유효성 검사는 파드 어드미션 단계에서만 수행한다. 실행 중인 파드에는 수행하지 않는다.
- `LimitRange`를 추가하거나 수정해도, 해당 네임스페이스에 이미 존재하는 파드는 변경되지 않고 계속 유지된다.
- 네임스페이스에 `LimitRange` 오브젝트가 두 개 이상 있으면, 어떤 기본값이 적용될지는 결정적이지 않다.
