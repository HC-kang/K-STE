* `spec`을 읽어보자. 파드에 대한 API 정의다. 여기에는 컨테이너(파드의 일부)의 정의가 포함되어 있다.
* 다운워드 API를 사용하여 노출할 수 있는 필드 목록을 읽어보자.

레거시 API 레퍼런스에서 볼륨에 대해 읽어본다.
* 컨테이너가 접근할 파드 내의 일반 볼륨을 정의하는 `Volume` API 정의를 확인한다.
* 다운워드 API 정보를 포함하는 볼륨을 정의하는 `DownwardAPIVolumeSource` API 정의를 확인한다.
* 다운워드 API 볼륨 내 파일를 채우기 위한 오브젝트 또는 리소스 필드를 가리키는 레퍼런스를 포함하는 `DownwardAPIVolumeFile` API 정의를 확인한다.
* 컨테이너 리소스와 그 출력 형식을 지정하는 `ResourceFieldSelector` API 정의를 확인한다.
