PR #742 is about the keyboard caption settings feature in the Saeon learning web lecture player. This PR belongs to bundle 5-3.

## Background

The existing caption settings window can only be opened with a mouse. As a result, keyboard users cannot change caption settings.

## Changes

- When the player has focus, pressing the C shortcut opens the caption settings window.
- When the search input field has focus, pressing C enters the letter "c" as usual.

## Scope

- Applies to the web player for recorded lectures.
- Live lectures are excluded.
- The mobile app player is excluded.
