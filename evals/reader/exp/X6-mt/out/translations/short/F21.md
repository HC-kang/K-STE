# Settlement CSV Generator: Remove Duplicate Rows (Moram Payment Batch 5-1, PR #526)

This PR fixes an issue where the settlement CSV generator writes the same transaction row more than once.

## Changes

- The cause is that the same transaction row is appended to the CSV on every retry request.
- This PR changes the logic so that a combination of the same transaction ID and settlement date is treated as a duplicate row.

## Scope

- This change applies only to the domestic KRW settlement CSV.
- The foreign currency CSV is not affected.
- The screen query API is not affected.
