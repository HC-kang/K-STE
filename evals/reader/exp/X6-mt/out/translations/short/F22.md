## Change

Bundle 5-2 of Nubi Warehouse, PR #631, automatically invalidates the previous shipping label when a shipping label is reprinted.

## Cause

Even after a label was reprinted, the previous label was still scanned, so one box was dispatched twice.

## Conditions for Automatic Invalidation

- When a label for the same box of the same order is reprinted, the previous label is invalidated.
- If the order is the same but the box is different, the existing label is kept.

## Verification Location

- Verification is performed in PR #631 of nubi/dispatch and on the verification server stage-pack.
- Do not test on the live dispatch server.

## Required Verification

- 20 cases must be verified in total: 12 reprint cases and 8 different-box cases.
- The results of all 20 cases must be recorded in the PR checklist.
- Verification with a fixed scanner is mandatory.
- Verification with a handheld scanner is optional.
- Photos of the printer's exterior are not required.

## Pass Criteria

Invalidation of the previous label must complete within 3 seconds. If even one case exceeds 3 seconds, the PR must be marked as a merge block.

To confirm: the memo does not specify whether the 3 seconds is measured from the moment the reprint request is made or from the moment the reprinted label starts printing.
