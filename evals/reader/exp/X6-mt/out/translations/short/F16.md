# Daon Payment Net Settlement File Resend Runbook (Batch 4)

## Background

Replacing the Daon Payment Net transmission gateway is expected to delay acknowledgment of receipt for settlement files. This runbook defines the procedure by which the overnight settlement operator resends files whose receipt acknowledgment is delayed.

## Scope

- The applicable work date is 11/12 (Thu).
- The target is the 11/11 (Wed) sales settlement file.
- The work location is the internal operations console "Gyeolbit" > Settlement > Transmission History.

## Roles

| Role | Owner | Responsibility |
|---|---|---|
| Overnight settlement operator | Min Seo-jun | Executes resends and records the work log. |
| On-duty supervisor | Bae Yu-rim | Reviews the work log and marks completion. |

## Procedure

1. Min Seo-jun must check the receipt status of the target file at 01:10 on 11/12 (Thu).
2. Min Seo-jun must handle each file according to its status, as shown in the table below.
3. Min Seo-jun must resend only files that have remained in "Not Received" status continuously for 10 minutes, starting at 01:20.
4. Before resending, Min Seo-jun must confirm that the hash of the original file matches the hash of the archived copy.
5. If the hashes do not match, Min Seo-jun must not resend that file and must report it to Bae Yu-rim.
6. If the file is still "Not Received" after the first resend, Min Seo-jun must perform a second resend 5 minutes later.
7. If the second resend also fails, Min Seo-jun must not transmit that file again.
8. Min Seo-jun must record the resend results and the list of failed files in the Gyeolbit work log by 01:50.
9. Bae Yu-rim must review the work log and mark it complete by 02:00.

### Handling by Status

| File Status | Handling |
|---|---|
| Not Received (sustained for 10 minutes) | Verify the hash, then resend starting at 01:20. |
| Received | No resend needed. A simple status check may be performed. |
| Processing | Do not resend. Bae Yu-rim must be asked to confirm. |

## Resend Limit

- A maximum of 2 resends is allowed per file.
- Files whose second resend has failed must not be transmitted again.

## Recording and Completion Sign-off

- Even if there are no failed files, Min Seo-jun must record "0 failures" in the work log.
- If there are no unresolved files, Bae Yu-rim marks the work as complete.
- If there are unresolved files, Bae Yu-rim must mark "Follow-up action required" instead of completion.
