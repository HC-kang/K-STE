# PR #964: Change to Re-notification Interval for Sensor Disconnection Email Alerts

This PR is part of Daon Sensor batch 5-5. It changes the re-notification interval for sensor disconnection email alerts.

## Background

Repeated short communication drops generate multiple alerts for the same equipment, which has increased customer support inquiries.

## Changes

- Applies to disconnection email alerts for the Standard plan.
- If a sensor stays disconnected, the first email is sent immediately.
- After the first email, re-notifications are sent every 20 minutes.
- Reconnection emails are sent immediately, without waiting.
- Enterprise plan and text message alerts are excluded from this change.
