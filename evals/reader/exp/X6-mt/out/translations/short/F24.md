# Add Automatic Release of Temporary Seat Holds (PR #853)

This PR is part of Haesol Booking bundle 5-4 and adds a task that automatically releases temporary seat holds. Mun Ra-on, the on-duty engineer responsible for running the deployment, will deploy using the procedure below.

## Background

Seat holds remained on booking screens that were closed without payment. As a result, the number of seats available for sale decreased.

## Changes

- Adds an automatic release task.
- The automatic release task runs at 5-minute intervals.
- This PR does not apply to the overseas performance area.

## Release Targets

Releases unpaid temporary holds that are more than 15 minutes past their creation time. Seats with completed payment and seats manually locked by agents are excluded from release.

## Deployment Procedure

1. Before deploying, Mun Ra-on must export the current configuration values.
2. After confirming Han Ji-yul's approval, Mun Ra-on starts the deployment at 09:00 on Thu 12/03 in the domestic performance area of the seat-ops operations console.
3. Mun Ra-on must monitor for the first 30 minutes after deployment.
4. Mun Ra-on must record the observation results in a comment on PR #853 by 10:00 on Thu 12/03.

Monitoring for an additional 30 minutes is optional. The overseas performance area does not require manual checks.

## Stop Condition

**If, during observation, the number of released seats with completed payment is 1 or more, Mun Ra-on must stop the task immediately and contact Han Ji-yul.**
