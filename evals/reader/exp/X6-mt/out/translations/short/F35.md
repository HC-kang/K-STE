Starting with online live courses that begin on 12/14 (Mon), the deadline for submitting course materials is moved up from 1 day before the start to 3 days before. Online instructors and course operations managers at Daonsel Education must check the details below.

## Reason for the Change

Course materials were updated late, which led to cases where outdated files were distributed to students.

## Scope

This applies to instructors and operations managers of online live courses. The existing material registration rules continue to apply to pre-recorded courses.

## Instructor Responsibilities

- Upload the final PDF to the "Distribution Materials" section for each course in the 'Baeumgyeol' system by 18:00, 3 days before the course start date.
- Materials must be one PDF per course, no larger than 20MB.
- If there are multiple documents, the instructor must merge them into a single PDF before uploading.

The submission deadline for the course starting 12/14 (Mon) is 12/11 (Fri) at 18:00.

## Operations Manager Responsibilities

The operations manager must confirm by 12:00, 2 days before the course start, that the file opens correctly and that the course name matches. After confirming, the manager must mark the item as inspection complete in the 'Baeumgyeol' system.

## Corrections After the Submission Deadline

**After the submission deadline, instructors must not replace files themselves.**

To correct content errors, instructors must submit a request through the "Correction Request" menu. Once the operations manager approves the request, the operations manager will replace the file.

If an instructor discovers a content error during class, they may correct it verbally on the spot. Even in this case, the instructor must submit a "Correction Request" within 2 hours after the class ends.

## Reopening the Same Course

If the same course is reopened without any change in materials, the existing file can be reused. In this case, the instructor must click the "Use Existing Materials" button before the submission deadline. There is no need to upload the file again.

## Rule Confirmation

Instructors and operations managers must click the rule confirmation button on the 'Baeumgyeol' notice board by 17:00 on 12/10 (Thu).

## Inquiries

Direct inquiries to Seo Idam in Education Support via the messenger channel "Material Operations Inquiry."
