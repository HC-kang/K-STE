Starting with courses that begin on Mon, 12/14, the deadline for submitting materials for online live courses moves from 1 day before the course start to 3 days before. Instructors had been distributing outdated files to students because course materials were sometimes revised late. This applies to instructors and operations managers of online live courses. The existing material registration rules still apply to pre-recorded courses.

- Instructors must upload the final PDF to the course's 'Distribution Materials' section in the ‘배움결’ system by 18:00, 3 days before the course starts.
- Materials must be one PDF per course, no larger than 20MB. If there are multiple documents, the instructor must merge them into a single PDF before uploading.
- By 12:00, 2 days before the course starts, operations managers must confirm that the file opens and that the course name is correct, then mark it as reviewed in the system.
- After the submission deadline, instructors must not replace files themselves.
- Content corrections after the submission deadline are submitted through the 'Revision Request' menu. After an operations manager approves the request, the operations manager replaces the file.
- If an instructor finds a content error during class, the instructor may correct it verbally right away. Even in this case, a 'Revision Request' must still be submitted within 2 hours after the class ends.
- When reopening the same course without changing the materials, the existing file may be reused. In this case, the instructor must click the 'Use Existing Materials' button before the submission deadline and does not need to upload the file again.

Instructors and operations managers must click the confirmation button in the rules notice on ‘배움결’ by 17:00 on Thu, 12/10. For questions, message Seo Idam in Education Support via the ‘자료운영문의’ messenger channel.
