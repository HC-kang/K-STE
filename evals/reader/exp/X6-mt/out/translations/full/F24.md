# Auto-Release of Temporary Seat Holds (PR #853)

PR #853 in the Haesol Booking bundle 5-4 adds automatic release of temporary seat holds. Seats held on booking screens that were closed without payment were not being freed, which reduced the number of seats available for sale. This PR does not apply to the overseas performance area.

## Changes

- Release target: unpaid temporary holds created 15 or more minutes ago
- Release exclusions: seats with completed payment, seats manually locked by agents
- Interval for the automatic release job: 5 minutes
- Review location: PR #853 in haesol/booking
- Deployment location: domestic performance area in the seat-ops operations console

## Execution Procedure

All of steps 1–5 below must be completed.

1. Before starting deployment on 12/03 (Thu) at 09:00, export the current configuration values.
2. After receiving approval from Han Jiyul, start deployment in the domestic performance area of the seat-ops operations console at 12/03 (Thu) 09:00.
3. Observe for the first 30 minutes after deployment.
4. If, during observation, the number of released seats with completed payment is 1 or more, stop the job immediately and contact Han Jiyul.
5. Record the observation results in the PR comments by 12/03 (Thu) 10:00.
