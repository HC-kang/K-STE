# PR #742: Keyboard Caption Settings for Web Lecture Player

Saeon Learning bundle 5-3's PR #742 adds a keyboard-accessible caption settings feature to the web lecture player. The existing caption settings dialog could only be opened with a mouse, so keyboard users could not change their caption settings. Min Yeoul is the implementer, and Jung I-deun is the required accessibility approver. Jo Ha-rin handles translation inquiries only.

## Changes

- Shortcut key C opens the caption settings dialog only when focus is in the player.
- When focus is in the search input field, typing the letter "c" continues to enter text as usual.

## Scope

This feature applies to the web player for recorded lectures. Live lectures and the mobile app player are excluded.
