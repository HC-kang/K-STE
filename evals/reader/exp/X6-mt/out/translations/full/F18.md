# Sandsnail Studio Online Concert Backup Line Switchover Runbook

The main line equipment is being inspected, so there is a possibility that the broadcast could be interrupted during the online concert. A backup line is being prepared. This document summarizes the switchover criteria and procedures that the broadcast engineer Yun Taerim, the audio engineer Seo Gaon, and the on-site manager Mun Haesol will follow on site.

## Scope

- Concert: Friday, 11/27, 19:30–21:00
- Work location: Broadcast room, 3rd floor, headquarters
- Operating console: Byeolsong

## Roles

- Yun Taerim (primary broadcast engineer): Executes the line switchover.
- Seo Gaon (audio engineer): Checks the audio after the switchover.
- Mun Haesol (on-site manager): Decides whether to stop the concert broadcast.

## Preparation

1. Yun Taerim must complete the backup line connection test by 19:00.
2. Test video must be verified only through the internal preview. Test video must not be broadcast to the viewer channel.
3. The main line automatic return function must remain disabled throughout the concert.

## Switchover Criteria

- If the main line loss rate is 3% or higher and is sustained for 20 consecutive seconds, the switchover to the backup line must be performed without separate approval from Mun Haesol.
- If the main line loss rate is below 3%, no switchover is required.
- If the main line loss rate is 3% or higher but the duration is less than 20 seconds, no switchover is required.
- Even when no switchover is performed, the internal preview may still be checked.

## Switchover Procedure

1. If the main line loss rate is 3% or higher and is sustained for 20 consecutive seconds, Yun Taerim switches to the backup line on Byeolsong.
2. Within 40 seconds after executing the switchover, Seo Gaon records the audio check result in the Byeolsong work window.
3. If there is any audio problem, report it to Mun Haesol immediately.

## When Loss Continues on the Backup Line

If the loss rate of 3% or higher is sustained for 20 consecutive seconds on the backup line, Yun Taerim must broadcast the standby screen. Only Mun Haesol may decide whether to stop the concert broadcast.

## Prohibition on Returning to the Main Line

Even if the main line appears to be free of problems, it must not be manually restored before the concert ends.

## Post-Concert Submission

- Yun Taerim must submit the switchover time and loss rate records by 21:20.
- If no switchover occurred, submit "No switchover."

- Line inquiries: Mun Haesol, extension 6134
- Audio inquiries: Seo Gaon, extension 6139
