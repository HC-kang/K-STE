# PR #964: Change to Resend Interval for Sensor Disconnection Alerts (Batch 5-5)

We are changing the resend interval for sensor disconnection email alerts in Daon Sensor's factory monitoring product. This PR is in daon/alerts, and the customer support release reviewer must post verification results in the PR comments by Wednesday, 12/09, 16:00.

## Background

Repeated short communication dropouts piled up alerts for the same equipment, which increased customer support inquiries.

## Change Details

If a sensor's disconnection continues, the first email is sent immediately, and subsequent emails are resent at 20-minute intervals. The reconnection email is sent immediately without any delay.

## Scope

- Applies to: Email disconnection alerts for the Standard plan
- Excluded: Enterprise plan, SMS alerts
