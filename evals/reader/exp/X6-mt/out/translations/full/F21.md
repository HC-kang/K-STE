# PR #526: Removing Duplicate Rows in the Settlement CSV Generator

PR #526 in Moram Payments bundle 5-1 removes duplicate rows from the settlement CSV generator. A problem existed where the same transaction row was appended to the CSV on every retry request. This PR changes the logic to identify duplicates by the combination of transaction ID and settlement date. The author is Seo Dabin.

## Scope of Changes

- Only the domestic KRW settlement CSV is changed.
- The foreign currency CSV is not changed.
- The screen inquiry API is not changed.
