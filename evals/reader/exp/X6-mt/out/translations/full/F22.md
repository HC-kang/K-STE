# PR #631 Automatic Invalidation of Previous Shipping Labels on Reprint

Under Nubi Warehouse Bundle 5-2, PR #631 automatically invalidates the previous label when a shipping label is reprinted. Until now, the previous label could still be scanned after reprinting, so a single box was processed for shipment twice. This PR will be verified by the shipping system QA owner.

## Conditions for Automatic Invalidation

- When a label for the same box in the same order is reprinted, the previous label is automatically invalidated.
- If the order is the same but the box is different, the existing label is retained.
