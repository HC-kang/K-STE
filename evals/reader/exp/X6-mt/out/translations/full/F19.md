# Nuridam Rental Duplicate Exchange Order Handling Runbook (Bundle 4)

Retry errors in the customer app caused exchange orders for the same product to be created in duplicate. This runbook defines how customer service exchange-intake agents cancel duplicate exchange orders in the order system "Dam Order" or hand them off to logistics staff.

## Scope

- The application period runs from 09:00 on 12/03 (Thu) to 18:00 on 12/04 (Fri).
- The target audience is customer service exchange-intake agents.
- The working system is Dam Order.

## Review Criteria

- If two or more exchange orders with the same contract number, same product number, and same return address are created within 30 minutes, they are subject to duplicate review.
- If any one of the three pieces of information differs, normal intake must be maintained.
- Orders created more than 30 minutes apart cannot be handled under this duplicate cancellation procedure. Agents must not cancel these orders arbitrarily and must maintain normal intake.

## Procedure

1. In Dam Order, search for exchange orders and find the orders subject to duplicate review that meet the above criteria.
2. First, check the shipment status of the orders subject to review.
3. If all orders subject to review are "Before shipment," keep the first order and cancel the rest. Select cancellation reason code D14.
4. If cancellation was performed in step 3, record the retained order number in the order memo.
5. If even one order subject to review has "Shipped" status, the agent must not cancel it. Hand it off to logistics manager Ko Do-yun.
6. If a handoff was performed in step 5, record the logistics handoff number in the order memo.
7. After canceling the duplicate orders, send a notification text message to the customer.

## Common Rules

- Agents must cancel or hand off to logistics within 20 minutes of discovering a review target.
- Reason code D14 must be used for duplicate cancellations. Reason code D41 for customer change-of-mind cancellations must not be used.
- Agents do not need to call the customer before cancellation.
- If the customer requests it, cancellation details may additionally be sent by email. Regardless of whether an email is sent, the notification text message must be sent.

## Inspection and Inquiries

- Exchange team leader Jo Se-rin reviews the processing list daily by 18:30.
- Inquiries about standard criteria go to Jo Se-rin (ext. 7240).
- Inquiries about shipment status errors go to Ko Do-yun (ext. 7246).
