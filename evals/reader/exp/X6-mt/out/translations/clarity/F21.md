# [Bundle 5-1] Fix Duplicate Row Removal in Settlement CSV Generator (PR #526)

## Summary
Fixes an issue where identical transaction rows were output duplicated in the settlement CSV generator. The duplicate-detection criterion has been changed to the **combination of transaction ID + settlement date**.

## Cause
Each retry request was appending the same transaction row to the CSV again.

## Changes
- Rows where both the transaction ID and settlement date match are treated as duplicates, and only one is kept.

## Scope of Application
| Category | Applied |
|---|---|
| Domestic KRW settlement CSV | Applied |
| Overseas currency settlement CSV | Excluded from changes |
| Screen lookup API | Excluded from changes |
