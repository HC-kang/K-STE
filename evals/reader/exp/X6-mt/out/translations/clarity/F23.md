# PR #742: Keyboard Caption Settings for Web Lecture Player

**Service/Bundle**: Saeon Learning / Bundle 5-3
**Repository**: saeon/player

## Background
The existing caption settings window can only be opened with a mouse. As a result, keyboard users cannot change caption settings. This PR lets users open and operate the caption settings window using only the keyboard.

## Changes
- When the player has focus, pressing the **C** shortcut opens the caption settings window.
- When focus is in the search input field, the shortcut does not work, and the character `c` is typed as usual.

## Scope
- **Included**: Recorded lecture web player
- **Excluded**: Live lectures, mobile app player
