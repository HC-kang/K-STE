# PR #853: Add Automatic Release of Temporary Seat Holds

**Company**: Haesol Booking · **Batch**: 5-4 · **Review location**: haesol/booking PR #853

## Background
Temporary seat holds on booking screens that were closed without payment are not released and remain in place. This reduces the number of seats available for sale. This PR adds a job that automatically releases unpaid temporary holds.

## Changes
- The automatic release job runs at **5-minute intervals**.
- **Release target**: Unpaid temporary holds that are 15 minutes or more past their creation time.
- **Release exclusions**: Seats with completed payment, and seats manually locked by agents.
- **Scope**: Applies only to the domestic performance area. **Not applied to the overseas performance area.**
