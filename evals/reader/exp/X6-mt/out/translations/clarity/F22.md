# PR #631: Automatic Invalidation of Previous Shipping Labels on Reprint

- Company/Group: Nubi Warehouse / Group 5-2
- Repository: nubi/dispatch

## Background and Cause
Even after a shipping label was reprinted, the previous label could still be scanned, causing a single box to be dispatched twice.

## Changes
When a label is reprinted, the previous label is automatically invalidated.

| Category | Behavior |
|---|---|
| Reprinting the label for the same box in the same order | Previous label is automatically invalidated |
| Label for a different box in the same order | Existing label is kept (not invalidated) |
