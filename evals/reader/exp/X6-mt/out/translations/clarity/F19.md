# Duplicate Exchange Order Handling Runbook (Batch 4 / Nurissam Rental)

## 1. Overview
- **Target**: Exchange intake agents at the Nurissam Rental customer service center
- **System**: Order system "Dam Order" (담주문)
- **Effective period**: 12/03 (Thu) 09:00 ~ 12/04 (Fri) 18:00
- **Background**: Due to a customer app retry error, duplicate exchange orders for the same product were being created. This runbook describes the procedure for handling these duplicate orders.

## 2. Determining Duplicate Review Targets
If **all three of the following pieces of information are identical** and **2 or more** exchange orders were created **within 30 minutes**, they are subject to duplicate review.

1. Contract number
2. Product number
3. Collection address

| Situation | Action |
|---|---|
| All three match and 2+ orders created within 30 minutes | Duplicate review target → proceed to Section 3 |
| Any one of the three differs | Maintain regular intake |
| Orders created more than 30 minutes apart | This duplicate cancellation procedure does not apply. Do not cancel arbitrarily; maintain regular intake |

## 3. Processing Procedure
**Complete agent processing or logistics transfer within 20 minutes of discovering the review target.**

### Step 1: Check Shipping Status
First, check the shipping status of all orders under review.

### Step 2: Branch by Status

**A. If all are "Not yet shipped" (agent processing)**
1. Keep the first-created order (1 order).
2. Cancel all other orders. (Required)
3. Use cancellation reason code **D14 (Duplicate)**.
4. Record the **retained order number** in the order memo.

**B. If at least one order is "Shipped" (logistics transfer)**
1. The agent does **not cancel any orders.** (Cancellation prohibited)
2. Transfer to logistics manager **Ko Doyun**. (Required)
3. Record the **logistics transfer number** in the order memo.

### Step 3: Customer Notification
- There is no need to call the customer before cancellation.
- A notification text message **must be sent** after processing.
- If the customer requests it, the cancellation details can additionally be sent by email. Regardless of whether an email is sent, the notification text message must always be sent.

## 4. Code and Record Standards
| Item | Standard |
|---|---|
| Duplicate cancellation reason code | **D14** |
| Prohibited code | **D41** (customer change-of-mind cancellation) |
| Order memo | Retained order number (A) or logistics transfer number (B) |

## 5. Review and Inquiries
- **Processing list review**: Consultation leader Jo Serin reviews daily by 18:30.
- **Standards inquiries**: Jo Serin (ext. 7240)
- **Shipping status error inquiries**: Ko Doyun (ext. 7246)

## 6. Pre-Processing Checklist
- [ ] Are the contract number, product number, and collection address all identical?
- [ ] Were the orders created within 30 minutes?
- [ ] Have you checked the shipping status of all orders under review?
- [ ] If all are "Not yet shipped," did you keep only the first order and cancel the rest with D14?
- [ ] If at least one is "Shipped," did you refrain from cancelling and transfer to Ko Doyun?
- [ ] Did you complete processing within 20 minutes of discovery?
- [ ] Did you record the retained order number or logistics transfer number in the order memo?
- [ ] Did you send the notification text message after processing?
