# PR #742: Keyboard Caption Settings Feature for Web Lecture Player

**Company/Group:** Saeon Learning / Group 5-3
**Target Reviewer:** Accessibility Reviewer (required approval: Jung Ideun)

## Background and Cause
The existing caption settings window could only be opened with a mouse, so keyboard users were unable to change caption settings. This PR improves the feature so that the caption settings window can be opened and operated using the keyboard alone.

## Changes
- Open the caption settings window with the **C** shortcut key
  - Works only when focus is on the player.
  - When focus is in the search input field, the shortcut does not trigger and the character `c` is entered as typed.

## Scope
- **Included:** Recorded lecture web player
- **Excluded:** Live lectures, mobile app player
