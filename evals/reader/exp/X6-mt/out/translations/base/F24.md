# PR #853: Add Automatic Release of Temporary Seat Holds

## Overview
- **Company/Batch**: Haesol Booking / Batch 5-4
- **Summary**: Adds a job that automatically releases temporary seat holds left behind on booking screens closed without payment.
- **Cause**: Seat holds remaining on booking screens closed without payment reduce the number of seats available for sale.

## Behavior Changes
- **Release target**: Unpaid temporary holds created 15 or more minutes ago
- **Exclusions**: Seats with completed payment, seats manually locked by agents
- **Run interval**: 5 minutes
- **Scope**: Domestic performance area only. This PR does not apply to the overseas performance area.
