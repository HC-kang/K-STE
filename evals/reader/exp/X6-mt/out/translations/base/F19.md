# Duplicate Exchange Order Handling Runbook (Nuridam Rental Customer Center)

**Target:** Exchange reception agents
**System:** Order system "Damjumun"
**Effective period:** 12/03 (Thu) 09:00 ~ 12/04 (Fri) 18:00

## 1. Background
Due to retry errors in the customer app, exchange orders for the same product are being created in duplicate. Follow the procedure below to identify and handle duplicate orders.

## 2. Determining Duplicate Review Targets

An order is a duplicate review target if **all three of the following are identical** and **2 or more exchange orders** were created **within 30 minutes**.

| Check Item | Criteria |
|---|---|
| Contract number | Identical |
| Product number | Identical |
| Return address | Identical |
| Creation time | Within 30 minutes |

- If **any one** of the three pieces of information differs, it is not a duplicate review target, and **normal reception is maintained**.
- Orders created **more than** 30 minutes apart are not eligible for this procedure. Do not cancel them arbitrarily; **maintain normal reception**.

## 3. Processing Procedure

**Deadline: Process or transfer within 20 minutes of discovering a review target**

1. **Check shipment status:** First, check the shipment status of all orders under review.
2. Branch based on the result.

### A. If all are "Not yet shipped" (agent handles directly)
1. **Keep the first-created order** (1 order).
2. **Cancel all other orders.** (Cancellation is mandatory)
3. Use cancellation reason code **D14 (Duplicate cancellation)**.
4. Record the **retained order number** in the order memo.
5. After processing, **send a notification text message** to the customer.

### B. If at least one order is "Shipped" (logistics transfer)
1. **Agents do not cancel.** (Cancellation prohibited)
2. **Transfer to logistics manager Ko Doyun.** (Transfer is mandatory)
3. Record the **logistics transfer number** in the order memo.
4. After transfer, **send a notification text message** to the customer.

## 4. Customer Notification
- There is **no need** to call the customer before cancellation.
- Sending a **notification text message after processing is mandatory**.
- If the customer requests it, a **cancellation details email** can be additionally sent.
- Regardless of whether an email is sent, the **notification text message must always be sent**.

## 5. Input Rules

| Item | Rule |
|---|---|
| Duplicate cancellation reason code | **D14** |
| Customer change-of-mind cancellation code | **Do not use D41** |
| Order memo | Record retained order number or logistics transfer number |

## 7. Processing Checklist
- [ ] Are the contract number, product number, and return address all identical?
- [ ] Is the creation time within 30 minutes?
- [ ] Was the shipment status of all orders under review checked?
- [ ] If all are "Not yet shipped," was only the first order retained and the rest cancelled with D14?
- [ ] If any are "Shipped," was the order not cancelled and was it transferred to Ko Doyun?
- [ ] Was the retained order number or logistics transfer number recorded in the order memo?
- [ ] Was processing or transfer completed within 20 minutes of discovery?
- [ ] Was the notification text message sent?
