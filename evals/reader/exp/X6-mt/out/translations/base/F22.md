# PR #631: Automatically Invalidate Previous Shipping Labels on Reprint

## Background and Cause
Previous shipping labels continued to be scanned even after the shipping label was reprinted, so a single box could be shipped twice. This PR automatically invalidates the previous label when reprinting to prevent duplicate shipments.

## Changes
- **Applicable condition:** When the label for the **same box** of the **same order** is reprinted, the previous label is automatically invalidated.
- **Exclusion:** If the order is the same but the **box is different**, the existing label is kept.
