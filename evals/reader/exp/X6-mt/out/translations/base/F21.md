# PR #526: Remove Duplicate Rows in Settlement CSV Generator

**Company/Group:** Moram Payments / Group 5-1
**Repository:** Internal code repository `moram/settlement` PR #526
**Author:** Seo Dabin

## Overview
Fixes an issue where the same transaction was output as duplicate rows in the settlement CSV generator.

## Cause
Each retry request was appending the same transaction row to the CSV.

## Changes
- Changed duplicate detection to be based on the combination of transaction ID and settlement date.
- Rows with the same combination are output only once.

## Scope
| Category | Applied |
|---|---|
| Domestic KRW settlement CSV | Applied |
| Overseas currency CSV | Excluded from changes |
| Screen lookup API | Excluded from changes |
