# 분류기 장애 대응 회의록

푸른톱니물류 분류기 장애 대응 회의의 결정 사항을 센터별 설비 담당자용으로 정리한다. 회의 주재자는 설비지원팀장 윤해온이다. 센서 점검 기준, 일정, 문의처를 아래에 쓴다.

## 점검 기준

- 각 센터 설비 담당자는 분류기 1대당 센서 4개를 점검해야 한다.
- 각 센터 설비 담당자는 센터별 예비 센서 7개를 유지해야 한다.
- 각 센터 설비 담당자는 센서 점검표를 사내 시스템 ‘톱니함’의 센서점검함에 등록해야 한다.
- 점검 대상은 자동 분류기만이다. 수동 분류대는 점검 대상에서 제외한다.

## 일정과 담당

| 일정 | 구분 | 내용 | 담당 | 장소 |
|---|---|---|---|---|
| 12/4(금) | 실행일 | 장애 기록 읽기 교육을 한다. | 설비지원팀 민채록 | 중앙센터 3층 강의실 |
| 12/8(화) | 확인 필요 | 센서 점검표를 등록한다. | 각 센터 설비 담당자 | 톱니함 센서점검함 |
| 12/11(금) | 기한 | 교체 공구 대여를 신청한다. 12/11(금)이 마감이다. | 각 센터 설비 담당자 | |
| 12/16(수) | 확인 필요 | 분류기 멈춤 사고 원인 분석 보고서를 공유한다. | 설비지원팀 민채록 | |
| 12/21(월) 09:00 | 실행일 | 복구 모의훈련을 시작한다. | 설비지원팀 서도율 | 중앙센터 1층 훈련장 |
| 12/24(목) | 기한 | 예비 센서 수량을 보고한다. 12/24(목)까지 보고해야 한다. | 각 센터 설비 담당자 | |

확인 필요: 센서 점검표 등록 12/8(화). 12/8(화)에 등록하는 실행일인지, 12/8(화)까지 등록을 끝내는 기한인지.

확인 필요: 원인 분석 보고서 공유 12/16(수). 12/16(수)에 공유하는 실행일인지, 12/16(수)까지 공유를 끝내는 기한인지.

## 문의처

분류기 오류 문의처는 설비지원팀 서도율, 내선 581이다.
