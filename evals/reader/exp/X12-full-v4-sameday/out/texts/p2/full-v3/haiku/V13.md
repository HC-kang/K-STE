# 누리결제 PR #501: 중복 결제 요청 차단 로직 추가

이 PR은 결제 생성 API에 중복 결제 요청을 차단하는 로직을 추가한다. 동일 요청 키는 30분 동안 보관하며, 보관 시간 안에 들어온 중복 요청에는 기존 결제 결과를 반환한다. 결제 취소 API는 이번 변경 대상이 아니다.

## 변경 범위

- 변경 대상: 결제 생성 API
- 변경 대상이 아님: 결제 취소 API
- 동일 요청 키 보관 시간: 30분
- 보관 시간 안의 중복 요청에는 기존 결제 결과를 반환한다.

확인 필요: 동일 요청 키 보관 시간 30분. 보관 기산점이 최초 요청 시점인지 마지막 요청 시점인지 원문에 없다.
