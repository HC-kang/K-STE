# PR #503: 학습 기록 동기화 재시도 로직 수정

이 PR은 학습 기록 동기화의 재시도 로직을 수정한다. 자동 재시도는 연결 끊김 오류에만 적용되고, 인증 오류는 재시도하지 않고 고객지원 대기열로 이동한다.

## 변경 내용

- 자동 재시도는 연결 끊김 오류에만 적용한다.
- 자동 재시도 횟수는 최대 3회로 하고, 시도 사이 대기 시간은 8초로 한다.
- 인증 오류는 재시도하지 않고 고객지원 대기열로 이동한다.

| 12/21(월) 11:00에 | 오지완 | 로그 검색 시연 |
| 12/22(화) | 차유림 | 오류 분류표 등록 |

| 12/31(목) 마감 | 차유림 | 고객지원 검토 의견 접수 |

확인 필요: 12/22(화) 등록, 12/23(수) 실시, 12/29(화) 공유. 각 날짜가 그날 하는 일인지, 그날까지 끝낼 일인지 확인해야 한다.

## 오류 분류표 기재 기준

차유림은 오류 분류표에 오류 코드와 상담 분류를 반드시 기재해야 한다. 분류표 등록 위치는 저장소 PR 첨부 파일이다.
