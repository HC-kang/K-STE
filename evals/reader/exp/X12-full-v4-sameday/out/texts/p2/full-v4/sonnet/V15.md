# PR #503 학습 기록 동기화 재시도 로직 수정

별담교육 PR #503은 학습 기록 동기화의 재시도 로직을 수정한다. 자동 재시도는 연결 끊김 오류에서만 실행하고, 인증 오류는 재시도 없이 고객지원 대기열로 보낸다. 이 PR을 읽는 SRE와 고객지원 담당자는 아래 일정과 담당을 따라야 한다.

## 변경 내용

- 자동 재시도는 연결 끊김 오류에서만 실행한다.
- 자동 재시도는 최대 3회까지 시도하고, 시도 사이 대기 시간은 8초다.
- 인증 오류는 재시도 없이 고객지원 대기열로 이동한다.

## 복구 시험 규칙

- 복구 시험은 별담교육 스테이징 학습실에서만 해도 된다.
- 운영 학습실에서는 시험을 하면 안 된다.

## 오류 분류표

- 등록 위치는 저장소 PR 첨부 파일이다.
- 고객지원 담당 차유림은 오류 코드와 상담 분류를 반드시 기재해야 한다.
