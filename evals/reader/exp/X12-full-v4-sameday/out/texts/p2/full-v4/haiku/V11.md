# 모루방송 영상 송출 야간 당직 운영 절차 (런북 4-2)

이 문서는 모루방송 영상 송출 야간 당직자가 송출 지연과 회선 이상 때 따를 절차를 정한다. 장애 등록은 '파형'의 야간 송출 메뉴에서 하며, 등록 담당은 회선을 맡은 야간 당직자다.

## 1. 일정

| 일자 | 내용 | 구분 |
|---|---|---|
| 11/17(화)까지 | 개인별 비상 연락처 입력 | 기한 |
| 11/24(화) 22:00에 | 회선 담당 배소운의 예비 회선 점검 | 실행일 |
| 12/1(화) 18:00 | 야간 당직자별 교육용 계정 신청 마감 | 기한 |
| 12/3(목) | 원인 분석 보고서 공유 | 확인 필요 |
| 12/8(화) | 백업 회선 접속 시험 기록 등록 | 확인 필요 |
| 12/11(금) 21:00 | 교육 담당 조나겸의 장애 등록 교육 시작 | 실행일 |

확인 필요: 원인 분석 보고서 공유, 12/3(목). 12/3에 공유하는 것인지, 12/3까지 공유를 끝내는 것인지.
확인 필요: 백업 회선 접속 시험 기록 등록, 12/8(화). 12/8에 등록하는 것인지, 12/8까지 등록을 끝내는 것인지.

## 2. 송출 지연 시 장애 등록

1. 송출 지연이 8초 이상이면 야간 당직자는 '파형'의 야간 송출 메뉴에서 장애를 등록해야 한다.
2. 야간 당직자는 장애 등록 시 지연 측정값 3개를 첨부해야 한다.
3. 장애 화면 이미지에 시청자 식별값이 보이면 야간 당직자는 그 식별값을 가려야 한다.
4. 장애 화면 이미지에 시청자 식별값이 없으면 야간 당직자는 원본 이미지를 첨부해야 한다.

## 3. 회선 신호에 따른 재접속

1. 회선 신호가 정상인 경우 야간 당직자는 재접속을 1회만 해야 한다.
2. 회선 신호가 없는 경우 야간 당직자는 재접속하면 안 된다.
3. 회선 신호가 없는 경우 야간 당직자는 회선 담당 배소운을 호출해야 한다.

확인 필요: 회선 신호가 정상인 경우. 정상으로 판단하는 기준이 원문에 없다.

## 4. 교육과 계정

야간 당직자는 11/17(화)까지 개인별 비상 연락처를 입력해야 한다. 야간 당직자별 교육용 계정 신청 마감은 12/1(화) 18:00이다. 교육 담당 조나겸이 12/11(금) 21:00 장애 등록 교육을 시작한다.

## 5. 문의

절차 문의 창구는 교육 담당 조나겸과 사내 메신저 '야간송출지원' 채널이다.
