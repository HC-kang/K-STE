# 누리결제 PR #501: 중복 결제 요청 차단 로직 추가

이 PR은 결제 생성 API에 중복 결제 요청을 차단하는 로직을 추가한다. 변경 대상은 결제 생성 API이며, 결제 취소 API는 변경 대상이 아니다.

## 중복 요청 차단 방식

동일 요청 키는 30분 동안 보관한다. 보관 시간 안에 들어온 중복 요청에는 기존 결제 결과를 반환한다.

## 오류 응답 코드

오류 응답 코드 채택안은 한서율이 11/12(목)에 승인했다.

## 일정

- 리뷰어 민하준의 코드 검토는 11/9(월)에 시작한다.
- 개발자 윤다솔은 11/18(수) 10:00에 테스트 결제 시연을 한다.
- 개발자 윤다솔은 11/24(화)까지 회귀 테스트 결과를 PR 첨부 파일로 제출해야 한다.
- 민하준의 병합 반대 의견 접수는 11/27(금)에 마감한다.

## 검토 의견 등록

리뷰어 민하준은 검토 의견을 저장소 PR 댓글로 등록해야 한다.

## 테스트 조건

테스트 결제 금액은 건당 700원으로 한다. 운영 결제 데이터를 사용하면 안 된다.

## 병합 조건

자동 테스트가 통과한 경우에만 병합해도 된다. 실패 항목이 있으면 병합하면 안 된다.

## 문의

문의 담당자는 한서율이다. 문의는 사내 메신저 #결제개발 채널을 이용한다.
