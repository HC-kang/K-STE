# 누리결제 PR #501: 중복 결제 요청 차단 로직 추가

이 PR은 결제 생성 API에 중복 결제 요청 차단 로직을 추가한다. 결제 취소 API는 변경 대상이 아니다.

## 변경 내용

- 동일 요청 키는 30분 동안 보관한다.
- 30분 안에 같은 요청 키로 중복 요청이 들어오면 기존 결제 결과를 반환한다.

## 테스트

- 윤다솔이 11/18(수) 10:00에 테스트 결제를 시연한다.
- 테스트 결제 금액은 건당 700원이다.
- 테스트에 운영 결제 데이터를 사용하면 안 된다.

## 일정

| 날짜 | 구분 | 내용 |
|---|---|---|
| 11/9(월) | 실행일 | 민하준이 코드 검토를 시작한다 |
| 11/12(목) | 확인 필요 | 한서율이 오류 응답 코드 채택안을 승인한다 |
| 11/18(수) 10:00 | 실행일 | 윤다솔이 테스트 결제를 시연한다 |
| 11/24(화) | 기한 | 윤다솔이 회귀 테스트 결과를 PR 첨부 파일로 제출한다 |
| 11/27(금) | 마감일 | 민하준의 병합 반대 의견 접수가 마감된다 |

## 리뷰와 병합

- 민하준은 검토 의견을 저장소 PR 댓글로 등록해야 한다.
- 윤다솔은 자동 테스트를 통과한 경우에만 병합해도 된다.
- 윤다솔은 자동 테스트에 실패 항목이 있으면 병합하면 안 된다.

## 문의

문의 담당은 한서율이다. 사내 메신저 #결제개발 채널을 이용한다.

확인 필요: 11/12(목) 한서율 승인. 11/12(목)에 승인하는 것인지, 11/12(목)까지 승인해야 하는 것인지.
확인 필요: 민하준의 병합 반대 의견 접수. 민하준이 의견을 내는 것인지, 민하준이 의견을 받는 것인지.
