# 누리펄스 캐시 전환 런북

이 문서는 운영 절차 묶음 4의 누리펄스 캐시 전환 런북이다. 야간 서비스 운영 당직자가 11/12(목) 23:10에 시작하는 검색 캐시와 추천 캐시 전환 작업에 사용한다. 캐시 갱신 지연으로 검색 결과 누락이 발생했다.

## 작업 개요

- 작업 시간: 11/12(목) 23:10 시작, 23:40 종료
- 실행 담당: 야간 당직자 문세린
- 작업 대상: 검색 캐시, 추천 캐시
- 작업 위치: 사내 운영 포털의 검색 탭, 추천 탭 각각
- 사내 메신저 대기: 제품 관리자 나도윤, 프로젝트 관리자 서이안
- 장애 연락처: 플랫폼지원팀 윤하민, 내선 4726
- 작업 기록 저장 위치: 사내 운영 포털의 야간 작업함

## 준수 사항

- 나도윤과 서이안은 작업 시간 동안 두 사람 모두 사내 메신저에서 대기해야 한다.
- 문세린의 승인 없이 서버를 재시작하면 안 된다.
- 캐시 복원 작업에는 실행 화면을 1개만 사용해야 한다. 정식 화면명은 복원 제어판이다.
- 전환 완료 보고서를 PM에게 전달하기 전에는 당직 교대를 하면 안 된다.

## 서버 상태 조회

검색 로그 서버와 추천 로그 서버는 별도 장비다. 두 서버의 상태는 사내 운영 포털의 장비 탭에서 조회할 수 있다.

## 절차

1. 11/12(목) 23:10에 작업을 시작한다.
2. 검색 캐시와 추천 캐시 모두 전환 전 오류율을 5분간 측정해 작업 기록에 남겨야 한다.
3. 문세린이 23:20에 복원 제어판에서 복원 지점 2개를 등록한다.
4. 되돌림 데스크에 문세린이 23:20에 등록한 복원 지점 2개가 보이는지 표시 개수를 대조한다.
5. 전환 직전에 스냅샷 1개를 추가로 저장해야 한다.
6. 사내 운영 포털의 검색 탭에서 검색 캐시를, 추천 탭에서 추천 캐시를 전환한다.
7. 전환 후 오류율을 조회한다.
8. 전환 후 오류율이 2% 초과이면 즉시 복원해야 한다.
9. 전환 후 오류율이 2% 이하이면 복원하지 않고 관찰을 유지해야 한다.
10. 전환 완료 보고서를 PM에게 전달한다.
11. 작업 기록을 사내 운영 포털의 야간 작업함에 저장한다.

## 이상 발생 시

오류율을 조회할 수 없거나 복원에 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.

## 후속 점검

후속 점검은 11/13(금) 09:00에 한다.

확인 필요: 전환 직전 스냅샷 1개 추가 저장. 검색 캐시와 추천 캐시 각각 1개인지, 두 캐시를 합쳐 1개인지.
확인 필요: 되돌림 데스크. 복원 제어판과 같은 화면인지, 다른 화면인지.
확인 필요: 전환 후 오류율 2% 기준. 검색 캐시와 추천 캐시 각각에 적용하는지, 두 캐시를 합친 값에 적용하는지.
