# 누리펄스 캐시 전환 런북

이 런북은 11/12(목) 23:10부터 23:40까지 진행하는 누리펄스 검색 캐시와 추천 캐시 전환 작업의 절차를 정한다. 실행 담당은 야간 당직자 문세린이다. 주요 위험은 캐시 갱신 지연으로 인한 검색 결과 누락이다. 전환 전후 오류율을 기록하고, 전환 후 오류율이 2%를 넘으면 복원 지점으로 즉시 되돌려야 한다.

## 1. 작업 개요

- 작업 일시: 11/12(목) 23:10 시작, 23:40 종료
- 실행 담당: 야간 당직자 문세린
- 작업 대상: 검색 캐시, 추천 캐시
- 작업 위치: 사내 운영 포털의 검색 탭과 추천 탭 각각
- 주요 위험: 캐시 갱신 지연으로 인한 검색 결과 누락

## 2. 대기와 보고 체계

- 제품 관리자 나도윤과 프로젝트 관리자 서이안은 작업 시간 동안 모두 사내 메신저에서 대기해야 한다.
- 전환 완료 보고서는 PM에게 전달해야 한다. 보고서를 전달하기 전에는 당직을 교대하면 안 된다.
- 확인 필요: PM. 프로젝트 관리자 서이안을 가리키는 경우와 제품 관리자 나도윤을 가리키는 경우.

## 3. 전환 전 준비

1. 검색 캐시와 추천 캐시 각각의 전환 전 오류율을 5분간 측정하고, 측정값을 작업 기록에 남긴다.
   확인 필요: 전환 전 5분 측정의 시작 시점. 23:10 이전에 측정하는 경우와 23:10 이후 전환 직전에 측정하는 경우.
2. 전환 직전에 스냅샷을 1개 추가로 저장해야 한다.
3. 검색 로그 서버와 추천 로그 서버는 별도 장비이므로, 두 서버의 상태를 운영 포털의 장비 탭에서 각각 조회한다.
4. 서버 재시작은 문세린의 승인을 받은 후에만 진행해야 한다.

**경고**: 승인 없이 서버를 재시작하면 안 된다.

## 4. 전환 실행

1. 23:10에 캐시 전환 작업을 시작한다.
2. 23:20에 문세린이 복원 제어판에서 복원 지점 2개를 등록한다. 복원 작업의 실행 화면은 복원 제어판 1개만 사용해야 한다.
3. 되돌림 데스크에 23:20에 등록한 복원 지점 2개가 표시되는지 확인하는 대신, 표시 개수를 2개와 대조해야 한다.
4. 23:40에 작업을 종료한다.

## 5. 전환 후 점검과 판단

1. 전환 후 오류율을 측정하고 기록한다.
   확인 필요: 전환 후 오류율. 검색 캐시와 추천 캐시 각각의 오류율을 가리키는 경우와 두 캐시를 합산한 오류율을 가리키는 경우.
2. 전환 후 오류율이 2%를 초과하면 복원 지점으로 즉시 복원해야 한다.
3. 전환 후 오류율이 2% 이하이면 복원하지 않고 관찰을 유지한다.

**경고**: 오류율이 2%를 초과했는데 복원을 미루면 안 된다.

## 6. 후속 점검과 보고

1. 전환 완료 보고서를 작성해 PM에게 전달한다. 전달 전에는 당직 교대를 하면 안 된다.
2. 11/13(금) 09:00에 후속 점검을 실행한다.

## 7. 예외 상황

1. 오류율을 조회할 수 없거나 복원이 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.
2. 1번의 경우 작업 기록은 운영 포털의 야간 작업함에 저장해야 한다.
