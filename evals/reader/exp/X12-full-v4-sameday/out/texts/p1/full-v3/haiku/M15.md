# 강의 자막 편집 PR: 저장 후 줄바꿈 소실 수정 및 이번 공개 안내

이번 PR은 자막 편집기에서 저장 직후 줄바꿈이 사라지는 문제를 수정하고, 자막 편집기와 용어 사전 편집기의 변경 사항을 포함한다. 두 편집기는 콘텐츠 관리 포털의 강의 도구 메뉴에 배치된다. 공개는 12/10(목) 11:00에 진행하며, 접근성 검수는 12/09(수) 15:00에 마감한다. 개발 담당은 차이담, 공개 담당은 류하온이다.

## 변경 내용

- 자막 편집기는 저장 직후 줄바꿈이 사라지던 문제를 수정한다.
- 자막 편집기와 용어 사전 편집기를 변경한다.
- 두 편집기는 콘텐츠 관리 포털의 강의 도구 메뉴에 배치한다.

## 입력 제한

- 자막 한 줄은 최대 42자까지 입력할 수 있다. 공백도 글자 수에 포함한다.
- 용어 설명은 최대 120자까지 입력할 수 있다. 공백도 글자 수에 포함한다.

## 일정

| 구분 | 일시 | 내용 |
|---|---|---|
| 기한 | 12/09(수) 15:00 | 접근성 검수 마감 |
| 실행일 | 12/10(목) 10:00 | 타임가드 자동 검사 실행, 강의 36편 대상, 정모아 담당 |
| 실행일 | 12/10(목) 11:00 | 강의 공개, 류하온 담당 |
| 실행일 | 공개 당일 | CS팀에 공개 안내 전달 |

## 담당 역할

- 차이담: 개발 담당
- 류하온: 공개 담당
- 정모아: 타임가드 자동 검사 실행 담당
- 임새론: 콘텐츠 운영팀 팀장, 강의 공개 일정 담당
- 백여울: 접근성 검수팀 팀장, 검수 인력 배정 담당
- 고객지원팀: 강사 문의 대응 담당
- 고객성공팀: 기관 고객 교육 담당

## 접근성 검수 기준

1. 접근성 검수자는 키보드 조작 결과를 첨부해야 한다.
2. 보관 상태 강의는 이번 검수에서 제외한다.
3. 검수 관련 문의는 #강의-편집 채널로 한다.

## 공개 절차

1. 12/09(수) 15:00까지 접근성 검수를 마쳐야 한다.
2. 팀장님 승인 댓글을 받은 뒤 공개를 진행한다.
3. 정모아가 12/10(목) 10:00에 타임가드를 실행하여 강의 36편의 자막 시간축을 검사한다.
4. 검사 결과 시간축 오류가 1건 이상이면 공개를 보류한다.
5. 류하온이 12/10(목) 11:00에 강의를 공개한다.
6. 공개 당일 CS팀에 안내를 전달해야 한다.

**경고: 공개 후 2시간 동안은 일괄 수정 기능을 사용하면 안 된다.**
