# 결제 재시도 PR: 중복 승인 요청으로 고객 결제 알림이 두 번 나가는 문제 수정

문서 식별자: 묶음 5-1
작성자: 서다온
독자: 누벨핀 결제 백엔드 개발자, 배포 검토자

이 PR은 중복 승인 요청 때문에 고객 결제 알림이 두 번 나가는 문제를 수정한다. 변경 대상은 승인 재시도 작업과 알림 재전송 작업이며, 두 작업은 모두 결제 운영 콘솔에서 실행한다. 배포는 11/12(목) 14:00에 하며 배포 담당은 문해솔이다. 검토 완료 기한은 11/11(수) 17:00까지다.

## 배경

중복 승인 요청이 발생하면 고객 결제 알림이 두 번 나간다.

## 변경 내용

- 승인 재시도 작업 간격: 30초
- 승인 재시도 작업 최대 횟수: 3회
- 알림 재전송 작업 간격: 60초
- 알림 재전송 작업 최대 횟수: 2회
- DB 변경: 주문 DB와 정산 DB에 조회 인덱스를 각각 추가한다. 기존 컬럼은 삭제하지 않는다.

확인 필요: "최대 3회"와 "최대 2회". 재시도 횟수인지 전체 시도 횟수인지 원문에 없다.

## 배포 전 조건

**배포 전에 DB 스냅샷을 보관해야 한다.**

재시도 테스트 통과 기록을 첨부해야 한다.

확인 필요: "재시도 테스트 통과 기록 첨부". 기록을 첨부하는 행위자가 원문에 없다.

내부 시험 상점은 테스트 대상에서 제외한다.

## 사전 검사

이번 배포의 단일 사전 검사 작업은 결제 무결성 검사다. 서다온이 11/12(목) 13:30에 표본 240건을 대조한다.

페이체크도 서다온이 11/12(목) 13:30에 표본 240건을 대조하는 사전 검사다. 사전 검사가 실패하면 배포를 중단한다.

확인 필요: "결제 무결성 검사"와 "페이체크". 두 이름이 같은 사전 검사를 가리키는지 원문에 없다.

## 배포 후 제한

배포 직후 20분 동안 그거는 수동으로 실행하면 안 된다.

확인 필요: "그거는". 가리키는 작업이 원문에 명시되지 않았다.
