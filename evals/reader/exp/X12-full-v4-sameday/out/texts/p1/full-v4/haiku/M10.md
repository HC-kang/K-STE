# 누리펄스 캐시 전환 런북

이 런북은 운영 절차 묶음 4의 캐시 전환 작업 절차를 정리한다. 작업은 11월 12일(목) 23:10에 시작해 23:40에 종료하며, 실행 담당은 야간 서비스 운영 당직자 문세린이다. 대상은 검색 캐시와 추천 캐시다. 캐시 갱신 지연으로 검색 결과 누락이 발생할 수 있으므로, 전환 전후 오류율을 기준으로 복원 여부를 정한다.

## 1. 작업 개요

- 작업명: 누리펄스 캐시 전환
- 작업 일시: 11월 12일(목) 23:10 시작, 23:40 종료
- 실행 담당: 야간 당직자 문세린
- 작업 대상: 검색 캐시, 추천 캐시
- 작업 위치: 사내 운영 포털의 검색 탭과 추천 탭
- 서버 상태 조회 위치: 사내 운영 포털의 장비 탭

## 2. 역할과 연락처

- 실행 담당: 야간 당직자 문세린. 서버 재시작 승인도 문세린이 한다.
- 대기 담당: 제품 관리자 나도윤, 프로젝트 관리자 서이안. 두 사람은 작업 시간 동안 사내 메신저에서 대기해야 한다.
- 장애 연락: 플랫폼지원팀 윤하민, 내선 4726.

## 3. 작업 순서

| 시각 | 작업 |
|---|---|
| 23:10 | 작업 시작 |
| 23:20 | 문세린이 복원 지점 2개 등록 |
| 23:40 | 작업 종료 |
| 11월 13일(금) 09:00 | 후속 점검 |

작업은 다음 순서로 한다. 단계 사이의 세부 시각은 정해지지 않았다.

1. 23:10에 작업을 시작한다.
2. 운영 포털의 장비 탭에서 검색 로그 서버와 추천 로그 서버의 상태를 각각 조회한다. 두 서버는 별도 장비이므로 따로 조회해야 한다.
3. 전환 직전 스냅샷을 1개 추가로 저장해야 한다.
4. 검색 캐시의 전환 전 오류율을 5분간 측정하고 작업 기록에 남긴다.
5. 추천 캐시의 전환 전 오류율을 5분간 측정하고 작업 기록에 남긴다.
6. 23:20에 문세린이 복원 지점 2개를 등록한다. 복원 작업의 실행 화면은 복원 제어판 1개만 사용해야 한다.
7. 되돌림 데스크에 복원 지점 2개가 표시되는지 표시 개수를 대조한다.
8. 검색 탭과 추천 탭에서 각각 캐시 전환 작업을 한다.
9. 전환 후 검색 캐시와 추천 캐시의 오류율을 조회한다.
10. 9번의 결과를 4절의 판정 기준에 대조해 복원 여부를 정한다.

## 4. 판정 기준

전환 후 오류율에 따라 다음과 같이 한다.

- 전환 후 오류율이 2%를 초과하면 즉시 복원해야 한다.
- 전환 후 오류율이 2% 이하이면 복원하지 않고 관찰을 유지한다.
- 후속 점검은 11월 13일(금) 09:00에 한다.

## 5. 복원과 장애 대응

- 서버 재시작은 문세린의 승인을 받은 뒤에만 해야 한다. 승인 없이 재시작하면 안 된다.
- 오류율을 조회할 수 없거나 복원이 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.
- 오류율 조회 불가 또는 복원 실패가 발생하면 작업 기록을 운영 포털의 야간 작업함에 저장해야 한다.

## 6. 작업 후 보고와 교대

- 전환 완료 보고서를 작성해 PM에게 전달해야 한다.
- **경고: 전환 완료 보고서를 PM에게 전달하기 전에는 당직 교대를 하면 안 된다.**

## 7. 확인 필요 항목

- 확인 필요: 장비 탭의 서버 상태 조회 시점. 작업 전인지 작업 중인지 적히지 않았다.
- 확인 필요: 전환 직전 스냅샷의 대상. 검색 캐시, 추천 캐시, 또는 둘 다인지 적히지 않았다.
- 확인 필요: 캐시 전환 작업의 세부 방법과 검색 탭, 추천 탭의 작업 순서.
- 확인 필요: 전환 후 오류율의 측정 기간.
- 확인 필요: 2% 기준을 검색 캐시와 추천 캐시 각각에 적용하는지, 합산해 적용하는지.
- 확인 필요: 2% 이하일 때의 관찰 유지 기간.
- 확인 필요: 후속 점검 시각 "11월 13일(금) 09:00"이 실행 시각인지 기한인지.
- 확인 필요: 즉시 복원할 때 2개의 복원 지점 중 무엇을 사용하는지.
- 확인 필요: 되돌림 데스크의 표시 개수가 2개가 아닐 때의 조치.
- 확인 필요: PM이 나도윤(제품 관리자)과 서이안(프로젝트 관리자) 중 누구인지.
