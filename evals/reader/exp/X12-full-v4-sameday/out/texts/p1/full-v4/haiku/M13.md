# 결제 재시도 PR 설명 (묶음 5-1)

문서 식별자: 묶음 5-1

중복 승인 요청 때문에 고객 결제 알림이 두 번 나가는 문제를 수정하는 PR이다. 담당 개발자는 서다온이다. 변경 대상은 승인 재시도 작업과 알림 재전송 작업이며, 두 작업은 모두 결제 운영 콘솔에서 실행한다.

## 변경 내용

- 승인 재시도 작업의 재시도 간격은 30초, 최대 3회다.
- 알림 재전송 작업의 재전송 간격은 60초, 최대 2회다.
- 주문 DB와 정산 DB에 각각 조회 인덱스를 추가한다.
- 기존 컬럼은 삭제하지 않는다.

## 배포 일정

- 배포 실행: 11/12(목) 14:00
- 검토 완료 기한: 11/11(수) 17:00
- 배포 담당: 문해솔

## 사전 검사

이번 배포의 단일 사전 검사 작업은 결제 무결성 검사다. 서다온이 11/12(목) 13:30에 표본 240건을 대조한다. 사전 검사가 실패하면 배포를 중단해야 한다.

확인 필요: 페이체크. 결제 무결성 검사와 같은 작업인지, 별도의 검사인지.

## 배포 전 조건

- 배포 전에 DB 스냅샷을 보관해야 한다.
- PM 승인 댓글을 받은 뒤에 병합해야 한다.

## 배포 후 조건

- 그거는 배포 직후 20분 동안 수동 실행 금지

확인 필요: 그거는. 승인 재시도 작업, 알림 재전송 작업, 두 작업 모두 중 어느 것을 가리키는지.

## 검토자 확인 사항

- 배포 검토자는 재시도 테스트 통과 기록을 첨부해야 한다.
- 내부 시험 상점은 테스트 대상에서 제외해야 한다.
- 문의 채널: #결제-변경
