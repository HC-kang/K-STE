# 강의 자막 편집 PR

이 PR은 강의 자막 편집기와 용어 사전 편집기를 변경하고, 저장 직후 자막 줄바꿈이 사라지는 문제를 수정한다. 두 편집기는 콘텐츠 관리 포털의 강의 도구 메뉴에 배치한다. 개발 담당은 차이담이다.

## 변경 내용

- 자막 편집기는 저장 직후 줄바꿈이 사라지는 문제를 수정한다.
- 자막 한 줄은 공백을 포함해 42자를 넘으면 안 된다.
- 용어 설명은 공백을 포함해 120자를 넘으면 안 된다.

## 일정

| 구분 | 일시 | 내용 | 담당 |
|---|---|---|---|
| 기한 | 12/09(수) 15:00까지 | 접근성 검수 마감 | 검수 인력 배정은 백여울이 한다 |
| 실행일 | 12/10(목) 10:00에 | 타임가드 자동 검사(강의 36편) | 정모아가 실행한다 |
| 실행일 | 12/10(목) 11:00에 | 강의 공개 | 류하온이 한다 |

## 공개 조건

- 타임가드 검사에서 시간축 오류가 1건 이상이면 공개를 보류해야 한다.
- 팀장님 승인 댓글을 받은 뒤에 공개해야 한다.
- 공개 후 2시간 동안 일괄 수정 기능을 사용하면 안 된다.
- 공개 당일 CS팀에 안내를 전달해야 한다.

확인 필요: 팀장님 승인. 임새론 팀장과 백여울 팀장 가운데 누구의 승인인지 명시되지 않았다.

확인 필요: 그건. 공개 후 2시간 동안 일괄 수정 기능 사용 금지가 가리키는 대상이 명시되지 않았다.

## 접근성 검수

- 접근성 검수자는 키보드 조작 결과를 첨부해야 한다.
- 보관 상태 강의는 이번 검수에서 제외한다.
- 문의는 #강의-편집 채널로 한다.

## 역할

| 담당 | 역할 |
|---|---|
| 임새론 | 콘텐츠 운영팀 팀장으로서 강의 공개 일정을 담당한다 |
| 백여울 | 접근성 검수팀 팀장으로서 검수 인력 배정을 담당한다 |
| 정모아 | 12/10(목) 10:00에 타임가드 자동 검사를 실행한다 |
| 류하온 | 강의 공개를 담당한다 |
| 차이담 | 개발을 담당한다 |
| 고객지원팀 | 강사 문의에 대응한다 |
| 고객성공팀 | 기관 고객 교육을 담당한다 |
