# PR 5-2: 모아결에듀 강의 자막 설정 화면 개선

**묶음:** 5
**개발 담당:** 한도윤
**접근성 검토 담당:** 윤세하
**문의:** 사내 #자막검토 채널

## 변경 요약

학습 웹의 자막 설정 패널에서 키보드 초점 표시가 배경과 구별되지 않는 문제를 수정했습니다. 검토 의견은 반영 완료 상태입니다.

- **변경 위치:** 학습 웹의 자막 설정 패널
- **주요 수정:** 키보드 초점 표시가 배경과 구별되도록 개선
- **자막 글자 크기**
  - 기본값: 20px
  - 선택 범위: 16~32px
  - 저장된 사용자 설정이 있으면 저장값을 우선 적용

## 검토 환경 및 범위

- **검토 환경:** 사내 미리보기 사이트의 강의 L-28
- **제외 대상:** 외부 공개 강의는 이번 검토 대상에서 제외합니다.
- **추가 요청:** 검토 담당자는 확대 화면에서도 확인해 주시기 바랍니다.
