# 누리핀물류 야간 배차 점검 런북

## 1. 목적과 개요

- **점검 일시:** 2026-11-12(목) 22:00~23:00
- **목적:** 야간 시간대 중복 배차를 막기 위해 동부·서부 배차 서버의 대기열 건수를 10분 간격으로 확인하고 기록한다.
- **사용 도구:** 관제실 단말의 루온 콘솔 > **'야간 점검'** 메뉴
- **점검 대상:** 동부 배차 서버, 서부 배차 서버 (두 서버 모두 대기열 수집 대상)

## 2. 역할

| 역할 | 담당 | 주요 업무 |
|---|---|---|
| 관제 담당자 | 관제실 | 대기 건수 점검·기록, 신규 배차 중지·재개, 결과 요약 게시 |
| 플랫폼팀 | 서버 운영 | 22:30 서버 재시작 실행, 서버 조작 |
| 배차지원팀 | 운송사 연락 | 운송사 연락 및 문의 대응 (22:00~23:00 대기) |

## 3. 사전 준비 (점검 전)

1. 관제실 단말에서 루온 콘솔에 로그인하고 **'야간 점검'** 메뉴가 열리는지 확인한다.
2. 두 서버(동부, 서부)의 대기 건수가 화면에 각각 표시되는지 확인한다.
3. 점검표를 준비한다. 서버별로 시각 7칸(22:00, 22:10, 22:20, 22:30, 22:40, 22:50, 23:00)을 만들고 '비고' 칸을 둔다.
4. 플랫폼팀, 배차지원팀과 연락 수단을 확인한다.
5. 배차지원팀 내선 **731**을 확인한다.

## 4. 점검 절차 (22:00~23:00)

10분 간격으로 아래를 반복한다.

| 시각 | 작업 |
|---|---|
| 22:00 | 동부·서부 대기 건수 확인 및 점검표 기록 |
| 22:10 | 동부·서부 대기 건수 확인 및 기록 |
| 22:20 | 동부·서부 대기 건수 확인 및 기록 |
| 22:30 | 플랫폼팀 서버 재시작 (아래 6번 참고) |
| 22:40 | 동부·서부 대기 건수 확인 및 기록 |
| 22:50 | 동부·서부 대기 건수 확인 및 기록 |
| 23:00 | 동부·서부 대기 건수 확인 및 기록, 점검 종료 |

**각 확인 시 해야 할 일**

1. 서버별 대기 건수를 확인하고 점검표에 기록한다.
2. 어느 서버든 대기 건수가 **40건 이상**이면 해당 서버의 **신규 배차를 즉시 중지**한다. (5번 참고)
3. 중지 상태인 서버는 대기 건수가 **10건 이하**가 될 때까지 기록을 계속한다. (5번 참고)

## 5. 신규 배차 중지·재개 기준

### 중지
- **기준:** 특정 서버의 대기 건수가 **40건 이상**
- **조치:** 해당 서버의 신규 배차를 **즉시** 중지한다. 기준은 서버별로 따로 적용한다. 한쪽 서버를 중지해도 다른 서버는 기준에 맞으면 계속 운영한다.
- **예외:** **긴급 의료 운송**은 중지 대상에서 제외한다.

### 재개
- **기준:** 중지한 서버의 대기 건수가 **10건 이하**
- **조치:** 관제 담당자가 해당 서버의 신규 배차를 재개하고, 재개 시각을 점검표 비고란에 기록한다.

### 확인 필요
- 대기 건수가 **11~39건**인 구간의 처리 기준은 메모에 없다. 중지 상태를 유지하는지, 재개 가능한지 확인해야 한다.
- 긴급 의료 운송을 **어떻게 식별하는지**(오더 유형, 표시 항목 등)는 메모에 없다. 점검 전에 기준을 정해야 한다.

## 6. 22:30 서버 재시작 대응

- 실행 담당: **플랫폼팀**
- 재시작 중에는 대기 건수 집계가 정상적이지 않을 수 있다. 관제 담당자는 아래 순서로 대응한다.
  1. 22:30 정각에 재시작이 시작되는지 플랫폼팀과 확인한다.
  2. 재시작 **전**에 두 서버의 대기 건수를 먼저 기록한다.
  3. 재시작 후 재확인이 가능해지면 기록을 이어간다. 재시작 시각과 작업 상태를 비고란에 적는다.
- **확인 필요:** 재시작으로 대기열이 초기화되는지, 중지 상태가 재시작 후에도 유지되는지 플랫폼팀에 확인해야 한다.

## 7. 점검 종료 후 처리

1. **점검표 제출:** 11/13(금)까지 제출한다. (제출 방법과 대상은 메모에 없으므로 확인 필요)
2. **결과 요약 게시:** 점검 종료 후 운영 게시판에 결과 요약을 게시한다. 요약에 포함할 내용은 다음과 같다.
   - 점검 시간 및 재시작 시각
   - 서버별 최대·최소 대기 건수 및 40건 이상 발생 여부
   - 신규 배차 중지·재개 이력(시각, 서버)
   - 특이사항

## 8. 문의 및 연락

- 배차 관련 문의(중지·재개 기준 등): **배차지원팀 내선 731**
- 서버 관련 문의: 플랫폼팀
- 운송사 연락: 배차지원팀

## 9. 메모에서 확인해야 할 항목 요약

1. 대기 건수 11~39건일 때의 처리 기준

3. 22:30 재시작 시 대기열 초기화 여부와 중지 상태 유지 여부
4. 점검표 제출 방법과 제출 대상
5. 운영 게시판 게시 담당자
