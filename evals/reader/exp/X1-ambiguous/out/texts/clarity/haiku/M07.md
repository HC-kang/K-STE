# 누리결제 정산 점검 회의록

| 항목 | 내용 |
|---|---|
| 회의명 | 누리결제 정산 점검 회의 |
| 일시 | 2026년 11월 12일(목) 10:00~10:30 |
| 장소 | 본사 3층 소회의실 |
| 참석자 | 정산운영팀 강세린, 플랫폼팀 문도윤 |
| 공유 대상 | 정산운영팀, 플랫폼팀 |

## 1. 점검 배경

- **원인:** 야간 정산 파일 4건이 중복 생성됨
- **점검 대상:** 결제 서버, 정산 서버 (두 서버 모두 테스트 환경)

## 2. 조치 사항

1. **서버 자동 재시도 기능 중지**
   - 중지 시각: 11월 16일(월) 09:00
2. **중복 생성 기록 조회 (플랫폼팀)**
   - 일시: 11월 16일(월) 09:00~10:00
   - 대상: 결제 서버, 정산 서버 두 곳 모두
   - 조회 결과를 모아 회의 자료실에 비교표 업로드
3. **파일 건수 대조 (정산운영팀)**
   - 기한: 비교표 업로드 알림 수신 후 2시간 이내
   - 범위: 테스트 거래만 포함, 실제 고객 거래는 제외
4. **재발 방지 보고서 제출 (플랫폼팀)**
   - 기한: 11월 19일(목)
   - 저장 위치: 사내 자료실 '정산점검/11월'
   - 파일 형식: PDF

| 3 | 파일 건수 대조 (테스트 거래 기준) | 정산운영팀 | 비교표 업로드 알림 후 2시간 이내 |
