# 누리결제 정산 점검 회의록

**공유 대상:** 정산운영팀, 플랫폼팀

## 1. 회의 개요
| 항목 | 내용 |
|---|---|
| 일시 | 11/12(목) 10:00~10:30 |
| 장소 | 본사 3층 소회의실 |
| 참석자 | 정산운영팀 강세린, 플랫폼팀 문도윤 |

## 2. 점검 배경 및 대상
- **점검 원인:** 야간 정산 파일 4건 중복 생성
- **점검 대상:** 결제 서버, 정산 서버 (두 서버 모두 테스트 환경)

## 3. 결정 사항 및 할 일
| 구분 | 내용 | 담당 | 기한 |
|---|---|---|---|
| 자동 재시도 중지 | 서버의 자동 재시도 기능 중지 | 담당 미지정 | 11/16(월) 09:00 |
| 기록 조회 | 결제 서버와 정산 서버의 중복 생성 기록 조회 (필수) | 플랫폼팀 | 11/16(월) 09:00~10:00 |
| 비교표 업로드 | 조회 결과를 모아 회의 자료실에 비교표 업로드 | 담당 미지정 | 조회 완료 후 |
| 파일 건수 대조 | 비교표 업로드 알림 수신 후 파일 건수 대조 (필수) | 정산운영팀 | 알림 수신 후 2시간 이내 |
| 보고서 제출 | 재발 방지 보고서 제출 | 담당 미지정 | 11/19(목) |

## 4. 세부 기준
- **대조 범위:** 테스트 거래만 포함하며, 실제 고객 거래는 제외한다.
- **보고서 저장 위치:** 사내 자료실 '정산점검/11월'
- **보고서 파일 형식:** PDF

## 5. 문의
운영지원팀 윤하린 (사내 메신저 '정산점검 문의')

---

**확인이 필요한 사항** (메모에 명시되지 않아 비워 두었습니다)
1. 자동 재시도 중지의 담당자와 대상 서버(결제·정산 서버 모두인지)
2. 비교표 업로드 담당(플랫폼팀으로 보이나 메모에 없음)
3. 재발 방지 보고서 작성·제출 담당

공유 전에 담당을 채우시면 오해 없이 전달할 수 있습니다.
