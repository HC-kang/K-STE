# [PR 5-1] 주문 API 재시도 처리: 동일 요청 키 재사용 시 주문 중복 생성 차단

## 개요
주문 API의 재시도 처리 모듈에서, 동일한 요청 키가 다시 들어오면 주문이 중복 생성되는 문제를 수정합니다. (묶음 5 · PR 5-1)

## 변경 내용
- **변경 위치:** 주문 API의 재시도 처리 모듈
- **새 중복 차단 기준:** 동일 요청 키를 수신한 시점부터 90초 동안 같은 키의 요청을 중복으로 판단해 차단합니다.
- **요청 키가 없는 요청:** 기존 처리를 그대로 유지합니다.
- **요청 로그 보관 기간:** 서버의 요청 로그 보관 기간을 48시간으로 변경합니다.

## 대상 환경
- 스테이징 주문 서버
- 스테이징 환불 서버

두 서버 모두 비교 시험에 사용했습니다.

작성 중 확인이 필요해 보이는 점이 있습니다.
- **로그 보관 기간:** 메모에 "서버"로만 되어 있어 주문 서버, 환불 서버 중 어느 쪽인지(또는 둘 다인지)와 기존 보관 기간을 알 수 없었습니다. 리뷰어가 영향 범위를 오해하지 않도록 "변경 내용"에 서버 범위와 기존 값(예: 기존 ○○시간 → 48시간)을 추가하는 것이 좋습니다.
