# 다온빛전시 주말 입장 장비 점검 운영 절차

## 1. 개요
- **일시**: 12/05(토) 09:00~09:30
- **목적**: 입장권 중복 인식 방지
- **점검 장비**: 북문 스캐너, 남문 스캐너
- **기록 방법**: 북문 안내데스크의 미루 앱에서 안내 직원이 점검 기록 작성

## 2. 역할 분담
| 담당 | 역할 |
|---|---|
| 현장 안내 직원 | 시험권 인식 시험, 미루 앱 점검 기록, 시험권 회수·보관 |
| 기술팀 | 스캐너 전원 켜기(09:00), 장비 조작, 인식 설정 초기화(09:20) |
| 운영지원팀 | 시험권 발급 (현장 대기) |

**장비 문의**: 기술팀 내선 582

## 3. 시간표
| 시각 | 내용 | 담당 |
|---|---|---|
| 점검 시작 전 | 미루 앱 사용 안내 읽기 (권장) | 안내 직원 |
| 09:00 | 북문·남문 스캐너 전원 켜기 | 기술팀 |
| 09:00~ | 스캐너별 시험권 6장 인식 시험 및 미루 앱 기록 | 안내 직원 |
| 09:20 | 스캐너 인식 설정 초기화 | 기술팀 |
| 점검 종료 후 | 시험권 회수, 북문 안내데스크 잠금함에 보관 | 안내 직원 |

## 4. 안내 직원 절차
1. 점검 시작 전에 미루 앱 사용 안내를 읽습니다.
2. 운영지원팀에게서 시험권을 받습니다.
3. 09:00에 기술팀이 두 스캐너의 전원을 켠 것을 확인합니다.
4. **북문 스캐너와 남문 스캐너에서 각각 시험권 6장**을 인식시킵니다. 두 스캐너 합계로는 12장입니다.
5. 인식 결과를 북문 안내데스크의 미루 앱에 기록합니다.
6. 점검이 끝나면 시험권을 모두 회수해 북문 안내데스크 잠금함에 보관합니다.

> **주의**: 실제 관람객 입장권은 시험에 사용하지 않습니다. 시험에는 운영지원팀이 발급한 시험권만 씁니다.

## 5. 인식 실패 시 조치
같은 스캐너에서 인식이 **2회 이상** 실패하면 다음과 같이 처리합니다.
1. 해당 장비 사용을 **즉시 중지**합니다.
2. 기술팀 내선 582로 연락합니다.
3. 해당 장비를 쓰던 입구에서는 **수기 입장대장**을 사용합니다.
4. 기술팀장 **서하겸**의 재사용 승인을 받은 뒤에만 해당 장비를 다시 사용합니다. 승인 전에는 수기 입장대장을 계속 사용합니다.

## 6. 확인이 필요한 사항
메모에 없어 확인이 필요한 부분입니다.
- 09:20 설정 초기화 시점에 시험권 인식이 끝나 있어야 하는지, 초기화 후에 다시 인식해야 하는지
- 미루 앱 사용 안내의 위치(링크 또는 문서)

이 두 가지는 확정되면 시간표와 절차에 반영해 주세요.
