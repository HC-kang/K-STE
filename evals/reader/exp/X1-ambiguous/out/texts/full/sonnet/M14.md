# 묶음 5 · PR 5-2: 모아결에듀 강의 자막 설정 화면 개선

학습 웹의 자막 설정 패널에서 키보드 초점 표시가 배경과 구별되지 않는 문제를 수정했다. 윤세하가 11/18(수)에 키보드 이동 경로를 검토하고, 한도윤이 11/23(월) 11:00에 병합할 예정이다.

## 변경 내용

변경 위치는 학습 웹의 자막 설정 패널이다. 키보드 초점 표시가 배경과 구별되지 않는 문제를 수정했다.

자막 글자 크기 기본값은 20px이고, 선택 범위는 16-32px이다. 저장된 사용자 설정이 있으면 저장값이 우선한다.

## 검토 환경

검토는 사내 미리보기 사이트의 강의 L-28에서 한다. 외부 공개 강의는 이번 검토 대상이 아니다.

## 검토 요청

윤세하는 11/18(수) 15:00-16:00에 키보드 이동 경로 12개를 필수로 검토해야 한다. 검토 결과는 PR 댓글에 기록해야 한다. 검토 담당자는 확대 화면도 살펴보는 것을 권장한다.

## 일정

아래 날짜는 모두 그날 하는 일(실행일)이다.

| 실행일 | 할 일 |
|---|---|
| 11/18(수) 15:00-16:00 | 윤세하가 키보드 이동 경로 12개를 검토한다. |
| 11/20(금) | 검토 의견을 취합한다. |
| 11/23(월) 11:00 | 한도윤이 병합할 예정이다. |

## 병합 조건

병합하려면 윤세하의 승인 댓글이 있어야 한다. 차단 결함이 1건 이상이면 병합을 보류해야 한다.

개발 담당은 한도윤, 접근성 검토 담당은 윤세하이다. 문의는 사내 #자막검토 채널로 한다.
