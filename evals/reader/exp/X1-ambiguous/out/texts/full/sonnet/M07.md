# 누리결제 정산 점검 회의록

11/12(목) 10:00-10:30에 본사 3층 소회의실에서 누리결제 정산 점검 회의를 했다. 야간 정산 파일 4건이 중복 생성되어 점검하며, 점검 대상은 테스트 환경의 결제 서버와 정산 서버이다. 이 회의에서 플랫폼팀의 기록 조회, 정산운영팀의 파일 건수 대조, 재발 방지 보고서 제출 일정을 정했다.

## 회의 정보

- 일시: 11/12(목) 10:00-10:30
- 장소: 본사 3층 소회의실
- 참석: 정산운영팀 강세린, 플랫폼팀 문도윤

## 점검 내용

- 점검 원인: 야간 정산 파일 4건 중복 생성
- 점검 대상: 결제 서버와 정산 서버
- 환경: 두 서버 모두 테스트 환경

## 할 일

1. 플랫폼팀은 11/16(월) 09:00-10:00에 결제 서버와 정산 서버의 중복 생성 기록을 조회해야 한다.
2. 서버의 자동 재시도 기능을 중지한다. 중지 시각은 11/16(월) 09:00이다.
3. 조회 결과를 모아 회의 자료실에 비교표를 업로드한다.
4. 정산운영팀은 비교표 업로드 알림을 받은 뒤 2시간 이내에 파일 건수를 대조해야 한다. 이때 대조 범위에는 테스트 거래만 포함해야 하고, 실제 고객 거래는 포함하면 안 된다.
5. 재발 방지 보고서를 제출한다. 일정은 11/19(목)이다.

## 보고서 저장과 문의

- 보고서 저장 위치: 사내 자료실 ‘정산점검/11월’
- 파일 형식: PDF
- 문의: 운영지원팀 윤하린, 사내 메신저 ‘정산점검 문의’

확인 필요: 11/19(목) 재발 방지 보고서 제출. 11/19(목)에 제출하는 일정인지, 11/19(목)까지 제출해야 하는 기한인지.
확인 필요: 서버의 자동 재시도 기능. 결제 서버와 정산 서버 둘 다인지, 둘 중 한 서버인지.
확인 필요: 자동 재시도 기능 중지, 비교표 업로드, 재발 방지 보고서 제출. 담당 팀 또는 담당자.
