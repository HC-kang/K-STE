# 테르온물류 배차 집계 작업 개선 (묶음 5, PR 5-3)

야간 배차 집계 모듈에서 같은 운행 기록을 두 번 합산하는 문제를 수정한다. 배차운영팀이 12/03(목)에 검증 회의를 열고, 민하겸이 12/08(화) 09:00에 운영 환경에 배포한다.

## 변경 내용

- 야간 배차 집계 모듈에서 같은 운행 기록을 두 번 합산하는 문제를 수정한다.
- 새 집계 주기는 15분이다.
- 수동 확정한 운행 기록은 재집계 대상에서 제외한다.
- 문서 첫 페이지에 새 집계 기준을 추가한다.

## 담당

- 개발 담당: 민하겸
- 운영 검증 담당: 배차운영팀
- 문의: 사내 #배차배포 채널

## 검증

배차운영팀이 12/03(목) 16:00-16:30에 사내 회의실 청록에서 검증 회의를 연다. 이 회의에서 시험 운행 기록 360건을 검토한다. 배포 승인 담당자는 검증 회의에 가급적 참석하는 것을 권장한다.

## 배포

1. 배포 승인 담당자가 승인 댓글을 남겨야 한다.
2. 배포를 시작하기 전에 승인 번호를 변경 이력에 기록해야 한다.
3. 민하겸이 12/08(화) 09:00에 운영 환경에 배포한다.
4. 중복 합산을 1건 이상 발견하면 배포를 중단해야 한다.
