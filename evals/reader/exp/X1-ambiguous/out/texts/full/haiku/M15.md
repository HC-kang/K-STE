# 테르온물류 배차 집계 작업 개선 (묶음 5 · PR 5-3)

야간 배차 집계 모듈에서 같은 운행 기록을 두 번 합산하는 문제를 수정한다. 새 집계 주기는 15분이며, 수동 확정한 운행 기록은 재집계 대상에서 제외한다. 개발 담당은 민하겸, 운영 검증 담당은 배차운영팀이다. 운영 환경 배포는 12/08(화) 09:00에 민하겸이 진행한다.

## 변경 내용

- 야간 배차 집계 모듈에서 같은 운행 기록을 두 번 합산하는 문제를 수정한다.
- 집계 주기를 15분으로 한다.
- 수동 확정한 운행 기록은 재집계 대상에서 제외한다.

## 첨부 문서

- 배포 절차서
- 복구 절차서

두 문서는 운영 저장소 /dispatch/docs에 보관한다.

확인 필요: 문서 첫 페이지에 새 집계 기준을 추가한다. 배포 절차서와 복구 절차서 중 어느 문서의 첫 페이지인지 원문에 없다.

## 배포 조건

- 배포 시작 전에 승인 번호를 변경 이력에 기록해야 한다.
- 배포 승인 담당자는 승인 댓글을 남겨야 한다.

**중복 합산이 1건 이상 발견되면 배포를 중단해야 한다.**

## 검증 일정

- 배차운영팀 검증 회의: 12/03(목) 16:00-16:30, 사내 회의실 청록
- 검토 대상은 시험 운행 기록 360건이다.
- 배포 승인 담당자는 검증 회의에 참석하기를 권장한다.
