# 묶음 5 · PR 5-1 · 노벨릿커머스 주문 중복 차단 변경

이 PR은 주문 API의 재시도 처리 모듈에서 동일한 요청 키를 재사용하면 주문이 중복 생성되는 문제를 수정한다. 새 중복 차단 기준은 동일 요청 키 수신 후 90초다. 병합 전에 스테이징 주문 서버와 스테이징 환불 서버에서 비교 시험을 거쳐야 한다.

## 변경 내용

- 변경 위치: 주문 API의 재시도 처리 모듈
- 문제: 동일 요청 키를 재사용하면 주문이 중복 생성된다.
- 새 중복 차단 기준: 동일 요청 키 수신 후 90초
- 요청 키가 없는 요청은 기존 동작을 그대로 유지한다.
- 서버의 요청 로그 보관 기간을 48시간으로 변경한다.

확인 필요: 서버의 요청 로그 보관 기간 48시간 변경. 변경 대상이 주문 서버인지 환불 서버인지, 또는 두 서버 모두인지 원문에 없다.

## 대상 환경

- 스테이징 주문 서버
- 스테이징 환불 서버

두 서버 모두 비교 시험에 사용한다.

## 검증

주문QA팀이 11/10(화) 14:00-15:00에 비교 시험을 진행한다. 시험은 서버별 요청 240건으로 구성한다. 실패 건수 기준은 0건이다.

병합 전에 비교 시험 결과표를 이 PR의 첨부란에 업로드해야 한다.
