# 누리핀물류 야간 배차 점검 운영 절차

2026년 11월 12일(목) 22:00~23:00에 동부 배차 서버와 서부 배차 서버의 대기 건수를 점검하여 중복 배차를 막는다. 관제 담당자는 10분 간격으로 두 서버의 대기 건수를 점검표에 기록한다. 대기 건수가 40건 이상인 서버에서는 신규 배차를 즉시 중지한다. 긴급 의료 운송은 중지 대상에서 제외한다.

## 1. 역할

| 역할 | 담당 | 작업 |
|---|---|---|
| 관제 담당자 | 관제팀 | 대기 건수 기록, 신규 배차 중지와 재개, 점검표 제출, 결과 요약 게시 |
| 서버 조작 담당 | 플랫폼팀 | 22:30 서버 재시작 |
| 운송사 연락 담당 | 배차지원팀 | 22:00~23:00 대기, 운송사 연락 |

## 2. 점검 절차

1. 관제실 단말에서 루온 콘솔을 열고 '야간 점검' 메뉴를 연다.
2. 22:00부터 10분 간격으로 동부 배차 서버와 서부 배차 서버의 대기 건수를 각각 점검표에 기록한다.
3. 대기 건수가 40건 이상인 서버는 관제 담당자가 신규 배차를 즉시 중지한다. 긴급 의료 운송은 중지 대상에서 제외한다.
4. 중지한 신규 배차는 해당 서버의 대기 건수가 10건 이하일 때 관제 담당자가 재개한다.
5. 점검이 끝나면 결과 요약을 운영 게시판에 게시한다.
6. 11/13(금) 점검표를 제출한다.

확인 필요: 11/13(금) 점검표 제출. 해당 날짜에 제출하는 것인지, 그날까지 제출하는 것인지 불분명하다.

## 3. 시간표

| 시각 | 작업 | 담당 |
|---|---|---|
| 22:00 | 점검 시작, 첫 대기 건수 기록 | 관제 담당자 |
| 22:00~23:00 | 10분 간격으로 두 서버의 대기 건수 기록, 40건 이상이면 신규 배차 즉시 중지 | 관제 담당자 |
| 22:00~23:00 | 운송사 연락 대기 | 배차지원팀 |
| 22:30 | 서버 재시작 | 플랫폼팀 |
| 점검 종료 후 | 결과 요약 게시 | 관제 담당자 |

확인 필요: 10분 간격 기록 시각. 22:00부터 22:50까지 6회 기록하는 것인지, 23:00 기록을 포함해 7회 기록하는 것인지 불분명하다.
