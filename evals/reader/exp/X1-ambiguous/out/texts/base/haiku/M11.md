# 포장라인 라벨 검사 운영 절차서 (런북)

**문서명:** 모래별식품 포장라인 출고 라벨 검사 절차
**적용 대상:** 2공장 포장라인 반장
**검사 일시:** 2026년 11월 20일(금) 08:00~10:00
**목적:** 출고 라벨 누락 방지

---

## 1. 목적 및 적용 범위

- 생산 로트별 출고 라벨 누락을 검사하여 누락 제품의 출고를 막는다.
- 검사 대상은 생산 로트이며, **시험 생산 로트는 제외**한다.

## 2. 역할

| 역할 | 담당 업무 |
|---|---|
| 포장라인 반장 | 검사 수행, 세온 단말 기록 입력, 출고 보류 및 격리, 라벨 사진 촬영 |
| 품질팀장 (류다온) | 출고 보류 해제 승인 (단독 권한) |
| 품질팀 | 검사 지원 (08:00~10:00), 검사 기준 문의 응대 |

## 3. 준비 사항

- [ ] 2공장 검사대 세온 단말 작동 여부 확인
- [ ] 검사 대상 생산 로트 목록 확인 (시험 생산 로트 제외 표시)
- [ ] 격리구역 B 이동 가능 여부 및 공간 확인
- [ ] 라벨 사진 촬영용 기기 준비
- [ ] 품질팀 내선 426 연락 가능 여부 확인

## 4. 검사 절차

### 4.1 검사 시작 (08:00)
1. 검사 대상 생산 로트를 확인한다. 시험 생산 로트는 검사하지 않는다.
2. 세온 단말에 로트 정보를 입력하고 검사를 시작한다.

### 4.2 로트별 샘플 검사
1. 생산 로트마다 **12상자**를 검사한다.
2. 각 상자의 출고 라벨 부착 여부를 확인하고 누락 상자 수를 센다.
3. 검사 결과를 세온 단말에 입력한다.

### 4.3 판정 기준

| 12상자 중 라벨 누락 상자 수 | 판정 | 조치 |
|---|---|---|
| 0~1상자 | 합격 | 출고 진행 가능 |
| **2상자 이상** | **불합격** | **즉시 출고 보류** (4.4 참조) |

### 4.4 출고 보류 (불합격 로트)
1. 해당 로트의 **출고를 즉시 보류**한다.
2. 세온 단말에 보류 사실을 기록한다.
3. 해당 로트의 상자를 **2공장 격리구역 B**로 이동한다.
4. 품질팀장(류다온)에게 보류 사실을 알린다. 품질팀 내선 426으로 문의할 수 있다.

> **주의:** 품질팀장의 승인 전에는 보류 로트의 출고를 재개할 수 없다. 반장이 임의로 해제하지 않는다.

## 5. 라벨 사진 기록 (교대 전)

- 교대 전에 라벨 사진을 남기는 것을 권장한다.
- 촬영 대상: 검사한 로트의 라벨 상태, 누락 상자가 있을 경우 그 상태
- 사진 저장 위치 및 파일명 규칙: **[확인 필요]**

## 6. 검사 기록 제출 (11월 23일 월요일)

1. 11/20 검사 기록이 세온 단말에 모두 입력되었는지 확인한다.
2. 11/23(월)까지 검사 기록을 제출한다.
3. 제출 완료 후 처리함 관련 절차를 따른다. **[처리함의 구체적 의미와 절차 확인 필요]**

## 7. 출고 보류 해제 규칙

- 해제 승인자: **품질팀장 류다온만 가능**
- 반장은 승인 전 출고 재개를 하지 않는다.
- 승인 기록(일시, 승인자, 로트 번호)을 남긴다.

## 8. 연락처 및 지원

| 검사 기준 문의 | 품질팀 내선 426 |
| 출고 보류 해제 승인 | 품질팀장 류다온 |

## 확인이 필요한 항목

1. 상자 12개를 고르는 방법(무작위, 로트 내 지정 위치 등)
2. 라벨 누락의 정확한 판정 기준(예: 라벨 부착 불량, 정보 오류 포함 여부)
3. 라벨 사진의 저장 위치와 파일명 규칙
4. "처리함"의 의미와 제출 후 세부 절차
5. 세온 단말에 입력할 항목과 보류 기록 방법
