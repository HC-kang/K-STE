# 누리결제 정산 점검 회의록

| 항목 | 내용 |
|---|---|
| **일시** | 11/12(목) 10:00 ~ 10:30 |
| **장소** | 본사 3층 소회의실 |
| **참석** | 정산운영팀 강세린, 플랫폼팀 문도윤 |
| **공유 대상** | 정산운영팀, 플랫폼팀 |

## 1. 점검 배경
- 야간 정산 파일 4건이 중복 생성되는 문제가 발생하여 원인을 점검함.

## 2. 점검 대상
- 결제 서버 및 정산 서버 (두 서버 모두 **테스트 환경**)

## 3. 주요 결정 사항
- **서버 자동 재시도 기능 중지**: 11/16(월) 09:00부터 중지함.
- **대조 범위**: 테스트 거래만 포함하며, 실제 고객 거래는 제외함.

## 4. 향후 일정 및 역할

| 일정 | 담당 | 내용 |
|---|---|---|
| 11/16(월) 09:00 ~ 10:00 | 플랫폼팀 | 두 서버의 중복 생성 기록 조회 (필수) |
| 11/16(월) 이후 | 플랫폼팀 | 조회 결과를 취합하여 회의 자료실에 비교표 업로드 |
| 비교표 업로드 알림 수신 후 2시간 이내 | 정산운영팀 | 파일 건수 대조 (필수) |
| 11/19(목) | 플랫폼팀 | 재발 방지 보고서 제출 |
