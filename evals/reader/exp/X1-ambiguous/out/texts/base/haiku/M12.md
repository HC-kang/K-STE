# 다온빛전시 입장 장비 점검 운영 절차(런북)

| 항목 | 내용 |
|---|---|
| 문서 목적 | 입장 장비의 중복 입장권 인식 방지 기능 점검 절차를 현장 안내 직원에게 안내 |
| 점검 일시 | 2026년 12월 5일(토) 09:00~09:30 |
| 점검 장소 | 북문 안내데스크, 남문 스캐너 위치 |
| 대상 장비 | 북문 스캐너, 남문 스캐너 |
| 기록 도구 | 미루 앱(북문 안내데스크 비치) |

---

## 1. 역할 및 담당

| 역할 | 담당 업무 | 비고 |
|---|---|---|
| 현장 안내 직원 | 시험권 인식 테스트, 미루 앱에 점검 기록 작성, 이상 시 장비 사용 중지 | 본 런북의 주 수행자 |
| 기술팀 | 장비 전원 관리, 장비 조작, 09:20 인식 설정 초기화 | 장비 문의: **내선 582** |
| 운영지원팀 | 시험권 발급, 현장 대기 | |
| 기술팀장 서하겸 | 사용 중지 장비의 재사용 승인 | 승인 전까지 재사용 불가 |

---

## 2. 사전 준비 (점검 시작 전)

1. **앱 사용 안내 숙지**: 점검 시작 전에 미루 앱 사용 안내를 읽는다. 점검 기록 작성 방법을 미리 확인한다.
2. **시험권 확인**: 운영지원팀에서 시험권 12장(스캐너별 6장)을 수령하였는지 확인한다.
   - 시험권은 **점검 전용**이며, 실제 관람객 입장권으로 **절대 사용하지 않는다.**
3. **수기 입장대장 확인**: 장비 사용 중지 시 대체 수단으로 쓸 수기 입장대장이 북문 안내데스크에 준비되어 있는지 확인한다.
4. **내선 582 연락 가능 여부 확인**: 기술팀 연락 수단을 준비한다.

---

## 3. 점검 절차 (타임라인)

| 시각 | 담당 | 작업 내용 |
|---|---|---|
| 09:00 | 기술팀 | 북문 스캐너, 남문 스캐너 전원 ON |
| 09:00~09:05 | 안내 직원 | 미루 앱에 점검 기록 시작(일시, 장소, 담당자 입력) |
| 09:05~09:15 | 안내 직원 | **북문 스캐너**에 시험권 6장을 1장씩 인식시키고 결과 기록 |
| 09:15~09:20 | 안내 직원 | **남문 스캐너**에 시험권 6장을 1장씩 인식시키고 결과 기록 |
| 09:20 | 기술팀 | 스캐너 인식 설정 초기화(실행 담당: 기술팀) |
| 09:20~09:30 | 안내 직원 | 초기화 후 인식 상태 재확인(필요 시 시험권 재인식), 결과 기록 |
| 09:30 | 안내 직원 | 점검 종료, 시험권 회수, 미루 앱 기록 마무리 |

> 실제 소요 시간은 장비 상태에 따라 달라질 수 있다. 일정이 지연되면 기술팀(내선 582)과 협의한다.

---

## 4. 시험권 인식 방법

1. 스캐너 한 대에 시험권 6장을 **한 장씩** 인식시킨다.
2. 각 시험권의 인식 결과(성공/실패)를 미루 앱에 기록한다.
3. 같은 스캐너에서 **인식 실패가 2회 이상** 발생하면 아래 5번 기준을 따른다.
4. 한 스캐너의 테스트가 끝난 뒤 다른 스캐너를 진행한다.

---

## 5. 장비 사용 중지 기준 (필수 준수)

- **같은 스캐너에서 인식 실패가 2회 이상 발생하면, 안내 직원은 즉시 해당 장비의 사용을 중지한다.**
- 중지 즉시 다음을 수행한다.
  1. 해당 장비에 "사용 중지" 표시를 한다(안내 직원이 현장에서 표시).
  2. 미루 앱에 중지 시각, 실패 횟수, 상황을 기록한다.
  3. 기술팀(내선 582)에 연락한다.
  4. 해당 장비 대신 **수기 입장대장**으로 입장을 처리한다.
- 사용 중지된 장비는 **기술팀장 서하겸의 재사용 승인 후에만** 다시 사용할 수 있다.
- **승인 전까지는 수기 입장대장을 사용한다.**

---

## 6. 점검 종료 후 처리

1. 시험권 12장을 모두 회수한다. 사용하지 않은 시험권이나 실패한 시험권도 모두 회수한다.
2. 회수한 시험권을 **북문 안내데스크의 잠금함**에 보관하고 잠금 상태를 확인한다.
3. 미루 앱에 최종 점검 결과(북문/남문 각각의 성공·실패 횟수, 사용 중지 여부)를 기록하고 저장한다.
4. 사용 중지된 장비가 있으면 재사용 승인 요청 상태를 기술팀에 공유한다.

---

## 7. 비상 연락

| 상황 | 연락처 |
|---|---|
| 장비 문의, 장비 이상 | 기술팀 내선 **582** |
| 시험권 관련 문의 | 운영지원팀 |
| 재사용 승인 요청 | 기술팀장 서하겸 (기술팀 경유) |
