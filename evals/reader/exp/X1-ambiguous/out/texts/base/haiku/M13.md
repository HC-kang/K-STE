# [묶음 5 · PR 5-1] 노벨릿커머스 주문 중복 차단 변경

**개발 담당:** 서리안
**검증 담당:** 주문QA팀
**문의:** 사내 #주문변경 채널

## 개요

주문 API의 재시도 처리 모듈에서 동일한 요청 키가 재사용되면 주문이 중복 생성되는 문제를 수정합니다. 동일 요청 키를 수신한 뒤 90초 동안 중복 주문 생성을 차단합니다.

## 변경 위치

- 주문 API 재시도 처리 모듈

## 변경 내용

1. **중복 차단 기준 추가**
   - 동일 요청 키를 수신하면 90초 동안 같은 키의 요청을 중복으로 판단하고 주문 생성을 차단합니다.
   - 요청 키가 없는 요청은 기존 처리 방식을 그대로 유지합니다.

2. **요청 로그 보관 기간 변경**
   - 서버의 요청 로그 보관 기간을 48시간으로 변경합니다.

## 대상 환경

- 스테이징 주문 서버
- 스테이징 환불 서버

두 서버 모두 비교 시험에 사용합니다.
