# PR 5-2: 모아결에듀 강의 자막 설정 화면 개선

**묶음:** 5
**개발 담당:** 한도윤
**접근성 검토 담당:** 윤세하
**문의:** 사내 #자막검토 채널

## 변경 요약

학습 웹의 자막 설정 패널에서 키보드 초점 표시가 배경과 구별되지 않던 문제를 수정했습니다.

**변경 위치:** 학습 웹 자막 설정 패널

**주요 변경 사항**
- 키보드 초점 표시가 배경과 구별되도록 수정
- 자막 글자 크기 기본값을 20px로 설정
- 자막 글자 크기 선택 범위를 16~32px로 설정
- 저장된 사용자 설정이 있으면 저장값을 우선 적용

## 검토 범위

- **검토 환경:** 사내 미리보기 사이트의 강의 L-28
- **제외 대상:** 외부 공개 강의

검토 담당자는 확대 화면(화면 확대 상태)도 함께 확인해 주시기 바랍니다.
