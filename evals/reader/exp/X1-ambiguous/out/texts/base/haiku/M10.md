# 누리핀물류 야간 배차 점검 런북

| 항목 | 내용 |
|---|---|
| 목적 | 야간 중복 배차 방지 |
| 일시 | 2026년 11월 12일(목) 22:00~23:00 |
| 점검 대상 | 동부 배차 서버, 서부 배차 서버 (두 서버 모두 대기열 수집 대상) |
| 사용 도구 | 관제실 단말의 루온 콘솔 > '야간 점검' 메뉴 |
| 관제 담당자 | 대기 건수 기록, 신규 배차 중지·재개 |
| 플랫폼팀 | 서버 재시작 (22:30) 실행 |
| 배차지원팀 | 운송사 연락 (22:00~23:00 대기), 문의 내선 731 |

## 1. 사전 준비 (점검 전 확인)

- [ ] 관제실 단말에서 루온 콘솔 로그인 및 '야간 점검' 메뉴 접속 확인
- [ ] 두 서버(동부, 서부)의 대기 건수가 화면에 정상 표시되는지 확인
- [ ] 점검표(4장 양식) 준비 (인쇄본 또는 공유 시트)
- [ ] 플랫폼팀, 배차지원팀 담당자와 22:00 이전에 대기 상태 확인
- [ ] 교대 인수인계: 점검 담당자와 대리 담당자 지정

## 3. 신규 배차 중지 기준

**기준**: 서버의 대기 건수가 **40건 이상**이면 해당 서버의 **신규 배차를 즉시 중지**합니다.

1. 대기 건수 40건 이상 확인 시 해당 서버를 즉시 중지 대상으로 판단
2. 콘솔에서 해당 서버의 신규 배차 중지 처리
3. 중지 시각, 대기 건수, 처리자를 점검표에 기록
4. 배차지원팀에 중지 사실 공유 (운송사 안내 필요 시)

**예외**: **긴급 의료 운송은 중지 대상에서 제외**합니다. 긴급 의료 운송 건은 중지 상태에서도 배차를 허용하며, 해당 건은 점검표 비고란에 별도 기록합니다.

## 4. 신규 배차 재개 기준

- 중지한 서버의 대기 건수가 **10건 이하**로 떨어지면 관제 담당자가 신규 배차를 **재개**합니다.
- 재개 시각과 대기 건수를 점검표에 기록합니다.
- 재개 판단이 애매하면(예: 10건 전후를 오가는 경우) 배차지원팀(내선 731)과 협의합니다.

## 5. 서버 재시작 (22:30)

- 실행 담당: **플랫폼팀** (관제 담당자는 조작하지 않음)
- 관제 담당자 역할:
  - 재시작 직전·직후 두 서버 대기 건수 기록
  - 재시작 중 대기 건수가 비정상적으로 변하면 플랫폼팀에 즉시 알림
  - 재시작 후 서버가 정상 수집 상태인지 콘솔에서 확인 후 플랫폼팀에 회신
- 재시작 중 신규 배차 중지 기준(40건)은 계속 적용합니다.

## 6. 점검 종료 후 처리

1. **점검표 제출**: 11월 13일(금)까지 제출
2. **운영 게시판 결과 요약 게시**: 점검 종료(23:00) 후 게시
   - 게시 내용 예시:
     - 점검 일시 및 대상
     - 서버별 최고·최저 대기 건수
     - 신규 배차 중지 여부, 시각, 재개 시각
     - 긴급 의료 운송 예외 건 수
     - 재시작 결과 (정상 여부)
     - 특이사항 및 후속 조치

## 9. 메모에서 확인이 필요한 사항

운영 전에 아래 항목을 담당자와 확정해 두시기를 권장합니다.

1. **신규 배차 중지·재개 방법**: 콘솔에서 어떤 버튼이나 메뉴로 처리하는지 메모에 없습니다.
2. **긴급 의료 운송 식별 방법**: 콘솔에서 해당 건을 어떻게 구분하는지, 누가 최종 판단하는지 정해야 합니다.
3. **재시작 중 대기 건수 해석**: 22:30 재시작 시 대기 건수가 일시적으로 0이 되거나 급증할 수 있는지, 그 경우 중지 판단을 어떻게 할지 확인이 필요합니다.
4. **재시작 실패 시 절차**: 플랫폼팀이 재시작에 실패하거나 지연될 때 관제 담당자의 대응 기준이 없습니다.
5. **점검표 형식과 제출 경로**: 제출 방식(이메일, 공유 폴더 등)과 제출 대상자가 명시되지 않았습니다.
6. **운영 게시판 게시 담당 및 기한**: 누가 게시하는지, 종료 후 몇 분 이내에 올려야 하는지 정해야 합니다.
7. **연락처 공란 항목**: 플랫폼팀 및 운송사 연락 담당의 연락처를 채워 넣어야 합니다.
8. **대리 담당자**: 점검 중 관제 담당자가 자리를 비울 경우의 대체 인력이 정해져 있는지 확인이 필요합니다.

필요하시면 이 런북을 점검표 시트 형식이나 운영 게시판용 요약문 템플릿으로도 정리해 드리겠습니다.
