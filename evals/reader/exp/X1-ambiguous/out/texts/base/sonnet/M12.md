# 다온빛전시 입장 장비 점검 런북 (현장 안내 직원용)

## 1. 개요
- **목적**: 입장권 중복 인식 방지
- **일시**: 12/05(토) 09:00~09:30
- **대상 장비**: 북문 스캐너, 남문 스캐너
- **기록 위치**: 북문 안내데스크의 미루 앱 (점검 기록 작성)

## 2. 역할 분담
| 담당 | 역할 |
|---|---|
| 현장 안내 직원 | 시험권 인식 점검, 점검 기록 작성, 시험권 회수·보관 |
| 기술팀 | 장비 조작 (전원 켜기, 설정 초기화), 장비 문의 대응 |
| 운영지원팀 | 시험권 발급 (현장 대기) |

**장비 문의: 기술팀 내선 582**

## 3. 사전 준비 (점검 시작 전)
1. 미루 앱의 **사용 안내**를 읽어 둔다. (점검 시작 전 숙지 권장)
2. 북문 안내데스크에서 미루 앱을 열고 점검 기록을 작성할 수 있는지 확인한다.
3. 운영지원팀에서 시험권을 발급받는다. (스캐너당 6장, 총 12장)

## 4. 진행 절차

| 시각 | 담당 | 내용 |
|---|---|---|
| 09:00 | 기술팀 | 북문·남문 스캐너 전원 켬 |
| 09:00 이후 | 안내 직원 | 전원이 켜진 것을 확인하고 점검 시작 |
| 점검 중 | 안내 직원 | 각 스캐너에서 시험권 6장을 인식시키고 결과를 미루 앱에 기록 |
| 점검 종료 후 | 안내 직원 | 시험권 회수 후 북문 안내데스크 잠금함에 보관 |
| 09:20 | 기술팀 | 스캐너의 인식 설정 초기화 |
| 09:30 | - | 점검 종료 |

### 4.1 시험권 인식 점검
1. 북문 스캐너에서 시험권 6장을 차례로 인식시킨다.
2. 남문 스캐너에서 시험권 6장을 차례로 인식시킨다.
3. 각 인식 결과(성공/실패)를 장비별로 미루 앱에 기록한다.

> ⚠️ **실제 관람객 입장권은 시험에 절대 사용하지 않는다.** 반드시 운영지원팀이 발급한 시험권만 사용한다.

### 4.2 시험권 회수 및 보관
- 점검이 끝나면 사용한 시험권을 모두 회수한다.
- 북문 안내데스크의 **잠금함**에 보관한다.

## 5. 이상 발생 시 대응

### 5.1 인식 실패 기준
- **같은 스캐너에서 인식 실패가 2회 이상**이면 안내 직원은 **해당 장비 사용을 즉시 중지**한다.

### 5.2 조치 순서
1. 해당 스캐너 사용을 즉시 중지한다.
2. 기술팀(내선 582)에 연락한다.
3. 실패 내용을 미루 앱에 기록한다.
4. 승인 전까지는 **수기 입장대장**을 사용한다.

### 5.3 재사용 조건
- 사용 중지한 장비는 **기술팀장 서하겸의 재사용 승인**을 받은 후에만 다시 사용할 수 있다.
- 승인 전에는 해당 장비를 사용하지 않고 수기 입장대장으로 운영한다.

## 6. 체크리스트
- [ ] 미루 앱 사용 안내를 읽었다
- [ ] 운영지원팀에서 시험권을 받았다 (스캐너당 6장)
- [ ] 09:00 북문·남문 스캐너 전원이 켜졌다 (기술팀)
- [ ] 북문 스캐너 시험권 6장 인식 및 기록 완료
- [ ] 남문 스캐너 시험권 6장 인식 및 기록 완료
- [ ] 실제 관람객 입장권을 사용하지 않았다
- [ ] 같은 스캐너 인식 실패 2회 이상 여부를 확인했다 (해당 시 사용 중지)
- [ ] 시험권을 회수해 북문 안내데스크 잠금함에 보관했다
- [ ] 09:20 인식 설정 초기화가 완료되었다 (기술팀)

- 인식 실패 시 기술팀 연락 및 미루 앱 기록 절차는 일반적인 운영 관행에 따라 제가 보완한 내용이니, 실제 방침과 맞는지 확인 부탁드립니다.
