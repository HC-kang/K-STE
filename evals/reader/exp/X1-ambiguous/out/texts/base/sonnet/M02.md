# [공지] 자료보관 서비스 점검 안내 (12/5 토)

모래빛설계 국내·해외 사무소 전 직원 여러분께,

저장장치 교체를 위해 자료보관 서비스 점검을 진행합니다. 점검 시간에는 두 서비스에 접속할 수 없으니 아래 내용을 확인하시고 업무에 차질이 없도록 준비해 주시기 바랍니다.

## 1. 점검 개요
- **목적**: 저장장치 교체
- **대상**: 설계자료함, 계약자료함 (사내 포털의 같은 이름 메뉴로 접속)
- **일시**: 12월 5일(토) 10:00~14:00 (한국 시각 기준)
- **영향**: 점검 시간 동안 두 서비스 모두 접속 불가

## 2. 전 직원 준수 사항
- **점검 시작 전까지** 설계자료함·계약자료함에서 열어 둔 파일을 모두 저장하고 종료해 주세요. (필수)
- **12/4(금)** 개인 보관 파일 업로드가 필요한 경우 이날까지 처리해 주세요.
- 자료함의 **외부 공유 링크는 점검 종료 후에도 사용이 중지**됩니다. 외부 전달이 필요한 자료는 미리 다른 방법을 준비해 주세요.

## 3. 점검 중 긴급 열람
점검 중 불가피하게 자료를 열람해야 하는 경우 아래 절차를 따라 주세요.

1. 당직 자료관리자에게 **사내 메신저**로 열람을 요청합니다.
2. 자료관리팀이 승인한 건에 한해 **임시 열람실**에서 열람할 수 있습니다.
3. 열람 조건
   - 1인당 최대 **3개 파일**
   - 열람 시간은 **승인 통보 후 20분**
   - **파일 다운로드 불가**

## 4. 담당 부서
- **정보운영팀**: 저장장치 교체 수행
- **자료관리팀**: 긴급 열람 승인
