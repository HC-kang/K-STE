# PR 5-2: 모아결에듀 강의 자막 설정 화면 개선 (묶음 5)

## 개요
학습 웹의 **자막 설정 패널**에서 키보드 초점 표시가 배경과 구별되지 않던 문제를 수정했습니다. 수정은 반영 완료되었습니다.

- 개발 담당: 한도윤
- 접근성 검토 담당: 윤세하
- 문의: 사내 #자막검토 채널

## 변경 내용
- **키보드 초점 표시 개선**: 자막 설정 패널에서 키보드로 이동할 때 초점 표시가 배경과 구별되도록 수정했습니다.
- **자막 글자 크기 기준**
  - 기본값: 20px
  - 선택 범위: 16~32px
  - 저장된 사용자 설정이 있으면 저장값을 우선 적용합니다.
