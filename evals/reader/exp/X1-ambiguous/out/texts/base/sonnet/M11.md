# 모래별식품 포장라인 라벨 검사 운영 절차 (반장용)

## 1. 목적
출고 라벨 누락 방지

## 2. 일정 및 장소
| 항목 | 내용 |
|---|---|
| 검사 일시 | 11/20(금) 08:00~10:00 |
| 검사 장소 | 2공장 검사대 |
| 기록 입력 | 검사대의 세온 단말 |
| 검사 기록 제출 기한 | 11/23(월) |
| 품질팀 검사 지원 | 08:00~10:00 |
| 검사 기준 문의 | 품질팀 내선 426 |

## 3. 검사 절차
1. **검사 대상 확인**: 생산 로트마다 검사합니다. **시험 생산 로트는 검사 대상에서 제외**합니다.
2. **상자 검사**: 로트당 **12상자**를 검사해 라벨 누락 여부를 확인합니다.
3. **라벨 사진 (권장)**: 교대 전에 라벨 사진을 남기면 좋습니다. 필수는 아닙니다.
4. **기록 입력**: 2공장 검사대의 세온 단말에 검사 결과를 입력합니다.

## 4. 판정 및 조치
| 판정 | 조치 |
|---|---|
| 12상자 중 라벨 누락 **1상자 이하** | 별도 보류 조치 없음. 결과를 기록합니다. |
| 12상자 중 라벨 누락 **2상자 이상** | 아래 보류 절차를 즉시 진행합니다. |

### 출고 보류 절차 (누락 2상자 이상)
1. 해당 로트의 **출고를 즉시 보류**합니다.
2. 보류 중인 로트의 상자를 **2공장 격리구역 B**로 이동합니다.
3. 보류 사실과 검사 결과를 세온 단말에 기록합니다.

### 보류 해제
- 해제 승인은 **품질팀장 류다온만** 할 수 있습니다.
- **승인 전에는 출고를 재개하지 않습니다.** 반장이 임의로 재개할 수 없습니다.

## 5. 검사 후 제출
- 검사 기록을 **11/23(월)까지 제출**합니다.

## 6. 문의
- 검사 기준: 품질팀 내선 **426** (지원 시간 08:00~10:00)

---

**확인이 필요한 사항**
- 메모의 "처리함"은 무슨 뜻인지 알 수 없어 런북에 반영하지 않았습니다. 의도를 알려 주시면 추가하겠습니다.
- 11/23 검사 기록의 제출처(받는 사람 또는 시스템)가 메모에 없어 비워 두었습니다.
- 라벨 누락이 1상자 이하일 때의 별도 조치는 메모에 없어 "기록만 함"으로 적었습니다. 다르다면 알려 주세요.
