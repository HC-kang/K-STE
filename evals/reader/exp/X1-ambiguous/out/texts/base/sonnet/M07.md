# 누리결제 정산 점검 회의록

**공유 대상:** 정산운영팀, 플랫폼팀

## 1. 회의 개요
| 항목 | 내용 |
|---|---|
| 회의명 | 누리결제 정산 점검 회의 |
| 일시 | 11/12(목) 10:00~10:30 |
| 장소 | 본사 3층 소회의실 |
| 참석자 | 정산운영팀 강세린, 플랫폼팀 문도윤 |

## 2. 점검 배경
- 점검 원인: 야간 정산 파일 4건 중복 생성
- 점검 대상: 결제 서버, 정산 서버 (두 서버 모두 테스트 환경)

## 3. 결정 사항 및 조치 내용

### 3-1. 플랫폼팀
| 항목 | 내용 | 기한 |
|---|---|---|
| 중복 생성 기록 조회 (필수) | 결제 서버와 정산 서버 두 곳의 중복 생성 기록 조회 | 11/16(월) 09:00~10:00 |
| 자동 재시도 기능 중지 | 두 서버의 자동 재시도 기능 중지 | 11/16(월) 09:00 중지 |
| 비교표 업로드 | 조회 결과를 모아 비교표를 작성하여 회의 자료실에 업로드 | 조회 완료 후 |
| 재발 방지 보고서 제출 | 사내 자료실 ‘정산점검/11월’에 PDF로 저장 | 11/19(목) |

### 3-2. 정산운영팀
| 항목 | 내용 | 기한 |
|---|---|---|
| 파일 건수 대조 (필수) | 비교표 업로드 알림 수신 후 파일 건수 대조 | 알림 수신 후 2시간 이내 |

- 대조 범위: 테스트 거래만 포함하며, 실제 고객 거래는 제외

## 4. 일정 요약
| 일자 | 내용 |
|---|---|
| 11/12(목) | 정산 점검 회의 |
| 11/16(월) 09:00 | 자동 재시도 기능 중지 |
| 11/16(월) 09:00~10:00 | 플랫폼팀 중복 생성 기록 조회 |
| 비교표 업로드 후 | 정산운영팀 파일 건수 대조 (알림 수신 후 2시간 이내) |
| 11/19(목) | 재발 방지 보고서 제출 |

## 5. 보고서 제출 규정
- 저장 위치: 사내 자료실 ‘정산점검/11월’
- 파일 형식: PDF

## 6. 문의
- 운영지원팀 윤하린
- 사내 메신저 ‘정산점검 문의’

참고: 메모에 자동 재시도 기능 중지 대상이 "서버"로만 되어 있어 두 서버 모두로 정리했습니다. 한 서버만 해당된다면 수정이 필요합니다. 또한 재발 방지 보고서 제출 담당 팀이 메모에 명시되어 있지 않아 플랫폼팀 항목에 넣었으니 확인 부탁드립니다.
