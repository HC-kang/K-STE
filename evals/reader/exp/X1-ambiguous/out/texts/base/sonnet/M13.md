# [묶음 5 · PR 5-1] 노벨릿커머스 주문 중복 차단 변경

## 개요
주문 API의 재시도 처리 모듈에서, 동일한 요청 키가 재사용될 때 주문이 중복 생성되는 문제를 수정합니다. 아울러 서버의 요청 로그 보관 기간을 48시간으로 변경합니다.

## 담당 및 문의
- 개발 담당: 서리안
- 검증 담당: 주문QA팀
- 문의: 사내 #주문변경 채널

## 변경 내용
- **변경 위치:** 주문 API의 재시도 처리 모듈
- **문제:** 동일 요청 키를 재사용하면 주문이 중복 생성됨
- **새 중복 차단 기준:** 동일 요청 키 수신 후 **90초** 이내의 재요청을 차단
- **요청 키가 없는 요청:** 기존 처리 방식 유지 (변경 없음)
- **요청 로그 보관 기간:** 48시간으로 변경

## 대상 환경
- 스테이징 주문 서버
- 스테이징 환불 서버

두 서버 모두 비교 시험에 사용했습니다.
