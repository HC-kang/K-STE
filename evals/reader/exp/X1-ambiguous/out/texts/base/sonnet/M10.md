# 누리핀물류 야간 배차 점검 런북 (관제 담당자용)

## 1. 개요
- **목적**: 중복 배차 방지
- **일시**: 11/12(목) 22:00~23:00
- **수행자**: 야간 배차 관제 담당자
- **사용 도구**: 관제실 단말 → 루온 콘솔 → '야간 점검' 메뉴
- **점검 대상**: 동부 배차 서버, 서부 배차 서버 (두 서버 모두 대기열 수집 대상)

## 2. 역할 분담 (22:00~23:00 대기)
| 담당 | 역할 |
|---|---|
| 관제 담당자 | 대기 건수 점검·기록, 신규 배차 중지/재개 |
| 플랫폼팀 | 서버 조작 (22:30 서버 재시작 실행) |
| 배차지원팀 | 운송사 연락 |

## 3. 절차

### 3-1. 사전 준비 (22:00 전)
1. 관제실 단말에서 루온 콘솔에 접속합니다.
2. '야간 점검' 메뉴를 열고 동부·서부 두 서버의 대기열이 모두 수집되는지 확인합니다.
3. 점검표를 준비합니다.

### 3-2. 대기 건수 점검 (22:00부터 10분 간격)
1. 22:00부터 10분 간격으로 점검합니다 (22:00, 22:10, 22:20, 22:30, 22:40, 22:50, 23:00).
2. 매회 **동부 서버와 서부 서버의 대기 건수를 각각** 점검표에 기록합니다.

### 3-3. 신규 배차 중지 기준
- 어느 서버든 **대기 건수가 40건 이상**이면 해당 서버의 **신규 배차를 즉시 중지**합니다.
- **예외**: 긴급 의료 운송은 중지 대상에서 제외하며 계속 배차합니다.
- 중지 사실과 시각을 점검표에 함께 기록합니다.

### 3-4. 서버 재시작 (22:30)
- 22:30에 서버 재시작이 진행됩니다. **실행 담당은 플랫폼팀**이며, 관제 담당자는 서버를 직접 조작하지 않습니다.
- 재시작 전후에도 정해진 간격에 따라 대기 건수를 기록합니다.
- 운송사 연락이 필요하면 배차지원팀에 요청합니다.

### 3-5. 신규 배차 재개
- 중지한 서버의 **대기 건수가 10건 이하**가 되면 관제 담당자가 해당 서버의 신규 배차를 **재개**합니다.
- 재개 시각을 점검표에 기록합니다.
- 재개 기준 및 절차 문의: **배차지원팀 내선 731**

## 4. 점검 종료 후
1. 점검 종료 후 **결과 요약을 운영 게시판에 게시**합니다.
2. **11/13(금)** 까지 점검표를 제출합니다.

## 5. 한눈에 보는 체크리스트
- [ ] 루온 콘솔 '야간 점검' 접속, 두 서버 대기열 수집 확인
- [ ] 22:00부터 10분 간격, 동부·서부 각각 기록
- [ ] 40건 이상 서버 신규 배차 즉시 중지 (긴급 의료 운송 제외)
- [ ] 22:30 서버 재시작 (플랫폼팀 실행)
- [ ] 10건 이하 시 신규 배차 재개
- [ ] 결과 요약 운영 게시판 게시
- [ ] 11/13(금) 점검표 제출

## 6. 문의
- 배차지원팀 내선 **731**

---
참고: 메모에 점검표 제출처와 마지막 점검 시각(23:00 포함 여부)이 명시되어 있지 않아, 23:00 점검은 포함하는 것으로 작성했습니다. 다르다면 알려 주세요.
