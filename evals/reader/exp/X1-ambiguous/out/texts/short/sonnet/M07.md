# 누리결제 정산 점검 회의록

## 회의 정보

- 일시는 11/12(목) 10:00-10:30이다.
- 장소는 본사 3층 소회의실이다.
- 참석자는 정산운영팀 강세린, 플랫폼팀 문도윤이다.

## 점검 배경

야간 정산 파일 4건이 중복 생성되어 점검을 하기로 했다. 점검 대상은 결제 서버와 정산 서버이며, 두 서버 모두 테스트 환경이다.

## 결정 사항

- 플랫폼팀은 11/16(월) 09:00-10:00에 결제 서버와 정산 서버의 중복 생성 기록을 조회해야 한다.
- 조회 결과를 모아 회의 자료실에 비교표를 업로드한다.
- 서버의 자동 재시도 기능을 중지한다. 중지 시각은 11/16(월) 09:00이다.
- 정산운영팀은 비교표 업로드 알림을 받은 뒤 2시간 이내에 파일 건수를 대조해야 한다.
- 파일 건수 대조 범위에는 테스트 거래만 포함한다. 실제 고객 거래는 제외한다.
- 재발 방지 보고서는 11/19(목)에 제출한다.
- 보고서는 사내 자료실 '정산점검/11월'에 PDF 형식으로 저장한다.

## 확인 필요

- 비교표를 업로드하는 팀 또는 담당자는 누구인가?
- 자동 재시도 기능을 중지하는 팀 또는 담당자는 누구인가?
- 자동 재시도 기능 중지 대상은 결제 서버와 정산 서버 두 곳인가, 한 곳인가?
- 재발 방지 보고서를 제출하는 팀 또는 담당자는 누구이며, 제출 대상은 누구인가?

## 문의

문의는 운영지원팀 윤하린에게 사내 메신저 '정산점검 문의'로 한다.
