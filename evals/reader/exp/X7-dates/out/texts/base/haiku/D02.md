# [전사 공지] 모루빛디자인 자료 분류 교육 안내

안녕하세요, 임직원 여러분.

모루빛디자인 자료 분류 교육을 아래와 같이 진행하오니 참여해 주시기 바랍니다. **디자이너와 지원 부서의 정규직·계약직 직원 모두 참여가 필수**입니다.

## 1. 교육 일정

| 일정 | 내용 |
|---|---|
| **12/1(화)까지** | 교육 계정 활성화 **(필수)** |
| **12/2(수)** | 교육 과정 선택 |
| **12/7(월)** | 연습 파일 업로드 |
| **12/10(목)** | 이해도 평가 응시 |
| **12/15(화) 14:00** | 교육팀 실시간 질의응답 *(선택 참석)* |

## 2. 과정 선택 기준

- **디자이너**: 이미지 과정 선택 필수
- **지원 부서 직원**: 문서 과정 선택 필수
- **두 직무를 겸임하는 경우**: 이미지 과정만 선택

## 3. 제출 및 평가 안내

- **연습 파일**: PDF 2개 제출 필수, 파일당 6MB 이하
- **이해도 평가**: 총 12문항

## 4. 이용 위치

과정 선택, 연습 파일 업로드, 평가 응시, 계정 활성화는 모두 아래 위치에서 진행합니다.

> **교육 시스템 빛배움 > 자료 분류**

**실시간 질의응답**은 빛배움 화상교육실에서 진행되며, 참석은 선택 사항입니다.

## 5. 문의처

- **계정 관련**: 운영팀 서나겸 (내선 264)
- **교육 내용 관련**: 교육팀 도유찬 (내선 719)

기한 내에 계정을 활성화하지 못하면 이후 단계를 진행할 수 없으니, 12/1(화)까지 반드시 완료해 주시기 바랍니다.
