# [전사 공지] 다온궤물류 방한용품 지급 안내

**대상:** 배송 기사, 거점 운영직, 본사 전 직원

안녕하십니까. 다온궤물류 복지팀입니다.
올겨울 방한용품을 아래와 같이 지급하오니, 일정에 맞추어 각자 등록을 완료해 주시기 바랍니다.

## 1. 주요 일정

| 일정 | 내용 | 비고 |
|---|---|---|
| **11/2(월)까지** | 조끼 치수 등록 | **필수** |
| 11/4(수) | 방한용품 품목 선택 | |
| 11/10(화) | 수령 거점 등록 | |
| 11/16(월) | 수령 담당자 정보 입력 | |
| 11/23(월) 08:00 | 복지팀 거점별 물품 배부 시작 | |

## 2. 등록 방법

- **위치:** 복지 시스템 온꾸러미 > 방한용품
- **등록 항목:** 조끼 치수, 품목 선택, 수령 거점, 수령 담당자 정보

## 3. 지급 기준

- **기본 지급:** 조끼 1벌
- **추가 품목:** 아래 중 **1개 선택 필수**
  - 장갑 2켤레
  - 목도리 1개

## 4. 수령 안내

- **수령 장소:** 본인이 등록한 거점의 운영실 (본사 직원도 거점에서 수령합니다.)
- **수령 원칙:** 본인 직접 수령을 원칙으로 합니다.
- **대리 수령:** 휴직자에 한해 같은 팀 직원이 대리 수령할 수 있습니다.
- **수령 담당자 정보:** 실제 수령자의 이름과 사원번호를 정확히 입력해 주십시오.

## 5. 문의

- **치수·품목 문의:** 복지팀 한소율 (내선 356)
- **거점·수령 문의:** 배송지원팀 류태오 (내선 847)

기한 내 등록이 완료되지 않을 경우 지급에서 제외될 수 있으니, 각자 일정을 꼭 확인해 주시기 바랍니다. 감사합니다.
