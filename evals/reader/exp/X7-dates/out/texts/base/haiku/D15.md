# 묶음 5: 강의 플레이어 자막 글자 크기 설정 추가

## 변경 내용

강의 플레이어에 자막 글자 크기 설정을 추가했습니다. 사용자가 고른 값은 사용자 계정에 저장되어 다음 접속 때도 유지됩니다.

## 설정 값

| 항목 | 값 |
|---|---|
| 선택 가능 크기 | 16px, 22px, 28px |
| 기본값 | 22px |
| 저장 위치 | 로그인 사용자 계정 |

## 적용 범위

- **적용**: 로그인 사용자의 녹화 강의
- **미적용**: 실시간 강의. 기존 자막 설정을 그대로 유지합니다.

## 일정 및 담당

| 날짜 | 담당 | 작업 |
|---|---|---|
| 12/2 (수) | 유시온 (접근성 QA) | 키보드 탐색 검증 |
| 12/4 (금) | 배아린 (디자인) | 자막 화면 비교 자료 등록 |
| 12/8 (화) | 강로운 (리뷰어) | 변경 코드 승인 |
| 12/10 (목) 15:00 | 노해솔 (개발) | 검증 서버 기능 시연 |
| 12/15 (화) | 배아린 (디자인) | 자막 설정 도움말 제출 완료 |

## 산출물 제출 규칙

- **유시온**: 키보드 탐색 검증 결과를 이 PR 댓글에 작성합니다. (필수)
- **배아린**: 비교 자료와 도움말을 `화면검증함 CAP-64` 폴더에 등록합니다. (필수)

## 승인 조건 (리뷰어 확인용)

- 키보드 탐색 검증 **32개 항목을 모두 통과**한 경우에만 코드 승인이 가능합니다.
- 실패 항목이 하나라도 있으면 승인할 수 없습니다.

## 리뷰 체크리스트

- [ ] 16px / 22px / 28px 세 가지 값만 선택 가능한지 확인
- [ ] 기본값이 22px로 적용되는지 확인
- [ ] 선택값이 계정에 저장되고 재접속 후에도 유지되는지 확인
- [ ] 녹화 강의에만 설정이 적용되고 실시간 강의 자막 설정은 변하지 않는지 확인
- [ ] 키보드 탐색 검증 32개 항목 전체 통과 (유시온 댓글 기준)
- [ ] 비교 자료 및 도움말 등록 완료 (`화면검증함 CAP-64`)
