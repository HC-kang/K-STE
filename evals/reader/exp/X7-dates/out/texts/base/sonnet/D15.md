# [묶음 5] 강의 플레이어 자막 글자 크기 설정 추가

## 변경 내용
강의 플레이어에 **자막 글자 크기 설정**을 추가합니다. 사용자가 선택한 값은 **사용자 계정에 저장**됩니다.

## 설정 사양
| 항목 | 내용 |
|---|---|
| 선택값 | 16px, 22px, 28px (3가지) |
| 기본값 | 22px |
| 저장 위치 | 사용자 계정 |

## 적용 대상
- **적용**: 로그인 사용자의 녹화 강의
- **미적용**: 실시간 강의 (기존 자막 설정 유지)

## 일정 및 담당
| 일자 | 담당 | 내용 |
|---|---|---|
| 12/2(수) | 유시온 (접근성 QA) | 키보드 탐색 검증 |
| 12/4(금) | 배아린 (디자인) | 자막 화면 비교 자료 등록 |
| 12/8(화) | 강로운 (리뷰어) | 변경 코드 승인 |
| 12/10(목) 15:00 | 노해솔 (개발) | 검증 서버 기능 시연 |
| 12/15(화)까지 | 배아린 (디자인) | 자막 설정 도움말 제출 완료 |

## 필수 등록 사항
- **유시온**: 키보드 탐색 검증 결과를 **이 PR 댓글**에 작성해야 합니다.
- **배아린**: 화면 비교 자료와 도움말을 **화면검증함 CAP-64 폴더**에 등록해야 합니다.

## 승인 조건 (리뷰어 필독)
- 강로운 리뷰어는 **키보드 탐색 검증 32항목을 모두 통과한 경우에만** 코드를 승인할 수 있습니다.
- **실패 항목이 하나라도 있으면 승인할 수 없습니다.**
