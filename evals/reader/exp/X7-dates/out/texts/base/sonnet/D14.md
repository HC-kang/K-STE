# [묶음 5] 재고조정 화면: 차이 수량 필터 추가

## 개요
재고조정 화면에 **차이 수량 필터**를 추가하고, 목록을 **차이 수량의 절댓값 기준**으로 표시하도록 변경합니다.

## 변경 내용
- 재고조정 화면에 차이 수량 필터 추가
- 차이 수량 절댓값 기준으로 목록 표시
- **필터 기본값**: 차이 수량 절댓값 **6개 이상**

## 시범 적용 범위
- **대상**: 동문창고, 남문창고
- **제외**: 냉동 구역 상품은 필터 적용 대상에서 제외

## 검증 방법
- 검증 표본: **창고별 상품 45종**
- 표본 검증 결과는 **재고검증함 INV-73 폴더**에 등록합니다.

| 일자 | 담당 | 내용 |
|---|---|---|
| 11/18(수) | 한이솔 (물류 검증) | 표본 검증 결과를 재고검증함 INV-73 폴더에 등록 (필수) |
| 11/20(금) | 문태오 (개발) | 조회 성능 측정, 결과를 PR 댓글에 작성 (필수) |

## 병합 승인 조건
- 정라온 리뷰어는 **동문창고와 남문창고 두 곳의 표본 검증이 모두 통과한 경우에만** 병합을 승인할 수 있습니다.
- **한 창고라도 검증에 실패하면 승인할 수 없습니다.**
