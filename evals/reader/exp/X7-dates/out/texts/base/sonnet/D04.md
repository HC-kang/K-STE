**[장애 공유] 누리돛물류 운송장 시스템 ‘짐표’ 저장 오류 및 수기운송장 작성 안내**

안녕하세요, 누리돛물류 출고 담당자 여러분.

누리돛물류 운송장 시스템 ‘짐표’에서 운송장 저장 버튼 클릭 시 오류가 발생하고 있어 아래와 같이 공유드립니다.

**1. 장애 내용**
- 증상: 짐표에서 운송장 저장 버튼 클릭 시 오류 발생

**2. 출고 담당자 조치 사항**
- 저장 오류가 발생한 건마다 공유폴더 ‘출고대체’의 ‘수기운송장’ 파일을 반드시 작성해 주세요.
- 짐표에서 운송장 번호가 정상 발급된 건은 수기운송장 작성 대상에서 제외됩니다.
- 작성 기준: 수기운송장 파일 1개당 주문 최대 20건, 주문 1건당 운송장 번호 1개 입력

**3. 일정**
| 일자 | 담당 | 내용 |
|---|---|---|
| 11/10(화) | 물류운영팀 | 누락 운송장 목록을 공유폴더 ‘출고대체’에 업로드 |
| 11/12(목) | 출고 담당자 | 수기운송장 사본을 사내 메신저 ‘출고장애접수’ 채널에 제출 |
| 11/16(월) | 물류운영팀 | 주문별 운송장 대조 결과를 짐표 ‘대조결과’ 게시판에 등록 |
| 11/18(수) 10:00 | 시스템팀 | 짐표 저장 기능 재현 시험 시작 |
| 11/20(금) 17:00까지 | 출고 담당자 | 수기운송장 원본을 공유폴더 ‘원본보관’에 업로드 |

**4. 문의처** (모두 사내 메신저 개인 대화로 문의해 주세요)
- 수기운송장 작성 문의: 물류운영팀 도하린
- 짐표 오류 문의: 시스템팀 류건오

특히 원본 업로드는 11/20(금) 17:00까지이니 기한 내 꼭 완료 부탁드립니다. 업무에 불편을 드려 죄송하며, 협조에 감사드립니다.
