# 모바일 앱 검증 협의 회의록

**회의명:** 모바일 앱 검증 협의
**진행자:** 품질팀 나세온
**배포 대상:** 로에담소프트 서비스별 품질 검증 담당자

---

## 1. 일정 및 담당 업무

| 일자 | 담당 | 내용 | 등록·진행 방법 |
|---|---|---|---|
| 12/1(화) | 서비스별 품질 검증 담당자 | 테스트 계정 목록 등록 | 토비함 시스템 '앱 검증' 메뉴 |
| 12/3(목) | 서비스별 품질 검증 담당자 | 오류 재현 영상 업로드 | 토비함 시스템 '앱 검증' 메뉴 |
| 12/8(화) | 서비스별 품질 검증 담당자 | 검증 결과표 제출 | 토비함 시스템 '앱 검증' 메뉴 |
| 12/10(목) 11:00 | 품질팀 나세온 (진행) / 서비스별 품질 검증 담당자 (**참석 필수**) | 오류 분류 실습 | 본사 소담실 |
| 12/11(금)까지 | 서비스별 품질 검증 담당자 | 테스트 기기 대여 신청 완료 (**필수**) | 토비함 시스템 '기기 대여' 메뉴 |

## 2. 세부 준수 사항

### 2.1 테스트 계정
- 서비스별 테스트 계정 **4개** 등록 필수
- 계정별 사용자 유형은 중복 허용

### 2.2 오류 재현 영상
- 영상 길이 기준
  - 결제 오류: **30초 이하**
  - 로그인 오류: **60초 이하**
- 오류가 발견된 서비스: 재현 영상 업로드 필수
- 오류가 없는 서비스: 영상 업로드 면제

### 2.3 검증 결과표
- 오류 유무와 관계없이 **모든 서비스** 제출 필수

### 2.4 시스템 등록 원칙
- 계정 목록, 재현 영상, 검증 결과표는 토비함 시스템의 '앱 검증' 메뉴에 등록
- 기기 대여 신청은 같은 시스템의 '기기 대여' 메뉴 사용
