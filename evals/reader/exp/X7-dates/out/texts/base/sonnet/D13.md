# [묶음 5] 결제 API 중복 승인 차단

## 변경 요약
결제 API에서 동일 요청 키로 들어온 중복 승인을 차단하고, 이미 처리된 요청 키가 다시 들어오면 새로 승인하지 않고 **기존 승인 결과를 반환**합니다.

## 중복 판정 기준
| 항목 | 내용 |
|---|---|
| 판정 범위 | 동일 가맹점의 동일 요청 키 |
| 보관 시간 | 40분 |
| 요청 키 없는 호출 | 중복 판정에서 제외, 기존 승인 경로 사용 |

## 일정 및 담당
| 일자 | 담당 | 내용 |
|---|---|---|
| 11/3(화) | 윤하린 (개발) | 통합 테스트 결과 등록 |
| 11/5(목) | 최도윤 (운영) | 복구 절차 검토 |
| 11/10(화) | 박세온 (리뷰어) | 코드 승인 |
| 11/12(목) 14:00 | 임나루 (배포) | 검증 환경 배포 시작 |
| 11/17(화)까지 | 윤하린 (개발) | 부하 테스트 보고서 제출 완료 |

## 필수 조치
- **윤하린**: 통합 테스트 결과와 부하 테스트 보고서를 검증보관함 **PAY-58 폴더**에 등록해야 합니다.
- **최도윤**: 복구 절차 검토 결과를 **이 PR 댓글**에 작성해야 합니다.

## 승인 조건 (리뷰어 박세온)
- 통합 테스트 **120건 모두 통과**한 경우에만 코드 승인이 가능합니다.
- **실패가 1건 이상이면 승인할 수 없습니다.**
