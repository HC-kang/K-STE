# 누리결물류 야간 분류 설비 점검 런북

## 1. 개요
- **목적**: 달빛센터 분류기 S4의 야간 분류 설비 점검 절차를 표준화한다.
- **대상 설비**: 달빛센터 분류기 S4 (1대)
- **담당 기사**: 윤다솔
- **관제 담당**: 백이든
- **문의·신고 연락처**: 백이든, 사내 내선 **4628** (설비 문의 및 걸림 신고 공통)

## 2. 일정 요약

| 일자 | 작업 | 담당 |
|---|---|---|
| 11/9(월) | 센서 점검표 등록 | 윤다솔 |
| 11/11(수) | 시험 상자 통과 검사 | 윤다솔 |
| 11/13(금) | 예비 센서 수량 조사 | 윤다솔 |
| 11/16(월) 22:00 | 원격 진단 시작 | 백이든 |
| 11/18(수)까지 | 점검 결과서 제출 | 윤다솔 |

## 3. 사전 준비
- 설비 포털 **'톱니함'** 의 **S4 점검 폴더** 접근 권한을 확인한다.
- 시험 상자 **12개**를 준비한다 (상자당 무게 **2kg**).

## 4. 절차

### 4.1 센서 점검표 등록 (11/9 월)
1. 담당 기사 윤다솔이 S4 센서 점검표를 작성한다.
2. 톱니함의 S4 점검 폴더에 등록한다. (**필수**)

### 4.2 시험 상자 통과 검사 (11/11 수)
1. 윤다솔이 시험 상자 **12개**(상자당 2kg)를 모두 사용한다. (**필수**)
2. 상자를 S4에 통과시키며 걸림 발생 횟수를 센다.
3. 결과에 따라 아래 4.3 판정 기준대로 조치한다.

### 4.3 판정 및 조치

| 걸림 횟수 | 조치 |
|---|---|
| **1회 이상** | ① 윤다솔이 분류기 **정지 버튼**을 누른다. ② 백이든에게 **즉시 전화**한다 (내선 4628). (**필수**) |
| **0회** | 윤다솔이 **정상 판정**을 기록한다. (**필수**) 백이든 전화 보고는 **생략**한다. |

### 4.4 예비 센서 수량 조사 (11/13 금)
1. 윤다솔이 예비 센서 수량을 조사한다.
2. 수량 조사표를 톱니함의 S4 점검 폴더에 등록한다. (**필수**)

### 4.5 원격 진단 (11/16 월 22:00)
1. 관제 담당 백이든이 22:00에 S4 원격 진단을 시작한다.

### 4.6 점검 결과서 제출 (11/18 수까지)
1. 윤다솔이 점검 결과서를 작성한다.
2. 11/18(수)까지 톱니함의 S4 점검 폴더에 등록한다. (**필수**)

## 5. 톱니함 등록 문서 체크리스트
윤다솔은 아래 문서를 모두 **톱니함 > S4 점검 폴더**에 등록해야 한다.
- [ ] 센서 점검표 (11/9)
- [ ] 수량 조사표 (11/13)
- [ ] 점검 결과서 (11/18까지)

## 6. 비상 및 문의
- 걸림 발생 시: 분류기 정지 버튼 → 백이든에게 즉시 전화 (내선 **4628**)
- 설비 관련 문의: 백이든 (내선 **4628**)
