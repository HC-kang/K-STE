# 스캐너 관련 사내 규정 변경 안내

**수신:** 모래별물류 물류센터 작업자 및 조장 전체
**발신:** 장비관리팀
**적용 제외:** 사무동 근무자

물류센터 스캐너 운영 방식이 변경되어 아래와 같이 안내드립니다. 일정과 변경 규정을 꼭 확인해 주시기 바랍니다.

---

| 일자 | 대상 | 내용 | 비고 |
|---|---|---|---|
| 11/23(월) | 작업자 각자 | 창고길에 개인 보호구 치수 입력 | |
| 11/25(수) | 조장 각자 | 창고길에 조별 충전함 담당자 등록 | |
| 11/27(금) | 작업자 각자 | 장비실에 구형 스캐너 반납 | |

| 12/3(목)까지 | 조장 각자 | 창고길에 조별 장비 수량표 제출 | **제출 필수** |

---

## 2. 변경 규정

### 스캐너 보관
- 작업대 보관은 **폐지**됩니다.
- 근무 종료 시 작업자가 **지정 충전함에 직접 보관**해야 합니다.

### 충전함 수용 한도
- 칸당 스캐너 **4대**까지 보관할 수 있습니다.
- 한도를 초과하는 장비는 작업자가 **장비실 직원에게 인계**해야 합니다.

### 배터리 관리
- 배터리 잔량이 **25% 이하**인 스캐너는 작업자가 **사용을 중단**해야 합니다.
- 장비실 직원에게 **교체를 요청**해 주시기 바랍니다.

### 고장 스캐너
- 고장 스캐너는 **충전함에 보관할 수 없습니다.**
- 작업자가 **장비실 직원에게 직접 인계**해야 합니다.
