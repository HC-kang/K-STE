# 루미결제 결제 API 중복 승인 차단 (묶음 5)

이 PR은 결제 API가 중복 승인을 차단하도록 바꾼다. 같은 요청 키가 다시 들어오면 새로 승인하지 않고 기존 승인 결과를 반환한다.

## 중복 판정 범위

- 같은 가맹점의 같은 요청 키를 중복으로 판정한다.
- 요청 키의 보관 시간은 40분이다.
- 요청 키가 없는 호출은 중복 판정에서 제외하고, 기존 승인 경로를 사용한다.

## 일정

- 11/3(화): 윤하린(개발 담당)이 통합 테스트 결과를 등록한다.
- 11/5(목): 최도윤(운영 담당)이 복구 절차를 검토한다.
- 11/10(화): 박세온(리뷰어)이 코드를 승인한다.
- 11/12(목) 14:00에 임나루(배포 담당)가 검증 환경 배포를 시작한다.
- 11/17(화)까지 윤하린(개발 담당)이 부하 테스트 보고서를 제출해야 한다.

## 담당별로 해야 할 일

- 윤하린은 통합 테스트 결과와 부하 테스트 보고서를 검증보관함 PAY-58 폴더에 등록해야 한다.
- 최도윤은 복구 절차 검토 결과를 PR 댓글에 작성해야 한다.

## 코드 승인 조건

- 박세온은 통합 테스트 120건이 모두 통과한 경우에만 코드를 승인해도 된다.
- 박세온은 통합 테스트가 1건 이상 실패하면 코드를 승인하면 안 된다.

## 문의처

결제개발 채널 #pay-review에서 윤하린에게 문의한다. 배포 문의는 같은 채널의 임나루에게 한다.

확인 필요: 11/3(화), 11/5(목), 11/10(화)의 일이 그날 하는 일인지, 그날까지 끝낼 일인지.
