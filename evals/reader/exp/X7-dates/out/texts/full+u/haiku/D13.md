# 묶음 5: 결제 API 중복 승인 차단

이 PR은 루미결제 결제 API에 중복 승인 차단을 추가한다. 동일 요청 키가 재사용되면 기존 승인 결과를 반환한다. 이 PR은 통합 테스트 결과 등록, 복구 절차 검토, 코드 리뷰, 검증 환경 배포, 부하 테스트 보고서 제출 순으로 진행한다.

## 변경 내용

- 결제 API에 중복 승인 차단을 추가한다.
- 동일 요청 키가 재사용되면 기존 승인 결과를 반환한다.

## 중복 판정 기준

- 판정 범위는 동일 가맹점의 동일 요청 키다.
- 중복 판정에 쓰는 보관 시간은 40분이다.
- 요청 키가 없는 호출은 중복 판정에서 제외하고 기존 승인 경로를 사용한다.

## 일정

- 11/3(화): 개발 담당 윤하린이 통합 테스트 결과를 등록한다.
- 11/5(목): 운영 담당 최도윤이 복구 절차를 검토한다.
- 11/10(화): 리뷰어 박세온이 코드를 승인한다.
- 11/12(목) 14:00: 배포 담당 임나루가 검증 환경 배포를 시작한다.
- 11/17(화)까지: 개발 담당 윤하린이 부하 테스트 보고서를 제출한다.

확인 필요: 11/3(화), 11/5(목), 11/10(화). 각 날짜가 그날 하는 일인지, 그날까지 끝낼 일인지 원문에서 구분되지 않는다.

## 담당별 할 일

- 윤하린은 통합 테스트 결과와 부하 테스트 보고서를 검증보관함 PAY-58 폴더에 등록해야 한다.
- 최도윤은 복구 검토 결과를 PR 댓글에 작성해야 한다.
- 박세온은 통합 테스트 120건을 모두 통과한 경우에만 코드를 승인해도 된다. 실패가 1건 이상이면 승인하면 안 된다.
