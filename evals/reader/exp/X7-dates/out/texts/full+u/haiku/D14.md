# 묶음 5: 재고조정 화면 차이 수량 필터 추가

이 PR은 재고조정 화면에 차이 수량 필터를 추가하고, 목록을 차이 수량의 절댓값 기준으로 표시한다. 시범 적용 대상은 동문창고와 남문창고다. 병합 승인은 두 창고의 표본 검증 결과에 따른다.

## 변경 내용

- 재고조정 화면에 차이 수량 필터를 추가한다.
- 재고조정 목록을 차이 수량의 절댓값 기준으로 표시한다.

## 필터 기본값

필터의 기본값은 차이 수량 절댓값 6개 이상이다.

## 시범 적용 범위

- 시범 적용 대상은 동문창고와 남문창고다.
- 냉동 구역 상품은 필터 적용에서 제외한다.

## 표본 검증

- 검증 표본은 창고별 상품 45종이다.
- 물류 검증 담당 한이솔은 11/18(수)에 표본 검증 결과를 재고검증함 INV-73 폴더에 등록해야 한다.
  확인 필요: 11/18(수)이 실행일인지 기한인지 원문에 없다.

## 일정과 담당

- 개발 담당 문태오는 11/20(금)에 조회 성능을 측정한다. 측정 결과는 PR 댓글에 작성해야 한다.
  확인 필요: 11/20(금)이 실행일인지 기한인지 원문에 없다.
- 리뷰어 정라온은 11/24(화)에 변경 코드를 검토한다.
  확인 필요: 11/24(화)가 실행일인지 기한인지 원문에 없다.
- 교육 담당 오다빈은 11/26(목) 09:30에 창고 관리자를 대상으로 화면 시연을 진행한다.
- 개발 담당 문태오는 11/30(월)까지 운영 가이드를 재고검증함 INV-73 폴더에 업로드해야 한다.

## 병합 승인

- 정라온은 동문창고와 남문창고의 표본 검증이 모두 통과한 경우에만 병합을 승인해도 된다.
- 두 창고 중 한 곳이라도 표본 검증에 실패하면 병합을 승인하면 안 된다.

## 문의

- 변경 내용 문의는 재고개발 채널 #stock-change의 문태오에게 한다.
- 화면 시연 문의는 같은 채널의 오다빈에게 한다.
