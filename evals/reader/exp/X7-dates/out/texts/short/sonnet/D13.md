# 루미결제 결제 API 묶음 5: 중복 승인 차단

## 변경 내용

- 결제 API가 중복 승인을 차단한다.
- 같은 요청 키를 다시 쓰면 결제 API가 기존 승인 결과를 반환한다.

## 중복 판정 범위

- 결제 API는 동일 가맹점의 동일 요청 키를 중복으로 판정한다.
- 요청 키의 보관 시간은 40분이다.
- 요청 키가 없는 호출은 중복 판정에서 제외한다.
- 요청 키가 없는 호출은 기존 승인 경로를 사용한다.

## 일정

- 11/3(화): 개발 담당 윤하린이 통합 테스트 결과를 등록한다.
- 11/5(목): 운영 담당 최도윤이 복구 절차를 검토한다.
- 11/10(화): 리뷰어 박세온이 코드를 승인한다.
- 11/12(목) 14:00: 배포 담당 임나루가 검증 환경 배포를 시작한다.
- 11/17(화)까지: 개발 담당 윤하린이 부하 테스트 보고서 제출을 완료한다.

## 승인 조건

- 박세온은 통합 테스트 120건이 모두 통과한 경우에만 코드를 승인할 수 있다.
- 통합 테스트에서 실패가 1건 이상이면 박세온은 코드를 승인하면 안 된다.

## 등록 의무

- 윤하린은 통합 테스트 결과와 부하 테스트 보고서를 검증보관함 PAY-58 폴더에 등록해야 한다.
- 최도윤은 복구 검토 결과를 이 PR의 댓글에 작성해야 한다.
