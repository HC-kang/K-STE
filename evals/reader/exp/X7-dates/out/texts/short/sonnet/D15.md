# 묶음 5: 강의 플레이어 자막 글자 크기 설정

## 변경 내용

강의 플레이어에 자막 글자 크기 설정을 추가한다. 사용자가 고른 값은 사용자 계정에 저장한다.

- 선택할 수 있는 값은 16px, 22px, 28px 세 가지이다.
- 기본값은 22px이다.
- 로그인 사용자의 녹화 강의에 이 설정을 적용한다.
- 실시간 강의는 기존 자막 설정을 유지한다.

## 일정

| 날짜 | 담당 | 할 일 |
|---|---|---|
| 12/2(수) | 접근성 QA 담당 유시온 | 키보드 탐색을 검증한다. |
| 12/4(금) | 디자인 담당 배아린 | 자막 화면 비교 자료를 등록한다. |
| 12/8(화) | 리뷰어 강로운 | 변경 코드를 승인한다. |
| 12/10(목) 15:00 | 개발 담당 노해솔 | 검증 서버에서 기능을 시연한다. |
| 12/15(화)까지 | 디자인 담당 배아린 | 자막 설정 도움말을 제출한다. |

## 필수 작업

- 유시온은 키보드 탐색 검증 결과를 이 PR 댓글에 작성해야 한다.
- 배아린은 화면 비교 자료와 자막 설정 도움말을 화면검증함 CAP-64 폴더에 등록해야 한다.

## 승인 조건

강로은은 키보드 탐색 검증 32항목을 모두 통과한 경우에만 코드를 승인할 수 있다. 실패한 항목이 하나라도 있으면 강로은은 코드를 승인하면 안 된다.
