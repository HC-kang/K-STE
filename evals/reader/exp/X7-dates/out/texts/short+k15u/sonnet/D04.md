누리돛물류 운송장 시스템 '짐표'에 장애가 있어, 운송장 저장 버튼을 누르면 오류가 발생합니다.

출고 담당자는 저장 오류가 발생한 건마다 공유폴더 '출고대체'의 '수기운송장' 파일을 작성해야 합니다. 짐표에서 운송장 번호가 정상 발급된 건은 수기운송장을 작성하지 않아도 됩니다.

수기운송장 파일 1개에는 주문을 최대 20건까지 넣을 수 있습니다. 주문 1건에는 운송장 번호를 1개 입력합니다.

| 날짜 | 담당 | 할 일 |
|---|---|---|
| 11/10(화) | 물류운영팀 | 누락 운송장 목록을 공유폴더 '출고대체'에 업로드합니다. |
| 11/12(목) | 출고 담당자 | 수기운송장 사본을 사내 메신저 '출고장애접수' 채널에 제출합니다. |
| 11/16(월) | 물류운영팀 | 주문별 운송장 대조 결과를 짐표 '대조결과' 게시판에 등록합니다. |
| 11/18(수) | 시스템팀 | 10:00에 짐표 저장 기능 재현 시험을 시작합니다. |
| 11/20(금) | 출고 담당자 | 17:00까지 수기운송장 원본을 공유폴더 '원본보관'에 업로드해야 합니다. |

수기운송장 작성 문의는 물류운영팀 도하린 님께 사내 메신저 개인 대화로 보내 주세요. 짐표 오류 문의는 시스템팀 류건오 님께 사내 메신저 개인 대화로 보내 주세요.

확인 필요: 11/10, 11/12, 11/16은 그날 하는 일인지 그날까지 끝낼 일인지 원문에 없습니다. 어느 쪽인지 알려 주시면 표에 반영하겠습니다.
