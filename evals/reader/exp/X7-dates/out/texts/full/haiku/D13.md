# 결제 API 중복 승인 차단 및 동일 요청 키 재사용 시 기존 승인 결과 반환 (묶음 5)

이 PR은 결제 API에서 중복 승인을 차단하고, 동일 요청 키가 재사용되면 기존 승인 결과를 반환하도록 변경한다. 리뷰어와 운영 담당은 아래 일정과 담당별 요구 사항을 읽어야 한다.

## 변경 내용

중복 판정은 동일 가맹점의 동일 요청 키를 기준으로 한다. 보관 시간은 40분이다.

요청 키가 없는 호출은 중복 판정에서 제외하고 기존 승인 경로를 사용한다.

## 일정

1. 11/3(화): 개발 담당 윤하린이 통합 테스트 결과를 등록한다.
2. 11/5(목): 운영 담당 최도윤이 복구 절차를 검토한다.
3. 11/10(화): 리뷰어 박세온이 코드를 검토하고 승인 여부를 정한다.
4. 11/12(목) 14:00: 배포 담당 임나루가 검증 환경 배포를 시작한다.
5. 11/17(화)까지: 개발 담당 윤하린이 부하 테스트 보고서를 제출한다.

## 담당별 요구 사항

윤하린은 통합 테스트 결과와 부하 테스트 보고서를 검증보관함 PAY-58 폴더에 등록해야 한다.

최도윤은 복구 절차 검토 결과를 이 PR의 댓글로 작성해야 한다.

박세온은 통합 테스트 120건이 모두 통과한 경우에만 코드를 승인해도 된다. 실패가 1건 이상이면 승인하면 안 된다.

## 문의

문의는 결제개발 채널(#pay-review)의 윤하린에게 한다. 배포 문의는 같은 채널의 임나루에게 한다.

확인 필요: 보관 시간 40분. 최초 요청 시점부터 세는지 승인 완료 시점부터 세는지 원문에 없다.
