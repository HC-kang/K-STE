# 묶음 5: 강의 플레이어 자막 글자 크기 설정 추가

이 PR은 강의 플레이어에 자막 글자 크기 설정을 추가하고, 선택한 값을 사용자 계정에 저장한다. 설정은 로그인 사용자의 녹화 강의에 적용하며, 실시간 강의는 기존 자막 설정을 유지한다.

## 변경 내용

- 자막 글자 크기 선택값은 16px, 22px, 28px 세 가지이며, 기본값은 22px이다.
- 선택값은 사용자 계정에 저장한다.
- 적용 대상은 로그인 사용자의 녹화 강의다.
- 실시간 강의는 기존 자막 설정을 유지한다.

## 일정

- 12/2(수): 접근성 QA 담당 유시온이 키보드 탐색을 검증한다.
- 12/4(금): 디자인 담당 배아린이 자막 화면 비교 자료를 등록한다.
- 12/8(화): 리뷰어 강로운이 변경 코드를 승인한다. 승인 조건은 아래 승인 기준을 따른다.
- 12/10(목) 15:00: 개발 담당 노해솔이 검증 서버에서 기능을 시연한다.
- 12/15(화)까지: 디자인 담당 배아린이 자막 설정 도움말을 제출한다.

## 산출물과 등록 위치

- 유시온은 키보드 탐색 검증 결과를 PR 댓글에 작성해야 한다.
- 배아린은 비교 자료와 자막 설정 도움말을 화면검증함 CAP-64 폴더에 등록해야 한다.

## 승인 기준

- 강로운은 키보드 탐색 검증 32항목을 모두 통과한 경우에만 코드를 승인해도 된다.
- 검증 32항목 중 실패한 항목이 있으면 코드를 승인하면 안 된다.

## 문의

- 문의는 플레이어개발 채널 #caption-pr의 노해솔에게 한다.
