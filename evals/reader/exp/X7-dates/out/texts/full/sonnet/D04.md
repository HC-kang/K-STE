누리돛물류 운송장 시스템 '짐표'에서 운송장 저장 버튼을 클릭하면 오류가 발생하는 장애가 있습니다.

출고 담당자는 저장 오류가 발생한 건마다 공유폴더 '출고대체'의 '수기운송장' 파일을 작성해야 합니다. 짐표에서 운송장 번호가 정상 발급된 건은 수기운송장을 작성하지 않아도 됩니다. 수기운송장 파일 1개당 주문은 최대 20건까지 넣을 수 있고, 주문 1건당 운송장 번호를 1개 입력하십시오.

일정은 다음과 같습니다.
- 11/10(화): 물류운영팀이 공유폴더 '출고대체'에 누락 운송장 목록을 업로드합니다.
- 11/12(목): 출고 담당자가 사내 메신저 '출고장애접수' 채널에 수기운송장 사본을 제출합니다.
- 11/16(월): 물류운영팀이 짐표 '대조결과' 게시판에 주문별 운송장 대조 결과를 등록합니다.
- 11/18(수) 10:00: 시스템팀이 짐표 저장 기능 재현 시험을 시작합니다.
- 11/20(금) 17:00까지: 출고 담당자가 수기운송장 원본을 공유폴더 '원본보관'에 업로드해야 합니다.

수기운송장 작성 문의는 물류운영팀 도하린 님께, 짐표 오류 문의는 시스템팀 류건오 님께 사내 메신저 개인 대화로 하십시오.

확인 필요: 묶음 2. 이 표현이 가리키는 대상이 전달해 주신 내용에 없어 글에 넣지 않았습니다.
