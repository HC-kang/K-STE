결제 API가 같은 요청 키로 다시 들어온 승인 요청을 차단하고, 기존 승인 결과를 반환한다.

## 변경 내용

- 결제 API가 중복 승인을 차단한다.
- 동일한 요청 키를 다시 사용하면 결제 API가 기존 승인 결과를 반환한다.

## 중복 판정 범위

- 동일 가맹점의 동일 요청 키를 중복으로 판정한다.
- 보관 시간은 40분이다.
- 요청 키가 없는 호출은 중복 판정에서 제외한다.
- 요청 키가 없는 호출은 기존 승인 경로를 사용한다.

확인 필요: 보관 시간 40분은 요청 키의 보관 시간인지, 기존 승인 결과의 보관 시간인지 원문에 적혀 있지 않다.

## 코드 승인 조건

- 박세온은 통합 테스트 120건이 모두 통과한 경우에만 코드를 승인할 수 있다.
- 통합 테스트에서 실패가 1건 이상이면 박세온은 코드를 승인하면 안 된다.
