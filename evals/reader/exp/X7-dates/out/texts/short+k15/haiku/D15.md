이 PR은 강의 플레이어에 자막 글자 크기 설정을 추가하고, 선택한 값을 사용자 계정에 저장한다.

### 변경 내용

- 자막 글자 크기 선택값은 16px, 22px, 28px 세 가지다.
- 기본값은 22px이다.
- 적용 대상은 로그인 사용자의 녹화 강의다.
- 실시간 강의는 기존 자막 설정을 유지한다.

### 일정

- 12/2(수): 접근성 QA 담당 유시온이 키보드 탐색을 검증한다.
- 12/4(금): 디자인 담당 배아린이 자막 화면 비교 자료를 등록한다.
- 12/8(화): 키보드 탐색 검증 32항목을 모두 통과한 경우에만 리뷰어 강로운이 변경 코드를 승인한다.
- 12/10(목) 15:00: 개발 담당 노해솔이 검증 서버 기능을 시연한다.
- 12/15(화)까지: 디자인 담당 배아린이 자막 설정 도움말을 제출한다.

### 필수 작업

- 유시온은 키보드 탐색 검증 결과를 PR 댓글에 작성해야 한다.
- 배아린은 비교 자료와 도움말을 화면검증함 CAP-64 폴더에 등록해야 한다.

키보드 탐색 검증 항목에 실패가 있으면 코드를 승인하면 안 된다.

문의처는 플레이어개발 채널 #caption-pr의 노해솔이다. 자막 디자인 문의처는 같은 채널의 배아린이다.

확인 필요: 리뷰어 이름이 원문에 "강로운"(일정)과 "강로은"(승인 기준)으로 다르게 나온다. 같은 사람인지 확인 필요하다.
확인 필요: "화면검증함 CAP-64 폴더"가 하나의 폴더 이름인지, "화면검증함" 아래의 CAP-64 폴더인지 확인 필요하다.
확인 필요: 원문에는 로그인하지 않은 사용자에게 자막 글자 크기 설정이 적용되는지 나와 있지 않다.
