# 누리핀물류 야간 배차 점검 운영 절차

이 절차는 2026년 11월 12일(목) 22:00부터 23:00까지 진행하는 누리핀물류 야간 배차 점검에서 관제 담당자가 따를 내용을 정한다. 점검 목적은 중복 배차 방지다. 관제 담당자는 동부 배차 서버와 서부 배차 서버의 대기 건수를 10분 간격으로 점검표에 기록하고, 대기 건수가 40건 이상인 서버의 신규 배차를 즉시 중지한다. 플랫폼팀은 22:30에 서버를 재시작한다.

## 1. 점검 개요

| 항목 | 내용 |
|---|---|
| 점검 일시 | 2026년 11월 12일(목) 22:00~23:00 |
| 목적 | 중복 배차 방지 |
| 점검 도구 | 관제실 단말의 루온 콘솔 '야간 점검' 메뉴 |
| 점검 대상 | 동부 배차 서버, 서부 배차 서버 (두 서버 모두 대기열 수집 대상) |
| 서버 재시작 | 22:30, 실행 담당은 플랫폼팀 |

## 2. 역할

| 역할 | 담당 | 할 일 |
|---|---|---|
| 관제 담당자 | 관제 업무 | 대기 건수 기록, 신규 배차 중지와 재개 |
| 플랫폼팀 | 서버 조작 | 22:30 서버 재시작 실행 |
| 배차지원팀 | 운송사 연락 | 22:00~23:00 대기, 문의 창구(내선 731) 운영 |

## 3. 절차

1. 관제 담당자는 관제실 단말에서 루온 콘솔의 '야간 점검' 메뉴를 사용한다.
2. 관제 담당자는 22:00에 동부 배차 서버의 대기 건수와 서부 배차 서버의 대기 건수를 각각 점검표에 기록한다.
3. 관제 담당자는 22:10부터 10분 간격으로 2단계의 기록을 반복한다. 22:10, 22:20, 22:30, 22:40, 22:50에 기록한다.
4. 관제 담당자는 대기 건수가 40건 이상인 서버의 신규 배차를 즉시 중지한다. 긴급 의료 운송은 중지 대상에서 제외한다.
5. 플랫폼팀은 22:30에 서버를 재시작한다.
6. 관제 담당자는 중지한 서버의 대기 건수가 10건 이하가 되면 그 서버의 신규 배차를 재개한다.
7. 점검은 23:00에 종료한다.
8. 점검 종료 후 결과 요약을 운영 게시판에 게시한다.
9. 2026년 11월 13일(금)까지 점검표를 제출한다.

## 4. 중지와 재개 기준

| 구분 | 기준 | 내용 |
|---|---|---|
| 중지 | 대기 건수 40건 이상 | 해당 서버의 신규 배차를 즉시 중지한다 |
| 중지 제외 | 긴급 의료 운송 | 중지 대상에서 제외한다 |
| 재개 | 대기 건수 10건 이하 | 관제 담당자가 신규 배차를 재개한다 |

중지와 재개에 관한 문의는 배차지원팀 내선 731로 한다.

## 5. 확인 필요 사항

확인 필요: 10분 간격 기록의 마지막 시각. 23:00에도 기록하는지, 22:50까지만 기록하는지 원문에 없다.

확인 필요: 22:30 서버 재시작 대상. 두 서버를 모두 재시작하는지, 한 서버만 재시작하는지 원문에 없다.

확인 필요: 결과 요약의 운영 게시판 게시 담당. 원문에 담당자가 없다.

확인 필요: 점검표 제출 대상. 원문에 제출처가 없다.

확인 필요: 긴급 의료 운송 판단 기준. 원문에 어떤 배차를 긴급 의료 운송으로 보는지 기준이 없다.
