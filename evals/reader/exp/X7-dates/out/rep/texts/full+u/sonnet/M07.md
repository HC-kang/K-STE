# 누리결제 정산 점검 회의록

야간 정산 파일 4건이 중복 생성되어 결제 서버와 정산 서버를 점검하기로 했다. 두 서버 모두 테스트 환경이다. 이 문서는 11/12(목) 회의에서 정한 할 일과 일정을 정리한다.

## 회의 정보

- 일시: 11/12(목) 10:00~10:30
- 장소: 본사 3층 소회의실
- 참석: 정산운영팀 강세린, 플랫폼팀 문도윤

## 점검 개요

- 점검 원인: 야간 정산 파일 4건 중복 생성
- 점검 대상: 결제 서버와 정산 서버 (두 서버 모두 테스트 환경)

## 할 일과 일정

- 11/16(월) 09:00: 자동 재시도 기능을 중지한다.
- 11/16(월) 09:00~10:00: 플랫폼팀은 결제 서버와 정산 서버의 중복 생성 기록을 조회해야 한다.
- 플랫폼팀이 조회한 결과를 모아 비교표를 회의 자료실에 업로드해야 한다.
- 정산운영팀은 비교표 업로드 알림을 받은 뒤 2시간 이내에 파일 건수를 대조해야 한다.
- 파일 건수 대조 범위는 테스트 거래만 포함하고 실제 고객 거래는 제외한다.
- 재발 방지 보고서 제출: 11/19(목)
- 보고서 저장 위치: 사내 자료실 '정산점검/11월'
- 보고서 파일 형식: PDF

## 문의

- 담당: 운영지원팀 윤하린
- 경로: 사내 메신저 '정산점검 문의'

## 확인 필요

- 확인 필요: 재발 방지 보고서 제출 11/19(목). 11/19(목)에 제출하는 것인지, 11/19(목)까지 제출하는 것인지. 제출하는 팀도 메모에 없다.
- 확인 필요: 서버의 자동 재시도 기능 중지. 결제 서버와 정산 서버 둘 다 중지하는 것인지, 한쪽만 중지하는 것인지. 중지하는 팀도 메모에 없다.
- 확인 필요: 조회 결과를 모아 비교표 업로드. 업로드하는 팀이 메모에 없다.
