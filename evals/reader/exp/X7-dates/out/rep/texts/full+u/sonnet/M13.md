# PR 5-1: 노벨릿커머스 주문 중복 차단 변경

묶음 5의 PR 5-1이다. 주문 API의 재시도 처리 모듈에서 동일 요청 키를 재사용하면 주문이 중복 생성되는 문제를 수정한다. 새 중복 차단 기준은 동일 요청 키 수신 후 90초이고, 요청 키 없는 요청은 기존 처리를 유지한다. 주문QA팀의 비교 시험에서 실패는 0건이었다. 병합은 11/13(금) 10:00에 한다.

## 변경 내용

- 변경 위치: 주문 API의 재시도 처리 모듈
- 수정한 문제: 동일 요청 키를 재사용하면 주문이 중복 생성되는 문제
- 새 중복 차단 기준: 동일 요청 키 수신 후 90초
- 요청 키 없는 요청: 기존 처리를 유지한다.
- 서버의 요청 로그 보관 기간을 48시간으로 변경한다.

## 검증

- 대상 환경: 스테이징 주문 서버와 스테이징 환불 서버
- 비교 시험에는 두 서버를 모두 사용했다.
- 주문QA팀이 11/10(화) 14:00-15:00에 서버별 요청 240건으로 비교 시험을 했다.
- 비교 시험에서 실패는 0건이었다.

## 리뷰와 병합

- 리뷰 의견 등록: 11/12(목)
- 병합 전에 비교 시험 결과표를 PR 첨부란에 업로드해야 한다.
- 코드 리뷰어 전원이 승인해야 한다.
- 승인이 하나라도 없으면 병합을 보류해야 한다.
- 병합 일정: 개발 담당 서리안이 11/13(금) 10:00에 병합한다.
