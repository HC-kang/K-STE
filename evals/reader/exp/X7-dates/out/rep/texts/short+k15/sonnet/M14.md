# 모아결에듀 강의 자막 설정 화면 개선 (묶음 5, PR 5-2)

이 PR은 학습 웹의 자막 설정 패널에서 키보드 초점 표시가 배경과 구별되지 않는 문제를 수정한다.

## 변경 내용

- 변경 위치는 학습 웹의 자막 설정 패널이다.
- 키보드 초점 표시가 배경과 구별되지 않는 문제를 수정했다.
- 자막 글자 크기 기본값은 20px이다.
- 자막 글자 크기는 16-32px 범위에서 선택할 수 있다.
- 저장된 사용자 설정이 있으면 저장값을 우선한다.

확인 필요: 메모의 "반영 완료"가 무엇을 어디에 반영했다는 뜻인지 알려 주세요.

## 검토 방법

- 검토 환경은 사내 미리보기 사이트의 강의 L-28이다.
- 외부 공개 강의는 이번 검토 대상에서 제외한다.
- 윤세하는 키보드 이동 경로 12개를 필수로 검토해야 한다.
- 검토 결과는 PR 댓글에 기록한다.
- 접근성 검토 담당자는 확대 화면도 살펴보기를 권장한다.
