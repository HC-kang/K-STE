# PR 5-2: 모아결에듀 강의 자막 설정 화면 개선

이 PR은 학습 웹의 자막 설정 패널에서 키보드 초점 표시가 배경과 구별되지 않는 문제를 수정한다. 묶음 5에 속한다.

## 담당자와 문의

- 개발 담당은 한도윤이다.
- 접근성 검토 담당은 윤세하다.
- 문의는 사내 #자막검토 채널로 한다.

## 변경 내용

- 변경 위치는 학습 웹의 자막 설정 패널이다.
- 키보드 초점 표시가 배경과 구별되지 않는 문제를 수정했다.
- 자막 글자 크기 기본값은 20px이다.
- 자막 글자 크기 선택 범위는 16-32px이다.
- 저장된 사용자 설정이 있으면 저장값을 우선한다.

확인 필요: 메모의 "반영 완료"가 무엇을 어디에 반영했다는 뜻인지 적혀 있지 않다.

## 검토 범위와 환경

- 검토 환경은 사내 미리보기 사이트의 강의 L-28이다.
- 외부 공개 강의는 이번 검토 대상에서 제외한다.
- 검토 담당자는 확대 화면도 살펴보는 것을 권장한다.
