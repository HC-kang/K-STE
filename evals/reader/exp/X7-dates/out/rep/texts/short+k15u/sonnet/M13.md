# 묶음 5 · PR 5-1 · 노벨릿커머스 주문 중복 차단 변경

## 변경 내용

- 주문 API의 재시도 처리 모듈을 변경한다.
- 동일한 요청 키를 다시 사용하면 주문이 중복 생성되는 문제를 수정한다.
- 새 중복 차단 기준은 동일 요청 키 수신 후 90초이다.
- 요청 키가 없는 요청은 기존 처리를 유지한다.
- 서버의 요청 로그 보관 기간을 48시간으로 변경한다.

## 대상 환경

대상 환경은 스테이징 주문 서버와 스테이징 환불 서버이다. 두 서버를 모두 비교 시험에 사용했다.

## 검증

주문QA팀이 11/10(화) 14:00~15:00에 비교 시험을 했다. 서버별로 요청 240건을 보냈고, 실패는 0건이었다.

## 일정

- 11/12(목): 리뷰 의견을 등록한다.
- 11/13(금) 10:00: 개발 담당 서리안이 병합한다.

## 병합 조건

- 코드 리뷰어 전원이 승인해야 한다.
- 승인이 하나라도 없으면 병합을 보류한다.
- 병합 전에 비교 시험 결과표를 PR 첨부란에 업로드해야 한다.

## 담당과 문의

- 개발 담당은 서리안이다.
- 검증 담당은 주문QA팀이다.
- 문의는 사내 #주문변경 채널로 한다.
