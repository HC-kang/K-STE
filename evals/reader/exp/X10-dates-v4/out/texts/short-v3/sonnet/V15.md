이 PR(#503)은 별담교육 학습 기록 동기화의 재시도 로직을 수정한다.

## 변경 내용

- 자동 재시도는 연결 끊김 오류에만 적용한다.
- 자동 재시도는 최대 3회 하고, 시도 사이 대기 시간은 8초다.
- 인증 오류는 재시도 없이 고객지원 대기열로 이동한다.

## 일정과 담당

| 날짜 | 담당 | 할 일 |
|---|---|---|
| 12/21(월) 11:00 | 개발 담당 오지완 | 로그 검색을 시연한다. |
| 12/22(화) | 고객지원 담당 차유림 | 오류 분류표를 등록한다. |
| 12/23(수) | SRE 담당 문해솔 | 복구 시험을 실시한다. |
| 12/28(월) | 개발 담당 오지완 | 재시도 측정 결과를 PR 댓글로 제출한다. |
| 12/29(화) | SRE 담당 문해솔 | 동기화 장애 원인 분석 보고서를 공유한다. |
| 12/31(목) | 고객지원 담당 차유림 | 고객지원 검토 의견 접수가 마감된다. |

12/28(월)은 오지완이 재시도 측정 결과를 제출하는 기한이다.
