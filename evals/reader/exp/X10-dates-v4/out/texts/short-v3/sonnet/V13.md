## 개요

누리결제 PR #501은 중복 결제 요청을 차단하는 로직을 추가한다.

## 변경 범위

- 변경 대상은 결제 생성 API이다.
- 결제 취소 API는 변경 대상이 아니다.

## 동작

- 동일 요청 키의 보관 시간은 30분이다.
- 보관 시간 안에 같은 요청 키로 중복 요청이 들어오면 기존 결제 결과를 반환한다.
- 오류 응답 코드 채택안은 11/12(목)에 한서율이 승인했다.

## 일정

- 11/9(월): 민하준이 코드 검토를 시작한다.
- 11/18(수) 10:00: 윤다솔이 테스트 결제를 시연한다.
- 11/24(화): 윤다솔이 회귀 테스트 결과를 PR 첨부 파일로 제출해야 한다.
- 11/27(금): 민하준의 병합 반대 의견 접수가 마감된다.

## 리뷰어 요청 사항

민하준은 검토 의견을 저장소 PR 댓글로 등록해야 한다.

## 테스트 규칙

- 테스트 결제 금액은 건당 700원이다.
- 테스트에 운영 결제 데이터를 사용하면 안 된다.

## 병합 조건

- 윤다솔은 자동 테스트를 통과한 경우에만 병합할 수 있다.
- 자동 테스트에 실패 항목이 있으면 윤다솔은 병합하면 안 된다.

## 문의

문의 담당은 한서율이다. 사내 메신저 #결제개발 채널로 문의한다.
