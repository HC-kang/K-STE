# PR #502 출고 라벨 재출력 권한 분리

## 변경 내용

- 재출력 권한은 창고 운영 담당자에게만 부여한다.
- 임시 작업자는 재출력하면 안 된다.
- 라벨 한 장당 재출력 허용 횟수는 2회다.
- 허용 횟수를 초과하면 운영 담당자가 새 출고 요청을 작성해야 한다.

## 권한표

- 운영 담당 고나린이 창고별 권한표를 제출한다.
- 제출 위치는 이 저장소 PR의 첨부 파일이다.
- 권한표에는 창고 코드와 담당자 사번이 필수다.

## 일정

| 날짜 | 담당 | 내용 |
|---|---|---|
| 12/1(화) | QA 배도윤 | 권한 회수 시험을 한다. |
| 12/3(목) 14:00 | QA 배도윤 | 바코드 판독을 시연한다. |
| 12/8(화) | 운영 고나린 | 창고별 권한표를 제출한다. |
| 12/11(금) | 개발 서이담 | 권한 검사 로그를 PR 댓글로 제출한다. |
| 12/15(화) | 운영 고나린 | 사용 안내문을 게시한다. |
| 12/18(금) | QA 배도윤 | 테스트 계정 신청이 마감된다. |

## 시험 환경

- 시험 장소는 모래물류 테스트 창고 화면이다.
- 시험 계정 수는 6개다.
- **실제 창고 계정을 사용하면 안 된다.**

## 문의

문의 담당은 서이담이다. 사내 메신저 #출고도구 채널을 이용한다.
