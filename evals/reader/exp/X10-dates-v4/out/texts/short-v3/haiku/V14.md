이 PR(코드 변경 요청, #502)은 출고 라벨 재출력 권한을 창고 운영 담당자에게만 부여하도록 분리한다.

## 변경 내용

- 재출력 권한은 창고 운영 담당자에게만 부여한다.
- 임시 작업자는 라벨을 재출력하면 안 된다.
- 라벨 한 장당 재출력 허용 횟수는 2회다.
- 재출력 횟수를 초과하면 운영 담당자가 새 출고 요청을 작성한다.

## 권한표 제출 기준

권한표는 저장소 PR 첨부 파일로 제출한다. 권한표에는 창고 코드와 담당자 사번을 적어야 한다. 운영 담당 고나린은 창고별 권한표를 12/8(화)에 제출한다.

## 일정

아래 표는 작업 일정을 날짜순으로 정리한다. 배도윤은 12/1(화)에 권한 회수 시험을 하고, 12/3(목) 14:00에 바코드 판독 시연을 한다. 서이담은 12/11(금)까지 권한 검사 로그(권한 확인 기록)를 PR 댓글로 제출한다.

| 날짜 | 담당자 | 내용 |
|---|---|---|
| 12/1(화) | 배도윤 | 권한 회수 시험 |
| 12/3(목) 14:00 | 배도윤 | 바코드 판독 시연 |
| 12/8(화) | 고나린 | 창고별 권한표 제출 |
| 12/11(금)까지 | 서이담 | 권한 검사 로그 PR 댓글 제출 |
| 12/15(화) | 고나린 | 사용 안내문 게시 |
| 12/18(금) | 배도윤 | 테스트 계정 신청 마감 |

## 시험 조건

시험은 모래물류 테스트 창고 화면에서 한다. 시험 계정 수는 6개다. 실제 창고 계정은 시험에 사용하면 안 된다.

문의 담당은 서이담이며, 문의는 사내 메신저 #출고도구 채널을 이용한다.
