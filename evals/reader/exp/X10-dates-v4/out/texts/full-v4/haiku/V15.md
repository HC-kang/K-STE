# 별담교육 PR #503: 학습 기록 동기화 재시도 로직 수정

이 PR은 학습 기록 동기화의 재시도 로직을 수정한다. 자동 재시도는 연결 끊김 오류에만 적용한다. 인증 오류는 재시도하지 않고 고객지원 대기열로 이동한다.

## 변경 내용

- 자동 재시도는 최대 3회까지 수행한다.
- 재시도 시도 사이의 대기 시간은 8초다.
- 자동 재시도는 연결 끊김 오류에만 적용한다.
- 인증 오류는 재시도 없이 고객지원 대기열로 이동한다.

## 일정과 담당

| 날짜 | 담당 | 할 일 | 구분 |
|---|---|---|---|
| 12/21(월) 11:00 | 오지완 | 로그 검색 시연 | 실행일 |
| 12/22(화) | 차유림 | 오류 분류표 등록 | 확인 필요 |
| 12/23(수) | 문해솔 | 복구 시험 실시 | 실행일 |
| 12/28(월)까지 | 오지완 | 재시도 측정 결과를 PR 댓글로 제출 | 기한 |
| 12/29(화) | 문해솔 | 동기화 장애 원인 분석 보고서 공유 | 확인 필요 |
| 12/31(목) | 차유림 | 고객지원 검토 의견 접수 마감 | 기한 |

확인 필요: 12/22(화) 오류 분류표 등록. 실행일인지 기한인지 입력된 일정 정보에 밝혀져 있지 않다.

확인 필요: 12/29(화) 원인 분석 보고서 공유. 실행일인지 기한인지 입력된 일정 정보에 밝혀져 있지 않다.

## 오류 분류표

- 오류 분류표의 등록 위치는 저장소 PR 첨부 파일이다.
- 고객지원 담당 차유림은 오류 코드와 상담 분류를 필수로 기재해야 한다.

## 시험 조건

- 복구 시험은 별담교육 스테이징 학습실에서만 실시해야 한다.
- 운영 학습실에서 시험하면 안 된다.
