# 누리결제 PR #501: 중복 결제 요청 차단 로직 추가

이 PR은 결제 생성 API에 중복 결제 요청 차단 로직을 추가한다. 동일 요청 키는 30분 동안 보관하며, 보관 시간 안에 들어온 중복 요청에는 기존 결제 결과를 반환한다. 결제 취소 API는 변경 대상이 아니다.

## 변경 내용

- 결제 생성 API에 중복 결제 요청 차단 로직을 추가한다.
- 동일 요청 키를 30분 동안 보관한다.
- 보관 시간 안의 중복 요청에는 기존 결제 결과를 반환한다.
- 결제 취소 API는 변경 대상이 아니다.

| 일정 | 날짜 | 구분 | 담당 |

| 병합 반대 의견 접수 | 11/27(금) 마감 | 기한 | 민하준 |

## 검토와 병합 절차

1. 리뷰어 민하준은 검토 의견을 저장소 PR 댓글로 등록해야 한다.
2. 개발자 윤다솔은 회귀 테스트 결과를 11/24(화)까지 PR 첨부 파일로 제출해야 한다.
3. 테스트 결제 금액은 건당 700원이다.
4. 운영 결제 데이터를 사용하면 안 된다.
5. 자동 테스트 통과한 경우에만 개발자 윤다솔은 병합해도 된다.
6. 자동 테스트에 실패 항목이 있으면 개발자 윤다솔은 병합하면 안 된다.
7. 리뷰어 민하준의 병합 반대 의견 접수는 11/27(금) 마감이다.
