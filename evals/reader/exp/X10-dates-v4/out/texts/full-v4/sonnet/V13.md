# 누리결제 PR #501: 중복 결제 요청 차단 로직 추가

이 PR은 결제 생성 API에 중복 결제 요청을 차단하는 로직을 추가한다. 개발자는 윤다솔이고 리뷰어는 민하준이다.

## 변경 내용

- 변경 대상은 결제 생성 API이다. 결제 취소 API는 변경 대상이 아니다.
- 동일 요청 키는 30분 동안 보관한다.
- 보관 시간 안에 중복 요청이 들어오면 기존 결제 결과를 반환한다.
- 오류 응답 코드 채택안은 한서율이 승인했다.

## 일정

| 일정 | 날짜 | 구분 |
|---|---|---|
| 민하준 코드 검토 시작 | 11/9(월) | 실행일 |
| 오류 응답 코드 채택안 승인(한서율) | 11/12(목) | 실행일 |
| 윤다솔 테스트 결제 시연 | 11/18(수) 10:00 | 실행일 |
| 윤다솔 회귀 테스트 결과 제출 | 11/24(화) | 기한 |
| 민하준 병합 반대 의견 접수 마감 | 11/27(금) | 기한 |

## 테스트 결제

- 테스트 결제 금액은 건당 700원이다.
- 운영 결제 데이터를 사용하면 안 된다.

## 리뷰와 병합 규칙

- 민하준은 검토 의견을 저장소 PR 댓글로 등록해야 한다.
- 윤다솔은 회귀 테스트 결과를 PR 첨부 파일로 제출해야 한다.
- 윤다솔은 자동 테스트를 통과한 경우에만 병합해도 된다.
- 자동 테스트에 실패 항목이 있으면 윤다솔은 병합하면 안 된다.
