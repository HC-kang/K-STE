# 4-3. 시료 접수 담당자 업무 기준 및 일정

**대상:** 해온재료 분석실 시료 접수 담당자
**문의:** 안전 담당 류세온 / 사내 메신저 '시료접수지원' 채널

## 1. 시료 접수 시 준수 사항

시료를 접수할 때 아래 순서로 확인하고 처리한다.

1. **질량 확인:** 용기당 시료 질량이 40g 이상인지 확인한다.
   - 40g 이상: 접수를 진행한다.
   - 40g 미만: 접수하지 않고 의뢰 부서로 반송한다.
2. **용기 상태 확인:** 용기에 균열이 있는지 확인한다.
   - 균열 발견: 시료를 격리함 C로 이동한다.
   - 균열 없음: 시료를 보관함 D로 이동한다.
3. **접수 번호 발급:** 접수한 시료마다 접수 시스템 '입자록'에서 접수 번호를 발급한다.
4. **라벨 부착:** 접수 번호 라벨을 용기마다 2장 부착한다.

## 2. 등록 및 신청 사항

| 구분 | 내용 | 기한 |
|---|---|---|
| 보관함 위치표 등록 | '입자록' 접수 운영 메뉴에 등록 | 12/15(화) |
| 라벨 용지 사용량 입력 | 개인별 사용량을 '입자록' 접수 운영 메뉴에 입력 | 12/17(목) |
| 보호안경 교체 신청 | 시료 접수 담당자별 신청 | 11/30(월) 16:00 마감 |

- 위치표와 라벨 용지 사용량은 모두 '입자록'의 접수 운영 메뉴에 등록한다.

| 일시 | 내용 | 담당 |
|---|---|---|
| 11/30(월) 16:00 | 보호안경 교체 신청 마감 | 시료 접수 담당자 |
| 12/15(화) | 보관함 위치표 등록 | 시료 접수 담당자 |
