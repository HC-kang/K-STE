# 별담교육 PR #503: 학습 기록 동기화 재시도 로직 수정

## 개요

학습 기록 동기화 과정에서 발생하는 오류를 두 가지로 나누어 처리하도록 재시도 로직을 수정합니다. 연결 끊김 오류는 자동으로 재시도하고, 인증 오류는 재시도하지 않고 고객지원 대기열로 보냅니다.

## 주요 변경 사항

- **자동 재시도 대상**: 연결 끊김 오류만 자동 재시도합니다.
- **자동 재시도 횟수**: 최대 3회입니다.
- **시도 간 대기 시간**: 8초입니다.
- **인증 오류 처리**: 재시도하지 않고 고객지원 대기열로 이동합니다. 고객지원 담당자는 이 대기열에서 해당 건을 확인해 주세요.

- 12/29(화)까지 동기화 장애 원인 분석 보고서를 공유합니다.
