# [#501] 중복 결제 요청 차단 로직 추가

## 개요

결제 생성 API에 중복 결제 요청을 차단하는 로직을 추가합니다. 동일한 요청 키로 들어온 요청이 보관 시간(30분) 안에 다시 들어오면, 새로 결제를 처리하지 않고 기존 결제 결과를 반환합니다.

## 변경 범위

- **변경 대상:** 결제 생성 API
- **변경 대상 아님:** 결제 취소 API

## 동작 방식

- **동일 요청 키 보관 시간:** 30분
- **보관 시간 내 중복 요청:** 새 결제를 생성하지 않고 기존 결제 결과를 반환
- **오류 응답 코드:** 한서율 승인(11/12, 목)을 받은 채택안을 따릅니다.
