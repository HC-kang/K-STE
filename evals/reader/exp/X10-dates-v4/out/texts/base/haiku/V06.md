**[공지] 자리꽃 예약 확정 문자 누락 장애 안내 (솔무늬공방 체험 수업)**

솔무늬공방 체험 수업 상담 직원 여러분께 알립니다.

예약 시스템 '자리꽃'에서 예약 확정 문자가 누락되는 장애가 발생했습니다. 시스템 담당 오새봄 님이 12/10(목) 10:00에 문자 발송 모듈을 재시동할 예정입니다. 아래 일정과 업무 사항을 확인하고 협조해 주시기 바랍니다.

**■ 조치 일정**

| 일자 | 담당 | 내용 |
|---|---|---|
| 12/2(수) 16:00 | 오새봄 | 시험 번호 대상 문자 발송 점검 |
| 12/4(금) | 배라온 | 고객 안내문 게시 |
| 12/8(화) | 상담 직원 | 시험 문자 수신 결과 접수 마감 |
| 12/10(목) 10:00 | 오새봄 | 문자 발송 모듈 재시동 |
| 12/14(월) | 상담 직원 | 누락 예약 목록 제출 |
| 12/16(수) | 상담 직원 | 통화 기록 등록 마감 |

**■ 상담 직원 필수 업무**

1. **누락 예약 고객 전화 안내**
   - 문자가 누락된 예약을 발견하면 해당 고객에게 반드시 전화로 안내합니다.
   - 문자 수신이 확인된 고객은 전화 대상에서 제외합니다.
   - 고객별 전화 시도는 최대 3회이며, 연결되지 않은 고객은 40분 간격으로 재시도합니다.
   - 통화 기록은 상담 게시판 '자리꽃 통화'에 12/16(수)까지 등록합니다.

2. **누락 예약 목록 제출**
   - 12/14(월)까지 팀 공유 폴더 '자리꽃 누락'에 제출합니다.
   - 예약번호와 수업명을 반드시 기재합니다.

3. **시험 문자 수신 결과 접수**
   - 12/2(수) 시험 발송 결과를 12/8(화)까지 상담 게시판 '자리꽃 시험'에 등록합니다.
   - 시험 시에는 실제 고객 번호를 사용하지 않습니다.

**■ 문의처**

- 자리꽃 장애 관련: 오새봄 (사내 메신저 개인 메시지)
- 고객 응대 문구 관련: 배라온 (사내 메신저 개인 메시지)

일정이 변경되면 다시 공지하겠습니다. 감사합니다.
