# PR #502: 출고 라벨 재출력 권한 분리

## 개요

출고 라벨 재출력 권한을 창고 운영 담당자에게만 부여하도록 분리합니다. 임시 작업자는 라벨을 재출력할 수 없습니다.

## 대상 독자

- 창고 운영 담당자
- 출고 시스템 QA 담당자

## 변경 내용

- **재출력 권한**: 창고 운영 담당자에게만 부여합니다.
- **임시 작업자**: 라벨 재출력을 할 수 없습니다.
- **재출력 횟수**: 라벨 한 장당 재출력은 최대 2회까지 허용합니다.
- **횟수 초과 시**: 운영 담당자가 새 출고 요청을 작성합니다.

## 권한표 제출 기준

- **담당자**: 운영 담당 고나린
- **제출 기한**: 12/8(화)
- **제출 위치**: 저장소 PR 첨부 파일
- **필수 항목**: 창고 코드, 담당자 사번
