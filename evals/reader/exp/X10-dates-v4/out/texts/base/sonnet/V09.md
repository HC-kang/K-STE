# 분류기 장애 대응 회의록

**회의명:** 분류기 장애 대응 회의
**주재자:** 설비지원팀장 윤해온
**대상:** 푸른톱니물류 각 물류센터 설비 담당자

## 1. 핵심 요약

- 점검 대상은 **자동 분류기**뿐이며, 수동 분류대는 제외합니다.
- 분류기 **1대당 센서 4개**를 점검해야 합니다.
- 센터별 **예비 센서 7개**를 유지해야 합니다.
- 센서 점검표는 **12/8(화)까지** 사내 시스템 '톱니함'의 **센서점검함**에 등록해야 합니다.

## 2. 일정 및 담당

| 일자 | 내용 | 담당 | 장소/방법 |
|---|---|---|---|
| 12/4(금) | 장애 기록 읽기 교육 | 설비지원팀 민채록 | 중앙센터 3층 강의실 |
| 12/8(화) | 센터별 센서 점검표 등록 | 각 센터 설비 담당자 | 톱니함 > 센서점검함 |
| 12/11(금) | 교체 공구 대여 신청 마감 | 각 센터 설비 담당자 | - |
| 12/16(수) | 분류기 멈춤 사고 원인 분석 보고서 공유 | 설비지원팀 민채록 | - |
| 12/21(월) 09:00 | 복구 모의훈련 시작 | 설비지원팀 서도율 | 중앙센터 1층 훈련장 |
| 12/24(목) | 예비 센서 수량 보고 마감 | 각 센터 설비 담당자 | - |

## 3. 논의 및 결정 사항

### 3-1. 센서 점검
- 점검 대상은 자동 분류기로 한정하며, 수동 분류대는 점검 대상에서 제외합니다.
- 각 센터 설비 담당자는 분류기 1대당 센서 4개를 반드시 점검합니다.
- 점검표는 센터별로 작성하여 12/8(화)까지 톱니함의 센서점검함에 등록합니다. 등록은 각 센터 설비 담당자의 필수 사항입니다.

### 3-2. 예비 센서 관리
- 각 센터는 예비 센서 7개를 반드시 유지합니다.
- 각 센터 설비 담당자는 12/24(목)까지 예비 센서 수량을 보고합니다.

### 3-3. 교체 공구
- 교체 공구 대여를 희망하는 센터 설비 담당자는 12/11(금)까지 신청해야 합니다.

### 3-4. 교육 및 훈련
- **장애 기록 읽기 교육:** 12/4(금), 중앙센터 3층 강의실, 강사 민채록(설비지원팀)
- **복구 모의훈련:** 12/21(월) 09:00 시작, 중앙센터 1층 훈련장, 진행 서도율(설비지원팀)

### 3-5. 원인 분석
- 설비지원팀 민채록이 분류기 멈춤 사고 원인 분석 보고서를 12/16(수)에 공유합니다.

## 4. 센터 설비 담당자 조치 사항

1. 12/4(금): 장애 기록 읽기 교육에 참석합니다. (중앙센터 3층 강의실)
2. 12/8(화): 자동 분류기별 센서 점검(분류기 1대당 4개)을 마치고, 점검표를 톱니함 센서점검함에 등록합니다.
3. 12/11(금): 교체 공구 대여가 필요하면 신청을 마칩니다.
4. 12/16(수): 공유된 원인 분석 보고서를 확인합니다.
5. 12/21(월) 09:00: 복구 모의훈련에 참여합니다. (중앙센터 1층 훈련장)
6. 12/24(목): 예비 센서 수량을 보고합니다. (센터별 7개 유지)

## 5. 문의처

분류기 오류 관련 문의: **설비지원팀 서도율, 내선 581**
