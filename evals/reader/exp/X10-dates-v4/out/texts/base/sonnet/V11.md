# 모루방송 영상 송출 야간 당직 운영 절차 (런북 4-2)

## 1. 목적 및 적용 대상
이 문서는 모루방송 영상 송출 야간 당직자가 송출 지연, 회선 이상 등 장애 상황에서 따라야 할 등록·대응 절차를 정의한다.

## 2. 담당자 및 문의처

| 역할 | 담당자 | 비고 |
|---|---|---|
| 회선 담당 | 배소운 | 예비 회선 점검, 회선 신호 없음 시 호출 대상 |
| 교육 담당 | 조나겸 | 장애 등록 교육, 절차 문의 |
| 보고 담당 | 임해준 | 원인 분석 보고서 공유 |
| 장애 등록 담당 | 해당 회선의 야간 당직자 | |

- **절차 문의:** 교육 담당 조나겸, 사내 메신저 **'야간송출지원'** 채널

## 3. 주요 일정

| 일시 | 내용 | 담당 |
|---|---|---|
| 11/17(화)까지 | 개인별 비상 연락처 입력 | 야간 당직자 |
| 11/24(화) 22:00 | 예비 회선 점검 | 회선 담당 배소운 |
| 12/1(화) 18:00 | 야간 당직자별 교육용 계정 신청 마감 | 야간 당직자 |
| 12/3(목) | 원인 분석 보고서 공유 | 보고 담당 임해준 |
| 12/8(화) | 백업 회선 접속 시험 기록 등록 | 야간 당직자 |
| 12/11(금) 21:00 | 장애 등록 교육 시작 | 교육 담당 조나겸 |

## 4. 장애 등록 기준 및 방법

### 4.1 등록 기준
- 송출 지연이 **8초 이상**이면 장애 시스템 **'파형'**에 장애 등록을 **반드시** 해야 한다.

### 4.2 등록 위치 및 담당
- **위치:** '파형'의 **야간 송출** 메뉴
- **담당:** 해당 회선의 야간 당직자

### 4.3 첨부 사항
1. **지연 측정값 3개**를 반드시 첨부한다.
2. **장애 화면 이미지**를 첨부한다.
   - 시청자 식별값이 **보이는 경우:** 해당 식별값을 **반드시 가린 후** 첨부한다.
   - 시청자 식별값이 **없는 경우:** **원본**을 그대로 첨부한다.

## 5. 회선 신호 상태별 대응

| 회선 신호 상태 | 야간 당직자 조치 |
|---|---|
| **정상** | 재접속을 **1회만** 수행한다. |
| **없음** | **재접속 금지.** 회선 담당 **배소운**을 **즉시 호출**한다. |

## 6. 야간 당직자 사전 준비 사항
- [ ] 11/17(화)까지 '개인별 비상 연락처' 입력
- [ ] 12/1(화) 18:00까지 교육용 계정 신청
- [ ] 12/8(화)에 백업 회선 접속 시험 기록 등록
- [ ] 12/11(금) 21:00 장애 등록 교육 참석

## 7. 장애 대응 흐름 요약
1. 송출 지연 측정 → **8초 이상**인지 확인
2. 회선 신호 확인
   - 정상 → 재접속 1회 수행
   - 없음 → 재접속 없이 배소운 호출
3. 지연 측정값 3개 확보
4. 장애 화면 이미지 확인 → 시청자 식별값 유무에 따라 가림 처리 또는 원본 유지
5. '파형' > 야간 송출 메뉴에서 장애 등록 (측정값 3개 + 이미지 첨부)
6. 이후 원인 분석 보고서는 보고 담당 임해준이 12/3(목)에 공유

## 8. 문의
절차 관련 문의는 사내 메신저 **'야간송출지원'** 채널 또는 교육 담당 **조나겸**에게 한다.
