# 런북 4-3. 시료 접수 운영 절차

**대상:** 해온재료 분석실 시료 접수 담당자
**사용 시스템:** 접수 시스템 '입자록'

## 1. 일정 요약

| 일시 | 내용 | 담당 |
|---|---|---|
| 11/30(월) 16:00 | 보호안경 교체 신청 마감 (담당자별 신청) | 시료 접수 담당자 |
| 12/15(화) | 보관함 위치표 등록 | 시료 접수 담당자 |
| 12/17(목) | 개인별 라벨 용지 사용량 입력 마감 | 시료 접수 담당자 |
| 12/22(화) 10:00 | 접수대 저울 교정 | 장비 담당 오유담 |
| 12/24(목) 15:00 | 시료 유출 대응 훈련 | 안전 담당 류세온 |
| 12/28(월) | 접수 기준 안내문 게시 | 게시 담당 차루빈 |

## 2. 시료 접수 절차 (상시)

시료를 접수할 때마다 아래 순서로 처리합니다.

1. **질량 확인**
   - 용기당 시료 질량이 **40g 이상**인 시료만 접수합니다.
   - **40g 미만**이면 접수하지 않고 **의뢰 부서로 반송**합니다. (의무)
2. **접수 번호 발급**
   - 접수한 시료마다 '입자록'에서 **접수 번호를 발급**합니다. (의무)
3. **라벨 부착**
   - 발급된 접수 번호 라벨을 **용기마다 2장** 부착합니다. (의무)
4. **용기 상태 확인 및 보관 위치 결정**
   - **균열이 발견된 경우:** 시료를 **격리함 C**로 이동합니다. (의무)
   - **균열이 없는 경우:** 시료를 **보관함 D**로 이동합니다.

## 3. 사전 등록 및 신청 사항

### 3.1 보호안경 교체 신청
- 담당자별로 **11/30(월) 16:00까지** 신청합니다.

### 3.2 보관함 위치표 등록
- **12/15(화)** 에 등록합니다.
- 등록 위치: '입자록' → **접수 운영 메뉴**

### 3.3 라벨 용지 사용량 입력
- **12/17(목)까지** 개인별 사용량을 입력합니다.
- 등록 위치: '입자록' → **접수 운영 메뉴**

> 위치표와 라벨 용지 사용량은 모두 '입자록'의 접수 운영 메뉴에 등록합니다.

## 4. 장비·안전·공지 일정

- **저울 교정 (12/22(화) 10:00):** 장비 담당 오유담이 접수대 저울을 교정합니다.
- **시료 유출 대응 훈련 (12/24(목) 15:00):** 안전 담당 류세온이 실시합니다.
- **접수 기준 안내문 게시 (12/28(월)):** 게시 담당 차루빈이 게시합니다.

## 5. 문의

- **절차 문의:** 안전 담당 류세온
- **문의 경로:** 사내 메신저 **'시료접수지원'** 채널

## 6. 담당자 체크리스트

**접수 건별**
- [ ] 용기당 질량 40g 이상 확인 (미만이면 의뢰 부서로 반송)
- [ ] '입자록'에서 접수 번호 발급
- [ ] 용기마다 라벨 2장 부착
- [ ] 균열 확인 후 이동: 균열 있음은 격리함 C, 균열 없음은 보관함 D
