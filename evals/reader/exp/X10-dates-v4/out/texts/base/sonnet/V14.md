# PR #502 출고 라벨 재출력 권한 분리

## 변경 배경
출고 라벨 재출력 권한을 분리하여 창고 운영 담당자만 재출력할 수 있도록 합니다. 임시 작업자는 재출력할 수 없습니다.

## 주요 변경 내용
- **재출력 권한**: 창고 운영 담당자에게만 부여합니다.
- **임시 작업자**: 재출력을 금지합니다.
- **재출력 횟수 제한**: 라벨 한 장당 재출력은 최대 2회까지 허용합니다.
- **횟수 초과 시**: 운영 담당자가 새 출고 요청을 작성합니다.

## 일정
| 날짜 | 내용 | 담당 |
|---|---|---|
| 12/1(화) | 권한 회수 시험 | 배도윤 (QA) |
| 12/3(목) 14:00 | 바코드 판독 시연 | 배도윤 (QA) |
| 12/8(화) | 창고별 권한표 제출 | 고나린 (운영) |
| 12/11(금) | 권한 검사 로그 제출 (PR 댓글) | 서이담 (개발) |
| 12/15(화) | 사용 안내문 게시 | 고나린 (운영) |
| 12/18(금) | 테스트 계정 신청 마감 | 배도윤 (QA) |

## 창고 운영 담당자 확인 사항
- **권한표 제출**: 고나린 담당자가 12/8(화)까지 창고별 권한표를 제출합니다.
- **제출 위치**: 이 저장소의 PR 첨부 파일로 제출합니다.
- **필수 항목**: 권한표에는 **창고 코드**와 **담당자 사번**을 반드시 기재합니다.
- **사용 안내문**: 고나린 담당자가 12/15(화)에 게시합니다.
- **재출력 한도 초과**: 한도(2회)를 넘기면 재출력할 수 없으므로 새 출고 요청을 작성해야 합니다.

## QA 확인 사항
- **시험 환경**: 모래물류 테스트 창고 화면에서 진행합니다.
- **시험 계정**: 6개를 사용하며, **실제 창고 계정은 사용할 수 없습니다.**
- **테스트 계정 신청**: 배도윤 담당자의 신청 마감은 12/18(금)입니다.
- **권한 회수 시험**: 12/1(화)에 실시합니다.
- **바코드 판독 시연**: 12/3(목) 14:00에 진행합니다.
- **권한 검사 로그**: 서이담 담당자가 12/11(금)까지 PR 댓글로 제출합니다.
