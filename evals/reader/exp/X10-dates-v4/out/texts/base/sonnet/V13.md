# PR #501: 중복 결제 요청 차단 로직 추가

## 개요
결제 생성 API에 중복 결제 요청 차단 로직을 추가합니다. 동일한 요청 키로 들어온 요청이 보관 시간 내에 다시 오면 새로 결제하지 않고 기존 결제 결과를 반환합니다.

## 변경 내용
- **변경 대상:** 결제 생성 API
- **변경 대상 아님:** 결제 취소 API
- **동일 요청 키 보관 시간:** 30분
- **중복 요청 처리:** 30분 이내 동일 요청 키로 재요청 시 기존 결제 결과 반환
- **오류 응답 코드:** 채택안을 한서율 님이 11/12(목)에 승인했습니다.

## 테스트
- **테스트 결제 금액:** 건당 700원
- **데이터 사용 제한:** 운영 결제 데이터는 사용하지 않습니다.
- **시연:** 윤다솔 님이 11/18(수) 10:00에 테스트 결제를 시연합니다.
- **회귀 테스트:** 윤다솔 님이 결과를 11/24(화)까지 PR 첨부 파일로 제출합니다.
