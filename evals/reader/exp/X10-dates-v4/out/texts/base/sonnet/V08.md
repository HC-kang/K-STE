# 온라인 강좌 운영 회의록

**회의명:** 온라인 강좌 운영 회의
**주재자:** 교육운영팀장 하유담
**대상:** 교육운영팀 강좌 담당자

---

## 1. 회의 개요
온라인 강좌 운영을 위한 일정, 담당자, 제출 방법, 체험 계정 운영 기준을 공유하고 확정했다.

## 2. 주요 일정 한눈에 보기

| 일자 | 내용 | 담당 | 장소/방법 |
|---|---|---|---|
| 11/4(수) | 운영 도구 교육 실시 | 정이솔 | 동관 2층 교육실 |
| 11/9(월) | 강사 소개 자료 취합 마감 | 정이솔 | - |
| 11/17(화) | 강좌별 자막 검수표 제출 | 각 강좌 담당자 | 별서랍 > 자막검수함 |
| 11/23(월) | 체험 계정 추가 신청 마감 | 각 강좌 담당자 | - |
| 11/26(목) | 수강생 접속 안내문 발송 | 오세린 | - |
| 12/2(수) 14:00 | 수강 화면 시연 | 오세린 | 서관 4층 실습실 |

## 3. 논의 및 결정 사항

### 3.1 운영 도구 교육
- 정이솔 담당자가 11/4(수)에 동관 2층 교육실에서 운영 도구 교육을 실시한다.

### 3.2 강사 소개 자료 취합
- 정이솔 담당자가 11/9(월)까지 강사 소개 자료를 취합한다.

### 3.3 자막 검수
- 각 강좌 담당자는 11/17(화)까지 강좌별 자막 검수표를 제출한다.
- 제출 위치는 사내 시스템 **별서랍**의 **자막검수함**이며, 각 강좌 담당자 등록이 필수다.
- 자막 검수는 **유료 강좌만 필수**이며, 무료 체험 강좌는 검수 대상에서 제외한다.

### 3.4 체험 계정
- 강좌별로 체험 계정 6개를 배정한다.
- 계정별 동시 접속 한도는 2명이다.
- 추가 계정이 필요한 경우 각 강좌 담당자가 11/23(월)까지 신청한다.

### 3.5 수강생 접속 안내
- 오세린 담당자가 11/26(목)에 수강생 접속 안내문을 발송한다.
- 접속 오류 문의는 교육운영팀 오세린 담당자(내선 735)가 접수한다.

### 3.6 수강 화면 시연
- 오세린 담당자가 12/2(수) 14:00에 서관 4층 실습실에서 수강 화면을 시연한다.

## 4. 담당자별 할 일

- **정이솔:** 11/4(수) 운영 도구 교육 실시 → 11/9(월)까지 강사 소개 자료 취합
- **오세린:** 11/26(목) 수강생 접속 안내문 발송 → 12/2(수) 14:00 수강 화면 시연 → 접속 오류 문의 대응(내선 735)
- **각 강좌 담당자:** 11/17(화)까지 자막 검수표 제출(유료 강좌, 별서랍 자막검수함에 담당자 등록 후), 필요 시 11/23(월)까지 체험 계정 추가 신청

## 5. 문의
- 접속 오류 문의: 교육운영팀 오세린, 내선 735
