# PR #503: 학습 기록 동기화 재시도 로직 수정

## 개요
학습 기록 동기화 실패 시의 재시도 동작을 정리합니다. 자동 재시도는 **연결 끊김 오류에만** 적용하고, **인증 오류**는 재시도 없이 고객지원 대기열로 이동시킵니다.

## 변경 사항
| 항목 | 내용 |
|---|---|
| 자동 재시도 대상 | 연결 끊김 오류만 |
| 최대 재시도 횟수 | 3회 |
| 시도 간 대기 시간 | 8초 |
| 인증 오류 | 재시도 없이 고객지원 대기열로 이동 |

## 시험 및 제약
- 복구 시험은 **별담교육 스테이징 학습실에서만** 허용됩니다.
- **운영 학습실에서의 시험은 금지**입니다.

## 담당자 및 일정
| 일자 | 담당 | 내용 |
|---|---|---|
| 12/21(월) 11:00 | 개발 오지완 | 로그 검색 시연 |
| 12/22(화) | 고객지원 차유림 | 오류 분류표 등록 |
| 12/23(수) | SRE 문해솔 | 복구 시험 실시 |
| 12/28(월) | 개발 오지완 | 재시도 측정 결과를 PR 댓글로 제출 (마감) |
| 12/29(화) | SRE 문해솔 | 동기화 장애 원인 분석 보고서 공유 |
| 12/31(목) | 고객지원 차유림 | 고객지원 검토 의견 접수 마감 |

## 고객지원 참고 사항
- 오류 분류표는 **저장소 PR 첨부 파일**로 등록합니다.
- 분류표에는 **오류 코드와 상담 분류를 필수로 기재**해 주세요.
- 인증 오류는 자동 재시도되지 않고 고객지원 대기열로 바로 들어옵니다.

## SRE 참고 사항
- 연결 끊김 오류는 최대 3회, 8초 간격으로 재시도되며, 그 이후에도 실패하면 재시도가 종료됩니다.
- 복구 시험 시 대상 환경이 스테이징인지 반드시 확인해 주세요.
