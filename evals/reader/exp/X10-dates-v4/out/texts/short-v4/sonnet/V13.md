누리결제 PR #501은 결제 생성 API에 중복 결제 요청 차단 로직을 추가한다.

## 변경 내용

- 변경 대상은 결제 생성 API다.
- 결제 취소 API는 변경 대상이 아니다.
- 동일 요청 키를 30분 동안 보관한다.
- 보관 시간 안에 중복 요청이 오면 기존 결제 결과를 반환한다.
- 오류 응답 코드 채택안은 11/12(목) 한서율이 승인한다.

## 담당자

- 개발자는 윤다솔이다.
- 리뷰어는 민하준이다.
- 문의 담당은 한서율이다. 문의는 사내 메신저 #결제개발 채널로 한다.

## 일정

- 11/9(월): 민하준이 코드 검토를 시작한다.
- 11/18(수) 10:00: 윤다솔이 테스트 결제를 시연한다.
- 11/24(화)까지: 윤다솔이 회귀 테스트 결과를 PR 첨부 파일로 제출한다.
- 11/27(금): 민하준의 병합 반대 의견 접수가 마감된다.

## 리뷰 규칙

- 민하준은 검토 의견을 저장소 PR 댓글로 등록해야 한다.
- 윤다솔은 자동 테스트를 통과한 경우에만 병합할 수 있다.
- 자동 테스트에 실패 항목이 있으면 병합하면 안 된다.

## 테스트 결제 규칙

- 테스트 결제 금액은 건당 700원이다.
- 테스트에 운영 결제 데이터를 사용하면 안 된다.
