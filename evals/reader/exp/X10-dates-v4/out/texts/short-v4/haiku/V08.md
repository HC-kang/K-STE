# 온라인 강좌 운영 회의록

온라인 강좌 운영 회의는 교육운영팀장 하유담이 주재했다.

## 일정 및 담당

| 항목 | 담당 | 일정 | 장소 |
|---|---|---|---|
| 운영 도구 교육 | 교육운영팀 정이솔 | 11/4(수) | 동관 2층 교육실 |
| 강사 소개 자료 취합 | 교육운영팀 정이솔 | 11/9(월)까지 | |
| 자막 검수표 제출 | 각 강좌 담당자 | 11/17(화) | 사내 시스템 '별서랍'의 자막검수함 |
| 체험 계정 추가 신청 | 각 강좌 담당자 | 11/23(월) 마감 | |
| 수강생 접속 안내문 발송 | 교육운영팀 오세린 | 11/26(목) | |
| 수강 화면 시연 | 교육운영팀 오세린 | 12/2(수) 14:00 | 서관 4층 실습실 |

## 운영 규정

강좌별로 체험 계정 6개가 배정된다. 계정별 동시 접속 한도(같은 계정으로 동시에 접속할 수 있는 인원)는 2명이다. 유료 강좌는 자막을 검수해야 한다. 무료 체험 강좌는 자막 검수 대상에서 제외한다. 각 강좌 담당자는 자막 검수표를 사내 시스템 '별서랍'의 자막검수함에 등록해야 한다. 접속 오류 문의 창구는 교육운영팀 오세린(내선 735)이다.

확인 필요: 회의 일시와 참석자가 입력 내용에 없다.
