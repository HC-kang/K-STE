# 포장재 규격 검토 회의록

이번 회의에서 포장재 규격 검토 사항을 아래와 같이 정리한다.

- 회의명은 포장재 규격 검토 회의다.
- 회의 주재자는 생산기획팀장 문서윤이다.
- 회의 일시는 원문에 없으므로 확인 필요: 회의 일시.

## 검토 대상

이번 검토에서는 상온용 상자만 검토한다. 냉동용 상자는 이번 검토 대상에서 제외한다. 시험 대상은 유리병용 상자 3종이며, 상자별 시료는 8개가 필수다.

## 실행 사항

| 담당 | 내용 | 일정 |
|---|---|---|
| 문서윤(생산기획팀장) | 포장재 규격안 확정 | 11/12(목), 확인 필요: 실행일인지 기한인지 |
| 배도겸(생산기획팀) | 공급사별 단가표 제출 | 11/3(화)까지 |
| 배도겸(생산기획팀) | 규격 검토표를 사내 시스템 결보드의 규격검토함에 등록 | 확인 필요: 기한 |
| 배도겸(생산기획팀) | 설비 사용 신청 | 11/25(수) 마감 |
| 고나림(품질관리팀) | 압축 시험 결과 설명 | 11/20(금)에 본관 2층 소회의실 |
| 고나림(품질관리팀) | 접착 강도 시험 실시 | 11/30(월), 확인 필요: 실행일인지 기한인지 |

## 기타 사항

생산기획팀과 품질관리팀 직원은 압축 시험 결과 설명에 모두 참석해야 한다. 단가표의 금액 단위는 원으로 한다. 운송비는 제품 단가와 별도 칸에 기재해야 한다. 규격 관련 문의는 품질관리팀 고나림(내선 462)에게 한다.
