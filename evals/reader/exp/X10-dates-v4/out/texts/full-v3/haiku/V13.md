# PR #501: 중복 결제 요청 차단 로직 추가

이 PR은 결제 생성 API에 중복 결제 요청을 차단하는 로직을 추가한다. 동일 요청 키의 보관 시간 안에 들어온 중복 요청에는 기존 결제 결과를 반환한다. 결제 취소 API는 변경 대상이 아니다.

## 변경 범위

- 변경 대상: 결제 생성 API
- 변경 대상 아님: 결제 취소 API

## 동작

동일 요청 키의 보관 시간은 30분이다. 보관 시간 안에 같은 요청 키로 들어온 중복 요청에는 기존 결제 결과를 반환한다.

## 오류 응답 코드

오류 응답 코드 채택안의 승인자는 한서율이며, 승인일은 11/12(목)이다.

## 일정

- 코드 검토 시작일: 11/9(월)
- 테스트 결제 시연 일시: 11/18(수) 10:00, 담당 윤다솔
- 회귀 테스트 결과 제출 기한: 11/24(화), PR 첨부 파일로 제출
- 병합 반대 의견 접수 마감: 11/27(금)

## 리뷰와 테스트

- 리뷰어 민하준은 검토 의견을 저장소 PR 댓글로 등록해야 한다.
- 개발자 윤다솔은 회귀 테스트 결과를 11/24(화)까지 PR 첨부 파일로 제출해야 한다.
- 테스트 결제 금액은 건당 700원이다.
- 운영 결제 데이터를 테스트에 사용하면 안 된다.
