# 누리펄스 캐시 전환 작업 런북 (운영 절차 묶음 4)

이 런북은 11/12(목) 야간 서비스 운영 당직자가 누리펄스의 검색 캐시와 추천 캐시를 전환할 때 따를 절차를 정한다.

## 1. 작업 개요

- 작업 시간은 11/12(목) 23:10에 시작해 23:40에 종료한다.
- 실행 담당은 야간 당직자 문세린이다.
- 작업 대상은 검색 캐시와 추천 캐시다. 캐시(자주 쓰는 데이터를 미리 임시로 보관해 두는 저장 공간)는 응답 속도를 높이는 데 쓰인다.
- 검색 캐시는 사내 운영 포털의 검색 탭에서, 추천 캐시는 추천 탭에서 각각 작업한다.
- 캐시 갱신이 지연되면 검색 결과 누락이 발생한다.

## 2. 역할

- 문세린은 작업을 실행하고 복원 지점을 등록한다.
- 나도윤(제품 관리자)과 서이안(프로젝트 관리자)은 작업 시간 동안 모두 사내 메신저에서 대기한다.
- 플랫폼지원팀 윤하민은 장애 발생 시 연락하는 담당자다.

## 3. 작업 절차

1. 23:10에 작업을 시작한다.
2. 문세린이 23:20에 복원 지점 2개를 등록한다. 복원 지점은 캐시를 이전 상태로 되돌릴 때 기준으로 쓰는 저장 시점이다.
3. 검색 캐시와 추천 캐시 각각의 전환 전 오류율을 5분간 측정하고, 측정 결과를 작업 기록에 남긴다.
4. 전환 직전에 스냅샷(특정 시점의 캐시 상태를 저장한 사본)을 1개 추가로 저장한다.
5. 검색 탭과 추천 탭에서 각각 캐시를 전환한다.
6. 전환 후 오류율에 따라 다음과 같이 처리한다.
   - 오류율이 2%를 초과하면 즉시 복원해야 한다. 복원은 4장의 절차를 따른다.
   - 오류율이 2% 이하이면 복원하지 않고 관찰을 유지한다.
7. 23:40에 작업을 종료한다.
8. 전환 완료 보고서를 PM에게 전달한다. 보고서를 전달하기 전에는 당직을 교대하면 안 된다.
9. 11/13(금) 09:00에 후속 점검을 한다.

## 4. 복원 작업

- 캐시 복원 작업의 실행 화면은 복원 제어판 1개만 사용한다.
- 되돌림 데스크에는 문세린이 23:20에 등록한 복원 지점 2개가 보여야 한다.
- 되돌림 데스크에 표시된 복원 지점 개수를 2개와 대조해야 한다.

## 5. 서버 점검

- 검색 로그 서버와 추천 로그 서버는 별도 장비다.
- 두 서버의 상태는 운영 포털의 장비 탭에서 조회한다.
- 서버 재시작은 문세린의 승인을 받은 뒤에만 진행한다. 승인 전에는 서버를 재시작하면 안 된다.

## 6. 장애 연락과 작업 기록

- 오류율을 조회할 수 없거나 복원이 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락한다.
- 작업 기록은 운영 포털의 야간 작업함에 저장한다.

## 확인 필요 사항

- 확인 필요: 전환 완료 보고서를 받는 PM이 나도윤과 서이안 중 누구인지 원문에서 밝혀지지 않는다.
- 확인 필요: 전환 후 오류율을 조회하는 위치와 전환 전 5분 측정의 시작 시각이 원문에 없다.
- 확인 필요: 2% 기준이 검색 캐시와 추천 캐시 각각에 적용되는지, 두 캐시를 합산한 값에 적용되는지 원문에 없다.
- 확인 필요: 전환 직전 스냅샷 1개가 검색 캐시와 추천 캐시를 함께 대상으로 하는지 원문에 없다.
- 확인 필요: 되돌림 데스크에 표시된 복원 지점 개수가 2개가 아닐 때 따를 조치가 원문에 없다.
