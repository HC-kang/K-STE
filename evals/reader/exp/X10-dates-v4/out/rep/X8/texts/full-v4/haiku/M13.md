# [묶음 5-1] 결제 재시도 PR 설명

이 PR은 중복 승인 요청으로 고객 결제 알림이 두 번 발송되는 문제를 수정한다. 담당 개발자는 서다온이며, 배포 담당은 문해솔이다. 승인 재시도 작업과 알림 재전송 작업을 함께 변경하며, 두 작업은 모두 결제 운영 콘솔에서 실행한다.

## 변경 내용

승인 재시도 작업은 재시도 간격을 30초로 두고 최대 3회까지 재시도한다. 알림 재전송 작업은 재시도 간격을 60초로 두고 최대 2회까지 재전송한다.

주문 DB와 정산 DB에 조회 인덱스를 각각 추가한다. 기존 컬럼은 삭제하지 않는다.

## 배포 일정

| 항목 | 날짜와 시각 | 구분 |
|---|---|---|
| 검토 완료 | 11/11(수) 17:00 | 기한 |
| 결제 무결성 검사 | 11/12(목) 13:30 | 실행 |
| 배포 | 11/12(목) 14:00 | 실행 |

확인 필요: 페이체크. 결제 무결성 검사와 같은 작업인지, 별도 작업인지.

## 배포 전 절차

1. 배포 전에 DB 스냅샷을 보관해야 한다.
2. 11/12(목) 13:30에 서다온이 표본 240건을 대조하는 결제 무결성 검사를 실행한다.
3. 결제 무결성 검사가 실패하면 배포를 중단해야 한다.
4. PM 승인 댓글을 받은 뒤에 PR을 병합해야 한다.

## 배포 후 주의

**배포 직후 20분 동안 수동 실행을 하면 안 된다.**

확인 필요: 그거는. 변경된 승인 재시도 작업과 알림 재전송 작업 모두인지, 결제 무결성 검사인지.

## 검토 요청

배포 검토자는 다음 사항을 지켜야 한다.

- 재시도 테스트 통과 기록을 이 PR에 첨부해야 한다.
- 내부 시험 상점은 테스트 대상에서 제외해야 한다.
- 문의는 #결제-변경 채널로 해야 한다.

## 참여자

제품 관리자 이나루와 프로젝트 관리자 강도윤이 이번 결제 개편에 참여한다.
