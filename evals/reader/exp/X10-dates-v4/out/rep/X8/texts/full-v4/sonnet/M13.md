# 결제 재시도 PR 설명 (묶음 5-1)

서다온이 중복 승인 요청 때문에 고객 결제 알림이 두 번 나가는 문제를 고치는 결제 재시도 PR이다. 변경 대상은 승인 재시도 작업과 알림 재전송 작업이며, 두 작업 모두 결제 운영 콘솔에서 실행한다. 배포는 11/12(목) 14:00에 하고, 배포 담당은 문해솔이다.

## 변경 내용

- 승인 재시도 작업: 재시도 간격 30초, 최대 3회
- 알림 재전송 작업: 재전송 간격 60초, 최대 2회
- 주문 DB와 정산 DB에 각각 조회 인덱스를 추가한다.
- 기존 컬럼은 삭제하지 않는다.

## 일정

| 일시 | 내용 | 구분 |
|---|---|---|
| 11/11(수) 17:00 | 배포 검토 | 기한 |
| 11/12(목) 13:30 | 결제 무결성 검사 | 실행일 |
| 11/12(목) 14:00 | 배포 | 실행일 |

## 배포 전 조건

- DB는 배포 전에 스냅샷을 보관해야 한다.
- 이번 배포의 단일 사전 검사 작업은 결제 무결성 검사(페이체크)이다. 서다온이 11/12(목) 13:30에 표본 240건을 대조한다. 검사에 실패하면 배포를 중단해야 한다.
- 배포 검토자는 재시도 테스트 통과 기록을 첨부해야 한다.
- 내부 시험 상점은 테스트 대상에서 제외해야 한다.
- PM 승인 댓글을 받은 뒤 병합해야 한다.

## 참여자와 문의

제품 관리자 이나루와 프로젝트 관리자 강도윤은 모두 이번 결제 개편에 참여한다. 문의는 #결제-변경 채널로 한다.

확인 필요: 그거는 배포 직후 20분 동안 수동 실행 금지. 수동 실행을 금지하는 대상이 승인 재시도 작업과 알림 재전송 작업인지, 결제 무결성 검사인지.

확인 필요: PM 승인 댓글. 제품 관리자 이나루와 프로젝트 관리자 강도윤 중 한 명의 댓글이면 되는지, 두 명 모두의 댓글이 필요한지.
