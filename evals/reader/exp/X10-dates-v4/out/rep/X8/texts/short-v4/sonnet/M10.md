# 누리펄스 캐시 전환 런북 (운영 절차 묶음 4)

## 개요

- 이 런북은 누리펄스 야간 서비스 운영 당직자가 캐시 전환 작업에 사용한다.
- 작업은 11/12(목) 23:10에 시작하고 23:40에 종료한다.
- 실행 담당은 야간 당직자 문세린이다.
- 작업 대상은 검색 캐시와 추천 캐시이다.
- 작업 위치는 사내 운영 포털의 검색 탭과 추천 탭이며, 각 캐시를 해당 탭에서 작업한다.
- 캐시 갱신 지연으로 검색 결과 누락이 발생했다.

## 대기 인원

- 제품 관리자 나도윤과 프로젝트 관리자 서이안은 작업 시간 동안 모두 사내 메신저에서 대기해야 한다.

## 작업 절차

1. 전환 전에 검색 캐시와 추천 캐시 모두 오류율을 5분간 측정하고, 측정값을 작업 기록에 남겨야 한다.
2. 전환 직전에 스냅샷 1개를 추가로 저장해야 한다.
3. 23:20에 문세린이 복원 지점 2개를 등록해야 한다.
4. 캐시 복원 작업의 실행 화면은 복원 제어판 1개만 사용해야 한다.
5. 되돌림 데스크에 문세린이 23:20에 등록한 복원 지점 2개가 보이는지, 표시 개수를 등록한 개수와 대조해야 한다.
6. 검색 로그 서버와 추천 로그 서버는 별도 장비이다. 두 서버의 상태는 운영 포털의 장비 탭에서 조회한다.
7. 서버 재시작은 문세린이 승인한 뒤에만 할 수 있다.

## 전환 후 판정

- 전환 후 오류율이 2%를 초과하면 즉시 복원해야 한다.
- 전환 후 오류율이 2% 이하이면 복원하지 않고 관찰을 유지한다.
- 후속 점검은 11/13(금) 09:00이다.

## 보고와 교대

- 전환 완료 보고서를 PM에게 전달해야 한다.
- 보고서를 전달하기 전에는 당직을 교대하면 안 된다.
- 작업 기록은 운영 포털의 야간 작업함에 저장해야 한다.

## 장애 시 연락

- 오류율을 조회할 수 없거나 복원에 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.

## 확인 필요

- 확인 필요: 전환 직전 스냅샷 1개를 추가로 저장하는 대상이 검색 캐시와 추천 캐시 각각인지, 두 캐시를 합쳐 1개인지 원문에 지시 대상이 없다.
- 확인 필요: 되돌림 데스크가 복원 제어판과 같은 화면인지, 다른 화면인지 알 수 없다.
- 확인 필요: 11/13(금) 09:00이 후속 점검을 실행하는 시각인지, 마감 기한인지 알 수 없다.
- 확인 필요: 오류율 5분 측정의 시작 시각과 전환 후 오류율을 측정하는 시점이 원문에 없다.
