# 누리펄스 캐시 전환 런북 (운영 절차 묶음 4)

이 문서는 야간 서비스 운영 당직자가 누리펄스 캐시 전환 작업에 쓰는 절차서다. 캐시 갱신 지연으로 검색 결과 누락이 발생했다. 실행 담당 야간 당직자 문세린이 11/12(목) 23:10에 작업을 시작하고 23:40에 종료한다. 대상은 검색 캐시와 추천 캐시다.

## 작업 개요

- 작업 위치: 사내 운영 포털의 검색 탭(검색 캐시), 추천 탭(추천 캐시)
- 서버 상태 조회: 운영 포털의 장비 탭에서 검색 로그 서버와 추천 로그 서버의 상태를 조회한다. 두 서버는 별도 장비다.
- 복원 작업의 실행 화면: 복원 제어판
- 대기 인원: 제품 관리자 나도윤, 프로젝트 관리자 서이안

## 준수 사항

- 나도윤과 서이안은 작업 시간 동안 모두 사내 메신저에서 대기해야 한다.
- 캐시 복원 작업의 실행 화면은 복원 제어판 1개만 사용해야 한다.
- 문세린의 승인 없이 서버를 재시작하면 안 된다.
- 전환 완료 보고서를 PM에게 전달하기 전에는 당직을 교대하면 안 된다.

## 절차

1. 11/12(목) 23:10에 작업을 시작한다.
2. 검색 탭에서 검색 캐시의 전환 전 오류율을 5분간 측정하고, 측정값을 작업 기록에 남긴다.
3. 추천 탭에서 추천 캐시의 전환 전 오류율을 5분간 측정하고, 측정값을 작업 기록에 남긴다.
4. 문세린이 23:20에 복원 지점 2개를 등록한다.
5. 되돌림 데스크에 표시된 복원 지점 개수를 23:20에 등록한 2개와 대조한다.
6. 전환 직전에 스냅샷 1개를 추가로 저장한다.
7. 검색 탭에서 검색 캐시를, 추천 탭에서 추천 캐시를 각각 전환한다.
8. 전환 후 오류율을 조회한다.
9. 아래 판정 기준에 따라 복원하거나 관찰한다.
10. 전환 완료 보고서를 PM에게 전달한다.
11. 작업 기록을 운영 포털의 야간 작업함에 저장한다.

## 전환 후 판정 기준

| 전환 후 오류율 | 동작 |
|---|---|
| 2% 초과 | 즉시 복원해야 한다. |
| 2% 이하 | 복원하지 않고 관찰을 유지해야 한다. |

후속 점검은 11/13(금) 09:00이다.

## 장애 연락

오류율을 조회할 수 없거나 복원에 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.

확인 필요: 전환 직전 스냅샷 1개. 검색 캐시와 추천 캐시 각각 1개인지, 두 캐시를 합쳐 1개인지.
확인 필요: 되돌림 데스크. 복원 제어판과 같은 화면인지, 다른 화면인지.
확인 필요: PM. 제품 관리자 나도윤인지, 프로젝트 관리자 서이안인지.
