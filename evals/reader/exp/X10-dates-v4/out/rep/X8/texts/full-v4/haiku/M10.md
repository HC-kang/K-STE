# 누리펄스 캐시 전환 런북 (운영 절차 묶음 4)

이 런북은 11월 12일(목) 23:10부터 23:40까지 야간 당직자 문세린이 누리펄스의 검색 캐시와 추천 캐시를 전환하는 절차를 설명한다. 전환 후 오류율이 2%를 넘으면 즉시 복원하고, 2% 이하이면 복원 없이 관찰을 유지한다. 전환 완료 보고서는 PM에게 전달하며, 전달 전에는 당직을 교대하면 안 된다.

## 1. 작업 개요

- 작업 일시: 11월 12일(목) 23:10 시작, 23:40 종료
- 실행 담당: 야간 당직자 문세린
- 작업 대상: 검색 캐시, 추천 캐시
- 작업 위치: 사내 운영 포털의 검색 탭과 추천 탭 각각
- 서버 상태 조회 위치: 사내 운영 포털의 장비 탭
- 작업 기록 저장 위치: 사내 운영 포털의 야간 작업함
- 대기: 제품 관리자 나도윤, 프로젝트 관리자 서이안은 작업 시간 동안 사내 메신저로 대기한다.
- 지원 연락처: 플랫폼지원팀 윤하민, 내선 4726

## 2. 작업 전 준비

1. 운영 포털의 장비 탭에서 검색 로그 서버와 추천 로그 서버의 상태를 조회하고, 두 서버의 상태를 작업 기록에 적는다.
2. 복원 제어판은 이 작업의 복원 실행 화면으로 1개만 사용한다.

## 3. 작업 절차

1. 23:10에 작업을 시작하고, 시작 시각을 작업 기록에 적는다.
2. 23:20에 문세린이 복원 제어판에서 복원 지점 2개를 등록한다.
3. 되돌림 데스크에서 표시된 복원 지점 개수가 2개인지 대조하고, 대조 결과를 작업 기록에 적는다.
4. 전환 전에 검색 캐시와 추천 캐시의 오류율을 각각 5분간 측정하고, 측정 결과를 작업 기록에 적는다.
5. 전환 직전에 스냅샷을 1개 추가로 저장한다.
6. 운영 포털의 검색 탭과 추천 탭에서 각각 캐시를 전환한다.
7. 전환 후 오류율을 측정하고, 측정 결과를 작업 기록에 적는다.
8. 전환 후 오류율이 2%를 초과하면 즉시 복원한다. 복원 결과를 작업 기록에 적는다.
9. 전환 후 오류율이 2% 이하이면 복원하지 않고 관찰을 유지한다.
10. 23:40에 작업을 종료하고, 종료 시각을 작업 기록에 적는다.
11. 전환 완료 보고서를 작성해 PM에게 전달한다.
12. 11월 13일(금) 09:00에 후속 점검을 한다.
13. 작업 기록을 운영 포털의 야간 작업함에 저장한다.

**경고: 서버 재시작은 문세린의 승인을 받은 뒤에만 진행해야 한다. 전환 완료 보고서를 PM에게 전달하기 전에는 당직을 교대하면 안 된다.**

## 4. 예외 상황

- 오류율을 조회할 수 없거나 복원이 실패하면 플랫폼지원팀 윤하민에게 내선 4726번으로 즉시 연락한다.
- 연락 후에도 작업 기록은 운영 포털의 야간 작업함에 저장해야 한다.

## 5. 확인 필요 사항

확인 필요: 전환 후 오류율 기준의 대상. 검색 캐시와 추천 캐시 중 하나만 2%를 넘는 경우 해당 캐시만 복원하는지, 두 캐시를 모두 복원하는지 원문에 없다.

확인 필요: 전환 후 오류율의 측정 기간. 원문에 측정 시간이 없다.

확인 필요: "PM"의 대상. 나도윤과 서이안 중 누구에게 보고서를 전달하는지 원문에 없다. 보고서 작성 담당자도 원문에 없다.

확인 필요: "11/13(금) 09:00" 후속 점검. 점검을 시작하는 시각인지, 그때까지 끝내야 하는 기한인지 원문에 없다.
