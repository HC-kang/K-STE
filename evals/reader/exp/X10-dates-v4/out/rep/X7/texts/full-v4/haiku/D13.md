# 결제 API 중복 승인 차단 (묶음 5)

결제 API에 중복 승인을 막는 변경을 담았다. 동일 요청 키가 다시 들어오면 기존 승인 결과를 반환한다. 중복 판정은 동일 가맹점의 동일 요청 키를 대상으로 하며, 보관 시간은 40분이다. 리뷰어와 운영 담당은 아래 일정과 승인 조건에 따라 진행한다.

## 변경 내용

중복 판정 범위는 동일 가맹점의 동일 요청 키다. 보관 시간은 40분이다.

요청 키가 없는 호출은 중복 판정에서 제외한다. 이 호출은 기존 승인 경로를 사용한다.

## 일정

- 11/3(화): 개발 담당 윤하린이 통합 테스트 결과를 등록한다.
- 11/5(목): 운영 담당 최도윤이 복구 절차를 검토한다.
- 11/10(화): 리뷰어 박세온이 코드를 승인한다. 승인 조건은 아래 승인 조건 절을 따른다.
- 11/12(목) 14:00: 배포 담당 임나루가 검증 환경 배포를 시작한다.
- 윤하린은 11/17(화)까지 부하 테스트 보고서를 제출해야 한다.

확인 필요: 11/3(화), 11/5(목), 11/10(화). 각 날짜가 그날 하는 일인지 그날까지 끝낼 기한인지 원문에 없다.

## 승인 조건

- 박세온은 통합 테스트 120건을 모두 통과한 경우에만 코드를 승인해도 된다.
- 통합 테스트 실패가 1건 이상이면 코드를 승인하면 안 된다.

## 등록과 댓글 요구

- 윤하린은 통합 테스트 결과와 부하 테스트 보고서를 검증보관함 PAY-58 폴더에 등록해야 한다.
- 최도윤은 복구 검토 결과를 PR 댓글에 작성해야 한다.

## 문의

문의는 결제개발 채널 #pay-review의 윤하린에게 한다. 배포 관련 문의는 같은 채널의 임나루에게 한다.
