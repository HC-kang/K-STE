# 모바일 앱 검증 협의 회의록

품질팀 나세온이 진행한 모바일 앱 검증 협의의 결과이다. 로에담소프트의 서비스별 품질 검증 담당자가 따를 제출 일정, 등록 규칙, 문의처를 정리했다.

## 회의 개요

- 회의명: 모바일 앱 검증 협의
- 진행자: 품질팀 나세온

## 일정

| 날짜 | 할 일 | 날짜 구분 |
|---|---|---|
| 12/1(화) | 서비스별 품질 검증 담당자가 테스트 계정 목록을 등록한다. | 확인 필요 |
| 12/3(목) | 서비스별 품질 검증 담당자가 오류 재현 영상을 업로드한다. | 확인 필요 |
| 12/8(화) | 서비스별 품질 검증 담당자가 검증 결과표를 제출한다. | 확인 필요 |
| 12/10(목) 11:00 | 품질팀 나세온이 본사 소담실에서 오류 분류 실습을 진행한다. | 실행일 |
| 12/11(금) | 서비스별 품질 검증 담당자가 테스트 기기 대여를 신청한다. | 기한 |

## 등록 규칙

- 서비스별 품질 검증 담당자는 12/10(목) 오류 분류 실습에 참석해야 한다.
- 테스트 계정 목록, 오류 재현 영상, 검증 결과표는 토비함 시스템의 ‘앱 검증’ 메뉴에 등록해야 한다.
- 테스트 기기 대여 신청에는 같은 시스템의 ‘기기 대여’ 메뉴를 사용해야 한다.
- 서비스별로 테스트 계정 4개를 등록해야 한다. 계정별 사용자 유형은 중복해도 된다.
- 결제 오류 영상은 30초 이하로, 로그인 오류 영상은 60초 이하로 제작해야 한다.
- 오류를 발견한 서비스는 재현 영상을 업로드해야 한다. 오류가 없는 서비스는 영상을 업로드하지 않아도 된다.
- 검증 결과표는 모든 서비스가 제출해야 한다.

## 문의처

- 계정 권한 문의: 보안팀 도유림, 내선 735
- 영상 업로드 오류 문의: 품질팀 나세온, 사내 메신저 ‘검증 지원’

확인 필요: 12/1(화), 12/3(목), 12/8(화). 각 날짜에 하는 일(실행일)인지, 그날까지 끝낼 일(기한)인지.
