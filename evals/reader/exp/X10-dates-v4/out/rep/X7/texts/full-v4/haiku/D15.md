# 묶음 5: 강의 플레이어 자막 글자 크기 설정 추가

강의 플레이어에 자막 글자 크기 설정을 추가한다. 선택한 글자 크기는 사용자 계정에 저장한다. 적용 대상은 로그인 사용자의 녹화 강의이며, 실시간 강의는 기존 자막 설정을 유지한다. 리뷰어는 키보드 탐색 검증 결과를 확인한 뒤 코드를 승인한다.

## 변경 내용

- 강의 플레이어에 자막 글자 크기 설정을 추가한다.
- 선택한 자막 글자 크기는 사용자 계정에 저장한다.

## 자막 글자 크기

선택값은 16px, 22px, 28px 세 가지이며, 기본값은 22px이다.

## 적용 대상

- 로그인 사용자의 녹화 강의에 적용한다.
- 실시간 강의는 기존 자막 설정을 유지한다.

## 검증 및 승인 조건

- 접근성 QA 담당 유시온이 키보드 탐색을 검증하고, 검증 결과를 PR 댓글에 작성해야 한다.
- 디자인 담당 배아린이 자막 화면 비교 자료와 자막 설정 도움말을 화면검증함 CAP-64 폴더에 등록해야 한다.
- 리뷰어 강로운은 키보드 탐색 검증 32개 항목을 모두 통과한 경우에만 코드를 승인할 수 있다.
- **실패한 항목이 하나라도 있으면 코드를 승인하면 안 된다.**

## 일정

- 12/2(수): 유시온이 키보드 탐색 검증을 한다.
- 12/4(금): 배아린이 자막 화면 비교 자료를 등록한다.
- 12/8(화): 강로운이 변경 코드를 승인한다.
- 12/10(목) 15:00에 노해솔이 검증 서버 기능 시연을 한다.
- 12/15(화)까지 배아린이 자막 설정 도움말을 제출한다.

확인 필요: 12/2(수), 12/4(금), 12/8(화). 각 날짜가 그날 하는 일인지, 그날까지 끝낼 일인지 원문에 밝혀져 있지 않다.
