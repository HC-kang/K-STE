이 PR은 결제 API에 중복 승인 차단을 추가하고, 같은 요청 키가 다시 들어오면 새로 승인하지 않고 기존 승인 결과를 반환한다.

## 중복 판정 규칙

중복 판정 범위는 동일 가맹점의 동일 요청 키이다. 보관 시간은 40분이다. 요청 키가 없는 호출은 중복 판정에서 제외한다. 요청 키가 없는 호출은 기존 승인 경로를 사용한다.

## 일정

- 11/3(화) 개발 담당 윤하린이 통합 테스트 결과를 등록한다. 확인 필요: 11/3(화)이 결과 등록의 실행일인지 기한인지 확인해야 한다.
- 11/5(목) 운영 담당 최도윤이 복구 절차를 검토한다. 확인 필요: 11/5(목)이 검토의 실행일인지 기한인지 확인해야 한다.
- 11/10(화) 리뷰어 박세온이 코드를 승인한다. 확인 필요: 11/10(화)이 승인의 실행일인지 기한인지 확인해야 한다.
- 11/12(목) 14:00에 배포 담당 임나루가 검증 환경 배포를 시작한다.
- 11/17(화)까지 개발 담당 윤하린이 부하 테스트 보고서를 제출한다.

## 역할과 승인 기준

- 박세온은 통합 테스트 120건이 모두 통과한 경우에만 코드를 승인할 수 있다.
- 통합 테스트에서 실패가 1건 이상이면 박세온은 코드를 승인하면 안 된다.
- 윤하린은 테스트 결과와 보고서를 검증보관함 PAY-58 폴더에 등록해야 한다.
- 최도윤은 복구 검토 결과를 PR 댓글에 작성해야 한다.

문의처는 결제개발 채널 #pay-review의 윤하린이다. 배포에 관한 문의는 같은 채널의 임나루에게 한다.
