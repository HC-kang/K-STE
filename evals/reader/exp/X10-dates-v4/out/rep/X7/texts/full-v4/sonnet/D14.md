# 재고조정 화면 차이 수량 필터 추가 (묶음 5)

모래창고 재고조정 화면에 차이 수량 필터를 추가하고, 목록을 차이 수량 절댓값 기준으로 표시하도록 바꾼다. 시범 적용 대상은 동문창고와 남문창고이며, 표본 검증과 성능 측정, 코드 검토, 화면 시연이 남아 있다.

## 변경 내용

- 재고조정 화면에 차이 수량 필터를 추가한다.
- 재고조정 화면이 목록을 차이 수량 절댓값 기준으로 표시한다.
- 필터 기본값은 차이 수량 절댓값 6개 이상이다.
- 냉동 구역 상품에는 필터를 적용하지 않는다.

## 시범 적용과 검증 범위

- 시범 적용 대상은 동문창고와 남문창고다.
- 검증 표본은 창고별 상품 45종이다.

## 일정과 담당

- 11/18(수): 물류 검증 담당 한이솔이 표본 검증 결과를 등록한다.
- 11/20(금): 개발 담당 문태오가 조회 성능을 측정한다.
- 11/24(화): 리뷰어 정라온이 변경 코드를 검토한다.
- 11/26(목) 09:30에: 교육 담당 오다빈이 창고 관리자 대상으로 화면 시연을 진행한다.
- 11/30(월)까지: 개발 담당 문태오가 운영 가이드를 업로드해야 한다.

## 필수 사항

- 한이솔은 표본 검증 결과를 재고검증함 INV-73 폴더에 등록해야 한다.
- 문태오는 성능 측정 결과를 PR 댓글에 작성해야 한다.
- 문태오는 운영 가이드를 재고검증함 INV-73 폴더에 업로드해야 한다.

## 병합 승인 조건

정라온은 동문창고와 남문창고의 표본 검증이 모두 통과한 경우에만 병합을 승인할 수 있다. 한 창고라도 표본 검증이 실패하면 정라온은 병합을 승인하면 안 된다.
