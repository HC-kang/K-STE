# PR 5-1: 노벨릿커머스 주문 중복 차단 변경

묶음 5의 PR 5-1이다. 주문 API의 재시도 처리 모듈에서 동일 요청 키를 재사용하면 주문이 중복 생성되는 문제를 수정한다.

## 변경 내용

- 변경 위치: 주문 API의 재시도 처리 모듈
- 새 중복 차단 기준: 동일 요청 키 수신 후 90초
- 요청 키가 없는 요청은 기존 처리를 유지한다.
- 서버의 요청 로그 보관 기간을 48시간으로 변경한다.

## 검증

대상 환경은 스테이징 주문 서버와 스테이징 환불 서버이다. 두 서버 모두 비교 시험에 사용했다.

주문QA팀이 11/10(화) 14:00~15:00에 비교 시험을 했다. 서버별 요청은 240건이었고, 실패는 0건이었다.

## 일정과 병합 조건

- 리뷰 의견 등록: 11/12(목)
- 병합 일시: 11/13(금) 10:00. 개발 담당 서리안이 병합한다.
- 병합 전에 비교 시험 결과표를 PR 첨부란에 업로드해야 한다.
- 코드 리뷰어 전원이 승인해야 한다.
- 승인이 하나라도 없으면 병합을 보류해야 한다.
