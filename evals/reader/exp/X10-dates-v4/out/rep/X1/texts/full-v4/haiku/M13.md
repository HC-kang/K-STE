# PR 5-1: 노벨릿커머스 주문 중복 차단 변경

이 PR은 주문 API의 재시도 처리 모듈을 수정해, 동일한 요청 키가 재사용될 때 주문이 중복 생성되는 문제를 막는다. 묶음 5의 PR 5-1이며, 개발 담당은 서리안, 검증 담당은 주문QA팀이다. 문의는 사내 #주문변경 채널로 한다.

## 변경 내용

- 변경 위치는 주문 API의 재시도 처리 모듈이다.
- 새 중복 차단 기준은 동일 요청 키를 수신한 후 90초다.
- 요청 키가 없는 요청은 기존 처리를 그대로 유지한다.
- 서버의 요청 로그 보관 기간을 48시간으로 변경한다.

## 검증

주문QA팀이 아래 조건으로 비교 시험을 한다. 두 서버 모두 시험 대상이다.

| 항목 | 내용 |
|---|---|
| 시험 주체 | 주문QA팀 |
| 시험 일시 | 11/10(화) 14:00-15:00 |
| 시험 대상 | 스테이징 주문 서버, 스테이징 환불 서버 |
| 시험 규모 | 서버별 요청 240건 |
| 실패 건수 | 0건 |

확인 필요: 실패 0건. 시험 결과인지 통과 기준인지 사실에 없다.
