# 묶음 5 · PR 5-1: 노벨릿커머스 주문 중복 차단 변경

이 PR은 주문 API의 재시도 처리 모듈을 변경하여, 동일 요청 키가 재사용될 때 주문이 중복 생성되는 문제를 수정한다.

## 담당과 문의

개발 담당은 서리안이다. 검증 담당은 주문QA팀이다. 문의는 사내 #주문변경 채널로 한다.

## 변경 내용

- 새 중복 차단 기준은 동일 요청 키를 수신한 후 90초이다.
- 요청 키가 없는 요청은 기존 처리를 유지한다.
- 서버의 요청 로그 보관 기간을 48시간으로 변경한다.
- 확인 필요: 요청 로그 보관 기간을 변경하는 대상 서버가 어느 서버인지 확인 필요.

## 비교 시험

비교 시험은 주문QA팀이 진행하지 않고 실시하지 않으며, 다음 조건으로 한다.

- 시험 일시는 11/10(화) 14:00~15:00이다.
- 시험 대상은 스테이징 주문 서버와 스테이징 환불 서버이다.
- 시험 요청은 서버별로 240건이다.
- 확인 필요: "실패 0건"이 통과 기준인지 비교 시험 결과 값인지 확인 필요.

이 PR 설명에는 비교 시험 결과를 포함하지 않는다.

## 병합 조건

- 병합 전에 비교 시험 결과표를 PR 첨부란에 업로드해야 한다.
- 코드 리뷰어 전원의 승인을 받아야 한다.
- 승인이 하나라도 없으면 병합을 보류해야 한다.
- 개발 담당 서리안은 11/13(금) 10:00에 병합한다.
