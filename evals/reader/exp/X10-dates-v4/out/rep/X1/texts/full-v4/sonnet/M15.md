# PR 5-3: 테르온물류 배차 집계 작업 개선

묶음 5의 PR이다. 야간 배차 집계 모듈에서 같은 운행 기록을 두 번 합산하는 문제를 수정한다. 민하겸이 12/08(화) 09:00에 운영 환경에 배포한다. 배포 승인 담당자의 승인 댓글이 필요하다.

## 변경 내용

- 변경 위치: 야간 배차 집계 모듈
- 수정 내용: 같은 운행 기록을 두 번 합산하는 문제
- 새 집계 주기는 15분이다.
- 수동 확정한 운행 기록은 재집계 대상에서 제외한다.
- 문서 첫 페이지에 새 집계 기준을 추가한다.

## 배포 승인 담당자 요청 사항

- 배포 승인 담당자는 승인 댓글을 달아야 한다.
- 배포를 시작하기 전에 승인 번호를 변경 이력에 기록해야 한다.
- 배포 승인 담당자는 배차운영팀 검증 회의에 되도록 참석하는 것을 권장한다.

## 일정

- 검증 회의: 12/03(목) 16:00-16:30, 사내 회의실 청록. 배차운영팀이 시험 운행 기록 360건을 검토한다.
- 운영 환경 배포: 12/08(화) 09:00. 민하겸이 배포한다.

시험 운행 기록에서 중복 합산을 1건 이상 발견하면 배포를 중단해야 한다.

## 첨부 문서

배포 절차서와 복구 절차서를 첨부한다. 두 문서 모두 운영 저장소 /dispatch/docs에 보관한다.

## 담당자와 문의

- 개발 담당: 민하겸
- 운영 검증 담당: 배차운영팀
- 문의: 사내 #배차배포 채널

확인 필요: 문서 첫 페이지에 새 집계 기준을 추가한다. 대상이 배포 절차서인지, 복구 절차서인지, 두 문서 모두인지 메모에 없다.
확인 필요: 승인 번호를 변경 이력에 기록해야 한다. 기록하는 사람이 배포 승인 담당자인지, 배포 담당자 민하겸인지 메모에 없다.
확인 필요: 중복 합산을 1건 이상 발견하면 배포를 중단해야 한다. 발견하는 시점과 장소가 12/03(목) 검증 회의의 시험 운행 기록 검토인지, 12/08(화) 배포 중인지 메모에 없다.
