# 누리결제 정산 점검 회의록

야간 정산 파일 4건이 중복 생성되어 누리결제 정산 점검 회의를 열었다. 점검 대상은 결제 서버와 정산 서버이며, 두 서버 모두 테스트 환경이다. 후속 일정은 "할 일"에 적었다.

## 회의 개요

- 일시: 11/12(목) 10:00~10:30
- 장소: 본사 3층 소회의실
- 참석: 정산운영팀 강세린, 플랫폼팀 문도윤
- 점검 원인: 야간 정산 파일 4건 중복 생성
- 점검 대상: 결제 서버와 정산 서버, 두 서버 모두 테스트 환경

## 할 일

- 플랫폼팀은 두 서버의 중복 생성 기록을 조회한다. 조회는 필수이다. 일시: 11/16(월) 09:00~10:00
- 조회 결과를 모아 회의 자료실에 비교표를 업로드한다.
- 서버의 자동 재시도 기능을 중지한다. 중지 시각은 11/16(월) 09:00이다.
- 정산운영팀은 비교표 업로드 알림을 받은 뒤 2시간 이내에 파일 건수를 대조한다. 대조는 필수이다. 대조 범위는 테스트 거래만 포함하고, 실제 고객 거래는 제외한다.
- 재발 방지 보고서를 제출한다. 일자: 11/19(목)
