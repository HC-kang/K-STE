제목: 누리온클라우드 기업용 저장공간 점검 안내

고객사 관리자님께

누리온 운영팀은 저장 장치 노후화로 인해 11/12(목) 02:00~03:00에 저장 장치 교체 작업을 합니다.
작업 중에는 관리자 콘솔에 로그인할 수 없습니다.
기존 공유 링크에서 파일을 내려받는 것은 가능합니다.

점검 일정은 다음과 같습니다.

| 시각 | 내용 |
|---|---|
| 11/10(화) | 고객사 관리자 연락처 제출 |
| 작업 시작 30분 전 | 고객사별 비상 연락망 점검 |
| 11/12(목) 02:00~03:00 | 저장 장치 교체 작업 |
| 점검 완료 후 | 고객지원팀이 등록 관리자 이메일로 결과를 발송합니다. |
| 11/12(목) 04:00까지 | 결과 발송을 완료합니다. |

이번 점검 대상은 유료 기업 요금제 고객사입니다. 무료 체험 고객사는 점검 대상에서 제외됩니다.

관리자 콘솔에 게시된 점검 안내서와 복구 안내서를 내려받아 고객사 내부 게시판에 게시해야 합니다.

문의는 support@nurion.example로 접수합니다. 접수는 이 이메일 주소로만 받습니다.
