# PR 5-2: 모아결에듀 강의 자막 설정 화면 개선

현재 상태는 반영 완료다. 확인 필요: "반영 완료"의 대상과 위치는 무엇인가?

## 개요

이 PR(코드 변경을 검토받으려고 올리는 변경 요청 단위)은 학습 웹의 자막 설정 패널을 개선한다. 개발 담당은 한도윤이고, 접근성 검토 담당은 윤세하다. 문의는 사내 #자막검토 채널로 한다.

## 변경 내용

학습 웹의 자막 설정 패널에서 키보드 초점 표시(키보드로 이동할 때 현재 선택 위치를 보여 주는 테두리나 강조 표시)가 배경과 구별되지 않는 문제를 수정한다.
자막 글자 크기의 기본값은 20px이다. 선택 범위는 16-32px이다.
저장된 사용자 설정이 있으면 저장값을 우선한다.

## 검토 범위

검토 환경은 사내 미리보기 사이트의 강의 L-28이다.
외부 공개 강의는 이번 검토 대상에서 제외한다.
검토 담당자는 확대 화면도 살펴보기를 권장한다.
