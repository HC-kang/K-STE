# 누리결제 정산 점검 회의록

누리결제 정산 점검 회의에서 야간 정산 파일 4건이 중복 생성된 원인을 점검하기로 했다. 점검 대상은 테스트 환경의 결제 서버와 정산 서버이며, 플랫폼팀은 11/16(월) 두 서버의 중복 생성 기록을 조회해야 한다.

## 회의 개요

- 회의명: 누리결제 정산 점검 회의
- 일시: 11/12(목) 10:00~10:30
- 장소: 본사 3층 소회의실
- 참석: 정산운영팀 강세린, 플랫폼팀 문도윤
- 점검 원인: 야간 정산 파일 4건 중복 생성
- 점검 대상: 결제 서버와 정산 서버(두 서버 모두 테스트 환경)

## 할 일 및 일정

1. 플랫폼팀은 11/16(월) 09:00~10:00에 결제 서버와 정산 서버의 중복 생성 기록을 조회해야 한다.
2. 플랫폼팀은 조회 결과를 모아 비교표를 회의 자료실에 업로드한다.
3. 서버의 자동 재시도 기능을 중지한다. 중지 시각은 11/16(월) 09:00이다.
4. 정산운영팀은 비교표 업로드 알림을 받은 뒤 2시간 이내에 파일 건수를 대조해야 한다. 대조 범위는 테스트 거래만 포함하며, 실제 고객 거래는 제외한다.
5. 11/19(목) 재발 방지 보고서를 제출한다.
6. 보고서는 사내 자료실 '정산점검/11월'에 PDF 형식으로 저장한다.

확인 필요: 11/19(목) 재발 방지 보고서 제출. 제출 날짜인지 그때까지 끝낼 기한인지 원문에 밝혀져 있지 않다.

확인 필요: 서버의 자동 재시도 기능 중지. 중지를 수행하는 담당 팀이 원문에 없다.

확인 필요: 비교표 업로드. 업로드 담당자가 원문에 없다.

## 문의

운영지원팀 윤하린, 사내 메신저 '정산점검 문의'
