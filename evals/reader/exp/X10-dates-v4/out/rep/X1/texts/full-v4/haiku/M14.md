# PR 5-2: 모아결에듀 강의 자막 설정 화면 개선

이 PR은 모아결에듀 강의 자막 설정 화면에서 키보드 초점 표시가 배경과 구별되지 않는 문제를 수정한다. 변경 위치는 학습 웹의 자막 설정 패널이다. 개발 담당은 한도윤이고, 접근성 검토 담당은 윤세하다. 검토 의견 반영은 완료 상태로 기록되어 있으나, 어떤 의견을 어떻게 반영했는지는 이 설명에 적혀 있지 않다. 문의는 사내 #자막검토 채널로 한다.

## 변경 내용

- 학습 웹의 자막 설정 패널에서 키보드 초점 표시가 배경과 구별되지 않는 문제를 수정한다.
- 자막 글자 크기의 기본값은 20px이고, 선택 범위는 16-32px이다.
- 저장된 사용자 설정이 있으면 저장값을 우선한다.

## 검토 환경과 범위

- 검토는 사내 미리보기 사이트의 강의 L-28에서 한다.
- 외부 공개 강의는 이번 검토 대상에서 제외한다.

- 검토 결과는 PR 댓글에 기록해야 한다.
- 검토 담당자는 확대 화면도 살펴보는 것을 권장한다.
