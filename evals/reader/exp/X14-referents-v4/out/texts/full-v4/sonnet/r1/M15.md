# 강의 자막 편집기 저장 직후 줄바꿈 소실 수정

이 PR은 강의 자막 편집기에서 저장 직후 줄바꿈이 사라지는 문제를 수정한다. 자막 편집기와 용어 사전 편집기를 변경하며, 두 편집기는 모두 콘텐츠 관리 포털의 강의 도구 메뉴에 배치한다. 개발 담당은 차이담이다. 강의는 12/10(목) 11:00에 공개한다.

## 변경 내용

- 자막 편집기: 저장 직후 줄바꿈이 사라지는 문제를 수정했다.
- 용어 사전 편집기: 이번 PR에서 변경했다.
- 위치: 두 편집기 모두 콘텐츠 관리 포털의 강의 도구 메뉴에 있다.

## 입력 글자 수 상한

- 자막 한 줄: 최대 42자
- 용어 설명: 최대 120자
- 계산 방식: 공백도 글자 수에 포함한다.

## 일정

| 항목 | 일시 | 구분 |
|---|---|---|
| 접근성 검수 마감 | 12/09(수) 15:00 | 기한 |
| 타임가드 실행 | 12/10(목) 10:00 | 실행일 |
| 강의 공개 | 12/10(목) 11:00 | 실행일 |

## 공개 전 검사

타임가드는 자막 시간축을 검사하는 자동 작업이며, 이번 공개의 단일 자동 검사 작업이다. 정모아가 12/10(목) 10:00에 강의 36편을 검사한다. 시간축 오류가 1건 이상이면 공개를 보류해야 한다.

팀장 승인 댓글을 받은 뒤에 공개해야 한다. 공개 담당은 류하온이다.

## 접근성 검수 안내

- 접근성 검수자는 키보드 조작 결과를 첨부해야 한다.
- 보관 상태 강의는 이번 검수 대상이 아니다.
- 문의는 #강의-편집 채널로 한다.

## 공개 당일과 공개 후

- 공개 당일에 CS팀에 안내를 전달해야 한다.
- 공개 후 2시간 동안 일괄 수정 기능을 사용하면 안 된다.

## 담당

- 임새론(콘텐츠 운영팀 팀장): 강의 공개 일정을 담당한다.
- 백여울(접근성 검수팀 팀장): 검수 인력 배정을 담당한다.
- 고객지원팀: 강사 문의를 담당한다.
- 고객성공팀: 기관 고객 교육을 담당한다.

확인 필요: 팀장 승인 댓글. 임새론 팀장의 승인인지, 백여울 팀장의 승인인지.
확인 필요: CS팀. 고객지원팀인지, 고객성공팀인지.
확인 필요: 문서 식별자 묶음 5-3. 식별자의 실제 값이 없다.
