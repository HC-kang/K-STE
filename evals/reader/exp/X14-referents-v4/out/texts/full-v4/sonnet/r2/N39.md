# PR #133: 게임 패치 재개 기능 (이어받기창)

이 PR은 게임 패치 재개 기능을 다룬다. 다운로드 중 연결이 끊기면 처음부터 다시 받던 동작이 수정 원인이다. 개발 담당은 한루온이고, 게임 클라이언트 저장소에서 리뷰한다. 정식 명칭이 ‘패치 복구 패널’인 이어받기창에는 남은 용량을 MB 단위로 보여 준다.

## 변경 내용

- 이어받기창에 남은 용량을 MB 단위로 보여 준다.
- 예상 완료 시각은 이번 변경에 포함하지 않는다.
- 남은 공간이 500MB 미만이면 패치 재개를 차단해야 한다.
- 개발 전용 계정은 공간 검사에서 제외해야 한다.

## 병합 전 조건

- RC 검토 기록을 PR #133의 출시 검토 칸에 연결해야 한다.
- 검증용 계정 8개를 실험실에 전달해야 한다. 전달이 끝나야 리뷰를 시작한다.
- 검증 담당자는 12/02(수) 18:00까지 내부 시험 환경 ‘별무리-패치’에서 중단 후 재개 20회를 전부 성공시켜야 한다.
- 20회 중 실패가 한 번이라도 나오면 병합하면 안 된다.

## 검증과 첨부

| 항목 | 담당 | 내용 |
|---|---|---|
| 모바일 실험실 | 정나겸 | 휴대전화에서 패치 재개를 검증한다. |
| 콘솔 실험실 | 유서안 | 거치형 기기에서 패치 재개를 검증하고, 결과를 PR #133에 댓글로 올린다. |
| 중단 재현 보고서 | 정나겸 | 작성해 PR #133에 첨부한다. |
| 저장 공간 보고서 | 유서안 | 작성해 PR #133에 첨부한다. |

## 출시 위원회

위원회는 12/03(목) 14:00에 열린다. 의장은 배시온이고, 위원회가 정식 배포 여부를 심의한다. 앞서 올린 문서는 위원회 시작 1시간 전까지 배시온에게도 보내야 한다.

## 배포 후

정식 배포 후 첫 30분은 다운로드 실패율을 5분마다 기록해야 한다. 기능 문의는 클라이언트개발 채널의 한루온에게 하면 된다.

확인 필요: 실험실에는 검증용 계정 8개를 전달. 모바일 실험실만 가리키는지, 모바일 실험실과 콘솔 실험실 모두를 가리키는지.
