# 누리펄스 캐시 전환 런북

운영 절차 묶음 4의 이 런북은 누리펄스 검색 캐시와 추천 캐시의 전환 작업 절차를 정리한 것이다. 작업은 11/12(목) 23:10에 시작해 23:40에 종료하며, 야간 당직자 문세린이 실행한다. 이 작업 전에 캐시 갱신 지연으로 검색 결과 누락이 발생했다.

## 작업 개요

- 작업 대상: 검색 캐시, 추천 캐시
- 작업 위치: 사내 운영 포털의 검색 탭, 추천 탭 각각
- 작업 시간: 11/12(목) 23:10 시작, 23:40 종료
- 실행 담당: 야간 당직자 문세린
- 대기 인원: 제품 관리자 나도윤, 프로젝트 관리자 서이안

## 사전 요구사항

1. 나도윤과 서이안은 작업 시간 동안 모두 사내 메신저에서 대기해야 한다.
2. 검색 로그 서버와 추천 로그 서버는 별도 장비이므로, 두 서버의 상태를 운영 포털의 장비 탭에서 각각 조회해야 한다.
3. 서버 재시작은 문세린이 승인한 후에만 진행해야 한다.
4. 캐시 복원 작업의 실행 화면은 1개만 사용해야 한다. 정식 화면명은 복원 제어판이다.

## 전환 전 작업

1. 검색 캐시와 추천 캐시 모두 전환 전 오류율을 5분간 측정해 작업 기록에 남겨야 한다.
2. 전환 직전에 스냅샷 1개를 추가로 저장해야 한다.
3. 문세린은 23:20에 복원 제어판에서 복원 지점 2개를 등록해야 한다.
4. 되돌림 데스크에 문세린이 23:20에 등록한 복원 지점 2개가 보여야 한다. 표시된 개수를 등록한 개수와 반드시 대조해야 한다.

## 전환 후 판정

1. 전환 후 오류율을 조회한다.
2. 오류율이 2%를 초과하면 즉시 복원해야 한다.
3. 오류율이 2% 이하이면 복원하지 않고 관찰을 유지해야 한다.
4. 11/13(금) 09:00에 후속 점검을 한다.

## 장애 시 연락

오류율을 조회할 수 없거나 복원에 실패하면, 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.

## 보고와 기록

- 전환 완료 보고서는 PM에게 전달해야 한다.
- 보고서를 전달하기 전에는 당직을 교대하면 안 된다.
- 작업 기록은 운영 포털의 야간 작업함에 저장해야 한다.

확인 필요: 전환 직전 스냅샷 1개 추가 저장. 검색 캐시와 추천 캐시 각각 1개씩인지, 두 캐시를 합쳐 1개인지.
확인 필요: 되돌림 데스크. 복원 제어판과 같은 화면의 다른 이름인지, 복원 제어판과 별개인 화면인지.
확인 필요: PM. 프로젝트 관리자 서이안을 가리키는지, 다른 담당자를 가리키는지.
