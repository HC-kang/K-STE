# 구매 주문서 중복 저장 방지 (PR #501)

다온상사 구매 플랫폼에서 구매 주문서가 중복 저장되지 않도록 막는 변경이다. 구매 요청 대시보드의 중복 요청 경고 문구도 이번 변경에 포함한다.

## 변경 내용

- 구매 주문서의 중복 저장을 방지한다.
- 구매 요청 대시보드(팀 내 별칭은 구매판)의 중복 요청 경고 문구를 이번 변경에 포함한다.
- 구매 주문서 예시 파일: order-sample.csv

## 검증

작성자 민도겸이 서부 테스트 환경과 동부 테스트 환경에서 각각 40건을 재전송한다. 주문 번호가 같은 요청은 30초 안에 다시 와도 1건만 저장되어야 한다. 읽기 전용 계정은 재전송 시험에서 제외한다.

| 환경 | 검증 시작 |
| --- | --- |
| 서부 테스트 환경 | 11/12(목) 10:00 |
| 동부 테스트 환경 | 11/13(금) 15:00 |

## 병합 조건

1. 코드 리뷰어 전원이 승인해야 한다.
2. 병합 전에 PO 검토를 마쳐야 한다. 검토를 마친 기록을 PR 댓글에 첨부해야 한다.
3. 그 파일은 병합 직전 최신 버전으로 교체해야 한다.
