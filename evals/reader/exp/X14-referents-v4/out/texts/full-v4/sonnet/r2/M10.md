# 누리펄스 캐시 전환 런북 (운영 절차 묶음 4)

이 런북은 야간 서비스 운영 당직자가 누리펄스 캐시 전환 작업을 할 때 따르는 절차를 정한다. 작업은 11/12(목) 23:10에 시작해 23:40에 종료하며, 실행 담당은 야간 당직자 문세린이다. 작업 대상은 검색 캐시와 추천 캐시이다.

## 배경

캐시 갱신 지연으로 검색 결과 누락이 발생했다.

## 작업 정보

- 일시: 11/12(목) 23:10 시작, 23:40 종료
- 실행 담당: 야간 당직자 문세린
- 검색 캐시 작업 위치: 사내 운영 포털의 검색 탭
- 추천 캐시 작업 위치: 사내 운영 포털의 추천 탭
- 서버 상태 조회 위치: 운영 포털의 장비 탭

검색 로그 서버와 추천 로그 서버는 별도 장비이다. 제품 관리자 나도윤과 프로젝트 관리자 서이안은 작업 시간 동안 모두 사내 메신저에서 대기한다.

## 준수 사항

- 검색 캐시와 추천 캐시 모두 전환 전 오류율을 5분간 측정해 작업 기록에 남겨야 한다.
- 전환 직전에 스냅샷 1개를 추가로 저장해야 한다.
- 서버 재시작은 문세린이 승인한 뒤에만 해야 한다.
- 캐시 복원 작업의 실행 화면은 1개만 사용해야 한다. 정식 화면명은 복원 제어판이다.
- 되돌림 데스크에 문세린이 23:20에 등록한 복원 지점 2개가 보여야 한다. 표시 개수를 대조해야 한다.
- 전환 완료 보고서를 PM에게 전달하기 전에는 당직을 교대하면 안 된다.

## 절차

1. 검색 탭에서 검색 캐시의 전환 전 오류율을 5분간 측정하고 작업 기록에 남긴다.
2. 추천 탭에서 추천 캐시의 전환 전 오류율을 5분간 측정하고 작업 기록에 남긴다.
3. 문세린이 23:20에 복원 지점 2개를 등록한다.
4. 되돌림 데스크에 복원 지점 2개가 보이는지 표시 개수를 대조한다.
5. 전환 직전에 스냅샷 1개를 추가로 저장한다.
6. 서버를 재시작해야 하면 먼저 문세린의 승인을 받은 뒤에 재시작한다.
7. 검색 탭과 추천 탭에서 각각 검색 캐시와 추천 캐시를 전환한다.
8. 전환 후 오류율을 조회한다.
9. 전환 후 오류율이 2%를 초과하면 즉시 복원한다.
10. 전환 후 오류율이 2% 이하이면 복원하지 않고 관찰을 유지한다.
11. 전환 완료 보고서를 PM에게 전달한 뒤에 당직을 교대한다.

## 후속 점검

후속 점검 일시는 11/13(금) 09:00이다.

## 장애 시 연락

오류율을 조회할 수 없거나 복원이 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다. 작업 기록은 운영 포털의 야간 작업함에 저장해야 한다.

확인 필요: 스냅샷 1개 추가 저장. 검색 캐시와 추천 캐시 각각 1개씩 저장하는 경우와, 두 캐시를 합쳐 1개만 저장하는 경우가 있다.
확인 필요: 되돌림 데스크. 복원 제어판과 같은 화면인 경우와, 별도 화면인 경우가 있다.
확인 필요: 후속 점검 11/13(금) 09:00. 09:00에 점검을 하는 경우와, 09:00까지 점검을 끝내야 하는 경우가 있다.
확인 필요: PM. 프로젝트 관리자 서이안인 경우와, 다른 사람인 경우가 있다.
