# PR #133: 게임 패치 재개 기능

이 PR은 묶음 13의 세 번째 PR이다. 다운로드 중 연결이 끊기면 처음부터 다시 받던 것이 수정 원인이다. 개발 담당은 한루온이고, 게임 클라이언트 저장소에서 리뷰한다.

## 변경 내용

정식 명칭은 '패치 복구 패널'이고, 팀에서는 '이어받기창'이라고 부른다. 이 문서는 '이어받기창'으로 쓴다.

- 이어받기창에 남은 용량을 MB 단위로 보여 준다.
- 예상 완료 시각은 이번 변경에 포함하지 않는다.
- 남은 공간이 500MB 미만이면 재개를 차단해야 한다.
- 개발 전용 계정은 공간 검사에서 제외해야 한다.

## 리뷰와 병합 조건

- 실험실에 검증용 계정 8개를 전달해야 한다. 계정 전달이 끝나야 리뷰를 시작한다.
- 병합 전에 RC 검토 기록을 PR #133의 출시 검토 칸에 연결해야 한다. 기록 연결은 필수다.
- 중단 후 재개 시험에서 실패가 한 번이라도 나오면 PR #133을 병합하면 안 된다.

## 검증과 첨부 문서

- 모바일 실험실: 휴대전화에서 패치 재개를 검증한다. 담당은 정나겸이다.
- 콘솔 실험실: 거치형 기기에서 패치 재개를 검증한다. 담당은 유서안이고, 검증 결과를 PR #133에 댓글로 올려야 한다.
- 중단 재현 보고서: 정나겸이 작성해 PR #133에 첨부해야 한다.
- 저장 공간 보고서: 유서안이 작성해 PR #133에 첨부해야 한다.

## 일정

- 12/01(화) 11:00에 출시 후보 빌드를 시험 배포한다.
- 검증 담당자는 12/02(수) 18:00까지 내부 시험 환경 '별무리-패치'에서 중단 후 재개 20회를 전부 성공시켜야 한다.
- 12/03(목) 14:00에 출시 위원회가 열린다. 의장은 배시온이고, 위원회가 정식 배포 여부를 심의한다.
- 앞서 올린 문서를 출시 위원회 시작 1시간 전까지 배시온에게도 보내야 한다. 전달은 필수다.
- 한루온이 12/04(금) 10:00에 정식 배포할 예정이다.
- 배포 후 첫 30분은 다운로드 실패율을 5분마다 기록해야 한다.

## 문의

기능 문의는 클라이언트개발 채널의 한루온에게 보낸다.

확인 필요: "실험실에 검증용 계정 8개를 전달". 모바일 실험실에 전달하는 경우와 콘솔 실험실에 전달하는 경우.
확인 필요: "앞서 올린 문서". 가리키는 문서가 원문에 없다.
확인 필요: "다운로드 실패율을 5분마다 기록". 기록하는 담당자가 원문에 없다.
