# PR #503: 오리엔테이션 참석 시간 중복 합산 수정

## 요지

PR #503은 오리엔테이션 참석 시간이 두 번 합산되던 오류를 수정한다. 참석 기록은 입문 연동 모듈이 받는다. 릴리스 승인자는 초과 근무 시간을 포함한 회귀 시험 18건이 모두 통과한 뒤 병합을 승인해야 한다. 운영 배포는 11/23(월) 08:00에 시작한다.

## 변경 내용

중복 여부는 직원 번호와 기록 식별자가 모두 같은지로 판단한다. 같은 기록이 60초 안에 재수신되면 최초 기록 1건만 합산한다. 수동 보정 기록은 중복 제거 대상에서 제외한다.

시간 집계 검토 화면(현업에서는 시간판이라고 부른다)에는 중복으로 제외한 기록의 개수를 표시한다.

근무 연동 모듈은 근무 기록을 받는다. 담당 개발자는 차은재다.

## 검증 계획

1. 차은재가 11/19(목) 10:00에 연습 공간에서 집계 결과를 검증한다.
2. 문해솔이 11/20(금) 16:00에 연습 공간에서 권한 설정을 검증한다.
3. 집계 결과 검증과 권한 설정 검증은 각각 45분 진행한다.
4. 11/20(금) 16:00 권한 설정 검증 시간에는 외부 참관자의 연습 공간 접속을 막아야 한다.
5. OT 집계 결과는 병합 전에 인사 운영 담당자의 승인을 받아야 한다.

## 병합 승인 조건

릴리스 승인자는 회귀 시험 18건이 모두 통과한 뒤 병합을 승인해야 한다. 일부 통과만으로는 승인할 수 없다.

## 배포 계획

1. 연동 모듈의 재시도 기능은 배포 중 반드시 꺼야 한다.
2. 운영 배포는 11/23(월) 08:00에 시작한다.
3. 배포 담당자는 배포 시작부터 20분 동안 오류율을 관찰해야 한다.
4. 배포 문의는 사내 메신저 #인사배포의 문해솔이 받는다.

## 확인 필요

확인 필요: "연동 모듈의 재시도 기능". 입문 연동 모듈의 재시도 기능만 끄는지, 근무 연동 모듈을 포함한 두 연동 모듈의 재시도 기능을 모두 끄는지.
