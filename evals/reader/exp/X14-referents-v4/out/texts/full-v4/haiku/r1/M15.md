# 강의 자막 편집기 및 용어 사전 편집기 변경

이 PR은 강의 자막 편집기의 저장 직후 줄바꿈이 사라지는 문제를 고치고, 자막 편집기와 용어 사전 편집기를 변경한다. 두 편집기는 콘텐츠 관리 포털의 강의 도구 메뉴에 배치된다. 개발 담당은 차이담이며, 강의는 12/10(목) 11:00에 공개된다. 접근성 검수는 12/09(수) 15:00까지 마쳐야 한다.

## 변경 내용

- 자막 편집기: 저장 직후 줄바꿈이 사라지는 문제를 수정한다.
- 용어 사전 편집기: 변경한다. 확인 필요: 용어 사전 편집기의 변경 세부 내용. 원문에 변경 내용이 없다.
- 배치: 자막 편집기와 용어 사전 편집기를 모두 콘텐츠 관리 포털의 강의 도구 메뉴에 둔다.

## 입력 제한

- 자막 한 줄은 42자를 넘으면 안 된다. 공백도 글자 수에 포함한다.
- 용어 설명은 120자를 넘으면 안 된다. 공백도 글자 수에 포함한다.

## 공개 일정과 담당

| 항목 | 일시 | 담당 |
|---|---|---|
| 접근성 검수 마감 | 12/09(수) 15:00까지 | 접근성 검수팀 |
| 자동 검사(타임가드) 실행 | 12/10(목) 10:00에 강의 36편 검사 | 정모아 |
| 강의 공개 | 12/10(목) 11:00에 | 류하온 |

- 강의 공개 일정은 콘텐츠 운영팀 팀장 임새론이 담당한다.
- 검수 인력 배정은 접근성 검수팀 팀장 백여울이 담당한다.

## 공개 보류 조건

타임가드는 이번 공개의 단일 자동 검사 작업이며, 정모아가 12/10(목) 10:00에 강의 36편의 자막 시간축을 검사한다. 시간축 오류가 1건 이상이면 공개를 보류한다.

## 공개 절차

1. 팀장님의 승인 댓글을 받는다. 확인 필요: 승인 댓글을 남기는 팀장. 임새론 팀장의 승인인지, 백여울 팀장의 승인인지 원문에 없다.
2. 승인 댓글을 받은 뒤 강의를 공개한다.
3. 공개 당일 CS팀에 안내를 전달해야 한다. 확인 필요: 안내를 전달할 담당자. 원문에 없다.

## 공개 후 제한

- 공개 후 2시간 동안 일괄 수정 기능을 사용하면 안 된다. 확인 필요: "그건"이 가리키는 대상. 일괄 수정 기능을 가리키는지, 공개를 가리키는지 원문에 분명하지 않다.

## 접근성 검수 기준

- 접근성 검수자는 키보드 조작 결과를 첨부해야 한다. 확인 필요: 첨부 파일 형식과 위치. 원문에 없다.
- 보관 상태 강의는 이번 검수에서 제외한다.

## 역할

- 고객지원팀: 강사 문의에 대응한다.
- 고객성공팀: 기관 고객 교육을 담당한다.
- CS팀: 공개 당일 안내를 받는다.
