# 결제 라우터 R4 야간 전환 운영 절차

이 절차는 11/12(목) 22:10부터 22:30까지 결제 라우터 R4를 전환할 때 야간 결제 운영 담당자가 따라 하도록 작성한다. 전환은 운영 콘솔 /route/r4에서 야간 담당 서루하가 실행한다. 외부 결제 중계 장비를 교체하면 기존 연결이 끊기므로, 이 작업은 그 상황에 대비하는 작업이다. 전환 전에는 승인 대기 건수를, 전환 중에는 응답 시간을 기준으로 중단 여부를 판단한다.

## 1. 역할

| 담당 | 역할 |
|---|---|
| 야간 결제 운영 담당자 | 전환 전 승인 대기 건수 조회, 중단 기준 확인 |
| 서루하 (야간 담당) | 운영 콘솔 /route/r4에서 전환 실행, 중단 시 이전 경로 복원 |
| 도이안 (제품 책임자, Product Owner) | 전환 영향 검토서 작성 |
| 고세림 (구매 담당) | 외부 결제 중계 장비의 구매 주문서 검토, 주문 검토서 작성 |
| 동문 관제실 | 전환 중 결제 응답 시간 감시 |
| 서문 관제실 | 11/13(금) 00:10에 결제 라우터 R4 로그 대조 |
| 나해솔 (운영 담당) | 작업 문의 응대 |

결제판(새 결제 관제 화면)의 조회 권한은 야간 결제 운영 담당자에게 부여된다.

## 2. 전환 전 확인

1. 결제판에서 전환 직전 승인 대기 건수를 조회한다.
2. 결제판에 접속되지 않으면 대기 건수를 추정하지 않고 전환을 보류한다.
3. 조회한 승인 대기 건수가 20건 이상이면 전환을 중단한다.
4. PO 검토 결과를 전환 전에 운영 기록에 첨부한다.

## 3. 전환 실행

5. 서루하가 22:10부터 22:30까지 운영 콘솔 /route/r4에서 결제 라우터 R4를 전환한다.
6. 동문 관제실이 전환 중 결제 응답 시간을 감시한다. 승인 대기 건수가 20건 미만이어도 응답 시간이 3초를 넘으면 전환을 중단한다.

## 4. 중단과 복원

7. 전환을 중단하면 서루하가 5분 이내에 이전 경로를 복원한다.
8. 중단된 건도 11/13(금) 00:10 서문 관제실의 결제 라우터 R4 로그 대조에 포함된다.

## 5. 작업 후 기록과 알림

9. 도이안이 전환 영향 검토서를 작성한다.
10. 작업 종료 후 30분 이내에 전환 영향 검토서 파일을 기록함 /night/close에 올린다.
11. 관제실에 완료 시각을 반드시 알린다. 알림은 운영 채널 #r4-night에 남긴다.

## 6. 문의

작업 문의는 운영 담당 나해솔에게 내선 4816으로 한다. 나해솔은 11/12(목) 21:50부터 11/13(금) 00:30까지 문의를 받는다.

## 확인 필요

확인 필요: PO 검토 결과. 제품 책임자 도이안의 검토 결과를 가리키는지, 구매 담당 고세림의 주문 검토서를 가리키는지 불분명하다.

확인 필요: 관제실에 완료 시각을 알리는 담당자와 전환 영향 검토서를 기록함에 올리는 담당자. 사실에 정해진 담당자가 없다.

확인 필요: 5분 이내. 복원 기한의 기준 시점이 사실에 없다.
