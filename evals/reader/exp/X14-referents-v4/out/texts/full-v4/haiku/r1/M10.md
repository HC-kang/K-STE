# 누리펄스 캐시 전환 런북

이 런북은 운영 절차 묶음 4에 속하며, 11/12(목) 23:10에 시작해 23:40에 끝나는 검색 캐시와 추천 캐시 전환 작업의 절차를 정한다. 실행 담당은 야간 당직자 문세린이다. 캐시 갱신 지연으로 검색 결과 누락이 발생하므로, 두 캐시 모두 전환 전 오류율을 5분간 측정해 작업 기록에 남겨야 한다. 전환 후 오류율이 2%를 초과하면 즉시 복원해야 한다.

## 1. 작업 개요

- 작업명: 누리펄스 캐시 전환
- 일시: 11/12(목) 23:10 시작, 23:40 종료
- 실행 담당: 야간 당직자 문세린
- 대상: 검색 캐시, 추천 캐시
- 작업 위치: 사내 운영 포털의 검색 탭과 추천 탭. 각 캐시는 해당 탭에서 전환한다.
- 장비: 검색 로그 서버와 추천 로그 서버는 별도 장비다. 두 서버의 상태는 운영 포털의 장비 탭에서 조회한다.

## 2. 역할과 연락처

| 역할 | 담당자 | 연락 방법 |
|---|---|---|
| 실행 담당 | 문세린 | 야간 당직 |
| 제품 관리자 | 나도윤 | 작업 시간 동안 사내 메신저 대기 |
| 프로젝트 관리자 | 서이안 | 작업 시간 동안 사내 메신저 대기 |
| 플랫폼지원팀 | 윤하민 | 내선 4726으로 즉시 연락 |

## 3. 작업 절차

1. 문세린이 23:10에 작업을 시작한다.
2. 검색 캐시의 전환 전 오류율을 5분간 측정하고, 측정값을 작업 기록에 남긴다.
3. 추천 캐시의 전환 전 오류율을 5분간 측정하고, 측정값을 작업 기록에 남긴다.
4. 전환 직전 스냅샷을 1개 추가로 저장해야 한다.
   확인 필요: 전환 직전 스냅샷 1개 추가 저장. 검색 캐시와 추천 캐시 각각에 1개씩 저장하는 경우와 두 캐시를 합쳐 1개만 저장하는 경우.
5. 문세린이 23:20에 복원 지점 2개를 복원 제어판에 등록한다. 캐시 복원 작업은 복원 제어판 화면 1개에서만 실행해야 한다.
6. 검색 탭에서 검색 캐시를 전환한다.
7. 추천 탭에서 추천 캐시를 전환한다.
8. 전환 후 오류율을 측정하고, 측정값을 작업 기록에 남긴다.
9. 되돌림 데스크에 문세린이 23:20에 등록한 복원 지점 2개가 보여야 한다. 표시된 개수가 2개인지 대조한다.

## 4. 서버 재시작

- 서버 재시작은 문세린의 승인을 받은 뒤에만 진행해야 한다.
- 승인을 받기 전에는 서버를 재시작하면 안 된다.

## 5. 복원 기준

- 전환 후 오류율이 2%를 초과하면 복원 제어판에서 즉시 복원해야 한다.
- 전환 후 오류율이 2% 이하이면 복원하지 않고 관찰을 유지해야 한다.
- 오류율 조회가 불가능하거나 복원이 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.

확인 필요: 전환 후 오류율 2% 기준. 검색 캐시와 추천 캐시 각각에 적용하는 경우와 두 캐시를 합산해 적용하는 경우.

## 6. 기록과 보고

- 작업 기록은 운영 포털의 야간 작업함에 저장해야 한다.
- 전환 완료 보고서는 PM에게 전달해야 한다.

확인 필요: PM. 프로젝트 관리자 서이안을 가리키는 경우와 제품 관리자 나도윤을 가리키는 경우.

**경고: 전환 완료 보고서를 PM에게 전달하기 전에는 당직을 교대하면 안 된다.**

- 후속 점검 시각: 11/13(금) 09:00
