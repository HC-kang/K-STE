# PR #133: 게임 패치 재개 기능 (패치 복구 패널)

이 PR은 게임 패치 다운로드를 중단한 뒤 재개하는 기능을 추가하고, 다운로드 중 연결이 끊기면 처음부터 다시 받던 문제를 수정한다. 개발 담당은 한루온이며 게임 클라이언트 저장소에서 리뷰한다. 패치 복구 패널은 팀에서 '이어받기창'으로 부른다. 병합 전에 RC 검토 기록을 PR #133의 출시 검토 칸에 연결해야 한다. 검증용 계정 전달이 끝난 뒤 리뷰를 시작해야 한다.

## 변경 내용

- 패치 복구 패널에 남은 용량을 MB 단위로 표시한다.
- 예상 완료 시각은 이번 변경에 포함하지 않는다.
- 다운로드 중 연결이 끊기면 처음부터 다시 받던 동작을 수정한다. 이 동작이 수정 원인이다.
- 남은 공간이 500MB 미만이면 재개를 차단해야 한다.
- 개발 전용 계정은 공간 검사에서 제외한다.

## 검증 요구사항

- 검증용 계정 8개를 실험실에 전달해야 한다. 확인 필요: 검증용 계정 전달 담당자. 원문에 전달 담당자가 없다.
- 모바일 실험실은 휴대전화에서 패치 재개를 검증한다. 담당은 정나겸이다.
- 콘솔 실험실은 거치형 기기에서 패치 재개를 검증한다. 담당은 유서안이다. 검증 결과는 PR #133에 댓글로 올린다.
- 검증 담당자는 12/02(수) 18:00까지 중단 후 재개 20회를 전부 성공시켜야 한다. 시험 장소는 내부 시험 환경 '별무리-패치'이다. 확인 필요: 검증 담당자와 20회 기준. 원문에 검증 담당자가 특정되어 있지 않고, 20회가 실험실별인지 합산인지 나타나 있지 않다.
- 실패가 한 번이라도 나오면 병합하면 안 된다.

## 첨부 문서

- 중단 재현 보고서: 정나겸이 작성해 PR #133에 첨부한다.
- 저장 공간 보고서: 유서안이 작성해 PR #133에 첨부한다.
- RC 검토 기록: 병합 전에 PR #133의 출시 검토 칸에 연결해야 한다. 확인 필요: RC 검토 기록 연결 담당자. 원문에 담당자가 없다.

## 배포 및 운영

- 정식 배포는 한루온이 진행한다.
- 출시 위원회는 배시온이 의장을 맡으며, 정식 배포 여부를 심의한다.
- 배포 후 첫 30분 동안 다운로드 실패율을 5분마다 기록해야 한다. 확인 필요: 실패율 기록 담당자. 원문에 기록 담당자가 없다.
- 앞서 올린 문서는 출시 위원회 시작 1시간 전까지 배시온에게 전달해야 한다. 확인 필요: 앞서 올린 문서. 원문에 어떤 문서인지 나타나 있지 않다.
- 기능 문의는 클라이언트개발 채널의 한루온에게 한다.
