# PR #131: 구매 주문서 중복 생성 차단

이 PR은 재전송 때문에 같은 구매 주문서가 두 번 생성되는 문제를 막는다. 동일 주문 키가 30초 안에 다시 들어오면 주문 생성을 차단해야 한다. 함께 추가하는 주문 중복 검사 화면(이하 주문돋보기)은 구매 주문서를 번호로 조회하는 기능만 제공한다.

## 기본 정보

- 개발자: 윤해솔
- 제품 책임자: 서도윤 (요구사항 승인)
- 리뷰 시작: 11/12(목) 14:00
- 저장소: 구매 서비스 저장소 PR #131
- 문의: 구매개발 채널의 윤해솔

## 배경

재전송된 요청 때문에 같은 주문이 두 번 생성되었다. 이 PR은 재전송으로 생기는 중복 생성을 차단하는 것을 목표로 한다.

## 변경 내용

1. 동일 주문 키가 30초 안에 다시 들어오면 주문 생성을 차단해야 한다.
2. 수동 복구 계정은 위 차단에서 예외로 통과시킨다.
3. 주문 중복 검사 화면을 추가한다. 이 화면에서 구매 주문서를 번호로 조회한다.
4. 주문 중복 검사 화면은 이번 PR에서 조회 기능만 제공한다. 주문 취소 버튼은 포함하지 않는다.

## 검증 계획

- 동부 검증실은 실제 주문 형식 재현을 맡는다.
- 서부 검증실은 대량 요청 재현을 맡는다.
- 실패 기록은 재시도 로그 파일에, 처리 시간은 응답 측정 파일에 남긴다.
- 리뷰어는 11/13(금) 16:00까지 차단 사례 12건을 전부 검증해야 한다.
- 검증실에는 병합 전에 결과표를 올려야 한다. 결과표 제출은 필수다.
