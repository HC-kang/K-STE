# 결제 재시도 PR 설명 (묶음 5-1)

이 PR은 중복 승인 요청 때문에 고객 결제 알림이 두 번 나가는 문제를 수정한다. 승인 재시도 작업과 알림 재전송 작업의 재시도 설정을 바꾸고, 주문 DB와 정산 DB에 조회 인덱스를 추가한다. 담당 개발자는 서다온이다. 배포는 11/12(목) 14:00에 문해솔이 맡는다. 검토 완료 기한은 11/11(수) 17:00이다.

## 변경 대상

승인 재시도 작업과 알림 재전송 작업을 변경한다. 두 작업은 모두 결제 운영 콘솔에서 실행한다.

## 재시도 설정

- 승인 재시도: 간격 30초, 최대 3회
- 알림 재전송: 간격 60초, 최대 2회

## DB 변경

주문 DB와 정산 DB에 각각 조회 인덱스를 추가한다. 기존 컬럼은 삭제하지 않는다.

## 배포 절차

1. 11/12(목) 13:30에 서다온이 사전 검사를 실행한다. 사전 검사는 표본 240건을 대조한다. 검사가 실패하면 배포를 중단한다.
2. 배포 전에 DB 스냅샷을 보관해야 한다.
3. 11/12(목) 14:00에 배포한다. 배포 담당은 문해솔이다.
4. 배포 직후 20분 동안 [작업명 확인 필요] 작업을 수동으로 실행하면 안 된다.

## 검토 요청

배포 검토자는 재시도 테스트 통과 기록을 첨부해야 한다. 내부 시험 상점은 테스트 대상에서 제외한다. 문의는 #결제-변경 채널에 한다. 검토 완료 기한은 11/11(수) 17:00이다.

## 병합 조건

PM 승인 댓글을 받은 뒤 병합한다. 제품 관리자는 이나루이고, 프로젝트 관리자는 강도윤이다. 두 사람 모두 이번 결제 개편에 참여한다.

## 확인 필요

- 확인 필요: 배포 직후 20분 동안 수동 실행을 금지하는 대상. 원문의 "그거는"이 승인 재시도 작업, 알림 재전송 작업 중 무엇을 가리키는지, 또는 둘 다인지 알 수 없다.
- 확인 필요: 사전 검사 이름. 원문에는 "결제 무결성 검사"와 "페이체크"가 같은 사전 검사를 가리키는지 적혀 있지 않다.
