# PR #501: 구매 주문서 중복 저장 방지

이 PR은 구매 주문서가 중복 저장되는 문제를 막는다. 같은 주문 번호의 요청이 30초 안에 다시 들어와도 1건만 저장되어야 한다. 구매 요청 대시보드(팀 내 별칭 구매판)의 중복 요청 경고 문구도 이번 변경에 포함한다.

## 변경 범위

- 구매 주문서의 중복 저장을 막는다.
- 구매 요청 대시보드의 중복 요청 경고 문구를 바꾼다.

## 검토 자료

- 구매 주문서 예시 파일: order-sample.csv
- 승인 흐름 검토 기준 파일: approval-guide.pdf
- 승인 흐름 검토 담당: 제품 책임자 윤서린
- 개발 문의: 사내 메신저 #구매개발

## 병합 조건

- 병합 전에 PO 검토를 마쳐야 한다. 검토 결과는 PR 댓글에 첨부해야 한다.
- 코드 리뷰어 전원의 승인을 받아야 한다.
- 병합 직전에 해당 파일을 최신 버전으로 교체해야 한다.

## 검증 계획

| 환경 | 검증 시작(실행일) | 재전송 시험 |
|---|---|---|
| 서부 테스트 환경 | 11/12(목) 10:00 | 작성자 민도겸이 40건 재전송 |
| 동부 테스트 환경 | 11/13(금) 15:00 | 작성자 민도겸이 40건 재전송 |

1. 작성자 민도겸이 서부 테스트 환경에서 40건을 재전송한다.
2. 작성자 민도겸이 동부 테스트 환경에서 40건을 재전송한다.
3. 같은 주문 번호의 요청이 30초 안에 다시 와도 1건만 저장되는지 확인한다.

읽기 전용 계정은 재전송 시험에서 제외해야 한다. 운영 반영이 끝날 때까지 테스트 환경의 자동 초기화를 중지해야 한다.
