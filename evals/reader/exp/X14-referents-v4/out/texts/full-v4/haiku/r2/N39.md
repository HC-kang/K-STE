# PR #133: 게임 패치 재개 기능 (묶음 13, 세 번째 PR)

이 PR은 중단된 게임 패치를 이어받는 기능을 추가한다. 다운로드 중 연결이 끊기면 기존 방식은 처음부터 다시 받았는데, 이번 변경으로 중단된 지점부터 재개한다. 사용자에게 보이는 패치 복구 패널은 팀에서 '이어받기창'이라고 부른다. 개발 담당은 한루온이며, 리뷰는 게임 클라이언트 저장소에서 진행한다.

## 변경 내용

- 이어받기창에 남은 용량을 MB 단위로 표시한다.
- 예상 완료 시각은 이번 변경에 포함하지 않는다.
- 남은 공간이 500MB 미만이면 재개를 차단해야 한다.
- 개발 전용 계정은 공간 검사에서 제외한다.

## 검증 계획

- 모바일 실험실은 휴대전화에서 패치 재개를 검증한다. 담당은 정나겸이다.
- 콘솔 실험실은 거치형 기기에서 패치 재개를 검증한다. 담당은 유서안이며, 검증 결과를 PR #133에 댓글로 올린다.
- 검증 담당자는 12/02(수) 18:00까지 내부 시험 환경 '별무리-패치'에서 중단 후 재개를 20회 모두 성공시켜야 한다.
- 실패가 한 번이라도 나오면 병합하면 안 된다.
- 검증용 계정 8개를 실험실에 전달해야 한다. 계정 전달이 끝난 뒤에 리뷰를 시작해야 한다.
- 출시 후보 빌드는 12/01(화) 11:00에 시험 배포한다.

확인 필요: 검증 담당자. 가능한 해석은 정나겸(모바일 실험실 담당) 또는 유서안(콘솔 실험실 담당)이다.

## 첨부 문서

- 저장 공간 보고서: 유서안이 작성해 PR #133에 첨부한다.
