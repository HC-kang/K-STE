# 누리벡스 결제 라우터 R4 야간 전환 운영 절차

이 절차는 야간 결제 운영 담당자가 11/12(목) 결제 라우터 R4 전환 작업을 수행할 때 따르는 문서다. 전환은 외부 결제 중계 장비 교체로 기존 연결이 끊기는 상황에 대비하는 작업이며, 22:10부터 22:30까지 운영 콘솔 /route/r4에서 야간 담당 서루하가 실행한다. 전환 전에는 승인 대기 건수를 조회하고 PO 검토 결과를 운영 기록에 첨부해야 한다.

## 역할

| 역할 | 담당 | 할 일 |
|---|---|---|
| 야간 결제 운영 담당자 | 이 문서의 독자 | 결제판에서 승인 대기 건수를 조회한다. 결제판 조회 권한은 야간 결제 운영 담당자에게 부여한다. |
| 야간 담당 | 서루하 | 운영 콘솔 /route/r4에서 전환을 실행하고, 중단 시 이전 경로를 복원해야 한다. |
| 제품 책임자(Product Owner) | 도이안 | 전환 영향 검토서를 작성한다. |
| 구매 담당 | 고세림 | 외부 결제 중계 장비의 구매 주문서(Purchase Order)를 검토하고 주문 검토서를 작성한다. |
| 동문 관제실 | - | 전환 중 결제 응답 시간을 감시한다. |
| 서문 관제실 | - | 11/13(금) 00:10에 결제 라우터 R4의 로그를 대조한다. |
| 운영 담당 | 나해솔 | 작업 문의를 받는다. 내선 4816 |

결제판은 팀에서 새 결제 관제 화면을 부르는 이름이다.

| 11/12(목) 전환 직전 | 결제판에서 승인 대기 건수를 조회한다. | 실행 |

## 전환 전 준비

1. PO 검토 결과는 전환 전에 반드시 운영 기록에 첨부해야 한다. [확인 필요 1]
2. 결제판에서 전환 직전 승인 대기 건수를 조회한다. [확인 필요 3]
3. **결제판에 접속할 수 없으면 대기 건수를 추정하지 않고 전환을 보류해야 한다.**
4. 승인 대기 건수가 20건 이상이면 전환을 중단해야 한다.

## 전환 실행

5. 야간 담당 서루하가 22:10부터 22:30까지 운영 콘솔 /route/r4에서 결제 라우터 R4 전환을 실행한다.
6. **승인 대기 건수가 20건 미만이어도 결제 응답 시간이 3초를 넘으면 전환을 중단해야 한다.** 동문 관제실이 전환 중 결제 응답 시간을 감시한다.
7. 전환을 중단하면 서루하가 5분 이내에 이전 경로를 복원해야 한다.
8. 전환 완료 시각을 관제실에 반드시 알려야 한다. 알림은 운영 채널 #r4-night에 남겨야 한다. [확인 필요 4]

## 전환 후

9. 작업 종료 후 30분 이내에 전환 영향 검토서를 기록함 /night/close에 올려야 한다. [확인 필요 2]

## 문의

작업 문의는 운영 담당 나해솔에게 내선 4816으로 해야 한다. 나해솔은 11/12(목) 21:50부터 11/13(금) 00:30까지 문의를 받는다.

## 확인 필요 사항

- 확인 필요 1: PO 검토 결과. 제품 책임자(Product Owner) 검토 결과를 가리키는지, 구매 주문서(Purchase Order) 검토 결과를 가리키는지 원문에서 구분되지 않는다.
- 확인 필요 2: 기록함 /night/close에 올리는 담당. 야간 결제 운영 담당자가 올리는지, 작성자 도이안이 올리는지 원문에 없다.
- 확인 필요 3: 전환 직전 승인 대기 건수 조회. 조회를 맡는 사람과 정확한 조회 시각이 원문에 없다.
- 확인 필요 4: 관제실에 완료 시각을 알리는 담당. 알림을 맡는 사람이 원문에 없다.
