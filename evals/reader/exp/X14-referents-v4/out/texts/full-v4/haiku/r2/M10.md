# 누리펄스 캐시 전환 런북

이 런북은 2026년 11월 12일(목) 23:10부터 23:40까지 진행하는 누리펄스 검색 캐시와 추천 캐시 전환 작업의 절차를 정한다. 실행 담당은 야간 당직자 문세린이다. 전환 전후 오류율을 측정하고, 전환 후 오류율에 따라 복원 여부를 정한다. 전환 완료 보고서는 PM에게 전달해야 한다.

## 1. 작업 개요

- 작업 일시: 11/12(목) 23:10 시작, 23:40 종료
- 실행 담당: 야간 당직자 문세린
- 작업 대상: 검색 캐시, 추천 캐시
- 작업 위치: 사내 운영 포털의 검색 탭(검색 캐시), 추천 탭(추천 캐시)
- 대기: 제품 관리자 나도윤과 프로젝트 관리자 서이안은 작업 시간 동안 사내 메신저에서 대기해야 한다.
- 후속 점검: 11/13(금) 09:00

## 2. 배경

캐시 갱신이 지연되어 검색 결과가 누락되는 문제가 발생했다. 이 런북은 검색 캐시와 추천 캐시의 전환 절차를 정한다.

## 3. 사전 준비

1. 검색 캐시와 추천 캐시 각각의 전환 전 오류율을 5분간 측정하고, 측정 결과를 작업 기록에 남겨야 한다.
   확인 필요: 5분간 측정. 측정 시작 시각과 측정 방법이 원문에 없다.
2. 전환 직전에 스냅샷을 1개 추가로 저장해야 한다.
   확인 필요: 스냅샷 1개. 검색 캐시와 추천 캐시를 합쳐 1개인지, 캐시별로 1개씩인지 원문에 없다.
3. 검색 로그 서버와 추천 로그 서버의 상태를 운영 포털의 장비 탭에서 조회해야 한다.
   확인 필요: 장비 상태 조회 시점. 원문에 조회 시각이 없다.

## 4. 작업 절차

**경고: 서버 재시작은 문세린의 승인 후에만 해야 한다.**

복원 작업의 실행 화면은 정식 화면명 '복원 제어판' 1개만 사용해야 한다.

1. 23:10에 작업을 시작한다.
2. 23:20에 문세린이 복원 제어판에서 복원 지점 2개를 등록해야 한다.
3. 되돌림 데스크에 복원 지점 2개가 표시되는지 표시 개수를 대조해야 한다.
   확인 필요: 되돌림 데스크의 표시 개수가 2개가 아닐 때 할 일. 원문에 없다.
4. 전환 직전에 스냅샷을 저장한 뒤 검색 캐시와 추천 캐시를 전환해야 한다.
   확인 필요: 캐시 전환 실행 방법. 원문에 전환을 실행하는 화면이나 명령이 없다.
5. 전환 후 검색 캐시와 추천 캐시의 오류율을 측정해야 한다.
   확인 필요: 전환 후 오류율 측정 기간. 원문에 측정 기간이 없다.
6. 5절의 기준에 따라 복원 여부를 정해야 한다.
7. 23:40에 작업을 종료한다.

## 5. 전환 후 판정

| 전환 후 오류율 | 다음 행동 |
|---|---|
| 2% 초과 | 즉시 복원해야 한다 |
| 2% 이하 | 복원하지 않고 관찰을 유지해야 한다 |

확인 필요: 2% 기준의 적용 단위. 검색 캐시와 추천 캐시 각각에 적용하는지, 두 캐시를 합쳐 적용하는지 원문에 없다.

오류율 조회가 불가능하거나 복원이 실패하면 6절을 따라야 한다.

## 6. 비상 대응

오류율 조회가 불가능하거나 복원이 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.

## 7. 마무리

1. 작업 기록을 운영 포털의 야간 작업함에 저장해야 한다.
   확인 필요: 작업 기록 저장 조건. 모든 작업 후 저장하는지, 비상 상황에만 저장하는지 원문에 없다.
2. 전환 완료 보고서를 PM에게 전달해야 한다. 보고서를 전달하기 전에는 당직을 교대하면 안 된다.
   확인 필요: PM의 대상. 프로젝트 관리자 서이안을 가리키는지, 제품 관리자 나도윤을 가리키는지 원문에 없다.
3. 2026년 11월 13일(금) 09:00에 후속 점검을 해야 한다.
   확인 필요: 후속 점검 담당자. 원문에 없다.
