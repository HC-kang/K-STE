# 누리결패키징 포장 시험 회의록

11/12(목) 10:00-10:40에 본사 2층 회의실에서 누리결패키징 포장 시험 회의를 열었다. 윤다솔이 진행하였고 생산관리팀과 포장 품질검사 담당자가 참석하였다. 동관 시험실에서 진행한 낙하 시험은 시험실별 측정값에 차이가 있어 재시험을 하기로 결정하였다.

## 회의 개요

| 항목 | 내용 |
|---|---|
| 일시 | 11/12(목) 10:00-10:40 |
| 장소 | 본사 2층 회의실 |
| 진행 | 윤다솔 |
| 참석 | 생산관리팀, 포장 품질검사 담당자 |

## 담당자

| 담당 | 담당자 | 맡은 일 |
|---|---|---|
| 완충재 시험표 파일 | 민서후 | 동관 시험실 낙하 시험 결과 관리 |
| 봉합 시험표 파일 | 백이준 | 서관 시험실 밀봉 시험 결과 관리 |
| 출고 판정 대장(현장 별칭: 출고판) | 윤다솔 | 재시험 통과 수량 입력 |
| 품질 보증(QA) | 오해린 | 재시험 기준 검토 |
| 질의응답 기록 | 정나봄 | 회의 중 나온 작업자 질문과 답변 정리 |

## 논의 및 결정 사항

민서후가 맡은 완충재 시험은 동관 시험실에서 낙하 시험을 진행하였다. 시험실별 측정값에 차이가 있어 재시험을 하기로 결정하였다.

백이준이 맡은 봉합 시험은 서관 시험실에서 밀봉 시험을 진행한다. 봉합 시험 결과는 11/13(금) 12:00까지 취합한다.

11/13(금) 09:00부터 시험실에는 외부 방문객이 출입하면 안 된다. 직원은 출입해도 된다.

## 재시험 기준

재시험 표본은 포장재 종류별로 24개를 쓴다.

찢김이 1개 이상이면 해당 포장재 종류의 출고를 보류한다. 찢김이 0개이면 해당 포장재 종류는 출고할 수 있다.

자동 포장기용 포장재는 재시험을 해야 한다. 수작업 전용 포장재는 재시험에서 제외하며 기존 판정을 유지한다.

재시험 기준은 오해린이 검토한다. 재시험에 관한 문의는 오해린에게 사내 메신저 '포장품질 문의' 채널로 한다.

정나봄은 회의 중 나온 작업자 질문과 답변을 정리하여 별도 문서로 보관한다.

## 확인 필요

- 확인 필요: "그 파일". 최종본을 업로드할 파일이 원문에 지정되지 않았다.
- 확인 필요: 최종본 업로드(11/13(금) 15:00까지)와 QA 검토 결과 첨부(11/12(목) 17:00까지)의 담당자. 원문에 행위자가 없다.
- 확인 필요: 원본 시험표 보존 기간 30일의 기산일. 원문에 기준 시점이 없다.
- 확인 필요: 회의 일시(11/12(목))가 작성일(10/19)보다 뒤이다. 원문에 이 회의록이 회의 전에 작성된 것인지, 회의 후 확정된 내용인지 밝혀져 있지 않다.
