# 루미노트캐스트 투자설명회 송출 장애 대응 런북

이 런북은 11/19(목) 14:00-15:00 관제실에서 진행하는 루미노트캐스트 12차 송출 훈련에서 관제 근무자가 따를 장애 대응 절차를 정리한다. 훈련의 목적은 음성 인코더 전환 때 생기는 끊김에 대비하는 것이다. 투자자 관계 업무조는 발표자 안내를 맡고, 사고 대응 업무조는 장애 원인 기록을 맡는다. 대기 안내 화면은 우리 팀에서 대기막이라고 부른다.

## 역할

| 업무조 또는 담당 | 맡은 일 |
|---|---|
| 관제 근무자 | 음성 끊김 시간 측정, 대기막 켜기, 담당자에게 전화 알림 |
| 투자자 관계 업무조 | 발표자 안내 |
| 사고 대응 업무조 | 장애 원인 기록 |
| 송출 담당자 오해솔 | 14:10 연습 채널 열기 |
| 운영 담당자 배나린 | 14:20 검증 채널 열기 |

## 시간표

| 시각 | 할 일 |
|---|---|
| 14:00 | 훈련 시작 |
| 14:10 | 송출 담당자 오해솔이 연습 채널을 연다. |
| 14:20 | 운영 담당자 배나린이 검증 채널을 연다. |
| 14:50 | 확인 필요 항목 1의 채널을 닫는다. |
| 15:10까지(기한) | 전체 훈련 결과를 관제 기록함에 올린다. |

## 장애 대응 절차

1. 음성 끊김이 발생하면 끊김이 이어지는 시간을 잰다.
2. 음성 끊김이 5초 이상 이어지면 대기막을 켜야 한다.
3. 음성 끊김이 5초 미만이면 대기막을 켜지 않고 재생 상태만 기록한다.
4. 장애 요약을 IR에 전달한다. 확인 필요 항목 2를 참조한다.
5. 담당자에게 재개 버튼을 누르기 전에 전화로 알린다. 확인 필요 항목 3을 참조한다.

## 채널 운영 기준

연습 채널과 검증 채널은 음성 확인용으로만 쓴다. 외부 시청자를 연결하면 안 된다.

훈련 중 녹화 실패만 발생하면 송출 중단은 생략해도 된다.

문의는 관제 지원창구 내선 5632로 한다.

## 확인 필요

- 확인 필요: "그 채널은 14:50에 닫아 주세요". 연습 채널만 닫는지, 검증 채널만 닫는지, 두 채널을 모두 닫는지 원문으로는 정할 수 없다.
- 확인 필요: "장애 요약을 IR에 먼저 전달해 주세요". "먼저"가 대기막을 켜기 전을 뜻하는지, 장애 원인 기록이 끝난 뒤를 뜻하는지 원문으로는 정할 수 없다.
- 확인 필요: "담당자에게 재개 버튼을 누르기 전에 전화로 알려 주세요". 송출 담당자 오해솔을 가리키는지, 다른 담당자를 가리키는지 원문으로는 정할 수 없다.
