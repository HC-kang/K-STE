# PR #501: 구매 주문서 중복 저장 방지

다온상사 구매 플랫폼에서 구매 주문서가 중복 저장되지 않게 하는 변경이다. 구매 요청 대시보드(팀 내 별칭 구매판)의 중복 요청 경고 문구도 이번 변경에 포함한다. 운영 반영 예정은 11/16(월) 09:00이다.

## 검증 기준

주문 번호가 같은 요청은 30초 안에 다시 와도 1건만 저장돼야 한다. 작성자 민도겸이 서부 테스트 환경과 동부 테스트 환경에서 각각 40건을 재전송해 이 기준을 검증한다. 읽기 전용 계정은 재전송 시험에서 제외한다.

## 검증 일정

- 서부 테스트 환경: 11/12(목) 10:00에 검증을 시작한다.
- 동부 테스트 환경: 11/13(금) 15:00에 검증을 시작한다.

## 병합 조건

- 코드 리뷰어 전원이 승인해야 한다.
- 병합 전에 PO 검토를 마쳐야 한다. 검토 완료 기록은 PR 댓글에 첨부해야 한다.
- 그 파일은 병합 직전에 최신 버전으로 교체해야 한다.
- 테스트 환경의 자동 초기화는 운영 반영이 끝날 때까지 중지해야 한다.
