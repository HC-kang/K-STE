# PR #501 구매 주문서 중복 저장 방지

다온상사 구매 플랫폼에서 구매 주문서가 중복 저장되지 않게 하는 변경이다. 구매 요청 대시보드(팀 내 별칭 구매판)의 중복 요청 경고 문구도 이번 변경에 포함된다. 구매 주문서 예시 파일은 order-sample.csv이다.

## 검증

작성자 민도겸이 서부 테스트 환경과 동부 테스트 환경에서 각각 40건을 재전송한다. 주문 번호가 같은 요청은 30초 안에 다시 와도 1건만 저장되어야 한다. 읽기 전용 계정은 재전송 시험에서 제외해야 한다. 테스트 환경의 자동 초기화는 운영 반영 종료까지 중지해야 한다.
