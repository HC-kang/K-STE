# 누리펄스 캐시 전환 런북 (운영 절차 묶음 4)

이 문서는 누리펄스 야간 서비스 운영 당직자가 캐시 전환 작업을 할 때 따르는 런북이다. 작업은 11/12(목) 23:10에 시작한다. 작업 대상은 검색 캐시와 추천 캐시이다. 캐시 갱신 지연으로 검색 결과 누락이 발생했다.

## 작업 개요

- 작업 시간: 11/12(목) 23:10 시작, 23:40 종료
- 실행 담당: 야간 당직자 문세린
- 작업 대상: 검색 캐시, 추천 캐시
- 작업 위치: 사내 운영 포털의 검색 탭과 추천 탭 각각
- 후속 점검: 11/13(금) 09:00
- 작업 기록 저장 위치: 운영 포털의 야간 작업함

## 운영 조건

- 제품 관리자 나도윤과 프로젝트 관리자 서이안은 작업 시간 동안 모두 사내 메신저에서 대기해야 한다.
- 검색 로그 서버와 추천 로그 서버는 별도 장비이다. 두 서버 상태는 운영 포털의 장비 탭에서 조회할 수 있다.
- 서버 재시작은 문세린의 승인을 받은 뒤에만 해야 한다.
- 캐시 복원 작업의 실행 화면은 복원 제어판 1개만 사용해야 한다.

## 복원 지점 등록과 대조

1. 문세린이 23:20에 복원 제어판에 복원 지점 2개를 등록한다.
2. 복원 제어판에 표시된 복원 지점 개수를 대조한다. 복원 제어판에는 문세린이 23:20에 등록한 복원 지점 2개가 보여야 한다.

## 전환 절차

1. 검색 캐시와 추천 캐시 모두 전환 전 오류율을 5분간 측정해 작업 기록에 남긴다.
2. 전환 직전에 스냅샷 1개를 추가로 저장한다.
3. 사내 운영 포털의 검색 탭과 추천 탭 각각에서 캐시를 전환한다.
4. 전환 후 오류율을 조회한다.

## 전환 후 판정

| 전환 후 오류율 | 할 일 |
|---|---|
| 2% 초과 | 즉시 복원해야 한다. |
| 2% 이하 | 복원하지 않고 관찰을 유지해야 한다. |

## 보고, 연락, 기록

- 전환 완료 보고서는 PM에게 전달해야 한다. 전달 전에는 당직 교대를 하면 안 된다.
- 오류율을 조회할 수 없거나 복원이 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.
- 작업 기록은 운영 포털의 야간 작업함에 저장해야 한다.

확인 필요: 그건 전환 직전 스냅샷 1개 추가 저장 필수. 검색 캐시와 추천 캐시 각각에 스냅샷 1개씩을 저장하는지, 두 캐시를 합쳐 스냅샷 1개를 저장하는지 알 수 없다.

확인 필요: 전환 후 오류율이 2% 초과면 즉시 복원 필수. 검색 캐시와 추천 캐시 각각의 오류율에 2% 기준을 적용하는지, 두 캐시를 하나로 묶은 오류율에 적용하는지 알 수 없다.
