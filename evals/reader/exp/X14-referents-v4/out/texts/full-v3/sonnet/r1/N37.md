# 묶음 13 PR #131: 구매 주문서 중복 생성 차단

묶음 13의 첫 번째 PR이다. 재전송 때문에 주문이 두 번 생긴 것이 원인이며, 동일 주문 키가 30초 안에 다시 들어오면 구매 주문서 생성을 차단한다. 구매 주문서를 번호로 조회하는 새 화면 주문돋보기도 추가한다. 윤해솔이 개발했고, 11/12(목) 14:00에 구매 서비스 저장소 PR #131에서 리뷰를 시작한다.

## 변경 내용

- 동일 주문 키가 30초 안에 다시 들어오면 생성을 차단해야 한다.
- 수동 복구 계정은 예외로 통과시켜야 한다.
- 새 화면의 정식 이름은 주문 중복 검사 화면이며, 팀에서는 주문돋보기라고 부른다. 구매 주문서는 이 화면에서 번호로 조회한다.
- 이번 PR에서 주문돋보기는 조회만 제공한다. 주문 취소 버튼은 넣지 않는다.
- 실패 기록은 재시도 로그 파일에, 처리 시간은 응답 측정 파일에 남긴다. 두 파일은 PR #131 첨부 탭에 있다.

## 담당

- 개발: 윤해솔
- 요구사항 승인: 제품 책임자 서도윤
- 실제 주문 형식 재현: 동부 검증실
- 대량 요청 재현: 서부 검증실
- 문의: 구매개발 채널의 윤해솔
