# 별담미디어 생방송 리허설 운영 절차

11/19(목) 14:00에 시작하는 생방송 리허설을 송출 기술 담당자가 실행하는 절차다. 새 자막 모듈의 화면 겹침을 잡기 위한 리허설이다. 송출 담당 은도하가 통합 송출석에서 실행한다.

## 담당

| 담당 | 이름 | 역할 |
|---|---|---|
| 송출 담당 | 은도하 | 통합 송출석에서 리허설 실행 |
| 개발 담당 | 윤세빈 | 송출 제어 프로그램의 출시 후보판(Release Candidate) 준비 |
| 장비 담당 | 진하람 | 원격 조종기(Remote Control) 배터리 교체 |
| 기술 지원 담당 | 류모아 | 절차 문의 응대, 내선 6932 |
| 달빛 스튜디오 | - | 발표자 영상 제공 |
| 별숲 스튜디오 | - | 제품 시연 영상 제공 |

방송 상태 대시보드는 현장에서 온에어판이라고 부른다. 이 문서에서는 방송 상태 대시보드로 쓴다.

## 리허설 전 준비

1. 출시 후보판을 시험 단말 T6에 설치한다.
2. 진하람이 통합 송출석에 둔 원격 조종기의 배터리를 교체한다. 배터리 잔량이 40퍼센트 미만이면 교체가 필수다.
3. RC 점검 결과를 리허설 시작 전에 점검표에 반드시 남겨야 한다.
4. 리허설 시작 10분 전까지 스튜디오에 점검 완료를 통보해야 한다. 통보는 송출 채널 #live-gate에 남긴다.

## 일정

11/19(목)에 아래 시각에 시작한다.

| 시각(시작) | 내용 | 비고 |
|---|---|---|
| 14:00 | 생방송 리허설 시작 | 달빛 스튜디오가 발표자 영상을 제공한다. |
| 14:20 | 주 회선 시험 | 별숲 스튜디오가 제품 시연 영상을 제공한다. |
| 14:40 | 예비 회선 시험 | |

## 리허설 중 규칙

- 전송 지연이 800밀리초를 넘으면 은도하가 즉시 예비 회선으로 바꿔야 한다.
- 전환 후에도 지연이 800밀리초를 넘는 상태가 15초간 이어지면 리허설을 중단해야 한다.
- 녹화 전용 세션은 회선 전환 대상에서 제외해야 한다.
- 방송 상태 대시보드의 경고 내역은 통합 송출석에서 조회한다.

## 리허설 종료 후

1. 은도하가 방송 상태 대시보드의 경고 내역을 리허설 종료 후 10분 이내에 기록함 /live/check로 내보낸다.

## 문의

절차 문의는 기술 지원 담당 류모아에게 한다. 내선은 6932다.

확인 필요: "그때는 은도하와 진하람이 통합 송출석에 함께 있어야 한다." 14:40 예비 회선 시험 때를 뜻하는지, 회선 전환이나 리허설 중단이 일어나는 때를 뜻하는지 알 수 없다.
확인 필요: "RC 점검 결과". RC가 출시 후보판(Release Candidate)인지, 원격 조종기(Remote Control)인지 알 수 없다.
확인 필요: "스튜디오에 점검 완료를 통보한다". 통보 대상이 달빛 스튜디오와 별숲 스튜디오 모두인지, 어느 한쪽인지 알 수 없다.
