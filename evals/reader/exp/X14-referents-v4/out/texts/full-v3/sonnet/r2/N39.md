# PR #133: 게임 패치 재개 기능

이 PR은 묶음 13의 세 번째 PR이며, 게임 패치 재개 기능을 다룬다. 다운로드 중 연결이 끊기면 처음부터 다시 받던 동작이 수정 원인이다. 개발 담당은 한루온이고, 게임 클라이언트 저장소에서 리뷰한다.

## 변경 내용

- 정식 명칭은 패치 복구 패널이고, 팀에서는 이어받기창이라고 부른다.
- 이어받기창은 남은 용량을 MB 단위로 보여 준다.
- 예상 완료 시각은 이번 변경에 포함하지 않는다.
- 남은 공간이 500MB 미만이면 재개를 차단해야 한다.
- 개발 전용 계정은 공간 검사에서 제외한다.

## 병합 조건

- RC 검토 기록을 병합 전에 PR #133의 출시 검토 칸에 연결해야 한다. 기록 연결은 필수다.
- 검증 담당자는 12/02(수) 18:00까지 내부 시험 환경 '별무리-패치'에서 중단 후 재개 20회를 전부 성공시켜야 한다.
- **중단 후 재개에서 실패가 한 번이라도 나오면 병합하면 안 된다.**

## 검증

- 모바일 실험실은 휴대전화에서 패치 재개를 검증한다. 담당은 정나겸이다.
- 콘솔 실험실은 거치형 기기에서 패치 재개를 검증한다. 담당은 유서안이며, 검증 결과를 PR #133에 댓글로 올려야 한다.
- 실험실에 검증용 계정 8개를 전달해야 한다. 계정 전달이 끝나야 리뷰를 시작한다.
- 정나겸이 '중단 재현 보고서'를 작성해 PR #133에 첨부한다.
- 유서안이 '저장 공간 보고서'를 작성해 PR #133에 첨부한다.
