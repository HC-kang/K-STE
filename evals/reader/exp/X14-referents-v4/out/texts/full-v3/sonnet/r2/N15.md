# 모래빛교육 인사 서비스 PR #503: 오리엔테이션 참석 시간 중복 합산 수정

PR #503은 오리엔테이션 참석 시간이 두 번 합산되는 오류를 수정했다. 참석 기록은 입문 연동 모듈이 받는다. 릴리스 승인자는 회귀 시험 18건이 모두 통과한 뒤 병합을 승인해야 한다. 운영 배포는 11/23(월) 08:00에 시작한다.

## 변경 내용

중복 여부는 직원 번호와 기록 식별자가 모두 같은지로 판단한다. 중복 처리 규칙은 다음과 같다.

- 같은 기록이 60초 안에 재수신되면 최초 기록 1건만 합산한다.
- 수동 보정 기록은 중복 제거 대상에서 제외한다.

시간 집계 검토 화면(현업 명칭: 시간판)에는 중복으로 제외한 기록의 개수를 표시한다.

## 회귀 시험

초과 근무 시간도 이번 회귀 시험에 포함한다. 근무 연동 모듈은 근무 기록을 받는다. 담당 개발자는 차은재다.

## 병합 조건

- 릴리스 승인자는 회귀 시험 18건이 모두 통과한 뒤 병합을 승인해야 한다.
- 회귀 시험 일부만 통과한 상태에서 승인하면 안 된다.
- OT 집계 결과는 병합 전에 인사 운영 담당자의 승인을 받아야 한다.

## 검증 일정

두 검증은 모두 연습 공간에서 하고, 각각 45분 진행한다.

- 11/19(목) 10:00: 차은재가 집계 결과를 검증한다.
- 11/20(금) 16:00: 문해솔이 권한 설정을 검증한다.

그때는 외부 참관자의 연습 공간 접속을 막아야 한다.

## 배포

- 연동 모듈의 재시도 기능은 배포 중 반드시 꺼야 한다.
- 배포 담당자는 배포 시작부터 20분 동안 오류율을 관찰해야 한다.

배포 문의는 사내 메신저 #인사배포의 문해솔이 받는다.

확인 필요: OT 집계 결과. OT가 오리엔테이션 집계 결과인지, 초과 근무 집계 결과인지.
확인 필요: 그때. 11/20(금) 권한 설정 검증 때만인지, 11/19(목) 집계 결과 검증과 11/20(금) 권한 설정 검증 때 모두인지.
확인 필요: 연동 모듈의 재시도 기능. 입문 연동 모듈의 재시도 기능인지, 근무 연동 모듈의 재시도 기능인지, 또는 두 모듈 모두의 재시도 기능인지.
