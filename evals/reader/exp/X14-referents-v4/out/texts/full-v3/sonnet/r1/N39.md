# PR #133: 게임 패치 재개 기능 (묶음 13)

이 PR은 별무리게임즈 게임 클라이언트의 패치 재개 기능을 다룬다. 개발 담당은 한루온이고, 리뷰는 게임 클라이언트 저장소에서 한다. 이 글에서 '이어받기창'은 정식 명칭이 '패치 복구 패널'인 화면이다.

## 변경 내용

- 이어받기창은 남은 용량을 MB 단위로 보여 준다.
- 이번 변경에는 예상 완료 시각을 포함하지 않는다.
- 남은 공간이 500MB 미만이면 재개를 차단해야 한다.
- 개발 전용 계정은 공간 검사에서 제외해야 한다.

## 수정 원인

다운로드 중 연결이 끊기면 처음부터 다시 받던 동작이 수정 원인이다.

## 병합 전 조건

1. 리뷰는 모바일 실험실에 검증용 계정 8개를 전달한 뒤에 시작해야 한다.
2. 병합 전에 RC 검토 기록을 PR #133의 출시 검토 칸에 연결해야 한다. 이 연결은 필수다.
3. 검증 담당자는 12/02(수) 18:00까지 내부 시험 환경 '별무리-패치'에서 중단 후 재개 20회를 전부 성공시켜야 한다.
4. 20회 중 실패가 한 번이라도 나오면 PR #133을 병합하면 안 된다.

## 검증 담당과 보고서

- 모바일 실험실: 휴대전화에서 패치 재개를 검증한다. 담당은 정나겸이다.
- 콘솔 실험실: 거치형 기기에서 패치 재개를 검증한다. 담당은 유서안이다. 검증 결과는 PR #133에 댓글로 올려야 한다.
- 중단 재현 보고서: 정나겸이 작성해 PR #133에 첨부한다.
- 저장 공간 보고서: 유서안이 작성해 PR #133에 첨부한다.

## 일정

- 12/01(화) 11:00: 출시 후보 빌드를 시험 배포한다.
- 12/02(수) 18:00까지: 중단 후 재개 20회 검증을 끝내야 한다.
- 12/03(목) 14:00: 출시 위원회가 열린다. 의장은 배시온이고, 위원회가 정식 배포 여부를 심의한다.
- 12/04(금) 10:00: 한루온이 정식 배포를 진행한다.

앞서 올린 문서는 출시 위원회 시작 1시간 전까지 배시온에게도 보내야 한다. 이 전달은 필수다.

## 배포 후 기록

정식 배포 후 첫 30분 동안 다운로드 실패율을 5분마다 기록해야 한다.

## 문의

기능 문의는 클라이언트개발 채널의 한루온에게 한다.
