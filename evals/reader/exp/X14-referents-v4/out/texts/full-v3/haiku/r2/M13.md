# 결제 재시도 PR: 중복 승인 요청으로 인한 결제 알림 중복 발송 수정

문서 식별자: 묶음 5-1
담당 개발자: 서다온
배포 담당: 문해솔
참여: 제품 관리자 이나루, 프로젝트 관리자 강도윤

이 PR은 중복 승인 요청 때문에 고객 결제 알림이 두 번 발송되는 문제를 수정한다. 변경 대상은 승인 재시도 작업과 알림 재전송 작업이며, 두 작업은 모두 결제 운영 콘솔에서 실행된다.

## 변경 내용

- 승인 재시도 작업은 재시도 간격 30초, 최대 3회로 실행된다.
- 알림 재전송 작업은 재시도 간격 60초, 최대 2회로 실행된다.
- 주문 DB에 조회 인덱스를 추가한다.
- 정산 DB에 조회 인덱스를 추가한다.
- 기존 컬럼은 삭제하지 않는다.

## 일정

- 검토는 11/11(수) 17:00까지 마쳐야 한다.
- 사전 검사는 11/12(목) 13:30에 서다온이 실행한다.
- 배포는 11/12(목) 14:00에 문해솔이 실행한다.

## 배포 절차

1. 배포 전에 DB 스냅샷을 보관해야 한다.
2. 11/12(목) 13:30에 서다온이 결제 무결성 검사로 표본 240건을 대조한다.
3. 사전 검사가 실패하면 배포를 중단해야 한다.
4. 11/12(목) 14:00에 배포한다.

## 검토 기준

- 배포 검토자는 재시도 테스트 통과 기록을 첨부해야 한다.
- 내부 시험 상점은 테스트 대상에서 제외된다.
- 문의는 #결제-변경 채널로 한다.
- 병합은 PM 승인 댓글을 받은 뒤에 해야 한다.

## 확인 필요

- 확인 필요: '그거는 배포 직후 20분 동안 수동 실행 금지'. 해석 1: 승인 재시도 작업을 가리킨다. 해석 2: 알림 재전송 작업을 가리킨다.
- 확인 필요: '페이체크'. 해석 1: 결제 무결성 검사와 같은 사전 검사이다. 해석 2: 결제 무결성 검사와 별도인 사전 검사이다.
