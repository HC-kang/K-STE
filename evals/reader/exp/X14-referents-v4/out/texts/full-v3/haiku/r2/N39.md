# 게임 패치 재개 기능 추가 (PR #133)

이 PR은 게임 패치 다운로드를 중단 후 이어서 받도록 한다. 다운로드 중 연결이 끊기면 파일을 처음부터 다시 받던 동작을 고치는 것이 목적이다. 패치 복구 패널(팀에서는 '이어받기창'이라고 부른다)에는 남은 용량을 MB 단위로 표시한다. 현재 병합 전 상태이며, 출시 후보(RC) 빌드를 12/01(화) 11:00에 시험 배포한다.

## 변경 내용

- 패치 복구 패널에 남은 용량을 MB 단위로 표시한다.
- 예상 완료 시각은 이번 변경에 포함하지 않는다.
- 다운로드 중 연결이 끊기면 파일을 처음부터 다시 받던 문제를 수정한다. 이번 수정의 원인은 이 동작이다.
- 남은 저장 공간이 500MB 미만이면 재개를 차단해야 한다.
- 개발 전용 계정은 저장 공간 검사에서 제외된다.

## 검증 계획

| 실험실 | 기기 | 담당 | 결과 보고 |
|---|---|---|---|
| 모바일 실험실 | 휴대전화 | 정나겸 | PR #133에 첨부 |
| 콘솔 실험실 | 거치형 기기 | 유서안 | PR #133에 댓글 |

- 검증용 계정 8개를 실험실에 전달해야 한다. 계정 전달이 끝나야 리뷰를 시작한다.
- 중단 후 재개 20회를 전부 성공해야 한다. 시험 장소는 내부 시험 환경 '별무리-패치'다.
- **실패가 한 번이라도 나오면 병합하면 안 된다.**
- 중단 재현 보고서는 정나겸이 작성해 PR #133에 첨부한다.
- 저장 공간 보고서는 유서안이 작성해 PR #133에 첨부한다.

## 담당과 문의

- 개발 및 정식 배포 진행: 한루온
- 기능 문의: 클라이언트개발 채널의 한루온
- 모바일 실험실: 정나겸
- 콘솔 실험실: 유서안
- 출시 위원회 의장: 배시온

## 리뷰와 병합 조건

- 리뷰는 게임 클라이언트 저장소에서 진행한다.
- 병합 전에 RC 검토 기록을 PR #133의 출시 검토 칸에 연결해야 한다. 이 연결은 필수다.

## 확인 필요

- 확인 필요: 20회 재개 검증의 "검증 담당자". 원문은 담당자를 특정하지 않는다. 모바일과 콘솔 실험실 담당자 모두를 뜻하는지, 한 사람을 뜻하는지 밝혀져 있지 않다.
- 확인 필요: 20회 재개 검증의 시험 장소 '별무리-패치'. 원문은 어느 실험실 기기에서 수행하는지 밝히지 않는다.
- 확인 필요: 검증용 계정 전달 기한. 원문에 날짜가 없다.
- 확인 필요: 배포 후 첫 30분 동안 실패율을 기록할 담당자. 원문에 지정되어 있지 않다.
- 확인 필요: "앞서 올린 문서"의 구체적인 목록. 원문에 문서 이름이 없다.
