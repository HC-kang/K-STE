# 누리펄스 캐시 전환 런북 (운영 절차 묶음 4)

이 런북은 2026년 11월 12일(목) 23:10부터 23:40까지 진행하는 검색 캐시와 추천 캐시의 전환 작업 절차를 정한다. 실행 담당은 야간 당직자 문세린이다. 캐시 갱신이 지연되면 검색 결과 누락이 발생하므로, 전환 전후 오류율을 측정하고 그 결과에 따라 복원 여부를 정한다.

## 1. 작업 정보

- 작업 시간: 2026년 11월 12일(목) 23:10 시작, 23:40 종료
- 실행 담당: 야간 당직자 문세린
- 작업 대상: 검색 캐시, 추천 캐시
- 작업 위치: 사내 운영 포털의 검색 탭과 추천 탭
- 메신저 대기: 제품 관리자 나도윤, 프로젝트 관리자 서이안 (작업 시간 동안 사내 메신저 대기)
- 긴급 연락: 플랫폼지원팀 윤하민, 내선 4726
- 작업 기록 저장: 운영 포털의 야간 작업함
- 후속 점검 시각: 2026년 11월 13일(금) 09:00

## 2. 작업 전 준비

1. 운영 포털의 장비 탭에서 검색 로그 서버와 추천 로그 서버의 상태를 각각 조회해야 한다. 두 서버는 별도 장비이므로 따로 조회해야 한다.
2. 검색 캐시와 추천 캐시의 전환 전 오류율을 각각 5분간 측정하고, 측정 결과를 작업 기록에 남긴다.
3. 전환 직전에 스냅샷을 1개 추가로 저장해야 한다.

## 3. 작업 중 (23:10부터 23:40까지)

4. 23:10에 검색 캐시와 추천 캐시의 전환 작업을 시작한다.
5. 23:20에 문세린이 복원 제어판에서 복원 지점 2개를 등록한다.
6. 되돌림 데스크에 복원 지점 2개가 보여야 한다. 표시 개수를 대조해야 한다.
7. 서버 재시작은 문세린의 승인을 받은 뒤에만 진행한다.
8. 캐시 복원 작업은 복원 제어판 1개 화면에서만 실행한다. 다른 화면에서 캐시 복원 작업을 실행하면 안 된다.

## 4. 전환 후 판단

9. 검색 캐시와 추천 캐시의 전환 후 오류율을 측정한다.
10. 전환 후 오류율이 2%를 초과하면 복원 제어판에서 즉시 복원해야 한다.
11. 전환 후 오류율이 2% 이하이면 복원하지 않고 관찰을 유지한다.
12. 복원이 실패하거나 오류율을 조회할 수 없으면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락한다.

## 5. 작업 종료

13. 작업 기록을 운영 포털의 야간 작업함에 저장한다.
14. 전환 완료 보고서를 PM에게 전달하기 전에는 당직을 교대하면 안 된다.
15. 전환 완료 보고서를 PM에게 전달한다.

## 확인 필요

- 확인 필요: 전환 전 오류율을 5분간 측정(2번 단계). 측정을 시작하는 시각이 원문에 정해져 있지 않다.
- 확인 필요: 전환 후 오류율을 측정(9번 단계). 측정을 시작하는 시각과 측정 기간이 원문에 정해져 있지 않다.
- 확인 필요: PM(14번, 15번 단계). 가능한 해석은 프로젝트 관리자 서이안 또는 제품 관리자 나도윤이다.
