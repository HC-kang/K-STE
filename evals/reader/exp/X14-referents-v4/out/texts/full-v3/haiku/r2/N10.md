# 결제 라우터 R4 전환 야간 운영 런북 (11/12 목)

11/12(목) 22:10부터 22:30까지 운영 콘솔 /route/r4에서 결제 라우터 R4를 전환한다. 전환은 야간 담당 서루하가 실행한다. 전환 전 승인 대기 건수와 전환 중 응답 시간을 기준으로 중단 여부를 판단한다. 이 런북은 야간 결제 운영 담당자가 따른다.

## 1. 역할과 연락처

| 역할 | 담당 | 내용 |
|---|---|---|
| 야간 결제 운영 담당자 | 본 런북의 독자 | 결제판에서 승인 대기 건수를 조회하고 절차를 따른다 |
| 야간 담당 | 서루하 | 전환을 실행하고, 중단 시 이전 경로를 복원한다 |
| 제품 책임자(Product Owner) | 도이안 | 전환 영향 검토서를 작성한다 |
| 구매 담당 | 고세림 | 외부 결제 중계 장비의 구매 주문서(Purchase Order)를 검토하고 주문 검토서를 작성한다 |
| 동문 관제실 | 관제실 | 전환 중 결제 응답 시간을 감시한다 |
| 서문 관제실 | 관제실 | 11/13(금) 00:10에 결제 라우터 R4의 로그를 대조한다 |
| 운영 담당 | 나해솔, 내선 4816 | 11/12(목) 21:50부터 11/13(금) 00:30까지 작업 문의를 받는다 |

## 2. 사전 준비

1. 제품 책임자 도이안의 전환 영향 검토서와 구매 담당 고세림의 주문 검토서를 준비한다.
2. PO 검토 결과를 전환 전에 운영 기록에 첨부해야 한다.
3. 결제판의 조회 권한은 야간 결제 운영 담당자에게 부여한다. 권한이 없으면 전환 전에 운영 담당 나해솔에게 내선 4816으로 문의해야 한다.

## 3. 전환 직전 점검

1. 전환 직전에 결제판에서 승인 대기 건수를 조회한다.
2. 승인 대기 건수가 20건 이상이면 전환을 중단한다.
3. 승인 대기 건수가 20건 미만이면 4단계로 넘어간다.
4. 결제판에 접속할 수 없으면 대기 건수를 추정하지 않는다. 전환을 보류한다.

**결제판에 접속할 수 없을 때는 대기 건수를 추정하면 안 된다. 반드시 전환을 보류해야 한다.**

## 4. 전환 실행 (22:10-22:30)

1. 22:10에 운영 콘솔 /route/r4에 접속한다.
2. 야간 담당 서루하가 결제 라우터 R4를 전환한다. 이 작업은 중계 장비 교체로 기존 연결이 끊기는 상황에 대비하는 작업이다.
3. 동문 관제실이 전환 중 결제 응답 시간을 감시한다.
4. 응답 시간이 3초를 넘으면 승인 대기 건수가 20건 미만이어도 전환을 중단한다.
5. 전환이 끝나면 완료 시각을 관제실에 알린다.

## 5. 전환 중단 시 복원

1. 전환을 중단하면 서루하가 5분 이내에 이전 경로를 복원한다.
2. 중단 건도 11/13(금) 00:10 로그 대조 대상에 포함한다.

## 6. 작업 후 기록

1. 작업이 끝나면 전환 영향 검토서를 작업 종료 후 30분 이내에 기록함 /night/close에 올린다.
2. 완료 시각을 운영 채널 #r4-night에 남긴다.

## 7. 익일 대조

서문 관제실은 11/13(금) 00:10에 결제 라우터 R4의 로그를 대조한다. 전환 중단 건도 대조 대상이다.

## 8. 문의

작업 중 문의는 운영 담당 나해솔에게 내선 4816으로 한다. 나해솔은 11/12(목) 21:50부터 11/13(금) 00:30까지 문의를 받는다.
