# 누비결제 승인 데이터베이스 야간 전환 런북

이 문서는 누비결제 승인 데이터베이스를 야간에 전환할 때 당직 엔지니어가 따르는 절차를 정한다. 작업 책임자는 서린우이고, 중단 결정권자는 배도현이다. 승인주 서버는 11/12(목) 02:00에, 승인보조 서버는 11/13(금) 03:00에 전환을 시작한다.

## 담당자

| 역할 | 담당자 |
|---|---|
| 작업 책임자 | 서린우 |
| 중단 결정권자 | 배도현 |
| 승인주 서버 담당자 | 서린우 |
| 승인보조 서버 담당자 | 문해솔 |
| 전환 계획 등록 | 문해솔 |
| 전환 계획 승인 | 배도현 |
| 1단계 원본스냅 생성 | 서린우 |
| 4단계 검증스냅 생성 | 하유담 |
| 일반 가맹점 대기열 | 문해솔 |
| 긴급 가맹점 우회망 | 하유담 |
| 완료 보고 작성 | 서린우 |

## 일정

전환 실행일과 시작 시각은 다음과 같다.

| 전환 대상 | 실행일 | 시작 시각 |
|---|---|---|
| 승인주 서버 | 11/12(목) | 02:00 |
| 승인보조 서버 | 11/13(금) | 03:00 |

사전 준비와 보고의 기한은 다음과 같다.

| 할 일 | 기한 |
|---|---|
| 전환 계획 등록 | 11/10(화) 17:00까지 |
| 전환 계획 승인 | 11/11(수) 15:00까지 |
| 완료 보고 | 11/13(금) 10:00까지 |

## 사전 준비

1. 문해솔이 11/10(화) 17:00까지 변경장부의 승인DB 항목에 전환 계획을 등록해야 한다.
2. 배도현이 11/11(수) 15:00까지 전환 계획을 승인해야 한다.
3. 작업을 시작하기 전에 긴급 가맹점을 긴급명부에 등록해야 한다. 작업 시작 전에 긴급명부에 등록이 끝난 가맹점이 긴급 가맹점이다.

## 전환 중 가맹점 승인 요청

일반 가맹점의 승인 요청은 전환 중 대기열에 최대 6분 보관해야 한다. 담당자는 문해솔이다.

긴급 가맹점의 승인 요청은 전환 중 대기열에 보관하지 않고 우회망으로 즉시 전송해야 한다. 담당자는 하유담이다.

## 전환 절차

1. 쓰기를 차단하기 직전에 서린우가 원본스냅을 생성한다. 원본스냅의 보관 기간은 72시간이다.
2. 쓰기를 차단하기 전에 감시판에서 진행 중 거래 수가 0건인지 확인한다.
3. 배도현의 승인 기록을 확인한 뒤 전환 명령을 실행한다.
4. 시험 승인 24건이 성공한 뒤 하유담이 검증스냅을 생성한다. 검증스냅의 보관 기간은 12시간이다.

## 중단 기준

전환 중 다음 상태가 지속되면 중단을 요청해야 한다.

- 승인 오류율이 2%를 초과한 상태가 3분 연속 지속된다.
- 복제 지연이 서버별 허용 상한을 초과한 상태가 2분 연속 지속된다.

복제 지연의 서버별 허용 상한은 다음과 같다.

| 서버 | 복제 지연 허용 상한 |
|---|---|
| 승인주 서버 | 4초 |
| 승인보조 서버 | 9초 |

중단 요청은 운영메신저의 야간전환 방에 접수한다. 중단 여부는 배도현이 결정한다.

## 원복

전환 후 원복이 필요하면 1단계 원본스냅을 복원 원본으로 쓴다.

원복이 끝난 뒤 시험 승인 8건이 전부 성공하기 전에는 쓰기 차단을 해제하면 안 된다.

## 완료 보고

서린우가 11/13(금) 10:00까지 완료 보고를 작성해야 한다. 오류율 그래프와 승인 응답 기록을 첨부해야 한다.

감사에 제출하는 대조 자료는 4단계 검증스냅이다.

## 스냅 삭제

원본스냅과 검증스냅은 보관 기간이 만료된 뒤 배도현의 승인을 받아야 삭제할 수 있다.

확인 필요: 1-4단계는 승인주 서버 전환과 승인보조 서버 전환에 각각 한 번씩 하는지, 두 전환 전체에 한 번만 하는지.
