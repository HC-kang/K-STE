# 모래빛방송 연말 생방송 송출 장애 대응 런북

이 문서는 모래빛방송 연말 생방송에서 송출 장애가 생겼을 때 송출 감독이 따르는 대응 절차를 정리한다. 장애 대응 총괄 담당자는 차서온이고, 편성 승인 담당자는 유다겸이다.

## 담당자

| 역할 | 담당자 |
|---|---|
| 장애 대응 총괄 | 차서온 |
| 편성 승인 | 유다겸 |
| 송출본선 점검 | 차서온 |
| 송출복선 점검 | 남이준 |
| 대체 편성안 제출 | 남이준 |
| 대체 편성안 승인 | 유다겸 |
| 일반 프로그램 대체 영상 전환 | 남이준 |
| 긴급 안내 프로그램 대체 음성 전환 | 차서온 |
| 1단계 장애클립 저장 | 백해린 |
| 4단계 복귀클립 저장 | 남이준 |
| 비상 안내 파일 재생 | 백해린 |
| 장애 보고서 작성 | 차서온 |

## 일정

| 항목 | 구분 | 일시 |
|---|---|---|
| 송출본선 점검 | 실행일 | 11/19(목) 01:00 |
| 송출복선 점검 | 실행일 | 11/20(금) 02:00 |
| 대체 편성안 제출 | 기한 | 11/17(화) 14:00 |
| 대체 편성안 승인 | 기한 | 11/18(수) 16:00 |
| 장애 보고서 제출 | 기한 | 11/20(금) 12:00 |

## 사전 준비

남이준은 대체 편성안을 11/17(화) 14:00까지 제출해야 한다. 유다겸은 대체 편성안을 11/18(수) 16:00까지 승인해야 한다. 대체 편성안은 편성보드의 야간장애 항목에 등록해야 한다.

## 경보 기준

- 송출본선: 영상이 4초 연속 정지하면 경보 기준에 해당한다.
- 송출복선: 영상이 7초 연속 정지하면 경보 기준에 해당한다.

## 프로그램 분류

긴급 안내 프로그램은 편성보드에 긴급 표식이 등록 완료된 프로그램이다. 그 밖의 프로그램은 일반 프로그램이다.

## 장애 최초 공유

장애를 확인하면 3분 이내에 운영메신저 송출당직 방에 게시해야 한다.

## 대응 절차

1. 장애를 확인한 직후, 백해린이 직전 90초 분량을 1단계 장애클립으로 저장한다. 1단계 장애클립의 보관 기간은 21일이다.
2. 장애가 일반 프로그램이면, 장애를 확인한 뒤 20초 대기하고 남이준이 대체 영상으로 전환한다.
3. 장애가 긴급 안내 프로그램이면, 장애를 확인한 뒤 대기 없이 차서온이 대체 음성으로 즉시 전환한다.
4. 2단계로, 대체 소스 전환 결과를 음성 감시기와 영상 감시기 모두로 확인한다.
5. 3단계로, 유다겸이 승인한 뒤에 본 소스로 복귀한다.
6. 4단계로, 남이준이 본 소스 복귀 직후부터 45초 분량을 4단계 복귀클립으로 저장한다. 4단계 복귀클립의 보관 기간은 7일이다.

## 비상 안내

대체 소스에서도 무음이 6초 연속 감지되면, 백해린이 비상 안내 파일 안내_달무리.wav를 재생해야 한다.

## 경보 해제

경보 해제 조건은 영상 정상과 음성 정상 상태가 함께 5분 연속 유지되는 것이다.

## 제출 자료

- 원인 분석 회의에 제출하는 자료는 1단계 장애클립이다.
- 광고주 정상화 확인 요청에 제출하는 자료는 4단계 복귀클립이다.

## 장애 보고서

차서온은 장애 보고서를 작성해 11/20(금) 12:00까지 제출해야 한다. 장애 보고서에는 최초 감지 시각과 대체 소스 전환 시각을 반드시 포함해야 한다.
