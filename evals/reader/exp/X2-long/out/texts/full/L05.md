# 모렌픽셀 배포 승인·복구 규정 개편 안내 (묶음 번호 2)

모렌픽셀 운영 서비스의 프로그램 배포와 설정 변경에 적용하는 배포 승인·복구 규정을 개편한다. 이 규정은 11/16(월) 09:00부터 적용한다. 모렌픽셀 개발자, 배포 승인자, 서비스 운영 담당자는 아래 일정에 맞춰 교육, 권한 신청, 설명회 참석을 준비해야 한다.

## 적용 범위

- 이 규정은 모렌픽셀 운영 서비스의 프로그램 배포와 설정 변경에 적용한다.
- 개발자 개인 실습 환경 배포에는 승인 규정이 적용되지 않는다.
- 배포 신청 시스템은 릴리즈문이다.

## 일정

| 일시 | 내용 | 구분 |
|---|---|---|
| 11/05(목) 15:00 | 규정 설명회. 온라인 회의실 코드는 룸-픽셀이다. | 행사 |
| 11/10(화) 14:00 | 배포 권한 교육 평가 | 행사 |
| 11/12(목) 17:00 | 배포 권한 신청 마감 | 기한 |
| 11/16(월) 09:00 | 배포 권한 활성화와 규정 적용 시작 | 실행일 |

## 배포 서버

| 서버 | 용도 | 담당자 | 배포 가능 시각 | 동시 배포 작업 상한 |
|---|---|---|---|---|
| 네온본선 | 운영 배포 | 서도윤 | 20:00-22:00 | 1건 |
| 네온예행 | 검증 배포 | 서도하 | 10:00-18:00 | 3건 |

각 서버의 동시 배포 작업은 상한을 넘으면 안 된다.

## 배포 신청과 승인

### 일반 배포

- 일반 배포 승인권자는 서비스 운영팀장이다.
- 일반 배포에는 승인 2명이 필요하다.
- 일반 배포는 배포 전 영업일 16:00까지 신청해야 한다.
- 일반 배포 결과는 배포 종료 후 2시간 이내에 보고해야 한다.

### 긴급 장애 배포

- 고객 접속 중단이 15분 이상일 때만 긴급 장애 배포로 인정한다.
- 긴급 장애 배포에는 승인 1명이 필요하다.
- 긴급 장애 배포를 신청할 때는 장애 번호를 반드시 입력해야 한다.
- 긴급 장애 배포 결과는 배포 종료 후 30분 이내에 보고해야 한다.

### 결과 보고

일반 배포와 긴급 장애 배포의 결과 보고에는 실행 로그와 승인 기록을 첨부해야 한다.

## 배포 권한

- 배포 권한 신청서는 릴리즈문 권한함에 11/12(목) 17:00까지 제출해야 한다.
- 배포 권한 교육의 수료 기준은 실습 평가 80점 이상이다.
- 교육을 수료하지 못한 사람에게는 배포 실행 권한을 부여하면 안 된다.
- 배포 권한은 11/16(월) 09:00에 활성화한다.

## 문의

규정 문의 담당자는 운영지원팀 윤해솔이다.

확인 필요: 일반 배포 승인 필요 인원 2명. 서비스 운영팀장을 포함한 2명일 수도 있고, 서비스 운영팀장 외에 2명이 더 필요할 수도 있다.
