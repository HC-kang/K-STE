# 묶음 번호 3 모래별콘텐츠 다국어 전자책 출시 프로젝트 일정 공지

모래별콘텐츠 다국어 전자책 출시 프로젝트(묶음 번호 3)의 출시 예정일은 12/18(금) 09:00이다. 출시 대상은 4개 언어이고, 출시 총괄은 유라겸이다. 이 문서는 사내 편집자와 외주 번역 담당자에게 일정, 담당, 보관 기간, 출시 보류 조건을 알린다.

## 일정

날짜 열에는 그때 하는 일(실행)과 그때까지 끝낼 일(기한)이 섞여 있어 구분 열을 두었다.

| 일시 | 구분 | 내용 | 담당 |
|---|---|---|---|
| 12/04(금) 17:00 | 기한 | 번역 원고 접수 마감 | 해당 없음 |
| 12/07(월) 11:00 | 실행 | 1차 배포본 생성 | 진서후 |
| 12/08(화) 15:00 | 기한 | 최종 교정 회의 의견 접수 마감 | 진서후(의견 취합) |
| 12/08(화) 18:00 | 기한 | 문장교정팀 작업 완료 | 문장교정팀 |
| 12/09(수) 10:00 | 실행 | 최종 교정 회의 개최 | 해당 없음 |
| 12/10(목) 11:00 | 기한 | 문장검수팀 작업 완료 | 문장검수팀 |
| 12/10(목) 16:00 | 기한 | 일반 원고 수정 마감 | 해당 없음 |
| 12/11(금) 12:00 | 기한 | 접근성 대체문구 수정 마감 | 해당 없음 |
| 12/14(월) 14:00 | 실행 | 3차 확정본 생성 | 오나린 |
| 12/16(수) 13:00 | 실행 | 판매 플랫폼 업로드 | 유라겸 |
| 12/18(금) 09:00 | 실행 | 출시 예정 | 유라겸(출시 총괄) |

담당이 "해당 없음"인 행은 메모에 담당자가 적혀 있지 않다는 뜻이다.

## 원고 접수와 수정

- 번역 원고 접수처는 별책 작업함이다. 접수 마감은 12/04(금) 17:00이다.
- 일반 원고 수정 마감은 12/10(목) 16:00이다.
- 접근성 대체문구 수정 마감은 12/11(금) 12:00이다.
- 오나린의 접근성 오류 확인표를 첨부한 접근성 대체문구에는 이 연장 마감이 적용된다.
- 오류 확인표가 없는 대체문구에는 일반 원고 수정 마감(12/10(목) 16:00)이 적용된다.

## 팀별 담당 범위

| 팀 | 책임자 | 담당 범위 | 작업 완료 기한 | 수정 이력 보관 기간 |
|---|---|---|---|---|
| 문장교정팀 | 진서후 | 본문 맞춤법 | 12/08(화) 18:00 | 30일 |
| 문장검수팀 | 오나린 | 번역 의미 대조 | 12/10(목) 11:00 | 60일 |

번역 의미 대조의 표본은 언어별 24쪽이다.

## 배포본

| 배포본 | 생성 | 담당 | 열람 유효기간 | 용도 |
|---|---|---|---|---|
| 1차 배포본 | 12/07(월) 11:00 | 진서후 | 3일 | 외주 번역자 교정 연습 입력물 |
| 3차 확정본 | 12/14(월) 14:00 | 오나린 | 10일 | 판매 플랫폼 업로드 입력물 |

## 최종 교정 회의

최종 교정 회의는 12/09(수) 10:00에 개최한다. 의견 접수 마감은 12/08(화) 15:00이고, 진서후가 의견을 취합한다.

## 출시 보류 조건

미해결 번역 의미 오류가 1건 이상이면 출시를 보류한다.

## 출시 후 오류 신고

출시 후 오류 신고처는 별책 작업함이다. 신고에는 언어명, 쪽번호, 오류 문장을 반드시 포함해야 한다.
