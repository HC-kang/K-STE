# 누리결물류 배송 관제 전환 프로젝트 일정 공지 (묶음 번호 3)

이 문서는 솔빛센터와 달빛센터의 배송 관제 전환 일정을 배송 관제 담당자와 물류센터 전산 담당자에게 알린다. 관제검증 서버는 11/10(화) 20:00에, 관제운영 서버는 11/12(목) 22:00에 전환한다. 프로젝트 총괄은 서다온이다.

## 전체 일정

| 일시 | 구분 | 내용 | 담당 |
|---|---|---|---|
| 11/06(금) 16:00 | 기한 | 센터별 연락망 제출 | 제출처: 관제지원 게시함 |
| 11/09(월) 14:00 | 실행 | 전환 리허설 실행 | 센터별 전산 담당자 |
| 11/10(화) 12:00 | 기한 | 전환 리허설 결과 제출 | 센터별 전산 담당자 |
| 11/10(화) 20:00 | 실행 | 관제검증 서버 전환 | 백시온 |
| 11/11(수) 19:00 | 실행 | 1단계 원본백업 생성 | 문하린 |
| 11/12(목) 15:00 | 실행 | 배송 이력 표본 대조 | 센터별 60건 |
| 11/12(목) 18:00 | 실행 | 일반 배송 노선 배차 수정 중단 | |
| 11/12(목) 21:00 | 실행 | 긴급 의약 노선 배차 수정 중단 | |
| 11/12(목) 22:00 | 실행 | 관제운영 서버 전환 | 문하린 |
| 11/13(금) 03:00 | 실행 | 4단계 안정화백업 생성 | 백시온 |
| 11/16(월) 10:00 | 실행 | 안정화 종료 점검 | 안정화 종료 승인: 서다온 |

전환 리허설 실행 담당은 메모에 없어서 표의 담당 칸에 "센터별 전산 담당자"를 넣은 것은 결과 제출 담당 기준이다. 

## 배차 수정 중단

일반 배송 노선의 배차 수정은 11/12(목) 18:00에 중단한다. 긴급 의약 노선의 배차 수정은 11/12(목) 21:00에 중단한다.

긴급 의약 노선에 21:00 중단 예외를 적용하려면 서다온 승인번호 등록이 끝나 있어야 한다. 승인번호가 없는 의약 노선에는 일반 배송 노선의 수정 중단 규칙을 적용한다.

## 서버 전환과 조회 중단

| 서버 | 전환 일시 | 담당 | 전환 중 예상 조회 중단 |
|---|---|---|---|
| 관제검증 서버 | 11/10(화) 20:00 | 백시온 | 15분 |
| 관제운영 서버 | 11/12(목) 22:00 | 문하린 | 40분 |

관제운영 서버 접속 확인에는 모든 배송 관제 담당자가 참여해야 한다. 관제검증 서버 접속 확인에는 센터별 전산 담당자 1명이 참여해야 한다.

## 백업과 복구

| 백업 | 생성 일시 | 담당 | 보관 기간 | 쓰임 |
|---|---|---|---|---|
| 1단계 원본백업 | 11/11(수) 19:00 | 문하린 | 14일 | 전환 실패 시 복구 입력물 |
| 4단계 안정화백업 | 11/13(금) 03:00 | 백시온 | 7일 | 정상 전환 후 이력 감사 입력물 |

## 전환 성공 판정

11/12(목) 15:00에 센터별 배송 이력 표본 60건을 대조한다. 표본 60건이 전부 일치해야 전환 성공으로 판정한다.

## 제출 사항

- 센터별 연락망을 11/06(금) 16:00까지 관제지원 게시함에 제출해야 한다.
- 전환 리허설 결과를 11/10(화) 12:00까지 센터별 전산 담당자가 제출해야 한다.

## 장애 신고

장애는 관제지원 게시함에 신고해야 한다. 신고에는 센터명, 노선번호, 발생 시각을 반드시 써야 한다.

확인 필요: 전환 리허설 실행 담당과 결과 제출처가 메모에 없다. 두 항목은 독자의 행동에 영향을 주므로 담당과 제출처를 알려 주면 문서에 넣겠다.
