# 재고 이동·반품 처리 규정 개편 안내 (안내 2)

**수신:** 다온궤도 솔바람 물류센터 피킹 직원, 반품 검수 직원, 교대 책임자
**문의:** 물류기획팀 차은목

## 1. 핵심 요약

- **시행일시:** 11월 23일(월) 08:00
- **적용 시설:** 다온궤도 솔바람 물류센터
- **적용 제외:** 외부 위탁 창고의 재고 이동에는 새 규정을 적용하지 않습니다.
- **필수 사전 조치:** 규정 교육 참석(11/17), 출입증 재등록(11/19 마감)

## 2. 준비 일정

| 일시 | 내용 | 비고 |
|---|---|---|
| 11월 17일(화) 10:00 | 규정 교육 | 새 규정 전반 안내 |
| 11월 19일(목) 16:00 | 작업자 출입증 재등록 마감 | 접수처: 센터 운영실 |
| 11월 23일(월) 08:00 | 새 규정 시행, 재등록 출입증 사용 개시 | |

재등록 마감까지 등록하지 않으면 11월 23일 08:00부터 재등록 출입증을 사용할 수 없으니, 마감 시각을 지켜 주세요.

## 3. 구역 운영 기준

| 구분 | 라온동 | 라온별동 |
|---|---|---|
| 용도 | 출고대기 구역 | 반품검수 구역 |
| 구역 책임자 | 오하진 | 오하림 |
| 임시 적치 상한 | 40상자 | 25상자 |
| 재고 확인 시각 | 매일 09:00 | 매일 14:00 |

## 4. 재고 이동 기록 (스톡나루)

1. 재고 이동 기록은 시스템 **스톡나루**에 남깁니다.
2. 구역 간 이동 전에 스톡나루에 **출발 구역과 도착 구역을 반드시 입력**합니다.
3. **스톡나루 장애 시**에는 종이 이동대장에 이동 내역을 기록합니다.
4. 스톡나루 복구 후 **4시간 이내**에 종이 이동대장 내용을 전산에 입력합니다.

## 5. 반품 검수 기준

### 5-1. 검수 완료 기한

| 구분 | 검수 완료 기한 |
|---|---|
| 일반 반품 | 입고 후 24시간 |
| 누액 반품 | 입고 후 2시간 |

### 5-2. 누액 반품 처리

- **분류 조건:** 포장 외부에서 액체 흔적이 확인되는 반품
- **보관 방법:** 검수 전까지 밀폐 트레이에 분리 보관

## 6. 식별표 발행·활용·보관

| 구분 | 입고식별표 | 판정식별표 |
|---|---|---|
| 발행 단계 | 입고 접수 1단계 | 검수 완료 3단계 |
| 발행 담당자 | 입고 접수원 | 반품 검수원 |
| 활용 | 반품 출처 조회 | 재판매 가능 여부 확인 |
| 원본 보관 기간 | 발행일부터 7일 | 발행일부터 30일 |

반품 출처는 입고식별표로, 재판매 가능 여부는 판정식별표로 확인합니다. 두 표를 바꿔 사용하지 않도록 주의하세요.

## 7. 재고 수량 차이 보고

- 재고 확인 중 **수량 차이가 3개 이상**이면 교대 책임자에게 보고합니다.
- 보고 기한은 **발견 후 30분 이내**입니다.

## 8. 교대 인수인계

교대 인수인계 문서에는 **미검수 상자 수**를 반드시 기재합니다.

## 9. 문의

규정 관련 문의는 물류기획팀 차은목 담당자에게 해 주세요.
