# 묶음 4 장애 회고: 수강 완료 표시 지연 (12/02 수)

**대상 독자:** 강좌 운영 매니저, 수강생 상담 담당자
**작성 회사:** 새결러닝(기업용 온라인 교육)

## 1. 요약

12/02(수) 13:06부터 14:18까지 72분간 수강 완료 표시가 늦게 반영됐습니다. 수강생 640명, 강좌 18개가 영향을 받았습니다. 영상 재생과 시험 답안 저장은 정상 운영됐고, 지연된 것은 수강 완료 표시뿐입니다.

원인은 12:50에 배포한 진도 이벤트 형식 변경입니다. 이 변경으로 완료 상태 필드의 이름이 바뀌었는데, 집계 모듈이 이전 필드 이름만 읽어서 완료 이벤트를 처리하지 못했습니다.

영향 수강생에게는 학습 기간 2일 연장을 제공합니다. 정상화 후 수료 결과는 620건이 생성됐고, 20명은 필수 시험 미제출로 미수료 상태를 유지합니다.

## 2. 영향 범위

| 구분 | 내용 |
|---|---|
| 영향 수강생 | 640명 |
| 영향 강좌 | 18개 |
| 장애 시간 | 12/02(수) 13:06 ~ 14:18 (72분) |
| 영향 있음 | 수강 완료 표시 지연 |
| 영향 없음 | 영상 재생, 시험 답안 저장 |

## 3. 원인

1. 12/02(수) 12:50에 진도 이벤트 형식 변경을 배포했습니다.
2. 이 변경으로 완료 상태 필드의 이름이 바뀌었습니다.
3. 집계 모듈은 이전 필드 이름만 읽도록 되어 있어 완료 이벤트 처리에 실패했습니다.
4. 그 결과 수강 완료 표시가 반영되지 않았습니다.

## 6. 수료증 발급과 수강생 안내

### 수료증 발급 규칙

| 구분 | 발급 조건 | 승인 담당 |
|---|---|---|
| 일반 수료증 | 진도 복구 후 운영 매니저 승인 | 노다인 |
| 당일 제출 수료증(예외) | 답안 저장 확인 후 교육 책임자 승인으로 **임시 발급** | 류해준 |

- 임시 수료증을 받은 수강생은 정식 수료증을 받은 뒤 **임시 수료증을 반드시 폐기**해야 합니다. 상담 시 꼭 안내해 주세요.
- 수강생 20명은 필수 시험을 제출하지 않아 정상화 후에도 미수료입니다. 수료 결과 620건과 20명을 합하면 영향 수강생 640명과 같습니다. 이 20명은 장애 때문이 아니라 시험 미제출로 미수료라는 점을 구분해 안내해 주세요.

### 학습 기간 연장

- 영향 수강생에게 학습 기간 2일 연장을 제공합니다.
- 적용 완료 기한은 12/04(금)입니다.

### 상담 시 안내 요점

- 영상 재생과 시험 답안 저장은 장애 중에도 정상이었으므로 학습 내용과 제출 답안은 유실되지 않았습니다.
- 수강 완료 표시는 14:18에 정상화됐습니다.
