# [묶음 2] 모렌픽셀 배포 승인·복구 규정 개편 안내

**대상:** 모렌픽셀 개발자, 배포 승인자, 서비스 운영 담당자
**문의:** 운영지원팀 윤해솔

## 1. 변경 요약

2026년 **11월 16일(월) 09:00**부터 모렌픽셀 운영 서비스의 프로그램 배포와 설정 변경에 새 승인·복구 규정을 적용합니다. 적용 전에 아래 일정에 맞춰 교육 평가를 받고 배포 권한을 신청해 주세요.

## 2. 적용 범위

- **적용 대상:** 모렌픽셀 운영 서비스의 프로그램 배포와 설정 변경
- **적용 제외:** 개발자 개인 실습 환경 배포(승인 규정 적용 제외)
- **배포 신청 시스템:** 릴리즈문

## 3. 주요 일정

| 일시 | 내용 |
|---|---|
| 11/05(목) 15:00 | 규정 설명회 (온라인 회의실 코드: 룸-픽셀) |
| 11/10(화) 14:00 | 배포 권한 교육 평가일 |
| 11/12(목) 17:00 | 배포 권한 신청 마감 |
| 11/16(월) 09:00 | 배포 권한 활성화 및 규정 적용 시작 |

## 4. 배포 권한

- **신청서 제출처:** 릴리즈문 권한함
- **교육 수료 기준:** 실습 평가 80점 이상
- **교육 미수료자:** 배포 실행 권한을 부여할 수 없습니다.

## 5. 배포 서버

| 구분 | 서버 | 담당자 | 배포 가능 시각 | 동시 배포 작업 상한 |
|---|---|---|---|---|
| 운영 | 네온본선 | 서도윤 | 20:00~22:00 | 1건 |
| 검증 | 네온예행 | 서도하 | 10:00~18:00 | 3건 |

## 6. 배포 신청·승인

| 구분 | 일반 배포 | 긴급 장애 배포 |
|---|---|---|
| 인정 조건 | - | 고객 접속 중단 15분 이상 |
| 승인권자 | 서비스 운영팀장 | - |
| 승인 필요 인원 | 2명 | 1명 |
| 신청 마감 | 배포 전 영업일 16:00 | - |
| 필수 입력 | - | 장애 번호 |
| 결과 보고 마감 | 배포 종료 후 2시간 | 배포 종료 후 30분 |

- 긴급 장애 배포는 신청 시 장애 번호를 반드시 입력해야 합니다.
- 결과 보고에는 **실행 로그**와 **승인 기록**을 첨부합니다.

## 7. 백업 및 복구

| 백업 이름 | 생성 시점 | 생성 책임자 | 보관 기간 | 용도 |
|---|---|---|---|---|
| 사전보관본 | 배포 준비 1단계 | 배포 실행 개발자 | 생성일부터 14일 | 배포 실패 시 복구 |
| 검증보관본 | 배포 확인 4단계 | 검증 담당자 | 생성일부터 7일 | 배포 성공 확인 시 비교 기준 |

## 8. 사전 조치 사항

1. 11/05(목) 규정 설명회에 참석해 주세요.
2. 배포 실행이 필요한 분은 11/10(화) 교육 평가에서 80점 이상을 받아야 합니다.
3. 11/12(목) 17:00까지 릴리즈문 권한함에 배포 권한 신청서를 제출해 주세요.

## 9. 문의

규정 관련 문의는 운영지원팀 윤해솔 담당자에게 해 주세요.
