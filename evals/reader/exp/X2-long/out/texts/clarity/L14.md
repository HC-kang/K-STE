# 묶음 4 장애 회고: 출고 라벨 출력 정지 (11/10)

**대상 독자:** 모루물류 야간 출고 관리자, 재고 운영 담당자
**업무 영역:** 생활용품 창고 출고
**회고 배포일:** 11/20(금), 배포 담당 서나겸

## 1. 요약

11/10(화) 22:08에 출고 라벨 출력이 멈췄고, 23:02에 정상 출력을 확인해 종료했습니다. 지속 시간은 54분입니다. 출고가 지연된 주문은 780건이고, 오배송은 확인되지 않았습니다(0건).

원인은 21:50 라벨 양식 배포에 섞여 들어간 글꼴 경로 오류입니다. 출력 프로세스가 글꼴 로딩에 실패한 뒤 작업 잠금을 해제하지 못해 출력이 멈췄습니다. 작업 잠금을 수집하는 지표가 없어 자동 경보도 울리지 않았습니다. 최초 인지는 현장 신고였습니다.

## 2. 영향

| 항목 | 내용 |
|---|---|
| 출고 지연 주문 | 780건 |
| 재출력 완료 주문 | 760건 |
| 고객 취소 요청으로 출고 제외 | 20건 |
| 오배송 | 확인 0건 |

재출력 760건과 출고 제외 20건을 합하면 지연 주문 780건과 일치합니다.

## 3. 원인

- **직접 원인:** 11/10(화) 21:50 라벨 양식 배포에서 글꼴 경로 오류가 유입되었습니다.
- **장애 메커니즘:** 출력 프로세스가 글꼴 로딩에 실패한 뒤 작업 잠금을 해제하지 못했습니다.
- **탐지 공백:** 작업 잠금을 수집하는 지표가 없어 자동 경보가 발생하지 않았습니다.

## 7. 출고 재개 규칙

두 경우 모두 재고 대조를 마친 뒤에만 출고를 재개합니다.

| 구분 | 재개 조건 | 승인 담당 |
|---|---|---|
| 일반 출고 | 재고 대조 완료 후 반장 승인 | 민도하 |
| 냉장 출고 (예외) | 재고 대조 완료 후 품질 담당 승인 | 진세아 |

복구 선언 조건은 **시험 라벨 40장 연속 정상 출력**입니다.
