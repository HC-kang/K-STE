# 은솔기록 연말 종이문서 디지털화 스캔 품질 관리 런북 (묶음 1)

## 1. 목적과 범위
이 문서는 은솔기록 연말 종이문서 디지털화 작업(묶음 1)의 검수자가 스캔부터 납품, 종이 원본 반출까지 따라 할 절차를 정리한 것입니다.

## 2. 담당자

| 역할 | 담당자 |
|---|---|
| 검수 총괄 | 민도윤 |
| 납품 승인 | 정라희 |
| 납품 목록 제출 | 고은재 |
| 납품 목록 확정 | 정라희 |
| 일반 문서 묶음 육안 검수 | 고은재 |
| 훼손 문서 묶음 육안 검수 | 민도윤 |
| 재스캔 파일 재검수 | 고은재 |
| 고객 저장소 업로드 | 배시우 |
| 스캔청 장비 담당 | 민도윤 |
| 스캔청보 장비 담당 | 고은재 |

## 3. 일정

| 일시 | 내용 | 담당 |
|---|---|---|
| 12/08(화) 15:00 | 납품 목록 제출 기한 | 고은재 |
| 12/09(수) 17:00 | 납품 목록 확정 기한 | 정라희 |
| 12/10(목) 09:00 | 스캔청 장비 교정 | 민도윤 |
| 12/11(금) 10:00 | 스캔청보 장비 교정 | 고은재 |
| 12/11(금) 18:00 | 납품 완료 보고 기한 | 아래 12번 참조 |

## 4. 장비별 일일 처리 상한

| 장비 | 일일 상한 | 담당 |
|---|---|---|
| 스캔청 | 800쪽 | 민도윤 |
| 스캔청보 | 500쪽 | 고은재 |

## 5. 묶음 분류
- **훼손 문서 묶음**: 찢김 또는 물얼룩이 있는 쪽이 1쪽 이상 포함된 묶음
- **일반 문서 묶음**: 위 조건에 해당하지 않는 묶음

스캔 전에 묶음별로 분류해 두어야 육안 검수 비율과 담당자가 정해집니다.

## 6. 절차

### 1단계: 원본목록 작성 (스캔 시작 전)
1. 스캔을 시작하기 전에 원본목록을 작성합니다.
2. 기록 항목은 **종이문서 식별번호**와 **원본 쪽수**입니다.
3. 보관 기간은 **60일**입니다.
4. 이 목록은 종이 원본 쪽수를 대조하는 기준입니다.

### 2단계: 스캔
1. 스캔 파일명의 첫 부분에 **묶음 식별번호**를 표기합니다.
2. 장비별 일일 처리 상한(4번)을 넘지 않게 배정합니다.

### 3단계: 육안 검수와 재스캔
**육안 검수 대상 쪽수**

| 묶음 유형 | 검수 비율 | 담당 |
|---|---|---|
| 일반 | 묶음별 전체 쪽수의 10% | 고은재 |
| 훼손 | 묶음별 전체 쪽수의 100% | 민도윤 |

- 일반 문서 묶음은 표본 쪽수 계산 결과에 소수점이 있으면 **올림**합니다. 예를 들어 125쪽 묶음은 12.5쪽이므로 13쪽을 검수합니다.

**재스캔**
1. 검수 중 **잘림** 또는 **초점 불량**이 발견되면 재스캔합니다.
2. 재스캔을 마친 파일은 **고은재가 재검수**합니다.

### 4단계: 납품목록 작성 (재스캔과 검수 완료 후)
1. 재스캔과 검수가 모두 끝난 뒤에 작성합니다.
2. 기록 항목은 **최종 파일명**과 **최종 파일 쪽수**입니다.
3. 보관 기간은 **120일**입니다.
4. 이 목록은 고객 전달 파일 구성을 대조하는 기준입니다.

## 7. 대조 기준 요약

| 대조 대상 | 기준 문서 |
|---|---|
| 종이 원본 쪽수 | 1단계 원본목록 |
| 고객 전달 파일 구성 | 4단계 납품목록 |

## 8. 쪽수 불일치 시 조치
1. 불일치를 발견하면 **해당 묶음 전체의 납품을 보류**합니다.
2. **민도윤에게 보고**합니다.

## 9. 납품 목록 제출·확정
1. 고은재가 12/08(화) 15:00까지 납품 목록을 **작업장부의 겨울기록 항목**에 등록해 제출합니다.
2. 정라희가 12/09(수) 17:00까지 확정합니다.

## 10. 납품 승인과 업로드
1. **정라희의 납품 승인 전에는 고객 저장소에 업로드할 수 없습니다.**
2. 승인 후 배시우가 고객 저장소에 업로드합니다.
3. 업로드 결과를 정리해 업로드 결과표를 만듭니다.

## 11. 종이 원본 반출
다음 두 조건을 **모두** 충족해야 반출할 수 있습니다.
- 고객 수령 확인 완료
- 정라희의 반출 승인 완료

## 12. 납품 완료 보고
- 기한은 12/11(금) 18:00입니다.
- 첨부물은 **업로드 결과표**와 **4단계 납품목록**입니다.

## 13. 검수자 체크리스트
- [ ] 스캔 전 묶음 분류(일반/훼손)를 마쳤다.
- [ ] 스캔 전 1단계 원본목록을 작성했다. (보관 60일)
- [ ] 파일명 첫 부분에 묶음 식별번호가 있다.
- [ ] 장비별 일일 상한(스캔청 800쪽, 스캔청보 500쪽)을 지켰다.
- [ ] 일반 묶음은 10%(소수점 올림), 훼손 묶음은 100%를 육안 검수했다.
- [ ] 잘림·초점 불량 쪽을 재스캔하고 고은재가 재검수했다.
- [ ] 재스캔과 검수가 끝난 뒤 4단계 납품목록을 작성했다. (보관 120일)
- [ ] 원본 쪽수는 1단계 원본목록, 파일 구성은 4단계 납품목록과 대조했고 불일치가 없다.
- [ ] 12/08 15:00까지 겨울기록 항목에 납품 목록을 제출했다.
- [ ] 12/09 17:00까지 납품 목록이 확정되었다.
- [ ] 정라희의 납품 승인 후에 업로드했다.
- [ ] 12/11 18:00까지 업로드 결과표와 4단계 납품목록을 첨부해 보고했다.
- [ ] 고객 수령 확인과 정라희 반출 승인을 모두 받은 뒤 원본을 반출했다.

## 14. 확인이 필요한 사항
메모에 없어서 임의로 정하지 않았습니다. 운영 전에 확인해 주세요.

1. **교정일과 일정의 관계**: 장비 교정(12/10, 12/11)이 납품 목록 제출·확정 기한(12/08, 12/09)보다 늦습니다. 4단계 납품목록은 스캔·재스캔·검수가 끝난 뒤 작성하므로, 교정 전에 해당 작업이 끝나는 일정인지 확인이 필요합니다. 교정 중 장비 사용 가능 여부도 메모에 없습니다.
2. **납품 확정과 납품 승인**: 둘 다 정라희 담당입니다. 같은 행위인지 별도 단계인지 정해 주세요. 이 문서는 별도 단계로 보고 확정 → 승인 순서로 썼습니다.
3. **미지정 담당자**: 1단계 원본목록 작성자, 재스캔 실행자, 납품 완료 보고자는 메모에 없습니다.
4. **일일 상한 초과 시 처리**: 메모에 규정이 없습니다.
5. **납품 목록 명칭**: 메모의 "납품 목록"(제출·확정·등록)과 "4단계 납품목록"을 같은 문서로 보았습니다.
