# 모래빛방송 연말 생방송 송출 장애 대응 런북

## 1. 목적과 적용 범위
- 모래빛방송 연말 생방송 중 송출 장애가 발생했을 때 송출 감독이 순서대로 따라 할 대응 절차를 정리한다.
- 대상은 송출본선과 송출복선이다.

## 2. 담당자

| 역할 | 담당자 |
|---|---|
| 장애 대응 총괄 | 차서온 |
| 편성 승인 | 유다겸 |
| 송출본선 담당 | 차서온 |
| 송출복선 담당 | 남이준 |
| 일반 프로그램 대체 영상 전환 | 남이준 |
| 긴급 안내 프로그램 대체 음성 전환 | 차서온 |
| 1단계 장애클립 저장 | 백해린 |
| 4단계 복귀클립 저장 | 남이준 |
| 비상 안내 파일 재생 | 백해린 |
| 장애 보고서 작성 | 차서온 |

## 4. 경보 기준

| 구분 | 영상 정지 경보 기준 |
|---|---|
| 송출본선 | 4초 연속 정지 |
| 송출복선 | 7초 연속 정지 |

## 5. 장애 대응 절차

### 5-1. 장애 확인 및 최초 공유
1. 경보 기준에 해당하는 장애를 확인한다.
2. 확인 후 **3분 이내**에 운영메신저 **송출당직** 방에 최초 공유를 게시한다.
3. 최초 감지 시각을 기록해 둔다. 장애 보고서의 필수 항목이다.

### 5-2. 프로그램 분류
편성보드에 **긴급 표식 등록이 완료된** 프로그램은 긴급 안내 프로그램이고, 그 외는 일반 프로그램이다.

| 구분 | 분류 조건 | 조치 | 담당 |
|---|---|---|---|
| 일반 프로그램 | 긴급 표식 등록 완료가 아님 | 장애 확인 후 **20초 대기**, 이후 대체 영상으로 전환 | 남이준 |
| 긴급 안내 프로그램 | 편성보드에 긴급 표식 등록 완료 | 장애 확인 후 **대기 없이 즉시** 대체 음성으로 전환 | 차서온 |

### 5-3. 단계별 조치

**1단계. 장애클립 저장**
- 장애 확인 직후, 확인 시점 **직전 90초** 분량을 저장한다.
- 보관 기간은 **21일**이다.
- 담당은 백해린이다.
- 이 클립은 원인 분석 회의 제출 자료로 쓴다.

**2단계. 대체 소스 전환 확인**
- 전환 결과를 **음성 감시기와 영상 감시기 모두**로 확인한다.
- 대체 소스 전환 시각을 기록해 둔다. 장애 보고서의 필수 항목이다.

**3단계. 본 소스 복귀**
- **유다겸의 승인을 받은 뒤** 실행한다. 승인 없이 복귀하지 않는다.

**4단계. 복귀클립 저장**
- 본 소스 복귀 직후부터 **45초** 분량을 저장한다.
- 보관 기간은 **7일**이다.
- 담당은 남이준이다.
- 이 클립은 광고주 정상화 확인 요청에 제출하는 자료로 쓴다.

### 5-4. 대체 소스에서도 무음이 감지될 때
- 대체 소스에서 **무음이 6초 연속** 감지되면 비상 안내 파일 **안내_달무리.wav**를 재생한다.
- 재생 담당은 백해린이다.

### 5-5. 경보 해제
- **영상 정상과 음성 정상 상태가 함께 5분 연속** 유지되면 경보를 해제한다.
- 둘 중 하나라도 정상이 아니면 유지 시간을 처음부터 다시 센다.
