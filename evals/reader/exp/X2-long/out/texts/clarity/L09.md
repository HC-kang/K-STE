# [공지] 누리결물류 배송 관제 전환 프로젝트(묶음 3) 일정 안내

**수신:** 배송 관제 담당자, 물류센터 전산 담당자
**프로젝트 총괄:** 서다온
**전환 대상 센터:** 솔빛센터, 달빛센터

누리결물류 배송 관제 전환 프로젝트의 일정과 담당, 협조 사항을 아래와 같이 안내드립니다. 각 담당자는 본인 해당 항목의 기한과 시각을 확인해 주시기 바랍니다.

## 1. 전체 일정

| 일시 | 내용 | 담당·대상 |
|---|---|---|
| 11/06(금) 16:00 | 센터별 연락망 제출 마감 (제출처: 관제지원 게시함) | 센터별 |
| 11/09(월) 14:00 | 전환 리허설 실행 | 센터별 전산 담당자 |
| 11/10(화) 12:00 | 전환 리허설 결과 제출 마감 | 센터별 전산 담당자 |
| 11/10(화) 20:00 | **관제검증 서버 전환** (예상 조회 중단 15분) | 백시온 |
| 11/11(수) 19:00 | 1단계 원본백업 생성 (보관 14일) | 문하린 |
| 11/12(목) 15:00 | 배송 이력 표본 대조 (센터별 60건) | 센터별 |
| 11/12(목) 18:00 | 일반 배송 노선 배차 수정 중단 | 전체 |
| 11/12(목) 21:00 | 긴급 의약 노선 배차 수정 중단 | 전체 |
| 11/12(목) 22:00 | **관제운영 서버 전환** (예상 조회 중단 40분) | 문하린 |
| 11/13(금) 03:00 | 4단계 안정화백업 생성 (보관 7일) | 백시온 |
| 11/16(월) 10:00 | 안정화 종료 점검 및 종료 승인 | 서다온 |

## 2. 서버 전환 담당과 접속 확인

| 구분 | 전환 일시 | 전환 담당 | 예상 조회 중단 | 접속 확인 참여자 |
|---|---|---|---|---|
| 관제검증 서버 | 11/10(화) 20:00 | 백시온 | 15분 | 센터별 전산 담당자 1명 |
| 관제운영 서버 | 11/12(목) 22:00 | 문하린 | 40분 | 모든 배송 관제 담당자 |

전환 중 위 시간 동안 조회가 중단되므로, 필요한 조회는 전환 전에 마쳐 주시기 바랍니다.

## 3. 배차 수정 중단 규칙 (11/12)

- **일반 배송 노선:** 18:00부터 배차 수정이 중단됩니다.
- **긴급 의약 노선:** 21:00부터 배차 수정이 중단됩니다.
  - 단, 이 예외는 **서다온 승인번호가 등록 완료된 노선에만** 적용됩니다.
  - 승인번호가 없는 의약 노선은 일반 배송 노선과 같이 **18:00에 수정이 중단**됩니다.

## 4. 백업과 복구 기준

- **1단계 원본백업** (11/11 19:00, 문하린): 14일 보관하며, 전환 실패 시 복구 입력물로 사용합니다.
- **4단계 안정화백업** (11/13 03:00, 백시온): 7일 보관하며, 정상 전환 후 이력 감사 입력물로 사용합니다.

## 5. 전환 성공 판정

배송 이력 표본 대조(센터별 60건)에서 **60건이 전부 일치**해야 전환 성공으로 판정합니다.

## 6. 센터별 사전 제출 사항

1. **연락망:** 11/06(금) 16:00까지 관제지원 게시함에 제출
2. **전환 리허설 결과:** 11/10(화) 12:00까지 센터별 전산 담당자가 제출

## 7. 장애 신고

전환 중이나 안정화 기간에 장애가 발생하면 **관제지원 게시함**으로 신고해 주시기 바랍니다. 아래 세 항목은 반드시 포함해 주세요.

- 센터명
- 노선번호
- 발생 시각

## 8. 문의

일정과 승인 관련 문의는 프로젝트 총괄 서다온에게 연락해 주시기 바랍니다.

- 메모에 접속 확인 시각이 없어 문서에는 참여자만 적었습니다. 시각이 정해져 있으면 2번 표에 추가하는 것이 좋습니다.
- 배송 이력 표본 대조(11/12 15:00)가 관제운영 서버 전환(22:00)보다 앞섭니다. 성공 판정 시점이 전환 전 대조인지 전환 후 재대조인지 독자가 헷갈릴 수 있으니 확인 후 5번에 보완해 주세요.
- 전환 리허설이 어느 서버 대상인지 메모에 없어 따로 적지 않았습니다.
- 메모에 없는 2·3단계 백업은 언급하지 않았습니다.
- 발신자 이름은 넣지 않았으니 필요하면 추가해 주세요.
