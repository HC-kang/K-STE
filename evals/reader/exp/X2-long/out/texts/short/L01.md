# 누비결제 승인 데이터베이스 야간 전환 런북

## 역할

| 역할 | 담당자 |
|---|---|
| 작업 책임자 | 서린우 |
| 중단 결정권자 | 배도현 |
| 승인주 서버 담당자 | 서린우 |
| 승인보조 서버 담당자 | 문해솔 |
| 전환 계획 등록 담당자 | 문해솔 |
| 전환 계획 승인 담당자 | 배도현 |
| 일반 가맹점 대기열 담당자 | 문해솔 |
| 긴급 가맹점 우회망 담당자 | 하유담 |
| 1단계 원본스냅 생성 담당자 | 서린우 |
| 4단계 검증스냅 생성 담당자 | 하유담 |
| 완료 보고 작성자 | 서린우 |

## 일정

| 대상 | 실행일 | 시작 시각 | 복제 지연 허용 상한 |
|---|---|---|---|
| 승인주 서버 | 11/12(목) | 02:00 | 4초 |
| 승인보조 서버 | 11/13(금) | 03:00 | 9초 |

## 사전 준비

- 문해솔은 11/10(화) 17:00까지 변경장부의 승인DB 항목에 전환 계획을 등록해야 한다.
- 배도현은 11/11(수) 15:00까지 전환 계획을 승인해야 한다.
- 작업을 시작하기 전에 긴급 가맹점을 긴급명부에 등록해야 한다. 작업 시작 전에 긴급명부 등록이 끝난 가맹점만 긴급 가맹점으로 분류한다.

## 전환 중 승인 요청 경로

| 구분 | 전환 중 경로 | 담당자 |
|---|---|---|
| 일반 가맹점 | 승인 요청을 대기열에 최대 6분 보관한다. | 문해솔 |
| 긴급 가맹점 | 승인 요청을 대기열에 보관하지 않고 우회망으로 즉시 전송한다. | 하유담 |

## 전환 절차

1. 쓰기를 차단하기 직전에 원본스냅을 생성한다. 서린우가 생성하고, 보관 기간은 72시간이다.
2. 쓰기를 차단하기 전에 감시판에서 진행 중 거래 수가 0건인지 확인한다.
3. 감시판에서 배도현의 승인 기록을 확인한 뒤에 전환 명령을 실행한다.
4. 시험 승인 24건이 성공한 뒤에 검증스냅을 생성한다. 하유담이 생성하고, 보관 기간은 12시간이다.

## 중단 요청 기준

전환 중 아래 조건 중 하나라도 해당하면 중단을 요청한다.

- 승인 오류율이 2%를 초과한 상태가 3분 연속 지속된다.
- 복제 지연이 서버별 허용 상한을 초과한 상태가 2분 연속 지속된다. 승인주 서버의 상한은 4초이고, 승인보조 서버의 상한은 9초이다.

중단 요청은 운영메신저의 야간전환 방에 접수한다. 중단 결정권자는 배도현이다.

## 원복

- 전환 후 원복이 필요하면 1단계 원본스냅으로 복원한다.
- 원복을 마친 뒤 시험 승인 8건이 전부 성공해야 쓰기 차단을 해제할 수 있다.

## 스냅 사용과 삭제

- 감사 제출용 대조 자료는 4단계 검증스냅이다.
- 원본스냅과 검증스냅은 보관 기간이 만료된 뒤에 삭제할 수 있다. 삭제하려면 배도현의 승인이 필요하다.

## 완료 보고

- 서린우는 11/13(금) 10:00까지 완료 보고를 작성해야 한다.
- 첨부물은 오류율 그래프와 승인 응답 기록이다.

## 확인 필요

- 확인 필요: 1-4단계를 승인주 서버와 승인보조 서버 전환에 각각 따로 하는지, 한 번만 하는지 메모에 없다.
- 확인 필요: 시작 시각 02:00과 03:00이 작업 시작 시각인지 쓰기 차단 시각인지 메모에 없다.
- 확인 필요: 중단 요청을 야간전환 방에 올리는 사람이 누구인지 메모에 없다.
- 확인 필요: 원복을 결정하는 사람이 누구인지 메모에 없다.
- 확인 필요: 3단계 전환 명령을 실행하는 사람이 누구인지 메모에 없다.
- 확인 필요: 일반 가맹점 승인 요청이 6분을 넘으면 어떻게 하는지 메모에 없다.
- 확인 필요: 긴급명부에 가맹점을 등록하는 담당자가 누구인지 메모에 없다.
