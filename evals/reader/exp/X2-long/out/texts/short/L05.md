# 모렌픽셀 배포 승인·복구 규정 개편 안내 (묶음 번호 2)

모렌픽셀 운영 서비스의 프로그램 배포와 설정 변경에 적용하는 배포 승인·복구 규정이 2026년 11월 16일(월) 09:00부터 바뀐다. 이 문서는 모렌픽셀 개발자, 배포 승인자, 서비스 운영 담당자에게 보낸다.

## 적용 범위

- 규정은 모렌픽셀 운영 서비스의 프로그램 배포와 설정 변경에 적용한다.
- 개발자 개인 실습 환경 배포에는 승인 규정을 적용하지 않는다.
- 배포 신청 시스템의 이름은 릴리즈문이다.

## 일정

| 일시 | 내용 |
|---|---|
| 11/05(목) 15:00 | 규정 설명회. 온라인 회의실 코드는 룸-픽셀이다. |
| 11/10(화) 14:00 | 배포 권한 교육 평가 |
| 11/12(목) 17:00 | 배포 권한 신청 마감 |
| 11/16(월) 09:00 | 규정 적용 시작, 배포 권한 활성화 |

## 배포 서버

| 항목 | 네온본선 | 네온예행 |
|---|---|---|
| 용도 | 운영 배포 서버 | 검증 배포 서버 |
| 담당자 | 서도윤 | 서도하 |
| 배포 가능 시각 | 20:00~22:00 | 10:00~18:00 |
| 동시 배포 작업 상한 | 1건 | 3건 |

## 배포 승인

- 일반 배포의 승인권자는 서비스 운영팀장이다.
- 일반 배포에는 승인 2명이 필요하다.
- 일반 배포 신청은 배포 전 영업일 16:00까지 해야 한다.
- 긴급 장애 배포로 인정하는 조건은 고객 접속 중단 15분 이상이다.
- 긴급 장애 배포에는 승인 1명이 필요하다.
- 긴급 장애 배포를 신청할 때는 장애 번호를 반드시 입력해야 한다.

확인 필요: 일반 배포 승인 2명이 모두 서비스 운영팀장인지, 서비스 운영팀장을 포함한 2명인지 확인이 필요하다.

확인 필요: "배포 전 영업일 16:00"이 배포일 직전 영업일 16:00을 뜻하는지 확인이 필요하다.

## 백업과 복구

| 항목 | 사전보관본 | 검증보관본 |
|---|---|---|
| 생성 시점 | 배포 준비 1단계 | 배포 확인 4단계 |
| 생성 책임자 | 배포 실행 개발자 | 검증 담당자 |
| 보관 기간 | 생성일부터 14일 | 생성일부터 7일 |
| 용도 | 배포 실패 시 복구에 사용한다. | 배포 성공을 확인할 때 비교 기준으로 사용한다. |

## 배포 결과 보고

- 일반 배포는 배포 종료 후 2시간 안에 결과를 보고해야 한다.
- 긴급 장애 배포는 배포 종료 후 30분 안에 결과를 보고해야 한다.
- 결과 보고에는 실행 로그와 승인 기록을 첨부해야 한다.

## 배포 권한

- 배포 권한 교육 수료 기준은 실습 평가 80점 이상이다.
- 교육을 수료하지 못한 사람에게는 배포 실행 권한을 부여할 수 없다.
- 배포 권한 신청서는 11/12(목) 17:00까지 릴리즈문 권한함에 제출해야 한다.
- 배포 권한은 11/16(월) 09:00에 활성화한다.

## 문의

규정 문의 담당자는 운영지원팀 윤해솔이다.
