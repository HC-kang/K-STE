# 누리결물류 배송 관제 전환 프로젝트 일정 공지 (묶음 번호 3)

## 대상과 총괄

이 공지는 배송 관제 담당자와 물류센터 전산 담당자에게 보낸다. 전환 대상 센터는 솔빛센터와 달빛센터이다. 프로젝트 총괄은 서다온이다.

## 전체 일정

| 일시 | 내용 | 담당 |
|---|---|---|
| 11/06(금) 16:00 | 센터별 연락망 제출 기한 | 확인 필요 |
| 11/09(월) 14:00 | 전환 리허설 실행 | 확인 필요 |
| 11/10(화) 12:00 | 전환 리허설 결과 제출 기한 | 센터별 전산 담당자 |
| 11/10(화) 20:00 | 관제검증 서버 전환 | 백시온 |
| 11/11(수) 19:00 | 1단계 원본백업 생성 | 문하린 |
| 11/12(목) 15:00 | 배송 이력 표본 대조 | 확인 필요 |
| 11/12(목) 18:00 | 일반 배송 노선 배차 수정 중단 | 해당 없음 |
| 11/12(목) 21:00 | 긴급 의약 노선 배차 수정 중단 | 해당 없음 |
| 11/12(목) 22:00 | 관제운영 서버 전환 | 문하린 |
| 11/13(금) 03:00 | 4단계 안정화백업 생성 | 백시온 |
| 11/16(월) 10:00 | 안정화 종료 점검 | 안정화 종료 승인은 서다온 |

## 제출 사항

각 센터는 11/06(금) 16:00까지 센터별 연락망을 관제지원 게시함에 제출해야 한다.

센터별 전산 담당자는 11/10(화) 12:00까지 전환 리허설 결과를 제출해야 한다.

## 배차 수정 중단

일반 배송 노선은 11/12(목) 18:00부터 배차를 수정하면 안 된다.

긴급 의약 노선은 11/12(목) 21:00부터 배차를 수정하면 안 된다. 이 예외는 서다온 승인번호가 등록된 긴급 의약 노선에만 적용한다. 승인번호가 없는 의약 노선에는 일반 배송 노선의 수정 중단 규칙을 적용한다.

## 서버 전환

| 구분 | 전환 일시 | 담당 | 예상 조회 중단 | 접속 확인 참여자 |
|---|---|---|---|---|
| 관제검증 서버 | 11/10(화) 20:00 | 백시온 | 15분 | 센터별 전산 담당자 1명 |
| 관제운영 서버 | 11/12(목) 22:00 | 문하린 | 40분 | 모든 배송 관제 담당자 |

## 백업

| 구분 | 생성 일시 | 담당 | 보관 기간 | 쓰임 |
|---|---|---|---|---|
| 1단계 원본백업 | 11/11(수) 19:00 | 문하린 | 14일 | 전환에 실패하면 복구 입력물로 쓴다. |
| 4단계 안정화백업 | 11/13(금) 03:00 | 백시온 | 7일 | 정상 전환 후 이력 감사 입력물로 쓴다. |

## 전환 성공 판정

배송 이력 표본 대조는 11/12(목) 15:00에 하고, 표본은 센터별 60건이다. 표본 60건이 전부 일치하면 전환 성공으로 판정한다.

## 장애 신고

장애는 관제지원 게시함에 신고해야 한다. 신고에는 센터명, 노선번호, 발생 시각을 반드시 적어야 한다.

## 확인 필요

- 센터별 연락망 제출, 전환 리허설 실행, 배송 이력 표본 대조의 담당자가 메모에 없다.
- 서다온 승인번호를 누가 어디에 등록하는지 메모에 없다.
- 1단계 원본백업과 4단계 안정화백업의 보관 기간을 언제부터 세는지 메모에 없다.
- 관제운영 서버와 관제검증 서버의 접속 확인 일시가 메모에 없다.
