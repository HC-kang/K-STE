# 모래빛방송 연말 생방송 송출 장애 대응 런북

## 담당자

| 역할 | 담당자 |
|---|---|
| 장애 대응 총괄 | 차서온 |
| 편성 승인 | 유다겸 |
| 송출본선 | 차서온 |
| 송출복선 | 남이준 |
| 일반 프로그램 대체 영상 전환 | 남이준 |
| 긴급 안내 프로그램 대체 음성 전환 | 차서온 |
| 1단계 장애클립 저장 | 백해린 |
| 4단계 복귀클립 저장 | 남이준 |
| 비상 안내 파일 재생 | 백해린 |
| 장애 보고서 작성 | 차서온 |

## 사전 준비

### 송출 점검

| 구분 | 실행일 | 담당자 |
|---|---|---|
| 송출본선 점검 | 11/19(목) 01:00 | 차서온 |
| 송출복선 점검 | 11/20(금) 02:00 | 남이준 |

### 대체 편성안

- 남이준이 대체 편성안을 11/17(화) 14:00까지 제출한다.
- 유다겸이 대체 편성안을 11/18(수) 16:00까지 승인한다.
- 대체 편성안은 편성보드의 야간장애 항목에 등록한다.

## 경보 기준

| 구분 | 영상 정지 경보 기준 |
|---|---|
| 송출본선 | 4초 연속 정지 |
| 송출복선 | 7초 연속 정지 |

## 장애 대응 절차

1. 장애를 확인하면 3분 이내에 운영메신저 송출당직 방에 최초 공유를 게시한다.
2. 1단계로 백해린이 장애를 확인한 직후 직전 90초 분량의 장애클립을 저장한다. 장애클립은 21일 동안 보관한다.
3. 2단계로 대체 소스로 전환한다. 전환 방식은 아래 프로그램 분류에 따른다. 전환 결과는 음성 감시기와 영상 감시기 모두로 확인한다.
4. 3단계로 본 소스에 복귀한다. 유다겸이 승인한 후에 복귀를 실행해야 한다.
5. 4단계로 남이준이 본 소스에 복귀한 직후부터 45초 분량의 복귀클립을 저장한다. 복귀클립은 7일 동안 보관한다.
6. 영상 정상 상태와 음성 정상 상태가 함께 5분 연속 유지되면 경보를 해제한다.
7. 차서온이 장애 보고서를 11/20(금) 12:00까지 제출한다. 보고서에는 최초 감지 시각과 대체 소스 전환 시각을 반드시 넣어야 한다.

### 프로그램 분류별 전환

편성보드에 긴급 표식 등록이 완료된 프로그램을 긴급 안내 프로그램으로 분류한다.

| 구분 | 전환 방식 | 담당자 |
|---|---|---|
| 일반 프로그램 | 장애를 확인하고 20초 대기한 뒤 대체 영상으로 전환한다. | 남이준 |
| 긴급 안내 프로그램 | 장애를 확인하면 대기 없이 대체 음성으로 즉시 전환한다. | 차서온 |

### 대체 소스 무음 시 조치

대체 소스에서도 무음이 6초 연속 감지되면 백해린이 비상 안내 파일 `안내_달무리.wav`를 재생한다.

## 제출 자료

| 제출처 | 제출 자료 |
|---|---|
| 원인 분석 회의 | 1단계 장애클립 |
| 광고주 정상화 확인 요청 | 4단계 복귀클립 |

## 확인 필요

- 2단계에서 음성 감시기와 영상 감시기로 전환 결과를 확인하는 담당자가 메모에 없다.
- 3단계에서 본 소스 복귀를 실행하는 담당자가 메모에 없다.
- 경보를 해제하는 담당자가 메모에 없다.
- 영상 정상 상태와 음성 정상 상태를 판정하는 기준이 메모에 없다.
- 긴급 표식 등록이 완료되지 않은 프로그램을 일반 프로그램으로 분류하는지가 메모에 없다.
- "장애 확인 직후 직전 90초 분량"에서 "직전"이 어느 시점의 직전인지가 메모에 없다.
