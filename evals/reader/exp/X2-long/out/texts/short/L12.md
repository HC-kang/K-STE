# 온새미교육 온라인 연수 개편 프로젝트 일정 공지 (묶음 번호 3)

이 문서는 기업교육 강사와 수강 운영 담당자에게 온라인 연수 개편 프로젝트의 일정을 알린다. 개편 총괄은 한로운이다. 개편 과정은 6개이다. 정식 연수는 12/16(수) 10:00에 시작한다.

## 전체 일정

| 일시 | 내용 |
|---|---|
| 12/03(목) 17:00 | 강사 소개서 제출 마감 |
| 12/04(금) 10:00 | 1차 수강명부 생성 |
| 12/07(월) 16:00 | 일반 과정 교안 제출 마감 |
| 12/08(화) 13:00 | 배움연습 시스템 개통 |
| 12/08(화) 18:00 | 모의 강의 신청 마감 |
| 12/09(수) 12:00 | 수어 동반 과정 교안 제출 마감 |
| 12/10(목) 14:00 | 모의 강의 진행 |
| 12/11(금) 15:00 | 4차 확정명부 생성 |
| 12/14(월) 11:00 | 정식 연수 계정 발급 실행 |
| 12/14(월) 16:00 | 수강 안내문 발송 |
| 12/15(화) 09:00 | 배움운영 시스템 개통 |
| 12/16(수) 10:00 | 정식 연수 시작 |

## 강사 제출물

- 강사는 12/03(목) 17:00까지 강사 소개서를 연수준비 게시함에 제출해야 한다.
- 강사는 12/07(월) 16:00까지 일반 과정 교안을 제출해야 한다.
- 강사는 12/09(수) 12:00까지 수어 동반 과정 교안을 제출해야 한다.
- 수어 동반 과정 교안 제출 마감의 연장 조건은 한로운 승인 통역 배정표 첨부이다.
- 통역 배정표를 첨부하지 않은 과정에는 일반 과정 교안 제출 마감을 적용한다.

확인 필요: "한로운 승인 통역 배정표 첨부"가 한로운이 승인한 통역 배정표를 첨부한다는 뜻인지, 통역 배정표를 첨부해서 한로운의 승인을 받는다는 뜻인지 확인이 필요하다.

## 모의 강의

- 모의 강의는 12/10(목) 14:00에 진행한다.
- 모의 강의 신청 마감은 12/08(화) 18:00이다.
- 차도윤이 모의 강의 신청을 접수한다.
- 개편 과정 담당 강사 전원이 모의 강의에 참석해야 한다.
- 수강 운영 담당자가 모의 강의를 관찰한다.
- 모의 강의 초대장은 1차 수강명부를 기준으로 발송한다.

## 수강명부와 계정

- 차도윤이 12/04(금) 10:00에 1차 수강명부를 생성한다. 1차 수강명부 인원은 40명이다.
- 윤해솔이 12/11(금) 15:00에 4차 확정명부를 생성한다. 4차 확정명부 인원은 36명이다.
- 정식 연수 계정은 4차 확정명부를 기준으로 발급한다. 발급은 12/14(월) 11:00에 실행한다.
- 윤해솔이 12/14(월) 16:00에 수강 안내문을 발송한다.

## 시스템

| 시스템 | 개통 일시 | 담당 | 동시 접속 한도 |
|---|---|---|---|
| 배움연습 | 12/08(화) 13:00 | 차도윤 | 30명 |
| 배움운영 | 12/15(화) 09:00 | 윤해솔 | 120명 |

개통 승인 조건은 개편 과정 6개 모두 접속 시험을 통과하는 것이다.

확인 필요: 1차 수강명부 인원 40명이 배움연습 시스템 동시 접속 한도 30명보다 많다. 모의 강의 초대장을 1차 수강명부 40명 전원에게 발송하는지, 모의 강의에 동시에 접속하는 인원이 몇 명인지 확인이 필요하다.

## 접속 오류 신고

접속 오류는 연수준비 게시함에 신고한다. 신고에는 과정명, 계정명, 오류 발생 시각을 반드시 적어야 한다.
