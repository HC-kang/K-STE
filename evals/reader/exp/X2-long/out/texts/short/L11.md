# 푸른톱니제작 조립설비 교체 프로젝트 일정 공지 (묶음 번호 3)

푸른톱니제작 조립설비 교체 프로젝트의 일정을 공지한다. 독자는 조립라인 반장과 설비 정비 기사이다. 프로젝트 총괄은 고이든이고, 교체 구역은 새봄동 조립실이다.

## 전체 일정

| 일시 | 내용 | 담당 |
|---|---|---|
| 11/13(금) 12:00 | 외부 인증 정비조의 인증번호 등록 마감 | 외부 인증 정비조 |
| 11/13(금) 15:00 | 작업자 명단 제출 마감 | 설비일정 게시함에 제출 |
| 11/16(월) 09:00 | 일반 작업조 입실 교육 | |

| 11/17(화) 16:00 | 작업 변경 요청 마감 | 접수 남유찬 |
| 11/18(수) 10:00 | 교체 부품 12세트 반입 | |
| 11/18(수) 15:00 | 1단계 기준측정표 작성(측정 지점 8곳) | 남유찬 |

## 입실 교육

- 일반 작업조는 11/16(월) 09:00 입실 교육을 받는다.
- 외부 인증 정비조는 11/13(금) 12:00까지 인증번호를 등록하면 11/17(화) 14:00 별도 교육을 받는다.
- 인증번호를 등록하지 않은 정비조는 일반 작업조 입실 교육(11/16(월) 09:00)에 참석해야 한다.

## 작업자 명단과 작업 변경 요청

- 작업자 명단은 11/13(금) 15:00까지 설비일정 게시함에 제출해야 한다.
- 작업 변경 요청은 11/17(화) 16:00까지 남유찬에게 접수해야 한다.

## 부하 시험

- 부하 시험은 11/23(월) 10:00에 실행한다.
- 도세린이 부하 시험 계획서를 작성하고, 11/20(금) 16:00까지 제출한다.
- 진동 표시값이 7 이상이면 부하 시험 중단 기준에 해당한다.
- 중단한 부하 시험의 재개는 고이든이 승인한다.
- 부하 시험의 편차는 1단계 기준측정표와 비교한다.

## 측정표와 설비 인수

- 남유찬이 1단계 기준측정표를 작성한다.
- 도세린이 5단계 완료측정표를 작성한다.
- 5단계 완료측정표는 설비 인수 회의에 제출하는 자료이다.
- 고이든이 설비 인수를 승인한다.

## 현장 참관

조립라인별 현장 참관 인원은 반장 1명이다.

확인 필요: 부하 시험 계획서의 제출처가 메모에 없다. 제출처를 알려 주면 공지에 추가한다.
