# [사내 공지] 모렌픽셀 배포 승인·복구 규정 개편 안내 (묶음 2)

**수신:** 모렌픽셀 개발자, 배포 승인자, 서비스 운영 담당자
**발신:** (발신 부서/작성자 기재)
**문의:** 운영지원팀 윤해솔

---

## 1. 개편 개요

모렌픽셀 배포 승인·복구 규정이 개편되어 **11/16(월) 09:00부터** 적용됩니다. 이 문서는 변경된 승인 절차, 배포 서버 운영 기준, 백업·복구 기준, 결과 보고 기준, 권한 신청 및 교육 일정을 안내합니다.

## 2. 적용 범위

- **적용 대상:** 모렌픽셀 운영 서비스의 프로그램 배포와 설정 변경
- **적용 제외:** 개발자 개인 실습 환경 배포 (승인 규정 적용 제외)
- **배포 신청 시스템:** 릴리즈문

## 3. 배포 서버 운영 기준

| 구분 | 네온본선 (운영 배포 서버) | 네온예행 (검증 배포 서버) |
|---|---|---|
| 담당자 | 서도윤 | 서도하 |
| 배포 가능 시각 | 20:00~22:00 | 10:00~18:00 |
| 동시 배포 작업 상한 | 1건 | 3건 |

## 4. 배포 승인 기준

| 구분 | 일반 배포 | 긴급 장애 배포 |
|---|---|---|
| 승인권자 | 서비스 운영팀장 | - |
| 승인 필요 인원 | 2명 | 1명 |
| 신청 마감 | 배포 전 영업일 16:00 | - |
| 인정 조건 | - | 고객 접속 중단 15분 이상 |
| 필수 입력 | - | 신청 시 **장애 번호** 필수 입력 |

## 5. 백업 및 복구 기준

| 백업 이름 | 생성 시점 | 생성 책임자 | 보관 기간 | 용도 |
|---|---|---|---|---|
| **사전보관본** | 배포 준비 1단계 | 배포 실행 개발자 | 생성일부터 14일 | 배포 실패 시 복구 |
| **검증보관본** | 배포 확인 4단계 | 검증 담당자 | 생성일부터 7일 | 배포 성공 확인 시 비교 기준 |

## 6. 배포 결과 보고

| 구분 | 보고 마감 |
|---|---|
| 일반 배포 | 배포 종료 후 2시간 |
| 긴급 장애 배포 | 배포 종료 후 30분 |

- **첨부물:** 실행 로그, 승인 기록

## 7. 배포 권한 신청 및 교육

- **권한 신청서 제출처:** 릴리즈문 권한함
- **신청 마감:** 11/12(목) 17:00
- **권한 활성화:** 11/16(월) 09:00
- **교육 평가일:** 11/10(화) 14:00
- **수료 기준:** 실습 평가 80점 이상
- **유의 사항:** 교육 미수료자는 배포 실행 권한을 부여받을 수 없습니다.

## 8. 주요 일정 요약

| 일자 | 내용 |
|---|---|
| 11/05(목) 15:00 | 규정 설명회 (온라인 회의실 코드: **룸-픽셀**) |
| 11/10(화) 14:00 | 배포 권한 교육 평가 |
| 11/12(목) 17:00 | 배포 권한 신청 마감 |
| 11/16(월) 09:00 | 규정 적용 시작 및 배포 권한 활성화 |

## 9. 문의

규정 관련 문의는 **운영지원팀 윤해솔** 담당자에게 연락해 주시기 바랍니다.
