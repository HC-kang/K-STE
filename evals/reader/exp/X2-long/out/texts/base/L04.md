# 은솔기록 종이문서 디지털화 스캔 품질 관리 런북

**대상:** 묶음 1, 은솔기록 연말 종이문서 디지털화 검수자
**목적:** 스캔 품질 검수부터 고객 납품, 종이 원본 반출까지 일관된 절차로 수행한다.

---

| 역할 | 담당자 |
|---|---|
| 검수 총괄 | 민도윤 |
| 납품 승인 | 정라희 |
| 납품 목록 확정 | 정라희 |
| 납품 목록 제출 | 고은재 |
| 일반 문서 묶음 육안 검수 | 고은재 |
| 훼손 문서 묶음 육안 검수 | 민도윤 |
| 재스캔 파일 재검수 | 고은재 |
| 고객 저장소 업로드 | 배시우 |
| 스캔청 장비 담당 | 민도윤 |
| 스캔청보 장비 담당 | 고은재 |

## 2. 장비 정보

| 장비 | 담당자 | 교정일 | 일일 처리 상한 |
|---|---|---|---|
| 스캔청 | 민도윤 | 12/10(목) 09:00 | 800쪽 |

- 일일 처리 상한을 넘겨 배정하지 않는다.
- 교정일에는 해당 장비 담당자가 교정을 수행한다.

## 3. 주요 일정

| 일시 | 항목 | 담당 |
|---|---|---|
| 12/08(화) 15:00 | 납품 목록 제출 기한 | 고은재 |
| 12/09(수) 17:00 | 납품 목록 확정 기한 | 정라희 |
| 12/10(목) 09:00 | 스캔청 교정 | 민도윤 |
| 12/11(금) 10:00 | 스캔청보 교정 | 고은재 |
| 12/11(금) 18:00 | 납품 완료 보고 기한 | 배시우 업로드 결과 기반 |

- 납품 목록은 작업장부의 **겨울기록** 항목에 등록한다.

## 4. 묶음 분류

- **훼손 문서 묶음:** 찢김 또는 물얼룩이 있는 쪽이 **1쪽 이상** 포함된 묶음
- **일반 문서 묶음:** 위 조건에 해당하지 않는 묶음

## 5. 단계별 절차

### 1단계. 원본목록 작성
1. **스캔 시작 전에** 원본목록을 작성한다.
2. 기록 항목: **종이문서 식별번호**, **원본 쪽수**
3. 보관 기간: **60일**
4. 이 목록은 **종이 원본 쪽수 대조의 기준**이다.

### 2단계. 스캔
1. 장비별 일일 처리 상한을 지켜 스캔한다.
2. 파일명 **첫 부분**에 **묶음 식별번호**를 표기한다.

### 3단계. 육안 검수 및 재스캔

**육안 검수 비율과 담당**

| 구분 | 검수 비율 | 담당 |
|---|---|---|
| 일반 문서 묶음 | 묶음별 전체 쪽수의 **10%** | 고은재 |
| 훼손 문서 묶음 | 묶음별 전체 쪽수의 **100%** | 민도윤 |

- 일반 문서 묶음의 표본 쪽수 계산 결과에 소수점이 있으면 **올림**한다.
  - 예: 125쪽 → 12.5 → **13쪽** 검수

**재스캔**
1. **잘림** 또는 **초점 불량**을 발견하면 재스캔한다.
2. 재스캔 완료 파일은 **고은재가 재검수**한다.

### 4단계. 납품목록 작성
1. **재스캔과 검수가 모두 완료된 후** 작성한다.
2. 기록 항목: **최종 파일명**, **최종 파일 쪽수**
3. 보관 기간: **120일**
4. 이 목록은 **고객 전달 파일 구성 대조의 기준**이다.
5. 고은재가 12/08(화) 15:00까지 작업장부 겨울기록 항목에 제출하고, 정라희가 12/09(수) 17:00까지 확정한다.

## 6. 대조 기준

| 대조 대상 | 기준 문서 |
|---|---|
| 종이 원본 쪽수 | 1단계 원본목록 |
| 고객 전달 파일 구성 | 4단계 납품목록 |

### 쪽수 불일치 시
1. 해당 **묶음 전체의 납품을 보류**한다.
2. **민도윤에게 보고**한다.

## 7. 납품 및 업로드

1. 정라희의 **납품 승인 전에는 고객 저장소에 업로드하지 않는다.**
2. 승인 후 **배시우**가 고객 저장소에 업로드한다.

## 8. 납품 완료 보고

- **기한:** 12/11(금) 18:00
- **첨부물:**
  1. 업로드 결과표
  2. 4단계 납품목록

## 9. 종이 원본 반출

다음 **두 조건을 모두** 충족해야 반출할 수 있다.
1. 고객 수령 확인 완료
2. 정라희의 반출 승인 완료

하나라도 미충족이면 반출하지 않는다.
