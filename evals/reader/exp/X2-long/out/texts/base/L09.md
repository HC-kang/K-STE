# [공지] 묶음 3 · 누리결물류 배송 관제 전환 프로젝트 일정 안내

**수신:** 배송 관제 담당자, 물류센터 전산 담당자
**발신:** 프로젝트 총괄 서다온
**전환 대상 센터:** 솔빛센터, 달빛센터

---

## 1. 안내 요약

누리결물류 배송 관제 전환을 아래 일정으로 진행합니다. 담당자별 해야 할 일과 기한을 확인하시고, 특히 **연락망 제출(11/06)**, **배차 수정 중단 시각(11/12)**, **리허설 결과 제출(11/10)** 을 놓치지 않도록 유의해 주세요.

## 2. 전체 일정

| 일시 | 내용 | 담당/대상 |
|---|---|---|
| 11/06(금) 16:00 | 센터별 연락망 제출 기한 | 각 센터 (제출처: 관제지원 게시함) |
| 11/09(월) 14:00 | 전환 리허설 실행 | 센터별 전산 담당자 |
| 11/10(화) 12:00 | 전환 리허설 결과 제출 기한 | 센터별 전산 담당자 |
| 11/10(화) 20:00 | **관제검증 서버 전환** | 담당: 백시온 |
| 11/11(수) 19:00 | 1단계 원본백업 생성 | 담당: 문하린 |
| 11/12(목) 15:00 | 배송 이력 표본 대조 | 센터별 60건 |
| 11/12(목) 18:00 | 일반 배송 노선 배차 수정 중단 | 전체 |
| 11/12(목) 21:00 | 긴급 의약 노선 배차 수정 중단 | 전체 (예외 조건은 4항 참고) |
| 11/12(목) 22:00 | **관제운영 서버 전환** | 담당: 문하린 |
| 11/13(금) 03:00 | 4단계 안정화백업 생성 | 담당: 백시온 |
| 11/16(월) 10:00 | 안정화 종료 점검 | 종료 승인: 서다온 |

## 3. 서버 전환 안내

| 구분 | 전환 일시 | 담당 | 예상 조회 중단 | 접속 확인 참여자 |
|---|---|---|---|---|
| 관제검증 서버 | 11/10(화) 20:00 | 백시온 | 15분 | 센터별 전산 담당자 1명 |
| 관제운영 서버 | 11/12(목) 22:00 | 문하린 | 40분 | 모든 배송 관제 담당자 |

조회 중단 시간은 예상치이며, 해당 시간 동안에는 배송 조회가 어려울 수 있습니다. 사전에 업무 일정을 조정해 주세요.

## 4. 배차 수정 중단 규칙

- **일반 배송 노선:** 11/12(목) 18:00부터 배차 수정이 중단됩니다.
- **긴급 의약 노선:** 11/12(목) 21:00부터 배차 수정이 중단됩니다.
  - 이 예외는 **서다온 승인번호 등록이 완료된 노선**에만 적용됩니다.
  - **승인번호가 없는 의약 노선**은 일반 배송 노선 수정 중단 규칙(11/12 18:00)이 적용됩니다.

긴급 의약 노선 담당자는 11/12 18:00 이전에 승인번호 등록이 완료되었는지 반드시 확인해 주세요.

## 5. 사전 준비 사항

1. **연락망 제출 (각 센터):** 11/06(금) 16:00까지 센터별 연락망을 **관제지원 게시함**에 제출해 주세요.
2. **전환 리허설 (센터별 전산 담당자):** 11/09(월) 14:00에 리허설을 실행하고, 11/10(화) 12:00까지 결과를 제출해 주세요.

## 6. 백업 및 복구 기준

| 구분 | 생성 일시 | 담당 | 보관 기간 | 사용 목적 |
|---|---|---|---|---|
| 1단계 원본백업 | 11/11(수) 19:00 | 문하린 | 14일 | 전환 실패 시 복구 입력물 |
| 4단계 안정화백업 | 11/13(금) 03:00 | 백시온 | 7일 | 정상 전환 후 이력 감사 입력물 |

## 7. 전환 성공 판정

- 11/12(목) 15:00에 센터별 배송 이력 표본 **60건**을 대조합니다.
- **표본 60건이 전부 일치**해야 전환 성공으로 판정합니다.
- 전환에 실패하면 1단계 원본백업으로 복구합니다.

## 8. 장애 신고

전환 중 또는 전환 이후 장애가 발생하면 **관제지원 게시함**으로 신고해 주세요.

**필수 기재 항목:** 센터명, 노선번호, 발생 시각

## 9. 안정화 종료

11/16(월) 10:00에 안정화 종료 점검을 진행하며, 종료 승인은 프로젝트 총괄 서다온이 담당합니다.

문의 사항은 관제지원 게시함 또는 프로젝트 총괄 서다온에게 남겨 주세요.
