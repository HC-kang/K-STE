# 세리온러닝 상담 기록·품질 검토 규정 개편 안내

**수신:** 세리온러닝 상담 직원, 상담 품질 평가자, 고객지원 교대 관리자
**발신:** 상담정책팀
**시행일:** 12월 14일(월) 09:00

## 1. 개편 개요

세리온러닝 상담 기록·품질 검토 규정이 개편되어 **12월 14일(월) 09:00**부터 시행됩니다. 적용 대상은 세리온러닝 **전화 상담과 채팅 상담**입니다. 자동응답만으로 끝난 상담은 수동 요약 작성 의무에서 제외됩니다.

## 2. 주요 일정

| 일시 | 내용 |
|---|---|
| 12/08(화) 13:00 | 규정 실습 교육 |
| 12/10(목) 18:00 | 관리함 권한 전환 신청 마감 |
| 12/14(월) 09:00 | 관리함 권한 전환 실행 및 새 규정 시행 |

## 3. 시스템과 관리함

- **상담 기록 시스템:** 케이스온
- **당일 상담 기록 관리함:** 상담원장함 (관리 담당자: 문서연)
- **품질 평가 자료 관리함:** 상담평가함 (관리 담당자: 문서윤)

### 열람 권한 유효 기간

| 관리함 | 유효 기간 |
|---|---|
| 상담원장함 | 승인일부터 30일 |
| 상담평가함 | 승인일부터 7일 |

### 권한 전환 신청

- 접수처: **케이스온 권한창구**
- 마감: **12/10(목) 18:00**
- 전환은 12/14(월) 09:00에 실행되므로, 마감 전에 반드시 신청해 주세요.

## 4. 기록 생성 절차

| 기록 | 생성 시점 | 생성 담당자 | 비고 |
|---|---|---|---|
| **원문기록** | 상담 종료 1단계 | 상담 직원 | 상담 내용 정정 확인 시 대조 기준 |
| **가림기록** | 품질 검토 준비 3단계 | 상담 품질 평가자 | 고객 이름과 연락처를 가림 처리. 상담 교육 사례 발표에 사용 |

### 보관 기간

| 기록 | 보관 기간 |
|---|---|
| 원문기록 | 상담 종료일부터 60일 |
| 가림기록 | 상담 종료일부터 120일 |

## 5. 상담 요약 작성

### 필수 항목
1. 고객 요청
2. 답변 내용
3. 후속 조치

### 작성 기한

| 구분 | 기한 |
|---|---|
| 일반 상담 | 상담 종료 후 **2시간** |
| 분쟁 예고 상담 | 상담 종료 후 **20분** |

### 분쟁 예고 상담
- **분류 조건:** 고객이 외부 조정 신청 의사를 명시한 경우
- 분쟁 예고 상담은 **교대 관리자의 검토가 필수**입니다.

### 완료 처리 제한
후속 조치 담당자가 정해지지 않은 상담은 **완료 상태로 변경할 수 없습니다.**

## 6. 품질 검토

- **일반 상담 품질 표본 추출:** 상담 직원당 주 3건
- **재검토 신청 기한:** 결과 통지 후 3영업일
- **재검토 처리 기한:** 접수 후 5영업일

## 7. 케이스온 장애 시 대응

1. 케이스온 장애 시 **임시상담표**를 작성합니다.
2. 케이스온 복구 후 **1시간 이내**에 임시상담표를 등록합니다.

## 8. 역할별 확인 사항

**상담 직원**
- 상담 종료 1단계에서 원문기록 생성
- 요약 필수 항목 3가지 작성, 기한 준수(일반 2시간, 분쟁 예고 20분)
- 후속 조치 담당자 지정 후 완료 처리

**상담 품질 평가자**
- 품질 검토 준비 3단계에서 가림기록 생성(고객 이름·연락처 가림 처리)
- 상담평가함 열람 권한 유효 기간(7일) 확인
- 재검토 신청 처리 기한(접수 후 5영업일) 준수

**고객지원 교대 관리자**
- 분쟁 예고 상담 검토
- 후속 조치 담당자 미지정 상담의 완료 처리 여부 확인
- 팀원의 권한 전환 신청 마감(12/10 18:00) 안내
