# 묶음 4 장애 회고: 수강 완료 표시 지연 (12/02)

**대상 독자:** 강좌 운영 매니저, 수강생 상담 담당자
**회사/영역:** 새결러닝 / 기업용 온라인 교육
**배포 예정:** 12/11(금), 배포 담당 노다인

## 1. 요약

12/02(수) 13:06부터 14:18까지 약 72분 동안 수강생의 **수강 완료 표시가 지연**되었습니다. 수강생 640명, 강좌 18개가 영향을 받았습니다. **영상 재생과 시험 답안 저장은 정상 운영**되어 학습 내용이나 제출한 답안이 유실되지는 않았습니다.

원인은 12:50에 배포한 진도 이벤트 형식 변경입니다. 이 변경으로 완료 상태 필드 이름이 바뀌었는데, 집계 모듈이 이전 필드 이름만 읽어 완료 이벤트 처리에 실패했습니다.

## 2. 영향 범위

| 항목 | 내용 |
|---|---|
| 영향 수강생 | 640명 |
| 영향 강좌 | 18개 |
| 영향 내용 | 수강 완료 표시 지연 |
| 영향 없음 | 영상 재생, 시험 답안 저장 |
| 정상화 후 수료 결과 | 620건 |
| 미수료 유지 | 20명 (필수 시험 미제출) |

미수료 20명은 이번 장애 때문이 아니라 필수 시험을 제출하지 않았기 때문입니다. 정상화 후에도 미수료 상태가 유지됩니다.

## 3. 원인

- 12/02(수) 12:50에 진도 이벤트 형식 변경이 배포되었습니다.
- 이 변경으로 **완료 상태 필드 이름**이 바뀌었습니다.
- 집계 모듈은 **이전 필드 이름만** 읽었기 때문에 완료 이벤트를 처리하지 못했습니다.
- 이 상태에서 두 집계 작업이 계속 실행되었습니다.
  - 진도집계-실시간: 3분 간격, 담당 한서율
  - 진도집계-야간: 30분 간격, 담당 차온재

## 4. 타임라인 (12/02, 수)

| 시각 | 사건 |
|---|---|
| 12:50 | 진도 이벤트 형식 변경 배포 |
| 13:06 | **장애 시작**: 수강 완료 표시 지연 |
| 13:12 | 수강생 최초 상담 접수 |
| 13:16 | 1단계: 진도 원장 생성 |
| 13:20 | 진도집계-실시간 작업 중단 |
| 13:28 | 집계 모듈 수정 배포 |
| 13:35 | 진도집계-야간 작업 중단 |
| 13:42 | 완료 이벤트 재처리 시작 |
| 14:18 | **장애 종료**: 수강 완료 표시 정상화 |
| 14:30 | 4단계: 수료 검증표 생성 |

장애 시작 후 6분 만에 첫 상담이 접수되었습니다. 상담 담당자는 이 시점부터 수강생 문의를 받았습니다.

## 5. 대응 체계

- **장애 지휘:** 차온재
- **수강생 공지:** 노다인
- **복구 선언 조건:** 점검 계정 12개에서 수강 완료 표시가 일치할 것

## 7. 수료증 발급 규칙

수료증은 두 가지 경로로 발급합니다. 상담 시 수강생 상황에 맞게 안내해 주세요.

| 구분 | 일반 수료증 | 당일 제출 수료증 (예외) |
|---|---|---|
| 조건 | 진도 복구 후 | 답안 저장 확인 후 |
| 승인 | 운영 매니저 | 교육 책임자 |
| 승인 담당 | 노다인 | 류해준 |
| 성격 | 정식 발급 | 임시 발급 |

**주의:** 임시 수료증을 받은 수강생은 정식 수료증을 받은 뒤 **임시 수료증을 반드시 폐기**해야 합니다. 정식 수료증 안내 시 함께 전달해 주세요.

## 8. 수강생 보상과 일정

- 연장 적용 완료 기한은 **12/04(금)** 입니다.

## 11. 운영 매니저·상담 담당자 확인 사항

1. 학습 기간 2일 연장이 12/04(금)까지 적용되었는지 확인합니다.
2. 미수료 20명은 필수 시험 미제출이 사유임을 안내합니다.
3. 일반 수료증과 당일 제출 임시 수료증의 승인 경로를 구분해 안내합니다.
4. 임시 수료증 수신자에게 정식 수료증 수신 후 폐기하도록 안내합니다.
5. 기업 고객 담당자 문의는 류해준에게 연결합니다.
