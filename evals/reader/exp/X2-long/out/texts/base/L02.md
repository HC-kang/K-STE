# 다온냉장 물류센터 연말 냉장품 입고 운영 절차 (런북)

**대상:** 입고 반장
**목적:** 연말 냉장품 입고를 동일한 순서와 기준으로 처리하고, 기록으로 대기료 산정과 재고 반영 승인의 근거를 남긴다.

---

## 1. 역할과 담당자

| 역할 | 담당자 |
|---|---|
| 입고 총괄 | 강무진 |
| 품질 판정 | 오세나 |
| 북문 입고대 담당 | 강무진 |
| 북측 입고대 담당 | 윤가람 |
| 차량 명단 제출 | 윤가람 |
| 차량 명단 확정 | 강무진 |
| 정상 봉인 화물 온도 측정 | 윤가람 |
| 훼손 봉인 화물 온도 측정 | 오세나 |
| 입고 승인 화물 재고 반영 | 진우람 |

## 2. 입고대 운영 기준

| 구분 | 북문 입고대 | 북측 입고대 |
|---|---|---|
| 시범 가동 | 12/03(목) 08:00 | 12/04(금) 09:00 |
| 담당자 | 강무진 | 윤가람 |
| 동시 하역 상한 | 3대 | 5대 |

동시 하역 상한을 넘겨 차량을 투입하지 않는다.

## 3. 사전 준비

### 3.1 차량 명단
1. **제출:** 12/01(화) 16:00까지 윤가람이 입고장부의 **연말시범** 항목에 제출한다.
2. **확정:** 12/02(수) 11:00까지 강무진이 확정한다.

### 3.2 온도계 점검 (매일)
- 매일 **07:30**에 오세나가 점검한다.
- 점검에 실패하면 **오세나의 승인을 받은 뒤에** 예비 온도계를 사용한다. 승인 전에는 사용하지 않는다.

## 4. 차량 입고 절차

### 1단계. 도착표 작성
- **시점:** 차량 도착 직후
- **기록 항목:** 차량번호, 도착 시각
- **보관 기간:** 14일
- 이 도착 시각이 **차량 대기료 산정의 근거**가 된다.

### 2단계. 봉인 검사
- **시점:** 하역 시작 전에 완료한다.
- 봉인 상태에 따라 화물을 분류한다.
  - **훼손 봉인:** 봉인띠 절단 **또는** 봉인번호 불일치
  - **정상 봉인:** 위에 해당하지 않는 화물

### 3단계. 온도 측정

| 구분 | 표본 | 담당자 |
|---|---|---|
| 정상 봉인 | 팔레트마다 2상자 | 윤가람 |
| 훼손 봉인 | 팔레트마다 6상자 | 오세나 |

- 측정값이 **7도 초과**이면 품질 판정 전까지 **격리**한다.

### 4단계. 판정표 작성
- **시점:** 오세나의 품질 판정 직후
- **기록 항목:** 입고 승인 여부, 격리 사유
- **보관 기간:** 30일
- 이 판정표가 **재고 반영 승인 여부의 근거**가 된다.

## 5. 격리 구역 (Q-8)

- 최대 수용량: **18팔레트**
- 수용량 초과가 **예상되면** 추가 하역을 중단하고 강무진에게 연락한다. 초과가 발생할 때까지 기다리지 않는다.

## 6. 재고 반영

- 입고 승인된 화물만 진우람이 재고에 반영한다.
- 승인 여부는 4단계 판정표를 근거로 한다.

## 7. 일일 보고

- **마감:** 매일 18:00
- **첨부물:** 4단계 판정표 사본

## 8. 기록 정정 규칙

차량번호 오기를 수정할 때는 다음을 모두 지킨다.
1. **원문을 보존**한다. 지우거나 덮어쓰지 않는다.
2. **수정자 이름을 기록**한다.
