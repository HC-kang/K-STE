# 모루물류 장애 회고: 출고 라벨 출력 정지 (묶음 4)

**대상 독자:** 야간 출고 관리자, 재고 운영 담당자
**업무 영역:** 생활용품 창고 출고
**배포일:** 11/20(금), 배포 담당 서나겸

## 1. 요약

11/10(화) 21:50 라벨 양식 배포에 글꼴 경로 오류가 섞여 들어왔습니다. 출력 프로세스는 글꼴 로딩에 실패한 뒤 작업 잠금을 해제하지 못했고, 22:08에 출고 라벨 출력이 멈췄습니다. 라벨 양식 롤백과 작업 잠금 수동 해제를 거쳐 23:02에 정상 출력을 확인했습니다.

## 2. 원인

- **직접 원인:** 11/10(화) 21:50 라벨 양식 배포에서 글꼴 경로 오류가 유입되었습니다.
- **증상 확대:** 출력 프로세스가 글꼴 로딩 실패 후 작업 잠금을 해제하지 못해, 출력 작업이 계속 막혔습니다.
- **탐지 지연:** 작업 잠금을 수집하는 지표가 없어 자동 경보가 발생하지 않았습니다. 최초 인지는 현장 신고였습니다.

**출고 재개 규칙:** 두 경우 모두 재고 대조를 먼저 완료해야 합니다.

| 구분 | 재개 조건 | 승인 담당 |

- 미출고 잔여 주문 20건은 고객 취소 요청으로 출고에서 제외했습니다. 780건 중 760건이 재출력되고 20건이 취소되어 합계가 일치합니다.
