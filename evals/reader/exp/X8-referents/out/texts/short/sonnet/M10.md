# 누리펄스 캐시 전환 런북

## 개요

- 이 문서는 누리펄스 야간 서비스 운영 당직자가 캐시 전환 작업에 사용하는 운영 절차 묶음 4의 런북이다.
- 캐시 갱신이 지연되어 검색 결과 누락이 발생했다.
- 작업 일시는 11/12(목) 23:10 시작, 23:40 종료이다.
- 실행 담당은 야간 당직자 문세린이다.
- 작업 대상은 검색 캐시와 추천 캐시이다.
- 작업 위치는 사내 운영 포털의 검색 탭과 추천 탭이다. 검색 캐시는 검색 탭에서, 추천 캐시는 추천 탭에서 작업한다.

## 대기 인원

- 제품 관리자 나도윤은 작업 시간 동안 사내 메신저에서 대기한다.
- 프로젝트 관리자 서이안은 작업 시간 동안 사내 메신저에서 대기한다.

## 전환 전 절차

1. 문세린은 검색 캐시와 추천 캐시 모두 전환 전 오류율을 5분간 측정해야 한다.
2. 문세린은 측정한 전환 전 오류율을 작업 기록에 남겨야 한다.
3. 문세린은 전환 직전 스냅샷 1개를 추가로 저장해야 한다.
4. 문세린은 23:20에 복원 지점 2개를 등록해야 한다.
5. 복원 지점 등록 후 문세린은 되돌림 데스크에 23:20에 등록한 복원 지점 2개가 보이는지 표시 개수를 대조해야 한다.

## 서버 상태 조회와 재시작

- 검색 로그 서버와 추천 로그 서버는 별도 장비이다.
- 두 서버의 상태는 운영 포털의 장비 탭에서 조회한다.
- 서버 재시작은 문세린의 승인 후에만 할 수 있다.

## 복원 작업 화면

- 캐시 복원 작업의 실행 화면은 1개만 사용해야 한다.
- 정식 화면명은 복원 제어판이다.

## 전환 후 판정

1. 전환 후 오류율이 2%를 초과하면 즉시 복원해야 한다.
2. 전환 후 오류율이 2% 이하이면 복원하지 않고 관찰을 유지한다.
3. 오류율이 2% 이하인 경우 후속 점검은 11/13(금) 09:00에 한다.

## 장애 시 연락

- 오류율을 조회할 수 없거나 복원이 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.

## 작업 종료

- 작업 기록은 운영 포털의 야간 작업함에 저장한다.
- 전환 완료 보고서는 PM에게 전달해야 한다.
- 보고서를 PM에게 전달하기 전에는 당직을 교대하면 안 된다.

## 확인 필요

- 전환 직전 스냅샷 1개는 검색 캐시와 추천 캐시 각각 1개인지, 두 캐시를 합쳐 1개인지 확인 필요: 원문이 "그건 전환 직전 스냅샷 1개 추가 저장 필수"로 되어 있고 "그건"이 가리키는 대상이 없다.
- 되돌림 데스크와 복원 제어판이 같은 화면인지 다른 화면인지 확인 필요: 원문에 두 이름이 모두 나온다.
- 전환 후 오류율 2% 기준을 검색 캐시와 추천 캐시 각각에 적용하는지, 합산에 적용하는지 확인 필요.
- 전환 후 오류율을 몇 분간, 어느 시점에 측정하는지 확인 필요.
- 전환 완료 보고서를 받는 PM이 서이안인지 확인 필요.
- 11/13(금) 09:00 후속 점검의 담당자 확인 필요.
