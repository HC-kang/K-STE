이 런북은 야간 당직자 문세린이 2026년 11월 12일(목) 23:10부터 23:40까지 검색 캐시와 추천 캐시를 전환하는 절차를 정한다. 캐시(자주 쓰는 데이터를 임시로 저장해 두는 공간)를 전환하는 동안 나도윤과 서이안은 사내 메신저에서 대기한다.

## 1. 작업 개요

- 작업명: 누리펄스 캐시 전환
- 일시: 11/12(목) 23:10 시작, 23:40 종료
- 실행 담당: 야간 당직자 문세린
- 작업 대상: 검색 캐시, 추천 캐시
- 작업 위치: 사내 운영 포털의 검색 탭과 추천 탭. 각 캐시는 해당 탭에서 각각 작업한다.

**주의: 캐시 갱신이 지연되면 검색 결과 누락이 발생한다.**

## 2. 사전 준비

1. 문세린은 검색 캐시와 추천 캐시 모두에 대해 전환 전 오류율(요청이 실패한 비율)을 5분간 측정한다.
2. 문세린은 측정한 오류율을 작업 기록에 남겨야 한다.
3. 확인 필요: 원문 "그건 전환 직전 스냅샷 1개 추가 저장 필수"에서 "그건"이 가리키는 대상이 불분명하다. 스냅샷(특정 시점의 상태를 저장한 사본) 1개가 검색 캐시와 추천 캐시 중 어느 쪽에 대한 것인지, 또는 두 캐시 모두에 대한 것인지 알려 주세요.
4. 검색 로그 서버와 추천 로그 서버는 별도 장비다. 두 서버의 상태는 운영 포털의 장비 탭에서 조회한다.

## 3. 작업 절차

1. 문세린은 23:10에 작업을 시작한다.
2. 문세린은 23:20에 복원 제어판에서 복원 지점 2개를 등록한다. 복원 제어판은 캐시 복원 작업에서 사용하는 유일한 실행 화면이며, 다른 화면에서 복원 작업을 하면 안 된다.
3. 문세린은 되돌림 데스크에 복원 지점 2개가 표시되는지 개수를 대조해야 한다.
4. 확인 필요: 되돌림 데스크에 표시되는 복원 지점 개수가 2개와 다를 때의 조치가 원문에 없다. 이 경우 어떻게 해야 하는지 알려 주세요.
5. 문세린은 검색 캐시와 추천 캐시를 전환한다.
6. 문세린은 전환 후 오류율을 조회한다. 확인 필요: 전환 후 오류율을 조회할 화면과 조회 시점이 원문에 없다.
7. 서버 재시작은 문세린의 승인 후에만 진행한다. 승인 없이 재시작하면 안 된다.
8. 문세린은 23:40에 작업을 종료한다.

## 4. 전환 후 판단

전환 후 오류율에 따라 다음과 같이 조치한다.

| 전환 후 오류율 | 조치 |
|---|---|
| 2% 초과 | 즉시 복원해야 한다. |
| 2% 이하 | 복원하지 않고 관찰을 유지한다. |

## 5. 장애 대응과 기록

1. 오류율 조회가 불가능하거나 복원이 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.
2. 작업 기록은 운영 포털의 야간 작업함에 저장한다.
3. 전환 완료 보고서는 PM에게 전달한다. 확인 필요: 원문의 "PM"이 나도윤과 서이안 중 누구를 가리키는지 알려 주세요.
4. 보고서를 PM에게 전달하기 전에는 당직 교대를 하면 안 된다.
