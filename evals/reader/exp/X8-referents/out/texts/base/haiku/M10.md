# 누리펄스 야간 운영 런북: 캐시 전환 (운영 절차 묶음 4)

| 항목 | 내용 |
|---|---|
| 작업명 | 누리펄스 캐시 전환 |
| 작업 일시 | 2026-11-12(목) 23:10 시작 ~ 23:40 종료 |
| 실행 담당 | 야간 당직자 문세린 |
| 작업 대상 | 검색 캐시, 추천 캐시 |
| 작업 위치 | 사내 운영 포털 **검색 탭**, **추천 탭** (각각) |
| 복원 실행 화면 | **복원 제어판** (1개만 사용) |
| 보고 대상 | 제품 관리자 나도윤, 프로젝트 관리자 서이안 (작업 시간 동안 사내 메신저 대기) |
| 긴급 연락 | 플랫폼지원팀 윤하민, 내선 **4726** |

---

## 1. 작업 배경 및 목적

- 캐시 갱신 지연으로 **검색 결과 누락**이 발생할 수 있어 캐시 전환을 수행한다.
- 검색 캐시와 추천 캐시 모두 **전환 전후 오류율**을 측정하고 작업 기록에 남긴다.

---

## 2. 역할 및 책임

| 역할 | 담당 | 주요 책임 |
|---|---|---|
| 실행 담당 | 문세린 (야간 당직) | 스냅샷 저장, 복원 지점 등록, 캐시 전환, 오류율 측정, 기록 작성 |
| 승인자 | 문세린 | 서버 재시작 승인 (재시작은 승인 후에만 진행) |
| 대기자 | 나도윤 (제품 관리자), 서이안 (프로젝트 관리자) | 작업 시간 동안 사내 메신저 대기 |
| 비상 지원 | 윤하민 (플랫폼지원팀) | 오류율 조회 불가 또는 복원 실패 시 즉시 지원 (내선 4726) |

---

## 3. 사전 점검 (23:10 이전)

- [ ] 사내 운영 포털 접속 및 **검색 탭**, **추천 탭** 접근 확인
- [ ] **장비 탭**에서 검색 로그 서버, 추천 로그 서버 상태 확인 (두 서버는 별도 장비임)
- [ ] 나도윤, 서이안 사내 메신저 대기 상태 확인
- [ ] 윤하민 내선 4726 연락 가능 여부 확인
- [ ] 복원 제어판 접근 가능 여부 확인

---

## 4. 작업 절차 (타임라인)

| 시각 | 단계 | 수행 내용 | 확인 |
|---|---|---|---|
| 23:10 | 작업 시작 | 작업 시작을 작업 기록에 남기고, 대기자에게 시작 사실 공지 | ☐ |
| 23:10~23:15 | **전환 전 오류율 측정** | 검색 캐시와 추천 캐시 각각 **5분간** 오류율 측정, 작업 기록에 저장 | ☐ |
| 23:15~23:19 | **전환 직전 스냅샷 저장** | 전환 직전 스냅샷 **1개 추가 저장** (필수) | ☐ |
| 23:20 | **복원 지점 등록** | 문세린이 복원 제어판에서 복원 지점 **2개** 등록 | ☐ |
| 23:20 | **되돌림 데스크 확인** | 되돌림 데스크에 복원 지점이 **2개** 표시되는지 대조 | ☐ |
| 23:20 이후 | **캐시 전환 실행** | 검색 탭, 추천 탭에서 각각 캐시 전환 수행 | ☐ |
| 전환 직후 | **서버 상태 확인** | 장비 탭에서 검색 로그 서버, 추천 로그 서버 상태 확인 | ☐ |
| 전환 후 | **전환 후 오류율 측정** | 검색 캐시, 추천 캐시 오류율 조회 및 기록 | ☐ |
| 전환 후 | **판정 및 조치** | 4.1 판정 기준에 따라 복원 또는 관찰 유지 결정 | ☐ |
| 23:40 | 작업 종료 | 전환 완료 보고서 작성, PM 전달 | ☐ |

### 4.1 판정 기준 (전환 후 오류율)

| 조건 | 조치 |
|---|---|
| 오류율 **2% 초과** | **즉시 복원** (복원 제어판 사용, 필수) |
| 오류율 **2% 이하** | **복원하지 않고** 관찰 유지 |
| 오류율 조회 불가 **또는** 복원 실패 | **즉시** 윤하민(내선 4726)에게 연락 |

### 4.2 서버 재시작 규칙

- 서버 재시작은 **문세린 승인 후에만** 진행한다.
- 승인 사실(승인 시각, 대상 서버)을 작업 기록에 남긴다.

---

## 5. 복원 절차 (필요 시)

1. 복원 제어판을 연다. (실행 화면은 이 1개만 사용)
2. 23:20에 등록한 복원 지점 2개 중 대상을 선택한다.
3. 검색 캐시와 추천 캐시 각각 복원을 실행한다.
4. 복원 결과를 확인하고 작업 기록에 남긴다.
5. 복원이 실패하면 즉시 윤하민(내선 4726)에게 연락한다.

---

## 6. 인수인계 및 보고

- **당직 교대 금지**: 전환 완료 보고서가 PM에게 전달되기 전까지 당직 교대를 하지 않는다.
- **전환 완료 보고서**: 작업 기록을 바탕으로 작성하여 PM에게 전달한다.
- **작업 기록 저장**: 모든 기록(오류율 측정값, 스냅샷, 복원 지점 대조 결과, 재시작 승인, 판정 결과)을 **운영 포털의 야간 작업함**에 저장한다.

- 전환 후 캐시 상태와 검색 결과 누락 여부를 확인하고 결과를 기록한다.

## 9. 확인 필요 사항

원문에 명시되지 않아 실행 전 담당자 확인이 필요한 항목입니다.

1. **전환 후 오류율 측정 시간**: 전환 후 몇 분간 측정하는지 지정되어 있지 않습니다.
2. **캐시 전환 실행 정확한 시각**: 23:20 이후 어느 시점에 실행하는지 정해져 있지 않습니다.
3. **"그건 전환 직전 스냅샷 1개 추가 저장 필수"의 의미**: 원문 표현이 불명확하여 전환 직전 스냅샷 1개를 추가로 저장하는 단계로 해석했습니다. 다르면 수정이 필요합니다.
4. **사전 측정 시간 배치**: 23:10 시작 후 측정(23:10~23:15)과 스냅샷(23:15~23:19)의 배치는 순서 편의상 정한 안입니다. 필요 시 조정하세요.
5. **작업 종료 시각(23:40) 내 완료 가능 여부**: 전환 후 측정과 판정, 보고서 작성을 23:40 안에 마칠 수 있는지 검토가 필요합니다.
