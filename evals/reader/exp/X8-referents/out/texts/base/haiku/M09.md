# 다솜결교육 겨울 과정 운영 3차 회의록

| 항목 | 내용 |
|---|---|
| 일시 | 12/03(목) 10:00~10:40 |
| 장소 | 본사 모아실 |
| 진행 | 교육운영팀 한여울 |
| 참석 | 교육운영팀 팀장 정해온, 시설지원팀 팀장 유다빈 |
| 대상 | 지역 교육장 책임자 전원 (배포용) |

---

## 1. 접수 변경 사항

- **변경 대상 반:** 신규 수강생 반, 재등록 수강생 반
- **접수 방식:** 두 반 모두 온라인 신청과 현장 신청을 병행합니다.
- **신분 확인:** 12/07(월) 개강일부터 수업 시작 10분 전까지 신분 확인을 완료해야 합니다.

## 2. 역할 분담

| 팀 | 담당 업무 |
|---|---|
| 교육운영팀 | 출석 관리 |
| 시설지원팀 | 강의실 배정 |
| 고객지원팀 | 접수 오류 상담 |
| 고객성공팀 | 수강 유지 상담 |

고객지원팀과 고객성공팀은 모두 교육장의 문의를 접수할 수 있습니다.

## 3. 강의실 정원 기준

- **일반 강의실:** 상한 18명
- **실습실:** 시설지원팀이 승인한 실습실에 한해 상한 12명
- **정원 조정 사유:** 12/01(화) 모의 수업에서 통로 막힘이 3건 발생했습니다.
- **필수 조건:** 개강 전까지 비상 통로 폭 1.2m 이상을 확보해야 합니다.

## 4. 제출 및 등록 기한

| 기한 | 대상 | 내용 |
|---|---|---|
| 12/04(금) 12:00 | 교육장 책임자 | 개강 당일 상담 인원 요청을 CS팀에 전달 |
| 12/04(금) 16:00 | 교육장 책임자 | 교육장별 좌석 배치도 1부를 팀장(정해온)에게 제출 |
| 12/04(금) 09:00 | 서노을 (교육운영팀) | 출석 집계표(눈꽃장부) 운영 게시판 배포 |
| 12/04(금) 17:00 | 지역 교육장 책임자 전원 | 강의실별 정원을 운영 게시판에 등록 |

> **주의:** 눈꽃장부는 서노을이 12/04(금) 09:00에 운영 게시판에 올리는 **입력란 7개짜리 공식 양식**만 사용합니다. 개인 수정본은 사용할 수 없습니다.

## 5. 문의처

- **정원 입력 및 출석 양식:** 교육운영팀 서노을
- **연락 채널:** 사내 메신저 **겨울운영** 채널

---

**요약 체크리스트 (교육장 책임자용)**

- [ ] 12/04(금) 12:00까지 개강 당일 상담 인원 요청을 CS팀에 전달
- [ ] 12/04(금) 16:00까지 좌석 배치도 1부 제출 (정해온 팀장)
- [ ] 12/04(금) 17:00까지 강의실별 정원 등록 (운영 게시판, 상한 18명 / 승인 실습실 12명)
- [ ] 개강 전 비상 통로 폭 1.2m 이상 확보
- [ ] 출석 집계표는 공식 양식(눈꽃장부)만 사용
- [ ] 12/07(월)부터 수업 시작 10분 전까지 신분 확인 완료
