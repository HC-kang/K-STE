# 출고 파동 조정: 긴급 주문 피킹 대기열 적체 수정

- **개발 담당:** 배시온
- **대상 독자:** 창고 운영 책임자, 물류 서비스 QA 담당자
- **적용 환경:** 서부 시험창고 운영 포털

## 1. 배경 및 목적

출고 파동 조정 과정에서 피킹 대기열에 긴급 주문이 밀려 처리가 늦어지는 문제가 있었습니다. 이번 PR은 긴급 주문이 먼저 배치되도록 피킹 순서와 포장 대기 흐름을 수정합니다.

## 2. 주요 변경 사항

- **피킹 순서 화면 변경:** 긴급 주문을 우선 배치합니다. 예약 출고 주문은 우선 배치에서 제외합니다.
- **포장 대기 화면 변경:** 포장 묶음 기준을 적용합니다.
- **묶음 상한:**
  - 피킹 묶음 상한: **80건**
  - 포장 묶음 상한: **50건**
  - 상한을 초과한 주문은 **다음 묶음으로 이동**합니다.

## 3. 일정

| 구분 | 일시 |
|---|---|
| QA 결과 등록 기한 | 11/18(수) 16:00 |
| 시험 적용 | 11/19(목) 09:00 |

## 4. 배포 환경

- 시험창고 서버와 교육창고 서버에 **같은 버전**을 설치합니다.
- **시험창고 서버:** 실물 스캐너를 연결합니다.
- **교육창고 서버:** 모의 입력을 사용합니다.
