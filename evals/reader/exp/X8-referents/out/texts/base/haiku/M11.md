# 냉장 출고 장애 대응 런북 (운영 절차 묶음 4)

**대상:** 모래빛식품 동부 물류센터 새벽 출고 작업자
**점검일:** 2026년 12월 3일(목) 05:30 ~ 06:10
**현장 실행 담당:** 배유솔
**문서 상태:** 초안

---

## 1. 목적

전날 출고 시 온도 기록이 누락되었다. 이에 따라 냉장 대기구역과 냉장 상차구역의 온도를 출고 전에 정확히 측정·기록하고, 기준을 넘은 상자는 출고를 보류하도록 한다. 보류 상자 목록은 고객 문의에 대응할 수 있도록 CS팀에 전달한다.

## 2. 적용 범위

| 구역 | 위치 |
|---|---|
| 냉장 대기구역 | 동부센터 1층 동문 옆 |
| 냉장 상차구역 | 동부센터 1층 서문 옆 |

## 3. 시간표

| 시각 | 내용 | 담당 |
|---|---|---|
| 점검 시작 전 | 이동식 온도계 1대 추가 배치 | 현장 담당 |
| 05:30 | 점검 시작, 1차 온도 측정(두 구역) | 배유솔 |
| 05:40 | 보류 상자 8개 출고 보류 대장 등록, 2차 온도 측정 | 배유솔 |
| 05:40 이후 | 멈춤판에서 등록분 대조, 상자별 보류 사유 출력 | 배유솔 |
| 05:50 | 3차 온도 측정(두 구역) | 배유솔 |
| 06:00 | 보류 상자 목록 CS팀 전달 완료 | 배유솔 |
| 06:10 | 점검 종료, 출고 일지 보관 | 배유솔 |

> 측정 시각(05:30, 05:40, 05:50)은 "10분 간격 3회 측정"을 시간표에 맞춘 제안이다. 실제 시작 시각은 현장 담당이 확정한다.

## 4. 역할

- **배유솔 (현장 실행 담당):** 온도 측정, 기록, 보류 대장 등록, 상자별 보류 사유 출력, CS팀 전달
- **정해온 (출고팀 팀장)** 및 **류다빈 (시설팀 팀장):** 점검 시간(05:30~06:10) 동안 동부센터 1층 통제실에 함께 대기. 보류 해제 승인 권한
- **민재우 (시설지원 담당):** 온도계 표시 꺼짐 신고 접수 (내선 5834)
- **한시율 (고객지원팀):** 배송 문의 담당
- **오채린 (고객성공팀):** 납품 계약 고객 운영 담당

## 5. 사전 준비

1. 이동식 온도계 1대를 추가로 배치하고 표시 정상 여부를 확인한다.
2. 두 구역 온도계가 켜져 있고 표시가 정상인지 확인한다.
3. 종이 출고 일지를 준비한다. 측정 기록은 일지에 직접 적는다.
4. 출고 보류 대장(전산)에 접속 가능한지 확인한다.
5. 1층 통제실에 정해온 팀장, 류다빈 팀장이 대기 중인지 확인한다.

## 6. 절차

### 6.1 온도 측정 (05:30, 05:40, 05:50)

1. 각 구역에서 온도를 측정한다.
2. 측정값을 출고 일지에 **시각, 구역명, 측정값(℃), 측정자**와 함께 기록한다.
3. 세 번 모두 기록한다. 누락이 있으면 즉시 재측정하고 해당 사실을 일지에 남긴다.
4. 측정값이 7℃를 넘으면 즉시 판정 절차(6.3)로 넘어간다.

### 6.2 출고 보류 등록 (05:40)

1. 전산 **출고 보류 대장**에 보류 상자 8개를 등록한다. 등록분은 배유솔이 05:40에 입력한다.
2. 등록 후 **멈춤판**에서 등록된 8개 상자를 대조한다.
3. 상자별 보류 사유를 출력한다. 사유에는 해당 구역과 측정 온도를 포함한다.

### 6.3 판정 기준

| 조건 | 판정 |
|---|---|
| 해당 구역 측정값 중 **한 번이라도 7℃ 초과** | 해당 구역 상자 **전량 출고 보류** |
| 측정값이 **모두 7℃ 이하** | 온도 기준상 출고 가능 |

- 3차 측정(05:50)에서 새로 초과가 확인되면 해당 구역 상자를 추가로 보류 대장에 등록하고, 추가 목록도 CS팀에 전달한다.
- 보류 상자는 해제하지 않는다. **정해온 팀장 또는 류다빈 팀장의 승인 전에는 보류 해제를 금지한다.**

### 6.4 보류 상자 목록 CS팀 전달 (06:00까지)

1. 최종 보류 상자 목록(상자별 보류 사유 포함)을 CS팀에 **06:00까지** 전달한다.
2. 문의 유형에 따라 전달 대상을 나눈다.
   - 배송 문의: 한시율 (고객지원팀)
   - 납품 계약 고객 운영: 오채린 (고객성공팀)
3. 전달 완료 시각과 수신자를 일지에 기록한다.

### 6.5 점검 종료 (06:10)

1. 출고 일지의 3회 측정 기록이 모두 있는지 확인한다.
2. 종이 출고 일지를 **1층 통제실 파란 서류함**에 보관한다.
3. 점검 종료 시각을 일지에 기록한다.

## 7. 예외 상황

| 상황 | 조치 |
|---|---|
| 온도계 표시 꺼짐 | 즉시 민재우 담당에게 **내선 5834**로 신고한다. 신고 시각과 해당 구역을 일지에 기록한다. |
| 온도계 표시 꺼짐 상태에서 측정 불가 | 이동식 온도계로 대체 측정한다. 대체 사용 사실을 일지에 기록한다. |
| 측정 기록 누락 | 즉시 재측정하고, 누락 사유와 재측정 시각을 일지에 남긴다. |
| 보류 해제 요청 | 정해온 팀장 또는 류다빈 팀장 승인 전에는 해제하지 않는다. |
| 06:00까지 CS팀 전달 불가 | 현재까지의 목록을 먼저 전달하고, 이후 변경분을 추가 전달한다. 지연 사유를 일지에 기록한다. |

## 8. 후속 조치

- **12월 4일(금) 05:30:** 예비 온도계 교체 점검을 실시한다.

## 9. 확인 필요 사항

원문 지시에서 명확하지 않은 부분은 점검 전에 확인한다.

1. **이동식 온도계 배치 위치:** "거기는 점검 시작 전에 이동식 온도계 1대 추가 배치"의 대상이 어느 구역인지 불명확하다. 두 구역 중 어느 곳에 배치하는지 확정한다.
2. **"멈춤판"의 의미:** 원문에 등장하는 시스템 또는 도구명이다. 실제 사용하는 명칭과 위치를 확인한다.
3. **측정 시각:** 05:30, 05:40, 05:50 제안이 실제 출고 시간과 맞는지 확인한다.
4. **CS팀 전달 방식:** 전달 채널(전산, 메신저 등)과 수신 확인 방법을 정한다.
