# 유리숲전시 북관 전시 장비 기동 런북

**절차 묶음 4 · 전시 장비 기동 (개장 전)**

| 항목 | 내용 |
|---|---|
| 적용 장소 | 유리숲전시 북관 |
| 실행 일시 | 2026-12-15(화) 08:00 시작 ~ 08:50 종료 |
| 실행 담당 | 기술기사 차서후 |
| 대상 장비 | 입구 영상 장치, 중앙 음향 장치 |
| 설치 위치 | 입구 영상 장치: 북관 1층 입구 / 중앙 음향 장치: 북관 1층 중앙 무대 |
| 제어반 | 입구 제어반(입구 영상 장치 전용), 무대 제어반(중앙 음향 장치 전용). 두 제어반 모두 북관 1층 장비실 설치 |

---

## 1. 목적 및 적용 범위

개장 전 입구 영상 장치와 중앙 음향 장치를 순서대로 기동하고, 점검 결과를 기록해 개장 전 상태를 확인한다. 이 절차는 기동 담당 기술기사가 장비실과 전시장에서 수행하는 작업에 적용한다.

## 2. 핵심 주의 사항

> ⚠️ **전날 동시 기동 시 전원 차단이 발생했다.** 반드시 **입구 영상 장치를 먼저 켜고, 4분 후 중앙 음향 장치를 켠다.** 두 장치를 동시에 켜지 않는다.

- 제어반 덮개는 **차서후 입회하에만** 개방한다.
- 기동 전 케이블 연결 상태를 사진으로 기록한다.

## 3. 담당 및 연락 체계

| 역할 | 담당자 | 비고 |
|---|---|---|
| 실행 담당 | 기술기사 차서후 | 기동 및 점검 입력 전 과정 |
| 고객 담당 매니저 (Account Manager) | 유라온 | 전시 주최사 연락 담당, 개장 전 현장 대기 |
| 자산 담당 매니저 (Asset Manager) | 백이든 | 대여 장비 관리 담당, 개장 전 현장 대기 |
| 전기지원 담당 | 도하겸 | 내선 **6942**, 전원 차단 재발 시 즉시 연락 |

## 4. 실행 절차

| 순서 | 시각 | 작업 | 확인 사항 |
|---|---|---|---|
| 1 | 08:00 | 작업 시작, 장비실 진입 | 차서후 본인 확인 |
| 2 | 기동 전 | 제어반 덮개 개방 (차서후 입회하에만) | 입회자 확인 후 개방 |
| 3 | 기동 전 | **케이블 연결 사진 2장 촬영** 후 점검 기록에 첨부 | 사진 2장 첨부 여부 확인 |
| 4 | 기동 시작 | **입구 제어반**에서 **입구 영상 장치** 기동 | 정상 기동 여부 확인 |
| 5 | 기동 후 | **4분 대기** (타이머 사용) | 대기 시간 준수 |
| 6 | 4분 경과 | **무대 제어반**에서 **중앙 음향 장치** 기동 | 입구 영상 장치 정상 유지 확인 후 진행 |
| 7 | 기동 직후 | **잡음 확인 (30초)** | 아래 3-1 판단 기준 적용 |
| 8 | 08:30 | 개장 점검 등록부에 점검 결과 **6건 입력** (차서후) | 입력 건수 6건 확인 |
| 9 | 입력 후 | 오픈노트에서 **08:30 입력분 6건 조회** | 조회 결과와 입력 내용 대조 |
| 10 | 입력 후 | **결과표 출력** (필수) | 출력물 1부 이상 확인 |
| 11 | 완료 후 | 기동 완료 결과표를 **AM에게 전달** | 전달 대상과 시각 기록 |
| 12 | 완료 후 | 제어반 덮개 닫기, 장비실 정리 | 차서후 확인 |
| 13 | 08:50 | 작업 종료, 기술기사 퇴실 | 퇴실 시각 기록 |

### 4-1. 잡음 판단 기준 (7단계)

- **잡음이 30초 이상 지속**: **중앙 음향 장치를 즉시 정지**한다. 이후 원인을 확인하고, 점검 기록에 상황을 남긴다.
- **잡음이 30초 이내에 멎음**: 중앙 음향 장치 **가동을 유지**한다.

## 5. 이상 대응

### 5-1. 기동 중 전원 차단 재발 시

1. 즉시 **전기지원 담당 도하겸**에게 **내선 6942**로 연락한다.
2. 장비 상태와 발생 시각을 기록한다.
3. 출력한 결과표는 **북관 1층 장비실 흰 서류함**에 보관한다.

### 5-2. 후속 점검

- 후속 점검일: **2026-12-16(수) 08:00**

## 6. 기록 및 보관

| 기록물 | 작성자 | 보관 위치 |
|---|---|---|
| 케이블 연결 사진 2장 | 차서후 | 점검 기록에 첨부 |
| 개장 점검 등록부 (6건) | 차서후 | 개장 점검 등록부 |
| 결과표 (오픈노트 조회 기준 출력) | 차서후 | AM 전달 후 사본은 북관 1층 장비실 흰 서류함(전원 차단 발생 시 필수) |

- **입력 화면**: 개장 점검 등록부 (1개 화면)
- **조회 시스템**: 오픈노트 (08:30 입력분 6건 조회)

---

## 7. 확인 필요 사항 (작성 전 보완 권장)

1. **점검 결과 6건의 세부 항목**: 등록부에 입력할 6개 점검 항목 목록이 제공되지 않았다. 항목명을 확정해 부록으로 추가해야 한다.
2. **"AM" 약칭 중복**: 고객 담당 매니저(유라온)와 자산 담당 매니저(백이든) 모두 AM으로 줄여 쓸 수 있다. 결과표를 전달할 대상을 **이름으로 특정**해야 한다.
3. **08:30 입력 시점**: 작업 시작(08:00) 후 4분 뒤 중앙 음향 장치를 켜고 잡음을 확인하므로, 입력 시점이 기동 확인 후인지 확정이 필요하다.
4. **사진 2장의 촬영 대상**: 어떤 케이블 연결 지점을 찍을지 지정이 필요하다.
5. **결과표 양식**: 출력 양식과 필수 기재 항목을 정해야 한다.
