# [공지] 모래빛콘텐츠 편집 자료 보관 규정 변경 안내

**발신:** [부서명]
**날짜:** 2026.10.19.
**대상:** 모래빛콘텐츠 영상 편집 직원 전원
**시행일:** 2026년 12월 1일(화)부터

---

안녕하십니까. 저장 공간 부족과 파일 유실을 줄이기 위해 편집 자료 보관 규정을 아래와 같이 변경합니다. 12월 1일 이후 완료되는 프로젝트부터 적용하며, 변경 내용을 꼭 확인해 주시기 바랍니다.

## 1. 완료 프로젝트 원본 업로드

- **업로드 기한:** 납품 다음 영업일 18:00까지 지정 보관 공간에 원본을 업로드해야 합니다.
- **용량 한도:** 프로젝트당 원본 용량은 **80GB**를 넘을 수 없습니다.
- **업로드 위치:**
  - 원본 영상: **'원본보관함'**
  - 자막 파일: **'자막보관함'**
  - 두 보관함은 모두 편집 직원에게 공개됩니다.
- **업로드 중단 시간:** 매주 금요일 17:00~18:00에는 업로드가 중단되니 일정을 미리 확인해 주시기 바랍니다.

## 2. 분쟁 보존 프로젝트

- 분쟁 보존 요청을 받은 프로젝트는 **용량 한도 적용에서 제외**됩니다.
- 업로드 기한은 일반 프로젝트와 **동일**합니다(납품 다음 영업일 18:00까지).

## 3. 서버 운영 기준

| 서버 | 용도 |
|---|---|
| 편집실 서버 | 작업 파일 저장 |
| 보관실 서버 | 납품 완료 파일 저장 |

- 서버 계정 비밀번호는 **45일마다 변경**해야 합니다.

## 4. 외부 전달 기준

- 콘텐츠 전략팀은 고객사별 보관 범위를 조율하고, 고객지원팀은 고객사의 자료 반환 요청을 처리합니다. 두 팀 모두 외부 전달 업무를 담당합니다.
- 고객사에 보관 파일을 전달할 때는 **CS팀의 사전 승인**을 받아야 합니다.

## 5. 실습 안내

**영상자산등록시스템 실습 및 클립서랍 실습**

- **일시:** 2026년 11월 26일(목) 16:00
- **장소:** 사내 2층 시사실
- **담당:** 강이솔
- **인원:** 12명
- **참석 대상:** 신규 편집 직원은 **의무 참석**, 기존 직원은 **선택 참석**
- **클립서랍 실습 신청:** 강이솔에게 전달해 주시기 바랍니다.

## 6. 문의

- 규정 관련 문의는 **미디어운영팀 게시판 '보관상담'**을 이용해 주시기 바랍니다.
