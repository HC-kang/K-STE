# 강의 자막 편집: 저장 직후 줄바꿈이 사라지는 문제 수정

**개발 담당:** 차이담
**대상 독자:** 교육 콘텐츠 운영자, 접근성 검수자

## 변경 요약
- 자막을 저장하면 줄바꿈이 바로 사라지던 문제를 수정했습니다.
- 자막 편집기와 용어 사전 편집기를 변경했습니다.
- 두 편집기는 모두 콘텐츠 관리 포털의 **강의 도구** 메뉴에 있습니다.

## 입력 제한
| 항목 | 상한 |
|---|---|
| 자막 한 줄 | 42자 |
| 용어 설명 | 120자 |

공백도 글자 수에 포함됩니다.

## 일정
| 항목 | 일시 | 담당 |
|---|---|---|
| 접근성 검수 마감 | 12/09(수) 15:00 | 접근성 검수팀 |
| 타임가드 자동 검사 | 12/10(목) 10:00 | 정모아 |
| 강의 공개 | 12/10(목) 11:00 | 류하온 |

## 타임가드(자동 검사)
- 이번 공개의 단일 자동 검사 작업으로, 자막 시간축을 검사합니다.
- 정모아가 12/10(목) 10:00에 강의 36편을 검사합니다.
- **시간축 오류가 1건 이상이면 공개를 보류합니다.**

## 접근성 검수 안내
- 검수자는 **키보드 조작 결과를 반드시 첨부**해 주세요.
- 보관 상태 강의는 이번 검수에서 제외합니다.
- 문의는 **#강의-편집** 채널로 해 주세요.

## 공개 조건과 주의사항
- **팀장 승인 댓글을 받은 뒤에 공개를 진행합니다.**
- **공개 후 2시간 동안은 일괄 수정 기능을 사용하지 마세요.**
- CS팀에 공개 당일 안내를 반드시 전달해 주세요.

## 담당 및 역할
| 담당자/팀 | 역할 |
|---|---|
| 임새론 (콘텐츠 운영팀 팀장) | 강의 공개 일정 |
| 백여울 (접근성 검수팀 팀장) | 검수 인력 배정 |
| 고객지원팀 | 강사 문의 대응 |
| 고객성공팀 | 기관 고객 교육 |

---
**문서 식별자 묶음: 5-3**

참고: "문서 식별자 묶음 5-3"의 정확한 형식을 몰라서 마지막에 그대로 표기했습니다. 정해진 식별자 형식이 있으면 알려 주세요. 또한 승인 댓글을 임새론, 백여울 두 팀장 모두에게 받아야 하는지는 입력 내용에 명시되지 않아 "팀장 승인"으로만 적었습니다.
