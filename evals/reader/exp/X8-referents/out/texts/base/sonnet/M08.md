# 모브렌스튜디오 음향 납품 3차 회의록

## 1. 회의 개요
| 항목 | 내용 |
|---|---|
| 회의명 | 모브렌스튜디오 음향 납품 3차 회의 |
| 일시 | 11/19(목) 14:00~14:40 |
| 장소 | 온라인 회의방 '음향-4' |
| 진행 | 제작팀 강이솔 |
| 수신 | 모브렌스튜디오 외주 음향 편집자 |

## 2. 검수 대상 및 저장 위치
| 구분 | 저장 폴더 |
|---|---|
| 본편 음원 | 본편 폴더 |
| 예고편 음원 | 예고편 폴더 |

## 3. 기준 통일 사유
11/17(화) 검수에서 본편과 예고편 사이 음량 차이로 수정 요청이 5건 발생했습니다. 이에 두 음원에 공통 기준을 적용합니다.

## 4. 결정 사항 및 요청 사항

### 4-1. 잡음 제거 및 폴더 업로드
- 본편·예고편 음원은 **11/20(금) 16:00까지** 잡음 제거를 한 번 더 거친 뒤 제출해야 합니다. (필수)
- 폴더는 **11/20(금) 18:00부터 업로드가 잠깁니다.**
- 잠금 이후 수정본은 폴더에 올리지 말고 **강이솔에게 직접 전달**해 주세요.

### 4-2. 음량 기준 대조표(레벨카드) 적용
- 레벨카드 적용은 **필수**입니다.
- 담당: 제작팀 윤다온
- 배포 시점: **11/19(목) 17:00**
- 내용: 본편·예고편 공통 검사 항목 4개 수록

### 4-3. 최종 음원 제출
| 항목 | 내용 |
|---|---|
| 제출 기한 | **11/23(월) 15:00** |
| 제출처 | 납품 포털 '소리함' |
| 파일 형식 | WAV |
| 샘플레이트 | 48kHz |

**기한 연장 조건**
- 11/19(목) 18:00까지 강이솔에게 **재녹음 승인을 받은 음원**만 최종 제출 기한이 **11/24(화) 12:00**로 연장됩니다.
- 승인을 받지 않은 음원은 연장이 적용되지 않으며, 기존 기한(11/23 15:00)을 지켜야 합니다.

### 4-4. 재해 복구(DR) 훈련 참석
- 외주 편집자 **대표 1명**은 **11/20(금) 11:00 DR에 필수로 참석**해야 합니다.
- 참석 링크는 당일 개별 발송됩니다.

### 4-5. 기타 내부 활동 (참석 선택)
아래 두 활동은 외주 편집자도 참석할 수 있습니다.
- 재해 복구 훈련: 기술팀 백도겸 담당
- 설계 검토 회의: 제작팀 오새린 담당

## 5. 주요 일정 요약
| 일시 | 내용 |
|---|---|
| 11/19(목) 17:00 | 음량 기준 대조표(레벨카드) 배포 (윤다온) |
| 11/19(목) 18:00 | 재녹음 승인 요청 마감 (강이솔) |
| 11/20(금) 11:00 | DR 참석 (외주 편집자 대표 1명, 필수) |
| 11/20(금) 16:00 | 잡음 제거 완료 후 음원 제출 마감 |
| 11/20(금) 18:00 | 폴더 업로드 잠금 (이후 수정본은 강이솔에게 직접 전달) |
| 11/23(월) 15:00 | 최종 음원 납품 마감 (WAV, 48kHz) |
| 11/24(화) 12:00 | 재녹음 승인 음원에 한한 연장 마감 |
