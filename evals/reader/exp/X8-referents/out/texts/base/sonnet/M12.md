# 운영 절차 묶음 4: 전시 장비 기동 런북
**유리숲전시 북관 개장 전 장비 기동**

## 1. 개요

| 항목 | 내용 |
|---|---|
| 일시 | 12/15(화) 08:00 시작 ~ 08:50 종료 |
| 실행 담당 | 기술기사 차서후 |
| 대상 장소 | 북관 1층 |
| 대상 장비 | 입구 영상 장치, 중앙 음향 장치 |
| 대기 인원 | 고객 담당 매니저(AM) 유라온, 자산 담당 매니저 백이든 (개장 전 현장 대기) |
| 후속 점검 | 12/16(수) 08:00 |

## 2. 장비 및 제어반

| 장비 | 설치 위치 | 전용 제어반 | 제어반 위치 |
|---|---|---|---|
| 입구 영상 장치 | 북관 1층 입구 | 입구 제어반 | 북관 1층 장비실 |
| 중앙 음향 장치 | 북관 1층 중앙 무대 | 무대 제어반 | 북관 1층 장비실 |

- 입구 제어반은 입구 영상 장치 전용, 무대 제어반은 중앙 음향 장치 전용이다.
- 제어반 덮개는 **차서후 입회하에만** 개방한다.

## 3. 역할

| 담당 | 역할 |
|---|---|
| 기술기사 차서후 | 장비 기동, 점검 기록 입력, 결과표 출력 |
| 고객 담당 매니저(AM) 유라온 | 전시 주최사 연락 담당, 기동 완료 결과표 수령 |
| 자산 담당 매니저 백이든 | 대여 장비 관리 담당 |
| 전기지원 담당 도하겸 | 전원 차단 재발 시 대응 (내선 6942) |

## 4. 주의 사항

- 전날 동시 기동 시 **전원 차단이 발생**했다. 따라서 두 장치를 동시에 켜지 않는다.
- **입구 영상 장치를 먼저 켜고, 4분 뒤 중앙 음향 장치를 켠다.** (필수)

## 5. 절차

### 5.1 기동 전 (08:00~)
1. 차서후, 유라온, 백이든이 북관 1층에 대기 중인지 확인한다.
2. **기동 전에 케이블 연결 사진 2장을 촬영**하여 점검 기록에 첨부한다. (필수)
3. 차서후 입회하에 제어반 덮개를 개방한다. (입구 제어반, 무대 제어반 모두 북관 1층 장비실)

### 5.2 장비 기동
1. 입구 제어반에서 **입구 영상 장치**를 켠다. 기동 시각을 기록한다.
2. 4분이 경과할 때까지 대기한다.
3. 무대 제어반에서 **중앙 음향 장치**를 켠다.

### 5.3 기동 후 잡음 확인
| 상황 | 조치 |
|---|---|
| 잡음이 **30초 넘게** 지속 | **중앙 음향 장치 정지** (필수) |
| 잡음이 **30초 이내**에 멎음 | 가동 유지 |

### 5.4 점검 결과 입력 (08:30)
1. 차서후가 입력 화면 **개장 점검 등록부**(입력 화면은 이 1개뿐)에 08:30에 점검 결과 **6건**을 입력한다.
2. **오픈노트**에서 차서후의 08:30 입력분 6건을 조회한다.
3. 조회 결과를 **결과표로 출력**한다. (필수)

### 5.5 마무리 (~08:50)
1. 기동 완료 결과표를 **AM(유라온)에게 전달**한다.
2. 전달 후 기술기사 차서후가 퇴실한다.
3. 출력한 결과표는 **북관 1층 장비실 흰 서류함**에 보관한다.

## 6. 이상 발생 시

**기동 중 전원 차단이 재발하면** 전기지원 담당 **도하겸에게 내선 6942로 즉시 연락**한다.
