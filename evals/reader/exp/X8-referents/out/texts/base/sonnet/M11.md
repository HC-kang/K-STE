# 운영 절차 묶음 4: 냉장 출고 장애 대응 런북

**모래빛식품 동부 물류센터 | 새벽 출고 작업자용**

## 1. 개요

| 항목 | 내용 |
|---|---|
| 점검명 | 동부 물류센터 출고 점검 |
| 일시 | 12/03(목) 05:30 시작 ~ 06:10 종료 |
| 현장 실행 담당 | 배유솔 |
| 대기 인원 | 출고팀 팀장 정해온, 시설팀 팀장 류다빈 (점검 시간 동안 동부센터 1층 통제실 함께 대기) |
| 배경 | 전날 출고 때 온도 기록 누락 발생 → 재발 방지 |

## 2. 점검 대상 구역

| 구역 | 위치 |
|---|---|
| 냉장 대기구역 | 동부센터 1층 동문 옆 |
| 냉장 상차구역 | 동부센터 1층 서문 옆 |

## 3. 사전 준비 (05:30 점검 시작 전)

- [ ] 두 구역에 **이동식 온도계 1대 추가 배치**
- [ ] 출고 일지(종이) 준비
- [ ] 정해온 팀장, 류다빈 팀장의 통제실 대기 확인

## 4. 온도 측정 및 기록

- 두 구역 온도를 **출고 전 10분 간격으로 3회** 측정합니다.
- 측정값은 **반드시 출고 일지에 기록**합니다. (누락 금지)
- 종이 출고 일지는 **1층 통제실 파란 서류함**에 보관합니다.

## 5. 판정 기준

| 측정 결과 | 조치 |
|---|---|
| 3회 중 **한 번이라도 7℃ 초과** | 해당 구역 **상자 전량 출고 보류** |
| 전부 **7℃ 이하** | 온도 기준상 **출고 가능** |

## 6. 출고 보류 처리

1. 보류 접수는 전산 대장 **「출고 보류 대장」** 1개에만 등록합니다.
2. 배유솔이 **05:40**에 보류 상자 **8개**를 등록합니다.
3. 멈춤판에서 배유솔의 05:40 등록분 8개를 대조한 뒤, **상자별 보류 사유를 출력**합니다.
4. **보류 해제는 팀장 승인 전에는 절대 금지**입니다.

## 7. CS팀 전달 (06:00까지 필수)

보류 상자 목록을 **06:00까지** 아래 두 담당에게 전달합니다.

| 팀 | 담당 | 역할 |
|---|---|---|
| 고객지원팀 | 한시율 | 배송 문의 담당 |
| 고객성공팀 | 오채린 | 납품 계약 고객 운영 담당 |

두 팀 모두 새벽 당직으로 운영됩니다.

## 8. 장애 대응

| 상황 | 조치 |
|---|---|
| **온도계 표시 꺼짐** | 시설지원 담당 **민재우**에게 **내선 5834**로 즉시 신고 |
| 7℃ 초과 측정 | 5장 기준대로 해당 구역 전량 보류 → 6장 절차 진행 |
| 보류 해제 요청 발생 | 정해온·류다빈 팀장 승인 확인 전까지 해제하지 않음 |

## 9. 시간표 요약

| 시각 | 작업 |
|---|---|
| 05:30 이전 | 이동식 온도계 추가 배치 |
| 05:30 | 점검 시작, 온도 측정 개시 (10분 간격 3회) |
| 05:40 | 보류 상자 8개 「출고 보류 대장」 등록 (배유솔) |
| 05:40 이후 | 멈춤판 대조 후 상자별 보류 사유 출력 |
| 06:00 | 보류 상자 목록 CS팀 전달 완료 |
| 06:10 | 점검 종료 |

## 10. 참고

- 예비 온도계 교체 점검: **12/04(금) 05:30**
