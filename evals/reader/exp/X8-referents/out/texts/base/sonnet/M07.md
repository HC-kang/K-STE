# 누리온물류 출고 개선 3차 회의록

## 1. 회의 개요
- **일시:** 11/12(목) 15:00~15:30
- **장소:** 서하센터 회의실 B
- **진행:** 출고운영팀 문서윤
- **개선 대상:** 포장 작업대, 반품 작업대 (각 작업대에 출고 서버와 반품 서버 설치)

## 2. 변경 사유
11/09(월) 야간 출고에서 **라벨 중복 부착 8건**이 발생했고, 당일 **출고 지연은 24분**이었습니다.

## 3. 담당자
| 구분 | 담당 |
|---|---|
| 제품 관리자 | 배하람 (출고 화면) |
| 프로젝트 관리자(PM) | 도유찬 (센터 전환 일정) |
| 출고 누락 점검표·육칸표 | 이라온 |

## 4. 결정 사항 및 시행 일정

| 일시 | 내용 | 대상/담당 |
|---|---|---|
| 11/13(금) 17:00 | 출고 누락 점검표 개편본 배포 (점검 항목 6개로 통일) | 이라온 |
| 11/13(금) 17:00 | 육칸표를 6개 항목 양식으로 교체. **기존 인쇄본은 폐기** | 이라온 |
| 11/13(금) 18:00까지 | PM에게 **작업대별 점검 사진 2장씩** 전달 | 작업대 담당자 |
| 11/13(금) 20:00까지 | 서하센터 교육실에서 **스캐너 실습 15분** 이수 | 야간 출고조 전원 |
| 11/13(금) 20:40 | 서버 재시작 실시. **작업 전 문서윤에게 전화 보고 필수** | 작업 담당자 |
| 11/13(금) 21:00부터 | 포장·반품 작업대는 **바닥 표시선 안쪽에만 대차 배치** | 야간 출고조 전원 |

## 5. 스캐너 실습 보충 안내
- 11/13(금) 휴가자는 실습 대상에서 제외됩니다.
- 해당자는 **11/16(월) 20:00**, 같은 교육실(서하센터)에서 **보충 실습 15분**을 반드시 이수해야 합니다.

## 6. 야간 출고조 확인 사항
1. 11/13(금) 20:00 전까지 스캐너 실습을 마칩니다. 휴가자는 11/16(월) 20:00에 보충 실습을 받습니다.
2. 11/13(금) 17:00 이후에는 새 점검표와 육칸표(6개 항목)만 사용하고, 기존 인쇄본은 폐기합니다.
3. 11/13(금) 21:00부터는 대차를 바닥 표시선 안쪽에만 둡니다.
4. 서버 재시작(20:40) 전에 문서윤에게 전화로 보고합니다.

## 7. 문의
실습 일정·양식 관련 문의: 출고운영팀 이라온, 사내 내선 **431**
