# 출고 파동 조정: 긴급 주문이 피킹 대기열에 밀리는 문제 수정

**문서 식별자 묶음: 5-2**
**대상 독자:** 모래결로지스 창고 운영 책임자, 물류 서비스 QA 담당자

## 1. 개요
- **개발 담당:** 배시온
- **변경 목적:** 피킹 대기열에서 긴급 주문이 뒤로 밀리는 문제를 수정합니다.
- **변경 화면:** 피킹 순서 화면, 포장 대기 화면 (둘 다 서부 시험창고 운영 포털에서 사용)
- **참여자:** 재해 복구 담당 유재하, 설계 검토 담당 노세린

## 2. 일정
| 항목 | 일시 |
|---|---|
| QA 결과 등록 기한 | 11/18(수) 16:00 |
| 시험 적용 | 11/19(목) 09:00 |
| 첫 보고서 생성 | 11/19(목) 10:00 |

## 3. 변경 내용
- 피킹 묶음 상한은 **80건**, 포장 묶음 상한은 **50건**입니다.
- 상한을 초과한 주문은 **다음 묶음으로 이동**합니다.
- 예약 출고 주문은 우선 배치 대상에서 **제외**됩니다.

## 4. 설치 환경
같은 버전을 두 서버에 설치합니다.

| 서버 | 입력 방식 |
|---|---|
| 시험창고 서버 | 실물 스캐너 연결 |
| 교육창고 서버 | 모의 입력 사용 |

## 5. 신규 보고서: 웨이브북(출고 누락 대조표)

- **중단 기준:** 누락이 1건 이상이면 시험을 중단합니다.

## 6. 시험 시작 조건 및 운영 제한
- **DR 완료 기록**을 이 PR에 첨부해야 시험을 시작할 수 있습니다.
- 서버 재시작 시 **창고 운영 책임자의 입회가 필수**입니다.
- 시험 첫날에는 **현장 작업자 계정의 접근을 차단**합니다.

## 7. QA 확인 사항
- **긴급 주문 우선 배치 결과 등록은 필수**입니다. 11/18(수) 16:00까지 등록해 주세요.
- 예약 출고 주문이 우선 배치에서 제외되는지 함께 확인해 주세요.
- 문의는 **#창고-QA** 채널로 남겨 주세요.
