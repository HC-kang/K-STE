# 누리펄스 캐시 전환 런북 (운영 절차 묶음 4)

## 1. 작업 개요

| 항목 | 내용 |
|---|---|
| 작업명 | 누리펄스 캐시 전환 작업 |
| 일시 | 11/12(목) 23:10 시작 ~ 23:40 종료 |
| 실행 담당 | 야간 당직자 문세린 |
| 작업 대상 | 검색 캐시, 추천 캐시 |
| 작업 위치 | 사내 운영 포털 검색 탭(검색 캐시), 추천 탭(추천 캐시) |
| 배경 | 캐시 갱신 지연으로 검색 결과 누락 발생 |
| 후속 점검 | 11/13(금) 09:00 |

## 2. 역할 및 연락 체계

| 역할 | 담당 | 비고 |
|---|---|---|
| 실행 및 승인 | 야간 당직자 문세린 | 작업 실행, 서버 재시작 승인 |
| 제품 관리자 | 나도윤 | 작업 시간 내내 사내 메신저 대기 |
| 프로젝트 관리자 | 서이안 | 작업 시간 내내 사내 메신저 대기 |
| 보고 수신 | PM | 전환 완료 보고서 수신 |
| 긴급 연락 | 플랫폼지원팀 윤하민 | 내선 4726 |

## 3. 사전 준비 (23:10 이전~23:20)

1. 나도윤, 서이안이 사내 메신저에서 대기 중인지 확인한다.
2. 운영 포털 **장비 탭**에서 검색 로그 서버와 추천 로그 서버 상태를 각각 조회한다. 두 서버는 별도 장비이므로 따로 확인한다.
3. 운영 포털 **야간 작업함**에 이번 작업 기록 문서를 생성한다.

## 4. 작업 절차

### 4-1. 전환 전 오류율 측정 (23:10 시작)
1. 검색 탭에서 검색 캐시의 오류율을 5분간 측정한다.
2. 추천 탭에서 추천 캐시의 오류율을 5분간 측정한다.
3. 두 측정값을 작업 기록에 남긴다.
4. 오류율을 조회할 수 없으면 **8. 긴급 연락**을 따른다.

### 4-2. 복원 지점 등록 (23:20)
1. 문세린이 **복원 제어판**에서 복원 지점 2개를 등록한다.
   - 캐시 복원 작업의 실행 화면은 복원 제어판 1개만 사용한다.
2. 되돌림 데스크에서 문세린이 23:20에 등록한 복원 지점 2개가 보이는지 확인한다.
   - **표시 개수를 반드시 대조**한다(등록 2개 = 표시 2개).
   - 개수가 다르면 전환을 진행하지 않고 **8. 긴급 연락**을 따른다.

### 4-3. 스냅샷 저장
1. 전환 직전에 스냅샷 1개를 추가로 저장한다(필수).
2. 저장 완료를 작업 기록에 남긴다.

### 4-4. 캐시 전환
1. 검색 탭에서 검색 캐시 전환을 실행한다.
2. 추천 탭에서 추천 캐시 전환을 실행한다.
3. 서버 재시작이 필요하면 **문세린의 승인을 받은 후에만** 진행한다. 승인 전에는 재시작하지 않는다.
4. 전환 후 장비 탭에서 두 로그 서버 상태를 다시 확인한다.

## 5. 전환 후 판정

전환 후 오류율을 조회하여 작업 기록에 남긴 뒤 아래 기준으로 판정한다.

| 전환 후 오류율 | 조치 |
|---|---|
| 2% 초과 | **즉시 복원** (복원 제어판 사용) |
| 2% 이하 | 복원 없이 **관찰 유지** |

- 복원에 실패하면 **8. 긴급 연락**을 따른다.

## 6. 보고 및 교대

1. 전환 완료 보고서를 작성해 **PM에게 전달**한다.
2. **보고서 전달 전에는 당직 교대를 하지 않는다.**
3. 작업 기록을 운영 포털의 **야간 작업함**에 저장한다.

## 7. 후속 점검

- 11/13(금) 09:00에 후속 점검을 진행한다.

## 8. 긴급 연락

다음 경우 **플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락**한다.
- 오류율 조회 불가
- 복원 실패

연락 내용(시각, 증상, 수행한 조치)은 작업 기록에 남긴다.
