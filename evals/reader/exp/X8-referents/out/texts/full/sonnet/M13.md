# 묶음 5-1 결제 재시도 PR

중복 승인 요청 때문에 고객에게 결제 알림이 두 번 나가는 문제를 수정한다. 담당 개발자는 서다온이다. 배포는 11/12(목) 14:00에 하며, 배포 검토는 11/11(수) 17:00까지 끝내야 한다.

## 변경 내용

변경 대상은 승인 재시도 작업과 알림 재전송 작업이다. 두 작업은 모두 결제 운영 콘솔에서 실행한다. 재시도 설정은 다음과 같다.

| 작업 | 재시도 간격 | 최대 횟수 |
|---|---|---|
| 승인 재시도 작업 | 30초 | 3회 |
| 알림 재전송 작업 | 60초 | 2회 |

주문 DB와 정산 DB 각각에 조회 인덱스를 추가한다. 기존 컬럼은 삭제하지 않는다.

## 일정

- 검토 완료 기한: 11/11(수) 17:00
- 결제 무결성 검사 실행: 11/12(목) 13:30, 서다온
- 배포 실행: 11/12(목) 14:00, 배포 담당 문해솔

## 배포 전 조건

- 배포 검토자는 재시도 테스트 통과 기록을 첨부해야 한다.
- 내부 시험 상점은 테스트 대상에서 제외해야 한다.
- 배포 전에 DB 스냅샷을 보관해야 한다.
- 서다온이 11/12(목) 13:30에 결제 무결성 검사(페이체크)로 표본 240건을 대조한다. 이 검사가 이번 배포의 유일한 사전 검사 작업이다. 검사에 실패하면 배포를 중단해야 한다.
- PM 승인 댓글을 받은 뒤에 병합해야 한다. 제품 관리자 이나루와 프로젝트 관리자 강도윤은 둘 다 이번 결제 개편에 참여한다.

## 배포 후 제한

배포 직후 20분 동안은 수동 실행하면 안 된다.
