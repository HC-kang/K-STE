# 누리펄스 캐시 전환 런북

이 런북은 11/12(목) 23:10부터 23:40까지 진행하는 검색 캐시와 추천 캐시 전환 작업의 절차를 정한다. 실행 담당은 야간 당직자 문세린이다. 전환 후 오류율이 2%를 초과하면 즉시 복원한다. 2% 이하이면 복원하지 않고 관찰을 유지한다. 전환 완료 보고서를 PM에게 전달하기 전에는 당직을 교대하면 안 된다.

## 작업 개요

| 항목 | 내용 |
|---|---|
| 작업명 | 누리펄스 캐시 전환 |
| 일시 | 11/12(목) 23:10 시작, 23:40 종료 |
| 실행 담당 | 야간 당직자 문세린 |
| 작업 대상 | 검색 캐시, 추천 캐시 |
| 작업 위치 | 사내 운영 포털의 검색 탭, 추천 탭 |
| 대기 인원 | 제품 관리자 나도윤, 프로젝트 관리자 서이안. 작업 시간 동안 사내 메신저에서 대기한다. |

캐시 갱신이 지연되면 검색 결과 누락이 발생한다.

## 작업 절차

1. 23:10에 작업을 시작한다.
2. 23:20에 문세린이 복원 제어판에서 복원 지점 2개를 등록한다. 캐시 복원 작업의 실행 화면은 복원 제어판 1개만 사용해야 한다.
3. 되돌림 데스크에 23:20에 등록한 복원 지점 2개가 표시되는지 개수를 대조해야 한다.
4. 전환 직전 스냅샷 1개를 추가로 저장해야 한다.
5. 전환 전 검색 캐시와 추천 캐시의 오류율을 각각 5분간 측정하고, 측정 결과를 작업 기록에 남겨야 한다.
6. 운영 포털의 검색 탭과 추천 탭에서 각각 검색 캐시와 추천 캐시를 전환한다.
7. 전환 후 검색 캐시와 추천 캐시의 오류율을 측정한다.
8. 전환 후 오류율에 따라 다음과 같이 판단한다.
   - 오류율이 2%를 초과하면 복원 제어판에서 즉시 복원해야 한다.
   - 오류율이 2% 이하이면 복원하지 않고 관찰을 유지한다.
9. 23:40에 작업을 종료한다.
10. 전환 완료 보고서를 작성하여 PM에게 전달한다.
11. 보고서 전달이 끝나기 전에는 당직을 교대하면 안 된다.

## 서버 상태와 재시작

두 로그 서버는 별도 장비이므로 각각 상태를 조회해야 한다. 상태는 운영 포털의 장비 탭에서 조회한다. 서버 재시작은 문세린의 승인을 받은 뒤에만 진행해야 한다. 승인 없이 재시작하면 안 된다.

- 검색 로그 서버: 운영 포털 장비 탭에서 상태를 조회한다.
- 추천 로그 서버: 운영 포털 장비 탭에서 상태를 조회한다.

## 복원 실패와 연락

**경고: 오류율 조회가 불가능하거나 복원이 실패하면 플랫폼지원팀 윤하민에게 내선 4726으로 즉시 연락해야 한다.**
