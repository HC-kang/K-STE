# [묶음 5-1] 결제 재시도: 중복 승인 요청으로 인한 고객 결제 알림 중복 발송 수정

**담당 개발자:** 서다온

**배포 일정:** 2026-11-12(목) 14:00

**참여:** 제품 관리자 이나루, 프로젝트 관리자 강도윤

## 1. 배경 및 문제

중복 승인 요청이 발생하면 고객에게 결제 알림이 두 번 발송되는 문제가 있었습니다. 이번 PR은 이 문제를 수정하고, 승인 재시도와 알림 재전송 정책을 정리합니다.

## 2. 변경 대상

두 작업 모두 **결제 운영 콘솔**에서 실행합니다.

- **승인 재시도 작업**
- **알림 재전송 작업**

## 3. 재시도 정책

| 구분 | 재시도 간격 | 최대 횟수 |
|---|---|---|
| 승인 재시도 | 30초 | 3회 |
| 알림 재전송 | 60초 | 2회 |

## 4. DB 변경

- **주문 DB:** 조회 인덱스 추가
- **정산 DB:** 조회 인덱스 추가
- 기존 컬럼 삭제 없음

## 5. 배포 계획

1. **배포 전:** DB 스냅샷을 보관합니다. (필수)
2. **사전 검사:** 결제 무결성 검사를 실행합니다. 담당은 서다온이고, 2026-11-12(목) 13:30에 표본 240건을 대조합니다. **검사가 실패하면 배포를 중단합니다.**
3. **배포:** 2026-11-12(목) 14:00
4. **배포 직후:** 20분 동안 수동 실행을 금지합니다.
