# 누리펄스 캐시 전환 런북 (운영 절차 묶음 4)

| 항목 | 내용 |
|---|---|
| 작업명 | 누리펄스 캐시 전환 |
| 작업 일시 | 2026-11-12(목) 23:10 시작 ~ 23:40 종료 |
| 실행 담당 | 야간 당직자 문세린 |
| 작업 대상 | 검색 캐시, 추천 캐시 |
| 작업 위치 | 사내 운영 포털 > 검색 탭, 추천 탭 (각각) |
| 보고 대상 | PM (프로젝트 관리자 서이안) |
| 긴급 연락 | 플랫폼지원팀 윤하민, 내선 4726 |

## 1. 작업 배경

캐시 갱신 지연으로 검색 결과 누락이 발생한 사례가 있어, 전환 전후의 오류율을 비교해 이상 여부를 판단한다.

## 2. 작업 전 준비 (23:10 이전)

- [ ] 작업 대상이 검색 캐시와 추천 캐시 두 가지인지 확인한다.
- [ ] 운영 포털의 **장비 탭**에서 검색 로그 서버와 추천 로그 서버 상태를 각각 조회해 기록한다. 두 서버는 별도 장비이므로 한쪽 결과로 다른 쪽을 판단하지 않는다.
- [ ] 제품 관리자 나도윤, 프로젝트 관리자 서이안이 사내 메신저에서 대기 중인지 확인한다. 두 사람은 작업 시간 동안 모두 대기해야 한다.
- [ ] 작업 기록 양식을 열어 둔다.

## 3. 전환 전 오류율 측정

검색 캐시와 추천 캐시 **각각** 전환 전 오류율을 **5분간** 측정하고 작업 기록에 남긴다.

| 대상 | 측정 시작 | 측정 종료 | 오류율 (%) | 측정자 |
|---|---|---|---|---|
| 검색 캐시 | | | | 문세린 |
| 추천 캐시 | | | | 문세린 |

- 측정값을 조회할 수 없으면 즉시 **4번 예외 처리**를 따른다.

## 4. 전환 직전 스냅샷 저장

- [ ] 전환 시작 직전에 **스냅샷 1개를 추가 저장**한다. 이 과정은 생략할 수 없다.
- [ ] 저장 완료 여부와 저장 시각을 작업 기록에 남긴다.

## 5. 복원 지점 등록 (23:20)

- [ ] 문세린이 23:20에 **복원 지점 2개**를 등록한다.
- [ ] 캐시 복원 작업의 실행 화면은 **복원 제어판 1개만** 사용한다. 다른 화면에서 복원하지 않는다.

## 6. 캐시 전환 (23:10 ~ 23:40)

- [ ] 검색 탭과 추천 탭에서 각각 캐시를 전환한다.
- [ ] 서버 재시작이 필요하면 **문세린의 승인 후에만** 진행한다. 승인 없이 재시작하지 않는다.
- [ ] 재시작을 진행한 경우 승인 시각과 재시작 내역을 작업 기록에 남긴다.

## 7. 전환 후 오류율 확인 및 판단

전환 후 검색 캐시와 추천 캐시 각각의 오류율을 확인한다.

| 전환 후 오류율 | 조치 |
|---|---|
| **2% 초과** | **즉시 복원** (복원 제어판 사용). 복원 후 5절의 복원 지점 확인을 수행한다. |
| **2% 이하** | **복원하지 않고** 관찰을 유지한다. |
| **조회 불가** | **4번 예외 처리**를 즉시 따른다. |

- 2%는 기준에 포함된다. 정확히 2.0%이면 복원하지 않는다.

## 8. 되돌림 데스크 확인 (복원 시)

- [ ] 복원을 실행한 경우, 되돌림 데스크에 **문세린이 23:20에 등록한 복원 지점 2개가 표시되는지** 확인한다.
- [ ] 표시 개수를 **대조**한다. 2개가 아니면 복원을 진행하지 말고 즉시 4번 예외 처리를 따른다.

## 9. 예외 처리

다음 중 하나라도 발생하면 **즉시** 플랫폼지원팀 윤하민(내선 **4726**)에게 연락한다.

- 오류율 조회 불가
- 복원 실패

연락 후 상황을 작업 기록에 남긴다.

## 10. 작업 종료 (23:40)

- [ ] 작업 기록을 완성한다. 측정값, 스냅샷 저장 여부, 서버 상태, 승인 내역, 복원 여부를 포함한다.
- [ ] 작업 기록을 **운영 포털의 야간 작업함**에 저장한다.
- [ ] **전환 완료 보고서**를 작성해 PM(서이안)에게 전달한다.

## 11. 교대 규정

- **보고서를 PM에게 전달하기 전에는 당직 교대를 하지 않는다.**
- 전달 완료를 확인한 뒤에만 교대한다.

## 12. 후속 점검

- **2026-11-13(금) 09:00**에 후속 점검을 진행한다.
- 점검 결과를 작업 기록에 추가한다.

### 확인 필요 사항

원문에 없어 실행 전에 담당자 확인이 필요한 항목이다.

1. **전환 전 5분 측정 시작 시각**: 23:10 직전인지 확정이 필요하다.
2. **전환 후 오류율 측정 기간**: 2% 판단에 사용할 측정 시간이 정해져 있지 않다.
3. **보고서 전달 담당**: 문세린이 직접 전달하는지 확인이 필요하다.
4. **보고서 양식**: 별도 양식이 있는지 확인이 필요하다.
