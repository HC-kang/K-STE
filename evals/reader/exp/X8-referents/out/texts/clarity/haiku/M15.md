# PR: 강의 자막 편집 - 저장 직후 줄바꿈 소실 수정

**개발 담당:** 차이담
**공개 담당:** 류하온
**공개 일시:** 2026-12-10(목) 11:00
**접근성 검수 마감:** 2026-12-09(수) 15:00

## 1. 변경 내용

- **버그 수정:** 자막 편집기에서 저장 직후 줄바꿈이 사라지는 문제를 수정했습니다.
- **변경 대상:** 자막 편집기, 용어 사전 편집기
- **배치 위치:** 두 도구 모두 콘텐츠 관리 포털의 강의 도구 메뉴에 있습니다.

## 2. 입력 제한

글자 수는 공백을 포함해 셉니다.

| 항목 | 상한 |
|---|---|
| 자막 한 줄 | 42자 |
| 용어 설명 | 120자 |

## 3. 자동 검사 (타임가드)

이번 공개의 자동 검사 작업은 **자막 시간축 검사** 하나입니다.

- **담당:** 정모아
- **실행 시점:** 2026-12-10(목) 10:00
- **대상:** 강의 36편
- **판정 기준:** 시간축 오류가 1건 이상이면 **공개를 보류**합니다.

## 4. 접근성 검수 (검수자용)

- 검수 마감은 2026-12-09(수) 15:00입니다.
- **키보드 조작 결과를 반드시 첨부**해 주세요.
- **보관 상태 강의는 이번 검수에서 제외**합니다.
- 문의는 **#강의-편집 채널**로 해 주세요.

## 5. 공개 절차 (운영자용)

1. 자동 검사(시간축 검사)에서 오류가 0건인지 확인합니다.
2. 접근성 검수가 완료되었는지 확인합니다.
3. **팀장 승인 댓글**을 받은 뒤 공개를 진행합니다.
4. 공개 직후 **2시간 동안 일괄 수정 기능 사용을 금지**합니다.
5. **CS팀에 공개 당일 안내를 반드시 전달**합니다.

## 6. 담당 역할

| 담당 | 역할 |
|---|---|
| 콘텐츠 운영팀 팀장 임새론 | 강의 공개 일정 |
| 접근성 검수팀 팀장 백여울 | 검수 인력 배정 |
| 고객지원팀 | 강사 문의 대응 |
| 고객성공팀 | 기관 고객 교육 |
| CS팀 | 공개 당일 안내 전달 |
