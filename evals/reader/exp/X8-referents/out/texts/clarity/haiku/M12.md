# 유리숲전시 북관 전시 장비 기동 런북

**운영 절차 묶음 4 · 전시 장비 기동**

| 항목 | 내용 |
|---|---|
| 적용 대상 | 유리숲전시 북관 개장 전 전시 장비 기동 |
| 실행일·시간 | 2026-12-15(화) 08:00 시작 ~ 08:50 종료 |
| 실행 담당 | 기술기사 차서후 |
| 대상 장비 | 입구 영상 장치(북관 1층 입구), 중앙 음향 장치(북관 1층 중앙 무대) |
| 제어반 | 입구 제어반(입구 영상 장치 전용), 무대 제어반(중앙 음향 장치 전용). 두 제어반 모두 북관 1층 장비실 설치 |

---

## 1. 목적

개장 전에 입구 영상 장치와 중앙 음향 장치를 순서대로 기동하고, 기동 상태와 잡음 여부를 확인해 결과를 기록한다. 전날 두 장치를 동시에 기동했을 때 전원 차단이 발생했으므로, 반드시 **입구 영상 장치를 먼저 기동하고 4분 뒤에 중앙 음향 장치를 기동**한다.

## 2. 역할

| 역할 | 담당자 | 책임 |
|---|---|---|
| 실행 담당 | 기술기사 차서후 | 기동, 점검, 기록 입력, 결과표 조회·출력, 전달 |
| 고객 담당 매니저(Account Manager, AM) | 유라온 | 전시 주최사 연락 담당. 현장 대기 |
| 자산 담당 매니저(Asset Manager) | 백이든 | 대여 장비 관리 담당. 현장 대기 |
| 전기지원 담당 | 도하겸 (내선 6942) | 기동 중 전원 차단 재발 시 즉시 연락 |

## 3. 준비 사항 (08:00 이전)

- [ ] 기술기사 차서후 현장 도착 및 장비실 출입 확인
- [ ] AM 유라온, 자산 담당 매니저 백이든 현장 대기 확인
- [ ] **제어반 덮개 개방은 차서후 입회하에만 가능.** 입회 없이 개방하지 않는다.
- [ ] 개장 점검 등록부(오픈노트) 접속 가능 여부 확인
- [ ] 결과표 출력 장비 준비 확인

## 4. 절차

### 4.1 기동 전 점검 (08:00~)

1. 입구 제어반과 무대 제어반의 **대상 장비 매핑을 확인**한다.
   - 입구 제어반 → 입구 영상 장치만 연결
   - 무대 제어반 → 중앙 음향 장치만 연결
2. 케이블 연결 상태를 **사진 2장 촬영**한다. 촬영 사진은 점검 기록에 첨부한다.
3. 제어반 덮개를 여는 경우 **차서후 입회하에서만** 개방한다.

### 4.2 1단계: 입구 영상 장치 기동

4. 입구 제어반에서 **입구 영상 장치를 켠다.**
5. 입구 영상 장치의 정상 기동 여부를 확인한다.

### 4.3 대기

6. **입구 영상 장치 기동 후 4분 대기한다.** 전날 동시 기동으로 전원 차단이 발생했으므로 이 대기 시간을 생략하지 않는다.

### 4.4 2단계: 중앙 음향 장치 기동

7. 4분 경과 후 무대 제어반에서 **중앙 음향 장치를 켠다.**
8. 중앙 음향 장치의 정상 기동 여부를 확인한다.

### 4.5 기동 후 잡음 확인

9. 중앙 음향 장치 기동 후 잡음 발생 여부를 확인하고 지속 시간을 잰다.
   - **잡음이 30초를 넘게 지속되면 → 중앙 음향 장치를 정지한다(필수).**
   - **잡음이 30초 이내에 멎으면 → 가동을 유지한다.**
10. 결과를 기록하고 후속 점검 일정(12/16(수) 08:00)을 확인한다.

### 4.6 개장 점검 등록부 입력 (08:30)

11. 차서후가 **08:30에 개장 점검 등록부(입력 화면 1개)에 점검 결과 6건을 입력한다.**

### 4.7 결과 조회 및 출력

12. 오픈노트에서 **차서후의 08:30 입력분 6건을 조회한다.**
13. 조회 결과를 **결과표로 출력한다(필수).**
14. 출력한 결과표를 검토하고 입력값과 일치하는지 확인한다.

### 4.8 전달 및 퇴실

15. 기동 완료 결과표를 **AM(고객 담당 매니저 유라온)에게 전달한다.**
16. 전달 후 기술기사가 **퇴실한다.** 종료 시각은 08:50 이내로 한다.

## 5. 이상 발생 시 조치

| 상황 | 조치 |
|---|---|
| 기동 후 잡음이 30초 넘게 지속 | 중앙 음향 장치 즉시 정지 |
| 기동 후 잡음이 30초 이내 종료 | 가동 유지, 기록 |
| 기동 중 전원 차단 재발 | 전기지원 담당 도하겸(내선 6942)에게 즉시 연락. 출력한 결과표는 **북관 1층 장비실 흰 서류함**에 보관 |
| 제어반 덮개 개방 필요 | 차서후 입회 하에서만 개방 |

## 6. 후속 조치

- **후속 점검: 2026-12-16(수) 08:00**
- 전원 차단이 발생한 경우, 결과표는 전달 대상과 별도로 북관 1층 장비실 흰 서류함에 보관한다.

## 7. 점검 체크리스트

- [ ] 제어반-장비 매핑 확인
- [ ] 케이블 연결 사진 2장 촬영 및 첨부
- [ ] 입구 영상 장치 먼저 기동
- [ ] 4분 대기 완료
- [ ] 중앙 음향 장치 기동
- [ ] 잡음 지속 시간 확인 및 기록(30초 기준 판단)
- [ ] 08:30 개장 점검 등록부 6건 입력
- [ ] 오픈노트 조회 및 결과표 출력
- [ ] 결과표 AM 유라온에게 전달
- [ ] 후속 점검 일정(12/16 08:00) 확인
- [ ] 기술기사 퇴실(08:50 이내)

---

### 확인 필요 사항

1. **"AM" 표기 확인:** 본 문서에서 AM은 고객 담당 매니저(Account Manager) 유라온을 가리킨다. 자산 담당 매니저도 AM으로 줄여 부르는 경우가 있으므로, 결과표 전달 대상을 현장에서 이름(유라온)으로 한 번 더 확인한다.
2. **케이블 사진 촬영 대상:** 원문에는 "케이블 연결 사진 2장"으로만 되어 있다. 어느 연결 지점을 촬영할지 기준이 필요하면 별도로 정한다.
3. **결과표 전달과 보관의 관계:** 정상 기동 시에는 AM에게 전달하고, 전원 차단이 재발한 경우에는 흰 서류함에 보관한다. 두 경우에 결과표를 모두 전달할지는 원문에 명시되어 있지 않으므로 담당자와 확인이 필요하다.
