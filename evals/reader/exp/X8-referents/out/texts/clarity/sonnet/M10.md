# 누리펄스 캐시 전환 런북 (운영 절차 묶음 4)

## 1. 작업 개요

| 항목 | 내용 |
|---|---|
| 작업명 | 누리펄스 캐시 전환 |
| 일시 | 11/12(목) 23:10 시작 ~ 23:40 종료 |
| 실행 담당 | 야간 당직자 문세린 |
| 대상 | 검색 캐시, 추천 캐시 |
| 작업 위치 | 사내 운영 포털의 검색 탭(검색 캐시), 추천 탭(추천 캐시) |
| 배경 | 캐시 갱신 지연으로 검색 결과 누락이 발생함 |
| 대기 인원 | 제품 관리자 나도윤, 프로젝트 관리자 서이안 (작업 시간 동안 사내 메신저 대기) |

## 2. 사전 확인

1. 나도윤, 서이안이 사내 메신저에 접속해 있는지 확인한다.
2. 운영 포털의 장비 탭에서 검색 로그 서버와 추천 로그 서버의 상태를 각각 조회한다. 두 서버는 별도 장비이므로 따로 확인한다.
3. 복원 작업에는 복원 제어판 화면 1개만 사용한다. 다른 화면에서 복원을 실행하지 않는다.

## 3. 작업 절차

### 3-1. 전환 전 오류율 측정 (23:10 시작 후)
1. 검색 캐시(검색 탭)와 추천 캐시(추천 탭) 각각 전환 전 오류율을 5분간 측정한다.
2. 측정 결과를 작업 기록에 남긴다.

### 3-2. 복원 지점 등록 (23:20)
1. 문세린이 복원 제어판에서 복원 지점 2개를 등록한다.
2. 복원 제어판(되돌림 데스크)에 표시된 복원 지점이 등록한 2개와 일치하는지 표시 개수를 대조한다.
3. 개수가 맞지 않으면 전환을 진행하지 않고 등록 상태를 다시 확인한다. 해결되지 않으면 7번 항목에 따라 연락한다.

### 3-3. 스냅샷 저장
1. 전환 직전에 스냅샷을 1개 추가로 저장한다. 저장은 필수다.
2. 저장 여부를 작업 기록에 남긴다.

### 3-4. 캐시 전환
1. 검색 탭에서 검색 캐시 전환을 수행한다.
2. 추천 탭에서 추천 캐시 전환을 수행한다.
3. 서버 재시작은 문세린의 승인을 받은 뒤에만 진행한다. 승인 전에는 재시작하지 않는다.

### 3-5. 전환 후 판정
전환 후 오류율을 조회하고 아래 기준으로 판정한다.

| 전환 후 오류율 | 조치 |
|---|---|
| 2% 초과 | 즉시 복원한다 (필수). 복원 제어판에서 실행한다. |
| 2% 이하 | 복원하지 않고 관찰을 유지한다. |

## 4. 후속 점검
- 11/13(금) 09:00에 후속 점검을 한다.

## 5. 완료 보고
1. 전환 완료 보고서를 PM에게 전달한다.
2. 전달 전에는 당직 교대를 하지 않는다.
3. 작업 기록은 운영 포털의 야간 작업함에 저장한다.

## 6. 작업 기록 필수 항목
- 검색 캐시, 추천 캐시의 전환 전 오류율 (5분 측정)
- 복원 지점 2개 등록 및 표시 개수 대조 결과
- 전환 직전 추가 스냅샷 저장 여부
- 서버 재시작 여부와 문세린 승인 내역
- 전환 후 오류율과 판정 결과 (복원 또는 관찰 유지)
