# 출고 파동 조정: 피킹 대기열에서 긴급 주문이 밀리는 문제 수정

**문서 식별자 묶음: 5-2**
**개발 담당:** 배시온
**대상 독자:** 모래결로지스 창고 운영 책임자, 물류 서비스 QA 담당자

## 1. 변경 목적
피킹 대기열에서 긴급 주문이 다른 주문 뒤로 밀리는 문제를 수정합니다.

## 2. 변경 내용

- **묶음 상한:** 피킹 묶음은 80건, 포장 묶음은 50건까지입니다. 상한을 넘는 주문은 다음 묶음으로 이동합니다.
- **예외:** 예약 출고 주문은 긴급 주문 우선 배치에서 제외합니다.

## 3. 설치 환경

| 서버 | 입력 방식 |

| 교육창고 서버 | 모의 입력 사용 |
