# 누리온물류 출고 개선 3차 회의록

- **일시**: 11/12(목) 15:00~15:30
- **장소**: 서하센터 회의실 B
- **진행**: 출고운영팀 문서윤

## 1. 변경 사유
11/09(월) 야간 출고에서 라벨 중복 부착 8건이 발생했고, 당일 출고가 24분 지연되었습니다. 이를 계기로 아래 개선 사항을 시행합니다.

## 2. 개선 대상
- 포장 작업대
- 반품 작업대

두 작업대에는 출고 서버와 반품 서버가 각각 설치되어 있습니다.

## 3. 11/13(금) 일정 요약

| 시각 | 내용 | 담당·대상 |
|---|---|---|
| 17:00 | 6개 항목 점검표 양식 배포 | 이라온 |
| 18:00까지 | 작업대별 점검 사진 2장씩(총 4장) PM에게 전달 | 야간 출고조 |
| 20:00까지 | 스캐너 실습 15분 이수 (서하센터 교육실) | 야간 출고조 전원 |
| 20:40 | 서버 재시작 (작업 전 문서윤에게 전화 보고) | 해당 작업자 |
| 21:00부터 | 포장·반품 작업대는 바닥 표시선 안쪽에만 대차 배치 | 야간 출고조 |

## 4. 결정 및 전달 사항

**4-1. 출고 누락 점검표 개편**
- 담당은 이라온입니다.
- 점검 항목을 6개로 통일하고, 11/13(금) 17:00에 배포합니다.
- 육칸표는 배포되는 6개 항목 양식으로 교체합니다. 기존 인쇄본은 폐기해 주세요.

**4-2. 작업대 점검 사진 제출**
- 11/13(금) 18:00까지 PM에게 작업대별 점검 사진을 2장씩 전달해야 합니다.

**4-3. 스캐너 실습**
- 야간 출고조 전원이 11/13(금) 20:00까지 서하센터 교육실에서 15분 실습을 이수해야 합니다.
- 11/13(금) 휴가자는 이 실습 대상에서 제외됩니다. 대신 11/16(월) 20:00에 같은 교육실에서 보충 실습 15분을 이수해야 합니다.

**4-4. 서버 재시작**
- 11/13(금) 20:40에 실시합니다.
- 작업 전에 반드시 문서윤에게 전화로 보고해야 합니다.

**4-5. 대차 배치**
- 11/13(금) 21:00부터 포장 작업대와 반품 작업대에서는 바닥 표시선 안쪽에만 대차를 배치해야 합니다.

## 5. 역할 안내
- 제품 관리자 배하람: 출고 화면 담당
- 프로젝트 관리자 도유찬: 센터 전환 일정 담당

## 6. 문의
실습 일정과 양식 관련 문의는 출고운영팀 이라온(사내 내선 431)에게 해 주세요.

---

작성 시 확인이 필요한 부분이 두 가지 있습니다.
- "PM"은 프로젝트 관리자 도유찬으로 보고 작성하지 않고 "PM"으로 그대로 두었습니다. 사진 제출처가 도유찬이 맞다면 4-2에 이름을 넣는 것이 좋습니다.
- 서버 재시작을 누가 수행하는지와 문서윤에게 보고할 전화번호는 전달받은 내용에 없어 비워 두었습니다. 야간조가 바로 확인할 수 있도록 추가하면 좋겠습니다.
