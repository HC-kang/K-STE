# 강의 자막 편집: 저장 직후 줄바꿈이 사라지는 문제 수정

**문서 식별자 묶음:** 5-3
**개발 담당:** 차이담
**대상 독자:** 콘텐츠 운영자, 접근성 검수자

## 변경 내용
- 자막을 저장한 직후 줄바꿈이 사라지는 문제를 수정했습니다.
- 자막 편집기와 용어 사전 편집기가 변경되었습니다. 두 편집기 모두 콘텐츠 관리 포털의 **강의 도구** 메뉴에 있습니다.

## 입력 글자 수 상한 (공백 포함)
| 항목 | 상한 |
|---|---|
| 자막 한 줄 | 42자 |
| 용어 설명 | 120자 |

공백도 글자 수에 포함됩니다.

## 일정
| 항목 | 일시 |
|---|---|
| 접근성 검수 마감 | 12/09(수) 15:00 |
| 타임가드 자동 검사 | 12/10(목) 10:00 |
| 공개 | 12/10(목) 11:00 |

공개 담당은 류하온입니다.

## 담당
| 역할 | 담당 |
|---|---|
| 강의 공개 일정 | 임새론 (콘텐츠 운영팀 팀장) |
| 검수 인력 배정 | 백여울 (접근성 검수팀 팀장) |
| 공개 | 류하온 |
| 자동 검사 | 정모아 |

## 자동 검사: 타임가드
이번 공개에서 실행하는 자동 검사 작업은 타임가드(자막 시간축 검사) 하나입니다.
- 실행: 정모아가 12/10(목) 10:00에 강의 36편을 검사합니다.
- 기준: 시간축 오류가 **1건 이상이면 공개를 보류**합니다.

## 접근성 검수자 안내
- 검수 결과에 **키보드 조작 결과를 반드시 첨부**해 주세요.
- 보관 상태의 강의는 이번 검수에서 제외됩니다.
- 문의는 **#강의-편집** 채널로 남겨 주세요.

## 공개 전후 준수 사항
- 팀장 승인 댓글을 받은 뒤에 공개를 진행합니다.
- 공개 후 2시간 동안(12/10 11:00~13:00)은 일괄 수정 기능을 사용하지 않습니다.
- CS팀에 공개 당일 안내를 반드시 전달합니다.
  - 고객지원팀: 강사 문의 대응
  - 고객성공팀: 기관 고객 교육

---
확인이 필요한 부분이 두 가지 있습니다.
- **문서 식별자 묶음 5-3:** 구체적인 내용을 알 수 없어 "5-3"이라는 값만 상단에 적었습니다. 식별자가 여러 개로 구성된 묶음이라면 알려 주시면 풀어서 반영하겠습니다.
- **승인 팀장:** 승인 댓글을 남길 팀장이 임새론 팀장인지 백여울 팀장인지, 또는 두 분 모두인지 원문에 없어 "팀장"으로만 적었습니다. 지정해 주시면 이름을 넣겠습니다.
