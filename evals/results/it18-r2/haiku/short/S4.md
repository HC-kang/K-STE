# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api의 운영 배포를 이전 리비전(revision, 배포 버전을 가리키는 번호)으로 되돌리는 절차를 설명한다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션(데이터베이스 구조나 데이터를 바꾸는 변경 작업)이 포함됐는지 반드시 확인한다.
2. **마이그레이션이 포함됐으면 롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았을 때만 다음 절차로 넘어간다.

## 2. 롤백 실행

1. 롤백 대상 리비전 번호를 `<REVISION>` 자리에 넣는다.
2. 다음 명령을 실행한다: `argocd app rollback payment-api <REVISION>`

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 4. 이력 기록

1. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요

- 확인 필요: 롤백 대상 리비전 번호를 찾는 방법이 원문에 없다.
- 확인 필요: 배포에 DB 마이그레이션이 포함됐는지 판단하는 방법이 원문에 없다.
- 확인 필요: DBA 박지은의 연락처와 연락 수단이 원문에 없다.
- 확인 필요: #deploy 채널에 남기는 이력의 형식이 원문에 없다.
