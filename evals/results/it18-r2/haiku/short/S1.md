로컬 캐시는 각 서버 안에 상품 목록을 따로 보관하고, Redis 캐시는 서버 밖의 공용 캐시 서버 1대에 보관합니다. 캐시는 자주 쓰는 데이터를 빨리 꺼내 쓰려고 따로 복사해 두는 임시 저장소입니다. Redis는 여러 서버가 함께 쓰는 캐시 전용 프로그램입니다.

| 구분 | 로컬 캐시 (현재) | Redis 캐시 (도입 예정) |
|---|---|---|
| 저장 위치 | 서버 4대 각각의 메모리 | 캐시 서버 1대 |
| 서버 간 상품 목록 | 서버마다 내용이 다를 수 있습니다 | 4대 서버가 같은 목록을 봅니다 |
| 가격 변경 반영 | 최대 5분 늦게 반영됩니다 | 아래 조건에 따라 달라집니다 |

Redis를 도입하면 상품 목록이 서버마다 달라지는 문제는 없어집니다. 하지만 Redis에 저장된 상품 목록의 유효 시간(저장된 데이터를 그대로 쓰는 시간)을 5분으로 두면 가격 변경은 여전히 최대 5분 늦게 반영될 수 있습니다. 가격을 바꿀 때 Redis의 상품 목록을 바로 지우는 작업을 넣어야 가격이 즉시 반영됩니다. 확인 필요: 이 작업이 이번 도입 계획에 들어 있는지 아직 알 수 없습니다.

Redis는 서버 밖에 있으므로 상품 목록을 읽을 때마다 네트워크를 거칩니다. 이 캐시 서버가 멈추면 4대 서버 모두 캐시를 쓰지 못합니다.
