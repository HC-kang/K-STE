# 운영 배포 롤백 런북

ArgoCD로 배포한 `payment-api`의 운영 배포를 롤백하는 절차를 설명한다.

## 절차

1. 롤백하기 전에 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
2. 배포에 DB 마이그레이션이 포함됐으면 **롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락해야 하고, 3단계 이후는 하지 않는다.
3. 배포에 DB 마이그레이션이 포함되지 않았으면 아래 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백이 끝나면 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.
