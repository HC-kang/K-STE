로컬 캐시는 서버마다 따로 있고 Redis 캐시는 서버 4대가 하나를 같이 쓰기 때문에, Redis를 도입하면 서버마다 캐시 내용이 달라지는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 임시로 저장해 두고 빠르게 꺼내 쓰는 방식입니다. 지금 우리는 로컬 캐시를 씁니다. API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 캐시를 담는 서버 1대를 따로 두는 방식입니다. API 서버 4대가 이 서버를 같이 쓰므로, 어느 서버가 응답하든 캐시 내용이 같습니다.
