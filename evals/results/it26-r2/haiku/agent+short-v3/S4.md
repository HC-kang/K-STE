# 운영 배포 롤백 런북: payment-api

이 런북은 ArgoCD로 운영 `payment-api` 배포를 롤백하는 절차다. 롤백 전에 배포에 DB 마이그레이션이 포함됐는지 확인하고, 롤백 후에는 `/healthz`와 결제 테스트 주문으로 결과를 검증한다. 롤백 이력은 #deploy 채널에 남긴다.

## 롤백 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않는다. DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

**마이그레이션이 포함됐으면 롤백하면 안 된다.**

## 롤백 후 검증

4. `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 이력 기록

6. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요

확인 필요: DB 마이그레이션 포함 여부. 이 여부를 확인하는 방법이 주어진 사실에 없다.
확인 필요: `<REVISION>`. 롤백할 리비전 값을 찾는 방법이 주어진 사실에 없다.
확인 필요: `/healthz`. 확인할 주소와 결제 테스트 주문을 실행하는 방법이 주어진 사실에 없다.
