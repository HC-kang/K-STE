# API 키 관리 지침

이 지침은 운영 환경과 개발 환경의 API 키를 교체하고 저장하는 기준을 정한다. 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.

## 교체 주기와 시기

운영 환경 API 키는 90일마다 교체해야 한다.
이 규칙은 예외 없이 지켜야 한다.
개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.
API 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
장애를 복구하는 중이면 업무 시간 밖에도 API 키를 교체해도 된다.

## 키 발급, 저장, 보관

API 키를 Git 저장소에 커밋하면 안 된다.
Vault 웹 화면에서 API 키를 직접 발급할 수 있다.
교체한 API 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

확인 필요: 90일 기간의 기준 시점이 발급일인지 마지막 교체일인지 원문에 없습니다. 기준 시점을 정해 주시면 문서에 반영하겠습니다.
확인 필요: "교체"를 누가 수행하는지(담당자 또는 팀) 원문에 없습니다.
확인 필요: Git 커밋 금지가 모든 저장소에 적용되는지, 운영 환경 키에만 적용되는지 원문에 없습니다.
확인 필요: `prod/api-keys` 저장 규칙이 운영 환경 키에만 적용되는지, 개발 환경 키에도 적용되는지 원문에 없습니다.
