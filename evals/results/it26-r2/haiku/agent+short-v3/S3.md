# 토큰 만료 시각 경계의 유효성 판단 수정

`auth/token.py`의 `is_valid()`가 토큰 만료 시각과 정확히 같은 시각의 요청을 유효하다고 판단하던 문제를 고쳤다. 비교 연산자를 `now <= expires_at`에서 `now < expires_at`로 바꿨다.

## 버그

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단했다.

## 변경

`auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다. 이 변경으로 `now`가 `expires_at`와 같은 시각이면 `is_valid()`가 거짓을 반환한다.

## 테스트

- `test_token_expired_at_boundary`를 추가했다. 만료 시각 경계를 다룬다.
- `test_token_valid_before_expiry`를 추가했다. 만료 전 유효 판단을 다룬다.

## 검증

- 실행했다: 로컬 단위 테스트 전체가 통과했다.
- 실행하지 않았다: 통합 테스트는 아직 돌리지 않았다.
