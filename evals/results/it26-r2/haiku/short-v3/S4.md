이 런북은 ArgoCD로 payment-api 운영 배포를 롤백하는 절차를 정의한다.

## 1. 롤백 전 확인

롤백 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

**마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA 박지은에게 연락해야 한다.**

확인 필요: DB 마이그레이션 포함 여부를 확인하는 방법을 알려 주세요.

## 2. 롤백 실행

마이그레이션이 포함되지 않은 경우에만 롤백을 실행한다. 아래 명령에서 `<REVISION>`에는 롤백할 리비전을 넣는다.

```
argocd app rollback payment-api <REVISION>
```

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

롤백 이력은 #deploy 채널에 남긴다.
