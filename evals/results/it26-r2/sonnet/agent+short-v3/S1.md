로컬 캐시는 서버마다 따로 가지는 저장소이고, Redis 캐시는 서버 4대가 함께 쓰는 저장소 1개입니다. 캐시는 자주 쓰는 데이터를 미리 저장해 두고 빠르게 꺼내 쓰는 곳입니다.

지금은 API 서버 4대가 각자 메모리(서버가 작업 중에 데이터를 두는 빠른 저장 공간)에 상품 목록을 5분 동안 저장합니다. 그래서 서버마다 저장된 내용이 다릅니다. 이 때문에 가격을 바꾸면 고객에게 새 가격이 보이기까지 최대 5분이 걸립니다.

Redis를 도입하면 서버 4대가 캐시 서버 1대에 저장된 같은 상품 목록을 읽습니다. 그래서 서버마다 캐시 내용이 달라지는 문제가 없어집니다.

확인 필요: 가격 변경이 고객에게 보이는 시간이 5분에서 얼마나 줄어드는지는 아직 정해지지 않았습니다. 가격을 바꿀 때 Redis에 저장된 상품 목록을 바로 지우거나 갱신하는지, 지금처럼 5분 뒤 만료되기만 기다리는지에 따라 달라집니다.
