# API 키 관리 지침

## 교체 주기

1. 운영 환경 API 키는 90일마다 교체해야 한다.
2. 이 규칙은 예외 없이 지켜야 한다.
3. 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 교체 시점

1. 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
2. 장애 대응 중이면 업무 시간 밖에도 키를 교체해도 된다.

## 저장소 관리

1. API 키를 Git 저장소(코드 변경 이력을 기록하는 공간)에 커밋하면 안 된다.

## 키 발급 및 저장

1. Vault(비밀 값을 안전하게 보관하는 도구)의 웹 화면에는 API 키를 직접 발급하는 기능이 있다.
2. 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.
