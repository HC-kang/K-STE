# 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 `payment-api`의 운영 배포를 롤백하는 절차를 설명한다. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 된다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. **마이그레이션이 포함됐으면 롤백하면 안 된다.** 이때는 DBA 박지은에게 연락한다. 이후 단계는 하지 않는다.
3. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 6단계의 "롤백 이력"에 어떤 내용(예: 시각, 롤백한 사람, `<REVISION>`)을 남기는지 주어지지 않았다. 4단계와 5단계가 실패했을 때 할 일도 주어지지 않았다.
