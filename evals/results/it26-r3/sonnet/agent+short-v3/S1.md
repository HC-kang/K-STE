Redis를 도입하면 서버 4대가 캐시 하나를 같이 쓰므로, 서버마다 상품 목록 내용이 달라지는 문제가 없어집니다.

현재는 로컬 캐시(서버가 자기 메모리에 데이터를 임시로 저장해 두는 방식)를 씁니다. API 서버 4대가 각자 상품 목록을 5분 동안 저장합니다. 그래서 서버마다 저장한 내용이 다르고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버 1대입니다. 서버 4대가 이 캐시 서버에서 같은 상품 목록을 읽습니다. 그래서 같은 시점에 어느 서버에 접속했는지에 따라 고객이 다른 가격을 보는 일은 없어집니다.

확인 필요: Redis 도입 후에도 상품 목록을 5분 동안 저장하는지, 가격을 바꿀 때 저장된 목록을 바로 지우는지. 이 두 가지에 따라 가격 변경이 고객에게 반영되는 시간이 달라집니다.
