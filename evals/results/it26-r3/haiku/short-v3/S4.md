이 런북은 ArgoCD로 배포한 payment-api를 지정한 REVISION으로 롤백하는 절차를 정의한다.

## 1. 롤백 전 확인

**경고: 마이그레이션이 포함된 배포는 롤백하면 안 된다.**

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다.
3. 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 한다.
4. 마이그레이션이 포함되지 않은 경우에만 다음 단계로 진행한다.

확인 필요: 마이그레이션 포함 여부를 확인하는 방법(도구, 명령, 위치)은 제공되지 않았다.

## 2. 롤백 실행

롤백은 다음 명령으로 실행한다.

```
argocd app rollback payment-api <REVISION>
```

`<REVISION>` 자리에 롤백할 리비전 값을 넣는다.

확인 필요: 롤백할 REVISION 값을 확인하는 방법은 제공되지 않았다.

## 3. 롤백 후 검증과 기록

1. `/healthz`가 200을 반환하는지 확인해야 한다.
2. 결제 테스트 주문 1건이 성공하는지 확인해야 한다.
3. 롤백 이력을 #deploy 채널에 남겨야 한다.

확인 필요: `/healthz`를 확인할 주소, 결제 테스트 주문을 실행하는 방법, 검증이 실패했을 때의 조치, 이력에 포함할 항목은 제공되지 않았다.
