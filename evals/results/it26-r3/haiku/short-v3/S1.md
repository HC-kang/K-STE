로컬 캐시는 서버마다 자기 메모리(작업할 때 쓰는 임시 공간)에 데이터를 따로 저장하는 방식이고, Redis 캐시는 여러 서버가 함께 쓰는 공용 저장소(Redis)에 데이터를 저장하는 방식입니다.

| 구분 | 로컬 캐시 (현재) | Redis 캐시 (도입 예정) |
|---|---|---|
| 저장 위치 | 서버 4대 각각의 메모리 | 공용 캐시 서버 1대 |
| 서버 간 데이터 | 서버마다 내용이 다를 수 있습니다 | 서버 4대가 같은 데이터를 봅니다 |

현재 구조에서는 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다. Redis를 도입하면 서버 4대가 같은 캐시를 보므로, 가격 정보가 서버마다 다르게 보이는 문제는 줄어듭니다.

다만 Redis를 도입한다고 5분 지연이 자동으로 없어지지는 않습니다. 반영 시점은 캐시를 언제 갱신하거나 지우는지에 따라 정해지기 때문입니다.

확인 필요: 이번 도입 범위에 가격이 바뀔 때 캐시를 바로 지우는 작업이 포함되는지 확인해야 합니다.

Redis는 서버와 별도로 있는 저장소이므로, 서버가 캐시를 읽을 때마다 네트워크를 한 번 더 거치고, 이 서버에 문제가 생기면 서버 4대 모두 영향을 받을 수 있습니다.
