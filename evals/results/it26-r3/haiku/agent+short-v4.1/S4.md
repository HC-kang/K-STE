# 운영 배포 롤백 런북 (payment-api)

이 런북은 ArgoCD로 payment-api 운영 배포를 이전 리비전으로 롤백하는 절차다. 롤백 전에 DB 마이그레이션 포함 여부를 반드시 확인해야 하며, 마이그레이션이 포함됐으면 롤백하면 안 된다. 롤백 후에는 `/healthz`와 결제 테스트 주문으로 결과를 확인하고, 롤백 이력을 #deploy 채널에 남긴다.

## 사전 확인

1. 롤백 전에 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다. 이때 DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 다음 절차로 진행한다.

## 롤백

4. `<REVISION>`에 롤백할 리비전 값을 넣어 다음 명령을 실행한다.

```
argocd app rollback payment-api <REVISION>
```

## 결과 확인

5. `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 기록

7. 롤백 이력을 #deploy 채널에 남긴다.
