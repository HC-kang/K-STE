# payment-api 운영 배포 롤백 런북

배포 도구는 ArgoCD다. 이 런북은 payment-api 운영 배포를 지정한 리비전으로 되돌리는 절차를 다룬다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
2. 마이그레이션이 포함됐으면 **롤백하면 안 된다.** DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 다음 명령으로 payment-api를 롤백한다.

   `argocd app rollback payment-api <REVISION>`

4. 롤백 후 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. #deploy 채널에 롤백 이력을 남긴다.

## 확인 필요

- 확인 필요: `<REVISION>`에 넣을 값을 어디에서 확인하는지 정하지 않았다.
- 확인 필요: 4번의 `/healthz`를 호출할 주소가 정해지지 않았다.
- 확인 필요: 5번의 결제 테스트 주문을 실행할 환경과 방법이 정해지지 않았다.
- 확인 필요: 6번 이력에 적을 항목이 정해지지 않았다.
