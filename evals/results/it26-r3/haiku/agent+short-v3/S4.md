# 운영 배포 롤백 런북

payment-api 운영 배포를 ArgoCD로 롤백하는 절차다. 롤백 전에 DB 마이그레이션 포함 여부를 확인해야 하며, 마이그레이션이 포함된 배포는 롤백하면 안 된다. 롤백 후에는 `/healthz` 응답과 결제 테스트 주문을 확인하고, 롤백 이력을 #deploy 채널에 남긴다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
   확인 필요: 마이그레이션 포함 여부. 확인 방법과 확인 위치가 주어지지 않았다.
2. **경고:** 마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았을 때만 다음 롤백 절차를 진행한다.

## 롤백

4. 다음 명령으로 payment-api를 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

확인 필요: `<REVISION>`. 롤백할 REVISION 값을 정하는 기준이 주어지지 않았다.

## 롤백 후 확인

5. `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 기록

7. 롤백 이력을 #deploy 채널에 남긴다.
