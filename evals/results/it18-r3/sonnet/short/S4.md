# 운영 배포 롤백 런북

ArgoCD로 배포한 `payment-api`를 이전 리비전으로 되돌리는 절차를 정리한다.

## 롤백 전 확인

롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

**마이그레이션이 포함된 배포는 롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락해야 한다.

## 롤백 절차

마이그레이션이 포함되지 않았을 때만 아래 순서로 진행한다.

1. 다음 명령으로 롤백한다.
   ```
   argocd app rollback payment-api <REVISION>
   ```
2. `/healthz`가 200을 반환하는지 확인한다.
3. 결제 테스트 주문 1건이 성공하는지 확인한다.
4. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요

- 확인 필요: `<REVISION>` 값을 어디서 확인하는지 정해지지 않았다.
- 확인 필요: 배포에 DB 마이그레이션이 포함됐는지 확인하는 방법이 정해지지 않았다.
- 확인 필요: `/healthz`가 200이 아니거나 결제 테스트 주문이 실패할 때의 절차가 정해지지 않았다.
