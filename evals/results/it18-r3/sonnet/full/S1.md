Redis를 도입하면 서버 4대가 같은 캐시를 함께 보게 되어, 서버마다 캐시 내용이 달라지는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 미리 저장해 두고 다시 꺼내 쓰는 방식입니다. 지금은 로컬 캐시를 씁니다. API 서버(고객 화면에 데이터를 보내 주는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다.

이 때문에 서버마다 캐시 내용이 다릅니다. 가격을 바꾸면 바뀐 가격이 고객에게 최대 5분 늦게 보입니다.

Redis(여러 서버가 함께 쓰는 캐시 저장소)는 캐시 서버 1대를 두고 API 서버 4대가 그 서버 하나에 상품 목록을 저장하고 읽습니다. 4대가 같은 저장소를 읽으므로, 서버에 따라 고객에게 다른 상품 목록이나 다른 가격이 보이는 일이 없어집니다.
