이 문서는 API 키(외부 서비스나 내부 시스템에 접속할 때 쓰는 인증 값)의 교체와 보관 기준을 정한다.

## 교체 규칙

- 운영 환경 API 키는 90일마다 교체해야 한다.
- 90일 교체 규칙은 예외 없이 지켜야 한다.
- 개발 환경 API 키는 90일마다 교체하지 않아도 된다.
- 운영 환경 API 키는 평일 업무 시간(10:00-18:00)에 교체하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에 교체해도 된다.

## 보관과 금지

- **API 키를 Git(코드 변경 이력을 관리하는 도구)의 저장소에 커밋하면 안 된다.**
- Vault(비밀 값을 안전하게 보관하는 도구)의 웹 화면에는 API 키를 직접 발급하는 기능이 있다.
- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.
