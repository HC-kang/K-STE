로컬 캐시와 Redis 캐시의 차이는 자료를 저장하는 위치입니다. 캐시(자주 쓰는 자료를 다시 꺼내 쓰려고 임시로 저장해 두는 공간)는 지금 API 서버 4대가 각자 자기 메모리에 둡니다. Redis는 서버 4대가 함께 쓰는 캐시 서버 1대에 둡니다.

지금은 서버마다 상품 목록을 5분 동안 따로 저장합니다. 서버마다 저장된 내용이 달라서, 가격을 바꾸면 고객 화면에 바뀐 가격이 최대 5분 늦게 나타납니다.

Redis를 도입하면 서버 4대가 같은 캐시 서버의 자료를 읽습니다. 그래서 서버끼리 내용이 달라지는 문제가 줄어들 것으로 보입니다. 다만 Redis 도입만으로 5분 지연이 없어지지는 않습니다. 가격이 바뀔 때 캐시 자료를 지우거나 새로 쓰는 작업을 함께 설계해야 지연을 줄일 수 있습니다. 이 작업의 범위와 일정은 개발팀과 확인이 필요합니다.
