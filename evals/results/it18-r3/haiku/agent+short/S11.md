# API 키 관리 지침

## 목적

이 지침은 API 키(서비스를 호출할 때 신원을 증명하는 비밀 문자열)의 교체와 보관 방법을 정한다.

## 키 교체 주기

- 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.
- 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 키 교체 시간

- 키 교체는 평일 업무 시간인 10:00-18:00에 하는 것을 권장한다.
- 장애가 발생한 상황이면 업무 시간 밖에 키를 교체해도 된다.

## 키 발급과 보관

- Vault(비밀 값을 보관하는 도구)의 웹 화면에서 키를 직접 발급할 수 있다.
- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 금지 사항

- API 키를 Git 저장소(코드 변경 이력을 보관하는 저장소)에 커밋(변경 내용을 저장소에 기록하는 작업)하면 안 된다.
