# API 키 관리 지침

이 문서는 API 키의 교체 주기, Git 저장소 관리, 교체 시간, 저장 위치를 정한다. 운영 환경 API 키는 90일마다 교체해야 하며, 이 규칙은 예외 없이 지켜야 한다.

## 적용 범위

운영 환경 API 키에는 이 지침의 모든 규칙을 적용해야 한다.

개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 교체 주기

운영 환경 API 키는 90일마다 교체해야 한다.

확인 필요: 90일마다. 기산점(발급일 또는 직전 교체일)이 정해져 있지 않다.

## Git 저장소 관리

API 키를 Git 저장소에 커밋하면 안 된다.

## 교체 시간

키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.

장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.

## 저장 위치와 발급

교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

확인 필요: 교체한 키. 운영 환경 키에만 해당하는지, 개발 환경 키도 포함하는지 정해져 있지 않다.

Vault 웹 화면에서 키를 직접 발급할 수 있다.
