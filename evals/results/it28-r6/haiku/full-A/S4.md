# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포된 payment-api 운영 배포를 롤백하는 절차를 정한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 되고 DBA에게 연락해야 한다. 롤백 후에는 헬스체크와 결제 테스트 주문으로 결과를 검증하고, 롤백 이력을 #deploy 채널에 남긴다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다. DBA 박지은에게 연락하고, 이 런북의 롤백 절차를 진행하지 않는다.
3. 마이그레이션이 포함되지 않았으면 다음 단계로 진행한다.

## 2. 롤백 실행

4. 다음 명령으로 롤백한다. `<REVISION>`에는 롤백할 리비전을 넣는다.

```
argocd app rollback payment-api <REVISION>
```

## 3. 롤백 후 검증

5. `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문을 1건 실행하고, 주문이 성공하는지 확인한다.

## 4. 이력 기록

7. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 7번 단계를 진행하는 시점. 롤백 직후인지 검증(5-6번 단계) 후인지 사실에 없습니다.
