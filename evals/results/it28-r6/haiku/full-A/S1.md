로컬 캐시와 Redis 캐시의 차이는 임시 복사본을 어디에 두느냐입니다. 캐시는 자주 쓰는 데이터를 빨리 꺼내 쓰려고 미리 넣어 두는 임시 복사본입니다.

| 구분 | 현재 로컬 캐시 | Redis 캐시 도입 후 |
|---|---|---|
| 상품 목록 보관 위치 | API 서버 4대 각각의 메모리 | 캐시 서버 1대 |
| 서버 사이 내용 | 서버마다 다름 | 4대가 같은 내용을 봄 |
| 가격 변경의 고객 반영 | 최대 5분 늦게 반영 | 확인 필요 |

Redis는 여러 서버가 함께 쓰는 외부 캐시 저장소입니다. 도입하면 서버 4대가 같은 상품 목록을 보므로, 서버마다 내용이 달라서 생기는 문제는 없어집니다.

다만 가격 변경이 고객에게 보이는 시간은 Redis의 상품 목록을 언제 고치는지에 따라 달라집니다. 확인 필요: 가격 변경 후 Redis 캐시를 갱신하는 방식. 즉시 갱신하는 경우와 기존처럼 5분 뒤에 만료되는 경우.
