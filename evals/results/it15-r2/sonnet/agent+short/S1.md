로컬 캐시는 API 서버마다 따로 갖는 메모장이고, Redis(여러 서버가 함께 쓰는 캐시 전용 서버)는 서버 4대가 같이 보는 메모장 1개입니다. Redis를 도입하면 서버마다 캐시 내용이 달라지는 문제가 없어집니다.

| 구분 | 로컬 캐시(현재) | Redis(도입 예정) |
|---|---|---|
| 저장 위치 | API 서버 4대가 각자의 메모리에 저장합니다. | 캐시 서버 1대에 저장합니다. |
| 캐시 내용 | 서버마다 다를 수 있습니다. | 서버 4대가 같은 내용을 봅니다. |
| 상품 목록 보관 시간 | 서버마다 5분 동안 보관합니다. | 이 표에서는 정해진 값이 없습니다. |

현재는 서버마다 상품 목록을 따로 5분 동안 캐시합니다. 그래서 가격을 바꾸면 서버마다 새 가격을 가져오는 시점이 달라지고, 고객에게는 최대 5분 늦게 반영됩니다. Redis를 도입하면 서버 4대가 같은 캐시를 보기 때문에, 같은 시점에 서버마다 다른 가격이 보이는 일이 없어집니다.
