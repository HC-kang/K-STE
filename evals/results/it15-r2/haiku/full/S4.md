# payment-api 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 payment-api 운영 배포를 이전 REVISION으로 되돌리는 절차를 다룬다. 롤백하려는 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 되고 DBA에게 연락해야 한다. 마이그레이션이 없을 때만 롤백을 실행하고, 롤백 후에는 `/healthz` 응답과 결제 테스트 주문으로 결과를 확인한 뒤 #deploy 채널에 이력을 남긴다.

## 1. 롤백 전 확인

**롤백하려는 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다.**

1. 롤백하려는 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
2. 마이그레이션이 포함됐으면 롤백하지 않는다. DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았을 때만 다음 단계로 진행한다.

## 2. 롤백 실행

4. 아래 명령을 실행해 payment-api를 `<REVISION>`으로 롤백한다.

   `argocd app rollback payment-api <REVISION>`

## 3. 롤백 후 확인

5. `/healthz` 응답 코드가 200인지 확인해야 한다.
6. 결제 테스트 주문을 1건 실행하고, 그 주문이 성공하는지 확인해야 한다.

## 4. 이력 기록

7. 롤백 이력을 #deploy 채널에 남긴다.
