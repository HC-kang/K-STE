# 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 `payment-api`를 이전 리비전으로 되돌리는 절차다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 되고 DBA에게 연락해야 한다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
2. **경고:** 마이그레이션이 포함됐으면 롤백하면 안 된다. DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 다음 절차로 넘어간다.

## 롤백

4. `<REVISION>` 자리에 롤백할 리비전을 넣고 다음 명령을 실행한다.

```
argocd app rollback payment-api <REVISION>
```

## 결과 확인

5. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
6. 롤백한 뒤 결제 테스트 주문 1건이 성공하는지 확인한다.

## 기록

7. 롤백 이력을 #deploy 채널에 남긴다.
