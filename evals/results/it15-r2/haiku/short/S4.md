이 문서는 payment-api 운영 배포를 ArgoCD로 롤백하는 절차를 정의한다.

## 1. 롤백 전 확인

1. 롤백할 배포의 REVISION 값을 확인해야 한다. 확인 필요: REVISION 값을 찾는 위치와 방법.
2. 해당 배포에 DB 마이그레이션(데이터베이스 구조를 바꾸는 스크립트)이 포함됐는지 확인해야 한다. 확인 필요: 마이그레이션 포함 여부를 확인하는 방법과 위치.
3. 마이그레이션이 포함됐으면 **롤백하면 안 된다.**
4. 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 한다.
5. 마이그레이션이 포함되지 않았으면 다음 단계로 진행한다.

## 2. 롤백 실행

1. 다음 명령을 실행한다: `argocd app rollback payment-api <REVISION>`
2. 명령 실행 결과를 확인한다. 확인 필요: 정상 실행으로 판단하는 기준.

## 3. 롤백 후 검증

1. `/healthz`가 200을 반환하는지 확인해야 한다. 확인 필요: 요청을 보낼 주소와 확인 방법.
2. 결제 테스트 주문 1건이 성공하는지 확인해야 한다. 확인 필요: 테스트 주문을 실행하는 방법과 테스트 계정.
3. 검증이 실패하면 어떤 조치를 할지 확인 필요: 실패 시 조치 절차와 담당자.

## 4. 이력 기록

1. 롤백 이력을 #deploy 채널에 남겨야 한다. 확인 필요: 기록에 포함할 항목과 형식.
