캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: "배포 후 재시작하면 초기화됩니다". 무엇이 초기화되는지 쓰여 있지 않습니다. 초기화되는 대상이 서버의 메모리 내용일 수도 있고, 서버 설정일 수도 있습니다.
확인 필요: "캐시 서버와 API 서버는 ~ 초기화됩니다". 재시작 시 초기화가 두 서버 모두에 해당할 수도 있고, 캐시 서버에만 해당할 수도 있습니다.
확인 필요: "관리자 권한이 있는 팀원 및 QA 담당자". 관리자 권한 조건이 QA 담당자에게도 걸려 둘 다 관리자 권한자일 수도 있고, 팀원에게만 걸려 QA 담당자는 권한과 무관하게 해당할 수도 있습니다.
