로컬 캐시는 서버마다 따로 쓰는 임시 저장소이고, Redis 캐시는 서버 4대가 함께 쓰는 임시 저장소입니다. 캐시는 자주 조회하는 상품 목록을 미리 담아 두고 빠르게 보여 주는 용도입니다.

현재는 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 보관합니다. 서버마다 보관한 시점이 달라서 내용이 서로 다를 수 있습니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영되고, 같은 시점에도 어느 서버에 연결됐는지에 따라 고객이 보는 가격이 다를 수 있습니다.

Redis를 도입하면 서버 4대가 캐시 서버 1대를 같이 읽습니다. 서버마다 캐시 내용이 달라지는 문제가 없어지고, 어느 서버에 연결돼도 고객이 같은 상품 목록을 봅니다.

가격 반영이 5분에서 얼마나 빨라지는지는 아직 정해지지 않았습니다. 이 시간은 Redis에 담긴 내용을 언제 갱신하느냐에 따라 달라집니다. 가격 변경 시 즉시 갱신할지를 개발팀과 정하십시오.

확인 필요: Redis 서버가 1대여서, 이 서버에 문제가 생겼을 때 서비스가 어떻게 동작하는지는 확인하지 않았습니다.
