이 런북은 ArgoCD로 배포하는 payment-api 운영 배포를 이전 리비전으로 되돌리는 절차를 설명한다.

## 1. 마이그레이션 포함 여부 확인

롤백 전에 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인한다.

**마이그레이션이 포함됐으면 롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락하고 이후 절차를 진행하지 않는다.

확인 필요: 마이그레이션 포함 여부를 확인하는 방법은 제공된 사실에 없다.

## 2. 롤백 실행

마이그레이션이 포함되지 않았을 때만 다음 명령으로 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

`<REVISION>`에는 롤백할 리비전 값을 넣는다.

확인 필요: 롤백할 리비전 값을 찾는 방법은 제공된 사실에 없다.

## 3. 롤백 후 확인

롤백 후 다음 두 가지를 순서대로 확인한다.

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

확인 필요: 어느 한 항목이라도 실패했을 때 대응 절차는 제공된 사실에 없다.
