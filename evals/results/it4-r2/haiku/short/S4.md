이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 이전 REVISION으로 되돌리는 절차를 정한다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션(데이터베이스 구조나 데이터를 바꾸는 변경 스크립트)이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않은 경우에만 2단계로 넘어간다.

**경고: 마이그레이션이 포함된 배포는 롤백하지 않는다.**

확인 필요: 마이그레이션 포함 여부를 확인하는 구체적인 방법이 원문에 없으므로, 확인 방법과 확인 담당자를 이 런북에 추가해야 한다.

## 2. 롤백 실행

`argocd app rollback payment-api <REVISION>` 명령에서 `<REVISION>`에 되돌릴 REVISION 값을 넣어 실행한다.

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 4. 이력 기록

#deploy 채널에 롤백 이력을 남긴다.
