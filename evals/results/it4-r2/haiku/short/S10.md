현재 원인은 확정되지 않았다. 가장 유력한 가설은 로컬 `node_modules`에 1.4.0이 남아 있어서 로컬 빌드가 2.0.0을 검증하지 못한다는 것이다.

## 확인된 사실

- 3일 전에 `@company/ui`를 1.4.0에서 2.0.0으로 올렸다.
- 2.0.0에서 패키지에 `exports` 필드가 추가되었다.
- CI는 Node 18을 쓰고, 로컬은 Node 20을 쓴다.
- CI 캐시 키는 `package-lock.json`의 해시다.
- 로컬 `node_modules`는 3일 전보다 먼저 설치되었다.
- CI 빌드는 `Cannot find module '@company/ui/button'` 에러로 실패한다.
- 로컬 빌드는 성공한다.

## 추론

- `exports` 필드가 있으면 패키지는 그 목록에 적힌 경로만 외부에 공개한다. `./button` 항목이 2.0.0 `exports`에 없거나 다른 경로로 바뀌었다면 `@company/ui/button` import는 해석에 실패한다.
- 로컬 `node_modules`를 3일 전보다 먼저 설치한 뒤 다시 설치하지 않았다면, 로컬에는 `exports`가 없는 1.4.0이 남아 있을 가능성이 크다. 1.4.0에서는 `@company/ui/button` 경로가 그대로 동작하므로 로컬 빌드가 성공한다. 이 경우 로컬 빌드 성공은 2.0.0의 동작을 검증한 결과가 아니다.
- `package-lock.json`이 바뀌면 캐시 키도 바뀐다. 따라서 CI는 캐시를 쓰지 못하고 2.0.0을 새로 설치한다. 이 설치 결과가 실패 원인과 맞물린다고 볼 수 있다.
- `exports` 필드는 Node 18에서도 지원된다. 따라서 Node 버전 차이만으로 이 에러가 난다고 보기는 어렵다. 다만 Next.js 버전이 요구하는 최소 Node 버전에 따라 영향이 달라질 수 있다.
- Node 18은 2025년 4월에 지원이 종료되었다. CI의 Node 버전을 올리는 것은 별도로 검토할 만하다.

## 환경 비교

| 항목 | 로컬 | CI | 영향 가능성 |
|---|---|---|---|
| Node 버전 | 20 | 18 | Next.js 최소 요구 버전을 확인해야 한다 |
| `@company/ui` 버전 | 1.4.0으로 추정 (미확인) | 2.0.0으로 추정 (미확인) | 가장 유력한 차이다 |
| `node_modules` 상태 | 3일 전 설치본 | 캐시 미스 후 새로 설치 | 로컬이 2.0.0을 검증하지 않을 수 있다 |

## 미확인 사항

- 2.0.0 `package.json`의 `exports` 목록에 `./button`이 있는지 확인되지 않았다.
- 로컬에 실제로 설치된 `@company/ui` 버전이 확인되지 않았다.
- CI 로그의 설치된 버전과 실패 단계가 확인되지 않았다.
- 커밋된 `package-lock.json`에 2.0.0이 들어 있는지 확인되지 않았다.
- 사용 중인 Next.js 버전과 그 최소 Node 요구 사항이 확인되지 않았다.
- 실패가 업그레이드 커밋 이후 처음 발생했는지 확인되지 않았다.

## 확인 순서

1. 로컬에서 `npm ls @company/ui`를 실행하여 설치된 버전을 확인한다.
2. `node_modules/@company/ui/package.json`의 `exports` 항목에 `./button`이 있는지 확인한다.
3. CI 로그에서 설치된 `@company/ui` 버전과 실패한 빌드 단계를 확인한다.
4. 로컬에서 `rm -rf node_modules && npm ci`로 다시 설치한 뒤 빌드하여 재현 여부를 확인한다.
5. 로컬을 Node 18로 바꿔 빌드하여 Node 버전의 영향을 분리한다.

## 수정 방향

- 2.0.0 `exports`에 `./button`이 없다면, import 경로를 `exports`에 있는 경로로 바꾸거나 패키지 관리자에게 `exports` 항목 추가를 요청한다.
- 4번 확인에서 로컬이 재현되면, 로컬 빌드 성공을 근거로 2.0.0 검증이 끝났다고 보지 않는다.
- 5번 확인에서 Node 18에서만 실패하면, CI의 Node 버전을 Next.js가 지원하는 최신 LTS 버전으로 올리는 것을 검토한다.
