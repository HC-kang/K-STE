# 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 `payment-api`의 운영 배포를 롤백하는 절차를 설명한다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인한다.
2. **경고:** 그 배포에 DB 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다.

## 절차

1. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

## 결과 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 기록

1. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요

- 마이그레이션 포함 여부를 확인하는 방법을 받지 못했다. 방법을 알려 주면 사전 확인에 추가한다.
- `<REVISION>`에 넣을 값을 찾는 방법을 받지 못했다.
- 박지은의 연락 수단을 받지 못했다.
- `/healthz`가 200을 반환하지 않거나 테스트 주문이 실패할 때의 조치를 받지 못했다.
