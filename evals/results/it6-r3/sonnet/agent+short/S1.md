로컬 캐시는 서버마다 따로 저장하는 방식이고, Redis 캐시는 서버 4대가 하나를 같이 쓰는 방식입니다. Redis를 도입하면 서버마다 상품 목록이 다르게 보이는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 미리 저장해 두고 다시 꺼내 쓰는 방식입니다. 지금은 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 이것이 로컬 캐시입니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 캐시를 전용으로 맡는 서버입니다. 이번에는 서버 4대가 Redis 서버 1대를 같이 씁니다. 그래서 4대가 같은 상품 목록을 보고, 서버에 따라 내용이 달라지는 일이 없어집니다.

가격 반영이 늦는 시간이 얼마나 줄어드는지는 가격을 바꿀 때 Redis의 캐시를 어떻게 갱신하느냐에 따라 달라집니다.
