Redis를 도입하면 4대 서버가 같은 상품 캐시를 함께 쓰게 되어, 서버마다 캐시 내용이 달라지는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 매번 원본에서 가져오지 않도록 가까운 곳에 임시로 저장해 두는 공간입니다. 지금은 각 API 서버가 자기 메모리에 상품 목록을 5분 동안 캐시합니다. Redis는 여러 서버가 함께 쓰는 별도의 캐시 서버입니다.

| 구분 | 현재(서버 메모리 캐시) | Redis 도입 후 |
|---|---|---|
| 캐시 저장 위치 | 각 API 서버 안 | 별도 캐시 서버 1대 |
| 서버 간 공유 | 공유하지 않습니다 | 4대가 같은 데이터를 봅니다 |
| 가격 변경 반영 | 서버마다 최대 5분 늦게 반영됩니다 | 갱신 방식에 따라 달라집니다 |

가격 변경이 고객에게 얼마나 빨리 반영될지는 Redis에 저장한 상품 정보를 언제 갱신하는지에 따라 정해집니다. 이 기준은 도입 전에 정해야 합니다. 대신 서버가 상품 정보를 읽을 때 캐시 서버를 한 번 더 거치므로, 응답이 약간 느려질 수 있습니다.
