# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 이전 리비전으로 되돌리는 절차다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 확인하고, 포함됐으면 롤백하지 않는다. 롤백 후에는 `/healthz` 응답과 결제 테스트 주문으로 정상 동작을 확인하고, 롤백 이력을 #deploy 채널에 남긴다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다. 확인 필요: 마이그레이션 포함 여부를 확인하는 방법을 정하지 않았다.
2. **경고:** 마이그레이션이 포함됐으면 롤백하지 않는다. DBA 박지은에게 연락한다. 확인 필요: DBA 연락 채널과 연락처를 정하지 않았다.
3. 마이그레이션이 포함되지 않았으면 다음 단계로 넘어간다.
4. 롤백할 리비전 번호를 확인한다. 확인 필요: 리비전 번호를 확인하는 방법을 정하지 않았다.

## 롤백 실행

5. 다음 명령으로 롤백한다. `<REVISION>`에는 4번 단계에서 확인한 리비전 번호를 넣는다.

```
argocd app rollback payment-api <REVISION>
```

## 결과 확인

6. `/healthz`가 200을 반환하는지 확인한다. 확인 필요: 요청을 보낼 주소와 확인 방법을 정하지 않았다.
7. 결제 테스트 주문 1건을 실행하고 주문이 성공하는지 확인한다. 확인 필요: 테스트 주문을 실행하는 방법과 테스트 결제 수단을 정하지 않았다.
8. 6번 또는 7번 확인이 실패했을 때의 조치를 정하지 않았다. 확인 필요: 실패 시 조치와 담당자를 정한다.

## 기록

9. #deploy 채널에 롤백 이력을 남긴다. 확인 필요: 이력에 포함할 항목을 정하지 않았다.
