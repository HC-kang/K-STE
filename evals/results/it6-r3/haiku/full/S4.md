# 운영 배포 롤백 런북: payment-api

이 런북은 ArgoCD로 배포한 payment-api의 운영 배포를 이전 리비전으로 되돌리는 절차를 정한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함되었는지 확인한다. 마이그레이션이 포함되었으면 롤백하지 않고 DBA 박지은에게 연락한다.

## 1. 롤백 전 확인

1. 롤백 대상 배포에 DB 마이그레이션이 포함되었는지 확인한다.
2. 마이그레이션이 포함되었으면 DBA 박지은에게 연락한다. **롤백하지 않는다.** 이후 단계를 진행하지 않는다.
3. 마이그레이션이 포함되지 않았음을 확인한 경우에만 다음 단계로 진행한다.

## 2. 롤백 실행

4. 다음 명령으로 롤백한다. `<REVISION>`에는 롤백할 대상 리비전을 넣는다.

   `argocd app rollback payment-api <REVISION>`

## 3. 롤백 후 확인

5. `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 4. 이력 기록

7. #deploy 채널에 롤백 이력을 남긴다.

## 미정 사항

- 롤백 대상 배포에 마이그레이션이 포함되었는지 확인하는 방법과 담당자가 정해지지 않았다.
- `/healthz` 확인에 쓸 주소와 결제 테스트 주문 실행 방법이 정해지지 않았다.
- 5번 또는 6번 확인이 실패했을 때의 조치가 정해지지 않았다.
