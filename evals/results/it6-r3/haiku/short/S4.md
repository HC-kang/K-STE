이 런북은 ArgoCD로 배포한 payment-api를 이전 리비전으로 되돌리는 절차를 설명한다.

## 절차

1. 롤백할 대상 리비전 번호(REVISION)를 확인한다. 확인 필요: 리비전 번호를 조회하는 방법.
2. 해당 배포에 DB 마이그레이션(데이터베이스 구조를 바꾸는 변경 작업)이 포함됐는지 확인한다. 확인 필요: 마이그레이션 포함 여부를 확인하는 방법.
3. **마이그레이션이 포함됐으면 롤백하지 않는다.** 이 경우 DBA 박지은에게 연락하고 4번 이후를 진행하지 않는다. 확인 필요: DBA 박지은에게 연락하는 방법.
4. 마이그레이션이 포함되지 않았으면 `argocd app rollback payment-api <REVISION>` 명령을 실행한다. `<REVISION>`에는 1번에서 확인한 리비전 번호를 넣는다.
5. `/healthz`(서비스 상태를 확인하는 주소)가 200을 반환하는지 확인한다. 확인 필요: `/healthz`에 접속하는 주소.
6. 결제 테스트 주문 1건을 실행하고 결제가 성공하는지 확인한다. 확인 필요: 결제 테스트 주문을 실행하는 방법.
7. 롤백 이력을 #deploy 채널에 남긴다.
