로컬 캐시는 서버마다 따로 저장하고, Redis 캐시는 서버 4대가 함께 쓰는 저장소 한 대에 저장합니다. 캐시는 자주 쓰는 데이터를 빨리 꺼내 쓰려고 미리 넣어 두는 임시 저장 공간입니다. Redis는 이런 임시 저장 작업을 전담하는 별도의 서버 프로그램입니다.

지금은 API 서버 4대가 각자의 메모리(컴퓨터가 작업할 때 쓰는 임시 공간)에 상품 목록을 5분 동안 보관합니다. 그래서 서버마다 보관 내용이 다를 수 있고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

| 구분 | 현재 로컬 캐시 | Redis 캐시 |
|---|---|---|
| 저장 위치 | 서버 4대 각각의 메모리 | 캐시 서버 1대 |
| 서버 간 보관 내용 | 서버마다 다를 수 있습니다 | 4대 서버가 같은 내용을 봅니다 |
| 가격 변경 반영 시점 | 최대 5분 뒤 | 확인 필요 |

Redis를 도입하면 서버 4대가 같은 상품 정보를 보게 되므로, 서버에 따라 가격이 다르게 보이는 문제는 줄어듭니다.

다만 Redis 서버 1대에 4대가 모두 의존하게 되므로, 이 서버가 멈추면 영향을 받는 범위가 넓어집니다.

확인 필요: Redis를 도입해도 가격이 바로 반영되는지는 아직 알 수 없습니다. 반영 시점은 Redis에 보관한 정보를 몇 분 뒤에 지우는지, 가격을 바꿀 때 바로 지우는지에 따라 정해집니다. 이 기준이 정해졌는지 확인이 필요합니다.
