로컬 캐시는 서버 4대가 각자 따로 저장하는 방식이고, Redis 캐시는 서버 4대가 캐시 서버 1대에 함께 저장하는 방식입니다. 그래서 Redis를 도입하면 서버마다 상품 목록이 서로 다른 문제는 없어집니다.

지금은 서버마다 상품 목록을 자기 메모리에 5분 동안 캐시(자주 쓰는 데이터를 임시로 저장해 두는 것)합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 서버 4대가 같은 캐시 서버 1대를 읽습니다. 그래서 같은 시점에 어느 서버에 접속해도 고객은 같은 상품 목록을 봅니다.
