Redis를 도입하면 API 서버(고객 요청을 받아 응답하는 서버) 4대가 같은 캐시를 함께 쓰게 되어, 서버마다 상품 목록 내용이 달라지는 문제가 없어집니다.

지금은 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시(자주 보는 데이터를 임시로 저장해 두는 방식)합니다. 이것이 로컬 캐시입니다. 서버마다 캐시 내용이 다르기 때문에, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 캐시만 맡는 서버 1대입니다. 서버 4대가 상품 목록을 이 서버 한 곳에서 함께 읽고 씁니다. 그래서 어느 서버로 요청이 들어와도 고객은 같은 상품 목록을 봅니다.

가격 변경이 고객에게 얼마나 빨리 보이는지는 Redis 캐시를 갱신하는 방식에 따라 달라집니다.
