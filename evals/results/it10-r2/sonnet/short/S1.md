Redis를 도입하면 서버 4대가 같은 상품 목록을 보게 되어, 서버마다 캐시 내용이 달라지는 문제가 사라집니다.

캐시는 자주 쓰는 데이터를 매번 새로 가져오지 않도록 임시로 저장해 두는 것입니다. 지금은 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장하고, 이것을 로컬 캐시라고 부릅니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 서버 4대가 함께 쓰는 캐시 서버 1대입니다. 4대가 같은 캐시를 읽기 때문에, 같은 시점에 어느 서버에 접속하든 고객은 같은 상품 목록을 봅니다.

다만 가격 변경이 고객에게 바로 보일지는 Redis 도입만으로 정해지지 않습니다. 가격을 바꿀 때 Redis의 캐시를 함께 지우는지, 5분 저장 시간을 그대로 두는지에 따라 달라집니다. 이번 도입에서 어느 쪽으로 할지는 제가 아직 확인하지 못했습니다.

Redis 서버가 1대이므로, 이 서버에 문제가 생기면 API 서버 4대가 모두 영향을 받을 수 있습니다. 로컬 캐시는 서버마다 따로 있어서 이런 영향이 없습니다.
