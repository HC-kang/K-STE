# API 키 관리 지침

## 교체 규칙

- 운영 환경 API 키는 90일마다 교체해야 한다.
- 운영 환경 API 키의 90일 교체 규칙에는 예외가 없다.
- 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 교체 시간

- 담당자는 API 키를 평일 업무 시간(10:00-18:00)에 교체하는 것을 권장한다.
- 장애 대응 중이면 담당자가 업무 시간 밖에 API 키를 교체해도 된다.

## 저장과 커밋

- 담당자는 교체한 API 키를 Vault의 `prod/api-keys` 경로에 저장해야 한다.
- API 키를 Git 저장소에 커밋하면 안 된다.

## Vault 웹 화면

- Vault 웹 화면에는 API 키를 직접 발급하는 기능이 있다.
