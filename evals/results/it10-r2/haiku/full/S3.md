# 토큰 만료 경계에서 유효 판정 수정

## 배경

토큰 만료 시각과 정확히 같은 시각에 요청하면 `auth/token.py`의 `is_valid()`가 토큰을 유효하다고 판단했다. 관련 이슈는 #412다.

## 변경 사항

- `is_valid()`의 비교 조건을 `now <= expires_at`에서 `now < expires_at`로 바꿨다. 이에 따라 `now`가 `expires_at`과 같은 시각이면 토큰은 유효하지 않다고 판단된다.
- 테스트 `test_token_expired_at_boundary`를 추가했다.
- 테스트 `test_token_valid_before_expiry`를 추가했다.

## 테스트

- 로컬에서 단위 테스트를 실행했고 모두 통과했다.
- 통합 테스트는 아직 실행하지 않았다.
