**다듬은 공지**

> 캐시 서버와 API 서버는 메모리 사용량이 많습니다. 두 서버를 재시작하면 메모리에 저장된 데이터가 초기화되므로, 배포 후 재시작 시 이 점에 유의해 주세요.
>
> 배포 담당자(관리자 권한을 가진 팀원 및 QA 담당자)는 배포 전에 공지 채널에 배포 일정과 대상 서버를 알려야 합니다.

**바꾼 점**
- "배포 후 재시작하면 초기화됩니다"는 무엇이 초기화되는지 빠져 있어서 "메모리에 저장된 데이터"로 명시했습니다.
- "관리자 권한이 있는 팀원 및 QA 담당자"는 수식 범위가 모호합니다. QA 담당자에게도 관리자 권한이 필요한 것인지, 두 부류가 따로인지 알 수 없습니다. 위 문안은 두 부류를 모두 배포 담당자로 묶었으니 의도와 다르면 알려주세요.
- "알려야 합니다"는 알릴 내용이 없어서 "배포 일정과 대상 서버"를 넣었습니다.

**확인이 필요한 부분**
- 초기화 대상이 메모리 데이터가 맞는지, 아니면 캐시 데이터에 한정되는지.
- 알려야 할 내용이 일정과 대상 서버가 맞는지.
- 권한 범위를 "관리자 권한을 가진 팀원과 관리자 권한이 없는 QA 담당자"처럼 구분해야 하는지.
