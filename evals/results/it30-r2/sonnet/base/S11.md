# API 키 관리 지침

## 1. 적용 범위

이 문서는 운영 환경과 개발 환경의 API 키 관리 방법을 정한다.

## 2. 필수 규칙

| 구분 | 규칙 |
|---|---|
| 운영 키 교체 | 운영 환경 API 키는 **90일마다 교체한다. 예외는 없다.** |
| 저장 위치 | 교체한 키는 Vault의 `prod/api-keys` 경로에 저장한다. |

## 3. 금지 사항

- API 키를 Git 저장소에 커밋하지 않는다.

## 4. 권장 사항

- 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
- 장애 대응 중에는 업무 시간 밖에 교체해도 된다.

## 5. 개발 환경

개발 환경 API 키에는 90일 교체 규칙이 적용되지 않는다. 단, 3장의 Git 커밋 금지는 개발 환경 키에도 똑같이 적용된다.

## 6. 참고

- Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.

---

문서를 쓰면서 확인할 점이 두 가지 있습니다.

1. **Vault 웹 화면 발급 기능**: 원문에는 기능이 있다는 사실만 있고, 사용해도 되는지 또는 써야 하는지는 없습니다. 그래서 규칙이 아닌 참고 항목으로만 두었습니다. 사용 가능 여부나 권장 여부를 정하시면 해당 장으로 옮기겠습니다.
2. **개발 환경 키의 Git 커밋**: 원문의 금지 규칙은 환경을 구분하지 않으므로, 개발 키에도 적용된다고 명시했습니다. 의도와 다르면 알려 주세요.
