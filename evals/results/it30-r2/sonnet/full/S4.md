# 운영 배포 롤백 런북

이 문서는 ArgoCD로 운영 배포를 롤백하는 절차를 정리한다. 롤백 전에 배포에 DB 마이그레이션이 포함됐는지 확인해야 하고, 롤백한 뒤에는 `/healthz` 응답과 결제 테스트 주문을 확인한다.

## 규칙

- 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
- 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다.
- 배포에 DB 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 한다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. DB 마이그레이션이 포함됐으면 롤백하지 말고 DBA 박지은에게 연락한다.
3. DB 마이그레이션이 포함되지 않았으면 `argocd app rollback payment-api <REVISION>` 명령으로 롤백한다.
4. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.
