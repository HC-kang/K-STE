# 운영 배포 롤백 런북

## 사전 조건

롤백 전에 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

**마이그레이션이 포함된 배포는 롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락하고, 아래 롤백 단계를 실행하지 않는다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았으면 배포 도구 ArgoCD로 롤백한다. `<REVISION>` 자리에 롤백 대상 리비전을 넣는다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요

- 마이그레이션 포함 여부를 어디서 확인하는지 정해지지 않았다.
- `/healthz`를 호출할 대상 주소가 정해지지 않았다.
- 4번이나 5번 확인이 실패했을 때의 조치가 정해지지 않았다.
