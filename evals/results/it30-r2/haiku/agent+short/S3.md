# 토큰 만료 시각 경계 판정 수정 (#412)

토큰이 만료 시각과 정확히 같은 시각에 요청되면 유효하다고 판단하던 버그를 고친다. 이번 변경으로 `auth/token.py`의 `is_valid()`는 현재 시각이 만료 시각보다 작을 때만 토큰을 유효하다고 판단한다.

## 변경 내용

`auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다. 테스트 2개를 추가했다: `test_token_expired_at_boundary`, `test_token_valid_before_expiry`.

## 검증

로컬에서 단위 테스트를 모두 통과했다. 통합 테스트는 아직 실행하지 않았다.
