# payment-api 운영 배포 롤백 런북

## 대상과 도구

이 런북은 ArgoCD로 배포한 payment-api의 운영 배포를 이전 리비전으로 되돌리는 절차를 다룬다. 롤백 명령은 `argocd app rollback payment-api <REVISION>`이다. `<REVISION>`에는 롤백할 리비전 값을 넣는다. 확인 필요: 롤백할 리비전 값을 조회하는 명령과 방법.

## 롤백 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인한다. 확인 필요: 마이그레이션 포함 여부를 확인할 위치와 방법.
2. 마이그레이션이 포함됐으면 **롤백하면 안 된다.** DBA 박지은에게 연락한다. 이 경우 롤백 절차를 더 진행하지 않는다.
3. 마이그레이션이 포함되지 않았으면 `argocd app rollback payment-api <REVISION>` 명령으로 롤백한다.

## 롤백 후 확인

롤백한 뒤에는 다음 두 가지를 확인한다.

1. `/healthz`가 200을 반환하는지 확인한다. 확인 필요: `/healthz`를 요청할 주소와 확인 방법.
2. 결제 테스트 주문 1건이 성공하는지 확인한다. 확인 필요: 결제 테스트 주문을 실행하는 방법.

## 이력 기록

롤백 이력을 #deploy 채널에 남긴다. 확인 필요: 이력에 포함할 항목.
