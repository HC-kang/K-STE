## PR 제목

`fix: 토큰 만료 시각 경계 조건 수정 (is_valid)`

## 개요

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효한 것으로 판단하는 버그를 수정합니다.

Closes #412

## 원인

`auth/token.py`의 `is_valid()`가 `now <= expires_at`로 비교해서, `now == expires_at`인 순간에도 토큰을 유효하다고 판단했습니다. 만료 시각 자체는 이미 만료된 시점으로 보아야 합니다.

## 변경 사항

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 변경했습니다.
- 경계 조건을 검증하는 테스트 2개를 추가했습니다.
  - `test_token_expired_at_boundary`: `now == expires_at`일 때 토큰이 무효인지 확인합니다.
  - `test_token_valid_before_expiry`: `expires_at` 직전 시각에는 토큰이 유효한지 확인합니다.
