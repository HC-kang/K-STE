**공지 (수정안)**

캐시 서버와 API 서버는 메모리 사용량이 많습니다. 배포 후 서버가 재시작되면 메모리에 저장된 데이터가 모두 초기화됩니다.

관리자 권한을 가진 팀원과 QA 담당자는 배포 전에 공지 채널에 미리 알려 주시기 바랍니다.

**주요 수정 사항**
- "메모리를 많이 사용하며"를 "메모리 사용량이 많습니다"로 바꿔 문장을 간결하게 다듬었습니다.
- "초기화됩니다"의 주어를 "메모리에 저장된 데이터"로 명시해, 무엇이 초기화되는지 분명하게 했습니다.
- "알려야 합니다"를 "미리 알려 주시기 바랍니다"로 바꿔 요청의 의미를 부드럽게 전달했습니다.
