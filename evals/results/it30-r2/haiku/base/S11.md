# API 키 관리 지침

## 1. 목적

이 문서는 API 키의 교체 주기, 보관 위치, 저장소 관리 기준을 정한다.

## 2. 적용 범위

- **운영 환경(prod)**: 실서비스에서 사용하는 API 키
- **개발 환경(dev)**: 개발 및 테스트에 사용하는 API 키

## 3. 규칙

### 3.1 운영 환경 키 교체 주기 (필수)

- 운영 환경 API 키는 **90일마다 교체**한다.
- 이 규칙은 **예외 없이** 지켜야 한다.

### 3.2 Git 저장소 보관 금지 (필수)

- API 키를 **Git 저장소에 커밋하지 않는다.**

### 3.3 교체 시간 (권장)

- 키 교체는 **평일 업무 시간(10:00–18:00)**에 하는 것을 권장한다.
- **장애 대응 중**에는 업무 시간 외에 교체해도 된다.
- 위 예외는 **교체 시간에만** 적용된다. 장애 대응 중이라도 90일 교체 주기는 지켜야 한다.

### 3.4 개발 환경 키 (해당 없음)

- 개발 환경 API 키는 **90일 교체 규칙의 적용을 받지 않는다.**

### 3.5 키 발급 및 저장 위치

- 키 발급은 **Vault 웹 화면**에서 직접 할 수 있다.
- 교체한 운영 환경 키는 **Vault의 `prod/api-keys` 경로**에 저장해야 한다.

---

**참고:** 3.3의 장애 대응 예외를 3.1 규칙의 예외로 읽을 수 없도록 "교체 시간에만 적용된다"는 문장을 추가했습니다. 원문 내용은 바꾸지 않았습니다.
