# 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 `payment-api`를 운영 환경에서 롤백하는 절차를 설명한다. 롤백 대상 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다.

## 절차

1. 롤백하기 전에 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
2. 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다. 이때 DBA 박지은에게 연락해야 한다.
3. 배포에 DB 마이그레이션이 포함되지 않았으면 아래 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. #deploy 채널에 롤백 이력을 남긴다.

확인 필요: 3단계의 "포함되지 않았으면"은 요청에 직접 쓰여 있지 않고 2단계의 반대 조건으로 쓴 문장이다. 요청에는 마이그레이션이 포함되지 않은 경우의 조건이 따로 없다.
