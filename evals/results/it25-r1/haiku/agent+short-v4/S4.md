# payment-api 운영 배포 롤백 런북

## 적용 범위

이 런북은 ArgoCD로 배포된 운영 환경의 payment-api를 이전 리비전으로 롤백할 때 적용한다.

## 사전 준비

1. `argocd app history payment-api` 명령으로 되돌릴 리비전 번호(`<REVISION>`)를 찾는다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
   - 확인 필요: 마이그레이션 포함 여부를 확인할 위치와 방법이 원문에 없다.
2. 마이그레이션이 포함됐으면 **롤백하면 안 된다.** DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백 후 `/healthz`가 200을 반환하는지 확인한다.
   - 확인 필요: `/healthz`의 호스트 주소와 확인 방법이 원문에 없다.
   - 확인 필요: `/healthz`가 200을 반환하지 않을 때의 대응이 원문에 없다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
   - 확인 필요: 테스트 주문을 만드는 방법과 성공 판정 기준이 원문에 없다.
6. 롤백 이력을 #deploy 채널에 남긴다.
