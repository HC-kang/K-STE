이 문서는 ArgoCD로 배포한 payment-api를 이전 리비전으로 롤백하는 절차를 정리한다. 아래 순서대로 진행한다.

## 1. 롤백 전 DB 마이그레이션 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다. 확인 필요: 마이그레이션 포함 여부를 확인하는 방법과 위치.
2. 마이그레이션이 포함됐으면 **롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않은 것을 확인한 경우에만 2절로 넘어간다.

## 2. 롤백 실행

1. 롤백할 리비전 번호를 확인한다. 확인 필요: 리비전 번호를 찾는 방법.
2. `argocd app rollback payment-api <REVISION>` 명령을 실행한다. `<REVISION>` 자리에 1번에서 확인한 리비전 번호를 넣는다.

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다. 확인 필요: `/healthz`를 호출할 서버 주소.
2. 결제 테스트 주문 1건을 넣고, 그 주문이 성공하는지 확인한다. 확인 필요: 테스트 주문을 넣는 방법.

## 4. 롤백 이력 기록

#deploy 채널에 롤백 이력을 남긴다. 확인 필요: 이력에 적을 항목.
