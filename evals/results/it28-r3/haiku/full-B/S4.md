# payment-api 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 payment-api 운영 배포를 롤백하는 절차를 설명한다. 롤백하기 전에 해당 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 되며 DBA 박지은에게 연락해야 한다. 롤백한 뒤에는 `/healthz` 응답과 결제 테스트 주문으로 결과를 확인하고, 롤백 이력을 #deploy 채널에 남겨야 한다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
   확인 필요: 마이그레이션 포함 여부를 확인하는 방법과 위치. 이 문서에는 정해진 방법이 없다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다.

   **경고: 마이그레이션이 포함된 배포는 롤백하면 안 된다.**

   이 경우 DBA 박지은에게 연락해야 한다. 이후 롤백 절차는 진행하지 않는다.
3. 마이그레이션이 포함되지 않았으면 2단계의 롤백 절차를 진행한다.

## 2. 롤백 실행

4. 아래 명령을 실행해야 한다. `<REVISION>`에는 롤백할 리비전 번호를 넣어야 한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

## 3. 롤백 후 확인

5. `/healthz`가 200을 반환하는지 확인해야 한다.
   확인 필요: `/healthz`가 200을 반환하지 않을 때 따를 조치. 이 문서에는 정해진 조치가 없다.
6. 결제 테스트 주문을 1건 실행해 성공하는지 확인해야 한다.

## 4. 이력 기록

7. 롤백 이력을 #deploy 채널에 남겨야 한다.
