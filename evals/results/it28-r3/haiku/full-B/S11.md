# API 키 관리 지침

이 지침은 운영 환경과 개발 환경의 API 키를 교체하고, 발급하고, 저장하는 기준을 정한다. 운영 환경 API 키는 90일마다 교체해야 하며, 이 규칙에는 예외가 없다.

## 1. 운영 환경 API 키 교체

1. 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.
2. 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
3. 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.

## 2. 개발 환경 API 키

개발 환경 API 키는 90일 교체 규칙을 따르지 않아도 된다.

## 3. 키 발급과 저장

1. Vault 웹 화면에서 키를 직접 발급할 수 있다.
2. 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 4. 금지 사항

- **API 키를 Git 저장소에 커밋하면 안 된다.**
