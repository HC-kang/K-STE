# 토큰 만료 경계 시각 판정 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하는 버그를 수정한다. 수정 후에는 만료 시각과 같은 시각에 토큰을 유효하다고 판단하지 않는다.

## 변경 사항

- `auth/token.py`의 `is_valid()`에서 비교 조건을 `now <= expires_at`에서 `now < expires_at`로 바꿨다.

## 테스트

- `test_token_expired_at_boundary`를 추가했다. 만료 시각과 같은 시각의 판정을 검증한다.
- `test_token_valid_before_expiry`를 추가했다. 만료 시각 이전의 판정을 검증한다.
- 로컬에서 단위 테스트를 실행했고 모두 통과했다.
- **통합 테스트는 아직 실행하지 않았다.**
