캐시(자주 쓰는 정보를 미리 저장해 두고 빠르게 꺼내 쓰는 곳)는 지금 서버마다 따로 있고, Redis는 서버 4대가 함께 쓰는 캐시 서버 1대입니다.

지금은 API 서버(앱의 요청에 응답하는 서버) 4대가 각자 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 저장된 내용이 달라질 수 있어서, 가격을 바꾸면 서버마다 반영되는 시점이 달라지고 고객에게는 최대 5분 늦게 보입니다.

Redis를 도입하면 상품 목록을 한 곳에만 저장하므로 서버 4대가 같은 내용을 보게 됩니다. 가격을 바꾸면 모든 서버가 같은 시점에 새 가격을 보게 되므로, 서버마다 가격이 다르게 보이는 문제가 없어집니다. 다만 Redis에서 정보를 가져올 때는 서버 메모리보다 네트워크를 거치므로 조회 한 번에 시간이 조금 더 걸립니다.

확인 필요: 가격 변경을 5분 뒤가 아니라 바로 반영할지 정해야 합니다. 바로 반영하려면 가격이 바뀔 때 Redis에 저장된 상품 정보를 지우는 작업이 따로 필요합니다. 이 작업을 하지 않으면 Redis를 도입해도 최대 5분 지연은 그대로 남습니다.
