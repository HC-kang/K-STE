로컬 캐시는 서버마다 따로 가진 캐시(자주 쓰는 데이터를 임시로 저장해 두는 곳)이고, Redis 캐시는 서버 4대가 함께 쓰는 캐시 하나입니다. Redis를 도입하면 서버마다 캐시 내용이 달라지는 문제가 없어집니다.

현재 API 서버(앱과 웹의 요청에 응답하는 서버)는 4대입니다. 서버마다 자기 메모리(작업용 임시 공간)에 상품 목록을 5분 동안 캐시합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 보이는 가격이 최대 5분 늦게 바뀝니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버 1대로 도입할 예정입니다. 4대가 같은 캐시를 보므로 서버마다 내용이 달라지는 일이 없습니다. 그래서 고객에게 보이는 가격이 최대 5분 늦게 바뀌는 현재 문제를 줄일 수 있습니다.
