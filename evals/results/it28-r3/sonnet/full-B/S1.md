로컬 캐시와 Redis 캐시의 차이는 캐시(자주 쓰는 데이터를 임시로 저장해 두는 곳)를 서버마다 따로 두느냐, 서버 4대가 함께 쓰느냐입니다.

현재는 로컬 캐시를 씁니다. API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 서버마다 캐시 내용이 다르기 때문에, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis(여러 서버가 함께 쓰는 캐시 서버)를 도입하면 캐시 서버 1대를 API 서버 4대가 같이 씁니다. 이때 4대가 모두 같은 캐시 내용을 보므로, 서버마다 캐시 내용이 달라지는 일이 없어집니다. 가격 반영이 늦어지던 원인이 서버별 캐시 차이였으므로, 이 원인이 사라지는 것이 이번 도입으로 좋아지는 점입니다.
