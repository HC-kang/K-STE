# API 키 관리 지침

이 문서는 API 키의 교체 주기, 교체 시간, 금지 사항, 발급과 저장 위치를 정한다. 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.

## 교체 주기

- 운영 환경 API 키는 90일마다 교체해야 한다.
- 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 교체 시간

- 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.

## 금지 사항

- API 키를 Git 저장소에 커밋하면 안 된다.

## 키 발급과 저장

- Vault 웹 화면에서 키를 직접 발급할 수 있다.
- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

확인 필요: 교체한 키를 `prod/api-keys`에 저장하는 규칙이 운영 환경 키에만 적용되는지, 개발 환경 키에도 적용되는지 원문에 없습니다. 위키에 올리기 전에 정해 주십시오. 또한 90일을 세는 기준 시점(발급일인지 마지막 교체일인지)도 원문에 없습니다.
