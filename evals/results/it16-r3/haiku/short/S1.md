로컬 캐시는 각 서버가 자기 메모리에 상품 정보 사본을 따로 두는 방식이고, Redis 캐시는 서버 4대가 함께 쓰는 별도 캐시 서버에 사본을 두는 방식입니다. 지금은 서버마다 사본이 달라서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

| 구분 | 로컬 캐시 (현재) | Redis 캐시 (도입 예정) |
|---|---|---|
| 사본 위치 | API 서버(고객 요청을 처리하는 서버) 각각의 메모리 | 캐시 전용 서버 1대 |
| 서버 간 공유 | 공유하지 않음 | 서버 4대가 함께 사용 |
| 서버 간 사본 차이 | 발생함 | 발생하지 않음 |

Redis를 도입하면 서버 4대가 같은 사본을 보기 때문에 서버마다 가격이 다르게 보이는 문제가 없어집니다. 다만 Redis를 쓴다고 가격 변경이 곧바로 고객에게 보이지는 않습니다. 가격을 바꿨을 때 Redis의 사본을 즉시 지우도록 따로 구현해야 가격 변경이 바로 보입니다.
