Redis를 도입하면 API 서버 4대가 같은 상품 목록을 읽게 되어, 서버마다 가격이 다르게 보이는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 임시로 저장해 두는 공간입니다. 지금은 로컬 캐시를 씁니다. 로컬 캐시는 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장하는 방식입니다. 그래서 서버마다 저장된 내용이 다르고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다. 이 5분 동안에는 고객이 어느 서버에 접속했느냐에 따라 다른 가격을 볼 수 있습니다.

Redis 캐시는 서버 4대가 함께 쓰는 캐시 서버 1대입니다. 서버 4대가 같은 저장소에서 상품 목록을 읽으므로, 서버마다 내용이 달라지지 않습니다. 가격을 바꿀 때 Redis에 저장된 상품 목록을 지우도록 만들면, 5분을 기다리지 않고 서버 4대 모두에 바뀐 가격을 보여 줄 수 있습니다.
