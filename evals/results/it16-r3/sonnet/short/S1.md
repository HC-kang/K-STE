로컬 캐시는 서버 4대가 각자 따로 갖는 임시 저장소이고, Redis 캐시는 4대가 함께 쓰는 임시 저장소입니다. 캐시는 자주 쓰는 데이터를 빠르게 꺼내려고 잠시 저장해 두는 곳을 뜻합니다. 지금은 서버마다 자기 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 저장한 시점이 달라서 서버끼리 내용이 다를 수 있고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 서버 4대가 캐시 서버 1대를 같이 읽습니다. 그래서 요청이 어느 서버로 가도 같은 내용을 보게 되고, 서버마다 내용이 달라지는 문제는 없어질 것으로 보입니다.

다만 가격 변경이 얼마나 빨리 반영되는지는 Redis 도입만으로 정해지지 않습니다. 저장 시간을 5분으로 유지하면 최대 5분 지연이 남을 수 있습니다. 가격을 바꿀 때 저장된 상품 목록을 바로 지우는 기능이 있어야 지연을 줄일 수 있습니다. 확인 필요: 이번 도입에 가격 변경 시 캐시를 지우는 기능이 포함되는지는 아직 확인하지 못했습니다.

Redis 서버가 1대이므로, 이 서버가 멈추면 API 서버 4대 모두 Redis 캐시를 쓸 수 없습니다.
