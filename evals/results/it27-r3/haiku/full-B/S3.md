# 토큰 만료 시각 경계에서 토큰을 유효로 판단하던 문제 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 문제를 고친다. `auth/token.py`의 `is_valid()`에서 비교 조건을 `now <= expires_at`에서 `now < expires_at`로 바꾼다.

## 원인

`is_valid()`는 요청 시각 `now`가 `expires_at`과 같을 때도 `now <= expires_at`이 참이 되어 토큰을 유효하다고 판단했다.

## 변경 내용

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꾼다.
- 만료 시각 경계를 검사하는 `test_token_expired_at_boundary`를 추가한다.
- 만료 시각 이전의 토큰이 유효한지 검사하는 `test_token_valid_before_expiry`를 추가한다.

## 테스트

- 로컬에서 단위 테스트를 실행했고, 모두 통과했다.
- 통합 테스트는 아직 실행하지 않았다.
