# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 이전 리비전으로 롤백하는 절차를 정리한다. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 되고, DBA 박지은에게 연락해야 한다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. **경고:** 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 롤백할 리비전 번호를 준비한다.

## 롤백

4. 다음 명령으로 payment-api를 롤백한다. `<REVISION>`에는 3번에서 준비한 리비전 번호를 넣는다.

```
argocd app rollback payment-api <REVISION>
```

## 롤백 후 확인

5. `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 기록

7. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 1번과 3번의 마이그레이션 포함 여부를 확인하는 방법과 장소. 주어진 사실에 방법이 없다.
