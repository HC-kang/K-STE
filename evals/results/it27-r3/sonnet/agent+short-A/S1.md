Redis를 도입하면 서버 4대가 캐시(자주 쓰는 데이터를 빨리 꺼내 쓰려고 임시로 저장해 둔 곳) 하나를 같이 쓰므로, 서버마다 캐시 내용이 달라지는 문제가 없어질 것으로 보입니다.

로컬 캐시는 API 서버가 자기 메모리에 따로 저장하는 캐시입니다. 지금은 서버 4대가 각자 상품 목록을 5분 동안 캐시합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis 캐시는 서버 4대가 같이 쓰는 캐시 서버 1대에 저장하는 캐시입니다. 4대가 같은 캐시를 읽으므로, 서버에 따라 고객에게 다른 가격이 보이는 일이 없어질 것으로 보입니다.

확인 필요: 가격 변경이 고객에게 반영되는 시간. Redis에 저장한 상품 목록을 가격을 바꿀 때 바로 지우는지, 5분이 지나 만료되기를 기다리는지에 따라 달라집니다.
