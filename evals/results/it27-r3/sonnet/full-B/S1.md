로컬 캐시는 서버마다 따로 갖고, Redis 캐시는 서버 4대가 하나를 같이 쓴다는 점이 다릅니다.

현재 API 서버는 4대이고, 서버마다 자기 메모리에 상품 목록을 5분 동안 캐시(자주 쓰는 데이터를 임시로 저장해 두는 것)합니다. 이 방식이 로컬 캐시입니다. 이때 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis(여러 서버가 함께 쓰는 캐시 서버 프로그램)는 서버 4대가 같이 쓰는 캐시 서버 1대로 도입할 예정입니다. 서버 4대가 같은 캐시를 보게 되므로, 서버마다 캐시 내용이 달라지는 문제가 없어집니다.
