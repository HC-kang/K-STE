# API 키 관리 지침

이 지침은 사내 API 키의 교체 주기, 저장 위치, Git 저장소 관리 규칙을 정한다.

## 교체 주기

- 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.
- 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에 교체해도 된다.
- 개발 환경 API 키는 90일 교체 규칙을 따르지 않아도 된다.

## 발급과 저장

- Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.
- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## Git 저장소

- API 키를 Git 저장소에 커밋하면 안 된다.

---

확인할 점이 하나 있다. 본문은 운영 키 교체를 "예외 없이" 지키라고 하면서, 장애 대응 중에는 업무 시간 밖에 교체해도 된다고 쓴다. 두 문장은 교체 시점에 대한 규칙이라 충돌하지 않는다고 보고 원문대로 두었다. 장애 중에도 90일 주기는 지켜야 한다는 뜻이 맞는지는 확인이 필요하다. 맞다면 위키에 그 내용을 한 문장으로 덧붙이는 것을 권장한다. 90일을 어느 날부터 세는지도 원문에 없어서 쓰지 않았다.
