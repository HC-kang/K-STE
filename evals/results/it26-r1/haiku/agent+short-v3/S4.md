# 운영 배포 롤백 런북: payment-api

이 런북은 ArgoCD로 운영 payment-api 배포를 이전 리비전으로 롤백하는 절차다. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 되고, DBA 박지은에게 연락해야 한다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다. DBA 박지은에게 연락하고, 이후 단계를 진행하지 않는다.
3. 마이그레이션이 포함되지 않았을 때만 다음 명령을 실행한다. `<REVISION>` 자리에는 롤백할 리비전 값을 넣는다.

   `argocd app rollback payment-api <REVISION>`

4. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 롤백한 뒤 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남겨야 한다.
