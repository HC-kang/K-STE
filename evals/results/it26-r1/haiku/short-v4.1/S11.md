# API 키 관리 지침

## 교체 주기

- 운영 환경 API 키는 90일마다 교체해야 한다.
- 이 규칙은 예외 없이 지켜야 한다.
- 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 교체 시기

- 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에도 키를 교체해도 된다.

## 발급과 보관

- Vault(API 키 같은 비밀 값을 보관하고 발급하는 도구)의 웹 화면에서 키를 직접 발급할 수 있다.
- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.
- API 키를 Git 저장소에 커밋하면 안 된다.

확인 필요: 90일은 키를 발급한 날부터 세는지, 직전 교체일부터 세는지 알려 주세요.
