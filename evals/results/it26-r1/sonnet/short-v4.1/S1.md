로컬 캐시는 서버마다 따로 갖는 임시 저장소이고, Redis 캐시는 서버 4대가 하나를 같이 쓰는 임시 저장소입니다. 캐시는 자주 쓰는 데이터를 미리 저장해 두고 빠르게 꺼내 쓰는 곳입니다.

현재 API 서버 4대는 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 그래서 서버마다 캐시 내용이 다릅니다. 이 때문에 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 4대가 캐시 서버 1대를 같이 씁니다. 그래서 어느 서버가 요청을 받아도 같은 상품 목록을 보여 줄 수 있습니다. 고객이 서버에 따라 다른 가격을 보는 일이 사라집니다.

다만 Redis를 도입하는 것만으로 가격이 바로 반영되는지는 알 수 없습니다. 가격을 바꿀 때 Redis에 저장된 상품 목록을 바로 지우도록 만들면 반영 지연을 줄일 수 있습니다. 그렇게 만들지 않고 저장 시간을 5분으로 그대로 두면 최대 5분 지연이 남을 수 있습니다.

로컬 캐시는 같은 서버 안의 메모리에서 읽기 때문에 네트워크를 거치지 않습니다. Redis는 별도 서버에서 읽기 때문에 네트워크를 한 번 거칩니다.
