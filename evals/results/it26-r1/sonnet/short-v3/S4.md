# 운영 배포 롤백 런북

## 적용 범위

이 런북은 ArgoCD로 배포한 `payment-api`의 운영 배포를 롤백할 때 쓴다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다. 이 확인은 롤백 전에 반드시 해야 한다.
2. 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA 박지은에게 연락한다.
3. 배포에 DB 마이그레이션이 포함되지 않았으면 아래 명령으로 롤백한다. `<REVISION>` 자리에는 롤백할 리비전을 넣는다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 마이그레이션 포함 여부를 어디에서 확인하는지, 박지은에게 어떤 경로로 연락하는지, `/healthz`를 어느 주소로 호출하는지는 주어진 사실에 없다. 알려 주시면 해당 단계에 추가하겠다.
