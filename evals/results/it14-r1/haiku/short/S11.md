이 문서는 API 키의 교체 주기, 교체 시기, 발급과 저장 방법, 금지 사항을 정한다.

## 1. 교체 규칙

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.

개발 환경 API 키는 90일 교체 규칙을 지킬 필요가 없다.

운영 환경 API 키는 평일 업무 시간인 10:00-18:00에 교체하는 것을 권장한다. 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.

## 2. 발급과 저장

Vault(비밀 값을 안전하게 보관하는 도구)의 웹 화면에서 API 키를 직접 발급할 수 있다.

교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 3. 금지 사항

API 키를 Git(소스 코드 버전 관리 도구) 저장소에 커밋하면 안 된다.
