## 목적

이 런북은 `payment-api` 운영 배포를 ArgoCD로 롤백하는 절차를 정의한다.

## 롤백 절차

1. 롤백할 대상 REVISION을 확인한다.
   확인 필요: REVISION 값을 찾는 방법과 위치
2. 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
   확인 필요: 마이그레이션 포함 여부를 확인하는 방법과 위치
   - **마이그레이션이 포함됐으면 롤백하면 안 된다.**
   - 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 한다.
   확인 필요: DBA 박지은의 연락 방법
3. 마이그레이션이 포함되지 않았음을 확인한 뒤 롤백 명령을 실행한다.
   ```
   argocd app rollback payment-api <REVISION>
   ```
4. 롤백 후 `/healthz`가 200을 반환하는지 확인해야 한다.
5. 결제 테스트 주문 1건이 성공하는지 확인해야 한다.
   확인 필요: 테스트 주문을 실행하는 방법과 대상 환경
6. #deploy 채널에 롤백 이력을 남긴다.
   확인 필요: 이력에 포함할 항목과 형식

## 미정 사항

확인 필요: `/healthz`가 200을 반환하지 않거나 결제 테스트 주문이 실패했을 때의 조치
확인 필요: 롤백 명령을 실행할 권한을 가진 담당자
