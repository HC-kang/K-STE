# 토큰 만료 시각에 토큰을 유효하다고 판단하는 버그 수정

`auth/token.py`의 `is_valid()`는 토큰 만료 시각과 정확히 같은 시각에 요청이 들어오면 토큰을 유효하다고 판단했다. 이 PR은 비교 조건을 `now <= expires_at`에서 `now < expires_at`로 바꿔, 만료 시각 자체에서는 토큰을 만료된 것으로 본다.

## 변경 내용

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다.
- 테스트 2개를 추가했다: `test_token_expired_at_boundary`, `test_token_valid_before_expiry`.

## 테스트

- 로컬에서 단위 테스트를 실행했고, 모두 통과했다.
- 통합 테스트는 아직 실행하지 않았다.
