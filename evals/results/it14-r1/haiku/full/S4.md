# 운영 배포 롤백 런북

이 런북은 ArgoCD로 운영 환경의 `payment-api` 배포를 롤백하는 절차를 정한다. 롤백 대상 배포에 DB 마이그레이션이 포함되어 있으면 롤백하지 않고 DBA에게 연락한다. 롤백한 뒤에는 `/healthz` 응답 코드와 결제 테스트 주문으로 서비스를 확인하고, 롤백 이력을 #deploy 채널에 남긴다.

## 1. 롤백 여부 판단

**경고: DB 마이그레이션이 포함된 배포는 롤백하면 안 된다.**

1. 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 DBA 박지은에게 연락한다. 이 경우 이 런북의 롤백 절차는 진행하지 않는다.
3. 마이그레이션이 포함되지 않았으면 2절로 진행한다.

## 2. 롤백 실행

4. `argocd app rollback payment-api <REVISION>` 명령을 실행하고, `<REVISION>` 자리에 롤백할 배포의 REVISION 값을 넣는다.

## 3. 롤백 후 확인

5. `/healthz`에 요청을 보내 응답 코드가 200인지 확인한다.
6. 결제 테스트 주문을 1건 진행하고, 주문이 성공하는지 확인한다.

## 4. 이력 기록

7. #deploy 채널에 롤백 이력을 남긴다.
