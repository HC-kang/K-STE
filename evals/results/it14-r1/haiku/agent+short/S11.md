# API 키 관리 지침

이 지침은 운영 환경과 개발 환경의 API 키를 관리하는 기준을 정한다.

## 1. 운영 환경 키 교체 주기

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.

## 2. 키 교체 시간

키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다. 장애 대응 중이면 업무 시간 밖에 교체해도 된다.

## 3. 개발 환경 키

개발 환경 API 키는 90일 교체 규칙을 따를 필요가 없다.

## 4. Git 저장소 커밋 금지

API 키를 Git 저장소(코드 변경 이력을 관리하는 저장소)에 커밋하면 안 된다.

## 5. 키 발급과 저장

Vault(비밀 값을 안전하게 보관하는 도구)의 웹 화면에서 키를 직접 발급할 수 있다. 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

확인 필요: 교체한 키의 `prod/api-keys` 저장 규칙이 운영 환경 키에만 적용되는지, 개발 환경 키에도 적용되는지 확인해 주세요.
