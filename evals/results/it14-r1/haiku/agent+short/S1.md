로컬 캐시와 Redis 캐시의 가장 큰 차이는 보관 위치입니다. 캐시(자주 쓰는 데이터를 미리 담아 두는 임시 저장소)를 각 서버 안에 두면 로컬 캐시이고, 서버 바깥의 별도 서버에 두면 Redis 캐시입니다. Redis(여러 서버가 함께 쓰는 캐시 전용 서버)는 이번에 서버 4대가 함께 쓰는 1대로 도입됩니다.

현재는 서버 4대가 각자 메모리(서버가 작업할 때 쓰는 저장 공간)에 상품 목록을 5분 동안 보관합니다. 그래서 서버마다 보관하는 내용이 달라지고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 서버 4대가 같은 캐시 하나를 봅니다. 그래서 서버마다 내용이 달라지는 문제는 생기지 않습니다. 다만 가격 변경이 고객에게 반영되는 시간은 캐시를 언제 비우고 갱신하는지에 따라 달라집니다. 확인 필요: 가격을 바꿨을 때 Redis 캐시를 바로 비우는지, 아니면 5분 뒤에 저절로 비워지는 방식을 그대로 두는지.

한편 Redis를 쓰면 서버가 상품 목록을 가져올 때마다 Redis 서버를 거치게 됩니다. 그래서 Redis 서버가 멈추면 서버 4대 모두 영향을 받습니다. 이 점은 공용 캐시를 쓰는 구조에서 일반적으로 생기는 특징입니다.
