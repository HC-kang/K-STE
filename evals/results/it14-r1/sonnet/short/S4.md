# 운영 배포 롤백 런북

배포 도구는 ArgoCD이고, 롤백 대상 앱은 `payment-api`이다.

## 1. 롤백 전 확인

롤백하기 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

- 마이그레이션이 포함됐으면 롤백하면 안 된다. 이때 DBA 박지은에게 연락해야 한다.
- 마이그레이션이 포함되지 않았으면 2단계에서 롤백한다.

## 2. 롤백

다음 명령으로 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 4. 이력 기록

롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 마이그레이션 포함 여부를 확인하는 방법, `<REVISION>`에 넣을 값을 정하는 방법, #deploy 채널에 남길 이력의 항목은 주어진 사실에 없어서 적지 않았다.
