로컬 캐시는 서버 4대가 각자 따로 저장해 두는 방식이고, Redis 캐시는 4대가 한곳에 저장해 함께 쓰는 방식입니다. 캐시는 자주 쓰는 데이터를 가까운 곳에 임시로 저장해 두어 응답을 빠르게 하는 장치입니다.

| 구분 | 로컬 캐시(현재) | Redis 캐시(도입 예정) |
|---|---|---|
| 저장 위치 | 서버 4대가 각자 자기 메모리에 저장합니다. | 캐시 서버 1대에 저장하고 서버 4대가 함께 씁니다. |
| 서버 간 내용 | 서버마다 내용이 다를 수 있습니다. | 서버 4대가 같은 내용을 봅니다. |

지금은 서버마다 상품 목록을 5분 동안 따로 저장합니다. 그래서 가격을 바꾸면 서버마다 반영 시점이 달라지고, 고객에게는 최대 5분 늦게 반영됩니다. 고객이 같은 상품을 보더라도 요청이 어느 서버로 가느냐에 따라 이전 가격과 새 가격이 다르게 보일 수 있었습니다.

Redis를 도입하면 서버 4대가 같은 캐시를 읽습니다. 그래서 서버마다 가격이 다르게 보이는 문제는 사라집니다.

확인 필요: 가격 변경이 고객에게 5분보다 빨리 반영되는지는 Redis 도입만으로 정해지지 않습니다. 가격을 바꿀 때 Redis 캐시를 바로 지우는 방식을 함께 적용하는지 개발팀에 확인해야 합니다.

확인 필요: Redis 서버가 1대이므로, 이 서버가 멈출 때 서비스에 어떤 영향이 있는지도 개발팀에 확인해야 합니다.
