Redis를 도입하면 서버 4대가 같은 상품 목록을 읽으므로, 서버마다 가격이 다르게 보이는 문제가 없어집니다.

지금은 API 서버 4대가 캐시(자주 쓰는 데이터를 미리 저장해 두는 곳)를 각자 자기 메모리에 따로 갖고 있습니다. 이것이 로컬 캐시입니다. 서버마다 상품 목록을 5분 동안 따로 저장하기 때문에, 서버마다 저장한 시점이 다르고 내용도 다릅니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 메모리에 데이터를 저장하는 캐시 전용 서버입니다. 이번에는 서버 4대가 함께 쓰는 Redis 1대를 둘 예정입니다. 그래서 서버 4대가 Redis에 저장된 같은 상품 목록을 읽습니다.

가격을 바꿀 때 Redis에 저장된 상품 목록을 함께 지우거나 새로 쓰면, 서버 4대에 같은 가격이 동시에 보입니다. 다만 최대 5분 지연이 얼마나 줄어드는지는 가격을 바꿀 때 Redis 캐시를 어떻게 갱신하느냐에 달려 있습니다.
