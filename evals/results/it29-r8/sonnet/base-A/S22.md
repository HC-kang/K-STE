# 환불 기준 (고객센터 상담원용)

## 1. 전액 환불
- 가입일로부터 **7일 이내**에 해지하면 **전액 환불**합니다.

## 2. 환불 신청 접수 및 정산 시점
- **10월 31일 이후**에 접수된 환불 신청은 **11월 정산**에 포함합니다.

## 3. 승인 기준
- 환불 금액이 **50만 원을 초과**하면 **팀장 승인**을 받아야 합니다.
- 50만 원 이하인 경우, 이 문서에는 별도 승인 절차가 없습니다.

## 4. 상담 대기 시 인력 배치
- 상담 대기 고객이 **20명**이 되면 상담원을 **추가 배치**합니다.

---

### 한눈에 보기

| 항목 | 기준 | 처리 |
|---|---|---|
| 가입 후 7일 이내 해지 | 7일 이내 | 전액 환불 |
| 10월 31일 이후 접수 | 접수일 기준 | 11월 정산에 포함 |
| 환불 금액 50만 원 초과 | 50만 원 초과 | 팀장 승인 필요 |
| 상담 대기 20명 | 대기 20명 도달 | 상담원 추가 배치 |
