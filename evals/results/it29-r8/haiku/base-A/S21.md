# 파일 공유 규정

## 1. 목적

이 규정은 사내 위키에서 파일을 업로드하고 외부와 공유할 때 지켜야 할 기준을 정합니다.

## 2. 적용 대상

사내 위키에 파일을 업로드하거나 외부 공유 링크를 만드는 모든 구성원에게 적용합니다.

## 3. 파일 업로드 기준

1. **파일 크기**: 첨부 파일 하나의 크기가 25MB를 넘으면 업로드할 수 없습니다.
2. **파일 개수**: 한 게시물에는 파일을 최대 10개까지 올릴 수 있습니다.

## 4. 외부 공유 링크

1. **인턴 제한**: 만 19세 미만인 인턴은 외부 공유 링크를 만들 수 없습니다.
2. **유효 기간**: 외부 공유 링크는 생성 시각부터 72시간이 지나면 자동으로 닫힙니다.

## 5. 계정 보안

비밀번호를 연속으로 5번 틀리면 계정이 30분 동안 잠깁니다. 잠금이 풀리기 전까지는 로그인할 수 없습니다.

## 6. 문의

규정에 관한 질문은 담당 부서에 문의해 주세요.
