# 운영 배포 롤백 런북 (payment-api)

이 런북은 ArgoCD로 배포한 payment-api의 운영 배포를 지정한 리비전으로 되돌리는 절차를 정한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 되고 DBA 박지은에게 연락해야 한다.

## 1. 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
2. 마이그레이션이 포함됐으면 **경고: 롤백하면 안 된다.** DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 2단계로 진행한다.

## 2. 롤백 실행

1. 다음 명령을 실행한다. `<REVISION>`에는 롤백할 리비전을 넣는다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인해야 한다.
2. 결제 테스트 주문을 1건 진행하고, 그 주문이 성공하는지 확인해야 한다.

## 4. 이력 기록

1. 롤백 이력을 #deploy 채널에 남겨야 한다.
