로컬 캐시는 서버 한 대의 메모리에 상품 목록을 임시로 저장해 두는 방식이고, Redis 캐시는 서버 4대가 함께 쓰는 별도의 캐시 서버에 같은 내용을 저장하는 방식입니다. Redis를 도입하면 4대가 같은 데이터를 보게 되므로 서버마다 내용이 달라지는 문제가 없어집니다.

| 구분 | 로컬 캐시(현재) | Redis 캐시(도입 예정) |
|---|---|---|
| 저장 위치 | 서버마다 각자의 메모리 | 공용 캐시 서버 1대 |
| 서버 간 데이터 | 서버마다 다를 수 있음 | 4대가 같은 데이터를 봄 |
| 가격 반영 지연 | 최대 5분 | 확인 필요 |

Redis에서 가격 반영 지연이 얼마나 줄어드는지는 아직 정해지지 않았습니다. 확인 필요: 가격 변경 후 반영 시점. 캐시를 그대로 5분 보관하는지, 가격을 바꿀 때 캐시를 바로 지우는지에 따라 결과가 달라집니다.

또한 4대 서버가 모두 이 캐시 서버 한 대에 의존하게 되므로, 그 서버가 멈추면 4대 모두 영향을 받습니다.

개발팀에 가격을 바꿨을 때 캐시를 어떻게 갱신하는지 물어보십시오.
