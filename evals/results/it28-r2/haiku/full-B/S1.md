로컬 캐시는 각 서버가 자기 메모리에 데이터를 따로 저장해 두고 쓰는 방식이고, Redis는 여러 서버가 함께 쓰는 별도의 저장 서버입니다. Redis를 도입하면 API 서버 4대가 같은 캐시를 보게 되어, 서버마다 상품 정보가 달라지는 문제가 줄어듭니다.

지금은 서버 4대가 각자 캐시(자주 쓰는 데이터를 미리 저장해 둔 것)를 가지고 있어서 서버마다 내용이 다를 수 있습니다. 그래서 가격을 바꾸면 서버마다 반영되는 시점이 다르고, 고객은 최대 5분 늦게 새 가격을 봅니다.

| 구분 | 지금 (로컬 캐시) | Redis 도입 후 |
|---|---|---|
| 캐시 위치 | 서버 4대 각각의 메모리 | 캐시 서버 1대 |
| 서버 간 내용 | 서버마다 다를 수 있음 | 4대가 같은 내용을 봄 |

다만 Redis를 써도 가격을 바꾼 뒤 새 가격이 언제 보이는지는 캐시를 언제 지우는지에 따라 달라집니다.

확인 필요: 가격 변경 후 Redis 캐시를 지우는 방식. 5분 뒤 자동으로 지워지는지, 가격을 바꿀 때 바로 지우는지에 따라 고객에게 보이는 시점이 달라집니다.
