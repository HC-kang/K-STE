# 파일 공유 규정

## 1. 목적

이 규정은 사내 위키에 파일을 업로드하고 외부와 공유할 때 지켜야 할 기준을 정합니다.

## 2. 첨부 파일 용량 제한

- 첨부 파일 하나의 크기가 **25MB를 넘으면 업로드할 수 없습니다.**

## 3. 게시물당 첨부 개수

- 한 게시물에는 파일을 **최대 10개**까지 올릴 수 있습니다.

## 4. 외부 공유 링크 권한

- **만 19세가 되지 않은 인턴은 외부 공유 링크를 만들 수 없습니다.**

## 5. 외부 공유 링크 유효 기간

- 외부 공유 링크는 **생성 시각부터 72시간이 지나면 자동으로 닫힙니다.**
- 72시간 이후에도 공유가 필요하면 새 링크를 만들어야 합니다.

## 6. 계정 잠금 정책

- 비밀번호를 **5번 연속 틀리면** 계정이 **30분 동안 잠깁니다.**
- 잠금 시간이 지나면 다시 로그인할 수 있습니다.
