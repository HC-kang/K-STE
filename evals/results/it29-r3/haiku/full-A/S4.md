# payment-api 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 payment-api의 운영 배포를 롤백하는 절차를 정한다. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 되고 DBA에게 연락해야 한다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다. DBA 박지은에게 연락해야 한다. 이 경우 2절 이후를 진행하지 않는다.
3. 마이그레이션이 포함되지 않았으면 2절을 진행한다.

## 2. 롤백 실행

1. 아래 명령의 `<REVISION>`에 롤백할 리비전 값을 넣고 실행한다.

```
argocd app rollback payment-api <REVISION>
```

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건을 실행하고 주문이 성공하는지 확인한다.

## 4. 이력 기록

1. 롤백 이력을 #deploy 채널에 남긴다.
