# 토큰 만료 시각 경계 조건 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 버그를 수정한다. `auth/token.py`의 `is_valid()` 비교 연산자를 바꾸고, 경계 조건을 확인하는 테스트 2개를 추가한다.

## 배경

기존 `is_valid()`는 `now <= expires_at`로 판단했다. 그래서 요청 시각이 토큰 만료 시각과 정확히 같으면 토큰을 유효하다고 판단했다.

## 변경 사항

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다. 이제 요청 시각이 만료 시각과 같으면 토큰을 유효하지 않다고 판단한다.
- 테스트 `test_token_expired_at_boundary`와 `test_token_valid_before_expiry`를 추가했다.

## 테스트

- 로컬에서 단위 테스트를 실행했고 모두 통과했다.
- 통합 테스트는 아직 실행하지 않았다.
