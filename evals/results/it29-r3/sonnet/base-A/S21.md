# 파일 공유 규정

## 1. 목적
이 문서는 사내에서 파일을 업로드하고 공유할 때 지켜야 할 기준을 정합니다.

## 2. 첨부 파일 규정

### 2.1 파일 크기 제한
- 첨부 파일 하나의 크기가 **25MB를 넘으면 업로드가 차단됩니다.**

### 2.2 게시물당 파일 개수
- 한 게시물에는 파일을 **최대 10개**까지 올릴 수 있습니다.

## 3. 외부 공유 링크 규정

### 3.1 생성 제한
- **만 19세 미만 인턴**은 외부 공유 링크를 만들 수 없습니다.

### 3.2 유효 기간
- 외부 공유 링크는 **만든 시각부터 72시간이 지나면 자동으로 닫힙니다.**
- 72시간이 지난 뒤에도 공유가 필요하면 링크를 새로 만들어야 합니다.

## 4. 계정 보안 규정

### 4.1 로그인 실패 시 잠금
- 비밀번호를 **5번 연속 틀리면** 해당 계정은 **30분 동안 잠깁니다.**

## 5. 규정 요약

| 항목 | 기준 |
|---|---|
| 파일 1개 최대 크기 | 25MB |
| 게시물당 최대 파일 수 | 10개 |
| 외부 공유 링크 생성 불가 대상 | 만 19세 미만 인턴 |
| 외부 공유 링크 유효 시간 | 생성 후 72시간 |
| 계정 잠금 조건 | 비밀번호 5회 연속 오류 |
| 계정 잠금 시간 | 30분 |

---
*참고: 3.2의 "72시간 지나면 새로 만들어야 한다"는 문장은 링크가 닫힌다는 사실에서 풀어 쓴 설명입니다. 별도 재발급 절차가 있다면 위키 게시 전에 보완해 주세요.*
