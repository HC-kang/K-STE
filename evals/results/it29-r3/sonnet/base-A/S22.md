# 환불 기준 (상담원용)

## 1. 전액 환불
- 가입일로부터 **7일 이내**에 해지하면 **전액 환불**합니다.

## 2. 정산 시점
- **10월 31일 이후** 접수된 환불 신청은 **11월 정산**에 포함합니다.

## 3. 승인 기준
- 환불 금액이 **50만 원을 초과**하면 **팀장 승인**을 받아야 합니다.
- 50만 원 이하는 별도 승인 없이 처리합니다.

## 4. 상담 인력 운영
- 상담 대기 고객이 **20명**이 되면 **상담원을 추가 배치**합니다.

---

### 한눈에 보기

| 항목 | 기준 | 처리 |
|---|---|---|
| 가입 후 7일 이내 해지 | 7일 이내 | 전액 환불 |
| 10월 31일 이후 환불 신청 | 접수일 기준 | 11월 정산 반영 |
| 환불 금액 50만 원 초과 | 금액 기준 | 팀장 승인 필요 |
| 대기 고객 20명 | 대기 인원 기준 | 상담원 추가 배치 |

---

참고: 제공해 주신 사실에는 "50만 원 이하는 별도 승인 없이 처리"한다는 내용이 직접 명시되어 있지 않습니다. 3번 항목의 해당 문장은 문맥상 덧붙인 것이므로, 실제 운영 기준과 다르면 삭제하거나 수정해 주세요.
