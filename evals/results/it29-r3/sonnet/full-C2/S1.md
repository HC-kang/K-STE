Redis를 도입하면 고객이 어느 API 서버(고객 요청을 받아 응답하는 서버)에 연결되든 같은 캐시 내용을 보게 됩니다.

현재는 로컬 캐시(서버 자체 메모리에 임시로 저장해 둔 데이터)를 씁니다. API 서버 4대가 각자 상품 목록을 5분 동안 저장합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 바뀐 가격이 고객에게 최대 5분 늦게 보입니다.

Redis는 여러 서버가 함께 쓰는 캐시 전용 서버입니다. 이번에는 Redis 서버 1대를 두고 API 서버 4대가 이 한 곳을 같이 씁니다. 캐시가 한 곳에만 있으므로 서버마다 내용이 달라지는 문제가 없어집니다.
