로컬 캐시는 서버 4대가 각자 자기 메모리에 따로 갖는 캐시이고, Redis 캐시는 서버 4대가 함께 쓰는 캐시 서버 1대에 두는 캐시입니다. 캐시는 자주 보는 데이터를 미리 저장해 두는 임시 저장소입니다.

지금은 API 서버(앱의 요청을 받아 응답하는 서버) 4대가 각자 상품 목록을 5분 동안 자기 메모리에 캐시합니다. 그래서 서버마다 캐시 내용이 다를 수 있고, 가격을 바꾸면 바뀐 가격이 고객에게 최대 5분 늦게 보입니다.

Redis를 도입하면 서버 4대가 같은 캐시를 보게 됩니다. 따라서 서버마다 캐시 내용이 달라지는 문제가 없어집니다.
