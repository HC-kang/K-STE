# payment-api 운영 배포 롤백 런북

이 문서는 ArgoCD로 payment-api 운영 배포를 롤백하는 절차를 정한다.

## 롤백 전 확인

**롤백 전에 해당 배포에 DB 마이그레이션(데이터베이스 구조를 바꾸는 변경 스크립트)이 포함됐는지 반드시 확인해야 한다.**

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다. DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 아래 명령으로 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

`<REVISION>`에는 롤백할 리비전(배포 버전 식별 번호)을 넣는다.

## 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 이력 기록

롤백 이력은 #deploy 채널에 남긴다.

## 확인 필요

- 확인 필요: 배포에 마이그레이션이 포함됐는지 어디에서 어떻게 확인하는지 원문에 없다.
- 확인 필요: `<REVISION>` 값을 어디에서 찾는지 원문에 없다.
- 확인 필요: `/healthz`를 호출할 주소가 원문에 없다.
- 확인 필요: 결제 테스트 주문을 만드는 방법이 원문에 없다.
- 확인 필요: 마이그레이션이 없을 때 롤백을 누가 실행하는지 원문에 없다.
