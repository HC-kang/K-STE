# 토큰 만료 경계에서 유효성 판단 오류 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 버그를 수정한다. 이번 변경으로 만료 시각과 같은 시각의 요청은 유효하지 않다고 판단한다. 로컬 단위 테스트는 모두 통과했고, 통합 테스트는 아직 실행하지 않았다.

## 변경 사항

`auth/token.py`의 `is_valid()`에서 비교 조건을 `now <= expires_at`에서 `now < expires_at`로 바꾼다.

이번 변경에 테스트 2개를 추가한다. `test_token_expired_at_boundary`는 만료 시각과 같은 시각의 요청을 검증한다. `test_token_valid_before_expiry`는 만료 시각 이전의 요청을 검증한다.

## 테스트

로컬에서 단위 테스트를 실행했고 모두 통과했다. 통합 테스트는 실행하지 않았다.
