# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 payment-api 운영 배포를 롤백하는 절차를 정한다. 롤백 전에 DB 마이그레이션 포함 여부를 확인해야 하며, 마이그레이션이 포함된 배포는 롤백하면 안 된다. 롤백 후에는 헬스 체크와 결제 테스트 주문으로 상태를 검증하고, 이력을 #deploy 채널에 남겨야 한다.

## 사용 도구

- 배포 도구: ArgoCD
- 대상 애플리케이션: payment-api
- 롤백 명령:

```
argocd app rollback payment-api <REVISION>
```

`<REVISION>`에는 롤백할 리비전 값을 넣는다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다. DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 위의 롤백 명령을 실행해야 한다.
4. 롤백 후 `/healthz`가 200을 반환하는지 확인해야 한다.
5. 결제 테스트 주문을 1건 실행하고, 주문이 성공하는지 확인해야 한다.
6. 롤백 이력을 #deploy 채널에 남겨야 한다.
