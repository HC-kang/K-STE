# 운영 배포 롤백 런북

이 런북은 운영 환경의 payment-api 배포를 ArgoCD로 롤백하는 절차를 정한다. 롤백 전에 배포에 DB 마이그레이션이 포함됐는지 확인한다. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다. 롤백 후에는 `/healthz` 응답 코드와 결제 테스트 주문 결과를 확인하고, 롤백 이력을 #deploy 채널에 남긴다.

## 사전 조건

- 배포 도구: ArgoCD
- 롤백 대상 리비전(REVISION): 정보 없음
- DBA 연락처(박지은): 정보 없음

## 절차

1. payment-api의 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 확인한다. 확인 방법: 정보 없음
2. 마이그레이션이 포함됐으면 **경고: 롤백하면 안 된다.** DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 다음 명령을 실행하여 롤백한다.
   `argocd app rollback payment-api <REVISION>`
4. 롤백이 끝나면 `/healthz` 응답 코드가 200인지 확인한다.
5. 결제 테스트 주문 1건을 실행하고 성공하는지 확인한다. 테스트 주문 방법과 성공 판정 기준: 정보 없음
