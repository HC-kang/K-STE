로컬 캐시는 각 서버가 자기 메모리에 따로 보관하고, Redis 캐시는 4대가 함께 쓰는 보관소 하나에 보관합니다. 그래서 Redis를 도입하면 서버마다 다른 상품 목록을 보는 문제가 없어집니다.

| 구분 | 로컬 캐시 (현재) | Redis 캐시 (도입 예정) |
|---|---|---|
| 보관 위치 | 각 서버의 메모리 안 | 서버 밖의 공용 캐시 서버 1대 |
| 서버 4대가 보는 내용 | 서버마다 다를 수 있습니다 | 4대가 모두 같은 내용을 봅니다 |
| 가격 변경 반영 속도 | 서버마다 최대 5분 늦게 반영됩니다 | 캐시를 갱신하는 방식에 따라 달라집니다 |

가격을 바꿀 때 고객에게 5분 늦게 반영되는 문제가 줄어드는지는 Redis 값을 언제 갱신하느냐에 달려 있습니다. 가격을 바꾸는 순간 Redis 값도 바로 갱신하도록 만들면 지연이 크게 줄어들 것으로 보입니다.
