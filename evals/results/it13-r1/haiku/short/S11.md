이 문서는 API 키의 교체 주기, 교체 시점, 저장 위치, Git 저장소 관리 기준을 정한다.

## 교체 주기

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다. 개발 환경 API 키는 90일 교체 규칙을 따르지 않아도 된다.

## 교체 절차

키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다. 장애 대응 중이면 업무 시간 밖에도 키를 교체해도 된다. Vault 웹 화면(비밀 값을 안전하게 보관하는 도구인 Vault의 브라우저 화면)에서 API 키를 직접 발급할 수 있다. 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다. API 키는 Git 저장소(코드 변경 이력을 저장하는 공간)에 커밋하면 안 된다.
