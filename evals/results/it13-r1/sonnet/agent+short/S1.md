로컬 캐시는 서버마다 따로 갖는 저장 공간이고, Redis 캐시는 서버 4대가 하나를 같이 쓰는 저장 공간입니다. 그래서 Redis를 도입하면 서버마다 상품 목록이 달라지는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 미리 저장해 두는 곳입니다. 지금은 API 서버 4대가 각자 서버 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 저장한 시점이 달라서, 같은 시점에도 서버에 따라 고객이 보는 내용이 다를 수 있습니다. 가격을 바꾸면 고객 화면에 최대 5분 늦게 보입니다.

Redis는 여러 서버가 함께 쓰는 캐시 전용 서버입니다. 이번에는 Redis 서버 1대에 상품 목록을 저장하고, API 서버 4대가 같은 내용을 읽습니다. 가격을 바꿀 때 Redis에 저장된 상품 목록도 함께 지우거나 바꾸면, 4대 모두 새 가격을 보여줄 수 있습니다.

Redis 서버는 1대이므로, 이 서버에 문제가 생기면 API 서버 4대 모두 영향을 받을 수 있습니다.

확인 필요: 가격을 바꿀 때 Redis에 저장된 상품 목록을 함께 지우거나 바꾸는 방식을 쓸지는 전달받은 정보에 없습니다. 이 방식을 쓰지 않으면 5분 지연이 얼마나 줄어드는지 알 수 없습니다.
