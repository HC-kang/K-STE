Redis를 도입하면 서버 4대가 같은 캐시를 보기 때문에, 서버마다 상품 목록이 다르게 보이는 문제가 사라집니다.

캐시는 자주 쓰는 데이터를 매번 새로 가져오지 않도록 임시로 저장해 두는 공간입니다. 로컬 캐시는 서버가 각자 자기 메모리에 따로 저장하는 방식입니다. 지금 우리 서비스는 서버마다 상품 목록을 5분 동안 이 방식으로 저장합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 서버 4대가 함께 쓰는 캐시 전용 서버입니다. 상품 목록이 Redis 한 곳에만 저장되므로, 4대가 같은 내용을 고객에게 보여줍니다.

다만 가격 변경이 고객에게 얼마나 빨리 반영되는지는 Redis 도입만으로 정해지지 않습니다. 캐시를 보관하는 시간과, 가격을 바꿀 때 저장된 캐시를 지우는 방식에 따라 달라집니다.

확인 필요: Redis 도입 후에도 보관 시간을 5분으로 유지하는지, 가격을 바꿀 때 캐시를 바로 지우는지 개발팀에 물어봐야 합니다.

확인 필요: Redis 서버가 1대이므로, 이 서버가 멈출 때 API 서버 4대가 어떻게 동작하는지도 개발팀에 물어봐야 합니다.
