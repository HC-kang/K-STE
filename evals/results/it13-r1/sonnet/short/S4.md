# 운영 배포 롤백 런북

## 적용 대상

ArgoCD로 배포한 payment-api의 운영 배포를 롤백할 때 이 런북을 따른다.

## 롤백 전 확인

**롤백할 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다.**

1. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
2. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 다음 절차로 넘어간다.

## 롤백 절차

1. 다음 명령으로 롤백한다. `<REVISION>` 자리에는 롤백할 리비전을 넣는다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

2. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
3. 결제 테스트 주문 1건이 성공하는지 확인한다.
4. 롤백 이력을 #deploy 채널에 남긴다.
