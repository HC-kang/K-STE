# API 키 관리 지침

## 교체 주기

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.

개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 교체 시간

API 키 교체는 평일 업무 시간(10:00-18:00)에 하기를 권장한다.

장애 대응 중이면 업무 시간 밖에 API 키를 교체해도 된다.

## 저장 위치

교체한 API 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

Vault 웹 화면에는 API 키를 직접 발급하는 기능이 있다.

## 금지 사항

API 키를 Git 저장소에 커밋하면 안 된다.
