# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 이전 리비전으로 되돌리는 절차다. 롤백 전에 배포에 DB 마이그레이션이 포함됐는지 확인하고, 포함됐으면 롤백하지 않는다. 롤백 후에는 `/healthz`와 결제 테스트 주문으로 정상 동작을 확인하고, 이력을 #deploy 채널에 남긴다.

## 롤백 절차

**경고: 배포에 DB 마이그레이션이 포함됐으면 롤백하지 않는다. DBA 박지은에게 연락한 뒤 이 절차를 중단한다.**

1. 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았음을 확인했으면 다음 명령으로 롤백한다. `<REVISION>`은 롤백할 리비전으로 바꾼다.

   `argocd app rollback payment-api <REVISION>`

4. 롤백 후 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 마이그레이션 포함 여부를 확인하는 방법. 원문에 정해진 방법이 없다.
확인 필요: `/healthz` 확인 실패 또는 테스트 주문 실패 시의 조치. 원문에 없다.
확인 필요: #deploy 채널에 남길 이력의 기록 항목. 원문에 없다.
