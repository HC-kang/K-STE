## 목적

이 런북은 ArgoCD로 배포된 운영 환경의 payment-api를 이전 리비전으로 롤백하는 절차를 정한다.

## 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. **마이그레이션이 포함됐으면 롤백하지 않는다. DBA 박지은에게 연락한다.**
3. 마이그레이션이 포함되지 않았으면 다음 롤백 절차를 진행한다.

확인 필요: 마이그레이션 포함 여부를 확인하는 구체적인 방법과 담당자가 정해지지 않았다.

## 롤백 실행

1. 되돌아갈 대상 REVISION 값을 정한다.
2. 다음 명령을 실행한다.

```
argocd app rollback payment-api <REVISION>
```

확인 필요: REVISION 값을 찾는 방법이 정해지지 않았다.

## 롤백 후 확인

1. payment-api의 `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

확인 필요: 확인 중 하나라도 실패할 때 따를 조치 기준이 정해지지 않았다.
