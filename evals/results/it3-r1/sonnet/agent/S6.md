캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전에 공지 채널에 알려야 합니다.

확인 필요: "관리자 권한이 있는 팀원 및 QA 담당자". 관리자 권한은 팀원에게만 걸리는지, QA 담당자에게도 걸리는지 알 수 없습니다.
확인 필요: "초기화됩니다". 초기화되는 대상이 서버 메모리의 캐시 데이터인지, 서버 상태 전체인지 알 수 없습니다.
확인 필요: "알려야 합니다". 배포 사실을 알리라는 뜻인지, 재시작으로 인한 초기화를 알리라는 뜻인지 알 수 없습니다.
