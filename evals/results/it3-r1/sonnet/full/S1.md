로컬 캐시는 서버마다 따로 갖는 임시 저장소이고, Redis 캐시는 서버 4대가 함께 쓰는 임시 저장소입니다. 캐시는 자주 쓰는 데이터를 미리 저장해 두고 빠르게 꺼내 쓰는 방식을 말합니다. Redis는 이 캐시를 전용으로 맡는 서버입니다.

지금은 API 서버 4대가 각자 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 캐시 서버 1대를 4대가 같이 씁니다. 어느 서버가 요청을 받아도 같은 캐시 내용을 읽으므로, 서버마다 내용이 달라지는 문제가 없어집니다.

다만 가격 반영 지연이 없어지는지는 확인하지 않았습니다. 캐시를 5분 동안 유지하는 설정을 그대로 두면 최대 5분 지연이 남을 수 있습니다.
