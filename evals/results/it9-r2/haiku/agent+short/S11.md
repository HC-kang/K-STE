# API 키 관리 지침

이 문서는 API 키의 교체 주기, 교체 시점, 저장 위치와 Git 저장소 관리 규칙을 정한다.

## 교체 주기

운영 환경 API 키는 90일마다 교체한다. 이 규칙은 예외 없이 지켜야 한다.

개발 환경 API 키는 90일 교체 규칙을 지킬 필요가 없다.

확인 필요: 90일을 세는 기준 시점이 원문에 없다. 발급일인지 마지막 교체일인지 정해야 한다.

## 교체 시점

키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.

장애 대응 중이면 업무 시간 밖에 교체해도 괜찮다.

## 키 발급과 저장

Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.

교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 금지 사항

**경고:** API 키를 Git 저장소에 커밋하는 것은 금지한다.
