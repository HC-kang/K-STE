# API 키 관리 지침

## 1. 적용 대상

- 운영 환경 API 키
- 개발 환경 API 키

## 2. 규칙

### 2.1 운영 환경 API 키 교체 주기 (필수, 예외 없음)

- 운영 환경 API 키는 **90일마다 교체한다.**
- 이 규칙에는 예외가 없다.

### 2.2 Git 저장소 커밋 금지 (필수)

- API 키를 Git 저장소에 커밋하지 않는다.

### 2.3 교체 시간 (권장)

- 키 교체는 **평일 업무 시간(10:00–18:00)에 하는 것을 권장한다.**

### 2.4 장애 대응 중 교체 시간 (허용)

- 장애 대응 중이라면 **업무 시간 외에도 키를 교체해도 된다.**
- 이 항목은 교체 시간에 관한 것이다. 2.1의 90일 교체 주기는 그대로 적용된다.

### 2.5 개발 환경 API 키 (제외)

- 개발 환경 API 키는 2.1의 90일 교체 규칙을 적용하지 않는다.

### 2.6 교체한 키의 저장 위치 (필수)

- 교체한 운영 환경 API 키는 Vault의 **`prod/api-keys` 경로**에 저장한다.

## 3. 키 발급 방법

- Vault 웹 화면에서 API 키를 직접 발급할 수 있다.

---

**확인이 필요한 항목 (문서에 반영하지 않았음)**

1. **90일 기산일**: 발급일 기준인지, 마지막 교체일 기준인지 명시가 필요합니다.
2. **운영 환경 키의 범위**: 어떤 키가 "운영 환경 API 키"에 해당하는지 기준이 필요합니다.
3. **장애 대응의 정의**: 어떤 상황을 장애 대응으로 보는지 기준이 필요합니다.
4. **이전 키 폐기**: 교체 후 이전 키를 언제 폐기하는지 정해져 있지 않습니다.
5. **2.3과 2.4의 관계**: 2.3은 "권장"이고 2.4는 "허용"입니다. 두 항목의 강도 차이가 의도한 것이라면 그대로 두시고, 아니라면 표현을 맞추시기 바랍니다.

이 항목들에 대한 답을 주시면 문서에 반영하겠습니다.
