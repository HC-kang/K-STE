**[부하 테스트 결과 공유] 초당 500건은 통과, 800건은 실패**

**용어**
- 초당 요청 수(RPS): 1초 동안 서버에 보낸 요청 수
- p99 응답 시간: 전체 요청의 99%가 이 시간 안에 응답을 받았다는 뜻. 가장 느린 1%는 제외하고 본 값
- 오류율: 실패 응답 수 ÷ 전체 요청 수

**목표 기준**
- 초당 500건에서 p99 응답 시간 300ms 이하
- 오류율 0.1% 이하

**결과 (각 30분 실행)**

| 초당 요청 수 | p99 응답 시간 | 오류율 | DB CPU 사용률 | 판정 |
|---|---|---|---|---|
| 500건 | 280ms | 0.04% | - | 통과 |
| 800건 | 1.9초 | 2.3% | 최대 95% | 실패 |

- 500건: p99 응답 시간과 오류율 모두 기준 이내입니다.
- 800건: p99 응답 시간은 기준(300ms)의 약 6배, 오류율은 기준(0.1%)의 23배입니다. DB CPU가 95%까지 올라 DB가 병목으로 보입니다.
