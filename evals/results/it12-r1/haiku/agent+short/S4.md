# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 payment-api 운영 배포를 이전 리비전으로 되돌리는 절차를 정의한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하지 않는다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
   확인 필요: 마이그레이션 포함 여부를 확인하는 방법과 위치.
2. **경고:** 마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 롤백을 중단하고 DBA 박지은에게 연락해야 한다.

## 롤백

3. 다음 명령으로 payment-api를 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

   확인 필요: `<REVISION>`에 넣을 값을 찾는 방법.

## 결과 확인

4. `/healthz`가 200을 반환하는지 확인한다.
   확인 필요: `/healthz`를 호출할 주소.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 기록

6. 롤백 이력을 #deploy 채널에 남긴다.
