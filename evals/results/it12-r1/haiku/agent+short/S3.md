# 토큰 만료 시각 경계에서 만료된 토큰을 유효하다고 판단하던 문제 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 문제를 고쳤다. 관련 이슈는 #412다.

## 원인

`is_valid()`의 비교 조건이 만료 시각 당일 경계를 포함하고 있었다. 현재 시각이 만료 시각과 정확히 같으면 토큰을 유효하다고 판단했다.

## 변경 내용

`auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다. 이 변경으로 현재 시각이 만료 시각과 같은 경우에는 토큰을 유효하지 않다고 판단한다.

테스트 2개를 추가했다.

- `test_token_expired_at_boundary`
- `test_token_valid_before_expiry`

## 검증

로컬에서 단위 테스트를 실행했고 모두 통과했다. 통합 테스트는 아직 실행하지 않았다.
