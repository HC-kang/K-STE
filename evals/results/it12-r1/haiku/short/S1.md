Redis를 도입하면 서버 4대가 같은 상품 목록을 함께 보므로, 가격을 바꿨을 때 서버에 따라 다르게 보이는 문제가 없어집니다.

지금은 서버 4대가 각자 자기 메모리(작업할 때 쓰는 임시 저장 공간)에 상품 목록을 5분 동안 따로 보관합니다. 그래서 서버마다 보관하는 내용이 다르고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영될 수 있습니다.

Redis는 데이터를 빠르게 저장하고 꺼내도록 만든 별도의 캐시 서버 프로그램입니다. 도입 후에는 서버 4대가 이 서버 1대에 상품 목록을 보관하고 함께 꺼내 씁니다.

| 구분 | 현재 로컬 캐시 | Redis 캐시 |
|---|---|---|
| 보관 위치 | 서버 4대 각각의 메모리 | 캐시 서버 1대 |
| 서버 간 내용 | 서버마다 다를 수 있습니다 | 4대가 같은 내용을 봅니다 |
| 가격 변경 반영 | 서버에 따라 최대 5분 늦습니다 | 서버 간 차이가 없습니다 |

Redis를 도입해도 최대 5분이라는 지연이 줄어드는지는 알 수 없습니다. 지연 시간은 캐시를 얼마나 오래 보관하는지에 따라 정해지기 때문입니다.

Redis 서버 1대가 멈추면 서버 4대가 모두 캐시를 쓸 수 없게 됩니다. 이 경우 상품 조회가 느려지거나 실패할 수 있습니다.
