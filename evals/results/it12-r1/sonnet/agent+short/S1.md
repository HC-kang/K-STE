로컬 캐시는 서버마다 따로 가진 임시 저장소이고, Redis 캐시는 서버 4대가 함께 쓰는 임시 저장소입니다. 캐시는 자주 쓰는 데이터를 미리 담아 두는 임시 저장소입니다.

지금은 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 그래서 서버마다 캐시 내용이 다릅니다. 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 서버 4대가 캐시 서버 1대를 같이 씁니다. 그래서 서버 4대가 같은 캐시 내용을 읽고, 서버끼리 캐시 내용이 달라지는 문제가 없어집니다.

확인 필요: 가격 반영 지연이 5분보다 짧아지는지는 Redis 캐시의 보관 시간과 가격 변경 시 캐시를 갱신하는 방식에 달려 있습니다. 두 가지가 정해졌는지 알려 주십시오.
