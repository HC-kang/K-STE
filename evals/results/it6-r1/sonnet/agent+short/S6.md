캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: '관리자 권한이 있는 팀원 및 QA 담당자'. 관리자 권한 조건이 팀원에만 걸리는지, QA 담당자에게도 걸리는지 정해지지 않았습니다.

확인 필요: '알려야 합니다'. 알릴 내용이 원문에 없습니다. 배포 일정을 알리는지, 재시작하면 초기화된다는 사실을 알리는지 정해지지 않았습니다.

확인 필요: '초기화됩니다'. 서버가 초기화되는지, 서버의 메모리 내용이 초기화되는지 정해지지 않았습니다.
