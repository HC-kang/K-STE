로컬 캐시는 서버마다 따로 갖는 임시 저장소이고, Redis 캐시는 서버 4대가 함께 보는 임시 저장소입니다. Redis를 도입하면 서버마다 상품 목록이 달라지는 문제가 사라집니다.

캐시는 자주 쓰는 데이터를 미리 저장해 두고 빠르게 꺼내 쓰는 방식입니다. 지금은 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 이것이 로컬 캐시입니다.

서버마다 저장한 시점이 다르기 때문에 서버 4대가 서로 다른 내용을 보여 줄 수 있습니다. 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다. 같은 고객이 새로 고침할 때마다 다른 가격을 볼 수도 있습니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버 1대입니다. 4대가 같은 저장소를 보므로 서버에 따라 내용이 달라지지 않습니다.

아직 확인하지 않은 점이 두 가지 있습니다. 하나는 가격을 바꾼 즉시 고객 화면에 반영되는지입니다. 이는 Redis의 저장 내용을 어떻게 갱신하도록 만드느냐에 달려 있습니다. 다른 하나는 캐시 서버가 1대이므로, 이 서버가 멈추면 서비스에 어떤 영향이 있는지입니다. 두 가지 모두 개발팀에 확인하겠습니다.
