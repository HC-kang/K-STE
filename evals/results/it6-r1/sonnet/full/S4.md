# 운영 배포 롤백 런북

ArgoCD로 배포한 payment-api의 운영 배포를 롤백하는 절차를 정리한 문서다. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 하며, 포함됐으면 롤백하지 않는다.

## 사전 조건

- 배포 도구는 ArgoCD다.
- 롤백 명령은 `argocd app rollback payment-api <REVISION>`이다.

## 절차

**마이그레이션이 포함된 배포는 롤백하면 안 된다.**

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다. 이후 단계는 진행하지 않는다.
3. 마이그레이션이 포함되지 않았으면 아래 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.
