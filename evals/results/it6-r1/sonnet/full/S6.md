캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: "초기화됩니다". 서버 자체가 초기화된다는 뜻인지, 메모리에 있는 데이터가 초기화된다는 뜻인지 알 수 없습니다.
확인 필요: "관리자 권한이 있는 팀원 및 QA 담당자". 관리자 권한 조건이 QA 담당자에게도 걸리는지, 팀원에게만 걸리는지 알 수 없습니다.
확인 필요: "알려야 합니다". 배포 사실을 알리라는 뜻인지, 재시작과 초기화가 있다는 점을 알리라는 뜻인지 알 수 없습니다.
