# 운영 배포 롤백 런북: payment-api

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 이전 리비전으로 되돌리는 절차다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 확인한다. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다.

## 1. 마이그레이션 포함 여부 확인

1. 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않는다. DBA 박지은에게 연락하고, 이 런북의 나머지 단계는 진행하지 않는다.
3. 마이그레이션이 포함되지 않았으면 2단계로 진행한다.

확인 필요: 마이그레이션 포함 여부를 확인하는 방법(도구, 화면, 담당자)은 제공된 사실에 없다.

## 2. 롤백 실행

1. 롤백할 리비전 번호를 REVISION에 넣는다.
2. 다음 명령을 실행한다.

   `argocd app rollback payment-api <REVISION>`

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

확인 필요: `/healthz` 응답이 200이 아니거나 테스트 주문이 실패했을 때의 조치는 제공된 사실에 없다.

## 4. 이력 기록

1. #deploy 채널에 롤백 이력을 남긴다.

확인 필요: 이력에 담을 항목(시각, 리비전, 확인 결과 등)은 제공된 사실에 없다.
