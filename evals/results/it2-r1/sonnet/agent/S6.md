캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

고칠 곳이 없습니다.

확인 필요: '배포 후 재시작하면 초기화됩니다'. 초기화되는 것이 메모리에 쌓인 데이터인지 서버 전체인지 정해지지 않았습니다.
확인 필요: '관리자 권한이 있는 팀원 및 QA 담당자'. 관리자 권한이 QA 담당자에게도 걸리는지, 팀원에게만 걸리는지 정해지지 않았습니다.
확인 필요: '공지 채널에 알려야 합니다'. 무엇을 알려야 하는지(배포 일정, 초기화 사실 등) 정해지지 않았습니다.
