이 문서는 사내 API 키의 교체와 보관 기준을 정한다.

## 교체 기준

운영 환경 API 키는 90일마다 교체한다. **이 규칙은 예외 없이 지켜야 하는 규칙이다.** 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다. 장애 대응 중이면 업무 시간 밖에 교체해도 괜찮다. 개발 환경 API 키는 90일 교체 규칙을 지킬 필요가 없다.

## 보관과 발급

API 키를 Git 저장소(소스 코드의 변경 이력을 관리하는 저장소)에 커밋하는 것은 **금지다.** 교체한 키는 Vault(비밀 값을 안전하게 보관하는 도구)의 `prod/api-keys` 경로에 저장해야 한다. Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.
