# API 키 관리 지침

## 1. 목적

이 문서는 API 키의 발급, 교체, 보관 기준을 정한다.

## 2. 용어 정의

| 용어 | 정의 |
|---|---|
| 운영 환경 | 실서비스가 동작하는 환경 |
| 개발 환경 | 개발 및 테스트에 사용하는 환경 |
| 교체 | 기존 API 키를 폐기하고 새 API 키로 바꾸는 작업 |
| 교체 주기 기산일 | 해당 API 키가 발급된 날짜 |
| 업무 시간 | 평일 10:00–18:00 |
| 장애 대응 중 | 서비스 장애의 원인 분석, 복구, 또는 영향 완화 작업이 진행 중인 상태 |

## 3. 교체 주기

1. 운영 환경 API 키는 **교체 주기 기산일로부터 90일마다 교체한다.**
2. 이 규칙에는 **예외가 없다.**
3. 개발 환경 API 키는 90일 교체 규칙의 적용 대상이 아니다.

## 4. 교체 시간

1. 운영 환경 API 키 교체는 **평일 업무 시간(10:00–18:00)에 하는 것을 권장한다.**
2. 장애 대응 중이면 업무 시간 밖에 교체해도 된다.

## 5. 저장 및 보관

1. API 키를 Git 저장소에 커밋하는 것을 **금지한다.**
2. 교체한 운영 환경 API 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 6. 발급

1. API 키는 Vault 웹 화면에서 직접 발급할 수 있다.

---

**검토 요청 사항 (문서 게시 전 확인 필요)**

- **교체 주기 기산일**을 "발급일"로 정의했다. 교체 완료일 기준으로 할 경우 이 정의를 수정해야 한다.
- **"장애 대응 중"의 범위**가 명확하지 않을 수 있다. 장애 등급이나 공지 기준이 있다면 해당 기준을 명시하는 편이 좋다.
- 개발 환경 키가 `prod/api-keys` 경로에 저장되지 않도록 별도 규정이 필요한지 검토하기 바란다.
