payment-api 운영 배포는 ArgoCD로 롤백한다. 롤백 전에 마이그레이션(DB 구조를 바꾸는 변경 스크립트)이 포함됐는지 확인해야 하며, 포함됐으면 롤백하면 안 된다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다. 확인 필요: 포함 여부를 확인하는 방법과 확인 위치는 원문에 없다.
2. 마이그레이션이 포함됐으면 **롤백하면 안 된다.**
3. 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 한다. 확인 필요: 연락 수단은 원문에 없다.
4. 마이그레이션이 포함되지 않았으면 롤백을 실행할 수 있다.

## 2. 롤백 실행

아래 명령으로 payment-api를 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

확인 필요: `<REVISION>`에 넣을 값을 찾는 방법은 원문에 없다.

## 3. 롤백 후 확인과 이력 기록

1. `/healthz`가 200을 반환하는지 확인한다. 확인 필요: `/healthz`를 호출할 주소는 원문에 없다.
2. 결제 테스트 주문을 1건 실행하고, 그 주문이 성공하는지 확인한다. 확인 필요: 테스트 주문 실행 방법은 원문에 없다.
3. 롤백 이력은 #deploy 채널에 남긴다. 확인 필요: 기록을 남기는 시점과 기록에 넣을 내용은 원문에 없다.
