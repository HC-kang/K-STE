# 토큰 만료 경계 시각에 토큰을 유효하다고 판단하는 문제 수정 (#412)

## 배경

토큰 만료 시각과 정확히 같은 시각에 요청하면 `is_valid()`가 토큰을 유효하다고 판단한다. 이 PR은 이 버그를 수정한다. 관련 이슈는 #412다.

## 변경 사항

`auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꾼다. 이 변경으로 현재 시각이 만료 시각과 같으면 토큰을 더 이상 유효하다고 판단하지 않는다.

## 테스트

`test_token_expired_at_boundary`와 `test_token_valid_before_expiry` 테스트를 추가한다. 로컬에서 단위 테스트는 모두 통과했다. 통합 테스트는 아직 실행하지 않았다.
