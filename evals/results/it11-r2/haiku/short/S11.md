# API 키 관리 지침

## 목적

이 지침은 API 키(서비스에 접근할 때 쓰는 인증 값)를 안전하게 관리하는 기준을 정한다. 운영 환경과 개발 환경의 키 교체 규칙, 키 보관 위치, 저장소 관리 규칙을 다룬다.

## 운영 환경 API 키 교체

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.

키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다. 장애 대응 중이면 업무 시간 밖에 교체해도 된다.

## 개발 환경 API 키 교체

개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 교체한 키 보관

교체한 키는 Vault(비밀 값을 안전하게 보관하는 도구)의 `prod/api-keys` 경로에 저장해야 한다.

Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.

## 저장소 관리

API 키를 Git 저장소에 커밋(변경 내용을 저장소에 기록하는 작업)하면 안 된다.
