이 런북은 ArgoCD로 payment-api의 운영 배포를 롤백하는 절차를 설명한다. 아래 순서대로 진행한다.

1. 롤백 대상 리비전 값(REVISION)을 확인한다.
2. 롤백하려는 배포에 DB 마이그레이션이 포함됐는지 확인한다.
   - **마이그레이션이 포함됐으면 롤백하면 안 된다.** 롤백을 중단하고 DBA 박지은에게 연락해야 한다.
   - 마이그레이션이 포함되지 않았으면 3단계로 진행한다.
3. 다음 명령으로 롤백한다. `<REVISION>` 자리에 1단계에서 확인한 리비전 값을 넣는다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. #deploy 채널에 롤백 이력을 남긴다.

확인 필요: 리비전 값을 찾는 방법이 제공되지 않았다.
확인 필요: 마이그레이션 포함 여부를 확인하는 방법이 제공되지 않았다.
확인 필요: `/healthz`를 호출할 주소와 결제 테스트 주문을 실행하는 방법이 제공되지 않았다.
확인 필요: `/healthz`가 200을 반환하지 않거나 테스트 주문이 실패했을 때 따를 조치가 제공되지 않았다.
확인 필요: #deploy 채널에 남길 이력의 형식이 제공되지 않았다.
