Redis를 도입하면 서버 4대가 같은 상품 목록을 읽기 때문에, 서버마다 내용이 달라지는 문제를 없앨 수 있습니다.

캐시(자주 쓰는 데이터를 미리 저장해 두는 곳)는 지금 서버마다 따로 있습니다. 이것이 로컬 캐시입니다. 서버 4대가 상품 목록을 각자의 메모리(서버 안의 작업용 저장 공간)에 5분 동안 저장합니다. 서버마다 저장한 시점이 달라서 캐시 내용도 서로 다릅니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis 캐시는 서버 4대가 함께 쓰는 캐시 서버 1대입니다. 상품 목록이 이 서버 한 곳에만 저장되므로 4대가 같은 내용을 읽습니다. 가격을 바꿀 때 Redis의 상품 목록만 고치면 4대가 모두 바뀐 가격을 보여줍니다.

가격 반영 지연이 최대 5분에서 얼마로 줄어드는지는 아직 정해진 내용이 없습니다.
