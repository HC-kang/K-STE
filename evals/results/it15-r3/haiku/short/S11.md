이 문서는 API 키의 교체 주기, 교체 시기, Git 저장소 관리, 발급과 저장 기준을 정한다.

## 교체 주기

- 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.
- 개발 환경 API 키에는 90일 교체 규칙을 적용하지 않는다.

## 교체 시기

- 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.

## Git 저장소 관리

- API 키를 Git 저장소에 커밋하면 안 된다.

## 발급과 저장

- Vault 웹 화면에서 API 키를 직접 발급할 수 있다.
- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

확인 필요: "교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다"가 운영 환경 키에만 적용되는지, 개발 환경 키에도 적용되는지 원문으로는 알 수 없다. 범위를 임의로 정하지 않고 원문 그대로 두었다.
