로컬 캐시는 서버마다 따로 저장해 두는 방식이고, Redis 캐시는 서버 4대가 한 곳에 저장해 두고 같이 읽는 방식입니다. 캐시는 자주 쓰는 데이터를 임시로 저장해 두었다가 다시 쓰는 기능입니다.

지금은 API 서버(고객 요청을 받아 처리하는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 캐시 서버 1대를 API 서버 4대가 같이 씁니다. 그래서 4대가 같은 캐시 내용을 읽고, 서버마다 캐시 내용이 다른 문제가 없어집니다.

다만 가격 반영이 얼마나 빨라지는지는 Redis 캐시를 언제 갱신하느냐에 따라 달라집니다.
