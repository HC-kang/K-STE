# 운영 배포 롤백 런북

이 문서는 ArgoCD로 운영 배포를 롤백하는 절차를 정한다. 배포 도구는 ArgoCD다.

## 사전 확인

롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. **경고:** 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다. 이때 DBA 박지은에게 연락한다.

## 롤백

3. 배포에 DB 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

## 롤백 후 검증

4. `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 기록

6. 롤백 이력을 #deploy 채널에 남긴다.
