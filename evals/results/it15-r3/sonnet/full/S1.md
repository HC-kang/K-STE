Redis를 도입하면 서버 4대가 같은 캐시를 보게 되어, 서버마다 상품 목록이 달라지는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 미리 저장해 두고 다시 꺼내 쓰는 방식입니다. 로컬 캐시는 서버 각각이 자기 메모리에 따로 저장하는 캐시입니다. 지금은 API 서버 4대가 상품 목록을 5분 동안 이렇게 저장합니다. 그래서 서버마다 저장된 내용이 다르고, 가격을 바꾸면 새 가격이 고객에게 최대 5분 늦게 보입니다.

Redis(데이터를 메모리에 저장해 두는 캐시 전용 프로그램)는 서버 4대가 함께 쓰는 캐시 서버 1대로 도입할 예정입니다. 이후에는 캐시가 한 곳에만 있으므로 서버마다 내용이 달라지지 않습니다. 가격을 바꿀 때도 캐시 한 곳만 갱신하면 서버 4대가 모두 새 가격을 보여줄 수 있습니다.
