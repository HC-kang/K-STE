# 운영 payment-api 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 이전 리비전으로 되돌리는 절차를 정한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 되며, DBA 박지은에게 연락해야 한다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다. DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 2단계로 진행한다.

## 2. 롤백 실행

4. `<REVISION>`에 롤백할 리비전 값을 넣고 `argocd app rollback payment-api <REVISION>` 명령을 실행한다.

## 3. 롤백 후 확인

5. `/healthz`의 응답 코드가 200인지 확인한다.
6. 결제 테스트 주문 1건을 실행하고 주문이 성공하는지 확인한다.

## 4. 이력 기록

7. 롤백 이력을 #deploy 채널에 남긴다.
