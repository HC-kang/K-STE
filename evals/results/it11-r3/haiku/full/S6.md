캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전에 공지 채널에 알려야 합니다.

확인 필요: "관리자 권한이 있는 팀원 및 QA 담당자". 관리자 권한 조건이 두 대상 모두에 걸리는지, 팀원에만 걸리는지 원문으로는 알 수 없습니다. 해석 1은 팀원과 QA 담당자 모두 관리자 권한이 있어야 한다는 것이고, 해석 2는 관리자 권한이 있는 팀원과 권한과 관계없는 QA 담당자를 가리킨다는 것입니다.

확인 필요: "초기화됩니다". 초기화되는 대상이 캐시 데이터인지, 서버 설정이나 상태인지 원문으로는 알 수 없습니다.
