로컬 캐시는 각 API 서버가 자기 메모리에 상품 목록을 임시로 저장해 두는 방식입니다. Redis는 서버 4대가 함께 쓰는 별도의 저장 서버에 같은 목록을 저장해 두는 방식입니다.

지금은 서버마다 저장된 내용이 달라서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다. Redis를 쓰면 4대가 같은 저장 서버를 조회하므로 서버마다 가격이 다르게 보이는 문제가 없어집니다.

다만 Redis를 도입한다고 가격 반영 지연이 자동으로 줄어들지는 않습니다. 지연 시간은 캐시를 얼마나 오래 보관하느냐에 따라 정해지므로, 보관 시간을 지금처럼 5분으로 두면 최대 5분 지연은 그대로 남습니다. 가격 반영을 더 빠르게 하려면 개발팀과 보관 시간을 줄일지, 가격을 바꿀 때 저장된 내용을 바로 지울지 함께 정해 주십시오.
