# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 이전 리비전으로 되돌리는 절차를 정한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
2. **경고:** 마이그레이션이 포함됐으면 롤백하면 안 된다. 이때 DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 다음 절차를 진행한다.

## 롤백 절차

4. `<REVISION>`에 롤백할 리비전 번호를 넣고 다음 명령을 실행한다.

```
argocd app rollback payment-api <REVISION>
```

## 결과 확인

5. 롤백한 뒤에는 `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 기록

7. 롤백 이력을 #deploy 채널에 남긴다.

---

원문에 없어서 런북에 넣지 않은 내용은 다음과 같다. 리비전 번호를 찾는 방법, 마이그레이션 포함 여부를 확인하는 자료, `/healthz`의 호스트 주소, 테스트 주문을 넣는 방법, DBA 연락 수단, 롤백 후 확인이 실패했을 때의 조치다. 이 항목들을 알려 주시면 해당 단계에 추가하겠습니다.
