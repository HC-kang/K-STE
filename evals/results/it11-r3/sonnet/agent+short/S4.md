# 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 `payment-api`를 롤백하는 절차를 설명한다. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

## 롤백 가능 여부

**경고: 롤백하려는 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락해야 한다.

## 절차

1. 롤백하려는 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다. 이후 단계는 하지 않는다.
3. 마이그레이션이 포함되지 않았으면 `argocd app rollback payment-api <REVISION>` 명령을 실행한다.
4. `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 2번 단계에서 마이그레이션이 포함된 경우에도 #deploy 채널에 이력을 남겨야 하는지.
