# 만료 시각과 정확히 같은 시각의 요청에서 토큰을 유효하다고 판단하는 버그 수정

`auth/token.py`의 `is_valid()`가 토큰 만료 시각과 정확히 같은 시각에 들어온 요청에서 토큰을 유효하다고 판단하던 버그를 고친다. 비교 연산을 `now <= expires_at`에서 `now < expires_at`로 바꿨다. 단위 테스트는 로컬에서 모두 통과했고, 통합 테스트는 아직 돌리지 않았다.

## 변경 내용

`auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다.
