로컬 캐시는 API 서버 4대가 각자 사본을 따로 갖는 방식이고, Redis 캐시는 4대가 사본 하나를 같이 쓰는 방식입니다. 캐시는 자주 쓰는 데이터를 미리 저장해 두는 것을 말합니다.

지금은 서버마다 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 바뀐 가격이 고객에게 최대 5분 늦게 보입니다.

Redis(여러 서버가 같이 쓰는 캐시 전용 서버)는 서버 4대가 같이 쓰는 캐시 서버 1대로 도입할 예정입니다. 4대가 같은 캐시를 읽으므로, 서버마다 캐시 내용이 달라지는 문제가 없어집니다.
