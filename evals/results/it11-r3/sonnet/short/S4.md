# 운영 배포 롤백 런북

## 절차

1. 롤백 전에 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인한다.
2. 배포에 마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA 박지은에게 연락한다.
3. 배포에 마이그레이션이 포함되지 않았으면 ArgoCD로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요

- 마이그레이션 포함 여부를 어디에서 어떻게 확인하는가?
- `<REVISION>` 값은 어디에서 찾는가?
- 롤백 후 `/healthz` 확인이나 테스트 주문이 실패하면 어떻게 하는가?
