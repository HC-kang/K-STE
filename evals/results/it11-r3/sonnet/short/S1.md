가장 큰 차이는 캐시(자주 쓰는 데이터를 잠시 저장해 두는 곳)를 서버마다 따로 두느냐, 서버 4대가 하나를 같이 쓰느냐입니다.

지금은 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 이것이 로컬 캐시입니다. 서버마다 저장한 시점이 달라서 캐시 내용도 서로 다릅니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영되고, 같은 시점에도 어느 서버가 요청을 받느냐에 따라 고객이 다른 가격을 볼 수 있습니다.

Redis(캐시 전용 서버)를 도입하면 서버 4대가 캐시 서버 1대를 함께 봅니다. 그래서 서버마다 캐시 내용이 달라지는 문제가 없어지고, 고객은 어느 서버를 거쳐도 같은 상품 목록을 봅니다.

Redis 서버가 1대라서, 이 서버가 멈추면 API 서버 4대 모두 캐시를 쓰지 못합니다.

확인 필요: 가격 변경이 고객에게 반영되는 시간이 5분보다 짧아지는지는 지금 정보로 알 수 없습니다. Redis에 캐시를 몇 분 보관하는지, 가격을 바꿀 때 저장된 캐시를 바로 지우는지에 따라 달라집니다.
