고칠 곳은 없습니다.

확인 필요: '배포 후 재시작하면 초기화됩니다'. 메모리 사용량이 초기화된다는 뜻인지, 캐시에 저장된 데이터가 삭제된다는 뜻인지 정해지지 않았습니다.

확인 필요: '관리자 권한이 있는 팀원 및 QA 담당자는'. 관리자 권한이 있는 팀원과 QA 담당자 모두가 대상인지, 관리자 권한이 있는 팀원과 권한 여부와 상관없는 QA 담당자가 대상인지 정해지지 않았습니다.

확인 필요: '배포 전 공지 채널에 알려야 합니다'. 알려야 할 내용이 원문에 없습니다.
