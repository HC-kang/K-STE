캐시 서버와 API 서버는 메모리를 많이 사용합니다. 캐시 서버와 API 서버는 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: '관리자 권한이 있는 팀원 및 QA 담당자'. QA 담당자도 관리자 권한이 있어야 하는지, 관리자 권한이 있는 팀원과 권한 여부와 관계없는 QA 담당자인지 정해지지 않았습니다.
확인 필요: '알려야 합니다'. 공지 채널에 무엇을 알려야 하는지 원문에 없습니다.
확인 필요: '초기화됩니다'. 서버 전체가 초기화되는지, 메모리나 캐시 데이터가 초기화되는지 정해지지 않았습니다.
