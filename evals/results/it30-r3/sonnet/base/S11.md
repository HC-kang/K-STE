# API 키 관리 지침

## 적용 범위

이 지침은 사내에서 사용하는 모든 API 키에 적용한다. 환경별로 적용 여부가 다른 항목은 각 항목에 따로 적었다.

## 1. 키 교체 주기

| 환경 | 교체 주기 | 구분 |
|---|---|---|
| 운영 | 90일마다 교체 | 필수 (예외 없음) |
| 개발 | 정해진 주기 없음 | 90일 교체 규칙 적용 안 함 |

- 운영 환경 API 키는 90일마다 반드시 교체한다. 예외는 없다.
- 개발 환경 API 키에는 90일 교체 규칙을 적용하지 않는다.

## 2. 키 교체 시간

- **권장**: 평일 업무 시간(10:00-18:00)에 교체한다.
- **허용**: 장애 대응 중이면 업무 시간 밖에 교체해도 된다.

## 3. 키 저장

- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 4. 금지 사항

- API 키를 Git 저장소에 커밋하는 것은 금지한다.

## 참고

- Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.

---

**표기 기준**
- 필수: "~해야 한다", "~한다" (어기면 안 됨)
- 금지: "금지한다" (하면 안 됨)
- 권장: "권장한다" (따르는 것이 좋으나 어겨도 위반은 아님)
- 허용: "~해도 된다" (해도 되는 경우)
