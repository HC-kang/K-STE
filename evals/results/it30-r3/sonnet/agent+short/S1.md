로컬 캐시는 서버 4대가 각자 따로 가진 저장 공간이고, Redis는 서버 4대가 함께 쓰는 저장 공간입니다. 캐시는 자주 쓰는 데이터를 미리 가까운 곳에 저장해 두는 기능입니다.

지금은 서버마다 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다. 같은 시각에도 고객이 어느 서버에 접속했는지에 따라 다른 가격을 볼 수 있습니다.

Redis는 캐시 전용 서버 1대에 상품 목록을 저장합니다. API 서버 4대가 모두 이 Redis 서버를 읽기 때문에, 서버마다 캐시 내용이 달라지는 문제가 없어집니다.

가격 변경이 고객에게 얼마나 빨리 보일지는 가격을 바꿀 때 Redis의 캐시를 함께 바꾸느냐에 달려 있습니다. Redis를 도입하는 것만으로 5분 지연이 없어지는지는 아직 모릅니다.
