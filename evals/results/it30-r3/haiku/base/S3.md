## 요약

토큰 만료 시각과 정확히 같은 시각에 요청이 들어오면 토큰을 유효한 것으로 판단하던 경계 조건 버그를 수정합니다.

관련 이슈: #412

## 원인

`auth/token.py`의 `is_valid()`가 `now <= expires_at`로 비교하고 있었습니다. 이 경우 `now == expires_at`인 순간에도 토큰이 유효하다고 판단되어, 이미 만료된 시점에 요청이 통과할 수 있었습니다.

## 변경 사항

- `auth/token.py`의 `is_valid()`에서 비교 연산자를 `now <= expires_at`에서 `now < expires_at`로 변경했습니다. 만료 시각 자체는 더 이상 유효 시각에 포함되지 않습니다.
- 경계 조건을 검증하는 테스트 2개를 추가했습니다.
  - `test_token_expired_at_boundary`: `now == expires_at`일 때 토큰이 무효로 판단되는지 확인
  - `test_token_valid_before_expiry`: `expires_at`보다 이전 시각에는 토큰이 유효로 판단되는지 확인

## 리뷰 포인트

- 토큰 유효성 판단에 의존하는 다른 호출부가 있다면 경계 동작 변화에 영향을 받을 수 있습니다.
