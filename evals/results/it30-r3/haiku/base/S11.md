# API 키 관리 지침

## 1. 목적

이 문서는 API 키의 발급, 교체, 저장, 보관에 관한 기준을 정한다.

## 2. 용어

| 용어 | 정의 |
|---|---|
| 운영 환경 | 실제 서비스가 동작하는 환경 |
| 개발 환경 | 개발과 테스트에 사용하는 환경 |
| 교체 주기 | 직전 교체일로부터 90일 |
| 업무 시간 | 평일 10:00–18:00 |
| 장애 대응 중 | 운영 환경에서 장애가 발생하여 대응 작업을 진행하는 기간 |

## 3. 규칙

### 3.1 운영 환경 키 교체 (필수)

- 운영 환경 API 키는 **교체 주기(90일)마다 교체한다.**
- 이 규칙은 예외 없이 적용한다.

### 3.2 키 교체 시점

- 교체는 **평일 업무 시간(10:00–18:00)에 수행하는 것을 권장한다.**
- **장애 대응 중**에는 업무 시간 외에 교체해도 된다.

### 3.3 키 저장 위치

- 교체한 운영 환경 키는 Vault의 **`prod/api-keys` 경로**에 저장한다.

### 3.4 키 발급

- Vault 웹 화면에서 API 키를 직접 발급할 수 있다.

### 3.5 Git 저장소 보관 금지

- API 키를 Git 저장소에 **커밋하는 것을 금지한다.**
- 이 규칙은 운영 환경과 개발 환경 키 모두에 적용한다.

### 3.6 개발 환경 키

- 개발 환경 API 키는 **90일 교체 규칙(3.1)을 적용하지 않는다.**

## 4. 요약

| 항목 | 기준 |
|---|---|
| 운영 키 교체 주기 | 90일, 예외 없음 |
| 운영 키 교체 시간 | 평일 10:00–18:00 권장, 장애 대응 중에는 업무 시간 외 허용 |
| 운영 키 저장 위치 | Vault `prod/api-keys` |
| 개발 키 교체 주기 | 적용 없음 |
| Git 커밋 | 금지 |

---

**작성 시 정리한 내용**
- "교체 주기"를 "직전 교체일로부터 90일"로 명시했습니다. 원문의 "90일마다"를 기준일이 분명하도록 바꾼 것입니다.
- "장애 대응 중"의 정의는 원문에 없어 제가 일반적인 의미로 적었습니다. 위키에 올리기 전에 팀 기준에 맞는지 확인해 주세요.
- 개발 환경 키의 저장 위치와 관리 방법은 원문에 없어 문서에 넣지 않았습니다. 필요하면 별도로 정해 추가해야 합니다.
