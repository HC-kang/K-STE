# 운영 배포 롤백 런북 (payment-api, ArgoCD)

이 런북은 ArgoCD로 배포한 payment-api를 이전 REVISION으로 되돌리는 절차다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 되고, DBA 박지은에게 연락해야 한다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
   확인 필요: 마이그레이션 포함 여부를 확인하는 방법. 원문에 방법이 없다.
2. **경고:** 마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA 박지은에게 연락해야 한다.
   확인 필요: DBA 박지은의 연락 방법. 원문에 연락처가 없다.
3. 마이그레이션이 포함되지 않은 경우에만 다음 롤백 절차를 진행한다.
4. 롤백할 REVISION 값을 확인한다.
   확인 필요: REVISION 값을 찾는 방법. 원문에 방법이 없다.

## 롤백 절차

5. 마이그레이션이 포함되지 않은 것을 확인한 뒤 다음 명령으로 payment-api를 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

## 결과 확인

6. 롤백이 끝난 뒤 `/healthz`가 200을 반환하는지 확인한다.
   확인 필요: `/healthz`를 호출할 주소. 원문에 주소가 없다.
7. `/healthz`가 200을 반환하면 결제 테스트 주문 1건을 실행하고, 그 주문이 성공하는지 확인한다.
   확인 필요: 결제 테스트 주문을 실행하는 방법과 담당자. 원문에 방법이 없다.

## 기록

8. 롤백 이력을 #deploy 채널에 남긴다.
