지금 쓰는 로컬 캐시(자주 쓰는 데이터를 미리 복사해 둔 임시 저장소)는 서버 4대가 각각 따로 가지고, 도입 예정인 Redis(여러 서버가 함께 쓰는 캐시 전용 저장 프로그램)는 서버 4대가 함께 쓰는 1대입니다. Redis를 도입하면 4대의 서버가 같은 상품 목록을 보게 됩니다.

지금 우리 서버는 상품 목록을 각 서버의 메모리(작업할 때 쓰는 임시 기억 공간)에 5분 동안 보관합니다. 서버마다 보관한 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

| 구분 | 로컬 캐시 (지금) | Redis 캐시 (도입 예정) |
|---|---|---|
| 캐시를 두는 곳 | 서버 4대 각각의 메모리 | 캐시 서버 1대 |
| 서버마다 내용이 달라지는지 | 달라질 수 있습니다 | 같은 내용을 봅니다 |

Redis를 도입하면 서버마다 가격이 다르게 보이는 문제는 없어집니다. 다만 가격 변경이 고객에게 몇 분 만에 반영되는지는 이 내용만으로 알 수 없습니다.

확인 필요: Redis 캐시에도 상품 목록을 5분 동안 보관하는지, 가격을 바꿀 때 캐시를 바로 비우는지 정해야 합니다.
