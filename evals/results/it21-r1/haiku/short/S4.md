이 런북은 ArgoCD로 배포한 payment-api를 이전 리비전으로 롤백하는 절차를 정한다.

1. 롤백 전에 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 확인한다.
   - **마이그레이션이 포함됐으면 롤백하면 안 된다.**
   - 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 한다.
   - 마이그레이션이 포함되지 않았으면 2번 단계로 진행한다.
   - 확인 필요: 마이그레이션 포함 여부를 확인하는 방법과 DBA 박지은의 연락 방법을 확인 필요.
2. 마이그레이션이 포함되지 않은 경우에만 다음 명령을 실행해 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

   - 확인 필요: `<REVISION>`에 넣을 값을 확인 필요.
3. 롤백한 뒤에 `/healthz`가 200을 반환하는지 확인한다.
4. 롤백한 뒤에 결제 테스트 주문 1건이 성공하는지 확인한다.
5. 롤백 이력을 #deploy 채널에 남긴다.
