# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 롤백하는 절차다. 롤백 전에 배포에 DB 마이그레이션이 포함됐는지 먼저 확인하며, 마이그레이션이 포함된 배포는 롤백하지 않는다.

## 1. 롤백 전 점검

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 **롤백하지 않는다.** DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았으면 4번 단계로 진행한다.

## 2. 롤백 실행

4. 터미널에서 `argocd app rollback payment-api <REVISION>` 명령을 실행한다. `<REVISION>`에는 롤백할 대상 리비전을 넣는다.

## 3. 롤백 후 점검

5. payment-api의 `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문 1건을 실행하고, 주문이 성공하는지 확인한다.

## 4. 이력 기록

7. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 마이그레이션 포함 여부를 확인하는 방법. 원문에 확인 방법과 기준이 없다.
확인 필요: `<REVISION>`에 넣을 값을 정하는 방법. 원문에 대상 리비전을 고르는 기준이 없다.
