# 토큰 만료 시각 경계 판단 버그 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 버그를 수정한다. 이 PR은 `auth/token.py`의 `is_valid()` 비교 조건 한 곳을 바꾸고 경계 시각을 검증하는 테스트 2개를 추가한다.

## 버그

토큰 만료 시각과 정확히 같은 시각에 요청하면 `is_valid()`가 토큰을 유효하다고 판단했다. 만료 시각은 이미 만료된 시점으로 봐야 하지만, 기존 조건이 이 시각을 유효 범위에 포함했다.

## 변경 사항

`auth/token.py`의 `is_valid()`에서 비교 조건을 `now <= expires_at`에서 `now < expires_at`로 바꾼다. 이 변경으로 `now`가 `expires_at`과 같은 시각이면 토큰을 유효하지 않다고 판단한다.

## 테스트

- `test_token_expired_at_boundary`를 추가한다.
- `test_token_valid_before_expiry`를 추가한다.
- 로컬에서 단위 테스트를 실행한 결과 모두 통과했다.
- 통합 테스트는 아직 실행하지 않았다.
