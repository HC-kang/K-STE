이 런북은 ArgoCD(배포 도구)로 배포한 payment-api를 이전 리비전(배포 버전 식별자)으로 되돌리는 절차를 정한다.

## 1. 롤백 전 확인

1. 롤백 대상 배포에 DB 마이그레이션(데이터베이스 구조를 바꾸는 변경 작업)이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 **롤백하지 않는다.**
3. 마이그레이션이 포함됐으면 DBA(데이터베이스 관리자) 박지은에게 연락한다.
4. 마이그레이션이 포함되지 않았으면 2단계로 넘어간다.

확인 필요: 배포에 마이그레이션이 포함됐는지 확인하는 구체적인 방법은 주어지지 않았다.

## 2. 롤백 실행

1. 아래 명령의 `<REVISION>` 자리에 되돌릴 이전 리비전 값을 넣고 실행한다.

```
argocd app rollback payment-api <REVISION>
```

## 3. 롤백 후 검증

1. 상태 확인용 주소(`/healthz`)가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

확인 필요: `/healthz`가 200을 반환하지 않을 때의 조치는 주어지지 않았다.

## 4. 롤백 이력 기록

1. #deploy 채널에 롤백 이력을 남긴다.
