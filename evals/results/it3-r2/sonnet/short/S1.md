Redis를 도입하면 서버 4대가 같은 캐시를 보게 되어, 서버마다 가격이 다르게 보이는 문제가 사라집니다.

로컬 캐시는 서버 각각의 메모리에 상품 목록을 따로 저장해 두는 방식입니다. 캐시는 자주 쓰는 데이터를 임시로 저장해 두는 것을 뜻합니다. 지금은 서버 4대가 각자 5분 동안 자기 사본을 들고 있어서, 가격을 바꿔도 서버마다 반영 시점이 다르고 최대 5분까지 늦어집니다.

Redis 캐시는 서버 4대가 함께 쓰는 캐시 전용 서버 1대에 상품 목록을 한 벌만 저장하는 방식입니다. 서버 4대가 같은 사본을 읽으므로, 고객은 어느 서버에 연결되든 같은 가격을 봅니다.

주의할 점은 두 가지입니다.

- 캐시 유지 시간을 지금처럼 5분으로 두면 최대 5분 지연은 남습니다. 가격을 바꾸는 즉시 캐시를 지우는 작업을 함께 해야 지연이 줄어듭니다.
- Redis 서버는 1대이므로, 이 서버에 장애가 나면 API 서버 4대 모두 영향을 받을 수 있습니다.
