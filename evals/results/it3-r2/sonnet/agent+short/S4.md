운영 배포 롤백은 ArgoCD로 하며, 롤백 전에 DB 마이그레이션 포함 여부를 확인해야 한다.

사용자가 런북을 요청했으므로 한다체로 쓴다.

## 대상

이 런북은 ArgoCD로 배포한 `payment-api`의 운영 배포를 롤백하는 절차를 설명한다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다. DBA 박지은에게 연락하고 이후 단계를 진행하지 않는다.
3. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백한 뒤에 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.
