캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: "배포 후 재시작하면 초기화됩니다". 두 서버가 모두 초기화된다는 뜻일 수도 있고, API 서버만 초기화된다는 뜻일 수도 있습니다. 초기화되는 대상(메모리, 캐시 데이터 등)도 적혀 있지 않습니다.

확인 필요: "관리자 권한이 있는 팀원 및 QA 담당자". 관리자 권한이 팀원과 QA 담당자 모두에게 걸릴 수도 있고, 팀원에게만 걸릴 수도 있습니다.

확인 필요: "공지 채널에 알려야 합니다". 알릴 내용이 적혀 있지 않습니다. 배포 사실만 알리라는 뜻일 수도 있고, 재시작과 초기화까지 알리라는 뜻일 수도 있습니다.
