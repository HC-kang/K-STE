캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전에 공지 채널에 알려야 합니다.

확인 필요: "초기화됩니다". 초기화되는 것이 메모리인지, 캐시 데이터인지, 서버 상태 전체인지 원문에 없습니다.
확인 필요: "캐시 서버와 API 서버는 ~하며, ~초기화됩니다". 재시작 시 초기화가 두 서버에 모두 해당하는지, 캐시 서버에만 해당하는지 알 수 없습니다.
확인 필요: "관리자 권한이 있는 팀원 및 QA 담당자". 관리자 권한 조건이 QA 담당자에게도 걸리는지, 팀원에게만 걸리는지 알 수 없습니다. 또 "알려야 합니다"의 목적어(무엇을 알리는지)가 없습니다.
