# 파일 공유 규정

## 파일 업로드

첨부 파일 하나가 25MB를 넘으면 업로드를 막는다.

한 게시물에는 파일을 10개까지 올릴 수 있다.

## 외부 공유 링크

만 19세가 안 된 인턴은 외부 공유 링크를 만들 수 없다.

외부 공유 링크는 만든 시각부터 72시간이 지나면 닫힌다.

## 비밀번호 입력 제한

비밀번호를 5번 연속 틀리면 계정을 30분 동안 잠근다.

---

확인 필요: 원문에 연속 실패 횟수가 언제 초기화되는지 없어서 문서에 넣지 않았다. 확인 필요: 30분 잠금이 마지막 실패 시각부터 세는지도 원문에 없다. 확인 필요: 규정의 적용 대상, 예외, 문의처도 원문에 없어 문서에 넣지 않았다.
