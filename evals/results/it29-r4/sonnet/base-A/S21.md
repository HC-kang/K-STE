# 파일 공유 규정

## 1. 목적
이 문서는 사내에서 파일을 첨부하고 공유할 때 지켜야 할 기준을 정합니다.

## 2. 첨부 파일 규정

### 2.1 파일 크기 제한
- 첨부 파일 하나가 **25MB를 넘으면** 업로드가 차단됩니다.

### 2.2 게시물당 파일 개수
- 한 게시물에는 파일을 **최대 10개**까지 올릴 수 있습니다.

## 3. 외부 공유 링크 규정

### 3.1 생성 제한
- **만 19세가 안 된 인턴**은 외부 공유 링크를 만들 수 없습니다.

### 3.2 유효 기간
- 외부 공유 링크는 만든 시각부터 **72시간이 지나면** 자동으로 닫힙니다.

## 4. 계정 보안 규정

### 4.1 로그인 실패 시 잠금
- 비밀번호를 **5번 연속** 틀리면 계정이 **30분 동안** 잠깁니다.

## 5. 요약

| 항목 | 기준 |
|---|---|
| 파일 하나의 최대 크기 | 25MB (초과 시 업로드 차단) |
| 게시물당 최대 파일 수 | 10개 |
| 외부 공유 링크 생성 | 만 19세 미만 인턴은 불가 |
| 외부 공유 링크 유효 기간 | 생성 후 72시간 |
| 비밀번호 5회 연속 오류 | 계정 30분 잠금 |
