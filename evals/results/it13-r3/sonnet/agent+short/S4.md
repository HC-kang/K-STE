# 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 `payment-api`의 운영 배포를 롤백하는 절차를 정리한다. 롤백하기 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

## 경고

**DB 마이그레이션이 포함된 배포는 롤백하면 안 된다.**

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았으면 아래 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백한 뒤에 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 원문에는 마이그레이션이 포함되지 않았을 때 롤백한다는 문장이 없다. 3단계는 2단계의 반대 조건으로 쓴 것이므로 이 해석이 맞는지 확인이 필요하다.
