# 인증 개선 회의 회의록

10월 17일 14:00에 인증 개선 회의를 했다. 인증 서버의 세션 만료 시간을 30분에서 60분으로 늘리기로 했고, 결제 서버의 세션 만료 시간은 30분으로 유지하기로 했다. 할 일은 3건이다.

## 참석자

박준호, 정은지, 김하늘

## 결정

- 인증 서버의 세션 만료 시간을 30분에서 60분으로 늘린다.
- 결제 서버의 세션 만료 시간은 30분으로 유지한다.

## 할 일

- 박준호가 인증 서버 설정 파일 `auth.yaml`의 `session_timeout` 값을 바꾼다. 기한은 10월 21일이다.
- 정은지가 고객 공지 초안을 쓴다. 공지에는 인증 서버 변경만 넣는다. 기한은 10월 22일이다.
- 김하늘이 10월 23일에 결제 서버 설정이 바뀌지 않았는지 점검한다.
