로컬 캐시는 각 서버가 자기 메모리에 상품 목록 사본을 두는 방식이고, Redis(서버 4대가 함께 쓰는 공용 저장소)는 별도 서버 1대에 사본을 두는 방식입니다.

| 구분 | 로컬 캐시 | Redis 캐시 |
|---|---|---|
| 사본을 두는 곳 | 서버 4대 각각의 메모리 안 | 서버 4대가 함께 쓰는 별도 서버 1대 |
| 서버 간 가격 일치 | 서버마다 다른 값을 보일 수 있습니다 | 4대가 같은 값을 봅니다 |
| 읽는 속도 | 서버 안에서 바로 읽어 가장 빠릅니다 | 네트워크를 거쳐 읽어 로컬보다 조금 느립니다 |
| 장애 영향 | 서버 한 대가 멈추면 그 서버의 사본만 없어집니다 | Redis 서버가 멈추면 4대 모두 영향을 받습니다 |

Redis를 도입하면 서버 4대가 같은 사본을 보므로, 서버마다 가격이 다르게 보이는 문제는 없어집니다. 다만 가격을 바꾼 뒤 고객에게 바뀐 가격이 보이기까지 걸리는 시간은 도입 방식에 따라 달라집니다.

확인 필요: 가격을 바꿀 때 Redis의 사본을 바로 지우거나 갱신하는지, 아니면 사본이 만료될 때까지 기다리는지 개발팀에 확인해야 합니다.
