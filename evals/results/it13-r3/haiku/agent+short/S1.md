로컬 캐시는 서버마다 상품 목록을 자기 메모리(서버가 작업할 때 쓰는 임시 공간)에 따로 복사해 두는 방식입니다. Redis 캐시는 서버 4대가 함께 쓰는 별도의 캐시 서버(자주 쓰는 데이터를 임시로 보관하는 서버)에 상품 목록을 두는 방식입니다.

| 구분 | 지금: 로컬 캐시 | 도입 예정: Redis 캐시 |
|---|---|---|
| 보관 위치 | 각 서버의 메모리에 있습니다. | 캐시 서버 1대에 있습니다. |
| 서버 사이의 내용 | 서버마다 다를 수 있습니다. | 4대 서버가 같은 내용을 봅니다. |
| 조회 속도 | 서버 안에서 바로 꺼내므로 빠릅니다. | 네트워크를 거쳐 꺼내므로 로컬보다 느릴 수 있습니다. |

Redis를 도입하면 서버마다 다른 상품 정보가 보이는 문제가 없어집니다. 다만 가격을 바꾼 뒤 고객에게 반영되기까지 걸리는 시간이 5분에서 얼마나 줄어드는지는 아직 확인되지 않았습니다. 이 부분은 개발팀에 확인이 필요합니다.
