# 토큰 만료 시각 경계에서 만료된 토큰을 유효로 판단하는 문제 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 문제를 고친다. `auth/token.py`의 `is_valid()`에서 비교 조건을 `now <= expires_at`에서 `now < expires_at`으로 바꿨다. 관련 이슈는 #412다.

## 변경 내용

`is_valid()`는 현재 시각이 만료 시각과 같을 때도 토큰을 유효하다고 판단했다. 이번 변경으로 `is_valid()`는 현재 시각이 만료 시각보다 이른 경우에만 토큰을 유효하다고 판단한다.

테스트 2개를 추가했다.

- `test_token_expired_at_boundary`
- `test_token_valid_before_expiry`

## 검증

- 실행함: 로컬에서 단위 테스트를 모두 실행했고 모두 통과했다.
- 실행하지 않음: 통합 테스트는 아직 실행하지 않았다.
