# 운영 배포 롤백 런북

이 런북은 ArgoCD로 `payment-api`의 운영 배포를 롤백하는 절차를 설명한다. 아래 순서대로 진행한다.

1. 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 확인한다.
   확인 필요: 마이그레이션 포함 여부를 확인하는 방법과 기준 위치.

   **마이그레이션이 포함됐으면 롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락해야 한다.
   확인 필요: DBA 박지은에게 연락하는 방법.

2. 마이그레이션이 포함되지 않았다면 롤백 명령을 실행한다. `<REVISION>`에는 롤백할 리비전 값을 넣는다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

   확인 필요: 롤백할 리비전 값을 찾는 방법.

3. 롤백 후 `/healthz`가 200을 반환하는지 확인한다.
   확인 필요: `/healthz`를 호출할 주소.

4. 롤백 후 결제 테스트 주문 1건을 실행하고, 그 주문이 성공하는지 확인한다.
   확인 필요: 테스트 주문을 실행할 환경과 방법.

5. 롤백 이력을 #deploy 채널에 남긴다.
   확인 필요: 이력에 적을 항목.
