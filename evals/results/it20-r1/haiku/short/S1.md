로컬 캐시는 서버마다 따로 저장하고, Redis 캐시는 서버 4대가 함께 쓰는 한 곳에 저장합니다. 캐시는 자주 쓰는 데이터를 빨리 꺼내려고 임시로 담아 두는 저장소입니다.

| 구분 | 로컬 캐시 (현재) | Redis 캐시 (도입 예정) |
|---|---|---|
| 저장 위치 | 각 API 서버 안 | 별도 캐시 서버 1대 |
| 서버 간 내용 | 서버마다 다를 수 있습니다 | 4대 서버가 같은 내용을 봅니다 |
| 가격 반영 | 최대 5분 뒤 반영됩니다 | 아래 설명처럼 설정에 따라 달라집니다 |

Redis를 도입하면 서버 4대가 같은 상품 목록을 보므로, 고객이 서버에 따라 다른 가격을 보는 일이 줄어듭니다. 다만 Redis를 도입하는 것만으로는 가격 변경이 바로 반영되지 않습니다. Redis에서도 저장 유효 시간을 5분으로 두면 가격 변경은 최대 5분 뒤에 반영됩니다. 가격이 바뀔 때 저장된 목록을 바로 지우는 작업을 추가하면 고객에게 바로 반영할 수 있습니다.

확인 필요: Redis에 저장하는 상품 목록의 유효 시간을 5분으로 둘지, 가격 변경 시 목록을 지우는 작업을 넣을지 정해야 합니다.
