로컬 캐시는 서버 4대가 각자 따로 저장하는 방식이고, Redis 캐시는 서버 4대가 한 곳에 같이 저장하는 방식입니다. 그래서 Redis를 도입하면 서버마다 캐시 내용이 달라지는 문제가 없어집니다.

| | 로컬 캐시(현재) | Redis 캐시(도입 예정) |
|---|---|---|
| 저장 위치 | API 서버 4대가 각자 자기 메모리에 저장합니다. | 캐시 서버 1대에 저장합니다. |
| 서버 간 캐시 내용 | 서버마다 다릅니다. | 서버 4대가 같은 캐시를 읽습니다. |

캐시(자주 쓰는 데이터를 임시로 저장해 두고 다시 꺼내 쓰는 기능)는 지금 API 서버 4대가 각자 자기 메모리(서버가 데이터를 잠시 담아 두는 공간)에 상품 목록을 5분 동안 저장합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis(여러 서버가 같이 쓰는 캐시 전용 서버)는 1대를 두고 API 서버 4대가 모두 그 서버의 캐시를 읽습니다. 캐시가 한 곳에 있으므로, 한 곳의 내용만 고치면 서버 4대가 모두 같은 내용을 읽습니다.
