# payment-api 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 payment-api의 운영 배포를 롤백하는 절차를 설명한다.

## 롤백 전

롤백 전에 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

- 마이그레이션이 포함되지 않았으면 다음 단계에서 롤백 명령을 실행한다.
- 마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA 박지은에게 연락해야 한다.

## 롤백

마이그레이션이 포함되지 않았을 때 아래 명령을 실행한다.

```
argocd app rollback payment-api <REVISION>
```

## 롤백 후

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.
3. 롤백 이력을 #deploy 채널에 남긴다.
