Redis를 도입하면 API 서버 4대가 같은 상품 목록을 보게 되어, 서버마다 가격이 다르게 보이는 문제가 사라집니다.

캐시는 자주 쓰는 데이터를 임시로 저장해 두고 빠르게 꺼내 쓰는 방식입니다. 로컬 캐시는 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장하는 방식입니다. Redis 캐시는 4대가 함께 쓰는 캐시 서버 1대에 상품 목록을 저장하는 방식입니다.

지금은 서버마다 캐시 내용이 다릅니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다. Redis를 쓰면 4대가 같은 캐시를 읽으므로, 서버에 따라 고객이 다른 가격을 보는 일이 없어집니다.

하지만 가격 반영이 5분보다 빨라지는지는 아직 알 수 없습니다. Redis에서도 5분 동안 저장해 두고 그 시간이 끝나기를 기다리면 지연은 남을 수 있습니다.

확인 필요: 가격을 바꿀 때 Redis의 캐시를 바로 갱신하는지, 5분이 끝나기를 기다리는지 정해야 합니다.
