로컬 캐시는 서버마다 따로 갖는 저장 공간이고, Redis 캐시는 서버 4대가 함께 쓰는 저장 공간 하나입니다. 캐시는 자주 쓰는 데이터를 잠시 저장해 두고 다시 꺼내 쓰는 방식입니다.

현재는 API 서버 4대가 각자 메모리에 상품 목록을 5분 동안 캐시합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다. 직원 4명이 각자 자기 수첩에 가격표를 베껴 둔 상태와 비슷합니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버 1대입니다. 사무실 공용 게시판 하나를 4명이 같이 보는 것과 비슷합니다. 그래서 서버마다 캐시 내용이 달라지는 일이 없어집니다. 가격 변경이 늦게 반영되는 현재 문제는 서버마다 캐시 내용이 다른 데서 생기므로, Redis 도입은 이 원인을 없애는 변경입니다.
