## 요약

토큰 만료 시각과 정확히 같은 시각에 들어온 요청을 유효한 토큰으로 판단하던 버그를 수정합니다. 만료 시각 이후뿐 아니라 만료 시각 당시에도 토큰을 무효로 처리하도록 경계 조건을 바로잡았습니다.

Closes #412

## 원인

`auth/token.py`의 `is_valid()`가 `now <= expires_at`로 비교하고 있어서, `now`가 `expires_at`과 같은 순간에도 토큰이 유효하다고 판단했습니다.

## 변경 사항

- `auth/token.py`: `is_valid()`의 비교식을 `now <= expires_at`에서 `now < expires_at`로 변경
- 테스트 2개 추가
  - `test_token_expired_at_boundary`: 만료 시각과 같은 시각에 토큰이 무효인지 확인
  - `test_token_valid_before_expiry`: 만료 시각 이전에는 토큰이 유효한지 확인
