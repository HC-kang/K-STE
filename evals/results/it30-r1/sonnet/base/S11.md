# API 키 관리 지침

## 1. 적용 범위

운영 환경 API 키와 개발 환경 API 키에 적용한다. 규칙마다 적용 대상을 따로 적는다.

## 2. 규칙

### 2.1 필수

- **운영 환경 API 키는 90일마다 교체한다.** 예외는 없다.
- **교체한 키는 Vault의 `prod/api-keys` 경로에 저장한다.**

### 2.2 금지

- **API 키를 Git 저장소에 커밋하지 않는다.**

### 2.3 권장

- 키 교체는 평일 업무 시간(10:00-18:00)에 한다.

### 2.4 허용

- 장애 대응 중에는 업무 시간 밖에 키를 교체해도 된다.

### 2.5 면제

- 개발 환경 API 키에는 90일 교체 규칙을 적용하지 않는다.

## 3. 요약

| 항목 | 운영 환경 | 개발 환경 |
|---|---|---|
| 90일 교체 | 필수 (예외 없음) | 면제 |
| Git 커밋 | 금지 | 금지 |
| 교체 시간대 | 평일 10:00-18:00 권장, 장애 대응 중에는 시간 외 허용 | 해당 없음 |
| 저장 위치 | Vault `prod/api-keys` (필수) | 해당 없음 |

## 4. 참고

- Vault 웹 화면에서 키를 직접 발급할 수 있다.

---

작성 시 참고한 점은 다음과 같습니다.

- 규칙의 강도를 필수, 금지, 권장, 허용, 면제로 나누고 용어를 통일했습니다. "장애 대응 중 시간 외 교체"는 권장의 예외이므로 "허용"으로 적었습니다. 90일 규칙의 예외는 아닙니다.
- Git 커밋 금지는 개발 환경 키에도 적용되는 것으로 정리했습니다. 원문에 환경 구분이 없어서 그렇게 해석했으니, 운영 환경에만 적용하려면 알려주세요.
- Vault 웹 화면의 발급 기능은 규칙이 아니라 사실이라서 "참고"에 따로 두었습니다. "이 방법으로 발급해야 한다"는 규칙이 필요하다면 내용을 추가해 주세요.
- 개발 환경 키의 저장 경로는 원문에 없어서 "해당 없음"으로 표시했습니다.
