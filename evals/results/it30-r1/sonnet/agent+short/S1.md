로컬 캐시는 서버마다 따로 갖는 임시 저장소이고, Redis 캐시는 서버 4대가 함께 쓰는 임시 저장소입니다. 캐시(자주 쓰는 데이터를 미리 저장해 두고 빠르게 꺼내 쓰는 방식)는 두 경우 모두 같습니다.

지금은 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 그래서 서버마다 저장된 내용이 다를 수 있습니다. 가격을 바꾸면 고객에게 최대 5분 늦게 반영되고, 같은 시점에 어떤 서버에서는 옛 가격이, 어떤 서버에서는 새 가격이 보일 수 있습니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버 1대로 도입할 예정입니다. 4대가 같은 저장소를 보기 때문에 서버마다 상품 목록이 달라지는 문제가 없어집니다.

가격 변경이 고객에게 바로 반영되는지는 아직 모릅니다. 현재 사실은 Redis를 4대가 공유한다는 것까지입니다.
