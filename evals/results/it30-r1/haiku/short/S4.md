이 문서는 payment-api 운영 배포를 ArgoCD로 롤백하는 절차를 설명한다.

## 1. 롤백 전 확인

- 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
- **마이그레이션이 포함됐으면 롤백하면 안 된다.**
- 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 한다.
- 확인 필요: 배포에 마이그레이션이 포함됐는지 확인하는 방법과 위치

## 2. 롤백 절차

1. 롤백할 REVISION 값을 확인한다. 확인 필요: REVISION 값을 확인하는 방법
2. 다음 명령을 실행한다: `argocd app rollback payment-api <REVISION>`
3. `/healthz` 응답 코드가 200인지 확인한다.
4. 결제 테스트 주문 1건이 성공하는지 확인한다. 확인 필요: 결제 테스트 주문을 실행하는 방법
5. #deploy 채널에 롤백 이력을 남긴다. 확인 필요: 이력에 적을 항목과 형식
