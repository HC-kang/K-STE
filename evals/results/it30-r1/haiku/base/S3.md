## 요약

토큰 만료 시각과 정확히 같은 시각에 요청이 들어오면 토큰을 유효한 것으로 잘못 판단하던 경계 조건 버그를 수정합니다.

## 원인

`auth/token.py`의 `is_valid()`가 `now <= expires_at`로 비교하고 있었습니다. 이 때문에 만료 시각 `expires_at`과 정확히 같은 시각(`now == expires_at`)의 요청도 유효하다고 판단되었습니다.

## 변경 사항

- `auth/token.py`의 `is_valid()`에서 비교 연산자를 `now <= expires_at`에서 `now < expires_at`로 변경했습니다.
- 경계 조건을 검증하는 테스트 2개를 추가했습니다.
  - `test_token_expired_at_boundary`: `now == expires_at`일 때 토큰이 만료된 것으로 판단하는지 확인
  - `test_token_valid_before_expiry`: `now < expires_at`일 때 토큰이 유효한 것으로 판단하는지 확인
