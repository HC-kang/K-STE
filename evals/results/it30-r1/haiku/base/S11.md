# API 키 관리 지침

## 1. 목적

이 문서는 API 키의 발급, 교체, 저장, 보관 기준을 정한다.

## 2. 용어

- **운영 환경**: 실제 서비스가 운영되는 환경이다.
- **개발 환경**: 개발과 테스트에 쓰는 환경으로, 운영 환경이 아닌 모든 환경을 말한다.
- **교체**: 기존 API 키를 폐기하고 새 키로 바꾸는 것이다.
- **장애 대응 중**: 운영 환경에서 서비스 장애가 발생해 이를 복구하는 작업이 진행 중인 상태다.

## 3. 규칙

### 3.1 키 교체 주기 (필수)

1. 운영 환경 API 키는 **90일마다 교체한다.**
2. 이 규칙은 **예외 없이** 지킨다.
3. 개발 환경 API 키는 이 규칙의 적용 대상이 아니다.

### 3.2 교체 시기

1. 운영 환경 키 교체는 **평일 업무 시간(10:00–18:00)에 하는 것을 권장한다.**
2. 장애 대응 중이라면 업무 시간 외에 교체할 수 있다.
3. 이 예외는 교체 **시기**에만 적용된다. 3.1의 90일 교체 주기는 그대로 지켜야 한다.

### 3.3 키 보관 금지

1. API 키를 Git 저장소에 커밋하지 않는다.

### 3.4 키 발급 및 저장

1. Vault 웹 화면에서 API 키를 직접 발급할 수 있다.
2. 교체한 키는 Vault의 `prod/api-keys` 경로에 저장한다.

- **"장애 대응 중"**의 시작과 끝을 누가 판단하는지 정해져 있지 않습니다.
- **90일의 기산점**(발급일인지 교체일인지)이 명시되어 있지 않습니다.
