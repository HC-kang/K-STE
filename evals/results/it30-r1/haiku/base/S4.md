# 운영 배포 롤백 런북: payment-api

**대상**: 운영 환경 `payment-api`
**배포 도구**: ArgoCD
**롤백 명령**: `argocd app rollback payment-api <REVISION>`

> **중요**: 아래 1단계(마이그레이션 확인)를 통과하기 전에는 롤백 명령을 실행하지 마세요.

---

## 1. 사전 확인: DB 마이그레이션 포함 여부

### 1-1. 롤백 대상 리비전 확인

```bash
argocd app history payment-api
```

현재 배포된 리비전과 롤백할 이전 리비전(`<REVISION>`)을 확인합니다.

### 1-2. 마이그레이션 포함 여부 확인

현재 배포(롤백 대상이 되는 배포)에 DB 마이그레이션이 포함되었는지 확인합니다.

- 확인 방법: `<마이그레이션 확인 방법을 여기에 기입>`

### 1-3. 판단

| 결과 | 조치 |
|---|---|
| **마이그레이션 포함** | **롤백 중단.** 2단계로 이동하여 DBA 박지은에게 연락합니다. 롤백 명령을 실행하지 않습니다. |
| **마이그레이션 미포함** | 2단계(롤백 실행)로 진행합니다. |
| **확인 불가** | 마이그레이션 포함으로 간주하고 롤백을 중단합니다. DBA에게 연락합니다. |

---

## 2. 마이그레이션 포함 시: DBA 연락

- **담당자**: 박지은 (DBA)
- **연락 방법**: `<연락처/채널 기입>`
- 전달 내용: 서비스명(`payment-api`), 현재 리비전, 롤백 대상 리비전, 마이그레이션 포함 사실
- DBA 지시가 있을 때까지 롤백하지 않습니다.

---

## 3. 롤백 실행

마이그레이션이 포함되지 않았음을 확인한 후에만 실행합니다.

```bash
argocd app rollback payment-api <REVISION>
```

롤백이 완료될 때까지 상태를 확인합니다.

```bash
argocd app get payment-api
```

---

## 4. 롤백 후 검증

### 4-1. 헬스체크

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://<payment-api 호스트>/healthz
```

- **기대 결과**: `200`
- 200이 아니면 결제 테스트로 넘어가지 않고 5단계(에스컬레이션)로 이동합니다.

### 4-2. 결제 테스트 주문

- 결제 테스트 주문 **1건**을 실행하고 성공 여부를 확인합니다.
- 테스트 절차: `<테스트 주문 절차 기입>`
- **기대 결과**: 주문 성공

실패하면 5단계(에스컬레이션)로 이동합니다.

---

## 5. 에스컬레이션

헬스체크 또는 결제 테스트가 실패하면 즉시 담당자에게 알립니다.

- 담당자/온콜: `<담당자 기입>`
- 보고 내용: 롤백 리비전, 헬스체크 결과, 테스트 주문 결과

---

## 6. 롤백 이력 기록 (#deploy 채널)

롤백 시도 결과와 관계없이 **#deploy 채널에 기록을 남깁니다.** 롤백을 중단한 경우에도 기록합니다.

기록 양식:

```
[payment-api 롤백]
- 시각:
- 실행자:
- 현재 리비전 → 대상 리비전:
- 롤백 사유:
- 마이그레이션 포함 여부: (포함 / 미포함)
- DBA 연락 여부: (해당 시 박지은 연락 시각)
- 롤백 실행 여부: (실행 / 중단)
- 헬스체크 (/healthz): (200 / 그 외 코드)
- 결제 테스트 주문: (성공 / 실패)
- 비고:
```

## 체크리스트

- [ ] 포함 → 롤백 중단, DBA 박지은 연락
- [ ] 미포함 → `argocd app rollback payment-api <REVISION>` 실행
- [ ] `/healthz` 200 확인
- [ ] 결제 테스트 주문 1건 성공 확인
- [ ] #deploy 채널에 롤백 이력 기록

---

**확인이 필요한 항목**: 마이그레이션 확인 방법, 호스트 주소, DBA 연락처, 결제 테스트 절차, 에스컬레이션 담당자. 이 값들은 제가 알 수 없어서 `<>`로 비워 두었습니다. 채워 넣으시면 바로 쓸 수 있는 런북이 됩니다.
