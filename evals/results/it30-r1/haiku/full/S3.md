# 토큰 만료 시각 경계에서 유효로 판단하던 버그 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 버그를 고쳤다. `auth/token.py`의 `is_valid()`에서 비교 조건을 `now <= expires_at`에서 `now < expires_at`로 바꿨다. 로컬에서 단위 테스트를 실행한 결과 모두 통과했다. 통합 테스트는 아직 실행하지 않았다.

## 변경 사항

`auth/token.py`의 `is_valid()`에서 비교 조건을 `now <= expires_at`에서 `now < expires_at`로 바꿨다.

테스트 2개를 추가했다. `test_token_expired_at_boundary`는 만료 시각과 같은 시각의 경계를 검증하고, `test_token_valid_before_expiry`는 만료 전 시각의 유효성을 검증한다.

## 테스트

- 로컬 단위 테스트: 모두 통과
- 통합 테스트: 실행하지 않음
