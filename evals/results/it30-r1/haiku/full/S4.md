# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 지정한 리비전으로 되돌리는 절차를 정한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 된다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
   확인 필요: 마이그레이션 포함 여부. 이를 확인할 위치와 방법.
2. 마이그레이션이 포함됐으면 **롤백하면 안 된다.** 이 경우 롤백을 중단하고 DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았으면 롤백해도 된다.

## 2. 롤백 실행

4. 다음 명령으로 롤백한다. `<REVISION>`에는 롤백 대상 리비전 번호를 넣는다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

## 3. 롤백 후 검증

5. `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문을 1건 실행하고, 주문이 성공하는지 확인한다.

## 4. 이력 기록

7. 롤백 이력을 #deploy 채널에 남긴다.
