# API 키 관리 지침

이 문서는 API 키를 발급, 교체, 저장할 때 따를 기준을 정한다. 운영 환경 API 키는 90일마다 교체해야 하며, 이 규칙은 예외 없이 지켜야 한다. API 키를 Git 저장소에 커밋하면 안 된다.

## 적용 범위

운영 환경 API 키에는 90일 교체 규칙을 적용해야 한다. 개발 환경 API 키는 90일 교체 규칙을 따르지 않아도 된다.

## 키 교체 주기

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.

## 키 교체 시기

키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다. 장애 대응 중이면 업무 시간 밖에 교체해도 된다.

## 키 저장

교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 금지 사항

API 키를 Git 저장소에 커밋하면 안 된다.

## Vault 기능

Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.

---

확인 필요: 90일마다. 발급일부터 90일인지, 직전 교체일부터 90일인지 확인하십시오.
