Redis를 도입하면 서버 4대가 캐시 하나를 같이 쓰므로, 서버마다 캐시 내용이 달라지는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 임시로 저장해 두는 방식입니다. 로컬 캐시는 API 서버(앱과 웹의 요청을 받아 응답하는 서버)가 자기 메모리에 캐시를 따로 가지는 방식입니다. 지금은 서버 4대가 각자 상품 목록을 5분 동안 캐시합니다.

Redis는 여러 서버가 같이 쓰는 캐시 서버입니다. 이번에는 캐시 서버 1대를 API 서버 4대가 같이 쓰는 구조로 도입할 예정입니다.

현재 문제는 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영되는 것입니다. Redis를 도입하면 4대가 같은 캐시를 보게 되므로, 서버마다 내용이 달라서 생기던 차이가 없어집니다.
