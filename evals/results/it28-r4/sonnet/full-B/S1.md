로컬 캐시는 서버마다 따로 갖는 임시 저장 공간이고, Redis 캐시는 서버 4대가 함께 쓰는 임시 저장 공간입니다.

캐시는 자주 쓰는 데이터를 미리 저장해 두고 빠르게 꺼내 쓰는 방식입니다. 지금은 API 서버(고객 요청을 받아 응답하는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 서버마다 캐시 내용이 달라서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버 1대로 도입할 예정입니다. 4대가 같은 캐시를 함께 쓰므로 서버마다 캐시 내용이 달라지는 일이 없어집니다.
