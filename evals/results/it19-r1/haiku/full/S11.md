# API 키 관리 지침

이 지침은 API 키의 교체, 저장, 관리 방법을 정한다. 운영 환경 API 키는 90일마다 교체해야 하며, 이 규칙은 예외 없이 지켜야 한다. API 키는 Git 저장소에 커밋하면 안 된다.

## 운영 환경 API 키 교체

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.

키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다. 장애 대응 중이라면 업무 시간 밖에도 키를 교체해도 된다.

교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 개발 환경 API 키

개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 키 발급

Vault 웹 화면에서 키를 직접 발급할 수 있다.

## 금지 사항

API 키를 Git 저장소에 커밋하면 안 된다.

---

확인 필요: "90일마다". 90일을 발급일부터 셀지, 마지막 교체일부터 셀지 원문에 나와 있지 않습니다. 기준일에 따라 교체 시점이 달라집니다.
