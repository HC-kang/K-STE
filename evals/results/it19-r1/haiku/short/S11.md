이 문서는 사내 API 키의 교체 주기, 교체 시간, 저장과 관리 기준을 정한다.

- 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.
- 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.
- API 키를 Git 저장소에 커밋하면 안 된다.
- 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.
- Vault 웹 화면에는 API 키를 직접 발급하는 기능이 있다.
- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

확인 필요: 90일을 세는 기준일이 지시에 없다. 발급일로 세는지 직전 교체일로 세는지 알려 주어야 문서에 그 기준을 명시할 수 있다.
