Redis 도입으로 달라지는 점은 캐시를 서버마다 따로 갖느냐, 서버 4대가 하나를 같이 쓰느냐입니다. 캐시는 자주 쓰는 데이터를 미리 저장해 두고 빠르게 꺼내 쓰는 방식입니다.

로컬 캐시는 각 API 서버가 자기 메모리에 따로 저장하는 캐시입니다. 지금은 서버 4대가 각자 상품 목록을 5분 동안 캐시합니다. 그래서 서버마다 캐시 내용이 다릅니다. 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis 캐시는 서버 4대가 같이 쓰는 캐시 서버 1대에 저장하는 캐시입니다. 4대가 같은 캐시를 보므로, 어느 서버가 요청을 받아도 같은 상품 목록을 가져옵니다. 그래서 서버마다 캐시 내용이 달라서 생기는 불일치가 없어집니다.

확인 필요: Redis를 도입해도 가격 변경이 고객에게 최대 5분 늦게 반영되는지, 가격을 바꿀 때 캐시를 바로 지우는지 개발팀에 확인해야 합니다.

확인 필요: 캐시 서버 1대가 멈추면 API 서버 4대가 어떻게 동작하는지 개발팀에 확인해야 합니다.
