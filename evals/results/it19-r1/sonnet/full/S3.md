# 토큰 만료 시각과 같은 시각의 요청을 거부하도록 `is_valid()` 수정

`auth/token.py`의 `is_valid()`가 토큰 만료 시각과 정확히 같은 시각에 들어온 요청에서 토큰을 유효하다고 판단하던 버그를 고쳤다. 비교 연산자를 `<=`에서 `<`로 바꿨다. 관련 이슈는 #412다.

## 버그

토큰 만료 시각과 정확히 같은 시각에 요청하면 `is_valid()`가 토큰을 유효하다고 판단했다.

## 변경 내용

`auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다.

## 테스트

테스트 2개를 추가했다.

- `test_token_expired_at_boundary`
- `test_token_valid_before_expiry`

로컬에서 단위 테스트는 모두 통과했다. 통합 테스트는 아직 돌리지 않았다.

## 관련 이슈
