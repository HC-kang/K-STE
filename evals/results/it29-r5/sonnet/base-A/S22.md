# 환불 기준 (상담원용)

## 1. 전액 환불
- 가입일로부터 **7일 이내**에 해지하면 **전액 환불**합니다.

## 2. 정산 시점
- **10월 31일 이후**에 접수된 환불 신청은 **11월 정산**에 포함합니다.

## 3. 승인 기준
- 환불 금액이 **50만 원을 초과**하면 **팀장 승인**을 받아야 합니다.

## 4. 상담 인력 배치
- 상담 대기 고객이 **20명**이 되면 상담원을 **추가 배치**합니다.

---

### 빠른 확인표

| 상황 | 처리 |
|---|---|
| 가입 후 7일 이내 해지 | 전액 환불 |
| 10월 31일 이후 환불 신청 접수 | 11월 정산에 포함 |
| 환불 금액 50만 원 초과 | 팀장 승인 필요 |
| 상담 대기 20명 | 상담원 추가 배치 |

---

참고: 제공해 주신 사실에는 7일의 기산 기준(가입일 당일 포함 여부)이나 "10월 31일 이후"에 31일 당일이 포함되는지, 50만 원 정확히 일치할 때의 처리 등이 없어 문서에 임의로 적지 않았습니다. 필요하시면 기준을 알려주세요. 반영해 드리겠습니다.
