캐시 서버와 API 서버는 메모리를 많이 사용합니다. 배포 후 재시작하면 초기화됩니다.

관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: "관리자 권한이 있는 팀원 및 QA 담당자". 관리자 권한이 팀원과 QA 담당자 모두에게 해당하는지, 팀원에게만 해당하는지 원문으로 정해지지 않습니다.
확인 필요: "배포 후 재시작하면 초기화됩니다". 초기화되는 대상이 서버인지, 메모리인지, 데이터인지 원문에 없습니다.
확인 필요: "공지 채널에 알려야 합니다". 무엇을 알려야 하는지 원문에 없습니다.
