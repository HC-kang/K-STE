# 파일 공유 규정

## 1. 목적

이 문서는 사내 위키에서 파일을 업로드하고 외부와 공유할 때 지켜야 할 기준을 정한다.

## 2. 파일 업로드 기준

- **파일 크기:** 첨부 파일 하나의 크기가 25MB를 넘으면 업로드할 수 없다.
- **게시물당 파일 수:** 한 게시물에는 파일을 최대 10개까지 올릴 수 있다.

## 3. 외부 공유 링크

- **사용 자격:** 만 19세 미만인 인턴은 외부 공유 링크를 만들 수 없다.
- **유효 기간:** 외부 공유 링크는 생성된 시각부터 72시간이 지나면 자동으로 닫힌다.

## 4. 계정 보안

- **로그인 실패 제한:** 비밀번호를 5번 연속으로 잘못 입력하면 계정이 30분 동안 잠긴다.
