이 문서는 사내 API 키의 교체 주기, 교체 시기, 발급과 저장 방법, 금지 사항을 정한다.

## 1. 운영 환경 API 키 교체 주기

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다. 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 2. 키 교체 시기

운영 환경 API 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다. 장애 대응 중이면 업무 시간 밖에도 운영 환경 API 키를 교체해도 된다.

## 3. 키 발급, 저장, 금지 사항

Vault(API 키 같은 비밀 값을 발급하고 보관하는 도구)의 웹 화면에서 API 키를 직접 발급할 수 있다. 교체한 운영 환경 API 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다. API 키를 Git 저장소(코드 변경 이력을 저장하는 공간)에 커밋하면 안 된다.

확인 필요: 원문에 90일을 어느 날부터 세는지가 나와 있지 않아 문서에 적지 않았다. 기산일(발급일 또는 마지막 교체일)을 알려 주면 그 내용을 문서에 추가한다.
