# API 키 관리 지침

이 지침은 API 키를 발급하고 저장하고 교체할 때 지켜야 하는 규칙을 정한다. 운영 환경 API 키는 90일마다 교체해야 하며, 이 규칙은 예외 없이 적용한다. 개발 환경 API 키는 90일 교체 규칙을 따르지 않아도 된다.

## 1. 교체 주기

- 운영 환경 API 키는 90일마다 교체해야 한다.
- 개발 환경 API 키는 90일 교체 규칙을 따르지 않아도 된다.

## 2. 교체 시점

- 운영 환경 API 키는 평일 업무 시간(10:00-18:00)에 교체하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에 교체해도 된다.

## 3. 발급과 저장

- Vault 웹 화면에서 API 키를 직접 발급할 수 있다.
- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 4. 금지 사항

- API 키를 Git 저장소에 커밋하면 안 된다.
