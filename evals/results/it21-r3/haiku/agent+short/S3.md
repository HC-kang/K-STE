# 토큰 만료 시각 경계 판정 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 버그를 고친다. `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다. 로컬 단위 테스트는 모두 통과했다. 통합 테스트는 아직 실행하지 않았다.

## 원인

`is_valid()`의 비교 연산자가 `<=`였다. `now`가 `expires_at`과 같은 시각에도 이 조건이 참이므로, 만료 시각 정각의 토큰이 유효하다고 판단됐다.

## 변경 내용

`auth/token.py`의 `is_valid()`에서 비교 조건을 `now < expires_at`로 바꿨다. 이제 `now`가 `expires_at`과 같으면 조건이 거짓이 되어 토큰을 유효하지 않다고 판단한다.

## 테스트

- 추가한 테스트: `test_token_expired_at_boundary`, `test_token_valid_before_expiry`
- 로컬 단위 테스트: 모두 통과했다.
- 통합 테스트: 실행하지 않았다.
