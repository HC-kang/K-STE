# 운영 배포 롤백 런북

이 문서는 ArgoCD로 운영 환경의 payment-api 배포를 롤백하는 절차를 정의한다. 단계를 순서대로 따른다.

## 1. 롤백 전 확인

롤백 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 확인 필요: 마이그레이션 포함 여부를 확인하는 방법과 위치.

마이그레이션이 포함됐으면 롤백하면 안 된다. **이 경우 롤백을 중단하고 DBA 박지은에게 연락해야 한다.**

## 2. 롤백 실행

1. 롤백할 이전 리비전 번호를 확인한다. 확인 필요: 리비전 번호를 찾는 방법.
2. 아래 명령으로 payment-api를 롤백한다. `<REVISION>`에는 1번에서 확인한 리비전 번호를 넣는다.

```
argocd app rollback payment-api <REVISION>
```

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다. 확인 필요: `/healthz`를 호출하는 주소와 방법.
2. 결제 테스트 주문 1건이 성공하는지 확인한다. 확인 필요: 결제 테스트 주문을 실행하는 방법.
