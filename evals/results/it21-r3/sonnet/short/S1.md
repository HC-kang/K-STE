로컬 캐시는 서버마다 따로 갖는 메모장이고, Redis 캐시는 서버 4대가 함께 보는 공용 메모장입니다. 캐시는 자주 쓰는 데이터를 미리 저장해 두고 빠르게 꺼내 쓰는 방식입니다.

현재는 로컬 캐시를 씁니다. API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 저장한 시점이 달라서 캐시 내용이 서로 다릅니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다. 고객이 어느 서버에 연결되느냐에 따라 서로 다른 가격을 볼 수도 있습니다.

Redis를 도입하면 캐시 서버 1대를 API 서버 4대가 같이 씁니다. 상품 목록이 한 곳에만 저장되므로 서버 간 캐시 내용 차이가 없어집니다.

다만 Redis를 도입하는 것만으로 최대 5분 지연이 없어지는지는 알 수 없습니다. 확인 필요: 이번 도입 범위에 가격을 바꿀 때 Redis에 저장된 상품 목록을 바로 갱신하거나 지우는 작업이 들어 있는지 확인해야 합니다.
