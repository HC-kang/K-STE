로컬 캐시는 서버 4대가 각자 따로 저장하는 방식이고, Redis 캐시는 4대가 한 곳에 저장한 내용을 같이 읽는 방식입니다. 이번 도입으로 서버마다 상품 목록이 다르게 보이는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 매번 새로 조회하지 않도록 임시로 저장해 두는 공간입니다. 지금은 API 서버(고객 요청을 처리하는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 캐시 전용 서버 1대에 상품 목록을 한 벌만 저장합니다. API 서버 4대가 모두 이 한 벌을 읽으므로 서버마다 내용이 달라지지 않습니다.

확인 필요: 가격 변경의 최대 5분 지연이 사라지는지는 가격을 바꿀 때 Redis에 저장된 상품 목록을 바로 갱신하거나 지우는지에 달려 있습니다. 이번 도입 범위에 그 동작이 포함되는지는 아직 확인하지 못했습니다.

Redis 서버가 1대이므로, 이 서버에 문제가 생기면 API 서버 4대가 모두 영향을 받을 수 있습니다. 이는 구성에서 추론한 내용이며 실제 영향은 확인하지 않았습니다.
