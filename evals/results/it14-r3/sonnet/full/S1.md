Redis를 도입하면 서버 4대가 같은 캐시를 쓰게 되어, 서버마다 캐시 내용이 달라지는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 미리 저장해 두는 곳입니다. 지금 우리 API 서버(고객 요청을 받아 응답하는 서버) 4대는 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 이것이 로컬 캐시입니다. 서버마다 저장한 내용이 따로 있어서, 서버마다 캐시 내용이 다릅니다. 그래서 가격을 바꾸면 고객에게 새 가격이 보이기까지 최대 5분 걸립니다.

Redis는 여러 서버가 함께 쓰는 캐시 서버입니다. 이번에 도입할 Redis는 1대이고, API 서버 4대가 이 1대를 같이 씁니다. 상품 목록이 한 곳에만 저장되므로 4대가 같은 내용을 응답합니다.
