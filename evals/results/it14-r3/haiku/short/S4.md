# 운영 배포 롤백 런북

## 사전 확인

1. 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
2. **마이그레이션이 포함됐으면 롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 다음 절차를 따른다.

## 롤백 실행

1. 다음 명령으로 payment-api를 롤백한다. `<REVISION>`에는 되돌릴 리비전 값을 넣는다.

```
argocd app rollback payment-api <REVISION>
```

## 롤백 후 확인 및 기록

1. 롤백 후 `/healthz`가 200을 반환하는지 확인해야 한다.
2. 결제 테스트 주문 1건이 성공하는지 확인해야 한다.
3. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요

1. 확인 필요: 마이그레이션 포함 여부는 어떤 도구나 위치에서 확인하는가?
2. 확인 필요: `<REVISION>`에 넣을 값은 어디에서 얻는가?
3. 확인 필요: `/healthz`를 호출할 주소는 무엇인가?
4. 확인 필요: 결제 테스트 주문은 어떤 방법으로 하는가?
5. 확인 필요: #deploy 채널에 남길 이력의 형식이 정해져 있는가?
