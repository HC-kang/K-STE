이 문서는 API 키(API를 호출할 때 신원을 확인하는 데 쓰는 비밀 값)의 교체 주기, 교체 시점, 저장 위치, 금지 사항을 정한다.

**운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.**

개발 환경 API 키는 90일 교체 규칙을 지킬 필요가 없다.

키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다. 장애 대응 중이면 업무 시간 밖에 교체해도 된다.

교체한 키는 Vault(비밀 값을 보관하고 관리하는 도구)의 `prod/api-keys` 경로에 저장해야 한다. Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.

**API 키를 Git 저장소(코드 변경 이력을 기록하는 저장소)에 커밋하면 안 된다.**
