# 운영 배포 롤백 런북 (payment-api)

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션(데이터베이스 구조나 데이터를 바꾸는 변경 스크립트)이 포함됐는지 반드시 확인해야 한다.
2. **마이그레이션이 포함됐으면 롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않은 경우에만 아래 롤백 명령을 실행한다.

확인 필요: 배포에 마이그레이션이 포함됐는지 확인하는 방법과 위치.

## 롤백 실행

4. 다음 명령으로 롤백한다: `argocd app rollback payment-api <REVISION>`

확인 필요: `<REVISION>`에 넣을 값을 찾는 방법.

## 롤백 후 검증

5. `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문 1건이 성공하는지 확인한다.

확인 필요: `/healthz`를 호출할 주소와 결제 테스트 주문을 넣을 방법.

## 이력 기록

7. 롤백 이력을 #deploy 채널에 남긴다.
