로컬 캐시는 서버마다 따로 갖는 저장 공간이고, Redis 캐시는 서버 4대가 같이 쓰는 저장 공간입니다. 캐시는 자주 쓰는 데이터를 잠시 저장해 두고 빠르게 꺼내 쓰는 방식입니다.

현재는 API 서버(고객 요청을 받아 응답하는 서버) 4대가 각자 자기 메모리(서버 안의 임시 저장 공간)에 상품 목록을 5분 동안 캐시합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 바뀐 가격이 고객에게 최대 5분 늦게 보입니다.

Redis는 캐시 전용 서버 1대에 상품 목록을 저장합니다. API 서버 4대가 이 서버를 같이 읽으므로 서버마다 캐시 내용이 달라지는 문제가 없어집니다. 지금은 고객이 연결된 서버에 따라 같은 시점에 다른 가격을 볼 수 있지만, 도입 후에는 4대가 같은 내용을 봅니다.
