Redis를 도입하면 서버 4대가 같은 캐시(자주 보는 데이터를 미리 담아 두는 곳)를 읽습니다. 그래서 어느 서버에 접속하든 고객은 같은 상품 목록을 봅니다.

지금은 로컬 캐시를 씁니다. 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 보관합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 고객 화면에 바뀐 가격이 최대 5분 늦게 보입니다.

Redis는 서버 4대가 함께 쓰는 캐시 서버 1대입니다. 캐시가 한 곳에만 있으므로 서버마다 내용이 달라지는 일이 없습니다.

확인 필요: Redis에서 보관 시간을 5분으로 유지하는지. 5분으로 유지하면 가격을 바꾼 뒤 고객 화면에 보이기까지 최대 5분의 지연이 남을 수 있습니다.

확인 필요: Redis 서버 1대가 멈추면 서비스가 어떻게 동작하는지.
