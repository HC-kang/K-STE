# API 키 관리 지침

이 문서는 API 키의 교체 주기, 교체 시기, 발급과 저장 위치, 금지 사항을 정한다. 운영 환경 API 키는 90일마다 교체해야 하며, 이 규칙에는 예외가 없다.

## 교체 주기

- 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙에는 예외가 없다. 아래 교체 시기의 예외는 교체하는 시점에만 적용된다.
- 개발 환경 API 키는 90일 교체 규칙을 따르지 않아도 된다.

## 교체 시기

- 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.

## 발급

- Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.

## 저장 위치

- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 금지 사항

- API 키를 Git 저장소에 커밋하면 안 된다.

---

확인 필요: 90일마다. 마지막 교체일부터 90일을 세는 경우와 키를 발급한 날부터 90일을 세는 경우가 있다.
