# auth: 토큰 만료 시각에 토큰을 유효로 판단하는 버그 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하는 버그를 수정한다. 이 PR은 `auth/token.py`의 `is_valid()`에서 만료 경계 비교 연산자를 `<=`에서 `<`로 바꾼다.

## 변경 내용

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꾼다. 현재 시각이 만료 시각과 같으면 토큰은 유효하지 않다고 판단한다.
- 테스트 2개를 추가한다. `test_token_expired_at_boundary`는 만료 시각과 같은 시각의 경계 동작을, `test_token_valid_before_expiry`는 만료 전 유효 동작을 확인한다.

## 테스트

- 로컬에서 단위 테스트를 실행했고 모두 통과했다.
- 통합 테스트는 아직 실행하지 않았다.
