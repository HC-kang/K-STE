캐시 서버와 API 서버는 메모리를 많이 사용합니다. 캐시 서버와 API 서버는 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: '초기화됩니다'. 무엇이 초기화되는지(예: 캐시 데이터, 메모리 상태, 서버 설정) 원문에 없습니다.
확인 필요: '관리자 권한이 있는 팀원 및 QA 담당자'. 관리자 권한 조건이 팀원에게만 걸리는지, QA 담당자에게도 걸리는지 정해지지 않았습니다.
확인 필요: '공지 채널에 알려야 합니다'. 무엇을 알리는지 원문에 없습니다.
