이 런북은 ArgoCD로 배포한 payment-api를 `<REVISION>` 리비전으로 롤백하는 절차를 설명한다.

1. 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
   - 마이그레이션이 포함됐으면 **롤백하면 안 된다.**
   - 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 한다.
2. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다.
   ```
   argocd app rollback payment-api <REVISION>
   ```
   `<REVISION>` 자리에 롤백할 리비전 값을 넣는다.
3. `/healthz`가 200을 반환하는지 확인한다.
4. 결제 테스트 주문 1건이 성공하는지 확인한다.
5. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 마이그레이션 포함 여부를 확인하는 방법
확인 필요: `<REVISION>` 값을 찾는 방법
확인 필요: `/healthz`를 호출할 주소
확인 필요: 결제 테스트 주문을 넣는 방법
확인 필요: #deploy 채널에 남길 이력의 형식
