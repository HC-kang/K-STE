# payment-api 운영 배포 롤백 런북

배포 도구는 ArgoCD다. 롤백 전에 마이그레이션 여부를 먼저 확인해야 하며, 마이그레이션이 포함된 배포는 롤백하면 안 된다.

## 절차

1. 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 확인 방법은 아래 "확인 필요" 항목을 참고한다.
2. 마이그레이션이 포함됐으면 **롤백하면 안 된다.** DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다.

   `argocd app rollback payment-api <REVISION>`

4. 롤백 후 `/healthz`가 200을 반환하는지 확인해야 한다.
5. 롤백 후 결제 테스트 주문 1건이 성공하는지 확인해야 한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요

확인 필요: `<REVISION>`에 넣을 값을 어디에서 확인하는지 원문에 없다.

확인 필요: 마이그레이션 포함 여부를 어떻게 확인하는지 원문에 없다.

확인 필요: DBA 박지은에게 어떤 방법으로 연락하는지 원문에 없다.

확인 필요: `/healthz`를 호출할 주소와 결제 테스트 주문을 실행하는 방법이 원문에 없다.

확인 필요: #deploy 채널에 롤백 이력을 남기는 시점과 형식이 원문에 없다.
