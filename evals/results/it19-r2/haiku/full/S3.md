# 토큰 만료 시각 경계 판정 수정

`is_valid()`가 토큰 만료 시각과 정확히 같은 시각의 요청을 유효하다고 판단하던 버그를 고쳤다. 판정 조건을 `now <= expires_at`에서 `now < expires_at`로 바꿨다. 로컬 단위 테스트는 모두 통과했고, 통합 테스트는 아직 실행하지 않았다.

## 배경

토큰 만료 시각과 요청 시각이 정확히 같으면 `is_valid()`가 토큰을 유효하다고 판단했다. 만료 시각 자체는 이미 만료된 시점으로 봐야 하므로 이 판정은 잘못되었다.

## 변경 사항

- `auth/token.py`의 `is_valid()`에서 비교 연산자를 `<=`에서 `<`로 바꿨다.
- 경계 시각에서 토큰이 무효로 판정되는지 확인하는 테스트 `test_token_expired_at_boundary`를 추가했다.
- 만료 시각 이전에는 토큰이 유효로 판정되는지 확인하는 테스트 `test_token_valid_before_expiry`를 추가했다.

## 테스트

- 로컬 단위 테스트: 모두 통과.
- 통합 테스트: 실행하지 않았다.
