# 운영 배포 롤백 런북: payment-api

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 이전 리비전으로 되돌리는 절차를 정한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 된다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 되고, DBA 박지은에게 연락해야 한다.

확인 필요: 마이그레이션 포함 여부. 이를 확인하는 방법과 근거가 되는 정보가 주어진 사실에 없다.
확인 필요: DBA 박지은의 연락 수단. 연락처나 연락 경로가 주어진 사실에 없다.

## 2. 롤백 실행

3. `argocd app rollback payment-api <REVISION>` 명령을 실행한다. `<REVISION>`에는 롤백 대상 리비전 번호를 넣는다.

확인 필요: `<REVISION>`. 롤백 대상 리비전을 고르는 기준과 리비전 번호를 확인하는 방법이 주어진 사실에 없다.

## 3. 롤백 후 확인

4. 롤백 후 `/healthz`가 200을 반환하는지 확인한다.
5. 롤백 후 결제 테스트 주문 1건이 성공하는지 확인한다.

확인 필요: 결제 테스트 주문 1건을 만드는 방법. 주어진 사실에 그 방법이 없다.

## 4. 이력 기록

6. 롤백 이력을 #deploy 채널에 남긴다.
