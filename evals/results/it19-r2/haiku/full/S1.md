로컬 캐시와 Redis 캐시의 가장 큰 차이는 캐시를 어디에 두느냐입니다. 캐시는 자주 쓰는 데이터를 빨리 꺼내 쓰려고 임시로 저장해 두는 곳입니다. 로컬 캐시는 각 API 서버 안의 메모리에 저장합니다. Redis(여러 서버가 함께 쓰는 캐시 저장 프로그램)는 서버 4대가 같이 쓰는 캐시 서버 한 대에 저장합니다.

지금은 서버 4대가 각자 상품 목록을 5분씩 따로 보관합니다. 그래서 서버마다 캐시 내용이 다릅니다. 가격을 바꾸면 고객 화면의 가격이 최대 5분 늦게 바뀝니다.

Redis로 바꾸면 4대가 같은 캐시를 보게 됩니다. 서버마다 내용이 달라지는 문제는 없어집니다.

다만 Redis 도입만으로 가격이 늦게 바뀌는 시간이 줄어든다고 할 수는 없습니다. 이 시간은 캐시를 몇 분 동안 보관하는지, 가격을 바꿀 때 캐시를 지우는지에 따라 정해집니다. 이 두 설정이 도입 계획에 들어 있는지 확인하십시오.
