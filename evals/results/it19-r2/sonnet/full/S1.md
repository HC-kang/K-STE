Redis를 도입하면 API 서버 4대가 같은 상품 목록 캐시를 보게 되므로, 가격을 바꿨을 때 서버마다 새 가격이 보이는 시점이 달라지던 문제를 해결할 수 있습니다.

캐시(자주 쓰는 데이터를 미리 저장해 두는 곳)는 지금 서버마다 자기 메모리에 따로 있습니다. 이것이 로컬 캐시입니다. API 서버(요청을 받아 응답하는 서버) 4대가 상품 목록을 각자 5분 동안 저장합니다. 그래서 서버마다 저장된 내용이 다르고, 가격을 바꾸면 고객에게 새 가격이 최대 5분 늦게 보입니다.

Redis는 여러 서버가 함께 쓰는 캐시 서버입니다. 이번에는 1대를 도입하고 API 서버 4대가 같이 씁니다. 상품 목록이 한 곳에만 저장되므로 서버마다 내용이 달라지지 않습니다.
