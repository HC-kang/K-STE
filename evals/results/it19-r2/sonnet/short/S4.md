# payment-api 운영 배포 롤백 런북

ArgoCD로 payment-api 운영 배포를 지정한 리비전(REVISION)으로 되돌리는 절차다.

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
2. 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA 박지은에게 연락해야 한다.
3. 배포에 DB 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인해야 한다.
5. 롤백한 뒤 결제 테스트 주문 1건이 성공하는지 확인해야 한다.
6. 롤백 이력을 #deploy 채널에 남겨야 한다.

확인 필요: 배포에 DB 마이그레이션이 포함됐는지 어디에서 확인하는가.
확인 필요: `<REVISION>` 값을 어디에서 찾는가.
확인 필요: `/healthz`가 200을 반환하지 않거나 테스트 주문이 실패하면 무엇을 해야 하는가.
확인 필요: #deploy 채널에 남길 이력에 어떤 내용을 포함해야 하는가.
