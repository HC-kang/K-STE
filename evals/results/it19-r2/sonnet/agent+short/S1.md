로컬 캐시는 서버마다 따로 가진 메모장이고, Redis 캐시는 서버 4대가 함께 보는 메모장 1개입니다.

현재는 API 서버 4대가 각자 메모리에 상품 목록을 5분 동안 저장합니다. 그래서 서버마다 저장된 시점이 다르고, 서버마다 보여 주는 내용이 다를 수 있습니다. 가격을 바꾸면 고객에게 최대 5분 늦게 반영되는 이유가 이것입니다.

Redis를 도입하면 상품 목록을 캐시 서버 1대에 저장하고, 서버 4대가 모두 그 내용을 읽습니다. 그래서 서버 4대가 고객에게 같은 상품 목록을 보여 줍니다.

다만 Redis를 도입하는 것만으로 5분 지연이 없어지는지는 정해지지 않았습니다. 가격을 바꿀 때 Redis에 저장된 내용을 바로 지우거나 갱신하는 방식을 함께 만들어야 지연이 줄어듭니다.
