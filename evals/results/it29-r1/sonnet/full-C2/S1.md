로컬 캐시는 API 서버 4대가 각자 따로 갖고 있는 임시 저장소이고, Redis 캐시는 4대가 함께 쓰는 하나의 임시 저장소입니다. 캐시는 자주 쓰는 데이터를 미리 저장해 두는 곳이고, Redis는 이번에 캐시용으로 도입하는 별도 서버입니다.

지금은 서버마다 상품 목록을 자기 메모리에 5분 동안 캐시합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 서버 4대가 캐시 서버 1대를 같이 쓰므로, 4대가 같은 상품 목록을 보게 됩니다. 그래서 서버마다 캐시 내용이 달라서 생기는 차이가 없어집니다. 가격 반영이 얼마나 빨라질지는 Redis에서 캐시를 얼마 동안 유지하는지에 달려 있습니다.
