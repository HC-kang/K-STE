Redis를 도입하면 API 서버 4대가 캐시 하나를 같이 쓰므로, 고객이 접속한 서버에 따라 다른 상품 정보를 보는 일이 없어집니다.

캐시는 자주 쓰는 데이터를 빠르게 꺼내 쓰려고 잠시 보관해 두는 곳입니다. 로컬 캐시와 Redis 캐시는 이 보관 장소가 다릅니다.

로컬 캐시는 서버 4대가 각자 자기 메모리에 따로 가지고 있습니다. 지금은 서버마다 상품 목록을 5분 동안 캐시합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis(여러 서버가 함께 쓰는 캐시 전용 서버)는 별도 서버 1대에 캐시를 두고 API 서버 4대가 같이 읽습니다. 그래서 4대가 같은 캐시 내용을 보게 됩니다.
