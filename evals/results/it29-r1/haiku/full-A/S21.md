# 파일 공유 규정

이 문서는 사내 위키에서 파일을 올리고 외부와 공유할 때 따를 규정을 정한다. 업로드 크기, 게시물당 파일 수, 외부 공유 링크, 계정 잠금을 다룬다.

## 1. 파일 크기

시스템은 첨부 파일 하나가 25MB를 넘으면 업로드를 막는다. 25MB를 넘는 파일은 업로드하면 안 된다.

## 2. 게시물당 파일 수

한 게시물에는 파일을 10개까지 올릴 수 있다.

## 3. 외부 공유 링크

만 19세가 안 된 인턴은 외부 공유 링크를 만들면 안 된다.

외부 공유 링크는 만든 시각부터 72시간이 지나면 닫힌다.

## 4. 계정 잠금

시스템은 비밀번호를 연속으로 5번 틀리면 계정을 30분 동안 잠근다.
