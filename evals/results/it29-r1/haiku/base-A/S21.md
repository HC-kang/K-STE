# 파일 공유 규정

## 1. 목적

이 문서는 사내 위키에서 파일을 업로드하고 외부와 공유할 때 지켜야 할 기준을 정한다. 보안을 지키고 계정과 자료를 안전하게 관리하기 위해 적용한다.

## 2. 적용 대상

사내 위키에 파일을 업로드하거나 외부 공유 링크를 만드는 모든 사용자에게 적용한다.

## 3. 파일 업로드 기준

1. **파일 크기**: 첨부 파일 하나의 크기가 25MB를 넘으면 업로드할 수 없다.
2. **파일 개수**: 한 게시물에는 파일을 최대 10개까지 올릴 수 있다.

## 4. 외부 공유 링크 기준

1. **인턴 제한**: 만 19세 미만인 인턴은 외부 공유 링크를 만들 수 없다.
2. **링크 유효 기간**: 외부 공유 링크는 생성된 시각부터 72시간이 지나면 자동으로 닫힌다. 기간이 지난 링크는 다시 열리지 않으므로, 필요하면 새 링크를 만들어야 한다.

## 5. 계정 보안 기준

1. **로그인 실패 제한**: 비밀번호를 연속으로 5번 틀리면 계정이 30분 동안 잠긴다.
2. 잠금이 풀리기 전에는 올바른 비밀번호를 입력해도 로그인할 수 없다.

## 6. 용어 정의

- **외부 공유 링크**: 사내 계정이 없는 사람도 파일에 접근할 수 있도록 만든 링크를 말한다.
- **게시물**: 사내 위키에 작성해 파일을 첨부하는 단위를 말한다.
