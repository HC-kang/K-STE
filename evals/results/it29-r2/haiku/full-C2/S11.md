# API 키 관리 지침

이 지침은 API 키의 교체 주기, 교체 시점, 저장 위치, 저장소 관리 규칙을 정한다. 운영 환경 API 키는 90일마다 교체해야 하며, 이 규칙은 예외 없이 지켜야 한다.

## 1. 운영 환경 키 교체

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙에는 예외가 없다.

교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다. 장애 대응 중이면 업무 시간 밖에 교체해도 된다.

## 2. 교체한 키 저장

교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

확인 필요: "교체한 키"의 적용 범위. 운영 환경 키에만 해당하는지, 개발 환경 키도 해당하는지 원문에 명시되어 있지 않다.

## 3. 저장소 관리

API 키를 Git 저장소에 커밋하면 안 된다.

## 4. 개발 환경 키

개발 환경 API 키에는 90일 교체 규칙을 적용하지 않아도 된다.

## 5. 키 발급

Vault 웹 화면에서 API 키를 직접 발급할 수 있다.
