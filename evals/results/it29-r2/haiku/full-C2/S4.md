# payment-api 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 payment-api의 운영 배포를 롤백하는 절차를 정한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다. 롤백 후에는 `/healthz` 응답과 결제 테스트 주문으로 정상 동작을 확인해야 한다. 롤백 이력은 #deploy 채널에 남겨야 한다.

## 사용 도구와 명령

배포 도구는 ArgoCD다. 롤백 명령은 다음과 같다.

```
argocd app rollback payment-api <REVISION>
```

`<REVISION>` 자리에는 롤백할 리비전 번호를 넣는다.

## 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
2. 마이그레이션이 포함된 경우, 롤백하지 말고 DBA 박지은에게 연락해야 한다.

**경고: 마이그레이션이 포함된 배포를 롤백하면 안 된다.**

3. 마이그레이션이 포함되지 않은 경우, 다음 단계로 진행한다.

## 롤백 절차

4. 위 명령으로 payment-api를 `<REVISION>`에 롤백한다.

## 롤백 후 확인

5. `/healthz`가 200을 반환하는지 확인해야 한다.
6. 결제 테스트 주문 1건이 성공하는지 확인해야 한다.

## 이력 기록

7. #deploy 채널에 롤백 이력을 남겨야 한다.
