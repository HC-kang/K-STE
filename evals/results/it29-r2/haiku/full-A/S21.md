# 파일 공유 규정

이 문서는 사내 위키에서 파일을 올리고 외부와 공유할 때 적용하는 기준을 정한다. 파일 크기, 게시물당 파일 수, 인턴의 외부 공유 링크 생성, 비밀번호 오류에 따른 계정 잠금, 외부 공유 링크의 유효 기간을 다룬다.

## 파일 크기

첨부 파일 하나가 25MB를 넘으면 시스템이 업로드를 막는다.

## 게시물당 파일 수

한 게시물에는 파일을 10개까지 올릴 수 있다.

## 인턴의 외부 공유 링크

만 19세 미만 인턴은 외부 공유 링크를 만들 수 없다.

## 비밀번호 오류와 계정 잠금

비밀번호를 5번 연속 틀리면 시스템이 계정을 30분 동안 잠근다.

## 외부 공유 링크의 유효 기간

외부 공유 링크는 만든 시각부터 72시간이 지나면 닫힌다.
