# 환불 기준 안내 (고객센터 상담원용)

## 1. 전액 환불 조건
- **기준:** 가입 후 7일 이내에 해지한 경우
- **처리:** 전액 환불

## 2. 환불 신청 정산 시점
- **기준:** 10월 31일 이후에 접수된 환불 신청
- **처리:** 11월 정산에 포함

## 3. 팀장 승인 필요 기준
- **기준:** 환불 금액이 50만 원을 초과하는 경우
- **처리:** 팀장 승인 후 환불 진행

## 4. 상담 인력 배치 기준
- **기준:** 상담 대기 고객이 20명에 도달한 경우
- **처리:** 상담원 추가 배치

## 확인이 필요한 사항
아래 내용은 제공된 기준에 명시되지 않았습니다. 상담 전에 담당 부서에 확인하세요.
- 가입 후 7일이 정확히 어떻게 계산되는지(가입 당일 포함 여부 등)
- 환불 금액이 정확히 50만 원인 경우 승인이 필요한지 여부
- 10월 31일 기준의 연도 및 시각(예: 23:59 마감 여부)
- 7일 경과 후 해지 시 환불 방식
