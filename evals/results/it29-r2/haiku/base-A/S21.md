# 파일 공유 규정

## 1. 목적

이 문서는 사내 위키에서 파일을 업로드하고 외부와 공유할 때 지켜야 할 기준을 정합니다.

## 2. 적용 대상

사내 위키에 파일을 업로드하거나 외부 공유 링크를 만드는 모든 구성원에게 적용합니다.

## 3. 파일 업로드 기준

| 항목 | 기준 |
|---|---|
| 첨부 파일 1개의 최대 용량 | 25MB 이하 |
| 게시물 1개당 첨부 파일 수 | 최대 10개 |

- 첨부 파일 하나의 크기가 25MB를 넘으면 업로드가 차단됩니다.
- 한 게시물에는 파일을 10개까지만 올릴 수 있습니다.

## 4. 외부 공유 링크 기준

1. **연령 제한**: 만 19세가 되지 않은 인턴은 외부 공유 링크를 만들 수 없습니다.
2. **링크 유효 기간**: 외부 공유 링크는 생성 시각부터 72시간이 지나면 자동으로 닫힙니다.

## 5. 계정 보안 기준

- 비밀번호를 5번 연속으로 잘못 입력하면 계정이 30분 동안 잠깁니다.
- 잠금 시간이 지난 뒤 다시 로그인할 수 있습니다.

## 6. 문서 정보

- 문서 종류: 사내 규정
- 적용 시작일: 확정 후 기재
- 최종 수정일: 확정 후 기재
- 문의처: 확정 후 기재
