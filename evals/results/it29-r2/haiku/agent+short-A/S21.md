# 파일 공유 규정

## 규정

1. 첨부 파일 하나의 크기가 25MB를 넘으면 업로드를 막는다.
2. 한 게시물에는 파일을 10개까지 올릴 수 있다.
3. 만 19세가 되지 않은 인턴은 외부 공유 링크를 만들 수 없다.
4. 비밀번호를 5번 연속 틀리면 계정을 30분 동안 잠근다.
5. 외부 공유 링크는 만든 시각부터 72시간이 지나면 닫힌다.

확인 필요: 25MB가 10의 6제곱 바이트인지 2의 20제곱 바이트인지 확인해야 합니다. 두 기준의 차이가 문서 독자의 판단에 영향을 줄 수 있습니다.
확인 필요: 10개 제한이 게시물 하나에만 적용되는지, 게시물 전체의 합계에 적용되는지 확인해야 합니다.
확인 필요: 계정 잠금이 30분 뒤 자동으로 풀리는지, 다른 방법으로 풀어야 하는지 확인해야 합니다.
