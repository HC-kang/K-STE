# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api의 운영 배포를 이전 리비전으로 되돌리는 절차를 설명한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 확인해야 하며, 포함됐으면 롤백하면 안 된다. 롤백 후에는 `/healthz` 응답과 결제 테스트 주문으로 정상 동작을 확인하고, 이력을 #deploy 채널에 남긴다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다. DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 2단계로 진행한다.

## 2. 롤백 실행

4. 다음 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

   `<REVISION>`에는 되돌릴 리비전 값을 넣는다.

   확인 필요: `<REVISION>`. 되돌릴 리비전을 고르는 기준이 주어지지 않았다.

## 3. 롤백 후 확인

5. `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문을 1건 실행하고, 그 주문이 성공하는지 확인한다.

   확인 필요: 결제 테스트 주문. 테스트 주문을 실행하는 방법과 사용할 테스트 계정 또는 결제 수단이 주어지지 않았다.

## 4. 이력 기록

7. #deploy 채널에 롤백 이력을 남긴다.

   확인 필요: 롤백 이력. 채널에 남길 내용과 형식이 주어지지 않았다.
