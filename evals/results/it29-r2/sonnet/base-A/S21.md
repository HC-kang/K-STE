# 파일 공유 규정

## 1. 목적
이 문서는 사내에서 파일을 업로드하고 공유할 때 지켜야 할 기준을 정리한 것입니다.

## 2. 첨부 파일 제한

| 항목 | 기준 |
|---|---|
| 파일 1개당 최대 크기 | 25MB |
| 게시물당 최대 파일 수 | 10개 |

- 첨부 파일 하나가 25MB를 넘으면 업로드가 차단됩니다.
- 한 게시물에는 파일을 최대 10개까지 올릴 수 있습니다.

## 3. 외부 공유 링크

### 3.1 만료
- 외부 공유 링크는 생성 시각부터 72시간이 지나면 자동으로 닫힙니다.

### 3.2 인턴의 생성 제한
- 만 19세가 안 된 인턴은 외부 공유 링크를 만들 수 없습니다.

## 4. 계정 보안
- 비밀번호를 5번 연속 틀리면 해당 계정은 30분 동안 잠깁니다.

## 5. 요약

| 구분 | 내용 |
|---|---|
| 파일당 크기 | 25MB 초과 시 업로드 차단 |
| 게시물당 파일 수 | 최대 10개 |
| 외부 공유 링크 유효 기간 | 생성 후 72시간 |
| 외부 공유 링크 생성 제한 | 만 19세 미만 인턴 불가 |
| 비밀번호 오류 | 5회 연속 시 30분간 계정 잠금 |
