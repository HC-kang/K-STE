로컬 캐시와 Redis 캐시의 차이는 캐시를 어디에 두느냐이고, Redis를 도입하면 서버 4대가 같은 캐시를 읽게 되어 서버마다 캐시 내용이 달라지는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 미리 저장해 두고 빠르게 꺼내 쓰는 방식입니다. 현재 우리 서비스는 API 서버(앱의 요청을 받아 데이터를 돌려주는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 이것이 로컬 캐시입니다.

서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버 1대입니다. 도입하면 4대가 한 곳의 캐시를 읽으므로 서버마다 캐시 내용이 달라지는 일이 없어집니다.
