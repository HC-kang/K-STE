로컬 캐시는 서버 4대가 각자 자기 메모리에 따로 저장하는 방식이고, Redis 캐시는 4대가 같이 쓰는 한 곳에 저장하는 방식입니다. 캐시는 자주 쓰는 데이터를 임시로 저장해 두는 것입니다.

지금은 API 서버(앱의 요청을 받아 응답하는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버 1대로 도입할 예정입니다. 4대가 같은 캐시를 보기 때문에, 서버마다 캐시 내용이 달라지는 상황이 없어집니다.
