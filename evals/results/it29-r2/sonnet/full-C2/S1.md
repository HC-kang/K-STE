로컬 캐시와 Redis 캐시는 캐시(자주 쓰는 데이터를 잠시 저장해 두는 곳)를 두는 위치가 다릅니다.

지금 쓰는 로컬 캐시는 API 서버(앱이나 웹의 요청을 받아 데이터를 돌려주는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 따로 저장하는 방식입니다. 그래서 서버마다 캐시 내용이 달라지고, 가격을 바꾸면 바뀐 가격이 고객에게 최대 5분 늦게 보입니다.

Redis(여러 서버가 함께 쓰는 캐시 서버)는 서버 4대가 같이 쓰는 1대로 도입할 예정입니다. 서버 4대가 같은 캐시를 보기 때문에, 서버마다 캐시 내용이 달라지는 일이 없어집니다.
