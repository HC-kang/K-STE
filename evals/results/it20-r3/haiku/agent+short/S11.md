# API 키 관리 지침

이 문서는 API 키의 교체 주기, 교체 시점, 보관 방법을 정한다. 운영 환경 키와 개발 환경 키에 적용되는 규칙이 다르므로 각 항목에서 환경을 구분한다.

## 1. 교체 주기

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙에는 예외가 없다.

확인 필요: 90일을 어느 날부터 셀지 정해지지 않았다. 직전 교체일부터인지, 키 발급일부터인지 밝혀야 한다.

개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 2. 교체 시점

운영 환경 API 키는 평일 업무 시간(10:00-18:00)에 교체하는 것을 권장한다.

장애를 복구하는 중이라면 업무 시간 밖에 교체해도 된다.

## 3. Git 저장소 보관 금지

API 키를 Git 저장소에 커밋하면 안 된다.

## 4. 발급과 저장

Vault 웹 화면에서 API 키를 직접 발급할 수 있다.

교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

확인 필요: 이 저장 규칙이 개발 환경 키에도 적용되는지 정해지지 않았다. 개발 환경 키도 `prod/api-keys`에 저장해야 하는지, 다른 경로를 써도 되는지 밝혀야 한다.
