# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 지정한 리비전으로 롤백하는 절차를 정한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

**경고: DB 마이그레이션이 포함된 배포는 롤백하면 안 된다.**

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
2. 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 한다.
3. 확인 필요: 마이그레이션이 포함되지 않은 경우에도 롤백을 진행해도 되는지. 원문에 이 경우의 절차가 없다.

## 2. 롤백 실행

4. `argocd app rollback payment-api <REVISION>` 명령의 `<REVISION>`에 롤백할 리비전 번호를 넣어 실행한다.

## 3. 롤백 후 확인

5. `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 4. 이력 기록

7. 롤백 이력을 #deploy 채널에 남겨야 한다.
