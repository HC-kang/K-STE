# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api의 운영 배포를 롤백하는 절차를 정한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 판단해야 하며, 포함됐다면 롤백하지 않고 DBA에게 연락해야 한다. 롤백 후에는 헬스 체크와 결제 테스트 주문으로 결과를 점검하고, 롤백 이력을 #deploy 채널에 남긴다.

## 담당과 도구

- 배포 도구: ArgoCD
- DB 담당: DBA 박지은

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 판단해야 한다.
2. **경고: 마이그레이션이 포함된 배포는 롤백하면 안 된다.** 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 하며, 이후 단계는 진행하지 않는다.
3. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다: `argocd app rollback payment-api <REVISION>`
4. 롤백 후 `/healthz` 응답 코드가 200인지 점검해야 한다.
5. 롤백 후 결제 테스트 주문 1건이 성공하는지 점검해야 한다.
6. 롤백 이력을 #deploy 채널에 남겨야 한다.
