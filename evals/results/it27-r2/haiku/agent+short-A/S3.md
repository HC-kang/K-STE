이 PR은 토큰 만료 시각과 정확히 같은 시각에 요청할 때 토큰을 유효하다고 판단하는 버그를 수정한다. 버그의 원인은 `auth/token.py`의 `is_valid()`가 `now <= expires_at`로 비교하여 만료 시각 자체를 유효 범위에 포함한 것이다.

## 변경 사항

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꾼다.
- 테스트 `test_token_expired_at_boundary`와 `test_token_valid_before_expiry`를 추가한다.

## 테스트

로컬에서 단위 테스트를 실행했고 모두 통과했다. 통합 테스트는 아직 실행하지 않았다. 따라서 통합 테스트 결과는 아직 없다.

관련 이슈는 #412이다.
