로컬 캐시와 Redis 캐시의 차이는 상품 목록 사본을 어디에 두느냐입니다. 로컬 캐시는 API 서버 4대가 각자 자기 메모리에 사본을 따로 둡니다. Redis 캐시는 서버 4대가 함께 쓰는 별도의 캐시 서버 1대에 사본을 둡니다. Redis는 데이터를 메모리에 두고 여러 서버가 네트워크로 함께 읽고 쓰는 프로그램입니다.

지금은 서버마다 사본 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다. Redis를 쓰면 서버 4대가 같은 사본을 읽습니다. 그래서 사본을 한 번 갱신하면 4대가 같은 가격을 봅니다.

다만 Redis를 도입한다고 5분 지연이 자동으로 없어지지는 않습니다. 가격을 바꿀 때 캐시를 지우는 작업이 있어야 즉시 반영됩니다. 확인 필요: 이번 도입 범위에 가격 변경 시 캐시 삭제가 포함되는지.
