# 토큰 만료 시각과 정확히 같은 시각의 요청을 유효하지 않은 것으로 판단하도록 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 `is_valid()`가 토큰을 유효하다고 판단했다. `auth/token.py`의 비교 연산자를 `<=`에서 `<`로 바꿔 이 경우 토큰을 유효하지 않다고 판단하게 했다. 로컬에서 단위 테스트는 모두 통과했고, 통합 테스트는 아직 돌리지 않았다.

## 변경 내용

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다.
- 테스트 2개를 추가했다: `test_token_expired_at_boundary`, `test_token_valid_before_expiry`.

## 테스트

- 단위 테스트: 로컬에서 모두 통과했다.
- 통합 테스트: 아직 돌리지 않았다.
