# API 키 관리 지침

이 문서는 API 키의 교체 주기, 교체 시간, 저장 위치, 커밋 금지 규칙을 정리한다.

## 운영 환경 API 키

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙에는 예외가 없다.

교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다. 장애 대응 중이면 업무 시간 밖에 교체해도 된다.

## 개발 환경 API 키

개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 저장과 커밋

교체한 API 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

API 키를 Git 저장소에 커밋하면 안 된다.

## Vault

Vault 웹 화면에는 API 키를 직접 발급하는 기능이 있다.
