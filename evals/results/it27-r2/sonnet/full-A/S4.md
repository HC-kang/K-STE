# 운영 배포 롤백 런북

ArgoCD로 운영 배포를 롤백하는 절차를 정리한다. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 된다.

## 롤백 금지 조건

배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다. 이때는 DBA 박지은에게 연락해야 한다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. DB 마이그레이션이 포함되지 않았으면 아래 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

3. `/healthz`가 200을 반환하는지 확인한다.
4. 결제 테스트 주문 1건이 성공하는지 확인한다.
5. 롤백 이력을 #deploy 채널에 남긴다.
