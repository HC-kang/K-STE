Redis를 도입하면 API 서버(고객의 요청을 받아 데이터를 돌려주는 서버) 4대가 같은 캐시를 보게 되어, 서버마다 상품 목록이 달라지는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 미리 담아 두는 임시 저장소입니다. 지금은 서버마다 자기 메모리에 상품 목록을 5분 동안 캐시하며, 이것이 로컬 캐시입니다. 서버 4대가 각자 따로 담아 두기 때문에 캐시 내용이 서로 다릅니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버이고, 1대를 도입할 예정입니다. 4대가 이 서버 한 곳에서 같은 캐시를 읽으므로, 어느 서버에 접속하든 고객이 같은 상품 목록을 보게 됩니다.
