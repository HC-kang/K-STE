# fix: 토큰 만료 시각과 같은 시각의 요청을 유효로 판단하는 문제 수정

토큰 만료 시각과 요청 시각이 정확히 같을 때 토큰을 유효하다고 판단하던 경계 조건을 고친다. `is_valid()`의 비교 연산자를 `<=`에서 `<`로 바꿔 만료 시각에 도달한 시점부터 토큰을 만료로 판단한다. 로컬 단위 테스트는 모두 통과했고, 통합 테스트는 아직 실행하지 않았다.

## 배경

토큰 만료 시각(`expires_at`)과 요청 시각(`now`)이 정확히 같으면 `is_valid()`가 토큰을 유효하다고 판단했다.

## 변경 내용

- `auth/token.py`의 `is_valid()`에서 조건을 `now <= expires_at`에서 `now < expires_at`로 변경한다.
- 경계 조건을 검증하는 테스트 `test_token_expired_at_boundary`를 추가한다.
- 만료 전 토큰이 유효하게 판단되는지 검증하는 테스트 `test_token_valid_before_expiry`를 추가한다.

## 테스트

- 로컬 단위 테스트: 모두 통과했다.
- 통합 테스트: 아직 실행하지 않았다.
