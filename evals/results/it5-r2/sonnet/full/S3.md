# 토큰 만료 시각과 같은 시각의 요청을 만료로 처리

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 버그를 고쳤다. `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다. 로컬 단위 테스트는 모두 통과했고, 통합 테스트는 아직 돌리지 않았다.

## 변경 내용

`is_valid()`의 비교 연산자를 `<=`에서 `<`로 바꿨다. 이제 `now`가 `expires_at`과 같으면 토큰을 유효하지 않다고 판단한다.

## 테스트

테스트 2개를 추가했다. `test_token_expired_at_boundary`는 만료 시각과 같은 시각의 요청을 검증한다. `test_token_valid_before_expiry`는 만료 시각 이전의 요청을 검증한다.

로컬에서 단위 테스트를 실행했고 모두 통과했다. 통합 테스트는 아직 실행하지 않았다.
