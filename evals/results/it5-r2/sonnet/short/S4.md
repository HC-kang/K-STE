이 런북은 ArgoCD로 운영 배포를 롤백하는 절차를 설명한다. 롤백 전에 DB 마이그레이션 포함 여부를 반드시 확인한다.

## 롤백 전 확인

1. 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않는다.
3. 마이그레이션이 포함됐으면 DBA 박지은에게 연락한다.

## 롤백 실행

마이그레이션이 포함되지 않은 것을 확인한 뒤 아래 명령을 실행한다.

```
argocd app rollback payment-api <REVISION>
```

## 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 이력 기록

롤백 이력을 #deploy 채널에 남긴다.

확인 필요: `<REVISION>`에 넣을 값을 확인하는 방법과 마이그레이션 포함 여부를 확인하는 방법이 주어지지 않아 런북에 적지 않았다.
