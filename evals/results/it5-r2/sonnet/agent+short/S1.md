로컬 캐시는 서버마다 따로 갖는 임시 저장소이고, Redis 캐시는 서버 4대가 함께 보는 임시 저장소입니다. Redis를 도입하면 서버마다 상품 목록이 달라지는 문제가 없어집니다.

현재는 서버 4대가 각자 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 저장한 시점이 달라서 같은 시각에 서버 A와 서버 B가 서로 다른 가격을 보여 줄 수 있습니다. 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 캐시 서버 1대를 따로 두고 API 서버 4대가 모두 거기서 상품 목록을 읽습니다. 저장본이 하나뿐이므로 어느 서버에 접속해도 고객은 같은 가격을 봅니다. 가격을 바꿀 때도 저장본 하나만 갱신하면 됩니다.

가격 변경이 5분 지연 없이 바로 반영되는지는 Redis 도입만으로 정해지지 않습니다. 가격을 바꿀 때 Redis의 저장본을 바로 갱신하거나 지우도록 만들어야 합니다. 확인 필요: 이번 도입에서 가격 변경 시 저장본을 갱신하는 동작을 포함하는지 개발팀에 확인해 주세요.
