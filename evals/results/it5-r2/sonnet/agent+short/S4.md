# 운영 배포 롤백 런북

ArgoCD로 `payment-api`의 운영 배포를 롤백하는 절차다. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

## 절차

1. 롤백하려는 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. **마이그레이션이 포함됐으면 롤백하면 안 된다.** 롤백하지 않고 DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았으면 다음 명령을 실행한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백이 끝나면 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: "마이그레이션이 포함됐는지 확인"하는 방법과 `<REVISION>`을 정하는 방법은 주어진 사실에 없다. 4-6단계를 4단계가 실패해도 진행하는지, 실패하면 어떻게 하는지도 정해지지 않았다.
