로컬 캐시와 Redis 캐시의 차이는 캐시를 어디에 두느냐입니다. 캐시(자주 쓰는 데이터를 빨리 꺼내 쓰려고 따로 복사해 둔 임시 보관소)는 지금 각 서버 안에 있고, Redis 캐시는 서버 4대가 함께 쓰는 별도의 캐시 서버 1대에 있습니다.

지금은 서버 4대가 각자 상품 목록을 5분 동안 보관합니다. 서버마다 보관한 내용이 다를 수 있어서, 가격을 바꾸면 서버마다 반영되는 시점이 달라집니다. 그래서 고객이 보는 가격이 최대 5분 늦게 바뀝니다.

Redis 캐시를 쓰면 서버 4대가 같은 보관소를 보므로, 서버끼리 내용이 어긋나는 문제가 없어집니다. 가격을 바꾸면 모든 서버가 같은 값을 보게 됩니다.

반대로 로컬 캐시는 서버 안에서 바로 꺼내 쓰므로 응답이 조금 더 빠릅니다. Redis 캐시는 서버 사이의 네트워크를 거쳐 값을 가져오므로 그만큼 느릴 수 있습니다. 이 속도 차이는 일반적인 특성이고, 우리 서비스에서 측정한 값은 아닙니다.

다만 Redis 도입만으로 5분 지연이 없어진다고 단정할 수 없습니다. 지연이 줄어드는지는 가격을 바꿀 때 Redis 안의 값을 바로 갱신하는지, 5분이 지나야 만료되는지에 따라 달라집니다. 이 부분은 아직 확인하지 않았으므로 개발팀에 확인이 필요합니다.
