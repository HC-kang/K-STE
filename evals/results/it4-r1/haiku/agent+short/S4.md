# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 payment-api 운영 배포를 롤백하는 절차를 정리한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백해서는 안 되며, DBA 박지은에게 연락해야 한다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백해서는 안 된다.
3. 마이그레이션이 포함됐으면 DBA 박지은에게 연락한다.

## 2. 롤백 실행

1. 롤백 대상 REVISION을 확인한다.
2. 다음 명령으로 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 4. 이력 기록

1. #deploy 채널에 롤백 이력을 남긴다.

## 확인 필요

확인 필요: 마이그레이션 포함 여부를 확인하는 방법. 원문에 정해진 방법이 없다.
확인 필요: 롤백 대상 REVISION을 확인하는 방법. 원문에 정해진 방법이 없다.
확인 필요: DBA 박지은에게 연락하는 방법. 원문에 연락 채널이 없다.
확인 필요: `/healthz`를 확인할 주소와 방법. 원문에 주소가 없다.
확인 필요: 결제 테스트 주문을 하는 방법. 원문에 방법이 없다.
확인 필요: `/healthz` 확인 또는 테스트 주문이 실패할 때의 조치. 원문에 조치가 없다.
