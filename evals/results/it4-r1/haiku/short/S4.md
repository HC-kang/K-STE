payment-api 운영 배포는 DB 마이그레이션 포함 여부를 먼저 확인한 뒤에만 롤백한다.

## 롤백 전 확인

롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인한다. 확인 필요: 마이그레이션 포함 여부를 확인하는 구체적 방법은 제공된 내용에 없다.

마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA(데이터베이스 관리 담당자) 박지은에게 연락해야 한다.

## 롤백 실행

ArgoCD(배포 도구)에서 다음 명령을 실행한다.

```
argocd app rollback payment-api <REVISION>
```

`<REVISION>`에는 되돌릴 리비전(REVISION, 배포 이력의 번호)을 넣는다.

## 롤백 후 확인

롤백 후 `/healthz`(서비스 상태 확인 경로)가 200을 반환하는지 확인한다. 이어서 결제 테스트 주문 1건이 성공하는지 확인한다.

확인 필요: `/healthz`를 호출하는 방법과 결제 테스트 주문을 하는 방법은 제공된 내용에 없다.

## 이력 기록

롤백 이력을 #deploy 채널에 남긴다. 확인 필요: 이력에 적을 항목과 형식은 제공된 내용에 없다.
