캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: "배포 후 재시작하면 초기화됩니다". 초기화되는 대상이 메모리라는 뜻인지, 서버의 데이터나 설정이라는 뜻인지 알 수 없습니다.

확인 필요: "캐시 서버와 API 서버는 ~ 재시작하면 초기화됩니다". 뒤 절이 두 서버 모두에 해당한다는 뜻인지, API 서버에만 해당한다는 뜻인지 알 수 없습니다.

확인 필요: "관리자 권한이 있는 팀원 및 QA 담당자". 관리자 권한이 팀원에게만 걸리는 조건인지, 팀원과 QA 담당자 모두에게 걸리는 조건인지 알 수 없습니다.
