# 운영 배포 롤백 런북

이 런북은 payment-api 운영 배포를 ArgoCD로 롤백하는 절차를 설명한다. 아래 순서를 따른다.

## 롤백 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 **롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았으면 다음 단계로 넘어간다.
4. 롤백 대상 REVISION 값을 정한다.
5. 다음 명령을 실행한다: `argocd app rollback payment-api <REVISION>`
6. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
7. 결제 테스트 주문 1건이 성공하는지 확인한다.
8. #deploy 채널에 롤백 이력을 남긴다.

## 확인 필요

- 확인 필요: 롤백 대상 REVISION 값을 찾는 방법이 주어지지 않았다.
- 확인 필요: 배포에 마이그레이션이 포함됐는지 확인하는 방법이 주어지지 않았다.
- 확인 필요: DBA 박지은의 연락처와 연락 방법이 주어지지 않았다.
- 확인 필요: `/healthz`를 호출할 주소가 주어지지 않았다.
- 확인 필요: 결제 테스트 주문을 실행하는 방법과 테스트 환경이 주어지지 않았다.
- 확인 필요: `/healthz`가 200을 반환하지 않을 때 따를 조치가 주어지지 않았다.
