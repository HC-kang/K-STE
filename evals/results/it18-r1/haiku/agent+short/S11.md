# API 키 관리 지침

이 문서는 운영 환경과 개발 환경의 API 키 교체 규칙, Git 저장소 관련 금지 사항, Vault 저장 위치를 정한다.

## 교체 주기

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.

개발 환경 API 키는 90일 교체 규칙을 따르지 않아도 된다.

## 교체 시간

키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.

장애 상황을 수습하는 중이면 업무 시간 밖에 교체해도 된다.

## 저장과 발급

교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

Vault 웹 화면에서 API 키를 직접 발급할 수 있다.

## 금지 사항

API 키를 Git 저장소에 커밋하면 안 된다.
