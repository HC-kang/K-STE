# 토큰 만료 경계 판정 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 버그를 수정한다. `auth/token.py`의 `is_valid()`에서 비교 연산자를 `<=`에서 `<`로 바꿨다.

## 변경 사항

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다. 이 변경으로 현재 시각이 만료 시각과 같으면 토큰을 유효하지 않다고 판단한다.
- 테스트 2개를 추가했다.
  - `test_token_expired_at_boundary`: 만료 시각과 같은 시각의 판정을 검사한다.
  - `test_token_valid_before_expiry`: 만료 시각 이전의 판정을 검사한다.
