# API 키 관리 지침

## 교체 주기

- 운영 환경 API 키는 90일마다 교체해야 한다.
- 90일 교체 규칙은 예외 없이 지켜야 한다.
- 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.

## 개발 환경 키

- 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## Git 저장소 관리

- API 키를 Git 저장소(코드 변경 이력을 관리하는 저장소)에 커밋(변경 내용을 저장소에 기록하는 작업)하면 안 된다.

## Vault 발급과 저장

- Vault(비밀 값을 안전하게 보관하는 도구)의 웹 화면에는 API 키를 직접 발급하는 기능이 있다.
- 교체한 운영 환경 API 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.
