이 런북은 ArgoCD로 운영 배포를 롤백하는 절차를 설명한다.

## 롤백 전

롤백 전에 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

마이그레이션이 포함됐으면 롤백하면 안 된다. 이때는 DBA 박지은에게 연락해야 한다.

## 롤백

마이그레이션이 포함되지 않았으면 다음 명령을 실행한다.

```
argocd app rollback payment-api <REVISION>
```

## 롤백 후

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.
3. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: `<REVISION>`에 넣을 값을 어떻게 정하는지 알려주세요. 마이그레이션 포함 여부를 어디서 확인하는지도 알려주세요. 두 내용은 주어진 사실에 없어서 런북에 쓰지 않았습니다.
