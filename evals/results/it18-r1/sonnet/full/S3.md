# 만료 시각 정각의 토큰을 유효하다고 판단하는 버그 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단했다. `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿔 이 버그를 수정했다. 로컬에서 단위 테스트는 모두 통과했고, 통합 테스트는 아직 돌리지 않았다.

## 변경 내용

`auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다.

## 테스트

테스트 2개를 추가했다.

- `test_token_expired_at_boundary`
- `test_token_valid_before_expiry`
