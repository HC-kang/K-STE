가장 큰 차이는 캐시(자주 쓰는 데이터를 잠시 저장해 두는 곳)를 서버마다 따로 갖느냐, 서버 4대가 같이 쓰느냐입니다.

지금은 로컬 캐시입니다. API 서버(요청을 받아 응답하는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis 캐시는 서버 4대가 같이 쓰는 캐시 서버 1대에 상품 목록을 저장합니다. 그래서 Redis를 도입하면 서버 4대가 같은 캐시 내용을 보게 되어, 서버마다 캐시 내용이 다른 문제가 없어집니다.
