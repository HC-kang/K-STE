# API 키 관리 지침

이 문서는 사내 API 키의 교체 주기, 교체 시기, 발급과 저장 위치, Git 저장소 관리 규칙을 정한다.

## 교체 주기

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.

개발 환경 API 키는 90일 교체 규칙을 따르지 않아도 된다.

## 교체 시기

운영 환경 API 키는 평일 업무 시간(10:00-18:00)에 교체하는 것을 권장한다.

장애 대응 중인 경우에는 업무 시간 밖에 API 키를 교체해도 된다.

## 발급과 저장

Vault 웹 화면에서 API 키를 직접 발급할 수 있다.

교체한 API 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## Git 저장소 관리

**API 키를 Git 저장소에 커밋하면 안 된다.**
