# payment-api 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 payment-api의 운영 배포를 이전 리비전으로 되돌리는 절차를 설명한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다. 마이그레이션이 포함됐으면 **롤백하면 안 된다.** 롤백 후에는 `/healthz`와 결제 테스트 주문으로 정상 동작을 확인하고, 롤백 이력을 #deploy 채널에 남긴다.

## 1. 롤백 전 점검

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않는다. 이때 DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았으면 2단계로 넘어간다.

## 2. 롤백 실행

1. 아래 명령을 실행한다. `<REVISION>`에는 되돌릴 리비전 값을 넣는다.

   `argocd app rollback payment-api <REVISION>`

## 3. 롤백 후 검증

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문을 1건 실행하고, 주문이 성공하는지 확인한다.

## 4. 이력 기록

1. #deploy 채널에 롤백 이력을 남긴다.
