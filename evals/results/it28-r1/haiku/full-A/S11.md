# API 키 관리 지침

이 문서는 운영 환경과 개발 환경에서 사용하는 API 키의 교체 주기, 저장 위치, 형상 관리 금지 사항을 정한다. 운영 환경 API 키는 90일마다 교체해야 하며, 이 규칙에는 예외가 없다.

## 1. 운영 환경 API 키 교체

운영 환경 API 키는 90일마다 교체해야 한다. 교체 시기는 업무 시간 기준으로 정한다.

- 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.

## 2. 교체한 키 저장

교체한 운영 환경 API 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

Vault 웹 화면에서는 API 키를 직접 발급할 수 있다.

## 3. 형상 관리 금지

**API 키를 Git 저장소에 커밋하면 안 된다.** 키 값이 포함된 파일도 커밋 대상에 넣으면 안 된다.

## 4. 개발 환경 API 키

개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.
