로컬 캐시는 서버마다 따로 갖는 저장 공간이고, Redis 캐시는 서버 4대가 함께 쓰는 저장 공간 하나입니다.

지금은 API 서버(요청을 받아 응답하는 서버) 4대가 각자 메모리에 상품 목록을 5분 동안 캐시(자주 쓰는 데이터를 미리 저장해 두는 것)합니다. 이것이 로컬 캐시입니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 4대가 같이 쓰는 캐시 서버 1대입니다. 4대가 같은 캐시를 보므로 서버마다 캐시 내용이 달라지는 문제가 없어집니다. 가격 변경이 늦게 반영되는 문제는 서버마다 캐시가 따로여서 생기므로, Redis 도입은 이 원인을 겨냥합니다.
