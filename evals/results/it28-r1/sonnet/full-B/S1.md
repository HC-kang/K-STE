Redis를 도입하면 서버 4대가 캐시 하나를 같이 쓰게 되므로, 서버마다 캐시 내용이 달라서 생기는 문제가 없어집니다.

캐시는 자주 쓰는 데이터를 빠르게 꺼내려고 임시로 저장해 두는 곳입니다. 지금은 API 서버(요청을 받아 데이터를 돌려주는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 이렇게 서버마다 따로 가진 캐시가 로컬 캐시입니다. 서버마다 캐시 내용이 다르기 때문에, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 여러 서버가 함께 쓰는 캐시 서버입니다. 이번에는 서버 4대가 같이 쓰는 Redis 캐시 서버 1대를 도입할 예정입니다. 그러면 서버 4대가 같은 캐시 내용을 보게 됩니다.
