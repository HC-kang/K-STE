캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: '초기화됩니다'. 초기화되는 것이 메모리인지, 서버 설정이나 데이터인지 원문에 없습니다.
확인 필요: '관리자 권한이 있는 팀원 및 QA 담당자'. 관리자 권한이 있는 사람만 팀원과 QA 담당자인지, 관리자 권한이 있는 팀원과 권한과 상관없는 QA 담당자인지 정해지지 않았습니다.
확인 필요: '공지 채널에 알려야 합니다'. 무엇을 알려야 하는지 원문에 없습니다.
