가장 큰 차이는 캐시(자주 쓰는 데이터를 빨리 꺼내 쓰려고 임시로 저장해 둔 곳)를 서버마다 따로 두느냐, 서버 4대가 하나를 같이 쓰느냐입니다.

로컬 캐시는 서버 각자의 메모리에 있습니다. 지금은 API 서버 4대가 각자 상품 목록을 5분 동안 저장합니다. 서버마다 저장한 시점이 달라서 캐시 내용이 서로 다르고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis 캐시는 별도의 캐시 서버 1대에 있고, 서버 4대가 이를 같이 씁니다. 그래서 4대가 항상 같은 상품 목록을 보여줍니다. 고객이 어느 서버에 연결되느냐에 따라 다른 가격을 보는 일이 없어집니다.

가격 반영 속도는 도입만으로 빨라진다고 말하기 어렵습니다. 보관 시간을 지금처럼 5분으로 두면 최대 5분 지연은 남을 수 있습니다. 가격을 바꿀 때 캐시를 바로 지우도록 만들면 이 지연을 줄일 수 있습니다.

확인 필요: 이번 Redis 도입에 가격 변경 시 캐시를 바로 지우는 방식이 포함되는지 개발팀에 확인해야 합니다.
