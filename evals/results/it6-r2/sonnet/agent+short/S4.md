# 운영 배포 롤백 런북

이 문서는 ArgoCD로 `payment-api` 운영 배포를 이전 리비전으로 되돌리는 절차를 설명한다.

## 사전 확인

1. 롤백하려는 배포에 DB 마이그레이션이 포함됐는지 반드시 확인한다.
2. **경고:** 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다. 롤백하지 않고 DBA 박지은에게 연락한다.

## 절차

1. 배포에 DB 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다. `<REVISION>`에는 되돌릴 리비전을 넣는다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

## 결과 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 기록

1. #deploy 채널에 롤백 이력을 남긴다.

확인 필요: 결과 확인에서 `/healthz`가 200을 반환하지 않거나 결제 테스트 주문이 실패하면 어떻게 하는지 정보가 없다. 이 경우의 조치와 연락처가 있으면 알려 주면 반영한다.
