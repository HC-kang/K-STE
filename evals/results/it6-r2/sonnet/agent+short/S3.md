# 토큰 만료 시각과 같은 시각의 요청을 만료로 판단하도록 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 `is_valid()`가 토큰을 유효하다고 판단했다. 이 PR은 그 경계 조건을 고친다.

관련 이슈: #412

## 변경 내용

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다.
- 테스트 `test_token_expired_at_boundary`를 추가했다.
- 테스트 `test_token_valid_before_expiry`를 추가했다.

## 테스트

- 로컬에서 단위 테스트를 모두 통과했다.
- 통합 테스트는 아직 돌리지 않았다.
