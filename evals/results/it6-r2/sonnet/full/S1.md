로컬 캐시는 서버마다 따로 갖는 임시 저장소이고, Redis 캐시는 서버 4대가 함께 쓰는 저장소 하나입니다. 캐시는 자주 쓰는 데이터를 빨리 꺼내 쓰도록 임시로 저장해 두는 것입니다.

지금은 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis(여러 서버가 함께 쓰는 캐시 전용 서버)를 도입하면 서버 4대가 캐시 서버 1대를 같이 씁니다. 어느 서버가 응답해도 같은 캐시 내용을 보므로, 서버마다 내용이 달라서 생기던 차이가 없어집니다.

가격 변경이 얼마나 빨리 반영되는지는 캐시를 언제 갱신하느냐에 달려 있습니다. 이 갱신 방식은 아직 확인하지 않았습니다.
