# 토큰 만료 경계에서 만료된 토큰을 유효로 판단하는 문제 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 문제를 고친다.

## 원인

`auth/token.py`의 `is_valid()`가 `now <= expires_at`로 비교했다. 이 비교는 만료 시각 자체를 유효한 시각으로 본다.

## 변경 사항

`is_valid()`의 비교 조건을 `now < expires_at`로 바꿨다.

테스트를 2개 추가했다. `test_token_expired_at_boundary`는 만료 경계 시각의 판정을 검사한다. `test_token_valid_before_expiry`는 만료 전 시각에 토큰이 유효한지 검사한다.

## 검증

- 로컬에서 단위 테스트를 실행했고 모두 통과했다.
- 통합 테스트는 아직 실행하지 않았다.
