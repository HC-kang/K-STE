# 운영 배포 롤백 런북 (payment-api)

이 문서는 ArgoCD로 payment-api 운영 배포를 롤백하는 절차를 정리한다. 배포 도구는 ArgoCD이다.

## 1. 롤백 전 마이그레이션 확인

- 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인한다.
- 확인 필요: 마이그레이션 포함 여부를 확인하는 방법과 담당자가 원문에 없다.

**마이그레이션이 포함됐으면 롤백하지 않는다. DBA 박지은에게 연락한다.**

## 2. 롤백 실행

- 롤백할 REVISION 번호를 정한다.
- 확인 필요: REVISION 번호를 정하는 기준과 확인 방법이 원문에 없다.
- 아래 명령으로 롤백한다. `<REVISION>`은 정한 번호로 바꾼다.

```bash
argocd app rollback payment-api <REVISION>
```

## 3. 롤백 후 확인

- `/healthz`가 200을 반환하는지 확인한다.
- 확인 필요: `/healthz`를 호출할 기본 주소가 원문에 없다.
- 결제 테스트 주문 1건이 성공하는지 확인한다.
- 확인 필요: 테스트 주문을 실행하는 방법과 테스트 결제 환경 정보가 원문에 없다.
- 확인 필요: 확인이 실패했을 때 따를 조치가 원문에 없다.

## 4. 롤백 이력 기록

- 롤백 이력을 #deploy 채널에 남긴다.
- 확인 필요: 이력에 포함할 항목(예: REVISION, 시각, 담당자)이 원문에 없다.
