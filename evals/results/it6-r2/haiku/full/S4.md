# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api의 운영 배포를 이전 리비전으로 되돌리는 절차를 정한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함되었는지 확인한다. 마이그레이션이 포함되었으면 롤백하지 않고 DBA 박지은에게 연락한다. 롤백 후에는 `/healthz`와 결제 테스트 주문으로 정상 동작을 확인하고, 롤백 이력을 #deploy 채널에 남긴다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함되었는지 확인한다.
2. 마이그레이션이 포함되었으면 롤백하지 않는다. DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다. `<REVISION>`에는 되돌릴 리비전을 넣는다.
   `argocd app rollback payment-api <REVISION>`
4. 롤백 명령을 실행한 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건을 실행하고 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요 사항

- 배포에 DB 마이그레이션이 포함되었는지 확인하는 방법이 정해지지 않았다. 절차 1을 수행할 방법을 정해서 추가해야 한다.
- `<REVISION>`에 넣을 값을 찾는 방법이 정해지지 않았다.
- `/healthz`가 200을 반환하지 않거나 결제 테스트 주문이 실패했을 때의 대응 절차가 정해지지 않았다.
