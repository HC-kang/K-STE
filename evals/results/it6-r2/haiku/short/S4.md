이 런북은 ArgoCD로 배포한 payment-api의 운영 배포를 이전 리비전으로 롤백하는 절차를 설명한다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐는지 확인하지 못하면 롤백을 시작하지 않는다.

**경고: 배포에 DB 마이그레이션이 포함됐으면 롤백하지 않는다. 이 경우 DBA 박지은에게 연락한다.**

## 롤백 실행

1. 다음 명령으로 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

`<REVISION>`에는 롤백할 대상 리비전 번호를 넣는다.

## 롤백 후 검증

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 이력 기록

롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요

- 확인 필요: 배포에 마이그레이션이 포함됐는지 확인하는 방법이 명시되지 않았다.
- 확인 필요: `<REVISION>`에 넣을 리비전 번호를 확인하는 방법이 명시되지 않았다.
- 확인 필요: `/healthz` 확인이나 테스트 주문이 실패했을 때의 조치가 명시되지 않았다.
- 확인 필요: DBA 박지은에게 연락하는 방법이 명시되지 않았다.
- 확인 필요: 롤백 이력에 포함할 내용이 명시되지 않았다.
