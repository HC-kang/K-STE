# payment-api 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 payment-api 운영 배포를 이전 리비전으로 되돌리는 절차다. 롤백 전에 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락해야 한다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. **마이그레이션이 포함됐으면 롤백하면 안 된다.** DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았으면 2장으로 진행한다.

## 2. 롤백 실행

1. `<REVISION>`에 롤백할 리비전 번호를 넣는다.
2. `argocd app rollback payment-api <REVISION>` 명령을 실행한다.

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건을 진행하고, 그 주문이 성공하는지 확인한다.

## 4. 이력 기록

1. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인. 확인할 자료와 기준.
확인 필요: `<REVISION>`. 롤백할 리비전 번호를 찾는 방법.
확인 필요: 결제 테스트 주문. 주문을 진행하는 방법과 성공 기준.
