# API 키 관리 지침

이 문서는 API 키(외부 서비스에 접속할 때 쓰는 인증 값)의 교체, 저장, 금지 사항을 정한다.

## 규칙

- 운영 환경 API 키는 90일마다 교체해야 한다.
- 운영 환경 API 키의 90일 교체 규칙에는 예외가 없다.
- API 키를 Git 저장소(코드 변경 이력을 저장하는 곳)에 커밋하면 안 된다.
- 키 교체는 평일 업무 시간(10:00-18:00)에 하기를 권장한다.
- 장애 대응 중이면 업무 시간 밖에도 키를 교체해도 된다.
- 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.
- Vault(비밀 값을 안전하게 보관하는 도구)의 웹 화면에서 API 키를 직접 발급할 수 있다.
- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.
