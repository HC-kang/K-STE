# 운영 배포 롤백 런북

## 사전 확인

롤백 대상 배포에 DB 마이그레이션(데이터베이스 구조나 데이터를 바꾸는 변경 작업)이 포함됐는지 확인해야 한다.

확인 필요: 마이그레이션 포함 여부를 확인하는 방법이 원문에 없다. 확인 방법을 정한 뒤 이 항목에 적어야 한다.

## 롤백 절차

1. 롤백 대상 배포에 마이그레이션이 포함됐으면 **롤백하면 안 된다.**
2. 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았을 때만 아래 명령을 실행해야 한다.

```
argocd app rollback payment-api <REVISION>
```

`<REVISION>`은 롤백할 배포 버전을 나타내는 값이므로, 롤백 대상 값으로 바꿔야 한다.

## 롤백 후 확인

4. `/healthz`(서비스 상태를 확인하는 경로)가 200을 반환하는지 확인해야 한다.
5. 결제 테스트 주문을 1건 실행하고, 그 주문이 성공하는지 확인해야 한다.

## 이력 기록

6. #deploy 채널에 롤백 이력을 남겨야 한다.
