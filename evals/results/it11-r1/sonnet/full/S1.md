Redis를 도입하면 서버 4대가 캐시(자주 쓰는 데이터를 빨리 꺼내 쓰려고 임시로 저장해 두는 공간)를 하나로 같이 쓰게 되어, 서버마다 상품 목록이 달라지는 문제가 없어집니다.

지금은 API 서버(고객 요청을 받아 응답하는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 이것이 로컬 캐시입니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis 캐시는 서버 4대가 같이 쓰는 캐시 서버 1대에 상품 목록을 저장합니다. 4대가 같은 캐시를 읽으므로 서버마다 내용이 달라지지 않습니다. 가격 반영이 최대 5분 늦어지던 원인이 서버마다 캐시 내용이 다른 것이므로, Redis 도입은 이 원인을 없앱니다.
