# 인증 개선 회의록

10월 17일 14:00에 인증 개선 회의를 했다. 인증 서버의 세션 만료 시간을 30분에서 60분으로 늘리기로 했다. 결제 서버의 세션 만료 시간은 30분으로 유지하기로 했다.

## 참석자

박준호, 정은지, 김하늘

## 결정 사항

1. 인증 서버의 세션 만료 시간을 30분에서 60분으로 늘리기로 했다.
2. 결제 서버의 세션 만료 시간은 30분으로 유지하기로 했다.

## 할 일

- 박준호는 인증 서버 설정 파일 `auth.yaml`의 `session_timeout` 값을 바꿔야 한다. 기한은 10월 21일이다.
- 정은지는 고객 공지 초안을 써야 한다. 공지에는 인증 서버 변경만 넣어야 한다. 기한은 10월 22일이다.
- 김하늘은 10월 23일에 결제 서버 설정이 바뀌지 않았는지 점검해야 한다.
