로컬 캐시는 서버마다 따로 갖는 메모장이고, Redis는 서버 4대가 함께 보는 공용 메모장입니다. Redis를 도입하면 서버마다 상품 목록이 달라지는 문제가 없어집니다.

현재는 서버 4대가 각자 메모리(서버 한 대 안의 임시 저장 공간)에 상품 목록을 5분 동안 저장합니다. 서버마다 저장한 시점이 달라서 서버끼리 캐시 내용이 다릅니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 캐시 서버 1대에 상품 목록을 한 벌만 저장하고, 서버 4대가 그 한 벌을 읽습니다. 그래서 고객이 어느 서버에 접속해도 같은 상품 목록을 봅니다.

가격 반영 시간이 얼마나 줄어드는지는 가격을 바꿀 때 Redis에 저장된 내용을 바로 지우거나 갱신하는지에 달려 있습니다. 바로 지우거나 갱신하면 서버 4대가 모두 새 가격을 읽습니다. 확인 필요: 가격 변경 시 Redis 캐시를 바로 지우거나 갱신하도록 설계했는지.

Redis 서버가 1대라서 이 서버가 멈추면 서비스에 어떤 영향이 있는지도 확인이 필요합니다.
