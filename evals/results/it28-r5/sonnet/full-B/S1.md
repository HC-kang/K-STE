캐시(자주 쓰는 데이터를 미리 저장해 두고 빨리 꺼내 쓰는 곳)는 지금 서버마다 따로 있고, Redis를 도입하면 서버 4대가 캐시 서버 1대를 같이 쓰게 됩니다.

지금은 API 서버(고객의 요청을 받아 응답하는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 이 방식이 로컬 캐시입니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 보이는 가격이 최대 5분 늦게 바뀝니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버 1대입니다. 서버 4대가 같은 캐시를 보게 되므로, 서버마다 캐시 내용이 달라지는 문제가 없어집니다.
