로컬 캐시는 서버마다 자기 메모리에 따로 저장하는 방식이고, Redis 캐시는 서버 4대가 같이 쓰는 캐시 서버 1대에 저장하는 방식입니다. 캐시는 자주 쓰는 데이터를 잠시 저장해 두는 곳입니다.

지금은 API 서버(요청을 받아 응답하는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 서버 4대가 캐시 서버 1대에 저장된 같은 상품 목록을 함께 씁니다. 그래서 서버마다 캐시 내용이 달라지는 문제가 없어집니다.
