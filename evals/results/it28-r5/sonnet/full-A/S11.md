# API 키 관리 지침

이 문서는 API 키의 교체 주기, 교체 시점, 보관 위치, 발급 방법에 관한 규칙을 정한다. 운영 환경 API 키와 개발 환경 API 키의 교체 규칙은 서로 다르다.

## 교체 주기

- 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙에는 예외가 없다.
- 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 교체 시점

- API 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에 API 키를 교체해도 된다.

## 보관

- API 키를 Git 저장소에 커밋하면 안 된다.
- 교체한 API 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 발급

Vault 웹 화면에서 API 키를 직접 발급할 수 있다.
