원문이 대부분 규칙을 지키고 있어 고치지 않았습니다. 아래 두 곳은 원문만으로 뜻이 정해지지 않아 확인이 필요합니다.

캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: '관리자 권한이 있는 팀원 및 QA 담당자'. '관리자 권한이 있는'이 팀원과 QA 담당자를 모두 꾸미는지, 팀원만 꾸미는지 원문에 정해지지 않았습니다.
확인 필요: '배포 전 공지 채널에 알려야 합니다'. 무엇을 알려야 하는지 원문에 없습니다.
