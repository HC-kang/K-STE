# 환불 기준 (고객센터 상담원용)

## 1. 7일 이내 해지 시 전액 환불
- 가입 후 7일 이내에 해지하는 고객은 **전액 환불**합니다.

## 2. 환불 신청 정산 시점
- **10월 31일 이후**에 접수된 환불 신청은 **11월 정산**에 포함합니다.

## 3. 팀장 승인 기준
- 환불 금액이 **50만 원을 초과**하면 **팀장 승인**을 받은 후 처리합니다.

## 4. 상담 대기 고객 관리
- 상담 대기 고객이 **20명**에 도달하면 **상담원을 추가로 배치**합니다.

---

**확인 필요 사항** (제공된 기준에 없어 문서에 포함하지 않았습니다)
- 7일 기산점: 가입 시각 기준인지, 날짜 기준인지
- 10월 31일 "이후"에 10월 31일 당일 접수 건이 포함되는지
- 50만 원 "초과"는 정확히 50만 원인 경우 승인 대상이 아닌지 확인이 필요합니다.
