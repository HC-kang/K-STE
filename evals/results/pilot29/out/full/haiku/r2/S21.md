# 파일 공유 규정

이 문서는 사내 위키에서 파일을 첨부하고 외부 공유 링크를 만들 때 적용되는 기준을 정한다. 첨부 파일 크기, 게시물당 첨부 개수, 외부 공유 링크 생성 자격, 비밀번호 입력 제한, 외부 공유 링크의 유효 기간을 다룬다.

## 첨부 파일

- 첨부 파일 하나의 크기가 25MB를 넘으면 업로드가 차단된다.
- 한 게시물에는 파일을 최대 10개까지 첨부할 수 있다.

## 외부 공유 링크

- 만 19세 미만의 인턴은 외부 공유 링크를 만들 수 없다.
- 외부 공유 링크는 만든 시각부터 72시간이 지나면 닫힌다.

## 비밀번호 입력 제한

- 비밀번호를 5번 연속 틀리면 계정이 30분 동안 잠긴다.
