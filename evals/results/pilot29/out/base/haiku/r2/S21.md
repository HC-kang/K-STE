# 파일 공유 규정

## 1. 목적

이 규정은 사내 위키에 파일을 첨부하고 외부와 공유할 때 지켜야 할 기준을 정한다.

## 2. 적용 대상

위키에 파일을 업로드하거나 외부 공유 링크를 만드는 모든 구성원에게 적용한다.

## 3. 파일 업로드 기준

1. **파일 크기**: 첨부 파일 하나의 크기가 25MB를 넘으면 업로드할 수 없다.
2. **파일 개수**: 한 게시물에는 파일을 최대 10개까지 올릴 수 있다.

## 4. 외부 공유 링크

1. **작성 자격**: 만 19세가 안 된 인턴은 외부 공유 링크를 만들 수 없다.
2. **유효 기간**: 외부 공유 링크는 생성 시각부터 72시간이 지나면 자동으로 닫힌다.

## 5. 계정 보안

1. 비밀번호를 5번 연속 잘못 입력하면 계정이 30분 동안 잠긴다.
