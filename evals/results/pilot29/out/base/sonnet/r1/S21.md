# 파일 공유 규정

## 1. 목적
이 문서는 사내 게시물의 파일 첨부와 외부 공유 링크 사용에 관한 기준을 정한다.

## 2. 첨부 파일 규정

| 항목 | 기준 |
|---|---|
| 파일당 최대 크기 | 25MB |
| 게시물당 최대 파일 수 | 10개 |

- 첨부 파일 하나가 25MB를 넘으면 업로드가 차단된다.
- 한 게시물에는 파일을 최대 10개까지 올릴 수 있다.

## 3. 외부 공유 링크 규정

### 3.1 링크 유효 기간
- 외부 공유 링크는 생성 시각부터 72시간이 지나면 자동으로 닫힌다.

### 3.2 인턴의 링크 생성 제한
- 만 19세가 안 된 인턴은 외부 공유 링크를 만들 수 없다.

## 4. 계정 보안
- 비밀번호를 5번 연속 틀리면 계정이 30분 동안 잠긴다.

## 5. 요약

| 구분 | 내용 |
|---|---|
| 파일 크기 제한 | 파일당 25MB 초과 시 업로드 차단 |
| 파일 개수 제한 | 게시물당 최대 10개 |
| 외부 링크 유효 시간 | 생성 후 72시간 |
| 외부 링크 생성 제한 | 만 19세 미만 인턴은 불가 |
| 로그인 잠금 | 비밀번호 5회 연속 오류 시 30분 잠금 |
