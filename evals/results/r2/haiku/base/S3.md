## 제목

fix(auth): 토큰 만료 경계 시각에 토큰을 유효로 판단하는 문제 수정

## 관련 이슈

Closes #412

## 배경 / 원인

토큰 만료 시각(`expires_at`)과 정확히 같은 시각에 요청이 들어오면 `is_valid()`가 토큰을 유효하다고 판단했습니다. 만료 시각은 더 이상 유효하지 않아야 하므로 이는 잘못된 동작입니다.

## 변경 사항

- `auth/token.py`의 `is_valid()`에서 비교 연산자를 `now <= expires_at`에서 `now < expires_at`로 변경했습니다. 만료 시각 자체는 이제 만료로 취급합니다.
- 경계 동작을 검증하는 테스트 2개를 추가했습니다.
  - `test_token_expired_at_boundary`: `now == expires_at`일 때 토큰이 무효인지 확인
  - `test_token_valid_before_expiry`: `now`가 `expires_at`보다 이전일 때 토큰이 유효한지 확인
