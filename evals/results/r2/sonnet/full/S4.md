# 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 `payment-api`의 운영 배포를 롤백하는 절차를 정의한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 된다.

## 롤백 전 확인

**경고: 롤백할 배포에 DB 마이그레이션이 포함됐으면 롤백하지 않는다.** 이 경우 DBA 박지은에게 연락한다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다. 여기서 절차를 끝낸다.
3. 마이그레이션이 포함되지 않았으면 다음 명령을 실행한다.

   `argocd app rollback payment-api <REVISION>`

4. 롤백이 끝난 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 4-5단계에서 확인이 실패했을 때의 조치는 제공된 사실에 없어서 쓰지 않았다. 실패 시 절차를 알려 주면 추가한다.
