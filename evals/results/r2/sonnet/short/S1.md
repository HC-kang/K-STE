로컬 캐시는 서버마다 따로 쓰는 임시 저장 공간이고, Redis는 서버 4대가 함께 쓰는 하나의 저장 공간입니다. 도입하면 서버마다 상품 목록이 달라지는 문제가 해결됩니다.

캐시는 자주 쓰는 데이터를 매번 새로 가져오지 않도록 잠시 저장해 두는 방식입니다.

| 구분 | 로컬 캐시(현재) | Redis 캐시(도입 예정) |
|---|---|---|
| 저장 위치 | 서버 4대가 각자의 메모리에 저장합니다. | 캐시 서버 1대에 저장합니다. |
| 서버 간 내용 | 서버마다 저장한 시점이 달라 내용이 다를 수 있습니다. | 서버 4대가 같은 내용을 읽습니다. |
| 가격 변경 시 | 고객에게 최대 5분 늦게 반영됩니다. | 아래 확인 필요 항목에 따라 달라집니다. |

도입 후 좋아지는 점은 같은 시점에 어느 서버가 응답하더라도 고객이 같은 상품 목록과 가격을 본다는 것입니다. 지금은 같은 고객이 새로고침할 때 다른 서버에 연결되면 가격이 다르게 보일 수 있습니다.

확인 필요: 가격을 바꿀 때 Redis에 저장된 상품 목록을 바로 지우도록 만드는지, 현재처럼 5분 만료만 두는지 정해야 합니다. 바로 지우면 반영 지연이 줄어듭니다. 5분 만료만 두면 지연은 최대 5분으로 남습니다. 다만 이 경우에도 서버마다 내용이 다른 문제는 사라집니다.

주의할 점은 Redis 서버가 1대라는 것입니다. 이 서버가 멈추면 서버 4대가 공유 캐시를 쓸 수 없습니다. 그때 서비스가 어떻게 동작하는지는 확인이 필요합니다.
