## 요약

토큰 만료 시각과 정확히 같은 시각에 들어온 요청을 유효한 토큰으로 판단하던 경계 조건 버그를 수정합니다.

## 문제

`auth/token.py`의 `is_valid()`가 `now <= expires_at`로 비교하고 있어, 요청 시각이 만료 시각과 정확히 일치할 때 이미 만료된 토큰을 유효하다고 판단했습니다.

## 변경 사항

- `auth/token.py`: `is_valid()`의 비교 연산을 `now <= expires_at`에서 `now < expires_at`로 변경했습니다. 이제 만료 시각 도달 시점부터 토큰은 무효로 처리됩니다.
- 테스트 2개 추가
  - `test_token_expired_at_boundary`: 만료 시각과 정확히 같은 시각에 토큰이 무효로 판단되는지 확인합니다.
  - `test_token_valid_before_expiry`: 만료 시각 이전에는 토큰이 유효한지 확인합니다.
