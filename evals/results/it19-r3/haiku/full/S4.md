# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 이전 리비전으로 되돌리는 절차를 설명한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 확인해야 하며, 마이그레이션이 포함된 배포는 롤백하지 않는다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
   확인 필요: 마이그레이션 포함 여부를 확인하는 방법. 원문에 확인 방법이 없다.
2. **마이그레이션이 포함됐으면 롤백하면 안 된다.** 이 경우 롤백을 진행하지 않고 DBA 박지은에게 연락해야 한다.
   확인 필요: DBA 박지은에게 연락하는 방법. 원문에 연락 수단이 없다.
3. 마이그레이션이 포함되지 않았음을 확인한 뒤에만 다음 단계로 넘어간다.
4. 롤백할 대상 리비전(REVISION) 값을 확인해야 한다.
   확인 필요: REVISION 값을 얻는 방법. 원문에 리비전을 확인하는 방법이 없다.

## 2. 롤백 실행

5. 다음 명령으로 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

## 3. 롤백 후 확인

6. `/healthz`가 200을 반환하는지 확인해야 한다.
7. 결제 테스트 주문 1건이 성공하는지 확인해야 한다.

## 4. 이력 기록

8. 롤백 이력을 #deploy 채널에 남겨야 한다.
