# API 키 관리 지침

1. 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.
2. API 키를 Git 저장소에 커밋하면 안 된다.
3. 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
4. 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.
5. 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.
6. Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.
7. 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

확인 필요: 개발 환경에서 교체한 키도 `prod/api-keys` 경로에 저장해야 하는지 원문만으로는 알 수 없다. 7번 규칙의 "교체한 키"가 운영 키만 가리키는지, 개발 키까지 포함하는지 확인해야 한다.
