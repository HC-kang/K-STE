이 문서는 payment-api 운영 배포를 ArgoCD로 롤백하는 절차를 설명한다.

1. 롤백 전에 반드시 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다. 확인 필요: 마이그레이션 포함 여부를 확인하는 방법과 위치를 정해야 한다.
2. 마이그레이션이 포함됐으면 **롤백하면 안 된다. DBA 박지은에게 연락해야 한다.** 확인 필요: DBA 박지은의 연락 방법을 정해야 한다.
3. 마이그레이션이 포함되지 않은 경우에만 아래 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

   `<REVISION>`에는 롤백할 리비전 번호를 넣는다. 확인 필요: 리비전 번호를 찾는 방법을 정해야 한다.
4. 롤백한 뒤에는 `/healthz`가 200을 반환하는지 확인한다. 확인 필요: 요청할 대상 주소를 정해야 한다.
5. 롤백한 뒤에는 결제 테스트 주문 1건이 성공하는지 확인한다. 확인 필요: 테스트 주문을 만드는 방법을 정해야 한다.
6. 롤백 이력을 #deploy 채널에 남긴다. 확인 필요: 기록에 포함할 항목과 형식을 정해야 한다.
