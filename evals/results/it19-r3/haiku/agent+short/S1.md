Redis를 도입하면 서버 4대가 같은 캐시를 함께 보게 되므로, 서버마다 가격이 다르게 보이는 문제는 없어집니다.

캐시(자주 쓰는 데이터를 빨리 꺼내 쓰려고 잠시 보관해 두는 복사본)는 보관하는 위치에 따라 두 가지로 나뉩니다. 지금 방식인 로컬 캐시는 각 서버가 상품 목록을 자기 메모리(서버가 작업할 때 쓰는 임시 공간)에 5분 동안 보관합니다. Redis(여러 서버가 함께 쓰는 데이터 저장 프로그램)는 서버 바깥에 있는 공용 캐시 서버 1대입니다.

| 구분 | 로컬 캐시 (지금) | Redis 캐시 (도입 예정) |
|---|---|---|
| 캐시 위치 | 서버 4대 각각의 메모리 | 공용 캐시 서버 1대 |
| 서버마다 보는 값 | 서버마다 다를 수 있습니다 | 같은 값을 봅니다 |
| 가격 변경이 고객에게 반영되는 최대 시간 | 5분 | 확인 필요 |

확인 필요: Redis 도입 후 가격 변경이 고객에게 반영되는 시간이 지금의 최대 5분보다 줄어드는지는 현재 알려진 정보로 판단할 수 없습니다.
