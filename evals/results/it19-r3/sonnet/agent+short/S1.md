로컬 캐시는 서버마다 따로 가진 저장소이고, Redis 캐시는 서버 4대가 함께 쓰는 저장소입니다. 캐시는 자주 보여 주는 데이터를 매번 새로 가져오지 않도록 임시로 저장해 두는 곳입니다. 두 방식은 캐시를 어디에 두는지가 다릅니다.

지금은 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 고객 화면에 새 가격이 보이기까지 최대 5분이 걸립니다.

Redis를 도입하면 캐시 서버 1대에 상품 목록을 한 벌만 저장하고, 서버 4대가 그것을 같이 읽습니다. 그래서 서버마다 캐시 내용이 달라지는 문제가 없어집니다. 고객은 어느 서버에 연결되더라도 같은 캐시 내용을 보게 됩니다.
