로컬 캐시는 서버 4대가 각자 따로 저장하는 방식이고, Redis 캐시는 4대가 함께 쓰는 공용 저장소입니다. 캐시는 자주 쓰는 데이터를 빨리 꺼내려고 잠시 저장해 두는 곳입니다.

지금은 서버마다 자기 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 저장한 시점이 달라서 서버마다 내용이 다릅니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 서버 4대가 캐시 서버 1대의 같은 상품 목록을 봅니다. 그래서 서버마다 내용이 달라지는 문제가 없어집니다. 고객 요청이 어느 서버로 가든 같은 가격이 보입니다.

확인 필요: 가격을 바꿀 때 Redis의 상품 목록을 바로 지울지, 5분 만료를 기다릴지 개발팀에 물어봐야 합니다. 5분 만료를 기다리면 가격 반영이 최대 5분 늦어지는 것은 그대로입니다.

단점도 있습니다. Redis는 네트워크로 접근하므로 서버 자기 메모리보다 조금 느립니다. 또 Redis 서버가 1대라서 이 서버가 멈추면 API 서버 4대가 모두 영향을 받을 수 있습니다.
