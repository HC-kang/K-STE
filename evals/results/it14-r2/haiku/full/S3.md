# 토큰 만료 경계에서 유효성 판단 오류 수정

`is_valid()`가 토큰 만료 시각과 정확히 같은 시각의 요청을 유효하다고 판단하던 문제를 수정한다. 비교 조건을 `<=`에서 `<`로 바꿔서, 만료 시각과 같은 시각부터 토큰을 유효하지 않다고 판단하게 한다. 로컬 단위 테스트는 통과했고, 통합 테스트는 아직 실행하지 않았다.

## 배경

`auth/token.py`의 `is_valid()`는 `now <= expires_at`로 유효성을 판단했다. 요청 시각이 토큰 만료 시각과 정확히 같으면 토큰이 유효한 것으로 판단되었다.

## 변경 내용

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다.
- 테스트 2개를 추가했다: `test_token_expired_at_boundary`, `test_token_valid_before_expiry`.

## 테스트

- 로컬 단위 테스트: 모두 통과했다.
- 통합 테스트: 아직 실행하지 않았다.
