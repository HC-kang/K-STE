## 운영 환경 API 키 교체 주기

운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.
개발 환경 API 키에는 90일 교체 규칙을 적용하지 않는다.

## 키 보관과 커밋 금지

API 키를 Git 저장소에 커밋하면 안 된다.
교체한 키는 Vault(API 키 같은 비밀 값을 보관하는 도구)의 `prod/api-keys` 경로에 저장해야 한다.

## 키 교체 시간

키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
장애 대응 중이라면 업무 시간 밖에 키를 교체해도 된다.

## 키 발급

Vault 웹 화면에서 API 키를 직접 발급할 수 있다.

확인 필요: 마지막 규칙의 "교체한 키"가 운영 환경 키만 가리키는지, 개발 환경 키도 포함하는지 확인이 필요합니다. 원문에 범위가 나와 있지 않아 문서에는 원문 그대로 적었습니다.
