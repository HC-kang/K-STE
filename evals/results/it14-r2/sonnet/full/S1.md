차이는 캐시를 서버마다 따로 갖느냐, 서버 4대가 하나를 같이 쓰느냐입니다. 캐시는 자주 쓰는 데이터를 미리 저장해 두는 곳입니다.

지금은 API 서버(고객 요청을 받아 상품 목록을 내주는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 바뀐 가격이 고객에게 최대 5분 늦게 보입니다.

Redis는 캐시를 담아 두는 서버 프로그램입니다. 이번에는 Redis 캐시 서버 1대를 API 서버 4대가 같이 씁니다. 그러면 4대가 같은 상품 목록을 보게 되어, 서버끼리 캐시 내용이 달라지는 일이 없어집니다.
