Redis를 도입하면 서버 4대가 같은 캐시를 함께 쓰므로, 서버마다 상품 목록이 달라지는 문제는 없어집니다. 다만 가격 변경이 고객에게 몇 분 안에 반영되는지는 캐시를 언제 비우는지에 따라 달라지므로 확인이 필요합니다.

로컬 캐시는 각 서버가 자기 메모리(서버가 일할 때 쓰는 임시 작업 공간)에 상품 목록을 따로 보관하는 방식입니다. 지금은 서버 4대가 각자 5분 동안 목록을 보관합니다. 그래서 가격을 바꾸면 서버마다 갱신되는 시점이 달라지고, 고객에게는 최대 5분 늦게 반영됩니다.

Redis 캐시는 서버 바깥에 따로 둔 캐시 전용 서버입니다. Redis는 데이터를 메모리에 올려 두고 여러 서버가 함께 읽고 쓰게 해 주는 저장 프로그램입니다. 서버 4대가 이 한 곳을 같이 보므로, 같은 시점에 같은 상품 목록을 읽게 됩니다.

Redis 서버가 한 대뿐이므로, 이 서버가 멈추면 4대 서버 모두 캐시를 쓸 수 없게 됩니다.

확인 필요: 가격 변경 후 Redis 캐시를 바로 비우는지. 바로 비우면 반영이 즉시에 가까워지고, 기존처럼 5분이 지나야 갱신되면 반영 지연은 그대로 5분입니다.
