# 토큰 만료 시각 경계 비교를 수정한다

`auth/token.py`의 `is_valid()`는 토큰 만료 시각과 정확히 같은 시각의 요청을 유효하다고 판단했다. 이 PR은 비교 조건을 `now < expires_at`로 바꿔 만료 시각 당일 요청을 무효로 처리한다. 관련 이슈는 #412다.

## 원인

토큰 만료 시각과 정확히 같은 시각에 요청하면 `is_valid()`가 토큰을 유효하다고 판단했다. 기존 조건 `now <= expires_at`가 만료 시각 자체를 유효 범위에 포함했다.

## 변경 내용

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다.
- 테스트 2개를 추가했다: `test_token_expired_at_boundary`, `test_token_valid_before_expiry`.

## 검증

- 실행함: 단위 테스트를 로컬에서 실행했고 모두 통과했다.
- 실행하지 않음: 통합 테스트는 아직 실행하지 않았다.
