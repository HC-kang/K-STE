로컬 캐시는 서버마다 따로 갖고 있는 임시 저장소이고, Redis 캐시는 서버 4대가 함께 쓰는 임시 저장소입니다. 캐시(자주 쓰는 데이터를 미리 저장해 두고 빠르게 꺼내 쓰는 방식)라는 점은 둘이 같습니다.

지금은 API 서버 4대가 각자 메모리(서버 안의 작업 공간)에 상품 목록을 5분 동안 저장합니다. 그래서 서버마다 저장된 내용이 다릅니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 캐시 서버 1대를 API 서버 4대가 같이 씁니다. 그래서 고객 요청이 어느 API 서버로 가도 같은 상품 목록을 보게 됩니다.

확인 필요: Redis를 도입해도 상품 목록을 5분 동안 저장하면 가격 반영이 늦어질 수 있습니다. 가격을 바꿀 때 저장된 상품 목록을 바로 지우는 방식을 함께 쓸지는 아직 확인하지 못했습니다.
