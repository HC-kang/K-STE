# 인증 개선 회의록

10월 27일 14:00에 인증 개선 회의를 했다. 인증 서버의 세션 만료 시간을 30분에서 60분으로 늘리기로 했고, 결제 서버의 세션 만료 시간은 30분으로 유지하기로 했다. 할 일은 세 건이다.

## 참석자

박준호, 정은지, 김하늘

## 결정

1. 인증 서버의 세션 만료 시간을 30분에서 60분으로 늘리기로 했다.
2. 결제 서버의 세션 만료 시간은 30분으로 유지하기로 했다.

## 할 일

1. 박준호는 10월 31일까지 인증 서버 설정 파일 `auth.yaml`의 `session_timeout` 값을 바꾼다.
2. 정은지는 11월 1일까지 고객 공지 초안을 쓴다. 공지에는 인증 서버 변경만 넣어야 한다.
3. 김하늘은 11월 2일에 결제 서버 설정이 바뀌지 않았는지 점검한다.
