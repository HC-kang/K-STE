# 인증 개선 회의 회의록

## 개요

- 일시: 10월 27일 14:00
- 참석자: 박준호, 정은지, 김하늘

## 요지

인증 서버의 세션 만료 시간을 30분에서 60분으로 늘리기로 결정했다. 결제 서버의 세션 만료 시간은 30분으로 유지하기로 결정했다. 참석자별 할 일 세 가지를 정했다.

## 결정 사항

1. 인증 서버의 세션 만료 시간을 30분에서 60분으로 늘린다.
2. 결제 서버의 세션 만료 시간은 30분으로 유지한다.

## 할 일

1. 박준호가 인증 서버 설정 파일 auth.yaml의 session_timeout 값을 바꾼다. 기한은 10월 31일이다.
2. 정은지가 고객 공지 초안을 쓴다. 공지에는 인증 서버 변경만 넣는다. 기한은 11월 1일이다.
3. 김하늘이 11월 2일에 결제 서버 설정이 바뀌지 않았는지 점검한다.
