# 운영 배포 롤백 런북

배포 도구는 ArgoCD다. 롤백 명령은 `argocd app rollback payment-api <REVISION>`이다.

## 절차

1. 롤백할 배포에 DB 마이그레이션(데이터베이스 구조를 바꾸는 스크립트)이 포함됐는지 확인한다.
   **경고**: 마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA 박지은에게 연락한다.
2. 마이그레이션이 포함되지 않았으면 `argocd app rollback payment-api <REVISION>` 명령으로 롤백한다.
3. 롤백한 뒤에는 `/healthz`가 200을 반환하는지 확인한다.
4. 롤백한 뒤에는 결제 테스트 주문 1건이 성공하는지 확인한다.
5. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: `<REVISION>`에 넣을 값을 찾는 방법
확인 필요: 배포에 마이그레이션이 포함됐는지 확인하는 방법
확인 필요: `/healthz`가 200을 반환하지 않거나 테스트 주문이 실패할 때 따를 절차
