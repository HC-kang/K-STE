# 토큰 만료 시각 경계에서 만료된 토큰을 유효하다고 판단하던 버그 수정

만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 버그를 고친다. `auth/token.py`의 `is_valid()`에서 비교 연산자를 `<=`에서 `<`로 바꿨다. 관련 이슈는 #412다. 로컬에서 단위 테스트를 실행했고 모두 통과했다. 통합 테스트는 아직 실행하지 않았다.

## 원인

`is_valid()`는 `now <= expires_at`이 참이면 토큰을 유효하다고 판단한다. 현재 시각이 만료 시각과 정확히 같으면 이 조건이 참이 되어, 만료된 토큰이 유효하다고 판단된다.

## 변경 내용

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꾼다.
- 이 변경으로 현재 시각이 만료 시각과 같으면 토큰을 유효하지 않다고 판단한다.
- 테스트 2개를 추가한다.
  - `test_token_expired_at_boundary`는 만료 시각 경계를 검사한다.
  - `test_token_valid_before_expiry`는 만료 시각 이전의 토큰이 유효한지 검사한다.

## 검증 상태

- 로컬 단위 테스트: 모두 통과했다.
- 통합 테스트: 실행하지 않았다.
