# payment-api 운영 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 지정한 리비전(REVISION)으로 롤백하는 절차를 설명한다. 롤백할 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 되고, DBA 박지은에게 연락해야 한다.

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. **경고:** DB 마이그레이션이 포함됐으면 롤백하면 안 된다. 이때 DBA 박지은에게 연락해야 한다.
3. DB 마이그레이션이 포함되지 않았으면 `<REVISION>`에 롤백할 리비전을 넣고 다음 명령을 실행한다.

```
argocd app rollback payment-api <REVISION>
```

## 결과 확인

1. 롤백 후 `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 기록

1. 롤백 이력을 #deploy 채널에 남긴다.

위 런북은 주어진 사실만 반영했다. 마이그레이션 포함 여부를 확인하는 방법, `/healthz` 확인 위치, 결제 테스트 주문 절차, #deploy에 남길 내용의 형식은 주어지지 않아 런북에 쓰지 않았다. 이 내용이 정해지면 해당 단계에 추가하겠다.
