# 토큰 만료 경계 시각에 토큰을 유효하다고 판단하던 문제 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 문제를 고친다. `auth/token.py`의 `is_valid()`에서 비교 연산자를 `now <= expires_at`에서 `now < expires_at`로 바꿨다. 이 변경으로 만료 시각과 같은 시각의 요청은 유효하지 않은 토큰으로 판단한다.

## 배경

토큰 만료 시각과 정확히 같은 시각에 요청이 들어오면 `is_valid()`가 토큰을 유효하다고 판단했다.

## 변경 사항

1. `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다.
2. 경계 시각 테스트 `test_token_expired_at_boundary`를 추가했다.
3. 만료 전 유효성 테스트 `test_token_valid_before_expiry`를 추가했다.

## 테스트

로컬에서 단위 테스트를 실행했고 모두 통과했다. 통합 테스트는 아직 실행하지 않았다.
