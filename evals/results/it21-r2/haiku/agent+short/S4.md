## 1. 마이그레이션 포함 여부 확인

롤백 전에 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

**마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA(데이터베이스 관리자) 박지은에게 연락해야 한다.**

마이그레이션이 포함되지 않은 경우에만 다음 단계로 진행한다.

확인 필요: 마이그레이션 포함 여부를 확인하는 방법과 DBA 박지은의 연락 수단은 입력되지 않았다.

## 2. 롤백 실행

롤백할 리비전 값을 `<REVISION>` 자리에 넣어 다음 명령을 실행한다.

`argocd app rollback payment-api <REVISION>`

확인 필요: 롤백할 리비전 값을 찾는 방법은 입력되지 않았다.

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

확인 필요: 테스트 주문을 만드는 방법과 `/healthz`를 호출하는 주소는 입력되지 않았다. 또한 `/healthz`가 200을 반환하지 않거나 테스트 주문이 실패할 때 따를 절차는 입력되지 않았다.

## 4. 이력 기록

#deploy 채널에 롤백 이력을 남긴다.

확인 필요: 이력에 포함할 항목은 입력되지 않았다.
