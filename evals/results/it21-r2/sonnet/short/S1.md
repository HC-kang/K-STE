Redis를 도입하면 API 서버 4대가 같은 캐시를 보기 때문에, 서버마다 상품 정보가 달라지는 문제가 없어집니다.

로컬 캐시는 API 서버가 자기 메모리(서버 안의 임시 저장 공간)에 따로 보관하는 캐시입니다. 현재 서버 4대는 각자 상품 목록을 5분 동안 보관합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis 캐시는 캐시 전용 서버 1대에 보관하고, API 서버 4대가 함께 사용합니다. 그래서 고객이 어느 서버에 접속하든 같은 상품 목록을 받습니다.

확인 필요: 가격 반영 지연(최대 5분)이 줄어드는지는 가격을 바꿀 때 Redis의 캐시를 바로 지우는지, 5분 만료를 기다리는지에 따라 달라집니다.

확인 필요: Redis 서버가 1대이므로, 이 서버에 문제가 생겼을 때 API 서버 4대가 어떻게 동작하는지 정해져 있는지 확인해야 합니다.
