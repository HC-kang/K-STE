로컬 캐시는 서버 4대가 각자 따로 캐시를 갖는 방식이고, Redis 캐시는 4대가 캐시 한 곳을 함께 쓰는 방식입니다. 캐시는 자주 쓰는 데이터를 임시로 저장해 두는 공간입니다.

지금은 API 서버(요청을 받아 응답하는 서버) 4대가 각자 메모리에 상품 목록을 5분 동안 캐시합니다. 이것이 로컬 캐시입니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버 1대입니다. 도입하면 4대가 같은 캐시를 보게 되므로, 서버마다 캐시 내용이 달라지는 문제가 없어집니다. 그래서 고객이 어느 서버에 연결되느냐에 따라 다른 상품 정보를 보는 일도 없어집니다.
