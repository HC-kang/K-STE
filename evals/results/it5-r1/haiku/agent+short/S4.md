이 런북은 ArgoCD로 배포된 payment-api를 이전 리비전으로 롤백하는 절차를 설명한다. 롤백 전에 해당 배포에 DB 마이그레이션이 포함되었는지 반드시 확인한다.

## 롤백 절차

1. 롤백할 대상 리비전 값을 `<REVISION>`에 준비한다. 확인 필요: 리비전 값을 조회하는 방법이 원문에 없다.
2. 롤백하려는 배포에 DB 마이그레이션이 포함되었는지 확인한다. 확인 필요: 마이그레이션 포함 여부를 확인하는 방법이 원문에 없다.
3. 마이그레이션이 포함되었으면 **마이그레이션이 포함되었으면 롤백하지 않는다.** 이 경우 롤백을 중단하고 DBA 박지은에게 연락한다.
4. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

## 롤백 후 검증

1. `/healthz`가 200을 반환하는지 확인한다. 확인 필요: 확인할 호스트와 주소가 원문에 없다.
2. 결제 테스트 주문 1건을 실행하고 성공하는지 확인한다.
3. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요 사항

- `/healthz`가 200을 반환하지 않을 때 대응 절차가 원문에 없다.
- 결제 테스트 주문이 실패할 때 대응 절차가 원문에 없다.
- 롤백 이력에 포함할 내용과 작성 시점이 원문에 없다.
