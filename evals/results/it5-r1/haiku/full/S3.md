# 토큰 만료 경계 시각 판단 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 문제를 고친다. `auth/token.py`의 `is_valid()`를 수정하고 경계 시각 테스트 2개를 추가한다. 로컬 단위 테스트는 모두 통과했고, 통합 테스트는 아직 실행하지 않았다.

## 배경

수정 전에는 `is_valid()`가 `now <= expires_at` 조건으로 판단했다. 그래서 요청 시각이 만료 시각과 같으면 토큰을 유효하다고 판단했다.

## 변경 사항

`auth/token.py`의 `is_valid()`에서 `now <= expires_at` 조건을 `now < expires_at`로 바꿨다. 이 변경으로 요청 시각이 만료 시각과 같으면 토큰을 유효하지 않다고 판단한다.

## 테스트

- `test_token_expired_at_boundary`를 추가했다.
- `test_token_valid_before_expiry`를 추가했다.
- 로컬에서 단위 테스트를 실행했고 모두 통과했다.
- 통합 테스트는 아직 실행하지 않았다.
