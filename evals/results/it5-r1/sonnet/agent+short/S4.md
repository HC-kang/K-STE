# 운영 배포 롤백 런북

ArgoCD로 배포한 `payment-api`를 이전 리비전으로 되돌리는 절차를 정리한 문서다. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

**마이그레이션이 포함된 배포는 롤백하면 안 된다.**

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았으면 `argocd app rollback payment-api <REVISION>` 명령을 실행한다.
4. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 다음 정보는 주어지지 않아 적지 않았다. `<REVISION>` 값을 찾는 방법, 마이그레이션 포함 여부를 확인하는 방법, 박지은에게 연락하는 수단, #deploy 채널에 남길 내용이다.
