로컬 캐시는 서버 4대가 각자 자기 메모리에 상품 목록을 저장하고, Redis 캐시는 4대가 별도 캐시 서버 1대를 같이 씁니다. 캐시는 자주 쓰는 데이터를 미리 가까이에 저장해 두는 장치입니다.

지금은 서버마다 캐시를 따로 들고 있어서 가격을 바꾸면 고객에게 최대 5분 늦게 반영되고, 같은 시점에 서버에 따라 다른 가격이 보일 수 있습니다. Redis를 도입하면 캐시가 한 곳에만 있으므로 4대가 항상 같은 상품 목록을 보여 줍니다.

가격을 바꿀 때 Redis의 캐시를 바로 갱신하거나 지우면 4대 모두에 같은 시점에 반영됩니다. 확인 필요: 가격을 바꿀 때 Redis 캐시를 바로 갱신하도록 만드는지는 개발팀에 확인해야 합니다. 갱신하지 않으면 캐시 보관 시간이 5분이므로 지금처럼 최대 5분 뒤에 반영될 수 있습니다.

Redis 서버는 1대라서, 이 서버가 멈추면 공유 캐시를 쓸 수 없습니다. 확인 필요: Redis가 멈췄을 때 서비스가 어떻게 동작하는지 개발팀에 확인해야 합니다.
