로컬 캐시는 서버마다 따로 가진 임시 저장소이고, Redis는 서버 4대가 함께 쓰는 공용 임시 저장소입니다. 캐시는 자주 쓰는 데이터를 임시로 저장해 두고 다시 꺼내 쓰는 방식입니다.

지금은 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 저장한 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 서버 4대가 캐시 서버 1대를 같이 씁니다. 서버마다 캐시 내용이 달라지는 문제가 없어지고, 고객은 어느 서버로 연결되어도 같은 상품 목록을 보게 됩니다.

다만 가격 변경이 바로 반영되는지는 별도 문제입니다. 가격을 바꿀 때 캐시를 바로 지우는 동작을 넣어야 지연이 줄어듭니다. 확인 필요: 이번 Redis 도입 범위에 이 동작이 들어 있는지.
