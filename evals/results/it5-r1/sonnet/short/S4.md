운영 배포를 롤백할 때는 ArgoCD에서 `payment-api`를 지정한 리비전으로 되돌린 뒤, 상태를 확인하고 #deploy 채널에 이력을 남긴다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않는다. **마이그레이션이 포함된 배포는 롤백하면 안 된다.**
3. 마이그레이션이 포함됐으면 DBA 박지은에게 연락한다.

## 롤백

마이그레이션이 포함되지 않았을 때만 아래 명령을 실행한다. `<REVISION>`에는 되돌릴 리비전을 넣는다.

```
argocd app rollback payment-api <REVISION>
```

## 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 기록

롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 박지은에게 연락하는 방법(채널, 전화 등)과 `<REVISION>` 값을 확인하는 방법은 제공된 사실에 없어 적지 않았습니다.
