로컬 캐시는 각 서버 안에 자주 쓰는 데이터를 임시로 저장하는 방식이고, Redis 캐시는 4대 서버가 함께 쓰는 별도 캐시 서버에 같은 데이터를 저장하는 방식입니다.

| 구분 | 로컬 캐시 (지금 방식) | Redis 캐시 (도입 예정) |
|---|---|---|
| 저장 위치 | 각 서버의 메모리(서버가 작업할 때 쓰는 공간) | 4대 서버가 함께 쓰는 캐시 서버 1대 |
| 서버 간 내용 | 서버마다 따로 저장하므로 내용이 달라질 수 있습니다 | 4대 서버가 같은 내용을 봅니다 |
| 조회 속도 | 가장 빠릅니다 | 네트워크를 한 번 거치므로 로컬 캐시보다 느립니다 |

Redis를 도입하면 서버 4대가 같은 상품 목록을 보므로, 서버마다 가격이 다르게 나오는 문제가 없어집니다.

다만 Redis에서도 캐시 유지 시간을 5분으로 두면 가격 반영은 여전히 최대 5분 늦을 수 있습니다. 확인 필요: 가격을 바꿨을 때 Redis 캐시를 바로 지우는지, 아니면 5분이 지나야 지워지는지.
