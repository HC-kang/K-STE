이 런북은 ArgoCD로 배포한 payment-api를 이전 리비전으로 롤백하는 절차를 설명한다.

## 1. 롤백 전 확인

1. 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 확인한다. 확인 필요: 마이그레이션 포함 여부를 확인하는 위치와 방법.
2. **마이그레이션이 포함됐으면 롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락해야 한다.
3. 마이그레이션이 포함되지 않았음을 확인한 경우에만 2절의 롤백 명령을 실행한다.

## 2. 롤백 실행

1. 롤백할 리비전 값(REVISION)을 확인한다. 확인 필요: REVISION 값을 찾는 위치와 방법.
2. 다음 명령의 `<REVISION>`에 1번에서 확인한 값을 넣어 실행한다.

```
argocd app rollback payment-api <REVISION>
```

## 3. 롤백 후 검증

1. `/healthz`가 200을 반환하는지 확인한다. 확인 필요: `/healthz`의 전체 주소와 호출 방법.
2. 결제 테스트 주문 1건을 진행하여 성공하는지 확인한다. 확인 필요: 테스트 주문을 넣는 방법과 사용할 테스트 환경.

## 4. 이력 기록

1. 롤백 이력을 #deploy 채널에 남긴다. 확인 필요: 이력에 포함할 항목과 작성 형식.
