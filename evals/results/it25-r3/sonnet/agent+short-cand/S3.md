`auth/token.py`의 `is_valid()`가 토큰 만료 시각과 정확히 같은 시각의 요청을 유효하다고 판단하던 버그를 고친다. 관련 이슈는 #412다.

## 변경 내용

- `is_valid()`의 조건 `now <= expires_at`를 `now < expires_at`로 바꿨다.
- 테스트 `test_token_expired_at_boundary`를 추가했다.
- 테스트 `test_token_valid_before_expiry`를 추가했다.

## 테스트

- 로컬에서 단위 테스트를 실행했고 모두 통과했다.
- 통합 테스트는 아직 실행하지 않았다.
