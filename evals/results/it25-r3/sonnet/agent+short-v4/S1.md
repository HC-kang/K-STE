로컬 캐시는 서버마다 따로 가진 임시 저장소이고, Redis 캐시는 서버 4대가 함께 보는 저장소입니다. Redis를 도입하면 4대가 같은 캐시 내용을 보게 됩니다.

현재는 API 서버 4대가 각자 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 저장한 시점이 달라서 캐시 내용도 서로 다릅니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 캐시 서버 1대를 따로 두고 서버 4대가 그 서버 하나를 같이 쓰는 방식입니다. 서버 4대가 같은 상품 목록을 읽으므로 서버마다 가격이 다르게 보이는 일이 줄어듭니다.

가격 지연도 줄일 수 있습니다. 가격을 바꿀 때 Redis에 저장된 상품 목록을 한 번 갱신하거나 지우면 4대가 모두 새 가격을 읽습니다. 다만 Redis를 도입하는 것만으로 5분 지연이 없어지지는 않습니다. 가격을 바꿀 때 캐시를 어떻게 갱신할지는 개발팀과 함께 정해야 합니다.
