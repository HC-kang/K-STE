# 운영 payment-api 배포 롤백 런북

이 런북은 ArgoCD로 배포한 payment-api 운영 배포를 지정한 리비전으로 되돌리는 절차를 정의한다. 아래 순서를 건너뛰면 안 된다.

## 1. 롤백 전 확인

롤백 대상 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. **마이그레이션이 포함됐으면 롤백하면 안 된다.** 이 경우 DBA 박지은에게 연락해야 한다.

확인 필요: 마이그레이션 포함 여부를 확인하는 방법이 주어지지 않았다.
확인 필요: DBA 박지은에게 연락하는 수단이 주어지지 않았다.

## 2. 롤백 실행

롤백은 아래 명령으로 실행한다.

```
argocd app rollback payment-api <REVISION>
```

`<REVISION>`에는 롤백 대상 리비전 값을 넣는다. 확인 필요: 리비전 값을 확인하는 방법이 주어지지 않았다.

## 3. 롤백 후 검증

롤백 후 다음 두 가지를 확인한다.

1. `/healthz`가 200을 반환하는지 확인한다. 확인 필요: 요청을 보낼 주소가 주어지지 않았다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다. 확인 필요: 테스트 주문을 만드는 방법과 테스트 계정이 주어지지 않았다.

## 4. 이력 기록

롤백 이력은 #deploy 채널에 남긴다. 확인 필요: 기록 형식과 기록을 맡을 담당자가 주어지지 않았다.
