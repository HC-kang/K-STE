토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 버그를 수정한다.

기존 `is_valid()`는 `now <= expires_at` 조건을 사용하여 만료 시각과 같은 시각의 토큰도 유효하다고 판단하였다.

변경 내용은 다음과 같다.

- `auth/token.py`의 `is_valid()`에서 조건을 `now <= expires_at`에서 `now < expires_at`로 바꾼다.
- 테스트 `test_token_expired_at_boundary`를 추가한다.
- 테스트 `test_token_valid_before_expiry`를 추가한다.

검증 상태는 다음과 같다.

- 로컬에서 단위 테스트를 실행하였고 모두 통과하였다.
- 통합 테스트는 아직 실행하지 않았다.
