# payment-api 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 payment-api 운영 배포를 롤백하는 절차를 정한다. 롤백 전에 DB 마이그레이션 포함 여부를 확인하고, 롤백 후에 `/healthz`와 결제 테스트 주문으로 결과를 확인한다. 롤백 이력은 #deploy 채널에 남긴다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. **경고: DB 마이그레이션이 포함된 배포는 롤백하면 안 된다.**
3. 마이그레이션이 포함됐으면 롤백을 멈추고 DBA 박지은에게 연락해야 한다.
4. 마이그레이션이 포함되지 않았으면 다음 절차로 진행한다.

## 롤백 실행

5. `argocd app rollback payment-api <REVISION>` 명령을 실행한다. `<REVISION>` 자리에 롤백 대상 리비전을 넣는다.

## 롤백 후 확인

6. `/healthz` 응답이 200인지 확인한다.
7. 결제 테스트 주문을 1건 실행하고, 그 주문이 성공하는지 확인한다.

## 이력 기록

8. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 마이그레이션 포함 여부를 확인하는 방법. 확인할 위치와 판단 기준이 주어진 사실에 없다.
확인 필요: `/healthz` 응답이 200이 아니거나 결제 테스트 주문이 실패했을 때의 조치. 주어진 사실에 실패 시 절차가 없다.
확인 필요: DBA 박지은에게 연락하는 방법. 연락 채널과 연락처가 주어진 사실에 없다.
