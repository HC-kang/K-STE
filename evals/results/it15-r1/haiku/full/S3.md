# 토큰 만료 시각 경계에서 만료된 토큰을 유효하다고 판단하는 버그 수정

## 요약

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하는 버그를 수정한다. `auth/token.py`의 `is_valid()`에서 만료 비교를 `now <= expires_at`에서 `now < expires_at`로 바꾼다. 이 변경으로 만료 시각과 같은 시각의 토큰은 더 이상 유효하다고 판단되지 않는다.

## 변경 사항

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꾼다.
- `test_token_expired_at_boundary`와 `test_token_valid_before_expiry` 테스트 2개를 추가한다.

## 테스트

- 로컬에서 단위 테스트를 실행했고, 모두 통과했다.
- 통합 테스트는 아직 실행하지 않았다. 이 PR은 통합 테스트 결과 없이 올라간 상태다.
