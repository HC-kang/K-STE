# `is_valid()`의 만료 시각 경계 비교 수정

토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단하던 버그를 고쳤다. `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다. 통합 테스트는 아직 돌리지 않았다.

## 변경 내용

- 버그: 토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰을 유효하다고 판단했다.
- 수정: `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다.

## 테스트

- 테스트 2개를 추가했다: `test_token_expired_at_boundary`, `test_token_valid_before_expiry`.
- 로컬에서 단위 테스트는 모두 통과했다.
- 통합 테스트는 아직 돌리지 않았다.
