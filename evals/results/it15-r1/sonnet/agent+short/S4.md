# 운영 배포 롤백 런북

이 문서는 ArgoCD로 배포한 `payment-api`의 운영 배포를 롤백하는 절차를 설명한다. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

## 사전 규칙

- 롤백 전에 롤백할 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.
- 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다.

**경고: DB 마이그레이션이 포함된 배포는 롤백하면 안 된다. DBA 박지은에게 연락한다.**

## 절차

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. DB 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다.
3. DB 마이그레이션이 포함되지 않았으면 다음 명령을 실행한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백한 뒤 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. #deploy 채널에 롤백 이력을 남긴다.
