로컬 캐시는 서버 4대가 각자 따로 가진 메모장이고, Redis 캐시는 4대가 함께 보는 공용 메모장입니다.

지금은 서버마다 상품 목록을 자기 메모리(서버 안의 임시 저장 공간)에 5분 동안 보관합니다. 서버마다 저장한 시점이 달라서 같은 상품의 가격이 서버에 따라 다르게 보일 수 있습니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 캐시 서버 1대를 API 서버 4대가 같이 씁니다. 4대가 같은 내용을 보므로 서버마다 가격이 다르게 보이는 문제가 사라집니다.

Redis만 도입해서는 최대 5분 지연이 자동으로 없어지지 않습니다. 보관 시간을 5분으로 그대로 두면 가격 반영도 최대 5분 늦을 수 있습니다. 가격을 바꿀 때 캐시를 바로 지우는 기능을 함께 만들어야 지연이 줄어듭니다. 이 기능을 이번 도입 범위에 넣을지는 개발팀과 정해야 합니다.

캐시 서버가 1대이므로, 이 서버가 멈추면 API 서버 4대가 모두 공용 캐시를 쓰지 못합니다.
