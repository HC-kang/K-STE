1. 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙은 예외 없이 지켜야 한다.
2. API 키를 Git 저장소에 커밋하면 안 된다.
3. 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
4. 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.
5. 개발 환경 API 키는 90일 교체 규칙을 따르지 않아도 된다.
6. Vault(비밀 값을 저장하고 관리하는 도구)의 웹 화면에는 키를 직접 발급하는 기능이 있다.
7. 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

확인 필요: 3번 업무 시간 권장이 운영 환경 키에만 적용되는지, 개발 환경 키에도 적용되는지 원문에서 알 수 없습니다. 4번 장애 예외도 같은 범위로 적용되는지 확인해 주시기 바랍니다.
