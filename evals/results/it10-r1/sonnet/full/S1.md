로컬 캐시는 서버마다 따로 갖는 임시 저장소이고, Redis 캐시는 서버 4대가 함께 쓰는 임시 저장소입니다. 캐시는 자주 쓰는 데이터를 미리 저장해 두고 다시 꺼내 쓰는 방식입니다. Redis는 이 캐시를 맡는 전용 서버 프로그램입니다.

지금은 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객 화면에 바뀐 가격이 보이기까지 최대 5분이 걸립니다.

Redis를 도입하면 캐시 서버 1대를 API 서버 4대가 같이 씁니다. 서버 4대가 같은 캐시 내용을 읽으므로, 고객이 어느 서버에 연결되는지에 따라 상품 목록이 달라지는 일이 없어집니다.

최대 5분의 지연이 줄어드는지는 Redis 캐시의 보관 시간과 갱신 방식에 따라 달라집니다.
