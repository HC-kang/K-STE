# 운영 배포 롤백 런북

이 문서는 ArgoCD로 `payment-api`의 운영 배포를 이전 리비전으로 롤백하는 절차를 설명한다.

## 사전 확인

롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

## 절차

1. **경고:** 롤백할 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다. 이때 DBA 박지은에게 연락한다.
2. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

3. `/healthz`가 200을 반환하는지 확인한다.
4. 결제 테스트 주문 1건이 성공하는지 확인한다.
5. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요

- `<REVISION>` 값을 어디서 찾는지 원문에 없다.
- 3번이나 4번이 실패하면 어떻게 하는지 원문에 없다.
- 박지은에게 연락하는 방법과 5번에 남길 내용이 원문에 없다.
