# API 키 관리 지침

## 교체

- 운영 환경 API 키는 90일마다 교체한다. 이 규칙은 예외 없이 지켜야 한다.
- 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.
- 키 교체는 평일 업무 시간(10:00-18:00)에 하기를 권장한다.
- 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.

## 보관

- API 키를 Git 저장소에 커밋하면 안 된다.
- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.

## 참고

- Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.

확인 필요: Vault 웹 화면의 직접 발급 기능을 키 교체에 사용해도 되는지 원문에 없다. 사용 가능 여부나 권장 여부를 정해 주면 "참고" 항목에 규칙으로 쓴다.
