캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: "캐시 서버와 API 서버는 ~ 재시작하면 초기화됩니다". 초기화되는 것이 두 서버 모두인지 캐시 서버만인지, 서버 자체인지 서버 메모리의 데이터인지 알 수 없습니다.
확인 필요: "관리자 권한이 있는 팀원 및 QA 담당자". 관리자 권한 조건이 팀원에게만 걸리는지, 팀원과 QA 담당자 모두에게 걸리는지 알 수 없습니다.
확인 필요: "공지 채널에 알려야 합니다". 무엇을 알리는지 원문에 없습니다. 배포 일정인지, 재시작에 따른 초기화인지 알 수 없습니다.
