캐시 서버와 API 서버는 메모리를 많이 사용합니다. 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전에 공지 채널에 알려야 합니다.

확인 필요: "초기화됩니다". 초기화되는 대상이 메모리인지 캐시 데이터인지, 두 서버 모두인지 알 수 없습니다.
확인 필요: "관리자 권한이 있는 팀원 및 QA 담당자". 관리자 권한 조건이 QA 담당자에게도 적용되는지, 팀원에게만 적용되는지 알 수 없습니다.
확인 필요: "공지 채널에 알려야 합니다". 알려야 할 내용(배포 일정, 재시작 여부 등)이 원문에 없습니다.
