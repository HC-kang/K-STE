로컬 캐시는 서버마다 따로 갖는 임시 저장소이고, Redis 캐시는 서버 4대가 함께 쓰는 임시 저장소입니다.

지금은 서버 4대가 각자 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 캐시 내용이 달라서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 서버 4대가 같이 쓰는 캐시 서버 1대입니다. 4대가 같은 캐시를 읽으므로 서버마다 내용이 달라지는 문제가 없어집니다. 가격을 바꿀 때 Redis의 상품 목록 캐시를 바로 갱신하도록 만들면, 변경이 4대 모두에 같은 시점에 반영됩니다.

Redis 서버가 1대이므로, 이 서버가 멈추면 4대 모두 Redis 캐시를 쓸 수 없습니다. 이때 서비스에 미치는 영향은 아직 확인하지 않았습니다.
