## 요약
토큰 만료 시각과 정확히 같은 시각에 요청하면 토큰이 유효한 것으로 판단되던 경계값 버그를 수정합니다.

## 문제
`auth/token.py`의 `is_valid()`가 `now <= expires_at`로 비교하고 있어, 요청 시각이 `expires_at`과 정확히 같을 때도 만료된 토큰을 유효하다고 판단했습니다.

## 변경 사항
- `auth/token.py`: `is_valid()`의 비교 연산자를 `now <= expires_at`에서 `now < expires_at`로 변경했습니다. 이제 만료 시각 정각부터 토큰이 무효로 처리됩니다.
- 테스트 추가
  - `test_token_expired_at_boundary`: 만료 시각 정각에 토큰이 무효인지 확인합니다.
  - `test_token_valid_before_expiry`: 만료 시각 이전에는 토큰이 유효한지 확인합니다.
