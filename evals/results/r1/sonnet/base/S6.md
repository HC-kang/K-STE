**[공지] 배포 전 사전 안내 요청**

캐시 서버와 API 서버는 메모리 사용량이 많으며, 배포 후 재시작 시 초기화됩니다. 관리자 권한을 가진 팀원과 QA 담당자는 배포 전에 반드시 공지 채널에 알려 주시기 바랍니다.

**수정 포인트**
- "메모리를 많이 사용하며" → "메모리 사용량이 많으며": 더 자연스러운 표현
- "재시작하면 초기화됩니다" → "재시작 시 초기화됩니다": 간결하게 정리
- "알려야 합니다" → "반드시 ... 알려 주시기 바랍니다": 공지 어조에 맞게 정중하고 명확하게 수정
