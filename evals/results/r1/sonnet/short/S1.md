Redis를 도입하면 서버 4대가 같은 캐시를 읽어서, 서버마다 상품 목록이 다르게 보이는 문제가 없어집니다. 캐시는 자주 쓰는 데이터를 빠르게 꺼내려고 임시로 보관해 두는 곳입니다.

지금의 로컬 캐시는 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 보관하는 방식입니다. 서버마다 캐시 내용이 다를 수 있어서, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis는 서버 4대가 함께 쓰는 캐시 서버 1대입니다. 4대가 같은 캐시를 보기 때문에, 같은 시점에 어떤 서버에 접속하느냐에 따라 고객이 다른 가격을 보는 일이 없어집니다.

다만 가격 변경이 즉시 반영되는지는 아직 알 수 없습니다. 가격을 바꿀 때 캐시를 바로 비우도록 만들면 즉시 반영할 수 있습니다. 5분 만료만 유지하면 최대 5분 지연이 그대로 남을 수 있습니다.

확인 필요: 이번 Redis 도입에 가격 변경 시 캐시를 바로 비우는 동작이 포함되는지 개발팀에 확인해야 합니다.
