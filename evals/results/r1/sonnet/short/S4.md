운영 배포는 ArgoCD로 롤백하며, 롤백 전에 해당 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다.

**마이그레이션이 포함된 배포는 롤백하면 안 된다.**

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. 마이그레이션이 포함됐으면 롤백하지 않고 DBA 박지은에게 연락한다. 이 경우 아래 단계는 하지 않는다.
3. 마이그레이션이 포함되지 않았으면 다음 명령으로 롤백한다. `<REVISION>`에는 되돌릴 리비전을 넣는다.

   ```
   argocd app rollback payment-api <REVISION>
   ```

4. 롤백이 끝나면 `/healthz`가 200을 반환하는지 확인한다.
5. 결제 테스트 주문 1건이 성공하는지 확인한다.
6. 롤백 이력을 #deploy 채널에 남긴다.

확인 필요: 4단계나 5단계가 실패했을 때의 조치와, 마이그레이션 포함 여부를 확인하는 구체적인 방법은 제공된 사실에 없으므로 추가해야 한다.
