# API 키 관리 지침

이 문서는 운영 환경과 개발 환경의 API 키 교체 주기, 교체 시간, 저장 위치, Git 커밋 금지 규칙을 정한다.

## 교체 주기

- 운영 환경 API 키는 90일마다 교체해야 한다. 이 규칙에는 예외가 없다.
- 개발 환경 API 키는 90일 교체 규칙을 지키지 않아도 된다.

## 교체 시간

- 키 교체는 평일 업무 시간(10:00-18:00)에 하는 것을 권장한다.
- 장애 대응 중이면 업무 시간 밖에 키를 교체해도 된다.

## 저장과 보관

- 교체한 키는 Vault의 `prod/api-keys` 경로에 저장해야 한다.
- API 키를 Git 저장소에 커밋하면 안 된다.

## 키 발급

Vault 웹 화면에는 키를 직접 발급하는 기능이 있다.

확인 필요: Vault 웹 화면의 키 발급 기능을 쓰는 것이 의무인지, 권장인지, 허용인지 원문에 없다. 문서에 이 기능을 쓰는 규칙을 넣으려면 강도를 알려 주기 바란다.
