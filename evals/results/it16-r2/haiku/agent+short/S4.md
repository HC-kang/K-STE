# 운영 배포 롤백 런북

이 런북은 운영 환경의 `payment-api`를 ArgoCD로 이전 리비전으로 되돌리는 절차를 정한다. 롤백 대상 배포에 DB 마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 DBA 박지은에게 연락해야 한다.

## 사전 확인

1. 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
2. **경고:** 마이그레이션이 포함됐으면 롤백하면 안 된다. DBA 박지은에게 연락해야 한다.

확인 필요: 롤백 대상 배포에 DB 마이그레이션이 포함됐는지 확인하는 방법. 주어진 사실에 확인 방법이 없다.

## 롤백 절차

1. 다음 명령의 `<REVISION>` 자리에 되돌릴 리비전을 넣어 실행한다.

```
argocd app rollback payment-api <REVISION>
```

## 결과 확인

1. `payment-api`의 `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건을 진행하고, 그 주문이 성공하는지 확인한다.

확인 필요: 결제 테스트 주문 1건을 만드는 방법. 주어진 사실에 실행 방법과 환경이 없다.
