캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: '재시작하면 초기화됩니다'. 메모리에 있던 데이터가 지워진다는 뜻인지, 서버 자체가 초기 상태로 돌아간다는 뜻인지 정해지지 않았습니다.
확인 필요: '관리자 권한이 있는 팀원 및 QA 담당자'. '관리자 권한이 있는'이 팀원에만 걸리는지, QA 담당자에도 걸리는지 정해지지 않았습니다.
확인 필요: '배포 전 공지 채널에 알려야 합니다'. 무엇을 알려야 하는지 원문에 없습니다.
