이 런북은 ArgoCD로 배포한 payment-api를 이전 리비전으로 롤백하는 절차를 설명한다.

## 1. 롤백 전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인해야 한다.
2. 마이그레이션이 포함됐으면 롤백하면 안 된다.
3. 마이그레이션이 포함됐으면 DBA 박지은에게 연락해야 한다.
4. 마이그레이션이 포함되지 않았으면 2단계로 넘어간다.

## 2. 롤백 실행

1. `argocd app rollback payment-api <REVISION>` 명령을 실행한다.
2. `<REVISION>`에는 롤백할 대상 리비전 값을 넣는다.

## 3. 롤백 후 확인

1. `/healthz`가 200을 반환하는지 확인한다.
2. 결제 테스트 주문 1건이 성공하는지 확인한다.

## 4. 이력 기록

1. 롤백 이력을 #deploy 채널에 남긴다.

## 확인 필요

- 확인 필요: 마이그레이션 포함 여부를 확인하는 도구나 위치가 주어지지 않았다.
- 확인 필요: `<REVISION>` 값을 찾는 방법이 주어지지 않았다.
- 확인 필요: `/healthz` 확인 대상 주소가 주어지지 않았다.
- 확인 필요: 결제 테스트 주문을 실행하는 방법이 주어지지 않았다.
- 확인 필요: 3단계에서 `/healthz`가 200을 반환하지 않거나 테스트 주문이 실패할 때의 조치가 주어지지 않았다.
- 확인 필요: #deploy 채널에 남길 이력 항목이 주어지지 않았다.
