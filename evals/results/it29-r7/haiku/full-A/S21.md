# 파일 공유 규정

이 규정은 사내 위키에 파일을 올리고 외부와 공유할 때 적용하는 기준을 정한다. 첨부 파일 크기, 게시물당 파일 수, 외부 공유 링크를 만들 수 있는 자격, 비밀번호 입력 제한, 외부 공유 링크의 유효 기간을 다룬다.

## 첨부 파일 크기

첨부 파일 하나의 크기는 25MB 이하여야 한다. 25MB를 넘는 첨부 파일은 업로드가 차단된다.

## 게시물당 파일 수

한 게시물에 올리는 파일은 10개 이하여야 한다.

## 외부 공유 링크 자격

만 19세 미만인 인턴은 외부 공유 링크를 만들면 안 된다.

## 비밀번호 입력 제한

비밀번호를 5번 연속 틀리면 계정이 30분 동안 잠긴다.

## 외부 공유 링크 유효 기간

외부 공유 링크는 만든 시각부터 72시간이 지나면 닫힌다.
