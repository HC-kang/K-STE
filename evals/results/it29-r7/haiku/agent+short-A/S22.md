# 환불 기준

고객센터 상담원은 환불 요청을 받으면 아래 네 가지 기준으로 환불 여부와 정산 월을 정한다.

1. 가입한 뒤 7일 안에 해지하면 전액 환불한다.
2. 10월 31일 이후에 들어온 환불 신청은 11월 정산에 넣는다.
3. 환불 금액이 50만 원을 넘으면 팀장 승인을 받아야 한다.
4. 상담 대기 고객이 20명이 되면 상담원을 더 배치한다.

확인 필요: "10월 31일 이후에 들어온". 10월 31일 당일에 들어온 신청이 이 기준에 포함되는지 사실에 없다.

확인 필요: "상담원을 더 배치한다". 배치를 맡는 주체와 추가로 배치하는 인원 수가 사실에 없다.
