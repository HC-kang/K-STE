로컬 캐시와 Redis 캐시의 차이는 캐시(자주 쓰는 데이터를 미리 담아 두는 임시 저장 공간)를 어디에 두느냐입니다. 로컬 캐시는 각 API 서버 안의 메모리에 두고, Redis 캐시는 서버 밖에 따로 둔 캐시 전용 서버(Redis)에 둡니다.

지금은 API 서버 4대가 각자 상품 목록을 5분 동안 캐시합니다. 서버마다 캐시 내용이 달라서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis를 도입하면 API 서버 4대가 캐시 서버 1대를 함께 씁니다. 그래서 4대가 같은 상품 정보를 보게 되고, 서버마다 캐시 내용이 달라지는 문제는 없어집니다. 다만 가격 변경이 고객에게 최대 몇 분 안에 반영되는지는 이번 정보만으로는 확인하지 않았습니다.
