로컬 캐시는 서버 4대가 각자 따로 갖고 있는 저장 공간이고, Redis 캐시는 서버 4대가 함께 쓰는 저장 공간 1개입니다. 캐시(자주 쓰는 데이터를 미리 저장해 두고 꺼내 쓰는 방식)는 두 방식 모두 상품 목록을 저장하는 데 씁니다.

현재 로컬 캐시는 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 그래서 서버마다 캐시 내용이 다를 수 있습니다. 가격을 바꾸면 어떤 서버는 새 가격을, 다른 서버는 옛 가격을 보여 줄 수 있고, 고객에게 최대 5분 늦게 반영됩니다.

Redis(여러 서버가 함께 쓰는 캐시 전용 서버)는 캐시 서버 1대로 도입할 예정입니다. 서버 4대가 이 1대의 캐시를 같이 읽고 씁니다. 그래서 서버마다 캐시 내용이 달라지는 문제가 없어지고, 어느 서버에 접속해도 고객이 같은 상품 목록을 봅니다.

주의할 점이 하나 있습니다. 캐시 서버가 1대이므로 이 서버가 멈추면 API 서버 4대가 모두 캐시를 쓰지 못할 수 있습니다.

확인 필요: Redis 도입 후 가격 변경이 고객에게 반영되기까지 걸리는 시간. 현재 정보에는 이 시간이 정해져 있지 않습니다.
