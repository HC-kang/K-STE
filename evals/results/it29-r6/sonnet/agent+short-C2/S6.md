캐시 서버와 API 서버는 메모리를 많이 사용하며, 배포 후 재시작하면 초기화됩니다. 관리자 권한이 있는 팀원 및 QA 담당자는 배포 전 공지 채널에 알려야 합니다.

확인 필요: '배포 후 재시작하면 초기화됩니다'. 초기화되는 대상이 원문에 없습니다. 캐시 서버와 API 서버 둘 다인지, 캐시 서버의 메모리나 데이터인지 정해지지 않았습니다.
확인 필요: '관리자 권한이 있는 팀원 및 QA 담당자'. "관리자 권한이 있는"이 팀원만 꾸미는지, QA 담당자까지 꾸미는지 정해지지 않았습니다.
확인 필요: '배포 전 공지 채널에 알려야 합니다'. 알릴 내용이 원문에 없습니다. 또한 "배포 전"이 알리는 시점인지 "공지 채널"의 수식어인지 정해지지 않았습니다.
