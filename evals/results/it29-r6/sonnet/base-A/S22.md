# 환불 기준 (상담원용)

## 1. 전액 환불
- 가입일로부터 **7일 이내**에 해지하면 **전액 환불**합니다.

## 2. 정산 시점
- **10월 31일 이후**에 접수된 환불 신청은 **11월 정산**에 포함합니다.

## 3. 승인 절차
- 환불 금액이 **50만 원을 초과**하면 **팀장 승인**을 받아야 합니다.

## 4. 상담 대기 시 인력 배치
- 상담 대기 고객이 **20명**이 되면 상담원을 **추가 배치**합니다.

---

**빠른 확인표**

| 상황 | 처리 |
|---|---|
| 가입 후 7일 이내 해지 | 전액 환불 |
| 10월 31일 이후 환불 신청 접수 | 11월 정산에 포함 |
| 환불 금액 50만 원 초과 | 팀장 승인 필요 |
| 상담 대기 20명 | 상담원 추가 배치 |

---

참고: 제공해주신 내용에는 "7일 이내" 기준일(가입일 포함 여부)과 "50만 원" 정확히 일치할 때의 처리, 7일 초과 해지 시 환불 기준이 없어 문서에 넣지 않았습니다. 필요하시면 해당 내용을 알려주세요.
