# 파일 공유 규정

이 문서는 사내 위키에서 파일을 첨부하고 외부와 공유할 때 적용하는 규칙을 정한다. 첨부 파일 용량, 게시물당 파일 수, 외부 공유 링크를 만들 수 있는 대상, 로그인 실패 시 계정 잠금, 외부 공유 링크의 유효 기간을 다룬다.

## 첨부 파일 용량

첨부 파일 하나의 크기가 25MB를 넘으면 시스템이 업로드를 막는다.

## 게시물당 첨부 파일 수

한 게시물에는 파일을 10개까지 첨부할 수 있다.

## 외부 공유 링크 생성 대상

만 19세 미만인 인턴은 외부 공유 링크를 만들면 안 된다.

## 로그인 실패 시 계정 잠금

비밀번호를 5번 연속 틀리면 시스템이 계정을 30분 동안 잠근다.

## 외부 공유 링크 유효 기간

외부 공유 링크는 만든 시각부터 72시간이 지나면 닫힌다.
