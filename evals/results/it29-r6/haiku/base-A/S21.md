# 파일 공유 규정

## 1. 목적

이 문서는 사내에서 파일을 업로드하고 외부와 공유할 때 지켜야 할 기준을 정한다.

## 2. 파일 업로드 기준

### 2.1 파일 크기
- 첨부 파일 하나의 크기가 **25MB를 초과하면 업로드할 수 없다.**

### 2.2 게시물당 파일 수
- 한 게시물에는 파일을 **최대 10개**까지 첨부할 수 있다.

## 3. 외부 공유 링크

### 3.1 외부 공유 링크 생성 제한
- **만 19세가 되지 않은 인턴은 외부 공유 링크를 만들 수 없다.**

### 3.2 외부 공유 링크 유효 기간
- 외부 공유 링크는 **생성 시각부터 72시간**이 지나면 자동으로 닫힌다.

## 4. 계정 보안

### 4.1 비밀번호 오류 잠금
- 비밀번호를 **5번 연속 잘못 입력하면** 계정이 **30분 동안 잠긴다.**
