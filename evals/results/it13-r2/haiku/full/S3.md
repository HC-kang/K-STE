# 토큰 만료 시각과 같은 시각의 유효성 판정 수정

요청 시각이 토큰 만료 시각(`expires_at`)과 정확히 같을 때 토큰을 유효하다고 판단하던 버그를 수정한다. `auth/token.py`의 `is_valid()`에서 비교 연산자를 `<=`에서 `<`로 바꿨다.

## 원인

`is_valid()`는 `now <= expires_at`로 판정했다. 그래서 요청 시각이 만료 시각과 같으면 토큰이 유효한 것으로 판단되었다.

## 변경 사항

- `auth/token.py`의 `is_valid()`에서 `now <= expires_at`를 `now < expires_at`로 바꿨다.
- 테스트 2개를 추가했다: `test_token_expired_at_boundary`, `test_token_valid_before_expiry`.

## 테스트

- 로컬에서 단위 테스트는 모두 통과했다.
- 통합 테스트는 아직 실행하지 않았다.
