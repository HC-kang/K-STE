로컬 캐시와 Redis 캐시의 차이는 캐시를 어디에 두느냐입니다. 로컬 캐시는 각 API 서버 안에 임시로 저장해 둔 데이터여서 서버마다 따로 가지고 있습니다. Redis는 서버 밖에 있는 별도의 캐시 서버로, 서버 4대가 같은 곳에서 데이터를 읽습니다.

Redis를 도입하면 서버 4대가 같은 상품 정보를 보게 됩니다. 지금은 서버마다 캐시 내용이 달라서 가격을 바꿔도 서버마다 고객 화면에 반영되는 시점이 다릅니다. Redis에서 한 번 바뀌면 4대가 같은 값을 읽습니다.

다만 가격 변경이 고객 화면에 몇 분 안에 반영되는지는 Redis의 캐시를 얼마나 자주 새로 채우는지에 따라 달라집니다. 이 기준이 정해져야 최대 5분 지연이 없어지는지 말씀드릴 수 있습니다. Redis는 서버 밖에 있어서 상품을 읽을 때마다 네트워크를 한 번 거치므로 로컬 캐시보다 읽기가 느릴 수 있고, Redis 서버에 문제가 생기면 4대 서버 모두에 영향을 줄 수 있습니다.
