로컬 캐시는 서버 4대가 각자 따로 가진 저장 공간이고, Redis 캐시는 4대가 함께 쓰는 저장 공간 하나입니다. 캐시는 자주 쓰는 데이터를 임시로 저장해 두는 곳입니다.

지금은 API 서버 4대가 각자 자기 메모리에 상품 목록을 5분 동안 캐시합니다. 그래서 서버마다 캐시 내용이 다르고, 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다.

Redis(여러 서버가 함께 쓸 수 있는 캐시 서버)를 도입하면 캐시 서버 1대를 서버 4대가 같이 씁니다. 그래서 4대가 같은 캐시 내용을 보고, 서버마다 캐시 내용이 달라지는 문제가 없어집니다.
