Redis를 도입하면 서버 4대가 같은 상품 목록을 보게 되고, 가격을 바꿀 때 고객에게 늦게 반영되는 시간을 줄일 수 있습니다.

로컬 캐시는 API 서버 한 대가 자기 메모리에 임시로 저장해 두는 상품 목록입니다. 지금은 서버 4대가 각자 5분 동안 따로 저장합니다. 그래서 서버마다 저장한 시점이 다르고, 서버마다 보여 주는 내용이 다를 수 있습니다. 가격을 바꾸면 고객에게 최대 5분 늦게 반영되는 것도 이 때문입니다.

Redis 캐시는 서버 4대가 함께 쓰는 캐시 서버 1대에 상품 목록을 저장하는 방식입니다. 4대가 같은 저장소를 읽으므로 서버마다 내용이 달라지는 일이 없어집니다.

가격을 바꿀 때 Redis에 저장된 상품 목록을 바로 갱신하거나 지우면, 4대가 모두 새 가격을 보여 줄 수 있습니다. 이 경우 5분을 기다리지 않아도 됩니다.

확인 필요: 가격 변경 시 Redis의 상품 목록을 바로 갱신하거나 지우는 동작을 이번 도입 범위에 넣는지 정해야 합니다. 이 동작이 없으면 5분 저장 시간이 끝날 때까지 이전 가격이 남을 수 있습니다.
