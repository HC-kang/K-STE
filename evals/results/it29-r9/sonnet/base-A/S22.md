# 환불 기준 (상담원용)

## 1. 전액 환불
- 가입 후 **7일 이내**에 해지하면 **전액 환불**합니다.

## 2. 정산 시점
- **10월 31일 이후**에 접수된 환불 신청은 **11월 정산**에 포함합니다.

## 3. 승인 절차
- 환불 금액이 **50만 원을 초과**하면 **팀장 승인**을 받아야 합니다.
- 50만 원 이하의 환불은 위 승인 절차 대상이 아닙니다.

## 4. 상담 인력 운영
- 상담 대기 고객이 **20명**이 되면 상담원을 추가로 배치합니다.
