# 파일 공유 규정

## 1. 목적
이 문서는 사내 게시물의 파일 첨부와 외부 공유 시 지켜야 할 기준을 정리한 규정입니다.

## 2. 첨부 파일 규정

| 항목 | 기준 |
|---|---|
| 파일 1개당 최대 용량 | 25MB |
| 게시물당 최대 첨부 개수 | 10개 |

- 첨부 파일 하나가 25MB를 넘으면 업로드가 차단됩니다.
- 한 게시물에는 파일을 최대 10개까지 올릴 수 있습니다.

## 3. 외부 공유 링크 규정

### 3.1 유효 기간
- 외부 공유 링크는 생성한 시각부터 72시간이 지나면 자동으로 닫힙니다.

### 3.2 생성 제한
- 만 19세 미만 인턴은 외부 공유 링크를 만들 수 없습니다.

## 4. 계정 보안 규정
- 비밀번호를 5회 연속 틀리면 해당 계정은 30분 동안 잠깁니다.

## 5. 요약

| 구분 | 내용 |
|---|---|
| 파일 용량 | 개당 25MB 초과 시 업로드 차단 |
| 첨부 개수 | 게시물당 10개까지 |
| 외부 링크 생성 | 만 19세 미만 인턴은 불가 |
| 외부 링크 유효 시간 | 생성 후 72시간 |
| 로그인 실패 | 5회 연속 시 30분간 계정 잠금 |
