# 파일 공유 규정

이 문서는 사내 위키에서 파일을 첨부하고 외부 공유 링크를 만들 때 적용되는 기준을 정한다. 첨부 파일 크기, 게시물당 첨부 개수, 인턴의 외부 공유 링크 생성, 비밀번호 오류 시 계정 잠금, 외부 공유 링크의 유효 기간을 다룬다.

## 첨부 파일 크기

첨부 파일 하나의 크기는 25MB를 넘으면 안 된다. 시스템은 25MB를 넘는 파일의 업로드를 막는다.

## 게시물당 첨부 개수

한 게시물에 첨부하는 파일은 10개를 넘으면 안 된다.

## 인턴의 외부 공유 링크

만 19세 미만인 인턴은 외부 공유 링크를 만들면 안 된다.

## 비밀번호 오류와 계정 잠금

비밀번호를 5번 연속 틀리면 시스템이 계정을 30분 동안 잠근다.

## 외부 공유 링크의 유효 기간

시스템은 외부 공유 링크를 만든 시각부터 72시간이 지나면 해당 링크를 닫는다.
