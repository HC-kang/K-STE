# 파일 공유 규정

## 1. 목적

이 규정은 사내 위키에서 파일을 업로드하고 외부와 공유할 때 지켜야 할 기준을 정한다.

## 2. 적용 대상

사내 위키에 파일을 업로드하거나 외부 공유 링크를 만드는 모든 구성원에게 적용한다.

## 3. 파일 업로드 기준

3.1 첨부 파일 1개의 크기는 25MB 이하여야 한다. 25MB를 넘는 파일은 업로드할 수 없다.

3.2 한 게시물에는 파일을 최대 10개까지 첨부할 수 있다.

## 4. 외부 공유 링크 기준

4.1 외부 공유 링크는 만 19세 이상의 구성원만 만들 수 있다. 만 19세가 되지 않은 인턴은 외부 공유 링크를 만들 수 없다.

4.2 외부 공유 링크는 생성 시각부터 72시간이 지나면 자동으로 닫힌다.

## 5. 계정 보안 기준

5.1 비밀번호를 5회 연속 잘못 입력하면 해당 계정은 30분 동안 잠긴다.
