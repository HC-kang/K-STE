## 변경 내용

`auth/token.py`의 `is_valid()`에서 비교 조건을 `now <= expires_at`에서 `now < expires_at`로 바꿨다. 이 변경으로 만료 시각과 정확히 같은 시각에 들어온 요청은 유효한 토큰으로 판단되지 않는다.

## 원인

기존 `is_valid()`는 토큰 만료 시각과 정확히 같은 시각의 요청을 유효한 토큰으로 판단했다. 이 동작이 버그였다.

## 테스트

`test_token_expired_at_boundary`와 `test_token_valid_before_expiry` 테스트 2개를 추가했다.

## 검증

실행한 검사는 로컬 단위 테스트 전체다. 단위 테스트는 모두 통과했다.

실행하지 않은 검사는 통합 테스트다. 통합 테스트는 아직 실행하지 않았다.
