로컬 캐시는 서버 각자의 메모리(작업용 임시 공간)에 상품 목록을 보관하고, Redis 캐시는 서버 4대가 함께 쓰는 별도의 캐시 서버 1대에 보관합니다. 지금은 API 서버 4대가 각자 캐시를 5분 동안 보관하기 때문에 서버마다 내용이 다르고, 가격을 바꾸면 고객에게 최대 5분 늦게 보입니다.

Redis를 도입하면 서버 4대가 같은 캐시 서버를 보게 됩니다. 그래서 서버마다 상품 정보가 달라지는 문제는 없어집니다. 하지만 가격을 바꾼 뒤 고객에게 최대 5분 늦게 보이는 문제까지 함께 없어지는지는 아직 확인하지 않았습니다.

가격 변경이 바로 보여야 한다면 개발팀에 가격을 바꿀 때 캐시를 바로 지우는 방식을 넣을 수 있는지 확인하십시오.
