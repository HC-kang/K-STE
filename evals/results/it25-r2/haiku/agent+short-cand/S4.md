# 운영 payment-api 배포 롤백 런북

이 런북은 ArgoCD로 배포한 운영 payment-api를 이전 리비전으로 되돌리는 절차를 설명한다. 롤백 전에 그 배포에 DB 마이그레이션이 포함됐는지 반드시 확인해야 한다. 마이그레이션이 포함됐으면 롤백하면 안 되고 DBA 박지은에게 연락해야 한다.

## 사전 확인

1. 롤백할 배포에 DB 마이그레이션이 포함됐는지 확인한다.
2. **경고:** 마이그레이션이 포함됐으면 롤백하면 안 된다. 이 경우 롤백을 중단하고 DBA 박지은에게 연락한다.
3. 마이그레이션이 포함되지 않았으면 롤백할 리비전 번호를 정한다.

## 롤백

4. 다음 명령으로 payment-api를 롤백한다.

```
argocd app rollback payment-api <REVISION>
```

`<REVISION>`은 3번 단계에서 정한 리비전 번호로 바꾼다.

## 결과 확인

5. `/healthz`가 200을 반환하는지 확인한다.
6. 결제 테스트 주문 1건을 넣고 주문이 성공하는지 확인한다.

## 기록

7. 롤백 이력을 #deploy 채널에 남긴다.
