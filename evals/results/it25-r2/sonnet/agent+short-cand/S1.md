로컬 캐시는 서버마다 따로 갖는 임시 저장소이고, Redis 캐시는 서버 4대가 함께 쓰는 임시 저장소입니다. Redis를 도입하면 고객이 어느 서버에 접속하든 같은 상품 정보를 보게 됩니다.

현재는 API 서버(고객 요청을 받아 처리하는 서버) 4대가 각자 자기 메모리에 상품 목록을 5분 동안 저장합니다. 서버마다 저장한 시점이 달라서 서버마다 캐시 내용이 다릅니다. 그래서 가격을 바꾸면 서버에 따라 새 가격이 보이기도 하고 옛 가격이 보이기도 하며, 고객에게는 최대 5분 늦게 반영됩니다.

Redis는 캐시 서버 1대를 따로 두고 API 서버 4대가 모두 그 서버의 캐시를 읽는 방식입니다. 캐시가 한 곳에만 있으므로 서버 4대가 같은 내용을 봅니다. 가격을 바꾼 뒤 Redis의 캐시를 지우면 4대에 동시에 새 가격이 나옵니다.

다만 Redis를 도입하는 것만으로 최대 5분 지연이 없어지는지는 아직 모릅니다. 가격을 바꿀 때 캐시를 바로 지우도록 만드는지에 따라 달라지기 때문입니다.

확인 필요: 가격 변경 시 Redis 캐시를 바로 지우는 기능이 이번 도입 범위에 들어 있는지 개발팀에 확인해야 합니다.
