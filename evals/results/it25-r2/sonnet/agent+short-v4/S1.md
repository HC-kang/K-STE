로컬 캐시는 서버마다 따로 갖는 저장 공간이고, Redis 캐시는 서버 4대가 함께 쓰는 저장 공간입니다. 그래서 Redis를 도입하면 고객이 서버에 따라 다른 상품 정보를 보는 문제가 없어집니다.

캐시는 자주 보는 데이터를 미리 저장해 두고 꺼내 쓰는 공간입니다.

| 구분 | 로컬 캐시 (현재) | Redis 캐시 (도입 예정) |
|---|---|---|
| 위치 | API 서버 4대가 각자 자기 메모리에 둡니다. | 캐시 서버 1대에 둡니다. |
| 공유 | 서버끼리 내용을 공유하지 않습니다. | API 서버 4대가 같은 내용을 봅니다. |
| 상품 목록 보관 시간 | 서버마다 5분입니다. | 5분으로 둘지는 정해진 바가 없습니다. |

현재는 서버마다 캐시를 따로 저장하므로 서버마다 캐시 내용이 다릅니다. 그래서 가격을 바꾸면 고객에게 최대 5분 늦게 반영됩니다. Redis를 도입하면 서버 4대가 같은 캐시를 읽으므로 서버에 따라 가격이 다르게 보이는 일이 없어집니다.

확인 필요: 가격을 바꿀 때 Redis 캐시를 바로 갱신하는지, 최대 5분 지연이 줄어드는지는 제가 가진 정보에 없습니다.
