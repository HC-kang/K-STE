# 파일 공유 규정

이 문서는 사내 위키에서 파일을 올리고 외부와 공유할 때 적용하는 규정을 정한다. 첨부 파일 크기, 게시물당 파일 수, 외부 공유 링크, 비밀번호 입력 제한을 다룬다.

## 첨부 파일 크기

첨부 파일은 25MB를 넘으면 안 된다. 시스템은 25MB를 넘는 파일의 업로드를 막는다.

## 게시물당 파일 수

한 게시물에는 파일을 10개까지 올릴 수 있다.

## 외부 공유 링크

만 19세 미만인 인턴은 외부 공유 링크를 만들 수 없다.

외부 공유 링크는 만든 시각부터 72시간이 지나면 닫힌다.

## 비밀번호 입력 제한

비밀번호를 연속으로 5번 틀리면 계정을 30분 동안 잠근다.
