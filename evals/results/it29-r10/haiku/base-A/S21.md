# 파일 공유 규정

## 1. 목적

이 규정은 사내 위키에 게시하는 파일과 외부 공유 링크의 관리 기준을 정하여 정보 유출을 막고 안전한 파일 공유 환경을 유지하는 것을 목적으로 한다.

## 2. 적용 대상

사내 위키를 사용하는 모든 임직원과 인턴에게 적용한다.

## 3. 파일 업로드 기준

1. **파일 크기**: 첨부 파일 하나의 크기가 25MB를 넘으면 업로드할 수 없다.
2. **파일 개수**: 한 게시물에는 파일을 최대 10개까지 올릴 수 있다.

## 4. 외부 공유 링크 기준

1. **인턴의 외부 공유 링크 생성 제한**: 만 19세 미만인 인턴은 외부 공유 링크를 만들 수 없다.
2. **링크 유효기간**: 외부 공유 링크는 생성한 시각부터 72시간이 지나면 자동으로 닫힌다.

## 5. 계정 보안 기준

1. 비밀번호를 연속으로 5회 틀리면 계정이 30분 동안 잠긴다.
2. 잠금 기간 동안에는 해당 계정으로 로그인할 수 없다.
