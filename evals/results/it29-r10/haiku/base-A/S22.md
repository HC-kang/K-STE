# 환불 기준 안내 (고객센터 상담원용)

## 1. 해지 및 전액 환불

- **기준:** 가입 후 7일 이내에 해지한 고객에게 **전액 환불**합니다.

## 2. 환불 신청의 정산 월 배정

- **기준:** 10월 31일 이후에 접수된 환불 신청은 **11월 정산**에 포함합니다.

## 3. 팀장 승인 필요 기준

- **기준:** 환불 금액이 **50만 원을 초과**하면 **팀장 승인**을 받은 후 처리합니다.

## 4. 상담 인력 배치 기준

- **기준:** 상담 대기 고객이 **20명**에 도달하면 상담원을 추가 배치합니다.

---

### 상담원 확인 사항

아래 항목은 현재 기준에 명시되어 있지 않으므로, 상담 전 담당자에게 확인하시기 바랍니다.

- 7일의 기산점(가입 완료 시점 기준인지, 결제 시점 기준인지)
- 10월 31일 당일 접수 건의 처리 방식
- 환불 금액 50만 원의 포함 여부(50만 원 정각은 승인 대상인지)
- 상담 대기 고객 20명의 판단 시점(실시간 기준인지, 일 단위 집계인지)
