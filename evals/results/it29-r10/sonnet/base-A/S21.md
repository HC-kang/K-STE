# 파일 공유 규정

## 1. 목적
이 문서는 사내에서 파일을 업로드하고 공유할 때 지켜야 할 기준을 정리한 것입니다.

## 2. 업로드 제한

| 항목 | 기준 |
|---|---|
| 첨부 파일 1개당 용량 | 25MB 이하 (25MB를 넘으면 업로드가 차단됩니다) |
| 게시물당 첨부 파일 수 | 최대 10개 |

## 3. 외부 공유 링크

### 3.1 링크 유효 시간
- 외부 공유 링크는 생성 시각부터 **72시간**이 지나면 자동으로 닫힙니다.
- 72시간이 지난 뒤에도 공유가 필요하면 링크를 새로 만들어야 합니다.

### 3.2 인턴의 링크 생성 제한
- 만 19세가 되지 않은 인턴은 외부 공유 링크를 만들 수 없습니다.

## 4. 계정 보안
- 비밀번호를 **5번 연속** 틀리면 계정이 **30분간** 잠깁니다.

## 5. 요약

- 파일 1개당 25MB 초과 시 업로드 차단
- 게시물당 파일 10개까지
- 만 19세 미만 인턴은 외부 공유 링크 생성 불가
- 비밀번호 5회 연속 오류 시 30분간 계정 잠금
- 외부 공유 링크는 생성 후 72시간이 지나면 종료
