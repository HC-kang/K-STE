# 대체어 표

왼쪽 표현을 보면 오른쪽으로 바꾼다. "판단" 열이 있는 표현은 일괄로 바꾸지 않는다. 문맥을 보고 정한다.

## 바로 바꾸는 표현

| 표현 | 바꿀 말 |
|---|---|
| 보여지다, 되어지다, 쓰여지다 | 보이다, 되다, 쓰이다 |
| 진행하다, 실시하다, 수행하다 | 하다. 원문에 있는 명사를 동사로 쓴다: "점검을 진행했다" → "점검했다" |
| ~에 있어서 | ~에서, ~할 때 |
| ~을 필요로 하다 | ~이 필요하다 |
| ~에 위치하다 | ~에 있다 |
| 개선시키다, 향상시키다, 감소시키다 | 개선하다, 높이다, 줄이다 |
| ~하는 것으로 판단됩니다 | ~로 보입니다 (재작성에서는 확인 여부를 모르므로 "~입니다"로 바꾸지 않는다) |
| ~할 수 있도록 하겠습니다 | ~하겠습니다 |
| 금일, 익일, 명일 | 오늘, 다음 날, 내일 |
| 과반수 이상, 유무 여부 | 과반수, 여부 |
| 약 500여 개 | 약 500개 또는 500여 개 |
| 및 | 와/과 |

## 지우는 표현

| 표현 | 이유 |
|---|---|
| 다양한, 효율적인, 원활한, 강력한, 혁신적인, 획기적인 | 근거 없는 평가다. 수치나 사실로 바꾸거나 지운다. |
| ~하는 것이 중요합니다, ~에 주목할 필요가 있습니다 | 중요한 이유를 쓰거나 지운다. |
| 결론적으로, 요약하자면 | 결론은 첫 문장에 이미 있다. |
| 좋은 질문입니다, 물론입니다 | 인사다. |
| 살펴보겠습니다, 정리해 드리겠습니다 | 자기 서술이다. 결과를 바로 쓴다. |
| 필요하시면 말씀해 주세요, 원하시면 ~해 드릴 수 있습니다 | 맺음 제안이다. |
| 단순히 A가 아니라 B입니다 | 대구 수사다. "B입니다."로 쓴다. |
| 핵심은 ~입니다 | "~입니다."로 쓴다. |

## 판단해서 바꾸는 표현

| 표현 | 그대로 둘 때 | 바꿀 때 |
|---|---|---|
| ~에 대해, ~에 대한 | 다루는 주제를 가리킬 때: "보안에 대한 문서" | 군말일 때: "일정에 대해 공지" → "일정을 공지" |
| ~를 통해 | 경로나 수단일 때: "VPN을 통해 접속" | 동사로 풀 수 있을 때: "교육을 통해 개선" → "교육해서 개선" |
| ~로 인해 | 원인을 강조할 때 | "~ 때문에", "~로"가 더 짧을 때 |
| ~의 경우 | 여러 경우를 나눠 비교할 때 | 한 대상만 가리킬 때: "모바일 앱의 경우 느립니다" → "모바일 앱은 느립니다" |
| ~할 경우 | 법령이나 계약 문구를 인용할 때 | "~하면" |
| ~것 같습니다 | 추론임을 밝힐 때 (헤지는 문장당 하나) | 확인한 사실일 때: "~입니다" |
